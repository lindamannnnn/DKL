## 提示

- 即梦网址：https://jimeng.jianying.com/
- 每次输入 Prompt 后，选择 **图片生成** → **比例 16:9**，点生成
- 生成效果不满意时，可以在 Prompt 末尾加 `细腻，高细节` 或 `HD pixel art` 来提升质量
- 如果即梦不支持英文参数如 `--ar`，在平台内选择 16:9 比例即可，把 Prompt 里的 `--ar 16:9 --style pixel-art --v 5` 去掉
