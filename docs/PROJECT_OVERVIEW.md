# DKL 项目架构与设计说明

> DKL 是一个面向 4-6 年级小学生的 C++ 信奥自学平台。本文档记录系统的整体架构和几个关键模块的设计取舍。

## 一句话概括

**DKL = Markdown 微课渲染引擎 + 在线判题（IOI 部分分）+ AI 竞赛教练 + 课件质量评测体系。**

要解决的问题：不懂 C++ 的家长或机构，如何让孩子在家系统、正确地自学 GESP C++ 1-8 级。

## 数据模型（多租户，16 张表）

```
Tenant ── User ── Class ── ClassStudent / ClassCourse
Course ── Chapter ── Lesson ── LearningProgress
Problem ── TestCase ── Submission（含 aiFeedback）
Exam ── ExamProblem ── StudentExam
AIConversation / FeedbackReport / Achievement / UserAchievement / Mistake
```

所有业务表含 `tenant_id`，通过 `X-Tenant-Id` Header / JWT 做多机构数据隔离。`TestCase.score` 支撑 IOI 部分分；`Submission.aiFeedback` 落库 AI 点评供复盘。

## 关键模块设计

### 1. AI 教练：三层护栏

直接拿大模型教小学生是有风险的。实测发现裸调 LLM 会出现：把 `cin`/`cout` 操作符讲反、直接给完整答案、编造语法规则、超前讲没学过的内容。对教学场景这些都不能接受，所以做了三层：

```
学生提问 / 提交错误代码
        │
        ▼
┌─────────────────────────────┐
│ Layer 1: 事实知识库          │  高频语法问题（cin/cout、头文件、分号…）
│ aiKnowledgeBase.ts          │  命中 → 直接返回标准答案，不调 LLM
└─────────────┬───────────────┘
              │ 未命中
              ▼
┌─────────────────────────────┐
│ Layer 2: 编译错误规则引擎     │  15+ 确定性错误模式匹配
│ errorRules.ts               │  编译错误不走 LLM
└─────────────┬───────────────┘
              │
              ▼
┌─────────────────────────────┐
│ Layer 3: LLM + 护栏          │  · 知识点白名单 + 课时上下文（防超纲）
│ aiFeedbackService.ts        │  · "不确定就承认"（防编造）
│  温度 0.3 批改 / 0.7 聊天    │  · 只给思路不给完整代码（防抄答案）
└─────────────────────────────┘
```

一个细节：规则引擎只把"错误原因"传给 LLM，**不传"修复建议"**——避免 LLM 复述出完整修复代码，违反"不给答案"的原则。

### 2. 课件质量评测：双智能体学生

课件质量不靠"感觉不错"。建了一套有证据锚点的测量体系：

- **两个学生人设**（`docs/agents/`）：一个零基础、一个略有基础，模拟真实理解边界。
- **客观测量准则**（`evaluation-rubric-v1.md`）：禁止凭空打分；测"能否独立解题"时必须遮住示例代码（看着示例写等于没测）；每条结论要能指出证据在第几页/哪道题。
- **闭卷独立完成测试**：✅/🟡/❌ 三级判定 + 明确公式算完成度。
- **逐课评测报告**（`docs/reports/`）：GESP 1 级 18 课、GESP 3 级 20 课均产出报告，反向驱动了多轮课件修复（如剔除超认知的"前缀和"、把数组下标统一为从 1 开始等）。

### 3. 判题系统：IOI 部分分 + 题库流水线

- **IOI 部分分**：每个测试点独立计分，逐点返回 AC/WA/TLE/MLE/RE，而非"全对或全错"。
- **题库流水线**：从多个公开 OJ 源（东方博宜 1042 / 一本通 / CSP 真题等）抓取 → 清洗（修 markdown 转义、配对 in/out、兼容 `.ans`）→ 按 GESP 1-8 级分级 → 幂等导入 → 校验。当前库内 1500+ 道带测试数据的可判题。
- 导入器：`server/src/scripts/import-general.ts`（通用，兼容多套目录结构）。

## 项目现状

- 已跑通：全栈系统、判题、AI 教练（带护栏）、激励系统、模拟考试、1500+ 题库、GESP 1-3 级课件 + 评测闭环。
- 进行中：AI 大模型 Key 的真实效果验证、GESP 4-8 级课件、生产环境云端部署、E2E 集成测试。
- 已知边界：部分题目测试点数量待补全；AI 在复杂编译错误上仍引导回真人老师。
