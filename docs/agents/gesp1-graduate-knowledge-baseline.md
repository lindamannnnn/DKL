## 已经理解的概念

### 01 走进 C++ 之后

- 程序有固定骨架五件套：`#include <bits/stdc++.h>`、`using namespace std;`、`int main()`、`cout`、`return 0;`
- `main()` 是程序入口，电脑从这里开始执行
- `#include <bits/stdc++.h>` 是打开万能工具箱（全课程统一使用这个头文件）
- `cout << ... << endl;` 是小喇叭，让电脑输出文字
- `cin >> 变量;` 是小耳朵，让用户输入数字
- `int` 是装整数的盒子
- `int age = 10;` 是创建盒子并同时放数进去（初始化）
- `=` 在 C++ 里是"把右边放进左边"，不是数学里的等于
- 很多语句末尾要加分号 `;`，像一句话的句号
- 大括号 `{}` 要成对出现
- 会用 `+`、`-`、`*`、`/` 做基本算术运算（已初步知道整数相除会丢小数，02 课细讲）

### 02 整数运算 之后

- `/` 是整数除法，会丢掉小数，`5 / 2` 结果是 `2`
- `%` 是取余数，`5 % 2` 结果是 `1`
- `long long` 是超大整数盒子，数字超过 21 亿要用它
- 变量名规则：只能由字母、数字、下划线组成，不能以数字开头，不能用 `int`、`return` 等关键字
- 常量是不变的数（如 `100`、`3.14`、`'A'`），变量是可以换内容的盒子
- 拆数字口诀：`n % 10` 取个位，`n = n / 10` 去掉个位
- 时间换算：总秒数 `/ 3600` 得小时，余数 `/ 60` 得分钟，最后 `% 60` 得秒
- 星期计算：`(a + b) % 7`，注意题目若说 0 代表星期日要特判
- 最小公倍数枚举（从较大数开始逐个试）在例题里见过，但配套的 `while` 和 `?:` 当时明确"看不懂没关系"，不算掌握

### 03 小数运算 之后

- `double` 是装小数的盒子（`float` 也是小数盒子但位数少，小学阶段主要用 `double`）
- 保留 n 位小数：`fixed << setprecision(n)`（`bits/stdc++.h` 已包含所需工具，不用另加头文件）
- 整数变小数：给其中一个数穿 `(double)` 外套，如 `(double)a / b`
- 隐式转换陷阱：`double c = a / b;` 仍然先算整数除法，必须在运算前就把其中一个转成 `double`
- 四舍五入保留小数和数学课类似
- 知道小数有浮点误差（`0.1 + 0.2` 不是精确的 0.3），答案差一点点不用慌；听说过"四舍六入五凑双"，但比赛先用 `setprecision` 就够了
- `//` 是单行注释，`/* */` 是多行注释
- 温度转换公式：摄氏 `C = K - 273.15`，华氏 `F = C × 1.8 + 32`

### 04 练习课：计算小达人 之后

- 做题要先审题：输入几个数、输出什么、要不要保留小数
- 算平均分时，不能写 `total / 3`，要写 `total / 3.0` 或转 `double`
- 单位换算要小心，比如分转元要除以 100

### 05 分支入门 之后

- `if (条件) { ... }`：条件成立才执行
- `if (条件) { ... } else { ... }`：二选一
- 比较大小用 `>`、`<`、`>=`、`<=`、`==`、`!=`
- 判断相等必须写 `==`，不能写 `=`
- `bool` 是开关盒子，只有 `true`/`false`，输出显示 `1`/`0`
- 用 `n % 2 == 0` 判断偶数，用 `n % b == 0` 判断倍数

### 06 双路分支（分支嵌套与多条件） 之后

- `if` 里面可以再写 `if`，像俄罗斯套娃
- `&&` 是"并且"，两边都要成立
- `||` 是"或者"，一边成立就行
- 嵌套建议最多两层，太多会晕

### 07 多路分支 之后

- `if-else if-else` 像排队上车，只执行其中一个分支
- 多分支条件要从高到低排，否则高分会被低分条件"截胡"
- `!` 是"不是"，把结果反过来
- 运算符优先级：先算术、再关系、再逻辑（`!` 然后 `&&` 最后 `||`），赋值最低；复杂条件靠加小括号保命
- 闰年判断：`(y % 4 == 0 && y % 100 != 0) || y % 400 == 0`
- 长题拆读三步法：输入什么 → 怎么算（翻译成"如果…就…"）→ 输出什么
- 分段计费、方案比较都可以翻译成多分支

### 08 练习课：分支大冒险 之后

- 分支三种形式综合运用：单分支、双分支、多分支
- 三角形判断：`a + b > c && a + c > b && b + c > a`
- 月份季节判断用 `||` 组合多个值
- 嵌套 `if` 处理"温度 + 天气"组合条件

### 09 字符类型与 switch 之后

- `char` 装一个字符，字符要用单引号 `'A'`，不能用双引号
- ASCII 编码：每个字符都有编号，`'A'` 是 65、`'a'` 是 97、`'0'` 是 48
- `'A'` 到 `'Z'` 是大写，`'a'` 到 `'z'` 是小写，`'0'` 到 `'9'` 是数字字符
- `(int)'A'` 可以把字符看成编号，`(char)65` 可以把编号看成字符；`'5'` 是字符，不是数字 5
- 大写转小写加 32：`ch = ch + 32`
- 小写转大写减 32：`ch = ch - 32`
- `switch(变量)` 适合固定几个值的多选一，不能判断范围（口诀：固定值用 switch，有范围用 if）
- `case` 后面写可能的值，末尾一般要加 `break`
- `default` 是上面都不匹配时执行

### 10 for 循环 之后

- `for (int i = 1; i <= n; i++)` 三个部分：从哪开始、继续条件、每次变化
- `i++` 等价于 `i = i + 1`；`i++`（先用后加）和 `++i`（先加后用）和别人一起用时有区别，单独写效果一样
- 可以倒着数：`for (int i = n; i >= 1; i--)`
- 累加器：`int sum = 0;` 然后 `sum = sum + i;`
- 平方和也能累加：`sum = sum + i * i;`
- `for` 后面不能加分号，否则循环体为空
- 枚举法：从 1 试到 n，看哪些数符合条件
- 全局变量住在所有函数外面、默认初始化为 0；局部变量住在大括号里、不初始化是随机值（要养成创建即初始化的习惯）

### 11 循环控制 之后

- `break` 是直接退出整个循环
- `continue` 是跳过本次，进入下一次循环
- 两个英文单词容易记混，要先想中文动作
- 质数判断：先用 `bool isPrime = true;` 假设是质数，找到能整除的数就改成 `false` 并 `break`
- 优化：只要试到 `i * i <= n`
- `for` 中间条件空着表示一直循环，必须配合 `break`
- 双重循环在本课只是拓展了解（课件明确标注是 GESP2 内容），能看懂"外层走一次、内层完整跑一圈"即可

### 12 练习课：循环闯关 之后

- `for`、`break`、`continue` 综合运用
- 找第一个满足条件的数：`for (int i = 1; ; i++)` + `break`
- 数字金字塔需要双重循环，能看懂并模仿

### 13 求和计数 之后

- 循环输入求和：`sum = 0`，每次读一个数加进去
- 求平均：`(double)sum / n`，记得转小数
- 计数：`count = 0`，满足条件就 `count++`
- 找最大值：先读第一个数当老大，遇到更大的就换
- 找最小值：先读第一个数当最小，遇到更小的就换
- 因子和：枚举 `i` 从 1 到 n，`n % i == 0` 就把它加进 `sum`
- 多组数据：先读 `T`，再循环 `T` 次

### 14 while 循环 之后

- `while (条件) { ... }`：先判断条件，成立再执行
- `while` 适合"不知道循环几次"的情况
- `do-while` 先执行一次再判断，至少执行一次（课件说明 GESP1 不作硬性要求，会写最简单形式即可）
- 输入 0 才停止的套路：先 `cin >> x;` 再 `while (x != 0) { ... cin >> x; }`
- 复合赋值：`+=`、`-=`、`*=`、`/=`、`%=` 让代码更短
- 循环里一定要记得让条件变量变化，否则会死循环

### 15 短除法 之后

- `while (t--)` 可以循环 t 次
- 用 `while (n > 0)` 拆数字：`n % 10` 取个位，`n = n / 10` 去掉个位
- 数位和：`sum = 0`，每次加 `n % 10`
- 数位积：`product = 1`，每次乘 `n % 10`（乘法要从 1 开始，从 0 开始结果永远是 0）
- 找数字：用 `bool found = false`，找到就 `true` 并 `break`
- 统计次数：`count = 0`，符合条件就 `count++`
- 数字反转：`rev = rev * 10 + n % 10`
- 数字重构（拆位→改数字→拼回）：用 `ans = ans * 10 + d` 从个位拼新数，注意先拼出来的是倒序，需要再反转一次

### 16 练习课：数字拆解与统计 之后

- 综合运用求和、计数、最大最小、拆位
- 拆位时一定记得 `n = n / 10`，不然会死循环
- 求乘积时 `product` 要从 1 开始，不能从 0 开始

### 17 C 风格输入输出 之后

- `printf` / `scanf` 也用 `#include <bits/stdc++.h>`（课程统一头文件）
- `printf("...%d...", n);` 中 `%d` 是整数占位符
- `scanf("%d", &n);` 变量前面必须加 `&`
- `%f` 用来 `printf` 输出小数，`%lf` 用来 `scanf` 读 double
- 读 `long long` 用 `%lld`；`printf` 里用 `\n` 换行
- `%02d` 表示整数占 2 位、不够补 0
- `%.2f` 表示保留 2 位小数
- 两套输入输出不要混用，尤其不要在同一行里混 `cin` 和 `scanf`
- 建议初学先用 `cin`/`cout`，需要格式化再换 `scanf`/`printf`

### 18 练习课：GESP1 综合大闯关 之后

- 能把输入输出、计算、分支、循环、格式化输出串起来用
- 本课综合题：同时被 3 和 5 整除判断、字母大小写互换、乘法表一行、条件求和、`Price: ¥%.2f` 价格格式化
- 综合题独立做时仍偏模仿示例，需要多练

### 19 真题练习课：2026 年 3 月 之后

- 做过一套完整 GESP1 真题（单选、判断、两道编程题），熟悉考试题型
- 应试技巧：选择题用排除法；读代码题在纸上逐行模拟变量变化；编程题先写输入输出框架，再写核心逻辑
- 计算机常识：能区分硬件（输入/输出/存储设备、CPU）和软件（操作系统、应用程序）
- 编程题"交朋友"：找身高差最小的人，平局选更矮的；用 `if (d < 0) d = -d;` 手动求绝对值
- 编程题"数字替换"（4 换 8）：用位权 `t *= 10`、`b += t * d` 从个位直接拼新数（与 15 课的"反转两次"是两种做法，都见过）
- 见过真题陷阱：`a, b = 3, 4;` 不是同时赋值，只有 `b` 被赋成 4，`a` 不变

### 20 真题练习课：2026 年 6 月 之后

- 完成第二套真题，巩固读代码与避坑能力
- 真题陷阱专项：`=` 和 `==` 混淆、`i++`/`++i` 会改变循环次数、变量未初始化（如 `total *= n`）结果不确定
- 质数判断的循环条件可以写 `i < N`、`i <= N / 2`、`i * i <= N`，但不能写 `i <= N`（否则 `N % N == 0` 会误判）
- 环形位置用取模：秒针位置 `(start + n) % 60`，回到 12 点方向即 `pos == 0`
- 编程题"去旅行"：多种方案分别算出总价，再比较取最小
- 编程题"交税"：循环读 12 个月收入，超过 800 的部分乘 0.2 累加，最后 `printf("%.2f")` 输出（分支 + 循环 + 小数 + 格式化综合）

## 还经常犯的错误 / 还会困惑的点

- 一着急会把 `==` 写成 `=`
- 复杂分支的大括号 `}` 配对容易乱
- 算平均分时，第一反应还是可能写成 `sum / n`
- `break` 和 `continue` 的英文偶尔会记混
- `switch` 里某个 `case` 会忘记写 `break`
- `scanf` 里经常忘记加 `&`
- `%lf`（输入）和 `%f`（输出）容易搞反
- 综合题或变式题，自己从头写还是会卡
