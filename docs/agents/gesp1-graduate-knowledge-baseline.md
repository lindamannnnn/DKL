## 已经理解的概念

### 01 走进 C++ 之后

- 程序有固定骨架五件套：`#include <bits/stdc++.h>`、`using namespace std;`、`int main()`、`cout`、`return 0;`
- `main()` 是程序入口，电脑从这里开始执行
- `#include <bits/stdc++.h>` 是打开万能工具箱（全课程统一使用这个头文件）
- `cout << ... << endl;` 是小喇叭，让电脑输出文字
- `cin >> 变量;` 是小耳朵，让用户输入数字
- `int` 是装整数的盒子
- `int age = 10;` 是创建盒子并同时放数进去（初始化）
- `=` 在 C++ 里是"把右边放进左边"，不是数学里的等于
- 很多语句末尾要加分号 `;`，像一句话的句号
- 大括号 `{}` 要成对出现

### 02 整数运算 之后

- `/` 是整数除法，会丢掉小数，`5 / 2` 结果是 `2`
- `%` 是取余数，`5 % 2` 结果是 `1`
- `long long` 是超大整数盒子，数字超过 21 亿要用它
- 变量名规则：只能由字母、数字、下划线组成，不能以数字开头，不能用 `int`、`return` 等关键字
- 拆数字口诀：`n % 10` 取个位，`n = n / 10` 去掉个位
- 时间换算：总秒数 `/ 3600` 得小时，余数 `/ 60` 得分钟，最后 `% 60` 得秒

### 03 小数运算 之后

- `double` 是装小数的盒子
- 保留 n 位小数：`fixed << setprecision(n)`（`bits/stdc++.h` 已包含所需工具，不用另加头文件）
- 整数变小数：给其中一个数穿 `(double)` 外套，如 `(double)a / b`
- 四舍五入保留小数和数学课类似
- `//` 是单行注释，`/* */` 是多行注释

### 04 练习课：计算小达人 之后

- 做题要先审题：输入几个数、输出什么、要不要保留小数
- 算平均分时，不能写 `total / 3`，要写 `total / 3.0` 或转 `double`
- 单位换算要小心，比如分转元要除以 100

### 05 分支入门 之后

- `if (条件) { ... }`：条件成立才执行
- `if (条件) { ... } else { ... }`：二选一
- 比较大小用 `>`、`<`、`>=`、`<=`、`==`、`!=`
- 判断相等必须写 `==`，不能写 `=`
- `bool` 是开关盒子，只有 `true`/`false`，输出显示 `1`/`0`
- 用 `n % 2 == 0` 判断偶数，用 `n % b == 0` 判断倍数

### 06 双路分支（分支嵌套与多条件） 之后

- `if` 里面可以再写 `if`，像俄罗斯套娃
- `&&` 是"并且"，两边都要成立
- `||` 是"或者"，一边成立就行
- 三目运算符 `?:` 可以写简单二选一，如 `(a > b) ? a : b`
- 嵌套建议最多两层，太多会晕

### 07 多路分支 之后

- `if-else if-else` 像排队上车，只执行其中一个分支
- 多分支条件要从高到低排，否则高分会被低分条件"截胡"
- `!` 是"不是"，把结果反过来
- 复杂条件靠加小括号保命
- 分段计费、方案比较都可以翻译成多分支

### 08 练习课：分支大冒险 之后

- 分支三种形式综合运用：单分支、双分支、多分支
- 三角形判断：`a + b > c && a + c > b && b + c > a`
- 月份季节判断用 `||` 组合多个值
- 嵌套 `if` 处理"温度 + 天气"组合条件

### 09 字符类型与 switch 之后

- `char` 装一个字符，字符要用单引号 `'A'`，不能用双引号
- `'A'` 到 `'Z'` 是大写，`'a'` 到 `'z'` 是小写，`'0'` 到 `'9'` 是数字字符
- 大写转小写加 32：`ch = ch + 32`
- 小写转大写减 32：`ch = ch - 32`
- `switch(变量)` 适合固定几个值的多选一
- `case` 后面写可能的值，末尾一般要加 `break`
- `default` 是上面都不匹配时执行

### 10 for 循环 之后

- `for (int i = 1; i <= n; i++)` 三个部分：从哪开始、继续条件、每次变化
- `i++` 等价于 `i = i + 1`
- 可以倒着数：`for (int i = n; i >= 1; i--)`
- 累加器：`int sum = 0;` 然后 `sum = sum + i;`
- `for` 后面不能加分号，否则循环体为空
- 枚举法：从 1 试到 n，看哪些数符合条件

### 11 循环控制 之后

- `break` 是直接退出整个循环
- `continue` 是跳过本次，进入下一次循环
- 两个英文单词容易记混，要先想中文动作
- 质数判断：先用 `bool isPrime = true;` 假设是质数，找到能整除的数就改成 `false` 并 `break`
- 优化：只要试到 `i * i <= n`
- `for` 中间条件空着表示一直循环，必须配合 `break`

### 12 练习课：循环闯关 之后

- `for`、`break`、`continue` 综合运用
- 找第一个满足条件的数：`for (int i = 1; ; i++)` + `break`
- 数字金字塔需要双重循环，能看懂并模仿

### 13 求和计数 之后

- 循环输入求和：`sum = 0`，每次读一个数加进去
- 求平均：`(double)sum / n`，记得转小数
- 计数：`count = 0`，满足条件就 `count++`
- 找最大值：先读第一个数当老大，遇到更大的就换
- 找最小值：先读第一个数当最小，遇到更小的就换
- 多组数据：先读 `T`，再循环 `T` 次

### 14 while 循环 之后

- `while (条件) { ... }`：先判断条件，成立再执行
- `while` 适合"不知道循环几次"的情况
- `do-while` 先执行一次再判断，至少执行一次
- 输入 0 才停止的套路：先 `cin >> x;` 再 `while (x != 0) { ... cin >> x; }`
- 复合赋值：`+=`、`-=`、`*=`、`/=`、`%=` 让代码更短
- 循环里一定要记得让条件变量变化，否则会死循环

### 15 短除法 之后

- `while (t--)` 可以循环 t 次
- 用 `while (n > 0)` 拆数字：`n % 10` 取个位，`n = n / 10` 去掉个位
- 数位和：`sum = 0`，每次加 `n % 10`
- 数位积：`product = 1`，每次乘 `n % 10`
- 找数字：用 `bool found = false`，找到就 `true` 并 `break`
- 统计次数：`count = 0`，符合条件就 `count++`
- 数字反转：`rev = rev * 10 + n % 10`

### 16 练习课：数字拆解与统计 之后

- 综合运用求和、计数、最大最小、拆位
- 拆位时一定记得 `n = n / 10`，不然会死循环
- 求阶乘：`product = 1`，从 1 乘到 n

### 17 C 风格输入输出 之后

- `printf` / `scanf` 也用 `#include <bits/stdc++.h>`（课程统一头文件）
- `printf("...%d...", n);` 中 `%d` 是整数占位符
- `scanf("%d", &n);` 变量前面必须加 `&`
- `%f` 用来 `printf` 输出小数，`%lf` 用来 `scanf` 读 double
- `%02d` 表示整数占 2 位、不够补 0
- `%.2f` 表示保留 2 位小数
- 建议初学先用 `cin`/`cout`，需要格式化再换 `scanf`/`printf`

### 18 练习课：GESP1 综合大闯关 之后

- 能把输入输出、计算、分支、循环、格式化输出串起来用
- 闰年判断、累加和、字符类型判断、最大值、温度转换格式化都能做
- 综合题独立做时仍偏模仿示例，需要多练

## 还经常犯的错误 / 还会困惑的点

- 一着急会把 `==` 写成 `=`
- 复杂分支的大括号 `}` 配对容易乱
- 算平均分时，第一反应还是可能写成 `sum / n`
- `break` 和 `continue` 的英文偶尔会记混
- `switch` 里某个 `case` 会忘记写 `break`
- `scanf` 里经常忘记加 `&`
- `%lf`（输入）和 `%f`（输出）容易搞反
- 综合题或变式题，自己从头写还是会卡
