### 课程03：小数运算

**核心知识点**
- `int` 装不下小数，要用 `double`
- 保留小数：`fixed` + `setprecision(n)`，需要 `#include <iomanip>`
- 四舍六入五凑双规则
- 把整数变成小数：`(double)a / b` 或 `a / 100.0`
- 注释：`//` 单行、`/* */` 多行

## 4. 遇到的注意点

1. **输出格式要严格匹配**
   - 有些题要求输出空字符串（如“小明有没有考到90分”不满足时），此时不能加 `endl`。
   - 带标签的输出（如圆的立体几何）标签大小写、等号位置必须与样例一致。
2. **整数除法会丢小数**
   - 第 3 课所有涉及小数的题目，都必须显式把某个数转成 `double` 或使用 `x.0` 写法。
3. **拆位顺序**
   - `%10` 取个位，`/10` 去掉个位；倒序时要把取到的个位放到高位。
4. **逻辑运算符优先级**
   - 闰年条件要用小括号包起来：`((y%4==0 && y%100!=0) || y%400==0)`。
5. **多分支顺序**
   - 成绩、等级类题目要从高到低判断，否则高分会被低分条件“截胡”。
