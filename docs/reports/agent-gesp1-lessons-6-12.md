## 6. 遇到的注意点

1. **提交频率限制**
   - 后端 `/api/submissions` 有 15 分钟 50 次的 rate limit。验证脚本中每次提交后 sleep 800ms，并把后端重启了一次以重置计数器，最终顺利完成 35 题。
2. **Docker 服务未启动**
   - 本次开机后 Docker Desktop 未运行，导致数据库和 JudgeServer 无法连接。需要先启动 Docker Desktop，再等待容器自动恢复。
3. **保留进度 vs 重新导入**
   - 直接修改课件 Markdown 后，运行 `update-lessons-6-12.ts` 仅更新对应 3 个课时的 `content` 和 `rawMarkdown`，不影响 `learning_progress`。
   - 若后续需要全量重建课程，再运行 `import-gesp1.ts`，但要注意它会清空 GESP1 全部学习进度。
4. **输出格式严格匹配**
   - `求落地次数` 样例输入为 `0`，程序应直接按题意计算并输出，不读取输入。
   - `小明的幸运数` 只需输出个数，不要额外空格或标签。
   - `小兔子的最大活动面积` 注意篱笆总长为 `n`，周长 `2*(l+w)=n`，所以 `w = n/2 - l`。

- **可改进点**：
  - 课程07 的“三位回文数”需要用整数除法和取余比较百位与个位，虽然是已学运算，但对刚学 `for` 的同学仍是一道小综合题，建议在题面给出更明确的提示。
