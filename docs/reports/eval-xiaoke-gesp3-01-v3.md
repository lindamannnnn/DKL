## 逐页第一反应（按 `## ` 分页，边看边记）

- **P1 标题+目标**：目标写着"找最大值和它的位置"，我在 GESP1-13 学过找最大最小值，心里踏实。
- **P2 故事**：写 50 个变量写到手酸，哈哈这个我懂，`int s1, s2, s3...` 想想就累。想知道"大柜子"是什么。
- **P3 回顾**：`for (int i = 1; i <= n; i++)` 我熟，GESP1-10 学的。
- **P4 什么是数组**："一排编了号的储物柜"🗄️，一个名字管整排——这个比喻我一下子就记住了。
- **P5 数组的定义**：`类型 数组名[大小];`，`int a[5];` 就是申请 5 个连在一起的 int 柜子。⚠️说大小必须是固定数字不能写变量，我记住了：申请的时候电脑就要知道几个柜子。比赛开大一点比如 `a[105]`，多留余量。demo 我照着能看懂，`a[0] = 90` 就是往 0 号柜放 90。
- **P6 检查点**：选 B，中括号！A 是小括号不对，C 没写大小，电脑不知道申请几个。✅
- **P7 下标从 0 开始**：编号叫"下标"，从 0 数！`a[5]` 越界——"超出柜子的编号范围"。有解释，懂。5 个柜子是 a[0]~a[4]，第 5 个是 a[4]，要拐个弯。
- **P8 检查点**：选 B，`a[4]`。✅（刚学完就会）
- **P9 越界会闯大祸**：一个 int 占 4 个字节，字节是"电脑量内存的小格子"，有解释。但 `a[n] 的位置 = 起点 + n × 4 个字节` 这个公式我有点走神——为什么要算位置呀？好在后面三大后果（脏数据/搞破坏/崩溃）说得很清楚。"段错误"这个词没解释，不过括号前说了"程序直接崩溃"，我当它就是个崩溃的名字。
- **P10 检查点**：选 A。B 错，电脑不会报错才可怕。✅
- **P11 数组初始化**：`{90, 85, 70, 48, 91}` 装满；`{1, 2}` 只装前 2 个其余补 0；`{0}` 全变 0。补 0 这条很妙。全局数组自动清 0——GESP1-10 学过全局变量默认是 0，对上了。
- **P12 检查点**：`{0}` 全 0，`a[1] = 5`，总和 5，选 B。✅
- **P13 大数组放外面**：局部数组住"栈"这个小房间，开一千万个会"爆栈"崩溃；全局住大操场。比喻能懂，但我有个疑问：100005 和 10000000 都很大呀，多大算"大数组"？没有给我一把尺子。
- **P14 检查点**：选 B，大数组开全局。✅（凭秘诀记住的，其实心里还想问为什么）
- **P15 循环遍历数组**：让 i 当下标跑一遍，叫"遍历"，"遍"就是全部——有解释。**这里我停了一下**：前面 P7 明明说下标从 0 开始、5 个柜子是 a[0]~a[4]，这里怎么又从 1 开始用了？重新读了两遍口诀"定义从 0 数，比赛从 1 用"，哦——0 号柜故意空着占位，这样"第 i 个"就是 a[i]，和题目说法对得上。明白了，但这个弯拐得有点急。
- **P16 检查点**：选 A，`i <= n` 才能读满 n 个。✅
- **P17 查找最大值**：打擂台🥊！先让 a[1] 当擂主，后面挨个挑战。GESP1-13 我学过"先把第一个数当老大再逐个换人"，这里一样的思路，只是换成了数组。demo 里 `int a[6] = {0, 90, 85, 70, 48, 91}` 0 号柜放空，注释写清楚了。
- **P18 最大值的位置**：多带一个小本本 `pos` 记号码，换擂主时 `pos = i`。很自然。
- **P19 检查点**：两个一样大的最大值，`>` 不换人，所以留下第一个，选 A。✅（要想一下，但 GESP2-13 画表格模拟练过这种）
- **P20 挑战1**：读 n 个数再原样输出。闭卷我先写：`int a[105];` 全局，读 n，两个 for 循环一个读一个输出。对答案：一模一样。✅
- **P21 挑战2**：最大值和位置。闭卷写出 `maxv = a[1], pos = 1` 然后打擂台。对答案一致。✅
- **P22 挑战3**：逆序输出。闭卷想到"倒着读就行"：`for (int i = n; i >= 1; i--)`，`i--` 在 GESP1-10 学过。对答案一致。✅
- **P23 挑战4 第二大数**：闭卷时我想的办法是跑两趟：第一趟找最大值 m1，第二趟在比 m1 小的里面再找最大值（题目说各不相同，所以行得通）。写出来了，样例 90 85 70 48 91 → 90 对。翻开示例一看，人家一趟遍历用冠军 m1 + 亚军 m2 两个变量，更聪明！我的两趟也对，但学到了新招。换冠军时 `m2 = m1` 这句是关键，漏了老冠军就丢了。
- **P24 小贴士**：两条都是前面说过的，当复习。
- **P25 课后挑战**：5 道题，去做！

## 必须修改的问题（按优先级）

1. **P7 → P15 下标从 0 到从 1 的切换太急（P1）**：P7 刚建立"5 个柜子是 a[0]~a[4]"的模型，P15 直接改成从 1 用起、0 号柜空着，只靠一个引用块口诀过渡。建议在 P15 加一个并排对照图（同一排柜子，标"天生编号 0~4 / 我们只用 1~4"），或加一个检查点让学生主动说出"为什么要空着 0 号柜"。
2. **新授 demo 普遍 9~10 行，超 ≤8 行目标（P2）**：第 5、7、9、13、15 页都含完整五件套。建议新授页把五件套折叠成一行注释 `// 五件套照旧`，只突出新行。
3. **P13 "多大算大数组"没有尺子（P2）**：`a[100005]` 放外面安全、`b[10000000]` 放里面爆栈，两个数都很大，孩子只能死记"大数放外面"。建议给一句量级参照，比如"小房间大约只能住 100 万个 int，再多就挤爆"。
4. **P9 `a[n] 位置 = 起点 + n × 4 个字节` 偏抽象（P2）**：我没学过坐标和代数，这个公式对我像咒语，直接跳过去了。建议删掉公式，保留"电脑只管从起点走 n 格、不检查"这句人话。
5. **"段错误"首次出现无解释（P3）**：第 9 页括号里冒出"段错误"三个字。建议要么删掉，要么写成"程序直接崩溃（这种崩溃有个名字叫段错误，记住名字就行）"。
