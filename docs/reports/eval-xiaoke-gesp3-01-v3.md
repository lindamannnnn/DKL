### 至少 3 个必须修改的问题
1. **两套下标约定混用，容易数错**（证据：第6页用 a[0]/a[2]/a[4] 的 0 基示例，第14页又教"从1用、0号占位"，checkpoint2 考 a[4] 是第5个、挑战题却用 a[1]..a[n]）。建议：全课统一先讲清 0 基，再单独用一小节讲"比赛从1用"的占位技巧，并在 0 基示例里明确说"这里没用占位"。
2. **"栈/爆栈/字节/段错误"只给比喻没给尺度**（证据：第12、19页）。小柯记住名字但不知"多大算太大"。建议：加一句"大约开到几百万个 int（如 `a[5000000]`）才可能爆栈，比赛通常 `a[100005]` 很安全"，把 10000000 这个数字的来由说清。
3. **"两个相等最大值输出哪个"是真实陷阱但没提前提醒**（证据：第18页讲最大值位置时只给 `if (a[i] > maxv)`，checkpoint8 才考）。建议：讲打擂台时顺带点一句"用 `>` 会保留第一个，用 `>=` 会保留最后一个，题目要第一个就用 `>`"。
