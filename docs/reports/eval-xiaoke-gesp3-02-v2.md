## 必须修改的问题（按优先级）

1. **课后5"移动数组元素"有暗坑，课件零预警（P1）**：先换最小数会把"本来在第一位的最大数"挪到别处，再按旧 maxpos 换最大数就错了。要么在挑战环节加一个"交换顺序陷阱"提示（比如先换最大数、或换完最小后更新 maxpos），要么换一道不带这个坑的同主题题。
2. **"双指针"首次出现无解释（P1）**：第 10 页直接说"逆序用双指针夹逼"。建议加一句："指针就是指着某个位置的小手指，这里指的不是别的可怕东西"，为后面课程反复出现的"双指针"打底。
3. **P4 插入 demo 写死位置 2，与文字的 pos 不一致（P2）**：卡片说"第 pos 个位置前插入"，demo 却是 `i >= 2`，学生要自己完成"2 → pos"的抽象。建议 demo 直接写成 `int pos = 2; ... i >= pos`，和挑战1无缝衔接。
4. **新授 demo 9~11 行，超 ≤8 行目标（P2）**：第 4、6、10、12、14 页均含完整五件套，建议新授页折叠五件套。
5. **P12 回文 demo 的 `while (l < r && ok)` 首次出现双条件 while（P2）**：虽然 && 学过，但 while 带两个条件且循环体里改 ok 的写法值得一句解释（"两个条件都满足才继续转"）。
