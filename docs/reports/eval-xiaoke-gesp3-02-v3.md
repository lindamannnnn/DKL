### 至少 3 个必须修改的问题
1. **"移动数组元素"题有隐蔽边界 bug 未被覆盖**（证据：课后题 163fa904，输入 n 个不重复整数，要求最小换首位、最大换末位）。若最大数原本在首位（如 `5 1 2 3 4`），先 `swap(minpos,1)` 会把最大数挪走，再 `swap(maxpos,n)` 实际换走的是最小值，结果错误。题面未保证、讲评也未提醒。建议：题面加"数据保证最小数不在首位、最大数不在末位"，或讲评点出"先同时记好两个位置，且注意前一个交换可能移动后一个的位置"。
2. **回文判断 demo 控制流对小朋友略绕**（证据：第18页 `while (l < r && ok) { if (a[l]!=a[r]) ok=false; l++; r--; }`）。`ok` 在 while 条件里、循环内改 `ok` 比较绕。建议改成"发现不等就 `break`（或直接 `return 0;`）输出 NO"，更直白对应卡片说的"立刻判定不是回文，停止比较"。
3. **课后题1 与课内挑战2 口径不一**（证据：挑战2 第322页特意强调"是真正逆序，不是倒着输出哦"，但课后题1 只说"将其逆序输出"）。小朋友会困惑到底要不要真改数组。建议课后题1 明确写"可以倒序输出，也可以真正逆序，都能得分"，消除歧义。
