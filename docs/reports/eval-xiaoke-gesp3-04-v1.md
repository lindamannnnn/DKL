### 逐页体验记录（按 `## ` 分页）

- **开头目标** "复习第 01~03 课""不学新知识"——太好了，我喜欢复习课，不用怕新单词。
- **故事：数组训练场** 五座塔 🗼 的比喻好懂：擂台塔=比大小（01 课）、手术塔=增删（02 课）、投票塔=数选票（03 课）、翻转塔=逆序（02 课）。**清理塔"把指定元素统统赶走"——这个做法我回忆不起来在哪学过**，02 课只教过"删第 pos 个"，没教过"删掉所有等于 x 的"。先标记。
- **本课练习要点** 三条提醒都很有用：`a[105]` 留余量、移动方向别记反、计数先清 0，全是前三课强调过的。第 25 行"双指针逆序"我知道（02 课的螃蟹夹逼 🦀）。
- **检查点：数组取值** 闭卷选 B：下标从 1 用，`a[1]=90, a[2]=85, a[3]=70`。0 号柜占位是 01 课教的。
- **检查点：删除之后** 闭卷选 A：删掉第 2 个（值为 3），后面往前补 → `1 5 7`。
- **检查点：计数桶** 闭卷选 C：`2 1 2 3 2` 里有 3 张 2 号票。
- **挑战 1：最大最小差** GESP2 综合大闯关做过"最大最小差"，闭卷直接写：两个擂主 `mx=mn=a[1]`，从 `a[2]` 开始挑战。教师卡提醒"初始不能写 0"我记得（01 课警告过全负数的情况）。
- **挑战 2：删除一个数** 口诀"删除从前往后"背得出，闭卷写 `for (i=pos; i<n; i++) a[i]=a[i+1]; n--;`，和示例只差格式。
- **挑战 3：投票统计** 03 课挑战 2 几乎一样，"`>` 不用 `>=`，并列留小编号"我闭卷就写对了。
- **挑战 4：数组逆序** 02 课挑战 2 原题级复习，`while (l<r) { swap; l++; r--; }` 默写成功。教师卡特意警告"不许直接倒着输出"——我确实动过这个偷懒念头，被点名了，嘿嘿。
- **挑战 5：删除所有 x** ⭐ **本课唯一真正的新东西**。闭卷时我只会 02 课的老办法："发现 x 就前移删除"。写完我自己用 `1 3 3 2` 试了一下——删掉第一个 3 后，新补上来的第二个 3 被跳过去了，漏删！教师卡也说这种写法"删完要退回重看当前位置，容易漏判"。看完"筛选装柜"的分步讲解（`m=0`，要留的装进 `a[++m]`）我懂了：就是重新装箱，不要的跳过。但这是**新教的方法**，开头明明说了"不学新知识"。
- **小贴士** 三条口诀都在复习范围内，"筛选装柜法"再次巩固了挑战 5。
- **课后挑战** 只有编号，题面看快照文件（数据库导出）。
