## 必须修改的问题（按优先级）

1. **课后5"元素插入有序数组"输入顺序与命名双重反常（P1）**：第一行是待插入的值（叫 n），第二行才是个数（叫 m），与全课程"n 表示个数"的习惯完全相反，题面又没有醒目提示，我第一次就差点读反。建议改题面变量名（如 x 和 n）或在描述里加粗提醒。
2. **挑战5 示例把 `++m` 写进下标（P2）**：`a[++m] = a[i];` 对初学者是已知易混点（前缀/后缀自增混在别的语句里）。建议示例拆成 `m++; a[m] = a[i];` 两行，把 `a[++m]` 放到"易错点"里当对比。
3. **挑战1、5 的复习 demo 12~13 行（P3）**：超 ≤8 行目标，练习课虽可放宽，仍建议折叠五件套。
4. **票王两种写法并存无说明（P3）**：第 3 课用 `maxC = 0` 起点，本课挑战3 用 `ans = 1` 起点，都对但没告诉学生"两种都行、为什么都行"，爱纠结的孩子会以为有一个是错的。
