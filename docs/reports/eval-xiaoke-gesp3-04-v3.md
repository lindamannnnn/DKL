### 至少 3 个必须修改的问题
1. **课后题1"元素插入有序数组"漏了极端边界**（证据：56d15ba7，样例只给中间插入 `2` 插进 `1 3 4 5`）。闭卷写时我只在"找到首个 `a[i]>n` 就插"，若 n 比所有数都大（或比所有数都小），要在末尾/开头插入，容易漏 `pos=m+1` 或 `pos=1` 分支。建议题面加提示"n 可能最大也可能最小"，或补一组极端样例。
2. **本课唯一的新技巧"筛选装柜删多个"没收进课后题**（证据：第306页挑战5 教了"删除所有 x"，但 5 道课后题只有"删除最小数"这一个单个删除，没有一道要求删多个）。学完没练，最易忘。建议把"删除所有等于 x 的数"做成一道课后题呼应。
3. **课内 checkpoint 太浅，没覆盖本课难点**（证据：第36-71页只有 3 个选择，全是直接回忆"取值/删除后/计数桶"，难度远低于课后题，也没测"筛选装柜"和"有序插入找位置"）。建议加 1~2 个 checkpoint，例如"删除所有 x 后新数组怎么装柜"，让课内自测也能戳到真难点。
