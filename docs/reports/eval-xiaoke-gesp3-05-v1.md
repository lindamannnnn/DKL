### 逐页体验记录（按 `## ` 分页，先看标题 → 逐句读 → 默问"懂了吗"）

- **故事：最长连胜** 足球队"赢 赢 输 赢 赢 赢 输 赢"，我一眼数出最长连胜 3 场。"1000 场眼睛数不过来"说服我了——想让电脑帮我数。故事里的"小柯"就是我，哈哈。
- **回顾** 上节课（03）的 `cnt[x]++` 我记得，是计数桶。"分不清是不是挨着出现的"——对哦，桶只记总数。过渡自然。
- **卡片：连续和总数** "总次数"和"最长连续"分得很清楚：2 一共出现 4 回，但最多挨着 2 回。demo 是上节课的计数桶代码（9 行），我看得懂，`cnt[2]` 输出 3 是总次数不是连续次数——等等，我对着数组 `{0,1,2,2,3,3,3,2}` 数了一下，2 出现 3 次（位置 3、4、8），对的。
- **检查点：总数还是连续** 闭卷选 B：`1 2 2 2 3 3 2` 里 2 最多连着 3 个。
- **卡片：滑动计数器** ⭐ 本课核心。"计数器 `cur` 记当前连续几个，冠军本 `maxL` 记历史最长"，比喻好懂。但我发现一个怪地方：**卡片写 `maxL = max(maxL, cur)`，下面的代码却写 `if (cur > maxL) maxL = cur;`**——是两个写法都对吗？我想了一会儿才确定它们效果一样，但心里咯噔了一下。demo 9 行，有点长但能读完。
- **检查点：cur 变几** 闭卷选 B：`5 5 5 2`，cur 从 1 开始：1→2→3→（2 和 5 不同，断开了）回到 1。
- **卡片：记下冠军** "刷新纪录时顺手记下 `a[i]`"，只看一遍就懂，因为挑战 1 肯定要用。"只在打破纪录时记，并列时先出现的保留"——这句我多读了两遍，想明白了：`cur > maxL` 不带等号，所以并列不更新。
- **检查点：最长连续几** 闭卷选 B：`1 1 2 2 2 1` 最长是三个 2。
- **卡片：连续递增段** "后一个恰好比前一个大 1 也算连续"，条件改成 `a[i] == a[i-1] + 1`，套路不变——这个我喜欢，像换了个子弹的同一把枪。
- **检查点：递增段长度** 闭卷选 A：`1 2 3 1 2 4 5`，1-2-3 是 +1 三连；2→4 是 +2，不算，所以最长 3。差点把"1 2 4 5"看成一段，还好题目说了"恰好 +1"。
- **检查点：判断条件** 闭卷选 B，`a[i] == a[i-1] + 1` 就是"后一个比前一个大 1"。
- **挑战 1：最长连续段** 闭卷动手写：读 n、读数组我会（01 课挑战 1）。核心部分我凭记忆写：`cur=1, maxL=1`，从 `i=2` 开始比前一个……**写到 `ans` 卡住了：ans 一开始放什么？破纪录那行要不要也更新 ans？** 回看了一次"记下冠军"卡片，确认 `ans = a[1]` 起手、破纪录时 `ans = a[i]`，然后写对了。教师卡的"容易错的地方"里有一条我看糊涂了：**"下标从 1 用时 `a[0]` 是 0"——可是 01 课和 GESP1 都教我"main 里面的变量不初始化是随机值"，这道题的 `a[1005]` 写在 main 里面，`a[0]` 应该是乱七八糟的数才对呀？** 我标记了"这里我不太明白"。
- **挑战 2：最长连续 1** 闭卷我先套挑战 1 的"相同段"思路，对样例 `1 0 1 1 0 1 1 1` 算出来是 2（两个 1 挨着），可样例输出是 3！我愣了。再看题："最长连续 **1**"——哦，只数 1 的连续，跟"相不相同"不一样。**可是这个变形课件前面的卡片一张都没教过**，我是看了答案才知道：`cur` 要从 **0** 开始，遇到 1 加一，遇到 0 清 0。看完答案我能写出来，也看懂了，但这不是我自己想到的。
- **小贴士** 三条都总结得漂亮，尤其"数相同段 cur=1、数连续 1 cur=0——想清楚第一个元素算不算一段"，要是这句话能放在挑战 2 **前面**教我就好了。
- **课后挑战** 只有编号，题面看快照文件。

### 至少 3 个必须修改的问题

1. **挑战 1 教师卡"容易错的地方"写有知识性错误**（原文第 245 行："下标从 1 用时 `a[0]` 是 0，可能误判"）。本题 demo（第 217 行）的 `a[1005]` 是 **main 内局部数组**，未初始化时是随机值——GESP1-10 和 GESP3-01 都教过"局部变量不初始化是随机值""写在 main 外面的数组自动变 0"。这句话只有对挑战 2 那种全局数组（第 275 行 `int a[1005];` 在 main 外）才成立。建议改为："下标从 1 用时，`a[0]` 是没用过的位置——如果数组在 main 里面它还是随机值，所以比较一定要从 `i = 2` 开始。"
2. **"连续 1"变形零铺垫，未教先考**（证据：5 张新授卡片只教 `a[i]==a[i-1]` 相同段和 `==a[i-1]+1` 递增段；"cur 从 0 开始、只认一种值、断开清 0"首次出现在挑战 2 的答案 demo 第 279 行，我闭卷必然套错思路）。建议在挑战 2 前加一张小卡片："只数 1 的连胜：遇到 1 加一、遇到 0 清零，cur 从 0 开始（可能一场没赢）"——小贴士第 3 条其实现成，挪到前面当正课即可。
3. **卡片与代码写法不一致**（证据：滑动计数器卡第 78 行写 `maxL = max(maxL, cur)`，同页 demo 第 89 行写 `if (cur > maxL) maxL = cur;`，挑战 2 demo 第 281 行又用回 `max()`）。三种写法混着出现，我每次都要想"它们一样吗"。建议统一成一种（推荐 `if`，因为挑战 1 要在破纪录时顺手记 `ans`，`if` 天然能扩展），卡片里提一句"也可以写 max()，效果一样"就够了。
4. **课后题 1 道超纲 + 1 道边缘超纲**（证据：连胜统计需逐段输出未教，闭卷判 ❌；浪尖数需未教的 `a[i+1]` 右邻居比较）。处理建议与候选题 id 见快照文件"超纲初判"节。
