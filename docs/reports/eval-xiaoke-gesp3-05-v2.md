## 必须修改的问题（按优先级）

1. **P15 RLE demo 严重超纲（P0）**：5 行代码集中出现 5 个未教内容——`string` 类型、`s.size()`、`(int)` 强制转换、`for (int i = 0, j; ...)` 双变量声明、空循环体 `for (...; j++);`（还是学生被反复警告过的"for 后多分号"陷阱的故意版），且 0 基下标与本课其他 demo（1 基）不一致。学生完全无法照着打，"会用 RLE 打包"的目标落空。建议改用 int 数组 + 本课哨兵技巧重写 demo（如把 `1 1 1 2 2 3` 压成 `1 3 2 2 3 1`），或明确标注"这段代码欣赏即可、不要求懂"。
