## 测试课程：GESP3-06 字符数组

### 逐页体验记录（按 `## ` 分页，先看标题和图 → 逐句读 → 默问"懂了吗"）

- **故事：名字存不下啦** "`int name = mike;` 电脑报错"把我逗笑了——字母当然不能装进 int 盒子呀，这个我 GESP1 就会。"一排装字母的柜子"这个画面我一下就记住了。想往下读。
- **回顾** 第 01~05 课的 `int a[5]`、下标从 0 开始我都记得，"柜子换一种货物"这句把旧知识接上了，安心。
- **卡片：char 密码表** ASCII 我 GESP1 第 09 课学过、GESP2 第 04 课又练过，`'0'=48`、`'A'=65`、`'a'=97` 我都背得出。这张卡是复习，读得很快。demo 里 `(char)(c + 2)` 变 `'C'` 我以前见过类似的，懂。
- **检查点：密码是几** 闭卷选 B：65+1=66。太简单了。
- **卡片：字符数组** ⭐ 本课最重要的新知识。"电脑会自动在末尾加一个看不见的小旗子 `'\0'`"——小旗子比喻好懂，"4 个字母却占 5 个格子"我专门停下来数了一遍：m-i-k-e-旗子，真的是 5 格！demo 里 `cout << (int)a[4]` 输出 0，证明了小旗子真的住在那里，我喜欢这种"看得见的证明"。
- **检查点：柜子要几个** 闭卷选 C：hello 5 个字母 + 1 面小旗子 = 6。刚数过 mike，直接会做。
- **卡片：读入字符串** `cin >> s` 读到空格就停、`cin.getline(s, 100)` 读一整行——"两种读法要分清"，对比着讲，清楚。demo 注释里写了"输入 hi c++"，我知道空格也读进来了。
- **卡片：常用小助手** 四个函数都有中文说明：`strlen` 数字符、`strcat` 接尾巴、`strcpy` 抄进去、`strcmp` 比大小。⚠️ 但 `strcmp` 那行写着"比**字典序**"——"字典序"是什么？这里没解释。我猜是"像查字典那样排先后"，半懂，继续往下读。（后面挑战 2 的教师卡真的解释了"像查词典一样"，我猜对了，但那是 170 行以后了。）
- **检查点：长度是几** 闭卷选 B：`strlen("apple")` 数的是字母，不含小旗子，5。卡片里"（不含 `\0`）"那个括号我读到了，没上当。
- **卡片：大小写变身** `tolower`/`toupper` 我 GESP1 学过 ±32，这个函数版更省事；`isupper`/`islower`/`isdigit` 是"打听身份"，比喻好懂。demo 的循环条件 `s[i] != '\0'` 是新写法——"碰到小旗子就停"，和小旗子那张卡接上了，我想了一下就通了。
- **检查点：变身结果** 闭卷选 B：`tolower('B')` 变 `'b'`。
- **挑战 1：统计字母数字** 题面"可能含空格"四个字我圈出来了——所以要用 `cin.getline`，不能用 `cin >> s`！闭卷写：getline 读进来，三个计数器，循环条件是刚学的 `s[i] != '\0'`，里面 `isupper`/`islower`/`isdigit` 分三类。写完对样例 "Hello 123"：H 大写 1 个，ello 小写 4 个，123 数字 3 个，输出 `1 4 3` ✅。教师卡的"容易错"三条我都避开了（特别是 `cin >> s` 那条，我差点也想用）。
- **挑战 2：字符串比大小** 闭卷写：`cin >> a >> b`（题面说不含空格），`int r = strcmp(a, b)`，负数输出 `<`、0 输出 `=`、正数输出 `>`。样例 apple vs banana，a 排在 b 前面，输出 `<` ✅。教师卡警告"负数是 a 小，别记反"，我默念了两遍。⚠️ 但教师卡里还有一句"直接用 `a < b` 比的是**地址**不是内容"——"地址"是什么？完全没学过（GESP1、GESP2 都没这个词），这句我看不懂，只知道结论"必须用 strcmp"要记住。
- **小贴士** "`char a[5] = "hello";` 是错的，要 6 格"——和小旗子那张卡呼应，我已经会了。两条都复习到。
- **课后挑战** 只有编号，题面看快照文件。5 道题都试了（见三步法）。

### 至少 3 个必须修改的问题

1. **"字典序"首次出现无解释**（证据：小助手卡第 139 行"比字典序"，解释却在第 310 行挑战 2 教师卡，滞后 171 行；我在第 139 行真实卡住约 20 秒）。建议在首次出现处加半句："字典序就是像查词典一样，一个字母一个字母比先后"。
2. **"地址"未解释且属未学概念**（证据：挑战 2 教师卡第 321 行"直接用 `a < b` 比较字符数组，这样比的是地址不是内容"；GESP1/GESP2 基线中"指针和地址"明确列为"还不知道"；我卡住约 30 秒只能死记结论）。建议改成孩子能懂的说法："`a < b` 比的是柜子的位置，不是柜子里的字母，所以必须用 `strcmp`"。
3. **挑战 1 教师卡易错点表述有误**（证据：第 265 行"循环条件写成 `i < 1005`，会把空格后面的垃圾也数进去"——写成 `i < 1005` 的真实风险是读到小旗子 `\0` **后面**的乱数据，与"空格"无关；"垃圾"一词也容易误会）。建议改为："会把小旗子后面的乱数据也数进去"。
4. **3 个新授示例 9 行超标**（证据：密码表 demo 41-49 行、字符数组 demo 80-88 行、变身 demo 194-202 行，均超 ≤8 行目标 1 行；GESP3-01 v2 报告同款问题至今未修）。建议每段删 1 行可省注释，或考虑把骨架行排除在计数标准外（需教研组统一口径）。
5. **课后题 5 与课件之间存在教学缝隙**（证据：课件第 139 行只教 strcmp 返回"负数/0/正数"，快照题 5 要求输出具体 ASCII 差值；我闭卷不敢用 strcmp，手写双出口循环靠提示才完成，判 🟡）。建议在挑战 2 教师卡补一句："`strcmp` 只告诉你谁大谁小，不告诉你差多少；要差多少，就自己一个字母一个字母减"。
