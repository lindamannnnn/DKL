### 客观测量
- 最长中文行：全课最长约 50 字（第300页"strlen 和 sizeof 长得像，本领完全不同"段），目标 ≤80，**达标**，无超标页。

### 至少 3 个必须修改的问题
1. **strcat / strcpy / 恺撒密码教了却没收进课后题**（证据：第244-280页 strcat/strcpy、第455页恺撒公式都演示了，但 5 道课后题只用 getline/is*/tolower/strlen/strcmp 思路，无一道练拼接或恺撒）。学完没练最易忘。建议把"恺撒密码加密"（如输入字母串和 k，输出加密串）做成一道课后题，它最有趣也最考 `\0`+ASCII 综合运用。
2. **"比较字符串"题要 ASCII 差值，但课内只教了 strcmp 给正负号**（证据：cd0fc5d3 要求输出第一个不同字符的 ASCII 码差值；第206页只讲 `strcmp` 返回"谁大谁小"不返回具体差）。小朋友会卡"差值从哪来"，得自己写逐字符相减去拿。建议课内补一句"要具体差多少，得像挑战1那样一个字母一个字母减"，或课后题加提示。
3. **`sizeof` vs `strlen` 是 GESP 高频易错点，却只在一道选择里轻轻带过**（证据：第297-332页讲了，但仅 checkpoint7 一个 "sizeof=10"；且第613页提示"`char a[5]="hello"` 是错的"没解释原因）。建议加一道"给定 `char a[20]="hi"`，问 strlen 和 sizeof 各几"的综合 checkpoint 或课后题，并明确点出"格子数 = 字符数 + 1（给 `\0` 留位）"。
