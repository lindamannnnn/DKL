## 测试课程：GESP3-07 string 使用1

### 逐页体验记录（按 `## ` 分页，先看标题和图 → 逐句读 → 默问"懂了吗"）

- **故事：弹性魔法袋** "总要先算好格子数，还得小心 `\0` 小旗子，麻烦极了"——说的就是我上一课的感觉！魔法袋"想装多少就装多少"，我很想要。想往下读。
- **回顾** `char a[] = "mike"`、`strcat` 接尾巴、`strcmp` 比大小，都是 06 课刚学的，接上了，安心。
- **卡片：string 来啦** ⭐ 新东西！"不用提前说装多少，自动变大变小"。拼接用 `+`、比较用 `==`、`<`——我停了一下：06 课教师卡说字符数组 `a < b` 比的是"柜子的位置"不是内容，必须用 `strcmp`；现在 string 可以直接 `<`，这两个规则不一样，我专门默念了两遍："字符数组用 strcmp，string 用 <"，怕记混。demo 里 `a + b` 输出 applebanana，`a < b`（apple 排在 banana 前面）会输出，我懂——就像 06 课"像查词典一样"比。
- **检查点：拼起来是啥** 闭卷选 C：`s += "cd"` 就是把 "cd" 接到 "ab" 后面，`+=` 我 GESP1 第 14 课学过，现在是给袋子接字母，"abcd"。
- **卡片：读出整行** ⚠️ 这里我卡住了！`getline(cin, s)`——可是 06 课读整行写的是 `cin.getline(s, 100)`，点号和括号怎么反过来了？为什么 100 没有了？我翻回 06 课笔记对了半天，两种写法都对吗？课件一个字都没解释。我只能先死记："字符数组用 cin.getline(s, 100)，string 用 getline(cin, s)"。`s.size()` 数有几个字符、`s[i]` 看下标从 0 开始，这两个好懂。
- **检查点：长度是几** 闭卷选 B："hi c++" = h、i、空格、c、+、+ 共 6 个，空格也算一个字符（卡片说 getline 连空格一起读，size 数所有字符）。
- **卡片：find 找一找** `s.find("abc")` 找第一次出现的下标，好懂。⚠️ `string::npos` 里有两个冒号 `::`，以前从没见过，课件只说它是"查无此串"的"特殊记号"。两个冒号是什么意思？没人告诉我。我当咒语记住："找没找到，就跟 string::npos 比一比"。
- **检查点：找到哪儿** 闭卷选 B："abcde" 里 c 在 2 号位（a-0、b-1、c-2），`find("cd")` 返回 2。
- **卡片：replace 替换** `s.replace(起点, 个数, "新内容")`，"新内容可以更长也可以更短，袋子会自动伸缩"——和故事的魔法袋呼应，我喜欢。demo 把 "world"（6 号位起 5 个）换成 "C++"，我数了一遍位置，对。
- **检查点：换成什么** 闭卷选 A：0 号位起换 5 个，"hello" 换成 "hi"，剩下 " world"，所以是 "hi world"。B 是"插进去"不是"换"，不对。
- **卡片：大小写变身** `tolower`/`toupper` 06 课学过，现在配 for 循环逐格用，`i < s.size()` 当停止条件——06 课用 `s[i] != '\0'` 停，string 不用管小旗子了，用 size 停，这个区别我注意到了，觉得 string 方便。
- **挑战 1：找子串位置** "子串"这个词第一次出现，没解释，我猜是"字符串里面的一小串"，看样例 s="hello world"、t="world" 猜对了。闭卷写：两行都可能含空格（样例主串有空格），用刚学的 `getline(cin, s)`、`getline(cin, t)`；`int pos = s.find(t);`，跟 `string::npos` 比，相等输出 -1 否则输出 pos。样例 "world" 在 6 号位，输出 6 ✅。教师卡"容易错"三条里"用 cin >> s 读主串，空格后的内容会丢"——我 06 课挑战 1 就踩过这个坑，这次直接避开了。
- **挑战 2：替换所有子串** ⚠️ 全课最难的一页。闭卷（遮住 demo）我先写：三行 getline 读进来会；但"换完一个继续找下一个"怎么写？我只知道 `s.find(o)` 找第一个，不知道 find 还能带第二个参数从中间开始找。卡住了，偷看了 demo 一眼——`s.find(o, pos)` 还能这样！还有 `while ((pos = s.find(o, pos)) != string::npos)` 这一行，条件里面写 `=`？GESP1 老师说判断相等要用 `==`，这里怎么是 `=`？教师卡解释了 `pos += n.size()`（跳过刚换上的新内容，不然死循环），但**没有拆 while 那一行**。我照着样子能写，但这行为什么能这样写，我说不清楚，心里不踏实。
- **小贴士** 两条都复习到：npos 判断、"pos 要跳过新内容"。
- **课后挑战** 只有编号，题面看快照。5 道都试了（见三步法）。
