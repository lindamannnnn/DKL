## 测试课程：GESP3-07 string 使用1

> 评估声明：挑战题 demo 在页面上无法隐去，挑战题作答属开卷；checkpoint 和课后题为闭卷三步法。我带着 GESP3-01~06 的知识来上课（刚学完 06 的字符数组、strlen/sizeof、恺撒公式）。

### 逐页反应（按 `## ` 分页）

1. **故事：弹性魔法袋** —— 对对对，06 课算格子算 `\0` 是有点烦！魔法袋我很想要 🎒。
2. **回顾** —— strcat、strcmp 上节课刚学，记得。
3. **卡片：string 来啦** —— `+` 拼接、`==` 比较，比字符数组方便多了！`a < b` 也能直接比，开心。
4. **检查点：拼起来是啥** —— `s += "cd"` 是接上去，"abcd" ✅。
5. **卡片：更多初始化** —— `string s(5, 'a')` 造 5 个 a，这个花招好记。`length()` 和 `size()` 是双胞胎，记住一个就行。
6. **检查点：造出什么** —— "xxx" ✅。
7. **卡片：读出整行** —— `getline(cin, s)` 和 06 课的 `cin.getline(s, 100)` 写法不一样！我停下来想了一下：哦，都是"读一整行"，只是一个有逗号一个有点。没人跟我解释为什么写法不同，但我能接受"string 用 getline(cin, s) 这个新写法"。`s[i]` 下标从 0，和数组一样。
8. **检查点：长度是几** —— "hi c++" 含空格共 6 个字符 ✅。
9. **卡片：find 找一找** —— `s.find("abc")` 找下标，`string::npos` 是"查无此串"的特殊记号。`::` 两个冒号没见过，但当成一个整体名字记住就行。
10. **检查点：找到哪儿** —— "cd" 在 "abcde" 的 2 号位 ✅。
11. **卡片：replace 替换** —— `s.replace(起点, 个数, "新内容")`，袋子自动伸缩，清楚。
12. **检查点：换成什么** —— 从 0 号位换掉 5 个换成 "hi" → "hi world" ✅。
13. **卡片：增删清空** —— 四个工具一页，clear/empty/insert/erase，和 02 课数组的插入删除意思相通，不用后移补位真幸福。demo 里 `s.empty()` 输出 0 和 1——empty 返回 true/false 印出来是 1/0，这个我记得（bool 是开关，GESP1-05）。
14. **检查点：袋子空了吗** —— clear 后 empty 是 true ✅。
15. **卡片：数字变身串** —— to_string、stoi、stod 三个变身术，名字好记（to string / string to int / string to double）。
16. **检查点：变身加加看** —— stoi("38") 变整数 38，+2=40，不是 "382" ✅（这个陷阱出得好，拼接和加法我分清了）。
17. **卡片：大小写变身** —— string 没有一键变身，要 for 循环逐格 tolower。`i < s.size()` 当循环条件，能看懂。
18. **挑战 1：找子串位置** —— find + npos 判断，刚学过，开卷能对上 ✅。
19. **挑战 2：替换所有子串** —— **卡住**：`while ((pos = s.find(o, pos)) != string::npos)` 这行把我看懵了！`pos = s.find(...)` 用的是**一个等号**，老师明明说过"判断要两个等号"（GESP1-05、06 易错点），这里一个等号写在 while 里，我第一反应是"是不是印错了？"看了半天才明白：哦，这里是先把查找结果**放进** pos，再拿 pos 跟 npos 比。这种"一边放一边比"的写法从来没人教过我，分步说明和关键代码解释都没讲这行，只讲了 `pos += n.size()`。我是靠自己琢磨 + 看分步说明的中文才勉强懂的。
20. **卡片：把句子拆成词** —— istringstream 快递分拣员 📦，比喻很好！但 `while (ss >> word)` 又是一个"取东西的动作当条件"的写法，跟挑战 2 一样是没人解释的新花样。"取完自动下班"这句话救了我，让我敢接受它。
21. **检查点：分出几个词** —— "a b c" 分 3 个 ✅。
22. **卡片：按逗号切开** —— 手动切分，思路和 05 课的哨兵技巧一样（多走一格收最后一段），有老朋友的感觉 ✅。**但**：`if (i == s.size() || s[i] == ',')`——当 i 走到 s.size() 时 `s[i]` 不是越界了吗？06 课说越界会读脏数据！我猜是"|| 左边成立了右边就不看"（这是我自己以前猜的规则，老师从没确认过），所以没出事。可这正好踩在我一直没被证实的猜想上，心里不踏实。
23. **检查点：多走一步为啥** —— 输出最后一段 ✅（05 课哨兵技巧迁移成功）。
24. **小贴士** —— 两条都重要，尤其"pos 要跳过新内容否则死循环"。

### 必须修改的问题

1. **挑战 2 的 `(pos = s.find(o, pos))` 赋值当条件完全无解释**（证据：挑战 2 demo 及关键代码解释，只解释了 `pos += n.size()`）：学生刚被反复训练"判断用 `==`"，这里一个 `=` 出现在条件里，必然引发"是不是印错了"的困惑；应加一句"这里是先把结果存进 pos，再比较"，或先教拆成两行的朴素写法再展示合并写法。
2. **课后第 5 题提示要求用 substr，但 substr 本课从未出现**（证据：快照第 5 题提示字段"请分别用find及substr两种方法求解"）：课内只能完成 find 方法，提示让学生误以为漏学。建议删改提示或在 07/09 课补 substr。
3. **`while (ss >> word)` 把"取词动作"当循环条件无解释**（证据：把句子拆成词卡片）：istringstream 比喻很好，但条件写法是新花样，建议补一句"取到词就是 true，取完了就是 false，所以能当条件"。
4. **逗号切分 demo 隐式依赖"|| 短路"但未说明**（证据：按逗号切开 demo，`i == s.size() || s[i] == ','`）：06 课刚强调越界危险，这页却读 `s[s.size()]`，应确认并说明"左边成立右边就不看了，所以不会越界"。
