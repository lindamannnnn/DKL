## 测试课程：GESP3-08 练习课：字符数组与 string 入门

### 逐页体验记录（按 `## ` 分页，先看标题和图 → 逐句读 → 默问"懂了吗"）

- **故事：字符训练营** "五座闯关塔"的画面我喜欢，前两座塔用字符数组、后三座用 string，一下子就知道这节课要练什么了。"字符小达人"称号，想要！⚠️ 目标行说"练成条件反射"——"条件反射"是什么？我猜是"不用想就会做"，问了才知道意思，不影响做题。
- **本课练习要点** 五条复习清单我全能对上号：`'\0'` 小旗子、`s[i] != '\0'` 遍历、四个字符工具、`+` 拼接、find/replace，都是 06、07 课学过的。第 28 行写"读整行用 `getline`"，可是我记得 06 课字符数组读整行是 `cin.getline(s, 1005)`，07 课 string 读整行是 `getline(cin, s)`，**两种写法不一样**！这里只写了一个名字，我停下来想了一会儿才确认"哦，原来是两种袋子各有一种读法"。要是这里写清楚就好了。
- **挑战 1：数大写字母** 题面"可能含空格"我马上圈出来——要用 `cin.getline`！这道题和 06 课挑战 1 几乎是亲兄弟，我闭卷直接写出来了（见三步法）。教师卡说"循环写成 `i < 1005`，数进**垃圾字符**"——"垃圾字符"没解释，不过我联系 01 课"乱糟糟的数据"猜懂了：就是格子里没人管的脏东西。
- **挑战 2：大小写互换** 06 课大小写变身卡的练习版，`isupper` 问身份、`tolower` 施魔法，我闭卷写完对样例 "Hello World!" → "hELLO wORLD!" ✅。"其他字符不变——其实不处理就是对的做法"这句话让我松了口气，我原来还担心要不要写第三个分支。
- **检查点：读一整行** 闭卷选 B：`cin.getline(s, 100)`。刚做完挑战 1，手还热着。
- **挑战 3：拼接与比较** `a + b` 拼接、`a < b` 比字典序，07 课学过。"apple 排在 banana 前面"查词典比喻我记得。闭卷写完对样例 ✅。教师卡提醒"还在用 `strcat`、`strcmp`，string 根本不需要"——我 06 课确实学过那两个，差点就写 `strcat` 了，幸好想起 07 课说 string 更方便。
- **检查点：找不到咋办** 闭卷选 C：`string::npos`。07 课说它是"查无此串"的特殊记号，我记得不是 -1。
- **挑战 4：找所有位置** 题面括号"允许重叠"我先不懂，看到教师卡"'aaa' 里找 'aa' 能数出 2 次"才明白：哦，数完一次只往前挪 1 格。闭卷写的时候 while 循环里 `(pos = s.find(t, pos))` 这种"一边找一边记下来"的写法我 07 课见过一次，我写成了两段式（先找一次，再循环找），对答案发现意思一样、写法不同（见三步法）。
- **检查点：换完是啥** 闭卷选 A：`s.replace(1, 3, "XY")` 是从 1 号格开始数 3 个（b、c、d）换成 "XY"，剩 "aXYe"。我在纸上画了格子：a|b c d|e → a|X Y|e。画格子就不会错。
- **挑战 5：替换所有子串** find + replace 黄金搭档。闭卷我写的是 `pos++`，对样例 "abcabc/bc/XY" 跑出来也是 "aXYaXY" **全对**！可对答案才发现教师卡说要写 `pos += n.size()`。原来是因为新换上的 "XY" 里面没有旧子串 "bc"，我错着写也碰巧对——这个样例抓不到我的错误（见"必须修改的问题"第 2 条）。
- **小贴士** "find 循环三件套：找到就处理、pos 正确前进、找不到就停"——把挑战 4、5 的口诀收拢了，我抄进了小本本。
- **课后挑战** 5 道题，题面看快照文件。都试了（见三步法）。

### 至少 3 个必须修改的问题

1. **两种 getline 写法并排出现却不点明区别**（证据：要点第 28 行只说"读整行用 `getline`"，挑战 1 demo 第 49 行用 `cin.getline(s, 1005)`，挑战 5 demo 第 303 行用 `getline(cin, s)`）。我靠回忆 06/07 课才分清"字符数组一种、string 一种"；容易错成给 char 数组写 `getline(cin, s)`。建议要点里加一句对比。
2. **挑战 5 样例抓不到 `pos++` 错误**（证据：样例 abcabc/bc/XY，新子串 XY 不含旧子串 bc，`pos++` 与 `pos += n.size()` 输出相同；而教师卡第 330 行把 `pos++` 列为头号易错）。我闭卷写错照样过样例。建议增加一个"新子串含旧子串"的样例（如 `aaaa`/`a`/`aa`）或改成多组样例。
3. **课后题与本课重点错配**（证据：5 道题全是遍历/计数/转换类，0 道 find/replace/拼接/比较；本课挑战 3/4/5 练的技能课后不巩固）。候选 id 见上节。
4. （附加）**课后 T2 位置从 1 开始数，题面不说明**（证据：题面只说"首次出现位置"，样例 and→1 才暴露 1 起点；本课 find 返回的下标全是 0 起点）。我靠样例才发现，不看样例必错。
5. （附加）**"条件反射""垃圾字符"两个词未解释**（证据：原文第 3 行、第 76 行），虽可靠猜撑过，但按人设我遇到不懂会先标记。
