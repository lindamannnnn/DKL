## 测试课程：GESP3-09 string 使用2

> 评估声明：挑战题 demo 在页面上，挑战题作答属开卷；checkpoint 和课后题为闭卷三步法。我带着 GESP3-01~08 的知识来上课（08 是练习课，find/replace/分割已练熟；02 课学过数组双指针）。

### 逐页反应（按 `## ` 分页）

1. **故事：身份证的秘密** —— 身份证里剪出生日，这个用处好真实！想知道怎么剪 ✂️。
2. **回顾** —— 07 课的拼接/size/find/replace 我都记得。
3. **卡片：substr 剪绳子** —— `s.substr(起点, 个数)`，剪出来的新串不伤害原绳子，比喻清楚。demo 6 行能照打。
4. **检查点：剪出哪一段** —— "abcdef" 从 2 号位剪 3 个 = "cde" ✅。
5. **卡片：剪到绳子尾** —— 只写起点就剪到尾；"起点超出长度会咔嚓断掉报错"的警告好。身份证 demo 让 substr 一下变有用。
6. **检查点：再剪一次** —— `s.substr(5)` 从 5 号位到尾 = "world" ✅。
7. **卡片：reverse 倒车** —— `reverse(s.begin(), s.end())`，begin 是车头、end 是车尾。begin()/end() 是没见过的词，但当成"倒车器的两个夹子"记住了，不用懂原理。
8. **检查点：倒车后是啥** —— "abc"→"cba" ✅。
9. **卡片：回文判断** —— 回文我熟！GESP2-07 学过回文数（倒过来再比），02 课学过数组回文。复制一份倒车再比，思路完全能迁移 🪞。
10. **检查点：哪个是回文** —— "level" ✅。
11. **卡片：双指针回文** —— 这是 02 课数组双指针的老朋友！l 站排头、r 站排尾、`while (l < r)` 夹逼、不一样立刻收工——全是我会的手势，只是从 int 数组搬到 string 👈👉。**第一次见 string 版的双指针，零障碍**。
12. **检查点：指针碰头没** —— `l < r` ✅。
13. **卡片：sort 排排坐** —— `sort(s.begin(), s.end())` 把字符按 a→z 排队。我之前没学过"排序算法"，这页把它当工具直接给我："sort 从起点走到终点排整齐"。能接受——像 reverse 一样的魔法工具，会用就行。但"它怎么排的"我一点概念也没有。
14. **检查点：排序后是啥** —— "cab"→"abc" ✅。
15. **卡片：删掉指定字符** —— 遍历拼接法我懂（07 课课后题"删除指定字符"我就是这么做的：不是目标就 `+=` 拼上去）。**但是 demo 里的 `for (char c : s)` 是什么？！** for 的括号里不是"从几开始；到几停；每次加几"三格吗？这里只有一个 `char c`、一个冒号、一个 s，三格全没了！这页一个字都没解释这种写法。我只能连蒙带猜："大概是把 s 里的字符一个个拿出来叫 c"？猜的，没人告诉我。
16. **检查点：拼接留下谁** —— 要删的直接跳过 ✅。
17. **挑战 1：截取一段** —— 从 1 数和从 0 数的换算：`substr(l - 1, r - l + 1)`。"个数是 r - l + 1"用样例 2 6 比划一下能对上（2 到 6 是 5 个字符）✅。这个换算是本课最需要动脑的地方，分步说明讲透了。
18. **挑战 2：回文判断器** —— 先全转小写再复制倒车比较，组合了 07 的大小写循环和本课回文 ✅。"Racecar 直接判断会输出 NO"的提醒很关键。
19. **小贴士** —— 两条都实在。

### 必须修改的问题

1. **`for (char c : s)` 范围 for 语法首次出现、零解释**（证据：删掉指定字符卡片 demo）：for 循环的三格写法是学生的底层认知（GESP1-10），这里三格突然消失变成一个冒号，必须加一句"这是 string 专用的挨个取字符循环"或直接先用学生会的下标写法。
2. **课后第 4 题"子串统计"难度严重超标**（证据：快照第 4 题 + 卡点日志）：需要枚举全部子串（O(n²) 个）、对每个数出现次数、再做"次数→长度→先后"三级排序取最优。课内没教任何能给"字符串键"计数的结构（map 未学），也没有一道挑战题示范过"枚举所有子串"的循环骨架，与其他 4 道课后题难度断层。虽未用到课外概念（substr/find/枚举/打擂台都教过），但组合复杂度远超本课水平，建议换题或加引导。
3. **sort 作为全新工具没有任何"排序"概念铺垫**（证据：sort 排排坐卡片）：学生此前从未接触过排序（状态文件明确列为未知概念），这页直接给 `sort(s.begin(), s.end())` 黑盒。作为工具介绍可以接受，但至少应说明"sort 是现成的排序机器，给它车头车尾就排好"，并预告后面会学排序原理。
4. **双指针回文页文字偏长**（证据：双指针回文卡片约 85 字）：夹逼步骤分四行写在一页，超 80 字目标；可考虑拆成"步骤图 + 短句"。
