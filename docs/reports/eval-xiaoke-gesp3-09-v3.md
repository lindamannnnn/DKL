### 卡点日志
- [课后题1] 卡住约 30 秒：第一版代码用 `cin>>s` 把 "12321." 整串读入，直接 reverse 比较得 FALSE，和样例期望 TRUE 对不上。我停下来想"是不是 '.' 也当成字符了"——果然！"以.结束"意味着 '.' 是终止符不是内容，得先 `s.pop_back()` 或 `s.substr(0,s.size()-1)` 摘掉再判。摘掉后 "12321" 倒车还是 "12321"，判 TRUE ✓。接着又发现输出要 "TRUE"/"FALSE" 大写，而我照挑战2 demo 写成了 "YES"/"NO"，再改一遍。两处都是题面细节，不是概念不懂。

### 至少 3 个必须修改的问题
1. **回文题输出格式不一致：demo 用 YES/NO，课后题1 要 TRUE/FALSE**（证据：第 434 页挑战2 demo `cout << (s == rev ? "YES" : "NO")`；而课后题1 `output_desc` 写"输出只有一行.TRUE 或者FALSE"，样例期望 TRUE）。同一个"判断回文"概念，课内示范和课后题输出写法不一样，我第一版就照 demo 写了 YES/NO 导致 WA。建议本课把回文输出格式统一声明一次（"题目要什么就输出什么，别照抄 demo 的 YES/NO"），或在挑战2 demo 就用 TRUE/FALSE 和课后题对齐。
2. **"以.结束"的终止符剥离没教过**（证据：本课只教 `cin>>s` 整串读入再 reverse 比较整串（第 147-158 页），从未教"读到某字符停止"或"掐掉末尾一个字符"；但课后题1 输入"字符个数不超过100,且以.结束"）。我得自己想到先 `s.substr(0,s.size()-1)` 把 '.' 摘掉，否则 '.' 会被当串内容 → "12321." 判成非回文。建议本课在 substr 卡片补一句"想掐掉末尾字符：`s = s.substr(0, s.size()-1)` 或用 `s.pop_back()`"，并给一个"读字符串直到某符号停止"的小例子，否则这种 IO 细节全靠学生自己悟。
3. **双指针回文法（第176-215页花了大篇幅）没收进任何课后题**（证据：全课 5 道课后题里，回文只出现在课后题1，而我用"复制倒车比较"就能过，双指针版没人考；好比 03 课前缀和/区间计数、06 课 strcat/恺撒密码教了没收进题）。花了力气教的两指针夹逼法，学生练不到就会忘。建议至少一道课后题（或把课后题1 加一个"请用双指针法"的提示/变式）强制练到双指针回文，让两招都变成本领。
