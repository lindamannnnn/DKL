### 页11 挑战 1：水仙花数
**闭卷三步法**：
1. 闭卷：枚举 n 从 100 到 999，`a = n/100`、`b = n/10%10`、`c = n%10`（GESP2-05 教的数位拆分），判断 `a*a*a+b*b*b+c*c*c == n`。一次写对。
2. 对答案：与示例逐行一致，0 处差异。
3. 判定：✅ 独立通过。
（备注：GESP2-09 练习课我做过水仙花数，这题对我是老朋友。）

### 页12 挑战 2：百钱百鸡
**闭卷三步法**：
1. 闭卷：GESP2-05 就做过这题！我记得"小鸡用总数推"：`z = 100 - x - y`，再验证 `z>0`、`z%3==0`、`5*x+3*y+z/3==100`。边界我算了：公鸡最多 100/5=20，所以 x≤19；母鸡最多 100/3=33，y≤32。写出来了。
2. 对答案：与示例一致，0 处差异。
3. 判定：✅ 独立通过。
（备注：这题和 GESP2-05 的例题几乎一模一样，没有"挑战"的感觉。）

## 至少 3 个必须修改的问题

1. **与 GESP2 大面积重复，衔接断裂**：枚举概念（GESP2-05 原话"把所有可能列出来逐一判断"）、挑战2 百钱百鸡（GESP2-05 原题，连"小鸡用总数推"都一样）、挑战1 水仙花数（GESP2-09 做过）、i*i 枚举完全平方数（GESP2-16 真题课）——但本课把它们当全新内容讲，"回顾"卡只提 for 循环、只字不提 GESP2-05 的枚举课。（证据：课件 19~25 行回顾卡；227~279 行挑战2 与 GESP2-05 例题同解。）
2. **与 GESP3-01~10 零衔接**：本课 7 个示例/挑战全部是纯整数循环，没有一个数组或字符串场景；而课后题 5 道里有 4 道要数组/字符串。学生在课内见不到"枚举 + 数组"长什么样，直接做题等于跳台阶。（证据：课件全部 demo 均为 int 循环；课后题快照见 `snapshots/problems-gesp3-11.md`。）
3. **课后第 5 题"求和"超纲**：NOIP 复赛题，需 O(n) 数学分组优化，超纲判定与候选替换见上表。
4. **枚举去重知识被遗忘**：GESP2-05 教过 `for (b = a; ...)` 去重，本课双层枚举卡（139~143 行）只讲两个都从 1 开始，不呼应"什么时候该去重"，已学技能出现倒退风险。
5. **题库数据缺陷 2 处**：既生瑜何生亮 input_desc"一行，一个整数"与样例两个数矛盾；求和 output_desc 字段错乱。（证据：快照文件。）
