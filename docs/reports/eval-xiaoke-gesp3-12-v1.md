## 逐页体验记录

### 故事：蜗牛爬竹竿
蜗牛白天爬 3 米、晚上滑 2 米，故事里说"小柯在纸上演"——哈哈，写的是我！我确实会这样一天一天画出来。第 1 天到 3 滑到 1、第 2 天到 4 滑到 2……我自己接着演：第 8 天白天从 7 爬到 10，到顶了！这个开头我喜欢，一下就知道今天要干嘛。

### 回顾
"枚举是试所有可能，模拟是照着规则一步步做。"枚举我上节课刚学完，这两个对比我看得懂，像给老朋友介绍新朋友。

### 卡片：什么是模拟
"程序当演员，题目规则是剧本。"比喻好懂。demo 是砍小怪：10 点血每刀砍 3 点，砍 4 刀。我对着代码在心里演了一遍：10→7→4→1→-2，数了 4 次，和注释说的"4 刀"一样。代码 8 行，能看完。

### 检查点：模拟是什么
模拟是"按题目描述的规则一步步照着做"，选 A。B 是枚举，刚才回顾页刚讲过，不会混。

### 卡片：模拟三要素
状态、转移、终止，三个词每个都有一行解释："现在是什么样""每一步怎么变""什么时候停"。我把它们贴到蜗牛上：状态 = 位置和第几天，转移 = 白天 +3 晚上 -2，终止 = 到 10 米。对得上！demo 8 行，是"不滑落版"的蜗牛，我注意到它和挑战 1 的真题不一样（真题晚上会滑），当时心里记了一笔。

### 检查点：三要素归谁
`pos += 3` 是"转移"，选 B。刚讲完就做，稳。

### 卡片：按指令走路
机器人听 R/L 指令走路。坐标这个词 GESP2 画图形时学过，不怕。demo 里 `x += (c == 'R' ? 1 : -1);` 这一行我要拆两次才看懂：先三目运算符选出 +1 或 -1，再加到 x 上。三目运算符 GESP2-02 学过，但塞进 `+=` 里是第一次见，我停下来在纸上写了一遍才走。demo 一共 9 行，有点长但没崩。

### 检查点：最后在哪
1 号格出发，RRRL：1→2→3→4→3，停 3 号格，选 C。我在草稿纸上画了就对。

### 卡片：数组记状态
发牌给 3 个人，用 `a[1] a[2] a[3]` 记每人几张。`a[(c - 1) % 3 + 1]++` 这个下标我验算了：c=1→1号、c=2→2号、c=4→1号，对！取余数组下标在枚举课邮票题里见过类似的。demo 9 行。

### 检查点：牌发给谁
7 张牌：1、2、3、1、2、3、1，第 7 张给 1 号，选 A。数手指头就对了。

### 挑战 1：蜗牛爬竿
**闭卷尝试**：题目自己说了"如果白天已经爬到顶，当晚就不再滑"，我就把这句话直接翻译成 `if (pos < h) pos -= d;`。我写的是：

```cpp
int h, u, d; cin >> h >> u >> d;
int pos = 0, day = 0;
while (pos < h) {
    day++; pos += u;
    if (pos < h) pos -= d;
}
cout << day << endl;
```

**对答案**：和页面上 demo 逐行比，0 处不一致。样例 10 3 2 我手演：第 8 天到顶，输出 8，对。
**判定：✅**（题目把最关键的规则写在了题面里，我照着翻译就行）

### 挑战 2：机器人走方格
**闭卷尝试**：四个方向我列了 U/D/L/R，但第一遍把 U 写成了 `x++`——我以为"上"是变大。写到一半想起 GESP2 画图形时行号越大越靠下，改成 `x--`。边界我写了 `x > 1` 才动，这个想到了（卡片说撞墙不动）。
**对答案**：和 demo 比，1 处不一致（U 的方向我自己已经改回来了，但 D 的边界我第一遍写成 `x <= n`，看 demo 才确认是 `x < n`——因为动之前还没加，应该用 `<`）。
**判定：🟡**（看 1 次示例才写对，方向和边界各绊了一下）
