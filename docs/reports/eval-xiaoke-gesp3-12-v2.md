## 至少 3 个必须修改的问题

1. **【P0】围圈报数 demo 一行塞四个未教写法，第一次见的学生读不动**：`fill(alive, alive+6, true)`（未教函数）+ `++cnt == 3`（前置自增塞进条件）+ `alive[cur] = false, left--, cnt = 0;`（逗号三连赋值）。GESP2-13 刚把逗号表达式列为"易错点"，这里却用它写正式示范。建议拆成朴素多行：`if (alive[cur]) { cnt++; if (cnt == 3) { alive[cur] = false; left--; cnt = 0; } }`，fill 换成 `bool alive[6] = {0,1,1,1,1,1};` 或一句"fill 是把一段数组全填成同一个值"。
2. **【P1】范围 for `for (char c : s)` 两次零解释出现，且用在挑战 2 示范解法里**：GESP3-09 欠账未还，本课"按指令走路"页和挑战 2 demo 继续使用。学生模仿不了示范代码的主线写法。建议在第一次出现处补一句"范围 for：把 s 里每个字符轮流放进 c，不用数下标"，或挑战 2 demo 改用下标循环。
3. **【P1】围圈报数 demo 从 0 号数人，与 01 课"比赛从 1 用"冲突且无提醒**：cur 是 0~4、输出 `i + 1`，下标习惯切换没有任何说明，正是我最怕混的地方。建议加一句"这里为了配合 % 绕圈，临时从 0 号数起，输出时 +1 变回我们的编号"。
4. **【P2】方向数组与挑战 2 脱节**：挑战 2 用四个 if 写完才教方向数组，全课没有演示"方向数组 + 撞墙判断"的完整搭配，学生不知道两者怎么合体。建议挑战 2 讲解末尾加一段方向数组改写版，或加一道小 checkpoint。
5. **【P2】课后题"黑色星期五"缺少"星期数字化"的入门提示**：题目本身不超纲（闰年、模拟、取余都学过），但"把周四记成几、怎么 %7"这一步没有任何脚手架，建议题面加一句提示。

## 知识状态更新（本课新增）

- 模拟算法：程序当演员照规则演；三要素 = 状态、转移、终止；与枚举的区别（知规则用模拟，不知答案用枚举）。
- 模拟题特征词："每一步/每一轮""按照规则""重复直到""经过 N 次操作后"。
- 环形下标 `cur = (cur + 1) % n`：队尾自动绕回队首（圆形餐桌），报数出圈/星期推算都能用。
- 方向数组：`dx[4] = {0,1,0,-1}`、`dy[4] = {1,0,-1,0}`（0右1下2左3上），`x += dx[dir]; y += dy[dir];` 一步走一格；但还不会和撞墙判断组合使用。
- 能做：蜗牛爬竿（到顶不滑）、机器人走方格（四方向 if + 撞墙）、订做校服、珠心算测验（三重枚举 j<k）、小明的电梯（上下分层计时）、表达式的值（'+' 切分累加）、黑色星期五（需提示星期数字化后能做）。
- 读不懂但见过：`fill` 函数、逗号三连赋值、围圈报数的紧凑 demo。
