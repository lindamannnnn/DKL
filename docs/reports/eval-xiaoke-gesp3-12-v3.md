## 逐页体验（第一人称）

- **故事·蜗牛爬竹竿**："在纸上演一遍"——这个想法我 GESP2-13 循环模拟专项就用过（画表格模拟循环），一看就亲切。✅
- **回顾 枚举 vs 模拟**："枚举是不知道答案试一遍，模拟是照规则演"——把 GESP3-11 和今天连起来了，清楚。
- **什么是模拟**：程序当演员、规则是剧本，比喻好懂。
- **认出模拟题**：看到"每一步/按照规则/重复直到"就警惕——像老师教我读题的暗号，实用。
- **模拟三要素（状态/转移/终止）**：给"照规则演"起了正式名。我以前写 while 模拟时其实就是这三者，今天对上号了。
- **按指令走路**：`x += (s[i]=='R'?1:-1)` 用三目运算符（GESP2-02 学过），字符串遍历（GESP3 学过），秒懂。

- **挑战 1 蜗牛爬竿**：demo 里 `if(pos<h) pos-=d` 守住"到顶不滑"——我以前模拟时也踩过"最后一步多算"的坑，这个写法我记住了。
- **挑战 2 机器人走方格**：U/D/L/R 四方向各写一句 + 撞墙判断 `x>1` 等。上下动行 x、左右动列 y，我得小心别反（上是 x--）。
- **方向数组 dx/dy（新招）**：把四个方向装进数组，选几号走哪边——像遥控器选台，比喻我喜欢！但"0右1下2左3上"这个编号是老师定的，我记住了，但不确定换个题能不能自己编。

## 至少 3 个必须修改的问题

1. **「围圈报数」demo 信息密度过高，一个示例塞了 4 个难点**（证据 line 219-234：`alive[]` 数组记状态 + `cur=(cur+1)%n` 环形下标 + `cnt/left` 出局计数 + 输出 `i+1` off-by-one 同时出现）。9 岁孩子一次吸收 4 个新/难点的认知负担太大。建议拆成两页：①先单独讲"环形下标 `cur=(cur+1)%n`"配圆桌座位图；②再单独讲 `alive` 标记与出局，并把"从 0 号数起、最后输出要 +1"作为独立小贴士点名，避免 off-by-one 暗坑。

2. **方向数组的"0右1下2左3上"编号约定未说明"可自定义"**（证据 line 379-380）。我只背下了这个顺序，但不知道这是老师随意定的，换个题若用"0上1右…"我会懵。建议补一句："方向编号是你自己定的，只要 dx/dy 一一配对、和题目方向一致就行，不唯一"，并给一个"自己编一套"的小练习。

3. **课后题「黑色星期五」难度显著高于本课其他题，且依赖未教的"日期模拟"前置**（证据 problem `542e4d05`）。它需要月份天数数组、闰年判断（虽 GESP2-14 学过 `isLeap`，但需自己搭 months[]）、星期累加、`13 号`定位四步，是 5 题里唯一要"推日期"的；课件全程没教"月份天数数组"和"星期怎么逐月累加"。放在"模拟入门"课偏难且缺梯子。建议：要么课前补一节"日期三件套"(months[]、isLeap、weekday 累加)，要么把这题移到进阶/真题单元。

4. **课后题「表达式的值」实为字符串题，与"模拟"主线偏离**（证据 problem `0cab568c`，来源标注"字符串"）。它需要按 '+' 切分再 `stoi` 求和，对刚学模拟的小柯是额外的字符串解析负担。建议：标注"需用到 GESP3 字符串知识"，或替换为纯数值模拟题以聚焦本课目标。
