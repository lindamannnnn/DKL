### 页6 挑战 1：找因数
**闭卷三步法**：
1. 闭卷：这和 11 课"枚举三要素"的示例就是同一道题！`i` 从 1 到 n，`n % i == 0` 就输出。一次写对。
2. 对答案：与示例逐行一致，0 处差异。
3. 判定：✅ 独立通过。
（小嘀咕：练习课复习我理解，但这题连数字都没换呀。）

### 页7 挑战 2：银行叫号
**闭卷三步法**：
1. 闭卷：这就是 GESP1-13 的"循环读入求和"！我写的是 `t += x;` 然后 `cout << t << endl;` 两行。拿样例 5、3、8 在纸上演：5、8、16，对！
2. 对答案：示例把加法和输出写成一句 `cout << (t += x) << endl;`，和我两行写法不一样，但意思相同——1 处写法差异，逻辑等价。
3. 判定：✅ 独立通过。
（小嘀咕：把 `t += x` 塞进 `cout` 里的写法我第一次见，有点酷，但我怕记不住括号。）

### 页8 挑战 3：数字里的 7
**闭卷三步法**：
1. 闭卷：外层 `for (int i = 1; i <= n; i++)` 我会。内层我第一遍直接写 `while (i > 0) { ... i /= 10; }`——结果程序死循环了！我盯着看了半天，突然想起来 GESP1-15 老师说过"拆位会把原数毁掉"，赶紧改成 `int x = i;` 拆 `x`，就对了。
2. 对答案：与示例一致（示例也是复制给 `x` 再拆），修正后 0 处差异。
3. 判定：🟡 半独立（第一遍核心写法错了，靠自己回忆 15 课的教训 + 一次死循环反馈才改对，没有看示例）。
（备注：`has7` 小旗子和 GESP1-15 的 `found` 是同一个套路，这个我自己想到了。）

### 页9 挑战 4：轮流发牌
**闭卷三步法**：
1. 闭卷：12 课的"数组记状态"示例就是 7 张牌发 3 个人，公式 `(c - 1) % m + 1` 我当时抄在小本本上了，这次换成 n、m 照样写。数组开在 `main` 外面自动清零（GESP1-10 教的）。
2. 对答案：与示例一致，0 处差异。
3. 判定：✅ 独立通过。

### 页10 挑战 5：弹球反弹
**闭卷三步法**：
1. 闭卷：位置 `p`、每步 `p += v` 我会写。可是"越过两端就反弹"……从 10 号格走出 13，弹回 7——为什么是 7 呢？我对着样例 `10 8 5 1` 算了：8+5=13，13 比 10 多 3，10-3=7。哦！多出来几格就从边上退回几格。但是"用代码怎么写退回"我想了 2 分多钟，式子列不出来，方向还会乱。卡住了。
2. 对答案：示例用 `dir` 记方向（1 往右、-1 往左），右端折回 `p = 2 * n - p`，左端折回 `p = 2 - p`，同时方向掉头。我拿样例验证：2×10-13=7 ✓。看懂了，但让我自己写绝对想不到 `2 * n - p` 这个式子。
3. 判定：🟡 半独立（看 1 次示例后能理解并验证，闭卷写不出折回公式）。
（备注：`dir` 这个想法很妙，但 12 课从没见过"方向"这个词，我完全没想到要用它。）
