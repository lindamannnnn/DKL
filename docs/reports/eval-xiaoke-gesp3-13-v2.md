## 至少 3 个必须修改的问题

1. **【P1】课后题"计算表达式"题面被吞字符，算例不成立**：描述里写"3+56-4=86-4=48-4=44"，3+56≠86，唯一合理的解释是 `*` 号在 HTML 里丢失（应为"3+5\*6-4=8\*6-4=48-4=44"）。题面还说"运算数为一位整数"，与残缺的"56"自相矛盾。第一次读题的学生会在这一步直接卡死。建议修复题库 description 中被 Markdown 吃掉的 `*`（转义为 `\*`）。
2. **【P2】挑战 5 弹球反弹只给了右反弹的例子，左反弹公式 `p = 2 - p` 无任何样例**：学生只能靠类比猜，猜错也无法自查。建议题目卡补一句左反弹示例（如"从 1 号格走出 -2，会弹回 4 号格"）。
3. **【P2】小贴士"数组下标从 1 开始最不容易错"与 12 课围圈报数 demo（从 0 数起）口径冲突**：两课相邻却互相矛盾，没有一句"什么时候从 0 更方便"的说明。建议在 12 课 demo 或本课小贴士补一句协调说明。
4. **【P3】挑战 2 demo 的 `cout << (t += x) << endl;` 是"赋值塞输出"的紧凑写法**：虽然教师卡补了"拆开写也一样"，但对刚在易错点清单里记下"一边赋值一边判断要写起来心虚"的学生，示范代码最好直接拆两行。

## 知识状态更新（本课新增）

- 枚举/模拟复习巩固：三要素先写再动手；模拟先纸上演样例。
- `(c-1)%m+1` 轮流分配下标：闭卷能独立写出。
- 环形区间求和：起点枚举 + `(i-1+k)%n+1` 下标绕圈。
- 反弹公式：右越界 `p = 2*n - p`（用例子推出），左越界 `p = 2 - p`（类比猜出、对答案确认）。
- 数字移位枚举：六位数个位移首位 `700000 + n/10`，配合 4 倍关系枚举验证。
- 时间转秒：`substr`+`stoi` 剪时分秒，`h*3600+m*60+s` 再相减。
- 表达式求值（无优先级）：扫描时"遇运算符先结算上一个"的骨架。
