## 逐页学习日记

- **故事：外星人的数字** — 外星人用 0 和 1 数数！1101 是 13？我一开始不信，学完这节课我信了。
- **什么是进制** — "满 10 进 1"vs"满 2 进 1"，一句话就懂了。A 表示 10、F 表示 15，像密码。demo 里 `cout << oct` 和 `cout << hex` 是三个没见过的魔法单词，看注释能猜出"换种写法输出"，但它们为什么能这样用没讲。**而且这里输出的十六进制是小写 `ff`，后面全课和题目都用大写 FF，到底哪个对？**
- **按权展开** — "每位有自己的身价"，1、2、4、8 不停乘 2，1011=8+2+1=11，我算对了！可是 demo 代码的 `for (char c : s)` 又是那个没教过的范围 for（12 课见过两次了），还有代码用的是 `r = r * 2 + ...` 滚雪球，和卡片讲的"乘身价再加"看起来不一样，是两个方法吗？没人告诉我它们是一回事。
- **短除法** — 13÷2 一路除下去记余数，**倒着读**！这个 ⚠️ 提醒好重要。demo 把新余数拼到最前面 `r = 新字符 + r`，07 课的字符串拼接，看得懂。**可是我突然想到：如果 n 是 0 呢？`while (n > 0)` 一次都不进，r 是空的，那 0 的二进制不就输出了个寂寞？**课件没说。
- **转任意进制（复测重点）** — 想转几进制就除以几！密码表 `"0123456789ABCDEF"` 用余数当下标查表，03 课的"下标当桶"老本领，一下就看懂了。余 12 查表是 C，checkpoint 做对。
- **任意进制回家（复测重点）** — 滚雪球：`结果 = 结果 × 进制 + 这一位`，从左往右越滚越大。字母先变回数 `c - 'A' + 10`，02 课的字符算术。"大名 Horner 法则"——这个外国名字记不住也没关系吧？checkpoint "2A"：2×16+10=42，我会算！
- **快速转换** — 3 位二进制 = 1 位八进制、4 位 = 1 位十六进制，分组抄近路，好玩！2³ 我想成 2×2×3？不对不对，2×2×2=8，老师写的是 2³=8，应该是三个 2 相乘的意思。
- **两步走换乘（复测重点：任意进制双向）** — 没有直通车就换乘：先滚雪球回十进制，再短除法去目标进制。这个比喻我最喜欢，十进制是换乘大站！checkpoint 选对。
- **挑战 1 十进制转二进制** — 和短除法 demo 一样，闭卷默写成功。
- **挑战 2 二进制转十六进制** — 外层每次跳 4 格、内层滚雪球算一组、查表拼答案。三段都是本课刚教的零件，闭卷装起来了！下标 `s[i + j]` 我想了两遍才确认没写错。
- **二进制加法** — 1+1=10，写 0 进 1，竖式和十进制一样从右往左。checkpoint 选对。

## 至少 3 个必须修改的问题

1. **【P0】全课短除法代码缺 n=0 特例，而课后题 1（0<=n<=32767）和题 5（0≤n）都允许 0**：`while (n > 0)` 对 0 一行都不输出，学生严格照课件写必挂。建议在短除法卡片加一行"n=0 时答案是 0，循环进不去，要单独照顾"，并在挑战 1 的"容易错的地方"里列出。
2. **【P1】课后题 2（n≤10^12）和题 3（10 位十六进制最大约 1.1 万亿）都超 int，但全课 demo 一律用 `int`，没有一个字提醒按数据范围选 long long**：题 2 我可以自己想到，题 3 的"16 的 10 次方"超出三年级估算能力。建议在"转任意进制"或"任意进制回家"卡片加一句"数很大时（超过 21 亿）记得换 long long 盒子"。
3. **【P1】范围 for 第三次零解释出现在 3 个核心 demo 里**（按权展开、任意进制回家、两步走换乘）：滚雪球是本课最重要的代码骨架，却都用学生读不懂的循环写。建议全部改成 `for (int i = 0; i < (int)s.size(); i++)` 下标写法，或在第一次出现处正式补讲。
4. **【P2】`cout << hex` demo 输出小写 `ff` 与全课大写 FF 及题目要求不一致**：建议在 demo 注释里写"电脑这样输出小写，题目要大写时我们自己造字母"，顺便呼应密码表大写。
5. **【P2】"按权展开"卡片的"身价法"和 demo 的"滚雪球法"没有搭桥**：建议在任意进制回家处补一句"滚雪球其实就是把身价从左往右一个个乘进去，两种算法答案一样"。

## 知识状态更新（本课新增）

- 进制概念：十进制满 10 进 1、二进制满 2 进 1；八进制 0~7；十六进制 0~9+A~F（A=10…F=15，大写）。
- 按权展开：从右往左权是 1、2、4、8…（乘 2），每位乘权相加。
- 短除法（十→任意）：不停除以 base 记余数，**余数倒着读**；新余数拼到字符串最前面；余数>9 查密码表 `"0123456789ABCDEF"`。
- 滚雪球（任意→十，Horner）：从左往右 `r = r * base + v`；字母 `c-'A'+10`。
- 快速转换：3 位二进制=1 位八进制、4 位=1 位十六进制（2³=8、2⁴=16）。
- 换乘法：X→十进制（滚雪球）→Y 进制（短除法）。
- 二进制加法口诀：1+1=10，写 0 进 1，竖式从右往左。
- 能做：十转二、二转十六（4 位分组）、二转十、十六转十、n 转 8 进制、多组数据任意进制（大写+0X 前缀）。
- 新坑：短除法 n=0 会输出空行（要 `if (n==0)` 单独处理，被坑过一次后记住）；十六进制位数多时结果可能爆 int（估算不了 16^k，需老师提醒）。
