## 逐页体验（第一人称）

- **故事·外星人的数字**：电脑只用 0 和 1，`1101` 就是 13——比喻我喜欢，一下就记住"二进制是电脑的语言"。
- **回顾**：提醒我"`n%2`、`n/=2` 本领今天派用场"，正好接上 GESP1-15 的短除法，亲切。
- **什么是进制**：十进制满 10 进 1、二进制满 2 进 1、八进制(0~7)、十六进制(0~9加A~F)。A=10、F=15 我记了口诀。✅ 但"同一个数换种写法大小不变"——我得想一下才信。
- **进制操纵符 dec/oct/hex**：`hex` 输出小写、`oct`/`dec` 换进制——这个我记住了，但后面作业全用手算密码表，操纵符好像就"看看"用。
- **按权展开**：`1011 = 1×8+0×4+1×2+1×1 = 11`。课程用"1、2、4、8 不停乘 2"绕开了"2 的几次幂"（我没学幂），这点很贴心；但"为什么是 1、2、4、8"我还是当成数列背的，没真懂"翻倍"的道理。
- **短除法**：13→1101，余数倒着读。我在 GESP1-15 用过 `n%2`/`n/=2`，所以这套我熟；"倒着读"用"新余数放最前面"拼字符串实现，妙！
- **转任意进制**：除以几取余、密码表 `"0123456789ABCDEF"` 查字母——和我 GESP3-06 恺撒密码用的字母表一个套路，亲切。
- **躲开两个坑**：n=0 特判、数大换 long long（GESP1-02 学过 long long）。这两坑我记下了。
- **任意进制回家（Horner 滚雪球）**：`r = r*base + v` 从左往右滚。这个公式是新的，我算 checkpoint "2A"→42 时能算出，但背后"为什么这样累乘"说不太清。
- **快速转换 3/4 位分组**：二进制 3 位=1 位八进制、4 位=1 位十六进制；`1101 0110`→`D6`。分组思想新，但"从右往左分组、位数不够左补 0、去前导零"三步一起出现，我有点应接不暇。
- **两步走换乘**：X→十→Y，十进制当换乘大站。思路清楚（就是把前面两个套路拼起来）。
- **二进制加法**：1+1=10 满 2 进 1，竖式。但 demo 只用 `a+b` 用 int 直接加，没演示"手动按位进位写出二进制串"。

## 至少 3 个必须修改的问题

1. **一课塞入约 11 个新概念，认知负荷超标**（证据：line 31→507 依次出现 二/八/十六概念、按权展开、短除法、任意基短除、密码表、Horner 滚雪球、3/4 位分组、补零去前导零、换乘、二进制加法，仅 9 个检查点分散承接）。对从没见过进制的 9 岁孩子，一次吞下这么多，前面懂后面忘。建议：拆成两课——第 1 课只讲"二/八/十六是什么 + 短除法(含0特判) + 按权展开 + 十进制转二/八/十六"；第 2 课再讲"任意基(密码表) + 换乘 + 分组快速转换 + 二进制加法"。

2. **"按权展开"绕过幂记号但没把"翻倍"和"权"绑死**（证据 line 87-91 "各位的权依次是 1、2、4、8……（不停乘 2）"）。课程用"不停乘 2"照顾了没学幂的小柯，很好；但只给了数列，没解释"每往左一格能装的数翻倍"，孩子只能死背 1、2、4、8。建议：补一句生活比喻"每往左移一格就像多一个二进制盒子，能装的萝卜数翻倍（1→2→4→8）"，把"翻倍"和"权"真正讲通。

3. **课后题「小张的进制转换」藏了两个未教的点：b==16 加 `0X` 前缀 + 多组测试**（证据 problem `84a47b47` output_desc "b为16时记得加上0X"；input_desc "第一行为k，k组"）。课件只讲了通用短除法和换算，从没提"输出时按题目加 0X 前缀"这种题面特例，多组循环本课也没提（虽 GESP1-13 学过 T 组，但本课无承接）。建议：在"两步走换乘"或"任意进制回家"处补一句"有些题要求十六进制加 0X 前缀、字母大写，看清题面"；或把此题的 0X 规则在题干写清并标注为进阶题。

4. **`dec/oct/hex` 操纵符教了却全程不用，易误导**（证据 line 49-54 demo 用了操纵符，但 line 65 又说 `hex` 输出小写要自己转大写，且全部 5 道课后题都用"密码表手算"而非操纵符）。小柯可能误以为"直接用 hex 输出就行"，而作业偏偏要大写/特定格式，操纵符反而不够用。建议：在操纵符页明确"作业都要求自己用密码表手算转换，操纵符只用于快速验证；考试也可能考'认'操纵符输出结果"，避免误解。
