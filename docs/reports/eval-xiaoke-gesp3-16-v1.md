## 逐页体验记录

## 故事：二进制魔法

"猜奇偶"我会呀，`n % 2 == 1` 我写过好多遍！电脑说 `n & 1` 更快，还说"一个时钟周期"——**时钟周期是什么？** 是钟表吗？我问了两遍，课件没回答我。不过"对二进制的每一位施魔法"这句话好酷，我想知道怎么施。🪄

## 回顾

它说"我们知道了：整数在电脑里就是一串 0 和 1，比如 12 是 `1100`"。这个我真的知道！进制转换课学过短除法，我自己验算：12÷2=6 余 0，6÷2=3 余 0，3÷2=1 余 1，1÷2=0 余 1，倒过来 1100 ✅。10 是 1010 我也验了 ✅。"一位对一位地算，每一位互不影响"——这句我看懂了，就像竖式加减法但是没有进位。

## 卡片：按位与 &

"`&` 读作按位与：两位都是 1，结果才是 1"。竖式摆出来了：

```
  1100  (12)
& 1010  (10)
= 1000  (8)
```

我逐位检查：1和1得1，1和0得0，0和1得0，0和0得0 → 1000，就是 8 ✅。"妙用：`n & 1` 看最后一位"——我懂了！因为 1 的二进制只有最后一位是 1，跟它"与"一下，别的位全变 0，只剩下最后一位。这个比 `% 2` 巧妙！

demo 代码 8 行，每一行我都认识：`cout << (a & b)` 为什么要加括号？这里没讲，我先把疑问记下来（后面小贴士回答了）。

## 检查点：与一与（闭卷）

6 是 110，5 是 101。逐位与：1&1=1，1&0=0，0&1=0 → 100 = 4。选 A ✅。题目还把规则又写了一遍，不用翻前面。

## 卡片：按位或和异或

一次给两个符号，但每个都配了一句话规则和竖式，还行。`|` 有一个 1 就是 1；`^` 是"找不同"游戏——不同为 1 相同为 0，这个比喻我喜欢！竖式验证：12|10，1100|1010=1110=14 ✅；12^10=0110=6 ✅。

## 检查点：找不同（闭卷）

题目直接把 1100^1010=0110 给我了，0110=6，选 A ✅。有点太简单了，等于送分。

## 卡片：异或消消乐

三条性质：`a ^ a = 0`（自己消自己）、`a ^ 0 = a`、顺序随便换。前两条我用二进制想了想：`a^a` 每一位都相同所以全 0 ✅；`a^0` 跟 0 找不同，0 的位全 0，不同的就是 a 自己的 1 ✅。"顺序随便换"——它说是就是吧，我试了 2^3^2：2^3=1，1^2=3；换顺序 2^2=0，0^3=3，一样！真的是随便换。

demo 用数组 `int a[5] = {2,3,2,3,5}` 全部异或，答案 5。数组我学过（GESP3 数组课），`ans ^= a[i]` 就是 `ans = ans ^ a[i]`（复合赋值 GESP1-14 学过）✅。

## 检查点：异或消消乐（闭卷）

`a ^ b ^ a`：顺序随便换 → `a ^ a ^ b` → `0 ^ b` → `b`。选 A ✅。我一步步推出来的，很得意！

## 卡片：左移和右移

`<<` 左移 k 位 = 乘 2 的 k 次方；`>>` 右移 = 除以 2 的 k 次方（向下取整——floor 我 GESP2 学过）。3<<2=12（3×4）✅，12>>2=3 ✅。我想通了为什么：二进制里左移一位就像十进制里末尾添个 0（×10），二进制就是 ×2！

**但是最后一行：** "还有 `~` 按位取反，`~n = -(n+1)`"——就这一句话！没有竖式、没有例子、没有检查点。`-(n+1)`？取反怎么变出负数来了？`~5` 是 -6？为什么呀？我想了半天完全想不通，这里我标了"不太明白"⭐。开头目标说"学会六种位运算"，可 `~` 只给了一行，我觉得我五种会了，第六种没学会。

## 检查点：左移乘几？（闭卷）

3<<2 = 3×2² = 3×4 = 12。选 A ✅。

## 挑战 1：统计 1 的个数

**闭卷尝试**：我想——`n & 1` 看末位，看完要扔掉末位。右移我刚学，`n = n >> 1`。写出来：

```cpp
int n; cin >> n;
int cnt = 0;
while (n > 0) {
    if ((n & 1) == 1) cnt++;
    n = n >> 1;
}
cout << cnt << endl;
```

**对答案**：示例写的是 `cnt += n & 1;`（不加 if，直接加 0 或 1）和 `n >>= 1;`。2 处不一样，但我的写法也是对的，我数了样例 13=1101，我的循环走 4 次，cnt=3 ✅。示例的写法更短，我学会了"结果直接加进去不用 if"。**判定 🟡**（核心思路独立写出，但两种更简洁的本课新写法是看了示例才会的）。

另外示例完整程序 12 行，比新授示例的 8 行长，不过讲解卡把每一行都拆开了，我能跟上。

## 挑战 2：找落单的数

**闭卷尝试**：这不就是"异或消消乐"吗！只是输入变成"先读 n 再读 n 个数"。我写：

```cpp
int n; cin >> n;
int ans = 0, x;
for (int i = 0; i < n; i++) {
    cin >> x;
    ans = ans ^ x;
}
cout << ans << endl;
```

**对答案**：只差 `ans ^= x` 一个写法，思路完全一致。**判定 ✅**。

## 小贴士

"位运算符号优先级很低：`n & 1 == 1` 会先算 `1 == 1`！"——啊，这回答了我在按位与那页记下的疑问（为什么 `cout << (a & b)` 要加括号）！优先级 GESP1-07 学过，但"位运算比 == 还低"是新知识，我记住了：**写位运算就套括号**。

## 知识状态更新（真正掌握）

- `&` `|` `^` 三个按位运算的规则 + 竖式验算

- `>>=` 复合写法、`cnt += n & 1` 直加技巧
- 位运算优先级很低，必须加括号
- **未掌握**：`~` 按位取反（只有一行公式，没懂）
