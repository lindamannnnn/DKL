## 检查点：进制热身
题干直接给了 `1111` = 8+4+2+1，我闭卷心算 15，选 A ✅。其实不看提示我也会，`1101`=13 我 14 课就会了。

## 检查点：位运算热身
题干直接给了逐位结果 `001`，所以 5 & 3 = 1，选 A ✅。这三个 checkpoint 都把计算过程写好了，我基本没动脑——**像是"读一遍就选对"，不太能检查我是不是真的会**。

## 挑战 1：转成任意进制
闭卷写：14 课的短除法我熟，把 2 换成 d、余数查表 `"0123456789ABCDEF"` 我也记得（14 课教过查表）。我写出来了：
```cpp
int n, d; cin >> n >> d;
string g = "0123456789ABCDEF", r = "";
while (n > 0) { r = g[n % d] + r; n /= d; }
cout << r << endl;
```
对答案：demo 多了一行 `if (n == 0) r = "0";` 特判。题面说"输入**正整数** n"，所以不写也对。差 1 处（防御性特判）→ **✅ 独立通过**。
小意见：demo 有 10 行，比平时的例子长一点，但每行我都认识。

## 挑战 2：二进制转十进制
闭卷写：滚动乘加 `r = r * 2 + (c - '0')`，14 课一模一样的写法，我直接默出来了。对答案：demo 用 `long long r`，我用了 `int r`——讲解卡说"字符串很长时 int 装不下"，题面没给长度，我没想到这茬。差 1 处（类型选择）→ **✅ 独立通过**（思路全对，`long long` 是保险写法）。

## 挑战 3：负数的补码
闭卷写：推导链我记得——绝对值转 7 位二进制 → 符号位 1 → 取反 → 加 1。前两步我写出来了（15 课练过）。第三步"加 1 的进位"我记得规则是"遇 0 变 1 就停、遇 1 变 0 继续"，但**写成循环代码时卡住了**：从哪头开始扫？进位变量怎么停？想了大概一分半钟没写顺，偷看了一眼 demo 的 `for (int i = 7, c = 1; i >= 1 && c; i--)` 才写出来。→ **🟡 半独立**（看 1 次示例）。
这段 demo 有 12 行，而且 `for (int t = -n, i = 0; i < 7; i++, t /= 2)` 一行里塞了好多东西，我读了三遍才拆开。

## 挑战 4：统计 1 的个数
咦，这个题和 16 课挑战 1 **一模一样**，连样例 13 → 3 都没换。我闭卷直接默写 `while (n > 0) { cnt += n & 1; n >>= 1; }` → **✅ 独立通过**。但说实话有点像"把上节课的作业再交一遍"，没有新挑战。

## 挑战 5：找落单的数
又和 16 课挑战 2 **一模一样**，样例 `2 3 2 3 5` 都相同。异或消消乐我闭卷默写 → **✅ 独立通过**。同上，重复感明显。

## 课后挑战
5 道题我逐道闭卷做了（题面来自题库快照，我先遮住脑子里 14 课的例子）：

1. **八进制转十进制**（20 位以内）：滚动乘加 `r = r*8 + (c-'0')`。我注意到样例答案 1152921504606846975 好大，超过 21 亿，想起挑战 2 讲解卡的提醒，主动用了 `long long` → **✅**。
2. **二进制转换八进制**（100 位以内）：100 位 `long long` 装不下，要用字符串 3 位一组。可是 100 ÷ 3 除不尽！14 课只教过"长度刚好是 4 的倍数"的分法，**最前面多出来的 1~2 位怎么办**我没学过。卡了一会儿，后来想到"左边补 0 凑成 3 的倍数"（是看了样例 `111100001111000011110000` 长度 24 才反应过来可以先补零）→ **🟡**。
3. **十六进制转二进制**（≤100 位）：每个字符查表转 4 位，这个我会。但拼起来后**开头的 0 要不要去掉**？我第一版输出了带前导零的结果，对样例发现 `123...` 的第一位 `1` 变成 `1001` 而不是 `0001`，才明白首组要特殊处理 → **🟡**。
4. **8进制、16进制转10进制**：先读 N 再循环 N 次（GESP1 学过）。判断 `0x` 开头是十六进制、`0` 开头是八进制——这个规则题面写得清楚，我照着做了。但字母是**小写**的！课程里只见过大写 A~F，我愣了一下，想起 GESP1 学过"大写小写差 32"，写了 `c - 'a' + 10`。对样例确认 `0x1`→1、`011`→9 都对了 → **🟡**（小写字母和 `00` 这种边界让我核对了两次样例）。
5. **小张的进制转换**：就是挑战 1 多做 k 次，16 进制前面加 `0X`。我注意到 n 可以是 0，想起挑战 1 demo 的特判，补上了 → **✅**。

## 至少 3 个必须修改的问题

1. **挑战 4、挑战 5 与 16 课挑战 1、2 完全重复**（题干、样例、demo 逐字几乎相同，证据：对比 16 课 193~275 行与本课 242~323 行，样例 `13`→`3`、`2 3 2 3 5`→`5` 均未换）。练习课复习可以同型，但原题照搬让我"默写上节课作业"，没有检验迁移能力。建议至少换数字、换问法（如"统计 0 的个数""输出最低位的 1 在第几位"）。
2. **课后 5 题全部是进制转换，15 课数据编码、16 课位运算一题都没有**（证据：快照题 1~5 来源标注全是"进制转换"）。课目标写"复习第 14~16 课"，但补码和位运算结课后没有任何课后检验，等于白复习。【缺纲判定 + 建议】替换 2 道：位运算候选 `dc314ed7-039b-43f5-b8f3-95bfd4d58525`（找筷子，与挑战 5 同型）、`f94c5696-b78f-4020-8b45-4f06d5ab5249`（2进制中的0和1，进制+位计数双覆盖）；编码方向题库中**没有补码编程题**（`342c47f7`"字符串的反码"是字符镜像题，名不符实），最近似的是 `35c97828-348a-4c5c-a195-ee7fd8619adc`（二进制折半交换），建议补录一道真正的补码题。
