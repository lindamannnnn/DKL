## 至少 3 个必须修改的问题

1. **【严重】课后题偏离本课刚练的真题考点**（证据：课后题 1 字符串加密、2 字符串反码、3 八进制转二进制、4 半个回文、5 潜在素数，5 题全是"字符串变换 + 大数进制转换 + 回文/素数"，而本课真题单选/判断/编程练的是**补码换算、异或、substr、sizeof/strlen、凯撒密码**）。学生刚在课里练了补码和凯撒，作业却跑去练大数进制回文，巩固落空。建议：把作业换成紧扣本课考点的题，如——①给 8 位补码求真值（用"减 256"）②`a^b^c` 异或抵消求落单数 ③读入字符串用凯撒公式解密，与课内形成闭环。

2. **课后题出现"超长数/大范围"但课件没给脚手架**（证据：题3"100 位八进制"需字符串；题5"30 位二进制转十进制判素数"、题4"0~999999999"判二进制/十六进制回文）。小柯做这些要从前课自己拼"字符串拆位 + 回文 + 素数"三件套，跨度大、易错，而本课只在"编程题1 二进制回文串"示范了枚举+拆位，没示范"大数多进制 + 回文"套路。建议在题旁加提示："数太大用字符串，每位拆出来拼成 M 进制串再双指针比对回文"。

3. **题5 潜在素数 样例与题面数据范围矛盾**（证据：problem `f2a91cc3` input_desc 写"10<=n<=100"，但样例输入 `n=6`）。材料瑕疵会让小柯怀疑自己读错题。建议统一：要么题面改"1<=n<=100"，要么样例用 n=10 起步。

4. **检查点只有 2 个，单选/判断/编程都直接给答案，无强制闭卷**（证据：本课除 2 个 checkpoint 外，所有挑战题答案内联在 demo 卡里）。对自测诊断力弱——小柯容易"看着答案觉得会"。建议在每道挑战后加 1 个"遮住答案先做"的小测点或把部分答案折叠。
