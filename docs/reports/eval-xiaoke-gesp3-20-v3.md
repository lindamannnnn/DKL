## 至少 3 个必须修改的问题

1. **【严重】课后题偏离本课真题考点**（证据：课后题 3 二进制转八进制、4 小X转进制(平方在 M 进制回文)、5 乐乐的数(2~36 进制几重回文) 全是"大数多进制转换 + 回文"，而本课真题单选/判断/编程练的是**编码解释、`~` 公式、优先级、sizeof/strlen、字符替换、密码本**。学生刚练了 `~n=-n-1` 和优先级，作业却去练进制回文，巩固落空）。建议：把 3、4、5 部分换成紧扣主线的题，如——①用 `~` 公式算 `~x` ②求表达式 `!a<<b&c^d|e` 的值 ③输入字符串输出 `sizeof` 与 `strlen` 的差，与课内真题形成闭环。

2. **课后题再次出现"超长数/大范围"却无脚手架**（证据：题3"100 位二进制"、题4"N≤10000、M≤16"、题5"n≤2e9、进制 2~36"）。小柯做这些要从前课自己拼"字符串拆位 + M 进制 digit 表 + 回文双指针"三件套，跨度大，而本课编程题只示范了"密码本查表"和"字符大小写转换"，没示范"转 M 进制 + 回文"套路。建议在题旁加提示："转 M 进制用短除法取余查 `0123...9ABC...Z` 表，拼成串后双指针比对回文；数太大用字符串"。

3. **题5 乐乐的数实现风险高，课件未给脚手架**（证据：problem `2ea8126d` 要求 n≤2e9、对 base 2..36 逐个转进制判回文并输出"在哪些进制下回文"）。需 `long long` 防溢出、36 进制 digit 表、base 循环边界（base=2 与 base=36 都易漏），小柯独立写容易在"前导零/空结果/输出顺序"上出错，而本课未提供此类多进制回文模板。建议：要么降难度（如固定 base 集合），要么在课里补一段"转任意进制 + 回文判断"的通用脚手架代码。

4. **检查点仅 2 个，编程题直接给完整代码，无强制闭卷**（证据：本课除 2 个 checkpoint 外，编程题 1 加密、2 字符转换 均直接给出参考代码）。对收官课的自测诊断力弱。建议：把编程题改成"先写思路、再给代码"的两段式，或加 1~2 个闭卷小测点（如"字符转换里小写变大写用 + 还是 - 32"）。
