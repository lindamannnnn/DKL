### 逐页第一反应（边读边记）

- **故事页**：哈哈小柯写 50 个变量手酸，这个我懂，柜子的比喻不错，想看看数组长啥样。
- **回顾页**：`for` 循环我记得，OK 快速翻过。
- **什么是数组**：一排编了号的储物柜 🗄️，一个名字管整排——这个比喻我听懂了。
- **数组的定义**：`int a[5];` 是中括号！不是小括号。"大小必须固定、不能写变量"这个警告我看到了，还说了比赛开 `a[105]` 多留余量。代码 9 行能照着打。
- **检查点1**：抢答 B！`int a[5];`，太简单了。
- **下标从 0 开始**：啊？编号从 0 开始数？好奇怪……不过柜子的例子 `a[0]`~`a[4]` 画出来我认了。`a[5]` 叫"越界"，越界就是超出编号范围，有解释，好。
- **检查点2**：B，`a[4]`。刚才那页刚讲的，难不倒我。
- **越界会闯大祸**：一个 int 占 4 个字节，字节有解释（量内存的小格子），内存 GESP2-11 学过。但是"程序直接崩溃（**段错误**）💥"——段错误是啥？没解释，我愣了一下，算了反正知道会崩。"起点 + n × 4"这句有点像数学课，我眼神飘了一下。
- **检查点3**：A，越界会闯祸，刚才看了。
- **数组初始化**：`{1, 2}` 剩下补 0，`{0}` 全 0，好记。写在 main 外面自动全 0，记住了。
- **检查点4**：`{0}` 全 0 再把 `a[1]` 改成 5，总和 = 5，选 B。这个要稍微想一下，但没抢答错。
- **大数组放外面**："栈"是个小房间、地方挤，"爆栈"就是挤爆了——有比喻，能懂。秘诀：大数组开全局。
- **检查点5**：B，开全局。
- **循环遍历数组**："遍历"有解释（全部看一遍）。但是！前面说从 0 开始，这里又说比赛从 1 开始用、0 号柜空着占位？我迷糊了 10 秒钟。好在有个口诀"定义从 0 数，比赛从 1 用"，念了两遍，勉强接受。
- **检查点6**：A，`i <= n`。B 是 `i < n` 会漏最后一个，这个坑 GESP1 就踩过。
- **查找最大值**：打擂台 🥊！`maxv = a[1]` 当擂主，赢了就换人，这个比喻我喜欢。
- **最大值的位置**：多带个小本本 `pos` 记号码，换擂主顺手记，懂。
- **检查点7**：两个一样大的最大值输出哪个位置？我抢答了 B（最后那个）……等等，条件是 `>` 才换，一样大不换，所以是第一个，选 A。差点答错，好险。
- **挑战1~3**：都是刚讲过的，读入输出、打擂台、倒着 `i--`，代码都不到 10 行，能看懂。
- **挑战4（第二大数）**：呃，冠军 `m1` 亚军 `m2` 两个人一起记，`if (a[i] > m1) { m2 = m1; m1 = a[i]; } else if (a[i] > m2) m2 = a[i];`——我看了三遍才捋顺"老冠军退位当亚军"。看讲解能懂，合上书让我自己写，心虚。而且这段 demo **没有 `return 0;`**，前面每段都有，这段突然没了，我还以为复制漏了。
- **小贴士**：两条都是刚才讲过的，当复习。

### 至少 3 个必须修改的问题

1. **P1｜"段错误"无解释**（越界会闯大祸页）：三大后果里突然冒出"段错误"这个专业词，小学生会卡一下。建议改成"程序直接崩溃（电脑报一个看不懂的错）"。
2. **P1｜挑战4 示例缺 `return 0;`**：全课其他 demo 都完整，唯独最难的一段缺结尾，容易被当成"复制漏了"或直接照抄坏习惯。
3. **P1｜挑战4（第二大数）难度跳档且无模拟表格**：从"一个擂主"直接跳到"冠军+亚军双变量接力"，中间没有逐行表格模拟。GESP2-13 教过画表格模拟循环，这里应该用一次，否则多数同学只能看懂不能复现。
4. **P2｜从 0/从 1 只靠口诀硬扛**：全课练习全部从 1 开始用，"定义从 0 数"没有配套练习巩固，两节课后必混。建议加 1 道从 0 开始的小练习对照。
5. **P2｜课后题1 输入格式与课上样例不一致**：课上演示全是"第二行 n 个整数空格隔开"，课后题1 是每人一行（n 行）。`cin` 其实都能读，但题面没提，第一次见会愣住怀疑自己做错。
