## 学习日记（逐页体验，第一人称）

- **故事页**：小柯写 `s1,s2...s20` 手酸了 😵，说想要个大柜子。我心想：这个比喻不错，比写 50 个变量强多了，开头有 🗄️ 表情我眼睛没飘走。
- **回顾页**：for 循环复习，`for (int i=1;i<=n;i++)` 我早会了，秒过。
- **卡片·什么是数组**：一排编了号的储物柜，一个名字 `a` 管整排。✅ 懂。
- **卡片·数组定义**：`int a[5];` 中括号里必须是固定数字，`int a[n];` 错。我抢答："a[n] 错！"——但说实话没太注意"固定数字"这个限制，只记住了中括号。
- **checkpoint1**：闭卷想选 B `int a[5];` ✅。
- **卡片·下标从0开始**：`int a[5]` 编号 `a[0]~a[4]`，`a[5]` 越界。哦原来从 0 数，那"第5个"是 `a[4]`。
- **checkpoint2（第5个呢）**：一上来直觉想选 A `a[5]`（"第5个嘛"），但想起刚说从0开始、`a[5]` 越界，赶紧改选 B `a[4]`。首答错后改对 → 🟡（典型抢答没过脑子）。
- **卡片·越界会闯大祸**：脏数据 / 改掉别的变量 / 段错误。段错误这名字我记住了，但"为什么电脑不检查"我有点飘，没细看那句"起点走 n 格"。
- **checkpoint3（越界会怎样）**：选 A ✅（卡片刚列了三大后果）。
- **卡片·数组初始化**：`{1,2}` 其余补 0；`{0}` 全 0；写在 main 外面自动全 0。我记住了"大数组写外面"。
- **checkpoint4（总和是几）**：`int a[4]={0}; a[1]=5;` 总和=5，选 B ✅。
- **卡片·大数组放外面**：栈/爆栈/全局。栈这词我没完全懂，但记住"大数组写 outside（全局）"。
- **checkpoint5（大数组开哪）**：选 B 全局 ✅。
- **卡片·为什么从1用**：0 号柜空着占位，让"第 i 个"对上 `a[i]`。我觉得这招聪明，口诀"定义从0数，比赛从1用"我念了两遍。
- **checkpoint6（0号柜用处）**：选 A ✅。
- **卡片·循环遍历**：`for` + `i` 当下标一口气读写。✅ 这页我早就会（for 循环）。
- **checkpoint7（循环到哪）**：选 A ✅。
- **卡片·查找最大值**：打擂台，`maxv=a[1]`，后面逐个挑战。✅ 懂。
- **卡片·最大值位置**：带小本本 `pos` 记位置。懂了，但"两个一样大时输出哪个"这里我开始迷。
- **checkpoint8（哪个位置）**：闭卷想"两个一样大，那输出最后一个吧？"没想清 `>` 不更新 `pos` 的含义，选错方向。看答案 A（第一个）。🟡 需要看提示。
- **挑战1~4**：跟着 demo 看，心里想"这有什么难的"。逆序输出 `i--` 我会，第二大数维护 m1/m2 看完觉得还行但自己写可能漏 `m2=m1`。
- **课后挑战5题**：开始闭卷写。

## 至少 3 个必须修改的问题

1. **第5页"段错误"只给名字不给原理**（证据：第5页卡片仅写"这种崩溃有个名字叫段错误，记住名字就行"）。小明这类容易受挫的学生看到"段错误"会更慌，建议补一句"就是程序跑飞了、电脑不让它继续"，降低恐惧。
