### 至少 3 个必须修改的问题

1. **P1｜一节课塞 6 个新概念，密度过高**：插入、删除、交换、逆序、回文、逆序数，每个都配 demo。注意力差的学生到"逆序数"页已经疲劳（我 checkpoint 4、6 连续数错就是证据）。建议把"逆序数"挪到第 03 课或练习课，本课专注增删+交换+逆序。
2. **P1｜回文 demo 缺 `return 0;`**：连续第 2 课出现最难示例缺结尾行，风格不一致，学生照抄会养成坏习惯。
3. **P2｜逆序数 demo 没解释 `j = i + 1`**：为什么内层从 `i+1` 开始（自己不算、不重复数）是最容易被问的点，代码里一行注释就能解决。
4. **P2｜"指针"一词首次出现无解释**：虽然有"站排头/站排尾"兜底，但"指针"在 C++ 里另有含义，建议改成"左标记/右标记"或加一句"这里的指针就是位置编号的意思"。
5. **P2｜checkpoint 全是选择题**：插入、删除是本课核心动手技能，却没有一道手写代码的检查点，选择题全对 ≠ 会写（我课后题4 还是把插入位置搞错了）。
