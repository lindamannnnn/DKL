### 至少 3 个必须修改的问题

1. **P0｜挑战4 demo 与题目不符**：题目要求读入多组提问并逐组回答（样例 2 组提问 2 行输出），demo 却写死数组、只输出一行，既不是完整解法也不能运行出题面样例。这是本课唯一的"前缀和"内容，学生看完无法知道完整程序长什么样。必须补成完整读入 + 循环回答提问的版本。
2. **P1｜`while (cnt[v]--)` 写法超纲炫技**：后缀自减塞进循环条件，小学生无法理解"为什么刚好倒空"，也绝不会自己写出来。应改成 `for (int k = 0; k < cnt[v]; k++) cout << v << " ";`。
3. **P1｜前缀和无 checkpoint 巩固**：全新概念只出现在挑战4，配的还是残缺 demo，学完无法自检。建议加一道选择题 checkpoint（如 `sum[5]-sum[2]` 表示什么）。
4. **P2｜0 起始 / 1 起始混用无说明**：本课计数 demo 用 `for (int i = 0; i < 6; i++)`，与 01 课"比赛从 1 用"口诀冲突，学生到底听谁的没有交代。
5. **P2｜"值域"、大 O 记号无解释**：建议"值域"直接写"值的范围"，大 O 那页只保留数字对比即可，记号删去或标"知道意思就行，不用记"。
6. **P2｜三段 demo 缺 `return 0;`**：票王、桶排序、去重。连续三课出现，建议全课程统一检查。
