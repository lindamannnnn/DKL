## 学习日记（逐页体验，第一人称）

- **故事页**：选班长投票，小柯一张张数眼花 😵，老师说"一排桶，票写几号扔几号桶"——🗳️ 开头有图，我眼睛没飘。数组下标当桶这招我一下就开窍了！
- **回顾页**：复习数组遍历，过。
- **卡片·下标当桶用**：`cnt[v]` 表示值 v 出现几次，读到 x 就 `cnt[x]++`。比喻"往 x 号桶投球"⚽ 好懂。✅
- **checkpoint1（桶里几票）**：`a={2,1,2,1}` → `c[1]=2`，选 B ✅。
- **卡片·桶要先清空**：写在 main 外面自动清 0 最省心；值最大 100 就开 `cnt[101]`。小明：这点和 GESP3-01 学的"大数组写外面"对上了。✅
- **checkpoint2（数组开多大）**：1~100 → `cnt[101]`，选 B ✅（记得 +1 留 0 号位）。
- **卡片·什么时候能用**：值域别太大（≤10⁶）、必须是整数、个数随便。小明：看到"身份证号""小数"直接判不能用，✅。
- **checkpoint3（哪种适合）**：选 A 一万个0~100成绩 ✅。
- **卡片·谁是票王**：扫桶打擂台，`cnt[v]>cnt[ans]` 换冠军。✅ 和 GESP3-01 打擂台一个套路。
- **checkpoint4（票王几号）**：`2 1 2 3 2`→2号，选 B ✅。
- **卡片·桶排序**：桶从小到大依次打开，倒几次就输出几次，自动排好。✅ 好玩。
- **checkpoint5（倒出来啥样）**：`3 1 4 1 5`→`1 1 3 4 5`，选 B ✅。
- **卡片·计数法有多快**：O(n+V) vs O(n²)，10万数据时 10万次 vs 100亿次。O 记号"混个脸熟"，小明：公式记不住但知道计数法快很多。⚠️ 这里开始走神 2 秒，"一亿次"数字太大我没概念。
- **checkpoint6（多快）**：选 A ✅。
- **挑战1~3**：统计票数、票王、去重（seen 签到表）。去重用 `bool seen` 当签到表，我觉得妙。会写。
- **卡片·前缀和**：`sum[v]`=值≤v 的个数，台阶🪜 比喻。"区间 [l,r] 一次减法 `sum[r]-sum[l-1]`"——这句我开始晕，减法怎么就出区间了？
- **checkpoint7（sum表示啥）**：选 A "值≤i 的个数" ✅（卡片刚写），但 `sum[r]-sum[l-1]` 的真正含义我没真懂，只是背了定义。
- **挑战4 区间计数**：前缀和真应用。`while(q--)` 答 q 次。小明：照着 demo 能写，但"为什么 l=1 时 sum[0]=0 不越界"没细想。
- **课后挑战5题**：闭卷。

## 至少 3 个必须修改的问题

1. **课后题 P5「查找含有x的数」会被计数法误导，但解法根本不是计数法**（证据：快照 P5 要找"数位里含 x 的数"，需拆数字逐位判断，我用 `cnt[x]++` 直接错）。建议在本课"计数法适用条件"卡片补一句反例："如果要比的是'数字里含不含某位'，计数法不顶用，得拆数字"；或在 P5 题目前加一行提示。
2. **前缀和只给了台阶比喻，缺一张"区间减法"可视化图**（证据：checkpoint7 我会选定义但 `sum[r]-sum[l-1]` 真义没懂）。建议在"前缀和"卡片配一张区间相减的图/例子，帮小明类学生建立"减法=扣掉前面"的直觉。
3. **挑战4「区间计数」的 `while(q--)` 和 `sum[0]=0` 没解释**（证据：第"区间计数"页 demo 直接出现这两个，小明没细想 l=1 为何不越界）。建议卡片里补一句"`sum[0]` 是 0 号起点，l=1 时减它刚好减 0"，以及 `while(q--)` 就是"问几次答几次"。
