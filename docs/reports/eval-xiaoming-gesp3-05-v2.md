### 逐页第一反应（边读边记）

- **故事页**：足球队最长连胜！1000 场数不过来所以让电脑数，动机清楚。
- **回顾页**：对哦，`cnt[x]++` 只管总数不管挨不挨着，这个矛盾点提得好。
- **连续和总数**：总次数 vs 最长连续，两道题对比摆出来，一下分清了。这页很重要。
- **检查点1**：`1 2 2 2 3 3 2`，2 最多连着 3 个，选 B。没掉进"总数 4 个"的坑（选项 A 就是坑）。
- **滑动计数器**：`cur` 记当前、`maxL` 记历史，相同 `cur++` 不同 `cur=1`。套路清楚，代码 10 行能跟。又没 `return 0;`（我都懒得数第几段了）。
- **检查点2**：`5 5 5 2` 走完 cur 是几？我抢答 A（3）……不对！最后一个是 2，断了，`cur=1`，选 B。又抢答，该打。
- **记下冠军**：破纪录时顺手记 `a[i]`，和第 01 课 `pos` 小本本一个套路，亲切。
- **检查点3**：`1 1 2 2 2 1` 最长 3，选 B。这次数了两遍才答，对！
- **逐段点名**：哨兵 🧍！最后一段没人提醒断开，让 `i` 多走一格到 `n+1` 触发输出。`i == n+1 || a[i] != a[i-1]` 这个"或者"的用法妙，我想了想才明白：到最后一个假位置时，前面半截条件直接成立。有点绕但能接受。
- **检查点4**：A，哨兵是为了最后一段。刚讲的。
- **连续递增段**：条件改成 `a[i] == a[i-1] + 1`，套路不变，这个"换条件不换套路"的设计我喜欢。
- **检查点5**：`1 2 3 1 2 4 5` → 最长 3，选 A。
- **检查点6**：B，后一个恰好大 1。秒答。
- **RLE 压缩术**：`aaabbc` 压成 `a3b2c1`，概念看例子就懂，挺酷。但是！**代码我完全看不懂**：`string s` 是什么？`.size()` 是什么？`(int)` 套外面干嘛？还有 `for (j = i; j < ...; j++);` 后面直接一个分号，循环体呢？？这不就是我老是手滑多打分号的写法吗，这里居然是**故意的**？？我盯着看了快一分钟，放弃了，反正例子我懂。
- **检查点7**：`1 1 1 2 2 3` → `1×3 2×2 3×1`，选 A。概念题能答。
- **挑战1**：就是"记下冠军"加输入输出，能默写。
- **挑战2**：最长连胜回到故事了！`cur=0` 起步的解释清楚（可能全输），"边数边更新 maxL"的提醒关键。
- **小贴士**：四条全是干货，`cur=1` vs `cur=0` 的区别总结得好。

### 至少 3 个必须修改的问题

1. **P0｜RLE 卡片 demo 严重超纲**：用了 `string`、`s.size()`、`(int)` 强转、逗号声明 `int i = 0, j`、空循环体 `for (j = i; ...; j++);`。string 是第 07 课才教的内容，且"for 后面故意带分号"正是小学生最典型的手滑错误，在这里出现会严重误导。建议用 int 数组 + 本课哨兵套路重写，或明确标注"这段代码第 07 课后再回来看，现在只看懂例子"。
2. **P1｜五段 demo 缺 `return 0;`**：滑动计数器、记下冠军、逐段点名、递增段、RLE。01~05 课反复出现，建议全课程脚本化检查补全。
3. **P1｜课后题"小X数字母"超纲（已替换）**：原题输入是字符串，需要 string 或字符数组（第 06/07 课内容）。已按流程替换为同主题（逐段统计连胜）同难度的"连胜统计"，并补齐 5 个测试点（1 可见 + 4 隐藏、各 20 分），重跑导入完成。原题保留在题库未删。
