## 至少 3 个必须修改的问题

1. **课后题 P1「浪尖数」要"比左右都大"且首尾不算，但课件只教了"相同段/递增段"的单向相邻比较，没示范"局部极大值"这种左右双判 + 边界**（证据：快照 P1 要求数浪尖数，我首答漏了 i=1/i=n 边界）。建议本课"连续"下补一句："相邻比大小也能找'浪尖'（左右都小），注意第1个和最后1个不能算浪尖。"
2. **哨兵逐段输出是本课难点，但只在一道 demo 出现、课后题 P3 直接要"逐段输出+过滤"，跨度大**（证据：P3 我卡在哨兵输出+长度≥2过滤）。建议在"逐段点名"卡片后加一道"带过滤的逐段输出"小练习，降低直接上 P3 的挫败。
3. **"相同段 cur 从 1"与"连续1/连续≥90 cur 从 0"的起始差异，只在小贴士提了一句，没有对比练习**（证据：P5 我把 cur 初值设错）。建议加一道对比 checkpoint：给"连续相同段"vs"连续达标段"两个例子让群众选 cur 初值，强化区分。
