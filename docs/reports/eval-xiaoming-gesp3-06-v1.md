### 逐页体验记录（按 `## ` 分页，先看有没有好玩的 → 快速翻 → 挑重点读）

- **故事：名字存不下啦** "`int name = mike;` 报错"哈哈，这个我知道，字母不能塞进 int。故事还行，10 秒看完。
- **回顾** int 数组我记得……大概。`int a[5]`、下标从 0 开始，对对对。跳过。
- **卡片：char 密码表** ASCII 表？这个 GESP1 就学过了嘛，48、65、97，我会！（自信）demo 扫了一眼就翻页了，`(char)(c + 2)` 没细看。
- **检查点：密码是几** B，66。这有什么难的。
- **卡片：字符数组** ⭐ 新东西来了。"末尾加小旗子 `'\0'`"，"4 个字母占 5 格"——加粗了，我看到了。行吧，字符串后面跟着个隐形的 0。demo 里 `cout << (int)a[4]` 输出 0，哦，真的有个 0 在那。
- **检查点：柜子要几个** C，6 个。5 个字母加 1 个旗子，刚才那个加粗句救了我。
- **卡片：读入字符串** `cin >> s` 和 `cin.getline(s, 100)`，一个有空格就停一个读整行。知道了知道了。（其实没太往心里去，后面证明真没往心里去。）
- **卡片：常用小助手** 四个函数，名字都挺直白：strlen 数长度、strcat 接上去、strcpy 抄、strcmp 比大小。"字典序"？啥玩意儿，不管了，先翻。两个 demo 长得差不多，扫了一眼。
- **检查点：长度是几** `strlen("apple")`……我刚学完"旗子占一格"，所以是 6！选 C！……对答案发现是 B。啊？括号里写了"不含 `\0`"？我漏看了！烦，这个括号也太小了。
- **卡片：大小写变身** tolower、toupper、isupper、islower、isdigit，一堆英文函数名，头有点大，但每个都配了中文，忍忍能看。demo 的循环条件 `s[i] != '\0'`——用旗子当停止信号，这个写法挺巧，我记住了（自认为）。
- **检查点：变身结果** B，`'b'`。秒选。
- **挑战 1：统计字母数字** 看到"统计""大写小写数字"就开始写了，用 `cin >> s` 读，三个计数器 + is 系列判断。跑样例 "Hello 123"：我输出 `1 4 0`，答案 `1 4 3`。啊？？数字哪去了？……哦，"123" 在空格后面，`cin >> s` 只读了 "Hello"！题面里"（可能含空格）"我根本没看见。回去翻读入字符串卡，换 `cin.getline`，对了。浪费我五分钟，什么破题……好吧是我没看题。
- **挑战 2：字符串比大小** `strcmp(a, b)`，我记得是"负数 a 大、正数 a 小"……写了 `if (r < 0) cout << ">"`，样例 apple banana 答案是 `<`，我输出 `>`。错了！翻教师卡："负数是 **a 小**，不是 a 大"。靠，记反了。改过来对了。教师卡那句"比的是地址不是内容"——地址？听不懂，跳过，反正记住要用 strcmp。
- **小贴士** "`char a[5] = "hello"` 是错的"——知道知道，6 格嘛。（刚错的 CP3 其实就是因为这个……算了不想了。）
- **课后挑战** 5 道题。做完给徽章对吧？冲。

### 至少 3 个必须修改的问题

1. **检查点 3 的关键信息藏在括号里，对粗心的孩子形同虚设**（证据：第 136 行 `strlen(s)` 的说明"数有几个字符（不含 `\0`）"，"不含 `\0`"是全题题眼却只出现在括号里；我闭卷直接答错）。建议把"**不含小旗子**"做成加粗主句或单独一行，例如："`strlen(s)`：数有几个字符，**小旗子不算！**"
2. **"字典序"首次出现无解释**（证据：第 139 行首次使用，解释滞后到第 310 行；我全程没搞懂这个词，纯靠背规则过的挑战 2）。建议首次出现处加半句解释。
3. **课后题 5 与课件有教学缝隙，且存在"碰巧 AC"的陷阱**（证据：课件第 139 行只承诺 strcmp 返回负/0/正；题 5 要求输出具体差值；我直接 `cout << strcmp()` 碰巧对样例但说不清原理——这会**奖励侥幸心理**，比做错更有害）。建议挑战 2 教师卡补一句"strcmp 只告诉你谁大，差多少要自己逐字符减"，把题 5 的正路指出来。
4. **挑战 1 教师卡易错点表述有误**（证据：第 265 行"会把空格后面的垃圾也数进去"——`i < 1005` 的真实风险是读到 `\0` **之后**的乱数据，和"空格"无关；我读到这句时真的困惑"空格后面不是数字吗"）。建议改为"会把小旗子后面的乱数据也数进去"。
5. **"地址"未解释**（证据：第 321 行；基线中指针/地址属未学；我看了 5 秒跳过）。建议改成"比的是柜子的位置，不是里面的字母"或删去该分句。
