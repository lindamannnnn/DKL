## 测试课程：GESP3-07 string 使用1

### 逐页体验记录（按 `## ` 分页，先看有没有好玩的 → 快速翻 → 挑重点读）

- **故事：弹性魔法袋** 袋子自己变大变小？行吧，比上一课"算格子"省事就行。10 秒看完。
- **回顾** strcat、strcmp……上一课那堆函数，大概记得。跳过。
- **卡片：string 来啦** 拼接用 `+`，比较用 `==`、`<`——"比字符数组方便嘛，早干嘛去了"。demo 扫一眼：`a + b` 拼起来，哦。`if (a < b)` 那行没细想，注释说会输出就会输出吧。
- **检查点：拼起来是啥** C，"abcd"。这有什么难的。
- **卡片：读出整行** `getline(cin, s)` 读整行、`cin >> s` 读一个单词、`s.size()` 数长度、`s[i]` 看下标。三个本领塞一张卡，我扫了 20 秒，"反正都是读和数"。（没注意到这跟上一课的 `cin.getline(s, 100)` 写法不一样——根本没发现，后来才知道反而少了个烦恼，但也说明我压根没读细。）
- **检查点：长度是几** "hi c++"……h、i、c、+、+，5 个！选 A！……对答案是 B（6）。啊？**空格也算？** 卡片里根本没加粗说"空格算一个字符"啊！烦。哦等等，getline 那行是说了"含空格"……可我哪会把两句话连起来想。
- **卡片：find 找一找** `s.find("abc")` 找下标。`string::npos`？什么鬼名字，两个冒号，长得像乱码。"查无此串"是吧，行，背下来。demo 里 `if (s.find("xyz") == string::npos)` 那行太长了，跳过。
- **检查点：找到哪儿** "abcde" 找 "cd"……a 是 0、b 是 1、c 是 2，选 B。下标从 0 开始这个我还是记得的，数组那几课没白学。
- **卡片：replace 替换** `s.replace(起点, 个数, "新内容")`，换就换呗。demo 扫一眼。
- **检查点：换成什么** 0 号位换 5 个，hello→hi，剩 world，A。秒选。
- **卡片：大小写变身** tolower 逐格变，上一课见过，"这个我会"。demo 没看，翻页。
- **挑战 1：找子串位置** "子串"啥意思？看样例大概懂了，就是要找的那一小段。闭卷写：`cin >> s >> t`……等等不对，主串样例 "hello world" 有空格，先这么写试试。跑样例：输出 -1，答案是 6。啊？？哦——`cin >> s` 只读到 "hello"！又是这个坑，06 课挑战 1 我就踩过一次！翻回读出整行卡，换 `getline`，对了。同一坑踩两次，气死。
- **挑战 2：替换所有子串** 看到 demo 那行 `while ((pos = s.find(o, pos)) != string::npos)` 我直接懵了：条件里怎么是 `=`？find 后面怎么有两个东西？这行我盯着看了半天，放弃理解，直接抄形式。"反正照着写能跑"。教师卡说 `pos += n.size()` 是跳过新内容防死循环——嗯嗯，抄的时候带上。说实话这页我只学到了"复制这段"。
- **小贴士** 两条，瞄了一眼。
- **课后挑战** 5 道题，全过有徽章。冲！

### 至少 3 个必须修改的问题

1. **挑战 2 的 while 行是全课唯一的"硬坎"，且教师卡没拆——我三道题翻三次 demo 都默写不出**（证据：demo 第 273 行 `while ((pos = s.find(o, pos)) != string::npos)` 同时引入 find 第二参数、条件内赋值、npos 比较三件事；教师卡 285~310 行只解释了 `pos += n.size()`；我课后 2、课后 5 连续靠抄，理解缺口被重复验证 3 次）。建议：改用 `while (true)` + `if (pos == string::npos) break;` 的写法（break 我 GESP1 就会），或教师卡把该行逐块拆开讲。**这是我完成度差 0.05 没过的直接原因。**
2. **`size()` 数空格这条规则没有强调，检查点 2 直接考它**（证据：读出整行卡第 70~72 行只把"含空格"写在 getline 的说明里，size 的说明"有几个字符"没提空格；我闭卷选错）。建议 size 说明改为："`s.size()`：有几个字符，**空格也算一个！**"
3. **`getline(cin, s)` 与 06 课 `cin.getline(s, 100)` 写法冲突零解释**（证据：第 70 行；小柯卡了 40 秒，我虽然没发现但说明这处对细读的孩子是真实障碍）。建议加一句对比说明，顺带解释为什么 string 不用写 100。
4. **课后题 2 提示引入未教的 substr**（证据：快照题 2 提示；我当场烦躁 30 秒"这词没教过啊"）。建议改为"用 find 完成即可；以后学了 substr 可以再试"。
5. **`string::npos` 的双冒号无解释**（证据：第 109 行；长得像乱码，只能硬背）。建议加半句"先当整体记号记住"。
