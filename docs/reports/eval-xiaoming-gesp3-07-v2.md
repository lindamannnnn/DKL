- **P9 数字变身串**：to_string 数字变串、stoi 串变整数、stod 串变小数。demo 对比好：`"123"+"!"` 是拼接，`stoi("456")+1` 是加法。stoi 这拼写好怪，s-t-o-i，我得盯着抄。

- **P10 大小写变身**：for 循环逐格 tolower，第 06 课学过 tolower，搬到 string 上一样用，懂。
- **P11 挑战 1**：find + npos 输出 -1，照着 CP4/CP6 的思路能看懂。代码 11 行有点长但讲得细。

### 至少 3 个必须修改的问题

1. **挑战 2 的 `while ((pos = s.find(o, pos)) != string::npos)` 把赋值塞进循环条件**（证据：这类写法我在 GESP3-03 就没学会，本课 3 道课后题全都要用这个骨架，闭卷一道都写不出，只能照抄；建议拆成两步写 `pos = s.find(o, pos); while (pos != npos)` 或明确说"先当咒语背"）
2. **课后题 2 的提示写"请分别用 find 及 substr 两种方法求解"，但 substr 全课没教**（证据：我翻遍课件没找到 substr，慌了 1 分钟；提示超纲，应删改或在课里补 substr）
3. **P8「增删清空」一页 4 个新函数，重蹈第 06 课覆辙**（证据：insert/erase 的参数顺序没有任何 checkpoint 巩固，我看完即混；建议拆页或至少给 insert、erase 各配 1 个 checkpoint）
