- **P7 挑战 5 替换所有**：第 07 课挑战 2 的原版复习，`pos += n.size()` 跳过新内容。第二遍看顺眼多了，但闭卷还是写不出那个 while 条件。

### 至少 3 个必须修改的问题

1. **课后 2「判定字符位置」没说清位置从 0 还是从 1 开始数**（证据：题面只有"首次出现位置"五个字，我闭卷输出 0 基下标，全靠样例 "and"→1 才发现是 1 基；课里 06/07 一直强调下标从 0 开始，这题突然从 1 数，题面必须写明）
2. **课后 4「有没有重复的字符」题意表述绕**（证据："第一个出现的重复字符"既可以理解成"按首次出现顺序第一个有重复的字符"（正解），也可以理解成"最早发生重复的那次"（我第一遍的理解），卡了 2 分钟靠两个例子才反推出来；建议题面直接写"按字符第一次出现的顺序，找到第一个在串中出现超过一次的字符"）
3. **挑战 4/5 继续使用 while 条件里塞赋值的写法**（证据：连续三课（03、07、08）出现这类写法，我至今闭卷写不出；练习课正是拆成两步教学的好机会，却只字未提）
4. **挑战 2 讲解"直接用 ASCII 加减 32 容易写错"与第 06 课矛盾**（证据：06 课卡片明说"不用函数也能手动变身"，我课后题就是用 ±32 做对的；这里又说容易写错，让人困惑到底听哪边的——建议改成"±32 也行，但 tolower 更不容易写错"）
