- **CP3**："abc" 倒车 → "cba"，选 B。✅

- **CP4**："level" 是回文，选 A。✅ 白送。
- **P7 双指针回文**（新补内容）：等等，这个我会！GESP3-02 学过双指针夹逼逆序，回文判断也是 `while (l < r)` 不一样就 NO！搬到 string 上一样。就是这行代码全挤在一行里，`while (l < r) { if ... break; } l++; r--;` 看得我眼花，不能一行一个动作吗？

- **P8 sort 排排坐**：`sort(s.begin(), s.end())` 自动排 a→z！排序不是很难的东西吗？一行就完事？将信将疑，先背下来。
- **CP6**："cab" 排序 → "abc"，选 B。✅
- **P9 删掉指定字符**：⚠️ `for (char c : s)` 是啥？！for 后面不是应该有三个格子（初始、条件、加加）吗？怎么变成 `c : s` 两个了？没人解释！……跳过跳过，反正意思我猜是"一个个字符看"，我用老办法 `for (i=0; i<s.size(); i++)` 照样能写。
- **CP7**：要删的字符直接跳过，选 B。✅（遍历拼接我 07 课课后题就会了）
- **P10 挑战 1 截取一段**：第 l 到第 r 个 → `substr(l-1, r-l+1)`。讲解把"起点减 1、个数 r-l+1"掰开揉碎讲了，还让我拿样例比划——这个提醒好，我就是需要比划的人。
