## 至少 3 个必须修改的问题

1. **【P1】第 16 页剪枝 demo 的去重逻辑零解释**：`for (int b = a; ...)` 为什么从 `a` 开始、`if (c >= b)` 防什么，正文和后面小贴士都没讲。我盯了一分钟只能猜。剪枝是本课新补重点，结果最关键的一步成了"看得懂跑、闭卷想不到"。建议加一句："b 从 a 开始、c 要比 b 大，是为了同一种分法不重复数（1,2,3 和 2,1,3 算一种）"。
2. **【P1】第 14 页 10⁸ 表格只有结论没有推导**：两重循环为什么 n 只能到 1 万？（因为 1 万×1 万=1 亿）。不讲推导我只能背表，换个问法（比如"三重循环 n=200 行不行"）我就傻眼。建议在表格下加一行算式演示。
3. **【P1】"超时"这个新词全文未解释**（第 14 页"超时红线"）：零基础小孩不知道"超时"=程序跑太久被判错误。一句话就能补："题目要求 1 秒内跑完，跑不完就叫超时，直接判错"。
4. **【P2】挑战 2 的 `z%3==0` 条件埋在正文之后的"容易错的地方"**：题面"小鸡 1 文买 3 只"的约束应该在解题思路分步里就点明，而不是等学生踩坑后再看。我就是漏了它。
5. **【P1】课后题"趣味填空"存在 int 溢出陷阱但课程零提示**：上限 2×10⁹，切开的两半相加可超 int 范围，需要 `long long`（GESP1 学过但没人提醒这里要用）。样例不触发、隐藏点必挂，对我这种"样例过了就交"的人是精准打击。建议课件在该题旁加一行提示，或把上限降到 int 安全范围。
