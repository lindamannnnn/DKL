### 至少 3 个必须修改的问题
1. **第"剪枝小妙招"卡片去重目的没点明**：示例 `b 从 a 开始 + c>=b` 同时在做"提速"和"避免重复计数"两件事，但卡片文字只强调"剪掉结不出果子的枝＝省时间"，没说清"a≤b≤c 也是为了不把 3+5+92 和 5+3+92 算两遍"。小明读完只记住"剪枝=跳过"，漏掉去重这层。证据：该卡片正文。
2. **第"电脑有多快"卡片一次塞三个新数（1亿/1万/500）**：五年级生一次性接收"超时红线 + 操作次数 + 层数对应上限"三个抽象概念，无生活比喻，小明直接走神。建议拆成两页或配"数数比赛"比喻。证据：该卡片表格。
3. **挑战1 水仙花数 demo 用 `a*a*a` 求立方，但没提醒"不能写 a^3"**：^ 在 C++ 里是按位异或不是乘方，小明凭数学直觉很可能写成 `a^3` 得错答案，课件应在易错点补一句。证据：挑战1 demo 与"容易错的地方"都未提及。
