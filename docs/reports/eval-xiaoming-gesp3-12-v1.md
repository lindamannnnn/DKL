## 逐页体验记录

### 故事：蜗牛爬竹竿
蜗牛爬竿，10 米，白天 3 晚上滑 2。不就是除一除嘛……等等还不能直接除。纸上画了一下，第 8 天到顶。行吧，有点意思，继续。

### 回顾
枚举 vs 模拟，两行字，扫一眼，懂了懂了（大概）。

### 卡片：什么是模拟
"程序当演员"。demo 砍小怪 8 行，hp 从 10 减减减，cnt 数数。输出 4。哦。还行，30 秒看完，没走神。

### 检查点：模拟是什么
选 A。这题白给。

### 卡片：模拟三要素
状态、转移、终止。三个词连着蹦出来，每个配一行小字。我看了第一句"状态：现在是什么样"就往下瞟 demo 了。demo 8 行，和上面砍小怪差不多嘛，`while (pos < 10)` 加加加。翻翻翻。

### 检查点：三要素归谁
`pos += 3` 属于哪个？状态吧，它在改 pos……不对，等等，"改"是动作，动作是转移？我翻回上一页对了一下那三行小字——哦，"每一步怎么变"是转移。选 B。**第一遍选了 A，回看后改对**。

### 卡片：按指令走路
机器人走路，R 右 L 左。demo 9 行，`x += (c == 'R' ? 1 : -1);` 这行啥玩意，密恐。跳过没细拆，反正后面有检查点。

### 检查点：最后在哪
RRRL 从 1 出发：右右右 = 4，左 = 3。选 C。这个不用看代码。

### 卡片：数组记状态
发牌，`a[(c - 1) % 3 + 1]++`。下标带取余，枚举课邮票题见过类似的。demo 9 行，扫过去，能跟。

### 检查点：牌发给谁
第 7 张：1231231，1 号。选 A。

### 挑战 1：蜗牛爬竿
**闭卷尝试**：这有什么难的，照抄页 5 的 demo 改成输入版：

```cpp
while (pos < h) { day++; pos += u; pos -= d; }
```

样例 10 3 2 一跑……我手算出来是 9，答案是 8。啊？哦，题面说"白天爬到顶当晚就不再滑"。谁让题面写那么长，我漏看了。烦躁。
**对答案**：demo 里多了 `if (pos < h)` 守住滑落。改完和 demo 一致，差 1 处。
**判定：🟡**（漏看题面规则 → 看示例才补对）

### 挑战 2：机器人走方格
**闭卷尝试**：四个方向四个 if，写完一跑样例，我输出 `3 3`，答案 `1 1`。检查：U 写成了 `x++`（上面不是大吗！），L/R 和 x/y 也搅在一起了，边界还没判。改一次还不对，第二次还错。**想摔键盘，这什么破题。**
**对答案**：看 demo——上是 `x--` 配 `x > 1`，下是 `x++` 配 `x < n`，左右用 y。行号越小越靠上……行吧。逐行抄改后一致，差了 3 处。
**判定：🟡**（两次失败想退出，看到"全部通过有徽章"才回来，看示例改对）
