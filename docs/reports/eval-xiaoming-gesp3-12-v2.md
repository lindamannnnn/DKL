11. **卡片：数组记状态** —— `a[(c-1)%3+1]++` 轮流发牌，下标转圈，盯了两遍才看懂 -1 再 +1 是把 1~3 映射好。能看懂但写不出。
12. **检查点：牌发给谁** —— 第 7 张：7%3 余 1，1 号，选 A。✅
13. **卡片：围圈报数** —— 环形下标 `cur = (cur + 1) % n` 配"圆形餐桌头尾相接"的比喻，**概念我懂了**！但是 demo 看得我头皮发麻：`fill(alive, alive+6, true)` 没见过；`if (alive[cur] && ++cnt == 3)` 把 `++` 塞进条件里；`alive[cur] = false, left--, cnt = 0;` 一串逗号是什么？（GESP2-13 提过逗号表达式，当时就懵，现在还是懵。）这一页代码我投降，只看懂了思想。
14. **检查点：绕圈怎么数** —— (3+1)%4=0，选 A。✅ 环形下标会算，就是代码写不出。
15. **挑战 1：蜗牛爬竿** —— 闭卷写：`while (pos < h) { day++; pos += u; pos -= d; }`——**漏了 `if (pos < h)` 守住到顶不滑**，样例 10 3 2 我算出 9 天（第 8 天到 10 又滑回 8 再爬一天），对答案才发现要"先爬、再判断、最后才滑"。改完对。🟡
16. **挑战 2：机器人走方格** —— 闭卷：我用老式 `for (int i = 0; i < s.size(); i++)`（范围 for 不会，绕开它），四个 if 写了，但**第一次把 U 写成 `x++`**（忘了行号越小越靠上），样例 RRDDUULL 绕回 (1,1) 我算成 (3,3)，对答案改过来。🟡
17. **卡片：方向数组** —— 新补的内容！"遥控器选台"比喻好，`dx/dy` 两个数组把四个 if 变一行。demo 短，这次没用范围 for，我能完整读懂！从 (1,1) 选 1 号"下"走到 (2,1)，对上了。这个我真学会了。
18. **检查点：方向走一走** —— dir=2 是"左"：dx[2]=0、dy[2]=-1，(2,2)→(2,1)，选 A。✅ 一次对，方向数组没白学。
19. **小贴士** —— "小心最后一步"：到顶不滑、撞墙作废，刚好是我今天栽的两个坑，服了。

## 至少 3 个必须修改的问题

1. **【P0】范围 for `for (char c : s)` 连续两课零解释使用**：09 课见过没学会，本课第 9 页、第 16 页核心 demo 继续使用。我这页代码只能靠猜，挑战 2 被迫绕回老式 for。要么在第一次出现处加一行解释（"这是把 s 里每个字符轮流交给 c 的简便写法"），要么全课程统一先用三段式 for。
2. **【P1】围圈报数 demo 单行塞 3 个未教知识点**：`fill()`、`++cnt == 3`（前缀自增塞条件）、逗号表达式三连出现在同一行。约瑟夫是本课新补重点，环形下标的比喻讲得不错，但代码写法直接把我劝退——建议拆成朴素写法（`cnt++; if (cnt==3) {...}`，初始化用 for 循环），压缩写法放"拓展"。
3. **【P1】课后 4"黑色星期五"难度跳档**：日期+星期推算在本课没有任何示例铺垫（课程里连"每月天数表"都没出现过），需要自行发明"逐月推进星期"的模型。对刚学会蜗牛爬竿的学生跨度过大，我直接 ❌。建议换成同主题（过程模拟）的课内题，或在课件补一节日期模拟示例。
4. **【P2】课后 3"小明的电梯"题面有病句**："往上走，走一层需要6秒，往下走一层需要4秒，。"逗号句号连用，且"每到一站停止5秒"没明说"起始的 0 层不算一站、最后一站也要停 5 秒"——我靠样例 `1 2`→17 反推才确认规则。题面应该自己说清楚，不该让学生猜。
5. **【P2】挑战 1 与挑战 2 的"容易错的地方"都是"最后一步"类错误，但正文 demo 没有把守卫条件单独标红/讲解**：`if (pos < h)` 和四个边界 `x > 1` 都是一闪而过，我两题都栽在同一个模式上。建议正文就强调"模拟题 80% 的错在最后一步"。
