## 至少 3 个必须修改的问题

1. **【P0】课后 5"计算表达式"题面 Markdown 吞掉乘号**：description 里 `3+5*6-4` 被渲染成"3+56-4"、推导"8*6-4"变成"86-4"，题面自相矛盾（一边说"运算数为一位整数"一边出现 56）。我对着题面懵了一分钟，靠样例才活过来。这是题库题面的转义事故，必须修（`*` 需要转义或改用 ×/全角符号）。
2. **【P1】挑战 5 弹球反弹的样例 `10 8 5 1` 只走 1 步，无法暴露"忘记掉头"错误**：我漏写 `dir = -1` 样例照样过，隐藏点才会炸。建议样例改成 `t=2` 或 `t=3`，让"穿墙"当场现形；或在题面强调"反弹后方向改变"。
3. **【P1】`(c-1)%m+1` 环形映射在 12、13 两课出现但始终没有"为什么"的推导**：为什么减 1 再加 1？（因为人从 1 号数、% 结果是 0 基。）我已经第二次"看得懂写不出"了，下次遇到还是会卡。建议在 12 课首次出现处加一句推导。
4. **【P2】课后 3 起始位置是 1 基还是 0 基题面没写**："给出它们的起始位置"不说从 0 还是从 1 数，我第一遍输出 0 基错了，靠样例才改。题面应写明"位置从 1 开始数"。
5. **【P2】挑战 2 的 `cout << (t += x)` 压缩写法**：虽然解释了"拆开写也一样"，但这是我"赋值塞语句"弱点的同款写法，建议 demo 就用朴素两行，压缩写法放注释。
