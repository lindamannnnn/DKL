### 逐页体验（小明的自言自语）
- 故事外星人信 `1101`=13：哦电脑只用 0 和 1，挺神奇，开头没走神。
- 回顾 n%2 / n/=2：这俩我熟（GESP1 拆数字）。
- 什么是进制：十进制满10进1、二进制满2进1、十六进制 0~9+A~F，原来同一数换写法大小不变——懂了。
- 进制操纵符 dec/oct/hex：`hex` 输出小写，题目要大写得自己转，这个坑我先记着。检查点八进制不能有8，对。
- 按权展开 1011=11：`r = r*2 + (s[i]-'0')` 这个滚雪球我会，和我 GESP3-09 拼数一个套路。
- 短除法：13→1101 余数倒着读！我差点顺着读成 1011，幸好红字提醒"从下往上"。检查点都在。
- 转任意进制：除以几就转几进制，余数>9 查密码表，cool。
- 躲开两个坑：n=0 要特判、数大用 long long——这俩我 GESP1 就吃过亏，有共鸣。
- 滚雪球求值 "2A"=42：2→2, 2*16+10=42，对。
- 快速转换 4位一组：1101=D，补零凑4位、去前导零，记口诀。检查点 1101→D 对。
- 两步走换乘：X进制→十进制→Y进制，十进制是换乘大站，好记。
- 二进制加法：1+1=10 写0进1，但 demo 直接 `cout<<a+b` 用 int 加……呃这就是普通加法啊，竖式到底怎么写没展示，我有点懵这页。

### 至少 3 个必须修改的问题
1. **挑战1 demo 只给正解没给"反面教材"**：短除法最关键、也最易错的"余数拼最前面"只在"容易错"里用一句话提"写成 `r=r+...` 会倒序"，demo 只展示正确写法 `r = ... + r`。小明闭卷就是会写成 `r += ...` 把答案整个反掉。建议 demo 旁并排给"错误写法→得到 0010011"对比，强化记忆。证据：挑战1 demo 与"容易错的地方"。
2. **第"二进制加法"卡片 demo 用 int 直接 `a+b`，没展示真正竖式算法**：卡片文字讲"竖式右对齐、有进位传左边"，但示例代码 `cout << a + b` 根本没演示进位变量怎么写，小明看完以为"二进制加法=普通加法"就过了，竖式算法形同虚设。建议补一段"按位异或+进位"或数组模拟竖式的真示例（或明确说"底层就是普通加法，这里只记口诀"）。证据：该卡片 demo。
3. **挑战2 题面限定"长度是4的倍数"，回避了本课刚讲的"补零凑4位"**：卡片"补齐与去零"刚教了位数不是4倍数要左补零、还要去前导零，但挑战2 直接给"4的倍数"把补零练习吃掉，小明在真实任意长度题目上会卡。建议去掉"4的倍数"限制，让他练补零+去前导零。证据：挑战2 题面 vs "补齐与去零"卡片。
