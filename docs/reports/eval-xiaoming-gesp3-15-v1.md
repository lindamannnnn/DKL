## 逐页体验记录

### 页0 标题 + 目标
"数据编码"——名字好无聊。但是目标里说"电脑为什么爱用补码"，补码是啥？算了，往下翻。

### 页1 故事：负数怎么存？
"连减号都没有，负数怎么存"——哎这个有点意思！"百年难题""当一回科学家"，行吧，给你 30 秒。

### 页2 回顾
进制转换，14 课学过，跳过跳过。（其实我只记得短除法大概怎么写，8 位 256 种状态这种细节我没细看。）

### 页3 卡片：符号位
最左边 0 正 1 负。懂了懂了，就一句话的事。"机器数""真值"两个词出现了，解释就一行，我扫了一眼没细看——反正后面肯定还会讲吧？（结果后面再没细讲。）
demo 瞟了一眼，又是转二进制，14 课写过类似的，没细看。

### 页4 检查点：符号位
最高位是 1 → 负数，B！✅ 秒答，这题白送。

### 页5 卡片：原码
符号位 + 绝对值。+5 是 `00000101`，-5 是 `10000101`。懂！"0 有两种写法""原码加法会算错"——哦。为啥算错？没写例子。算了不管，估计不考。

### 页6 检查点：原码找找看
-3 = 符号位 1 + `0000011` = `10000011`，选 A。✅ 这个我会！

### 页7 卡片：反码
负数取反，符号位不动。例子 `10000101` → `11111010`。我大概对了对，嗯没问题。（其实只对了前 3 位，后面扫过去的。）

### 页8 检查点：反码怎么变
符号位不变，A。✅ 太简单了吧，能不能来点有难度的？

### 页9 卡片：补码
补码 = 反码 + 1。哦。"+5 和 -5 的补码加起来正好是 0（进位扔掉）"——是吗？不想验算，信了。
下面那个 demo 循环 `for (int i = 7; i >= 1 && carry; i--)` 什么鬼，for 里面还能写 `&&`？看不懂，跳过。（**这里埋下了雷，挑战全炸了。**）

### 页10 检查点：补码推一推
`11111001` + 1。最后一位加 1……1+1=10，写 0 进 1，变成 `11111010`，选 A。✅ 嘿嘿我在草稿纸上算的，没翻车。

### 页11 卡片：补码的本领
三个超能力，字好多。0 只有一种写法——哦。减法变加法——哦。-128~127——哦。int 最大值 2147483647 原来是这样来的——哦。（四个"哦"，其实一个都没过脑子。）
demo 说 2147483647 + 1 变成负的，"溢出"——哈？还能这样？有点好笑，但也只是看了一眼。

### 页12 检查点：int 最小值
A"补码里 0 只有一种写法"听着最正经，B 和 C 明显搞笑，选 A。✅ **说实话我是排除法选的，不是真懂。**

### 页13 挑战 1：补码转真值
**闭卷三步法**：
1. 闭卷：输入 `11111011` 输出 -5。我想：把 8 位转成十进制……`v = v*2 + (s[i]-'0')` 全套上，算出 251。不对啊样例是 -5。哦要减符号位……那减多少？128？为什么？我乱试了一下没搞出来，烦躁，**直接翻开示例看**——哦原来符号位是 1 就输出 `v - 128`，v 只算后 7 位。照着改出来了。
2. 对答案：主体逻辑是抄的，只有自己把循环下标从 0 改成 1 这一步理解了。
3. 判定：🟡 半独立（看了 1 次示例才写对；核心思路"减 128"不是我自己想的）。
- 备注："真值"这个词题面里突然冒出来，我又翻回页 3 找它啥意思。讨厌这种前面一笔带过、后面直接考的词。

### 页14 挑战 2：负数的三种编码
**闭卷三步法**：
1. 闭卷：要输出原码、反码、补码三行。原码我会，反码取反我也会，补码要"反码 + 1"——又是页 9 那个我跳过的进位循环！我凭感觉写了一个，跑 -5 得到 `11111010`（那是反码！加 1 没生效）。改了一次还是错。**两次没跑通，不想玩了**，直接抄示例。示例里 `for (int t = -n, i = 0; i < 7; i++, t /= 2)` 一行塞那么多东西，看着就烦。
2. 对答案：抄完之后对 -5、-6 手算验证，输出对了。但我清楚这是我抄的，不是我会的。
3. 判定：❌ 未通过（看了示例才"写"出，实质是抄；闭卷两次尝试均失败）。

### 页15 小贴士
口诀两行，挺顺口，扫了一眼。"取反再加 1 得绝对值"——嗯？挑战 1 还能这么做？我怎么没想到。（因为页 9 到挑战 1 我都没真正过脑子。）

### 页16 课后挑战
