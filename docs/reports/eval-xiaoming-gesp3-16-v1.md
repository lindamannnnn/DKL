## 逐页体验记录

## 故事：二进制魔法

"猜奇偶"？这我会！`n % 2 == 1` 嘛。电脑说 `n & 1` 更快？"时钟周期"是什么玩意儿，没讲。算了不管，"施魔法"听着挺酷，继续。

## 回顾

12 是 1100、10 是 1010——进制转换课学过，我大概记得短除法，懒得验算了，先信它。"每一位互不影响，快得像闪电"——行吧行吧。

## 卡片：按位与 &

"两位都是 1 结果才是 1"。竖式：1100 & 1010 = 1000 = 8。我跟着划了一遍，对上了。`n & 1` 判奇偶——哦就是只看最后一位呗，懂了懂了（自以为懂了）。

demo 8 行，瞄了一眼，能跑的样子。`cout << (a & b)` 那堆括号干嘛的？不管。

## 检查点：与一与（闭卷）

6&5，110 和 101，都是 1 才得 1 → 100 = 4，选 A ✅。秒了。

## 卡片：按位或和异或

一次两个符号？|` 有一个 1 就是 1，`^` 是"找不同"。两个竖式我扫了一眼，14 和 6，差不多信了。其实我有点分不清 `|` 和 `^` 的区别——都是"有 1"？不对我再看看……哦 `^` 是"相同就变 0"。行吧。

## 检查点：找不同（闭卷）

1100^1010=0110=6，选 A ✅。（题目都把答案算好了，白送。）

## 卡片：异或消消乐

`a^a=0`、`a^0=a`、顺序随便换。"成对的消掉，落单的露出来"——这个例子挺好玩！demo 数组 8 行，2 3 2 3 5 异或完剩 5。我大概懂了（半懂）。

## 检查点：异或消消乐（闭卷）

`a ^ b ^ a` = ？我想：a^a=0……等等，顺序是 a、b、a，能换吗？它说顺序随便换，那 a^a^b = 0^b = b。选 A ✅。（差点选成 a，还好我又读了一遍"顺序随便换"。）

## 卡片：左移和右移

左移 = 乘 2 的 k 次方，右移 = 除 2 的 k 次方。3<<2=12，好记！这个我喜欢，秒杀乘法。

**最后一行**："还有 `~` 按位取反，`~n = -(n+1)`"——哈？取反怎么出来个负数？`~5` 等于 -6？为啥？没有例子没有图，就一行字。我看了两遍，完全不懂，跳过！（老师，这个能不能跳过？）

## 检查点：左移乘几？（闭卷）

3<<2 = 3×4 = 12，选 A ✅。快！

## 挑战 1：统计 1 的个数

**闭卷尝试**：数二进制里有几个 1。我写：

```cpp
int n; cin >> n;
int cnt = 0;
while (n > 0) {
    if (n & 1) cnt++;
    n = n / 2;   // 忘掉右移怎么写了，用除 2 反正一样
}
cout << cnt << endl;
```

第一遍我忘了让 n 变化（`n = n/2` 那行漏了），死循环，黑框卡死，烦！这什么破电脑。加了之后对了。

**对答案**：示例用 `cnt += n & 1;` 和 `n >>= 1;`。2 处不一样，我的也能对。**判定 🟡**（死循环那次算我自己粗心，`>>=` 是看了示例才记住的写法）。

## 挑战 2：找落单的数

**闭卷尝试**：刚才消消乐刚看过，照思路写：读 n，循环读 x，`ans ^= x`。一次写对！**判定 ✅**（说实话这题和消消乐 demo 太像了，我算半抄半会）。
