## 挑战 1：转成任意进制
"转成任意进制，这有什么难的，短除法嘛。" 我闭卷唰唰写：
```cpp
while (n > 0) { r = r + g[n % d]; n /= d; }
```
跑样例 `255 16`，输出 `FF`……不对，我输出了 `FF`？让我看看……哦这次碰巧 FF 正反一样！换个数 13 转 2 就会输出 `1011` 倒的。对答案才发现：**余数要拼到最前面** `r = g[n % d] + r`。练习要点第 1 条明明写了，我没看。→ **🟡 半独立**（第一次写反，看示例后改对）。

## 挑战 2：二进制转十进制
闭卷写：我记得大概是"乘 2 加一下"：
```cpp
for (char c : s) r = r * 2 + c;
```
跑出来 `1101` 变成几百多，什么鬼？哦——`c` 是字符！`'1'` 是 49！要 `c - '0'`。对答案改完就对了。讲解卡"容易错"第三条说的就是这个，我没看。→ **🟡**。

## 挑战 3：负数的补码
看题面：输入负数输出 8 位补码。行，推导链我大概记得：绝对值→7 位→符号位→取反→加 1。
闭卷写：前两步写出来了（15 课写过类似的）。"加 1"那步……从右边扫？碰到 1 怎么办？我写了三行就乱了，改了两遍越改越错，烦死了。翻开 demo——`for (int i = 7, c = 1; i >= 1 && c; i--)` 一行挤这么多东西，我看了两遍还是没完全理顺那个 `c` 到底是干嘛的。**12 行的示例，这么长谁看得完啊**。最后照着敲了一遍跑通了，但你让我合上书再写一遍，我写不出。→ **❌ 未通过**（核心步骤独立写不出）。

## 挑战 4：统计 1 的个数

## 课后挑战
五道题，看标题全是进制转换。我说好的补码和位运算呢？

1. **八进制转十进制**（20 位）：滚动乘加嘛，我会！`int r = 0; r = r*8 + (c-'0');` 样例 `77777777777777777777` 一跑——输出一个奇怪的负数？！什么破电脑！……冷静想了半天，哦，20 位八进制 int 装不下（挑战 2 讲解卡说过，我没细看）。换 `long long` 才过 → **🟡**。
2. **二进制转换八进制**（100 位）：100 位？字符串分组呗，14 课做过 4 位一组的。我按 3 位一组写……等等，100 不是 3 的倍数，最前面剩 1 位怎么办？14 课的题是"长度刚好是 4 的倍数"，没人教过不齐的情况！我试着自己补零，补错位置，越改越乱。**两次没跑通，我不想做了** → **❌**（看了正确做法才知道要从左边补零，自己独立想不到）。
3. **十六进制转二进制**：每个字符转 4 位拼起来，我写了。样例一对：人家 `123...` 开头是 `1001`，我输出的是 `0001` 开头？不对，我输出的第一位 1 变成 `0001`……啊原来开头的 0 要去掉？题面没写啊！（其实样例里能看出来，但我做题不看那么细。）改了半天还是错，放弃 → **❌**。
4. **8进制、16进制转10进制**：读 N 再循环，判断 `0x` 开头。我写了个 `s[1] == 'x'` 就交……错了，`00` 这个样例 `s[1]` 是 `0` 不是 `x`，要看清楚"0x 开头才是十六进制"。还有字母是小写的！`c - 'a' + 10`，想起大小写差 32 才改对 → **🟡**（改了三次，差点摔键盘）。
5. **小张的进制转换**：挑战 1 的循环版 + 16 进制加 `0X`。我第一版忘加 `0X` 前缀（输出说明那么长谁看啊），加上之后就对了 → **🟡**。

## 至少 3 个必须修改的问题（小明视角，判定更严格）

1. **挑战 4、5 就是 16 课原题，一个字没改**（证据：样例 `13`→`3`、`2 3 2 3 5`→`5` 与 16 课完全相同）。对我这种"做过就懒得再想"的学生，原题 = 跳过，复习效果为零；而小柯也只是"默写"。必须换数字换包装，至少让我不能靠记忆通关。
2. **课后 2、3 隐含两个没教过的技能：组数不整除的补零、去前导零**（证据：14 课挑战 2 题面明确写"长度是 4 的倍数"，本课没有任何页面讲不齐怎么办）。这两题把我直接打退，是"未教先考"。建议在课后挑战前加一页"小技巧：不够一组就在左边补 0；答案开头的 0 要去掉"。
3. **挑战 3 demo 12 行、三条逻辑挤一行**（证据：课件 202、205 行），超过我 10 行上限，是我本课唯一彻底放弃的题。补码加 1 是 15 课就卡的点，练习课应该把它**拆小**（比如先只让输出反码，再只加 1），而不是整段 12 行再砸一遍。
4. **课后题 5/5 全是进制转换，说好的"进制·编码·位运算"三合一复习名不副实**（证据：快照 5 题来源全是"进制转换"）。我 checkpoint 刚复习完补码和位运算，课后一题都用不上，等于白复习。【缺纲 + 候选】建议换掉 2 道：位运算用 `dc314ed7-039b-43f5-b8f3-95bfd4d58525`（找筷子）或 `f94c5696-b78f-4020-8b45-4f06d5ab5249`（2进制中的0和1）；编码方向题库没有真正的补码题（`342c47f7`"字符串的反码"是字符镜像，别被骗），最近似 `35c97828-348a-4c5c-a195-ee7fd8619adc`（二进制折半交换），建议补录补码题。
