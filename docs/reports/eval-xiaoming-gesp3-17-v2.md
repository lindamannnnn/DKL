## 逐页第一反应

- **故事页**：密码特工五道门，行吧，比"我们来复习一下"好听一点。
- **练习要点页**：短除法倒读、查表、补码三步、位运算加括号——四条提醒全是 14/15/16 课踩过的坑，像有人在帮我翻错题本，这页我喜欢。
- **检查点1（进制热身）**：1111 = 8+4+2+1 = 15，选 A。秒了。
- **检查点2（补码热身）**：反码 11111101 + 1 = 11111110，选 A。15 课的"二进制加 1 进位传递"用上了，末位 1 变 0 进 1……等等，11111101 末位是 1，+1 → 11111110。对。
- **检查点3（位运算热身）**：5&3，101 & 011 = 001 = 1，选 A。不过题干又把答案 `001` 写出来了，17 课还这样。
- **挑战1（转成任意进制）**：短除法通用版 + n==0 特判。这就是 14 课那套，`g[n%d]+r` 拼前面。demo 8 行，清爽。
- **挑战2（二进制转十进制）**：滚雪球写法我会！可是 demo 里 `for (char c : s)` 又来了——这是第 5 次见这个写法，还是没人解释。我继续当它不存在，心里换成老式 `for (int i = 0; i < s.size(); i++)`。
- **挑战3（负数的补码）**：思路我懂（15 课学过推导链），但 demo 代码劝退：`for (int t = -n, i = 0; i < 7; i++, t /= 2)` 一个 for 里塞四件事，加 1 那行 `for (int i = 7, c = 1; i >= 1 && c; i--)` 整行挤在一起，我盯了两分钟放弃了，只看懂"遇 0 变 1 停、遇 1 变 0 继续"的文字说明。复习课的 demo 我看不懂，那复习了个啥？
- **挑战4（统计 1 的个数）**：昨天刚学，`cnt += n&1; n >>= 1;`，会。
- **挑战5（找落单的数）**：消消乐，昨天刚学，会。
- **小贴士**：两把钥匙总结得不错，抄进我的小本本了。

## 至少 3 个必须修改的问题

1. **范围 for 第 5 次无解释出现**（P1）：挑战 2 demo 又用 `for (char c : s)`。从 09 课到 17 课共 5 次出现零解释，我已养成"看到就当不存在"的坏习惯，考试时真题出现只能跳过。建议在第一次出现处加一句话解释，或统一改用老式 for。
2. **挑战 3 demo 压缩写法劝退**（P1）：`for (int t=-n, i=0; i<7; i++, t/=2)` 和加 1 那行多子句 for，复习课的学生读不懂 demo 就等于没复习到。建议拆成一行一步。
3. **课后 3 考恺撒公式但复习链断裂**（P1）："本课练习要点"只列了 14~16 课内容，恺撒移位是 06 课（10 课前）教过且当时就没学会，本课毫无铺垫突然出现在课后题。建议在要点页加一行"字符移位：`±k` 后记得 `%26` 绕回"。
4. **checkpoint 题干仍泄露答案**（P2）：cp3"得 `001`，那么 `5 & 3` = ？"——同 16 课的问题，练习课更该真测。
5. **课后 2 的 `0x` 约定课内没讲过**（P2）：题面自己能读懂，但"0x 开头表示十六进制"是值得讲的常识，14 课没提。
