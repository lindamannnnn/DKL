- 故事密码特工五道门：翻译进制/破译电文/还原负数/数信号1/找落单特工，正好对应14~16，带感没走神。
- 练习要点：把短除法、符号位、原反补、位运算优先级又列一遍，我基本都记得。
- 检查点 进制热身 1111=15 / 补码热身 -2→11111110 / 位运算热身 5&3=1：全是14~16 老题，闭眼过。

- 挑战5 清零某位：`n & ~(1<<k)`，16 课招式5，一眼看懂。

### 至少 3 个必须修改的问题
1. **课后题 3（夏令营小旗手 818a0e2e）题面缺映射规则，表述不清**：DB description 仅"长度不超过20的大写字母串→对应的学生编号"，既没说 A/B/C… 怎么变成数字，也没给"ABCD→266"的算法，小明完全无法从描述推出。建议补全规则（如"把字母串当作 26 进制数，A=1…转出"或实际规则）。证据：快照 problems-gesp3-17.md 第 3 条 ⚠️。
2. **课后题 1（十六进制转二进制 86307caf）"不超过 100 位"超 int 且首组前导零易错，但课件没演示**：每 hex 位要展开成 4 位二进制，最左一组必须去前导零、其余组必须补满 4 位，小明闭卷把首组也写成 4 位多出前导零。建议 demo 明示"首组去前导零、其余组固定 4 位"的拼接写法。证据：题1 description "不超过100位" vs 本课挑战/小抄无此示例。
3. **练习课课后题偏离三大核心，且混进规则隐蔽的题**：本课复习"进制/编码/位运算"，但 5 题里题2 是恺撒（属 GESP3-06）、题3 规则不明、题4 是数字→字母解码，真正针对"负数三码推导""位运算改位"的题反而不够（挑战3/5 讲了的没进课后）。建议在课后替换 1~2 道为"给负数求三码"或"把某位翻转/置1"的针对性题。证据：本课练习要点 vs 5 道课后题主题。
