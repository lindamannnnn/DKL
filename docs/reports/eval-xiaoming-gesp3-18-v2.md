## 逐页第一反应

- **故事页**：五座闯关塔，又是这套，行吧。
- **练习要点页**：12 个知识点一口气列出来，看得有点晕，但每条都是一句话口诀，大部分能接上。可是"连续性元素：相同就 `cur++`，不同就 `cur = 0`"——等等，05 课老师说过：数**相同段**时断掉要 `cur = 1`（新的一段从 1 开始），只有数"连续 1"这种"可能一个都没有"的才从 0 起。这里一刀切写 `cur = 0`，我要是背了这句去做"最长相同数字段"就错了。口诀写错了喂！
- **检查点1**：`int a[5] = {1,2,3};` 的 `a[4]`？01 课学过：初始化没写满的自动补 0，选 B。这次没抢答错，嘿嘿。
- **检查点2**：`strlen("GESP")` = 4，选 A。06 课 strlen 数旗子前的货物，5 是 sizeof 的事。
- **检查点3**：8 位补码 11111111？取反加 1：00000000+1……不对，求真值：减 1 得 11111110，取反（符号位不动）得 10000001 = -1，选 B。15 课的口诀用上了。
- **检查点4**：9^5，1001 ^ 0101 = 1100 = 12，选 A。手算稳的。
- **挑战1**：计数桶+打擂台，03 课老本行。`>` 不用 `>=`、从小到大扫，并列留小号——复习到了。
- **挑战2**：`for (int i = 0; s[i]; i++)` 用 `s[i]` 当循环条件——`'\0'` 是 0 就停，简洁，看懂了（06 课的旗子知识）。
- **挑战3**：find+replace 替换敏感词，`p = s.find(t, p + t.size())` 跳过刚换的——08 课练过。但 `s.replace(p, t.size(), t.size(), '*')` 四个参数的 replace 第一次见！以前只学过三参数版本（位置、个数、新串）。demo 里没多解释，靠讲解才知道"删几个、放几个、放什么"。
- **挑战4**：进制+数 1+判 2 的幂三合一。`n & (n-1) == 0` 判 2 的幂——16 课小抄第 8 招，当时只认脸，这里给了"二进制只有一个 1"的解释，终于懂了一点！三个 `for (int t = n; t; ...)` 用副本 t 拆数字，好习惯（以前把原变量拆没过的坑）。
- **挑战5**：删 0+逆序+统计三合一大杂烩。`if (x)` 过滤、`b[++m]` 装柜、`if (i < m) cout << " "` 前导空格技巧——都是旧招拼起来，能看懂。
- **小贴士**：四条口诀不错，但连续段口诀又写"不同清零"……和要点页一样的毛病，05 课的相同段明明是"不同归 1"。

## 至少 3 个必须修改的问题

1. **连续段口诀写错/一刀切**（P1）：要点页和小贴士都写"相同就 `cur++`，不同就 `cur = 0`"。05 课明确区分过：数相同段断掉归 **1**（新段从 1 起），数"连续 1"才归 0。按这句口诀做"最长相同段"必错。建议改成"相同加一；不同：数连续 1 归 0，数相同段归 1"。
2. **课后 2 与课内挑战 1 规则相反且无提示**（P1）：挑战 1 刚练完"并列取最小"，课后 2 立刻考"并列取 ASCII 最大"，唯一提示在题面"注意"段——正好是我不爱读的部分。这题用来练读题可以，但建议在课后题列表处加一句"小心，这题并列规则和挑战 1 相反"。
3. **replace 四参数版本首次出现无铺垫**（P2）：07 课只教过 `replace(起点, 个数, "新串")`，挑战 3 直接用 `replace(p, n, n, '*')` 填字符版本，只有讲解里一句话。建议补一句"这是 replace 的另一种用法：不换新串，改填 n 个相同字符"。
4. **课后题覆盖面与"复习 12 个知识点"不符**（P2）：5 道课后题没有任何一道位运算或原反补编码题，16 课刚学的位运算只有挑战 4 里蹭了一下。刚学的新知识最需要练，建议换一道位运算课后题进来。
