# 小柯（三年级优秀生）GESP1 18 课学习评估 v2

## 评估说明

- **评估人**：小柯，9 岁，小学三年级，编程零基础，只会 26 个字母但读不懂 `cout`/`int`，好奇心强但耐心只有 5 分钟。
- **学习方式**：严格按 01→18 顺序逐课学习，每节课都带着之前学过的知识。
- **评估标准**：不是"能不能把示例代码复制跑通"，而是"小柯能不能真正理解为什么这样写"。
- **重要假设**：小柯不会主动查资料或问老师；遇到报错会慌；看到 15 字以上的长句容易走神。

## 逐课理解率

| 课号 | 标题 | 理解率 | 关键问题 |
|------|------|--------|----------|
| 01 | 走进 C++ | 85% | 程序骨架里太多"咒语"：`#include`、`using namespace std;`、`return 0;`、`endl` 都只能照抄，不懂为什么。`=` 不是数学里的等于，这个转弯有点晕。课程太长（416 行），5 分钟后容易走神。 |
| 02 | 整数运算 | 88% | `%` 取余能听懂是"除法剩下的"。拆数字的 `%10` 和 `/10` 能跟着做，但独立写容易搞反顺序。口诀用了英文单词 **slash / percent**，小柯不认识，口诀白背。 |
| 03 | 小数运算 | 82% | `double` 盒子好懂，但 `fixed` + `setprecision` + `#include <iomanip>` 三样东西要一起记，容易漏一个。`(double)` 强制转换像"穿衣服"，但不太明白为什么 `7/2` 和 `(double)7/2` 结果不一样。 |
| 04 | 练习课-计算小达人 | 86% | 没有新概念，主要是复习。但"算平均分必须用 `total / 3.0`"这个坑前脚刚学后脚就忘，整数除法吃小数还是容易踩。 |
| 05 | 分支入门 | 84% | `if` 比喻成门很好懂。但 `==` 和 `=` 长得太像，小柯独立写时大概率写错。`bool` 输出 `1` 和 `0` 有点奇怪，6 个关系运算符一起出现有点多。 |
| 06 | 双路分支 | 86% | `if-else` 二选一好懂。嵌套 `if` 看到三层大括号会晕，虽然课件说"不用深追"，但自己写时括号配对容易错。 |
| 07 | 多路分支 | 83% | `if-else if-else` 排队上车能理解，但"顺序很重要"的原因（高分被低分截胡）要反应一下。`n % 3 == 0 && n % 5 == 0` 里运算符优先级没人讲，只能硬背格式。 |
| 08 | 练习课-分支大冒险 | 80% | **检查点 2 答案标错了**：题目问"a 大于 0 并且 b 大于 0"，正确答案明明是 A（`&&`），但课件标的是 B（`||`）。小柯会懵。"截胡"这个词太网络，不一定懂。 |
| 09 | 字符类型与 switch | 78% | 新概念爆炸：`char`、单引号 vs 双引号、字符范围、`+32/-32`、ASCII 编号、`switch`、`case`、`break`、`default`、`穿透`。单引号和双引号容易混。`switch` 的语法结构跟 `if` 完全不同，死记为主。 |
| 10 | for 循环 | 80% | `for` 括号里三个部分用分号隔开，格式复杂。`i++` 能记住是加 1。最大的坎是 `sum = sum + i`，因为它看起来不像数学等式，需要反复看表格才明白"先算右边再存回左边"。 |
| 11 | 循环控制 | 82% | `break` 和 `continue` 的跑步比喻有用，但两个都是英文单词，容易记混。`for (int i = 1; ; i++)` 中间空着表示"一直循环"太反直觉，虽然配合 `break` 能用，但心里没底。 |
| 12 | 练习课-循环闯关 | 84% | 纯复习，巩固了 for、break、continue。空条件的 for 循环 + break 还是不够稳。 |
| 13 | 求和计数 | 76% | 一次塞进来太多算法套路：求和、求平均、计数、最大值、最小值。`maxNum` 要拿第一个输入当"老大"，这个状态跟踪对 9 岁孩子有点抽象。求因子和、同时求最大最小值两道题独立做会卡。提示里出现 `-2147483647` 这种大数会吓到。 |
| 14 | while 循环 | 82% | `while` 比 `for` 好懂一点，因为条件就摆在前面。但"先读一个数，不是 0 再进循环，循环里再读下一个"这个哨兵输入模式，自己写很容易把 `cin` 的位置放错。 |
| 15 | 短除法 | 74% | 一节课变出太多花样：用 `t--` 循环 n 次、数位求和、找某个数字、数位乘积、统计出现次数。每道题都要同时用 `while`、`%10`、`/10`、累加/累乘/计数，认知负荷很大。`product = 1` 这个初始值违反直觉（为什么不是 0？）。 |
| 16 | 练习课-数字拆解与统计 | 78% | 复习课，但没有新知识。如果 13-15 课没真正消化，这节只是重复同样的卡壳点。 |
| 17 | C 风格输入输出 | 72% | 学了 16 节课 `cin/cout`，突然换成 `scanf/printf`，整个人要切换系统。`&` 符号被说成"地址小箭头"，但"地址"是什么根本不懂，只能死记"变量前面必须加 `&`".`%lf` 输入、`%f` 输出这对冤家特别容易写反。 |
| 18 | 练习课-GESP1 综合大闯关 | 76% | 没有新概念，但要在 `cin/cout` 和 `scanf/printf` 之间来回切换，还要综合运用分支、循环、拆位。如果前面有漏洞，这里会集中暴露。 |

## 最重要的修改建议

1. **把"照抄的咒语"拆开教，每行都要说人话**
   第 01 课程序骨架里 `#include`、`using namespace std;`、`return 0;`、`endl` 全让"照抄"，小柯会觉得自己在背魔法咒语。建议用"工具箱→大门→小喇叭→再见"的故事链，把每一行为什么存在讲清楚，而不是只给比喻。

2. **砍掉英文口诀，改用中文口诀或图画**
   第 02 课用 "slash 砍掉尾巴，percent 留下尾巴"，小柯不认识这两个单词。改成"除号砍尾巴，取余留尾巴"或者直接配一张小尾巴被砍掉/留下的卡通图，效果更好。

3. **第 08 课检查点 2 答案必须修正**
   "a 大于 0 并且 b 大于 0" 的正确写法是 `a > 0 && b > 0`（选项 A），课件标成了 B（`||`）。这个错误会直接教错孩子，建议立即修正并增加 "&& 是并且，|| 是或者" 的对照练习。

4. **把算法套路课（13、15）拆成更小的步子，先练一个再练下一个**
   第 13 课一次教求和、平均、计数、最大、最小；第 15 课一次教数位求和、找数字、数位乘积、统计次数。建议把每个套路变成单独一课或单独一关，并先用动画/表格展示变量是怎么变的，再让写代码。

5. **第 17 课不要和 `cin/cout` 混教，或明确告诉孩子"二选一即可"**
   对 9 岁孩子来说，同时维护两套输入输出系统负担太重，`&`、 `%lf`/`%f` 这些抽象规则很容易写错。如果 GESP 考试确实要求，建议把 C 风格 IO 单独做成一个"考试技巧"小专题，并给出对照速查表，而不是在第 17 课突然切换体系。
