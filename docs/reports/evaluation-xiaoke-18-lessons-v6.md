## 最重要的修改建议（下一轮）

1. **把平均理解率推过 90% 的关键仍在第 17 课**
   对 9 岁孩子，同时维护 `cin/cout` 和 `scanf/printf` 两套 IO 系统负担最重。建议把第 17 课进一步"减法"：只保留最常用的 `%d`、`%lf`/`%f`、`%02d`、`%.2f`，把 `%c`、多占位符、对齐等移到拓展包。

2. **第 09 课大小写转换去掉 ASCII 编号概念**
   "电脑给每个字符编了号"对三年级学生仍是抽象概念。建议直接给出口诀"大写转小写加 32"，用大量填空练习巩固，而不是解释编号。

3. **第 14 课哨兵输入模式增加可视化模板**
   "先读一个数，再进循环，循环里再读下一个"仍是常见错误点。建议用流程图或动画展示两个 `cin` 的位置，并提供"填空式"模板让学生先套再改。

4. **第 11 课质数判断拆成两关**
   虽然 `break`/`continue` 的中文动作名已经帮我记住了，但"普通版质数判断"和"加速版 `i*i<=n`"仍塞在同一关。建议拆成两关：第一关先会写普通版，第二关再讲为什么可以少试一些数。

5. **综合挑战题增加步骤提示卡**
   第 18 课终极挑战若前面某课薄弱会连锁卡壳。建议给每道综合题提供"步骤提示卡"，让学生一步一步完成，而不是直接看完整代码。

## 小柯的逐课学习日记

> 下面是我（小柯）逐课学习时的真实感受，全部用第一人称记录。

### 第 01 课：走进 C++

**已学知识帮我理解的地方**
- 我什么都没学过，但这节课从计算机小故事开始，像听故事一样，不无聊。
- 键盘符号表格很有用，`#` 在数字 3 上面，我按 Shift+3 找到了！
- "程序骨架五件套"像搭积木，我跟着写就能跑起来。

**最困惑的地方**
- `using namespace std;` 老师说是"标准工具箱"，但我还是不太懂它到底在干嘛，只能先照抄。
- `system("pause")` 是拓展技巧，为什么要加它？加了黑框框就不闪了吗？

**知识跳跃点**
- 第 0 关还在讲故事，第 1 关突然就到程序骨架了，虽然不算太跳跃，但 `using namespace std;` 没有自然过渡。

**最喜欢的部分**
- 让电脑说出"Hello, World!"的时候，我觉得自己也变成程序员了！
- 通关奖励有徽章，我想继续拿下一个。

**小学生一句话总结**
- "我能让电脑说话了，但有几句咒语我还不知道是什么意思。"

### 第 02 课：整数运算

**已学知识帮我理解的地方**
- 因为第 1 课学过 `int` 变量，所以看到 `int a = 12;` 不陌生。
- `cout << a + b` 和我学过的 `cout << "你好"` 很像，只是把字符串换成了算式。
- `%` 取余和我数学课学的余数一样！

**最困惑的地方**
- `标识符` 这个词第一次出现，听起来很高级，其实就是"变量名的规矩"，为什么不直接说变量名规矩呢？
- `long long` 后面的 `LL` 为什么要加？老师说是"告诉电脑这是超大数字"，但我还是会忘记。
- 最小公倍数那题用了 `while` 和 `?:`，`while` 我还没学过呢！

**知识跳跃点**
- 最小公倍数的例题里突然用了 `while` 循环和三目运算符，我才刚学分支，这里有点跳。

**最喜欢的部分**
- 拆数字像削铅笔，"先取个位再砍个位"这个口诀我记住了！
- 时间换算用大单位除、小单位余，和数学课有点像。

**小学生一句话总结**
- "我学会了拆数字，但超大数字的 LL 老是忘。"

### 第 03 课：小数运算

**已学知识帮我理解的地方**
- 上一课刚学过整数除法会吃掉小数，所以这节课说 `int` 装不下小数我能理解。
- `double pi = 3.14;` 和 `int` 写法一样，只是把类型名换了。
- 保留小数用 `fixed << setprecision(2)`，像一句咒语，多念几遍能记住。

**最困惑的地方**
- `(double)7 / 2` 为什么要给 7 穿外套？不能直接写 `7.0 / 2` 吗？
- 四舍六入五凑双：数学课明明是四舍五入，为什么 `2.35` 不是 `2.3` 而是 `2.4`？
- 隐式转换那里说 "两个整数先运算再放进 double 还是整数"，我要反应一下。

**知识跳跃点**
- 四舍六入五凑双的规则突然出现，没有和数学课的四舍五入做对比解释。

**最喜欢的部分**
- 计算圆的面积很实际，像在做数学题。
- 分转元的例子让我知道小数真的有用。

**小学生一句话总结**
- "我会保留小数了，但四舍六入五凑双和数学课不一样，有点懵。"

### 第 05 课：分支入门

**已学知识帮我理解的地方**
- `if` 像安检门，这个比喻很好懂。
- 关系运算符 `>` `<` `==` 和数学课比大小一样。
- `n % 2 == 0` 判断奇偶，我上节课学过 `%`，所以能懂。

**最困惑的地方**
- `bool` 类型第一次见，`true` 变成 1，`false` 变成 0，为什么不能直接说"对"和"错"？
- `==` 和 `=` 我明明知道不一样，但手还是会写错。

**知识跳跃点**
- `bool` 类型出现得有点突然，虽然开关比喻好懂，但为什么要单独学这个类型？

**最喜欢的部分**
- 判断成绩及格不及格，和我考试成绩有关，很亲切。

**小学生一句话总结**
- "if 就像门，条件对就开门，但 == 和 = 我还要多练。"

### 第 06 课：双路分支

**已学知识帮我理解的地方**
- `if-else` 二选一和上一课一脉相承。
- 嵌套 if 像俄罗斯套娃，这个比喻形象。
- `&&` 像"并且"，生活中经常说"并且"，好理解。

**最困惑的地方**
- 嵌套三层的大括号我要数半天，怕配错。
- 三目运算符 `?:` 太短了，像密码，我暂时只能照着抄。

**知识跳跃点**
- 三目运算符对于三年级学生来说有点高级，建议单独放一关。

**最喜欢的部分**
- 判断能否参加运动会，两个条件一起判断，像在玩条件游戏。

**小学生一句话总结**
- "if 里面还能写 if，但三目运算符像谜语。"

### 第 07 课：多路分支

**已学知识帮我理解的地方**
- `if-else if-else` 像排队上车，只会执行一个，这个比喻好。
- `&&` `||` `!` 上一课学过一部分，这节课补全了。

**最困惑的地方**
- 为什么条件要从高到低排？如果我先写 `>= 60` 再写 `>= 90`，会怎么样？
- 优先级表格：`!` 最先，然后 `&&`，最后 `||`，但谁比谁优先我没记住，只能加小括号。

**知识跳跃点**
- 优先级表格太抽象，直接给例子更好。

**最喜欢的部分**
- 出租车分段计费和生活相关，像妈妈在算打车费。

**小学生一句话总结**
- "多分支像排队，但顺序和优先级我还要慢慢理解。"

### 第 09 课：字符类型与 switch

**已学知识帮我理解的地方**
- `char` 装一个字符，和 `int` 装数字类似，只是类型不同。
- 单引号双引号的对比表格清楚，我记住了"一个字符用单引"。
- 字符可以比大小，因为 `'A'` 到 `'Z'` 是连着的。

**最困惑的地方**
- ASCII 编号是什么？电脑为什么要给字符编号？这个概念对三年级学生好抽象。
- 大写转小写加 32，小写转大写减 32，我能背口诀，但不知道为什么是 32。
- `switch` 的语法新东西很多：`case`、`break`、`default`，一开始会忘写 `break`。

**知识跳跃点**
- ASCII 编号概念出现得太早，建议直接给口诀。
- `switch` 的 `break` 穿透现象容易让人困惑。

**最喜欢的部分**
- 密码锁的例子好玩，输入 A/B/C 门就开。

**小学生一句话总结**
- "字符和 switch 新东西很多，单引号我记住了，但编号和 32 还搞不懂。"

### 第 10 课：for 循环

**已学知识帮我理解的地方**
- 之前已经会 `if` 和基本运算，现在用循环可以重复做同样的事。
- `i++` 就是让 i 加 1，和 `i = i + 1` 一样。
- 累加像往桶里丢石头，这个比喻帮我记住了 `sum = 0` 和 `sum = sum + i`。

**最困惑的地方**
- `for` 有三个部分，中间用分号隔开，我第一次打的时候分号位置老错。
- `++i` 和 `i++` 的区别，老师说我初学不用太纠结，但考试遇到会慌。

**知识跳跃点**
- `++i` 和 `i++` 的区别可以提前说明"初学先跳过"。

**最喜欢的部分**
- 用循环算 1+2+...+100，比我自己加快多了！

**小学生一句话总结**
- "for 循环像小机器人，但 ++i 和 i++ 我有点绕。"

### 第 11 课：循环控制

**最困惑的地方**

**知识跳跃点**
- 普通质数判断和加速版放在同一关，建议拆成两关。

**最喜欢的部分**
- 两个遥控器像游戏里的技能，break 是大招，continue 是闪避。

**小学生一句话总结**
- "break 和 continue 我记住了，但质数加速版一下塞太多。"

**知识跳跃点**

**最喜欢的部分**

### 第 14 课：while 循环

**已学知识帮我理解的地方**
- `while` 比 `for` 好懂，就是"条件成立就一直做"。
- `do-while` 至少做一次，这个特点和 `while` 不一样，但能记住。

**最困惑的地方**
- 哨兵输入模式：先 `cin` 一个数，再进循环，循环里再 `cin`。我把 `cin` 位置放错过。
- `do-while` 末尾有个分号 `;`，我总是忘记。

**知识跳跃点**
- 哨兵输入没有流程图或动画，光看书容易把两个 `cin` 搞混。

**最喜欢的部分**
