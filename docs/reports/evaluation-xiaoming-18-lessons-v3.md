# 小明（五年级中等生）GESP1 18 课学习评估 v3

## 评估说明

- **评估人视角**：严格扮演 `docs/agents/xiaoming-persona.md` 中的 11 岁五年级小学生小明。
- **学习顺序**：按 01 → 18 顺序逐课学习，新知识必须建立在前面课程已掌握的基础上。
- **评估重点**：每节课的「新授课」部分与「课后挑战」部分；对特别长的课程只看核心新知和综合练习。
- **理解率定义**：0–100%，表示小明**真正理解**这节课核心内容的比例，不是「看完」或「复制运行通过」。
- **通过标准**：70% 表示大部分核心概念懂了，但细节或综合题可能卡壳。

## 仍需关注的问题

1. **第 02 课：拆数字的多步骤顺序**
   `%10` 和 `/10` 连续使用时，独立写仍容易搞反。建议增加“先取个位、再去个位”的拖拽/填空练习。

2. **第 09 课：字符与 switch 仍偏密**
   虽然已经拆关，但单引号/双引号、字符 vs 数字、`switch`/`break`/`default` 对小明仍是多个新坑。

3. **第 11 课：`break`/`continue` 英文术语**
   两个单词容易记混。建议给中文动作标签，如“break = 直接退出，continue = 跳过本次”。

4. **第 17 课：两套 IO 系统**
   即使拆关，同时维护 `cin/cout` 和 `scanf/printf` 仍是负担。建议明确“比赛前再集中练 scanf/printf”。

5. **综合挑战题仍靠模仿**
   第 18 课终极挑战需要前面知识真正内化，目前仍偏模仿。
