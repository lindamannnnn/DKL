## 三、典型错题（共 9 道，全部列出）

### 1. 标识符命名规则（202303/522 第 19 题）
- **题目内容**：在 C++ 语言中，标识符中可以有数字，但不能以数字开头。
- **我的答案**：正确（A）
- **正确答案**：错误（B）
- **知识点**：标识符命名规则
- **错误原因**：按 C++ 语法该陈述为真，但标准答案标为错误。疑为答案键或题目文本在导入过程中存在偏差，已按标准答案记录。

### 2. 字符常量与 ASCII 运算（202303/1690 第 20 题）
- **题目内容**：C++ 表达式 `('1' + '1')` 的值为 `'2'`。
- **我的答案**：错（B）
- **正确答案**：对（A）
- **知识点**：字符常量与 ASCII 运算
- **错误原因**：`'1'` 的 ASCII 码为 49，相加结果为 98，对应字符 `'b'` 而非 `'2'`。我按 ASCII 规则判断为错，但标准答案为对。该题标准答案与 C++ 实际语义不一致，已按标准答案记录。

### 3. `switch` 分支与 `break` 穿透（202312/1694 第 13 题）
- **题目内容**：输入 `'C'` 时，下列 `switch` 代码的输出是？
  ```cpp
  case 'A': cout << "1"; break;
  case 'B': cout << "3";
  case 'C': cout << "3";
  case 'D': cout << "5"; break;
  ```
- **我的答案**：以上都不对（D）
- **正确答案**：`3 5`（B）
- **知识点**：`switch` 分支与 `break` 穿透
- **错误原因**：代码从 `case 'C'` 进入后输出 `"3"`，因无 `break` 继续执行 `case 'D'` 输出 `"5"`，实际连续输出 `"35"`。我据此认为选项 B（带空格）不对而选了 D。若标准答案为 B，可能是题目选项在展示时省略了空格，或官方预期答案为 B。

### 4. 变量声明与数据类型（202409/2221 第 7 题）
- **题目内容**：代码段 `cin >> a; cin >> b; cout << a + b;` 先后输入 5 和 2，输出是？
- **我的答案**：将输出整数 7（A）
- **正确答案**：执行结果不确定，因为代码段没有显示 a 和 b 的数据类型（D）
- **知识点**：变量声明与数据类型
- **错误原因**：我默认了 `a`、`b` 为 `int` 型并计算了 7，忽略了题目只给出代码片段、未声明变量类型，因此输出结果不确定。应养成“先看变量是否声明”的习惯。

### 5. 标识符命名规则（202409/2221 第 22 题）
- **题目内容**：在 C++ 代码中，不可以将变量命名为 `five-star`，因为变量名中不可以出现 `-`（减号）符号。
- **我的答案**：对（A）
- **正确答案**：错（B）
- **知识点**：标识符命名规则
- **错误原因**：按 C++ 语法，变量名确实不能包含 `-`，该陈述为真。标准答案标为错，疑为答案键偏差，已按标准答案记录。

### 6. 输入输出与类型转换（202412/2216 第 18 题）
- **题目内容**：X 是 C++ 语言的基本类型变量，则语句 `cin >> X`，`cout << X` 能接收键盘输入并原样输出。
- **我的答案**：对（A）
- **正确答案**：错（B）
- **知识点**：输入输出与类型转换
- **错误原因**：没有考虑到当输入与变量类型不匹配时（例如向 `int` 输入 `2.5`），`cout` 会按变量类型输出，不能做到“原样输出”。

### 7. `printf` 格式化输出（202503/2354 第 10 题）
- **题目内容**：`printf("{N}*{N}={%d*%d}", N, N, N * N);` 的输出是？
- **我的答案**：`10*10={10*10}`（A）
- **正确答案**：`{N}*{N}={10*10}`（D）
- **知识点**：`printf` 格式化输出
- **错误原因**：误把格式串中的两个 `%d` 和第三个参数 `N*N` 对应起来。实际上格式串里只有 2 个 `%d`，第三个参数 `N*N` 未被使用，`{N}` 和 `*` 都是普通字符，因此输出保持 `{N}*{N}={10*10}`。

### 8. `for` 循环执行过程（202506/2651 第 19 题）
- **题目内容**：将 `for (int i = 0; i < 100; i = i + 1)` 改为 `for (int i = 0; i < 200; i += i + 1)` 后，输出是否与原来相同？
- **我的答案**：对（A）
- **正确答案**：错（B）
- **知识点**：`for` 循环执行过程
- **错误原因**：没有仔细推演修改后的递增序列。`i += i + 1` 每次把 `i` 变为 `2*i + 1`，循环只会执行约 8 次，输出不再是 100。

### 9. 运算符与注释（202509/2871 第 4 题）
- **题目内容**：
  ```cpp
  a = 13;
  b = 5;
  cout << a / b << a %// b << a % b;
  ```
- **我的答案**：以上都不准确（D）
- **正确答案**：20（C）
- **知识点**：运算符与注释
- **错误原因**：按当前提取出的代码，`%//` 会触发单行注释，导致编译错误，因此我选了 D。标准答案为 C，可能是题目原文或提取过程中代码被改动。该题提醒我：遇到 `%` 与 `/` 连续出现时要特别小心区分注释与运算符。

## 四、结论与建议

1. **整体表现**：在 11 套 GESP 一级真题、268 道可作答题目中，仅错 9 题，错误率 3.36%，说明对 GESP 一级 C++ 大纲知识掌握较好。
2. **主要薄弱点**：
   - **标识符规则**出现 2 次错误（部分与标准答案存疑有关），说明对“哪些字符可出现在标识符中、能否以数字开头”仍需巩固。
   - **`printf` 格式控制字符串**是实锤薄弱点，容易数错格式说明符个数或误解普通字符。
   - **`for` 循环变量更新表达式**一旦改变，需要逐步推演，不能凭直觉认为循环次数不变。
   - **代码片段完整性**（变量是否声明、输入输出是否原样）容易被忽略，做题时应先检查代码是否完整。
3. **后续建议**：
   - 针对 `printf`/`scanf` 格式、循环执行过程、标识符规则做专题练习。
   - 对代码阅读题，先确认变量声明、数据类型、循环边界，再计算输出。
   - 对于标准答案与 C++ 语义明显冲突的题目，做好标记，后续结合官方真题或教师讲解进一步核对。
