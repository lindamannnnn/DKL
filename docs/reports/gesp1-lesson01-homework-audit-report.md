# GESP1 课程 01 课后练习审核报告

## 一、审核背景

在将 GESP1 全部课程课后作业改造为 OJ 题引用后，需要验证课程 01（走进 C++）的课后练习是否与当课知识点匹配、是否存在超纲题目。为此启动了两个智能体：

- **智能体 A（学生视角）**：模拟 9 岁、第一次学习 C++ 的小学生，逐页学习课程 01，并从学生角度判断 5 道课后题能否独立完成。
- **智能体 B（教师视角）**：以 GESP1 课程审核教师的身份，依据课程 01 的知识点范围，对每道题进行专业审核。

审核前已将开发环境默认用户 `dev-user-id` 在课程 01 上的学习进度与相关提交记录重置，确保评估对象处于"未上过课"状态。

---

## 二、课程 01 知识点范围

根据课件 `server/courses/gesp1/01-走进C++.md`，本课教学目标与应掌握内容如下：

| 知识点 | 掌握要求 |
|---|---|
| 程序骨架五件套 | `#include <bits/stdc++.h>`、`using namespace std;`、`int main()`、`cout`、`return 0;` |
| `cout` 输出 | 输出字符串与整数，使用 `endl` 换行 |
| `int` 变量 | 定义整数变量、初始化、赋值 |
| `cin` 输入 | 从键盘读取整数 |
| 四则运算 | `+ - * /`，其中 `/` 为**整数除法**（小数部分直接丢弃） |

**明确未涉及、属于超纲的内容**：
- 循环（`while` / `for`）
- 分支（`if` / `else`）
- 小数 / 浮点数及格式化输出
- 取模运算 `%`
- 数字拆位
- `long long` 等大整数类型

## 四、逐题审核结果

### 第 1 题：求长方形的周长和面积

| 审核维度 | 结论 |
|---|---|
| 匹配度 | 高 |
| 是否超纲 | 否 |
| 难度评价 | 适中 |
| 对 9 岁学生是否合适 | 合适 |
| 标签准确性 | 不准确，标注了"分支"但本题完全不需要分支 |
| 测试用例 | 合理，`987 * 120 = 118440` 在 `int` 范围内 |

**说明**：仅需 `cin` 读入两个 `int`，用 `+ *` 计算周长和面积，`cout` 输出两行。与课内"挑战 2：输入两个数求和"高度相似，数学情境熟悉。

**建议**：删除错误标签"分支"，改为 `基础/输入输出` 或 `基础/四则运算`。

---

### 第 2 题：A+B 输入输出练习 I

| 审核维度 | 结论 |
|---|---|
| 匹配度 | 低 |
| 是否超纲 | 是，需要循环 / EOF 处理 |
| 难度评价 | 过难 |
| 对 9 岁学生是否合适 | 不合适 |
| 标签准确性 | 部分准确，"循环结构"标签提示了所需知识，但放在第 1 课本身不合理 |
| 测试用例 | 不合理，仅一个包含 99 组数据的巨大测试点，初学者难以调试 |

**说明**：题意要求持续输入多对数字并依次输出，必须使用 `while(cin >> a >> b)` 或 `while(scanf(...) != EOF)`，课程 01 完全未教循环。

**建议**：**替换**。改为单次输入两个整数并输出其和，与课内"挑战 2"保持一致。

---

### 第 3 题：已知正方形的周长求面积

| 审核维度 | 结论 |
|---|---|
| 匹配度 | 低 |
| 是否超纲 | 是，需要浮点数及保留 2 位小数 |
| 难度评价 | 偏难 |
| 对 9 岁学生是否合适 | 不合适 |
| 标签准确性 | 不准确，标注"基础/分支"，真正考点（小数运算 / 格式化）未标出 |
| 测试用例 | 有缺陷，仅 1 个测试点 |

**说明**：输入整数周长 25，要求输出面积 39.06。课程 01 只学了 `int` 和整数除法，`25 / 4 = 6`，无法得到 `6.25` 和 `39.06`；需要 `double`、`fixed`、`setprecision(2)` 等后续知识。

**建议**：**替换或修改**。可改为"已知正方形周长（保证是 4 的倍数），求边长"，完全使用整数除法。

---

### 第 4 题：输入一个三位数，把个位和百位对调后输出

| 审核维度 | 结论 |
|---|---|
| 匹配度 | 低 |
| 是否超纲 | 是，需要取模 `%` 和数字拆位 |
| 难度评价 | 偏难 |
| 对 9 岁学生是否合适 | 不合适 |
| 标签准确性 | 准确，"数字拆位"确实点明考点，但考点本身超纲 |
| 测试用例 | 有缺陷，仅 1 个测试点；`230` 对调后输出 `32`，涉及前导零处理，学生未学条件判断容易出错 |

**说明**：将 123 拆成百位、十位、个位再重组，需要 `%` 和 `/` 拆位，课程 01 未涉及。

**建议**：**替换**。改为简单整数运算题，例如"输入两个整数，输出它们的差与积"。

---

### 第 5 题：两个自然数 M 和 N 的最小公倍数

| 审核维度 | 结论 |
|---|---|
| 匹配度 | 低 |
| 是否超纲 | 是，需要循环 / 枚举 |
| 难度评价 | 过难 |
| 对 9 岁学生是否合适 | 不合适 |
| 标签准确性 | 准确，"循环结构, 枚举"标签正确，但放在第 1 课不合适 |
| 测试用例 | 有缺陷，仅 1 个测试点 |

**说明**：求最小公倍数需要循环枚举或辗转相除法，课程 01 未教循环和算法思维。

**建议**：**替换**。改为第 1 课能完成的纯四则运算题，例如"输入长方形的长和宽，输出周长和面积"（与第 1 题互补）。

## 六、总体结论

**课程 01 课后练习合格判定：不合格。**

5 道课后挑战中，**仅第 1 题完全匹配课程 01 知识范围**；其余 4 道均存在不同程度的超纲或数据设计问题，不适合作为第一课课后练习。

若保持当前题目不变，9 岁初学者在课后练习环节会频繁遇到未学知识（循环、小数、拆位、枚举），容易产生挫败感，并怀疑是否漏学了内容。

## 七、整改建议

### 即时整改

1. **保留并小修第 1 题**：删除错误标签"分支"，补充准确标签。

3. **替换第 3 题**：改为整数范围题目，避免引入小数格式化。
4. **替换第 4 题**：改为简单整数四则运算题。
5. **替换第 5 题**：改为第 1 课能力范围内的综合算术题。

### 替换原则

调整后，课程 01 的 5 道课后题应**全部围绕以下知识点**：

> 程序骨架 + `cout` 输出 + `int` 变量 + `cin` 输入 + `+ - * /` 整数四则运算

**不引入任何后续课程内容**（循环、分支、小数、取模、拆位等）。
