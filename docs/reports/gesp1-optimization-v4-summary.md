# GESP1 微课优化总结（v4）

## 一、优化范围

本次仅修改 `server/courses/gesp1/` 下的 `.md` 微课文件，修改完成后已同步到 `server/courses/gesp1-micro/`，文件名与结构保持一致。

## 四、重点优化的课程讲解

### 1. `02-整数运算.md`：拆分讲解、增加比喻与过渡

- 在「电脑三大件」后新增 **过渡页：三大件记住了吗？** 用「大脑 / 黑板 / 书柜」生活比喻二次强化。
- 在「变量名规则」后新增 **小练习：变量名大闯关**，用表格列出 5 个典型名字让学生判断，并给出口诀。
- 在 `long long` 后新增 **小练习：该用哪个盒子？** 帮助学生建立「21 亿是 int 边界」的直觉。
- 在拆位前新增 **过渡页：先取再砍，像削铅笔**，把 `%10` 和 `/10` 比喻为「看铅笔尾部」和「削掉一段」。
- 在挑战前新增 **分步拆解三位数** 表格，以 `n=352` 逐步演示变量变化。
- 修正小贴士口诀的格式错误（原有多余空格）。

### 2. `09-字符类型与switch.md`：补充 ASCII、增加小练习与过渡页

- 在 `char` 与单/双引号讲解后新增 **卡片：每个字符都有一个编号（ASCII）**，给出 `'0'~'9'`、`'A'~'Z'`、`'a'~'z'` 的关键码值表，并演示 `(int)'A'` 与 `(char)65` 的互转。
- 新增检查点 **A 的编号是多少？** 巩固 ASCII 记忆。
- 在大小写转换前新增 **过渡页：为什么加 32？** 用 `97 - 65 = 32` 解释大小写差值的来源。
- 在 `switch` 前新增 **过渡页：从 if-else if 到 switch**，用「范围判断用 if，固定值用 switch」的口诀降低切换负担。

### 3. `11-循环控制.md`：break/continue 与质数内容分步讲解

- 在 break/continue 对比检查点后新增 **小练习：break 和 continue 对对碰**，用两个并排的代码片段和输出对照表，让学生一眼看出差异。
- 新增 **过渡页：用遥控器解决质数问题**，明确把 break/continue 与质数判断隔开，避免概念堆叠。
- 在基础质数代码后新增 **分步拆解质数判断** 表格，以 `n=17` 和 `n=15` 演示 `isPrime` 标志位与 `break` 的工作过程。
- **全书未出现 `sqrt()` 或 `<cmath>`**，质数优化统一使用 `i * i <= n`。

### 4. `17-C风格输入输出.md`：更直观讲解、减少两套 IO 切换负担

- 在 `printf` 入门后新增 **printf 像做填空题** 卡片，用「我有 %d 个苹果，每个 %.2f 元」的生活化例子解释占位符与后面值的对应关系。
- 在第 2 关与第 3 关之间新增 **过渡页：两套输入输出怎么选？**，给出明确建议：初学先用 `cin`/`cout`，遇到格式化需求再换 `scanf`/`printf`，并强调不要混用。
- 在格式控制中新增 **格式控制小口诀** 表格，把 `%03d`、`%-5d`、`%.2f`、`%8.2f` 等常用写法集中对比。
- 将原「两套输入输出怎么选？」小贴士改为 **不要混用两套输入输出**，避免与过渡页重复。

## 五、仍需要人工复查的地方

1. **练习课题目与数据库绑定**：本次只改动了教学文本，课后挑战中的 `<!-- problem: ... -->` 占位符未改动。若题目难度或知识点范围随之调整，需要到题库侧检查对应题目是否仍然匹配。
2. **`03-小数运算.md` 的精度概念**：标准教案 03 要求讲解「四舍六入五凑双」与浮点数近似存储，当前微课已保留但偏抽象。若学生反馈理解困难，可考虑在保留概念的前提下增加更多具体例子或标记为「拓展了解」。
3. **`06-双路分支.md` 的嵌套 if 标注为拓展后**：若后续题库或课程路径依赖该内容，需要确认是否应将嵌套 if 重新纳入主路径，或保持拓展定位。
4. **`15-短除法.md` 的 `while(t--)`**：虽然已补充，但 `t--` 的后置自减概念在 `10-for循环.md` 的 `i++` 中已有铺垫。建议授课时先确认学生已掌握 `i++`/`i--` 再引入 `while(t--)`。
5. **代码片段运行验证**：所有新增/修改的 C++ 代码片段建议在实际 Dev-C++ 环境中快速跑一遍，特别是 `07-多路分支.md` 中 `||` 修正后的闰年判断代码。
