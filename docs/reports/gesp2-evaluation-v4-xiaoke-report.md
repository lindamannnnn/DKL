## 二、仍存在的问题清单

### 1. 概念理解不牢
- **随机数公式 `rand() % (b - a + 1) + a`**：能套用但不懂原理，容易记混 `+1` 位置。
- **负数取整 `floor(-3.1) = -4`**：与数学直觉冲突，容易记错。
- **形参/实参、值传递**：能照写但不理解“为什么函数里改了不影响外面”。
- **前置声明**：不理解编译器为什么需要“预告”。
- **ASCII 编码数字**：`'0'=48`、`'A'=65`、`'a'=97` 需要硬背，容易混淆。
- **TCP/IP 四层与 OSI 七层**：功能对应关系模糊，容易混层。
- **ROM 与硬盘区别**：都能断电保留，但使用场景分不清。
- **闰年规则**：逻辑组合复杂，容易漏条件。

### 2. 代码书写易错点
- **嵌套循环**：外层和内层执行顺序需要画表格才能想清。
- **数位拆分**：`n / 10 % 10` 取十位容易和 `n % 10 / 10` 搞混。
- **图形内部空格公式**：空心图形中 `2*i-3` 这类公式容易写错。
- **`cout << endl;` 漏写**：图形题仍容易忘。
- **循环边界**：负数起点（如 `j = -i`）和 `<=` / `<` 容易数错。
- **条件判断符号**：长串 `||` 容易漏写。

### 3. 综合应用困难
- **百钱百鸡**：数学建模 + 三重条件 + 整除判断，难度偏大。
- **空心菱形/沙漏**：上下半分别用不同公式，容易写反。
- **完全数**：双层循环 + 真因子概念，耗时且易错。
- **真题编程题**：从题意到代码的转化还不够熟练，尤其是边界处理。

### 4. 理论知识与编程切换
- 从纯编程课（第 10 课）跳到计算机存储网络（第 11 课），风格变化大，需要时间适应。

## 三、建议修改优先级

### 🔴 高优先级（必须改）
1. **GESP2-02 自定义函数**：前置声明需配“先报名再上场”类比喻；形参实参建议用“复印纸”类比。
2. **GESP2-05 多层循环**：嵌套循环需增加“慢动作回放”表格；百钱百鸡应先拆成三个独立条件再合起来。
3. **GESP2-10 图形打印2**：空心菱形应先讲实心菱形再挖空；沙漏需强调中间行不重复。
4. **GESP2-11 计算机的存储与网络**：TCP/IP 四层每层配生活例子；OSI 七层作为拓展或减少信息量。
5. **所有图形题**：每题先给填色坐标图或样例表，再写代码。

### 🟡 中优先级（建议改）
6. **GESP2-01 数学函数**：随机数公式加图解；负数取整多给对比例子。
7. **GESP2-04 数据类型转换**：ASCII 编码编口诀；流程图建议单独成章或与主题更紧密结合。
8. **GESP2-07 循环综合应用**：完全数先讲“求因子和”；回文数倒序加动画演示。
9. **GESP2-13 综合大闯关**：闰年规则用决策树展示；蝴蝶图案先给坐标图。
10. **GESP2-14/15 真题课**：增加草稿区、思路步骤、错题本模板。

### 🟢 低优先级（可优化）
11. 练习课部分题目与前面课程重复（如 challenge 2 的 myAbs），可替换为新题。
12. 每节课增加“限时小测验”或“先自己写再看答案”的环节。
13. 小贴士中反复强调 `cout << endl;`、大括号配对、变量名不要重复。
