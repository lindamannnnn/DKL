## 测试课程：GESP2-02 自定义函数

- **已学课程**：GESP1-01 ~ GESP1-18、GESP2-01
- **测试时长**：30 分钟
- **卡住次数**：3 次
- **求助次数**：2 次（一次问“形参和实参是不是同一个东西”，一次问“void 是什么英文”）
- **完成度**：80%

### 已学知识帮我理解的地方
1. 第 1 课刚学过 `max(3, 7)`，所以这节课说“括号里的数叫参数”，我能接上。
2. `main()` 自己也像一个函数，程序从它开始跑，这个比喻我懂。
3. `return` 在 GESP1 里就写过 `return 0;`，现在知道它还能把算好的结果送回去。
4. `for` 循环我会写，所以 `void printStar(int n)` 里面打印 n 个星号我能看懂。

### 最困惑的地方
1. **前置声明**：函数写在 `main` 后面还要在前面加一行“预告”，我有点不明白为什么编译器不能自己往下找。
2. **形参和实参**：名字不一样，但看起来长得差不多，我容易搞混哪个是“里面用的”，哪个是“外面传进去的”。
3. **作用域“局部优先”**：`show()` 里有个 `x`，外面也有个 `x`，为什么里面就看不见外面的？需要多举几个例子。
4. **三目运算符 `?:`**：写法像谜语，`return a > b ? a : b;` 我盯着看了半天，虽然最后能照抄，但自己写可能写错。

### 知识跳跃点
1. 三目运算符 `?:` 在这节课突然教了，但后面的图形课（第 8、9、10 课）马上会大量用到，幸好这里先教了，不然后面肯定卡。
2. `void` 函数不返回东西，这个从“有 return 值”到“没有 return 值”需要一个过渡例子。

### 最喜欢的部分
1. “造机器”这个故事特别好，我把函数想象成玩具工厂里的打包机，一下就记住了。
2. `printStar(5)` 打印出 `*****` 很有成就感，比自己写五遍 `cout << "*";` 酷多了。

### 必须修改的建议
1. 形参和实参能不能用颜色标出来？比如形参用蓝色、实参用红色，小朋友一眼就能分清楚。
2. 三目运算符 `?:` 建议单独做一页小练习，比如“把下面 if-else 改成 ?:”，练一次再往后用。
3. 作用域的例子有点少，最好再加一个“里面没有 x 时，会去外面找全局 x”的对比例子。
4. 前置声明那页，能不能画一张“编译器只能从上往下读”的图？这样我知道为什么要写预告。

### 小学生一句话总结
“函数就像造机器，我把代码打包好，想用的时候喊一声就行，就是 void 和 ?: 还要再练练。”
