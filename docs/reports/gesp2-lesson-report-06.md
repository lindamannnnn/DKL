### 已学知识帮我理解的地方
1. GESP1-09 学过 `switch`，所以挑战 4 用 `switch` 做成绩分级我很熟悉，知道要加 `break`。
2. GESP1-06、07 学过 `if-else if-else` 和逻辑运算符，挑战 1、2、3 的条件判断我都能写。
3. `max(a, max(b, c))` 在第 3 课练过，挑战 5 直接复用。
4. “`else` 找最近的 `if`”这个提醒很好，帮我避开了悬空 else 的坑。

### 最困惑的地方
1. **挑战 3 的 `if (card) price /= 2;`**：这里把整数 `card` 直接当 bool 用，没人告诉我 0 是 false、非 0 是 true，我愣了一下才敢抄。
2. **挑战 4 的 `case 10: case 9:`**：两个 case 连在一起共享同一段代码，我第一次见，虽然能猜出意思，但不确定自己会不会写。
3. **“固定值用 switch，范围判断用 if...else if”**：这个总结很好，但挑战 4 其实是范围（90~100）却用了 switch，让我有点困惑到底该听哪条。

### 知识跳跃点
1. 把整数当布尔值用（`if (card)`）这节课第一次出现，建议前面加一页说明。
2. 多个 `case` 共享代码的写法没有提前练习，直接出现在挑战里。

### 最喜欢的部分
1. 决策小镇的故事让我觉得自己在闯关，很有代入感。
2. 四象限判断这题很好玩，像在玩坐标游戏。

### 必须修改的建议
1. 在挑战 3 之前加一页小说明：C++ 里 0 表示“不成立”，其他数字表示“成立”，所以 `if (card)` 等价于 `if (card == 1)`。
2. 挑战 4 的 `case 10: case 9:` 最好单独解释一下，说这是“两个入口进同一扇门”。
3. “固定值用 switch，范围用 if”这句建议和 challenge 4 的实际情况协调一下，或者说明“范围也能用 switch，但要先转成固定值（如 score / 10）”。

“多层分支就是一层层做选择题，switch 我会用，就是把整数当条件那里让我多停了一下。”
