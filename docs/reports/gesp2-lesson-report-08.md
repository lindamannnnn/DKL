## 测试课程：GESP2-08 图形打印1

- **已学课程**：GESP1-01 ~ GESP1-18、GESP2-01 ~ GESP2-07
- **测试时长**：33 分钟
- **卡住次数**：3 次
- **求助次数**：2 次（一次问“`i == j ? '*' : ' '` 这是什么写法”，一次问“正斜边为什么是 n+1”）
- **完成度**：70%

### 已学知识帮我理解的地方
1. 第 5 课学过嵌套循环，所以这节课“外层管行、内层管列”我很熟悉。
2. 第 2 课学过三目运算符 `?:`，虽然当时觉得有点谜语，但这节课大量用，我终于练熟了。
3. 等腰三角形拆成“空格 + 星号”的方法，和第 5 课矩形很像，只是多了空格。
4. 边框矩形用 `i==1 || i==n || j==1 || j==m` 判断，我学会了“只要满足一个条件就画星”。

### 最困惑的地方
1. **反斜边和正斜边的条件**：`i == j` 我能理解（行号等于列号），但 `i + j == n + 1` 我需要画个表格才能确认。
2. **三目运算符嵌套在 `cout` 里**：`cout << (i == j ? '*' : ' ');` 括号很多，我漏过右括号。
3. **等腰三角形的空格数**：`n - i` 个空格，我总是算错，输出不是歪了就是不够居中。

### 知识跳跃点
1. 三目运算符在这节课高频出现，幸好第 2 课教过，否则完全跟不上。
2. “正斜边常数是 n+1”没有推导过程，直接给出结论。

### 最喜欢的部分
1. 图形工厂的故事让我觉得在当设计师，输出一个三角形很有成就感。
2. 口诀“i 等于 j，反斜边”很好记，我念了几遍就背下来了。

### 必须修改的建议
1. 正斜边 `i + j == n + 1` 建议配一个 5×5 的坐标表格，让小朋友自己圈出哪些点满足条件。
2. 三目运算符的代码建议先用 if-else 版本展示，再改成 ?: 版本，让小朋友看到等价关系。
3. 等腰三角形增加一页“先在草稿纸上画 n=4 的小样例，标空格数和星号数”。
4. 输出单个空格 `' '` 和输出空格字符串 `" "` 的区别可以说明一下，避免小朋友抄错。

### 小学生一句话总结
“图形打印像画画，找到行和列的规律就能打印出图案，就是空格数我总要算错。”
