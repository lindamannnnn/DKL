- **已学课程**：GESP1-01~GESP1-18、GESP2-01、GESP2-02
- **测试时长**：25 分钟
- **卡住次数**：1 次
- **求助次数**：1 次（问老师 `bool` 函数怎么和 `if` 一起用）
- **完成度**：85%

### 已学知识帮我理解的地方
1. 因为前两节课刚学过 `abs`、`sqrt`、`max` 和自定义函数，所以这节课像复习闯关，很多代码看起来眼熟。
2. 第 5 课学过 `if-else`，所以挑战 2 自己写 `myAbs` 的时候我不慌。
3. 第 9 课学过 `bool` 类型，挑战 3 的 `bool isSquare(int n)` 我知道它是返回“是”或“不是”。
4. 第 1 课学过 `cin >> a >> b >> c`，挑战 1 读三个数很顺利。

### 最困惑的地方
1. 挑战 3 里 `double x = sqrt(n); int sq = round(x); return sq * sq == n;` 这三行我一开始没懂为什么要先 `round` 再平方，直接 `sqrt(n) * sqrt(n)` 不行吗？
2. `max(a, max(b, c))` 这种套娃写法我要想一会儿，虽然能运行，但读起来像绕口令。

### 知识跳跃点
1. 判断完全平方数时把 `round` 和验证结合起来，对我来说是一个小跳跃，因为之前 `round` 只是取整，现在要配合 `sqrt` 一起用。

### 最喜欢的部分
1. 挑战 4 自己写一个 `roll()` 函数模拟掷骰子，调用两次就能掷两个骰子，感觉函数真的有用。
2. 挑战 5 求平方和，把 `square(a) + square(b)` 写在一行里，看起来很酷。

### 必须修改的建议
1. 完全平方数那里能不能加一句“因为 `sqrt` 算出来可能是 3.9999999，所以先用 `round` 变成 4，再乘回去验证”。
2. `max(a, max(b, c))` 这种嵌套调用能不能画个括号颜色图？
3. 挑战 2 和第二节课的 `myAbs` 重复了，可以换个新题，不然我有点犯困。
