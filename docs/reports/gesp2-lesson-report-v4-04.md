## 测试课程：GESP2-04 数据类型转换

- **已学课程**：GESP1-01~GESP1-18、GESP2-01、GESP2-02、GESP2-03
- **测试时长**：28 分钟
- **卡住次数**：2 次
- **求助次数**：1 次（问妈妈 `'A' + 2` 为什么等于 `'C'`）
- **完成度**：82%

### 已学知识帮我理解的地方
1. 因为第 3 课学过 `(double)5 / 2 = 2.5`，所以强制类型转换 `(double)a / b` 我不陌生，只是这节课讲得更细了。
2. 第 9 课学过 `char` 和单引号，也学过大写转小写要加 32，所以这节课看到 ASCII 编码我不觉得完全新。
3. 第 5 课学过 `if` 和关系运算符，挑战 2 判断大写小写我能自己写出来。

### 最困惑的地方
1. ASCII 编码表为什么 `'0'` 是 48、`'A'` 是 65、`'a'` 是 97？这些数字没有规律，我得硬背。
2. `(double)a / b` 和 `(double)(a / b)` 的区别我反复看了两遍，虽然例题说了结果不一样，但我容易忘记括号该放哪。
3. 隐式类型转换“低精度变高精度”这句话有点抽象，什么是精度？是不是就是小数点位数？
4. 流程图里菱形是判断、平行四边形是输入输出，这些图形为什么长这样？我也要背。

### 知识跳跃点
1. 从“字符可以比大小”一下子跳到“每个字符对应一个数字编码”，中间如果先让我玩玩 `'A'+1`、`'A'+2` 会更自然。
2. 流程图放在这节课有点突兀，它和类型转换关系不大，像突然插进来的。

### 最喜欢的部分
1. 密码锁的故事很好玩，`'A' + 2 = 'C'` 像解谜。
2. 字符大小写转换我能独立写出来，很有成就感。

### 必须修改的建议
1. ASCII 编码三个关键数字能不能编个口诀歌？比如“零是四十八，A 是六十五，小 a 九十七”。
2. `(double)a / b` 和 `(double)(a / b)` 建议用两个不同颜色框把“先转换”和“先计算”标出来。
3. 流程图要么单独放一节课，要么和本课主题联系更紧一些。
4. “隐式转换”建议改成“自动转换”，小学生更容易懂。

### 小学生一句话总结
“原来字母在电脑里也是数字，给字母加数字就能变成另一个字母，像变魔术一样！”
