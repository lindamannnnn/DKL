## 测试课程：GESP2-08 图形打印1

- **已学课程**：GESP1-01~GESP1-18、GESP2-01~GESP2-07
- **测试时长**：30 分钟
- **卡住次数**：2 次
- **求助次数**：1 次（问老师为什么正斜边是 `i + j == n + 1`）
- **完成度**：80%

### 已学知识帮我理解的地方
1. 因为第 5 课学过嵌套循环，所以外层管行、内层管列这个思路我能接受。
2. 第 6 课学过三目运算符 `?:`，所以这节课用 `i == j ? '*' : ' '` 写斜边我不陌生。
3. 第 15、16 课用过在纸上画表格，这节课 `i+j` 的表格我一看就懂。

### 最困惑的地方
1. **正斜边**：`i + j == n + 1` 这个式子我要在表格上把 i 和 j 填进去才能确认，直接记容易记成 `n - 1` 或 `n`。
2. **等腰三角形**：空格数 `n - i` 和星号数 `2 * i - 1` 这两个公式我要在草稿纸上列出来，不然容易写反。
3. 边框矩形里 `i==1||i==n||j==1||j==m` 一长串条件，我老担心漏写一个 `||`。

### 知识跳跃点
1. 从普通矩形一下子到“用坐标条件判断画斜线”，中间如果先练“只在第一行画星号”会好一些。
2. 等腰三角形把一行拆成“空格 + 星号”，这个拆解法很好，但第一次见还是要适应。

### 最喜欢的部分
1. 正斜边的表格太清楚了，我把 i 和 j 一个个填进去，发现真的连成一条线。
2. 等腰三角形打出来很漂亮，像圣诞树。

### 必须修改的建议
1. 正斜边建议加一个“把满足条件的位置圈出来”的互动图。
2. 等腰三角形先把 n=3、n=4、n=5 的空格数和星号数列成表格，再写代码。
3. 边框矩形的条件建议拆成“第一行或最后一行”和“第一列或最后一列”两部分写，再合并。
4. 每行结束加 `cout << endl;` 要反复强调，我差点又忘了。

### 小学生一句话总结
“图形打印就是在坐标纸上填色，只要算准每行空几个、画几个星号，图案就出来了。”
