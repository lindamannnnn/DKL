## 测试课程：GESP2-11 计算机的存储与网络

- **已学课程**：GESP1-01~GESP1-18、GESP2-01~GESP2-10
- **测试时长**：35 分钟
- **卡住次数**：3 次
- **求助次数**：2 次（一次问爸爸“TCP/IP 四层”是什么，一次问 OSI 七层口诀怎么背）
- **完成度**：75%

### 已学知识帮我理解的地方
1. 图书馆的比喻很形象：书桌=Cache、书架=内存、仓库=硬盘，我一下子记住了速度从快到慢。
2. “ROM 刻在石头上、内存写在白板上”这个比喻让我记住了断电后谁会丢数据。
3. IP 地址像门牌号，看第一个数字判断 A/B/C 类这个规则比较简单。

### 最困惑的地方
1. **TCP/IP 四层**：应用层、传输层、网络层、网络接口层，每个层具体干什么我分得不太清，尤其是“传输层”和“网络层”容易混。
2. **OSI 七层**：“物数网传会表应”这个口诀我能背，但每一层对应的功能我还是模模糊糊。
3. 只读存储器（ROM）和硬盘都能断电保留，它们有什么区别？为什么要有两个？
4. 私有地址和公网地址的区别，我大概知道一个是小区里有效、一个是全国有效，但什么时候用哪个还不清楚。

### 知识跳跃点
1. 这节课从纯编程一下子跳到计算机理论知识，风格变化很大，我一开始没进入状态。
2. TCP/IP 和 OSI 两个模型同时出现，信息量有点大。
3. IP 地址 A/B/C 分类没有解释为什么这样分，只是给了数字范围。

### 最喜欢的部分
1. 图书馆比喻我最喜欢，Cache、内存、硬盘一下分清。
2. LAN/MAN/WAN 的比喻（班级圈子、城市公交、世界航线）也很好记。

### 必须修改的建议
1. TCP/IP 四层建议每一层配一个生活例子，比如“我发微信”时每一层在做什么。
2. OSI 七层可以只作为拓展内容，或者给一张大表格对应 TCP/IP 四层。
3. ROM 和硬盘的区别要专门讲一讲：ROM 是出厂写好的小芯片，硬盘是可以自己存文件的大空间。
4. IP 地址分类最好说明“这是旧的分类方法，现在 mostly 看 CIDR”，不然我会以为必须死记。

### 小学生一句话总结
“电脑存储就像图书馆，越快的地方越小；网络就像寄信，一层一层把信息送出去。”
