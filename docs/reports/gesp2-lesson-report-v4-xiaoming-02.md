## 测试课程：GESP2-02 自定义函数

- **测试时长**：23 分钟
- **走神次数**：4 次（看"形参实参"那段文字太长；作用域示例有两个 `x` 我懵了；三目运算符像谜语；代码超过 8 行我不想打）
- **想放弃次数**：3 次（前置声明那行为啥加分号不懂；函数写在 `main` 后报错一次；`void` 函数没有 `return` 报错一次）
- **完成度**：80%

### 最困惑的地方
1. 前置声明像电影预告片，但为什么只写头还要加分号？
2. 函数里修改形参，外面的实参居然不变，我觉得这规则有点反直觉。
3. 全局变量和局部变量同名时局部优先，我以为是同一个盒子被覆盖了。
4. 三目运算符 `?:` 读起来像谜语，我先抄例子再说。

### 最喜欢的部分
1. 函数像工厂机器，这个比喻很酷，感觉自己能造东西了。
2. 用函数打印星号矩形，一运行就出来一个方块，有点像像素画。

### 必须修改的建议
1. 前置声明单独一页，并强调"只有函数头 + 分号"，别让我和定义搞混。
2. 形参实参用"复印件"比喻：函数拿的是复印件，改复印件不影响原件。
3. 三目运算符 `?:` 别和这节课混在一起，单独放一节或作为选学。
4. 每段代码示例控制在 8 行以内，太长了我就想复制。

### 小明一句话总结
"自定义函数让我感觉自己造了台机器，但前置声明和形参实参把我绕晕了。"
