1. Cache、RAM、ROM 名字都带 R，分不清谁快谁慢。
2. TCP/IP 四层到底对应什么？应用层和传输层有啥区别？
3. OSI 七层口诀"物数网传会表应"背了，但不知道每层干啥。
4. 私有地址和公网地址区别我没懂。

### 最喜欢的部分

2. `127.0.0.1` 像对着镜子喊自己，这个例子好笑。
