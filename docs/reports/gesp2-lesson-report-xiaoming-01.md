## 测试课程：GESP2-01 数学函数

- **测试时长**：20 分钟
- **走神次数**：4 次（看到 `floor`/`ceil` 负数例子时、随机数公式 `b-a+1` 时、想到游戏奖励时、课后挑战第 3 题卡壳时）
- **想放弃次数**：2 次（负数取整搞不懂、随机数公式像天书）
- **完成度**：85%（挑战 1、2 抄完能跑，但完全平方数那题靠复制，没真懂）

### 最困惑的地方
1. `floor(-3.1) = -4`：我以为 -3.1 向下应该是 -3，结果它往更小的方向走，我在草稿纸上画了半天数轴才勉强接受。
2. `rand() % (b - a + 1) + a` 这个公式：为什么要 `+1`？为什么要先 `%` 再 `+a`？我直接记成“骰子就是 `%6+1`”算了。
3. `sqrt()` 返回 `double`，和 `int` 混用时会报错，我复制示例时漏了强转就报错了。

### 最喜欢的部分
1. 掷骰子那题！`rand() % 6 + 1` 让我感觉像在写游戏，虽然我其实没完全懂 `srand(time(0))` 为什么叫“洗牌”。
2. 开头故事提到“工具箱”，让我觉得自己像在收集装备，但如果有进度条显示“获得 sqrt 技能”会更好。

### 必须修改的建议
1. `floor`/`ceil` 负数部分请配一个数轴图，标出 -4、-3、-3.1 的位置，光说“向下”我第一反应是朝 0 的方向。
2. 随机数公式先教 1~6 的骰子，再教 0~100，最后才抽象成 `a~b`，别直接甩公式。
3. 每介绍一个函数能不能给个小徽章？比如“abs 新手”“sqrt 学徒”，没有奖励我学得有点没劲。

### 小明一句话总结
“掷骰子那块挺酷的，但负数取整把我绕晕了，还好复制代码能跑通。”
