## 测试课程：GESP2-13 练习课：GESP2综合大闯关

- **测试时长**：30 分钟
- **走神次数**：6 次（最大最小差简单飘了、闰年条件复杂、素数 sqrt 边界、数字拆解顺手、蝴蝶图案有趣但分段多想游戏、想比较进度）
- **想放弃次数**：3 次（闰年条件括号放错报错两次、素数判断 `i <= (int)sqrt(n)` 记不住、蝴蝶图案中间空格对不齐）
- **完成度**：75%（挑战 1、3 独立完成，挑战 2、4 半抄半懂，挑战 5 靠复制，课后挑战做了 3 道）

### 最困惑的地方
1. 闰年条件：`(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)`，括号太多，我一开始把 `&&` 和 `||` 优先级搞错，输出全反了。
2. 素数判断：`for (int i = 2; i <= (int)sqrt(n); i++)` 这里为什么要强转 `sqrt(n)`？不能直接写 `i * i <= n` 吗？
3. 蝴蝶图案：中间空格数 `2*(n-i)` 我算成 `n-i` 和 `2*n-i` 都试过，图案要么太窄要么太宽。

### 最喜欢的部分
1. 蝴蝶图案：做出来真的像一只蝴蝶，我截图想发给同学看。
2. 数字拆解：用 `/1000`、`/100%10`、`/10%10`、`%10` 四位一起算，感觉自己像拆解炸弹的专家。

### 必须修改的建议
1. 闰年条件请用“四格漫画”分情况：① 能被 400 整除 → 闰年；② 能被 100 整除 → 不是；③ 能被 4 整除 → 是；④ 其他 → 不是。
2. 素数判断建议用 `i * i <= n` 而不是 `sqrt` 强转，减少一个容易出错的点。
3. 蝴蝶图案请给一个 n=4 的逐行拆解表，把每行左右星数和中间空格数标清楚。

### 小明一句话总结
“蝴蝶图案做出来我超有成就感，但闰年和素数那两个条件我基本靠复制，没真会。”
