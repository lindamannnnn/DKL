## 测试课程：GESP2-15 真题练习2

- **测试时长**：35 分钟
- **走神次数**：8 次（输入设备题简单飘了、循环边界负数时要数次数、类型转换题抽象、完全平方数枚举、菱形坐标条件直接懵、想到期末考试、想玩手机、想放弃）
- **想放弃次数**：4 次（菱形题四条线条件完全不懂、完全平方数边界 `<` 和 `<=` 搞错、判断题第 7 题内层循环次数数不清、最后一道编程题直接想关页面）
- **完成度**：70%（选择题对一半，判断题对一半，完全平方数半懂，菱形题基本放弃）

### 最困惑的地方
1. 菱形题：`i + j == n + 1 || i + j == 3*n - 1 || i - j == n - 1 || j - i == n - 1` 这四条线我怎么想出来的？我在草稿纸上画了半天，只能硬背答案。
2. `3*n - 1` 这个数字：为什么是 3n-1？我推导不出来，感觉像魔法数字。
3. 判断题第 7 题：`for (int j = -i; j < i; j++)` 内层循环次数，负数开始我数不清，要借助手指一根根数。
4. 完全平方数：`for (int i = 1; i * i <= r; ++i)` 这里 `<=` 还是 `<` 我又犹豫了。

### 最喜欢的部分
1. 输入设备题：湿度传感器是输入设备，这个我一看就会，像送分题。
2. 完全平方数：虽然边界有点晕，但 `i*i` 这个想法挺巧妙的，比一个一个判断快。

### 必须修改的建议
1. 菱形题这种复杂坐标推导不建议放在基础课程里，或者只给 n=3 的完整填表示例，不要直接给四条线公式。
2. 负数循环边界请单独开一个小练习，让我先数清楚 `-i` 到 `i-1` 有几个数。
3. 完全平方数边界请给一个 l=1, r=4 的小例子，让我看到 1 和 4 都算不算。
4. 最后一节课请有一个“毕业庆祝”动画或徽章，我熬到最后很想看到奖励。

### 小明一句话总结
“选择题我还能蒙对几个，但那个菱形编程题我直接投降了，四条线条件像天书。”
