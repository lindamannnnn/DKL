## 题 1：人数统计
- **UUID**：`ddf4dc1a-1071-4c9c-b539-3747cbace207`

**题面**：小张同学今天在信息技术课堂上学习了利用 Excel 进行成绩统计的方法，现在他想编写一个这样的程序：输入全级某次测验的成绩，分别统计 0～59、60～69、70～79、80～89 和 90～100 各分数段的人数。假如你就是小张，你能把这个程序编出来吗？

**输入**：第一行为全级人数（1000 以内），第二行至最后一行为学生的分数，分数都为 0～100 间的整数。

**输出**：输出包括 5 个分数段的人数，每行一个数。（顺序为 0～59 分的人数，60～69 分的人数，70～79 分人数，80～89 分人数，90～100 分人数）

**输入样例**：
```
7
80
87
90
53
65
68
100
```

**输出样例**：
```
1
2
0
2
2
```

## 题 2：找数组的最大数
- **UUID**：`ded7df5c-e634-4f0e-af7d-dc8949c53a4a`

**题面**：从键盘读入 n 个整数，请问这 n 个整数的最大数是多少？

**输入**：第 1 行读入一个整数 n（n<=100）；第 2 行读入 n 个整数；

**输出**：输出数组中的最大数；

**输入样例**：
```
5
2 1 5 3 4
```

**输出样例**：
```
5
```

## 题 3：找最小数的位置
- **UUID**：`c1f09e7c-554f-46ea-bef1-f68d2e746cf1`

**题面**：从键盘读入若干整数，请问这些数中，最小数是第几个数？

**输入**：第 1 行是一个整数 n（n<=100），第 2 行有 n 个整数

**输出**：输出 n 个数中，最小数是第几个数，如果有多个最小数，请输出第一个出现的最小数的位置。

**输入样例**：
```
5
2 1 3 4 1
```

**输出样例**：
```
2
```

## 题 4：奇数位偶数位和与差
- **UUID**：`4a3e827a-4f2c-4ef0-a597-0cc54c32947a`

**题面**：输入 N 个数，求它们奇数位之和偶数位之和（注意：不是奇数和偶数的和，是奇数位和偶数位的和），并输出这两个和中较大数减较小数的结果。

**输入**：第一行数值 n，接下来 n 行，每行一个整形数字。（n<=1000）

**输出**：第一行输出奇数位和。第二行输出偶数位的和。第三行，将上述大的和减去小的和的差。

**输入样例**：
```
5
4
6
8
10
12
```

**输出样例**：
```
24
16
8
```

## 题 5：排名第二高的成绩
- **UUID**：`b84fb640-90d2-4dc0-8b89-60407a054e84`

**题面**：帮老师统计一个班级 N （10<N<100）个同学的考试成绩（成绩不可能全一样）中排名第二高的成绩是多少。

**输入**：第 1 行有一个整数 n（10<n<100），第 2 行有 n 个整数，用空格隔开。

**输出**：输出排名第 2 高的成绩。

**输入样例**：
```
15
98 98 56 88 98 99 66 87 67 89 54 77 66 89 60
```

**输出样例**：
```
98
```

## 备注

- 题 5 样例：最高分为 99，第 2 高为 98（注意有多个 98，"排名第 2 高"指第二大的数值）。
- 题 4 样例：奇数位（第 1、3、5 个数）4+8+12=24，偶数位（第 2、4 个数）6+10=16，差 8。
