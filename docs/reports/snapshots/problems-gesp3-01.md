# GESP3 第 01 课（一维数组）课后题快照

## 1. 人数统计（ddf4dc1a-1071-4c9c-b539-3747cbace207）

输入全级某次测验的成绩，分别统计 0～59、60～69、70～79、80～89 和 90～100 各分数段的人数。

- 输入：第一行为全级人数（1000 以内），第二行至最后一行为学生的分数，分数都为 0～100 间的整数。
- 输出：5 个分数段的人数，每行一个数（顺序：0～59、60～69、70～79、80～89、90～100）。
- 样例输入：`7` 换行 `80 87 90 53 65 68 100`（每人一行）
- 样例输出：`1 / 2 / 0 / 2 / 2`（每行一个）

## 2. 找数组的最大数（ded7df5c-e634-4f0e-af7d-dc8949c53a4a）

从键盘读入 n 个整数，输出最大数。

- 输入：第 1 行 n（n<=100）；第 2 行 n 个整数。
- 输出：最大数。
- 样例：输入 `5` / `2 1 5 3 4` → 输出 `5`

## 3. 找最小数的位置（c1f09e7c-554f-46ea-bef1-f68d2e746cf1）

读入若干整数，输出最小数是第几个；多个最小数输出第一个位置。

- 输入：第 1 行 n（n<=100），第 2 行 n 个整数。
- 输出：最小数第一次出现的位置。
- 样例：`5` / `2 1 3 4 1` → `2`

## 4. 奇数位偶数位和与差（4a3e827a-4f2c-4ef0-a597-0cc54c32947a）

输入 N 个数，求奇数位之和、偶数位之和（注意：不是奇数和偶数的和，是奇数位和偶数位的和），并输出两个和中较大减较小的差。

- 输入：第一行 n，接下来 n 行每行一个整数（n<=1000）。
- 输出：第一行奇数位和；第二行偶数位和；第三行大的和减小的和的差。
- 样例：`5 / 4 6 8 10 12`（每个一行）→ `24 / 16 / 8`

## 5. 找找谁的身高超过全家的平均身高（2840edbc-4666-4a61-a776-3696c9ded197）

全家 n 口人，求平均身高（保留一位小数），并找出超过平均身高的人。

- 输入：第一行 n（1<n<11），第二行 n 个整数空格隔开。
- 输出：第一行 `AVE=x.x`（保留一位小数）；第二行 `位置:身高`，位置从 1 开始数，多个之间用空格隔开。
- 样例：`7` / `175 160 172 158 178 162 142` → `AVE=163.9` / `1:175 3:172 5:178`
