## 1. 数组元素的插入（d1fef4dd-4f2a-49da-ad2d-7ceb80823056）

- **描述**：在一个数组的第 x 个位置插入一个新的数 y
- **输入**：有四行。第一行一个整数 n（5 <= n <= 10）；第二行 n 个整数；第三行一个整数 x，为要插入的位置；第四行一个整数 y，为要插入的整数
- **输出**：更新后的数组
- **样例输入**：`5` / `7 2 3 4 5` / `2` / `9`
- **样例输出**：`7 9 2 3 4 5`
- **来源标注**：数组问题（dongfangboyi-id: 253）

## 2. 数组元素的删除（ebfa57a6-aca5-4304-967f-86b94595c3a0）

- **描述**：把一个数组的第 x 个位置的元素删除掉
- **输入**：有三行。第一行一个整数 n（n <= 10）；第二行 n 个整数；第三行一个整数 x，为要删除的位置
- **输出**：输出更新后的数组
- **样例输入**：`5` / `1 2 3 4 5` / `3`
- **样例输出**：`1 2 4 5`
- **来源标注**：数组问题（dongfangboyi-id: 138）

## 3. 数组逆序（32dec78b-f1d7-48cc-bdfa-83836bfa8ea8）

- **描述**：给你 m 个整数，将其逆序输出
- **输入**：第一行一个整数 m（3 <= m <= 100）：数的个数；第二行 m 个整数（空格隔开，0-9999999 之间）
- **输出**：m 个整数（空格隔开）
- **样例输入**：`3` / `5 7 1`
- **样例输出**：`1 7 5`
- **来源标注**：数组问题（dongfangboyi-id: 51）

## 4. 在最大数后面插入一个数（ca8c44c6-5606-4568-b8d4-10049c769a00）

- **描述**：在一个不重复数组的最大数的后面插入一个新的数 y
- **输入**：有三行。第一行一个整数 n（5 <= n <= 100）；第二行 n 个整数；第三行一个整数 y，为要插入的数
- **输出**：更新后的数组
- **样例输入**：`5` / `7 2 3 4 5` / `9`
- **样例输出**：`7 9 2 3 4 5`
- **来源标注**：数组问题（dongfangboyi-id: 204）

## 5. 移动数组元素（163fa904-d382-4fa9-9e3a-ac1e79eafb28）

> 🔄 **替换说明（2026-07-21）**：原第 5 题《数的操作》（3e62a106-4cc3-4060-99fc-032824e8acf8）来源标注为"容器 vector"，N,M≤100000 的动态增删超出本课静态数组范围，替换为本题。评测首选候选《元素插入有序数组》（56d15ba7）已被 04 课引用、《删除数组的最小数》（03fae952）为 04 课在用它题，故改用本题（打擂台找最值 + 元素交换，均为已教零件）。旧题保留在题库未删除。新题测试点已补齐为 5 个（1 可见 + 4 隐藏，每点 20 分）。

- **样例输入**：`5` / `6 7 1 10 4`
