# GESP3-02 课后题快照（测评时间：本次全新复测）

## 1. 数组元素的插入（d1fef4dd-4f2a-49da-ad2d-7ceb80823056）
- 题意：在数组第 x 个位置插入新数 y。
- 输入：四行——n（5<=n<=10）；n 个整数；x（插入位置）；y（要插入的整数）。
- 输出：更新后的数组。
- 样例输入：`5` / `7 2 3 4 5` / `2` / `9` → 样例输出：`7 9 2 3 4 5`

## 2. 数组逆序（32dec78b-f1d7-48cc-bdfa-83836bfa8ea8）
- 题意：给 m 个整数，逆序输出。
- 输入：第一行 m（3<=m<=100），第二行 m 个整数（0-9999999）。
- 输出：m 个整数（空格隔开）。
- 样例输入：`3` / `1 7 5` → 样例输出：`5 7 1`

## 3. 数组元素的删除（ebfa57a6-aca5-4304-967f-86b94595c3a0）
- 题意：删除数组第 x 个位置的元素。
- 输入：三行——n（n<=10）；n 个整数；x。
- 输出：更新后的数组。
- 样例输入：`5` / `1 2 3 4 5` / `3` → 样例输出：`1 2 4 5`

## 4. 在最大数后面插入一个数（ca8c44c6-5606-4568-b8d4-10049c769a00）
- 题意：在不重复数组的最大数后面插入新数 y。
- 输入：三行——n（5<=n<=100）；n 个整数；y。
- 输出：更新后的数组。
- 样例输入：`5` / `7 2 3 4 5` / `9` → 样例输出：`7 9 2 3 4 5`

## 5. 移动数组元素（163fa904-d382-4fa9-9e3a-ac1e79eafb28）
- 题意：不重复数组中，最小数和第一个数交换，最大数和最后一个数交换。
- 输入：两行——n（5<=n<=100）；n 个不重复整数。
- 输出：移动位置后的数组。
- 样例输入：`5` / `6 7 1 10 4` → 样例输出：`1 7 6 4 10`
- 暗坑：若最大数恰在第一位，先换最小数会把最大数挪走，再按旧位置换最大数就错了。
