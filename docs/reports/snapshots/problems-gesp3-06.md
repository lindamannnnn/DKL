## 题 2：大小写转换
- **UUID**：`acfe941c-3a14-4bcb-8c32-6a8e6f972757`
- **来源标签**：字符串

**题面**：把一个字符串里所有的大写字母换成小写字母，小写字母换成大写字母。其他字符保持不变。

**输入**：输入为一行字符串，其中不含空格。长度不超过80个字符。

```

```


## 题 3：统计字母数字空格和其他字符
- **UUID**：`491e0797-7a7f-494f-a960-8c5169ebdd64`
- **来源标签**：字符串

**题面**：晶晶学习了字符串的概念，她打算统计一下：一个字符串包含了大小写字母、数字、空格以及其他字符，这个字符串中，大小写字母、数字、空格、其他字符分别有多少个？

**输入**：一行字符，包含了大小写字母、数字、空格以及其他字符

**输出**：输出4个整数，空格隔开，分别代表该字符串中大小写字母、数字、空格以及其他字符的个数

**输入样例**：
```
aklsjflj123 sadf918u324 asdf91u32oasdf/.';123
```

**输出样例**：
```
23 16 2 4
```

## 题 5：比较字符串
- **UUID**：`cd0fc5d3-8ecc-4e9c-ac8f-cd13879193fd`
- **来源标签**：蓝桥杯 字符串

**题面**：编程实现两个字符串 s1 和 s2 的字典序比较。（保证每一个字符串不是另一个的前缀，且长度在 100 以内）。若 s1 和 s2 相等，输出 0 ；若它们不相等，则指出其第一个不同字符的 ASCII 码的差值：如果 s1>s2 ，则差值为正；如果 s1<s2 ，则差值为负。

**输入**：输入2个字符串，每个字符串仅包含小写字母（不含空格），两个字符串之间用空格隔开。

**输出**：按题意输出差值或0。

**输入样例**：
```
java basic
```

**输出样例**：
```
8
```
