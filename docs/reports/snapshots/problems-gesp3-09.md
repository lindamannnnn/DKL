## 1. 6134d2a0-9d73-42b4-8d44-c73e9c463f05 — 判断是否构成回文

- **描述**：输入只有一行，包括一串字符（字符个数不超过100，且以 "." 结束）。判断它们是否构成回文。
- **输入说明**：输入只有一行，包括一串字符。
- **输出说明**：输出只有一行，TRUE 或者 FALSE。
- **样例输入**：`12321.`
- **样例输出**：`TRUE`
- **来源**：字符串

## 2. 656eb4c6-42d5-43dd-805d-5df187bd59b4 — 统计字符的个数

- **描述**：从键盘中任意输入一串字符，直至输入 "#" 字符代表结束。请编程统计输入字符中的大写字母、小写字母和数字字符的个数分别是多少？
- **输入说明**：输入只有一行，包括一串字符（长度小于20）。
- **输出说明**：输出只有一行（末尾有回车），包括3个整数，分别代表大写字符、小写字符和数字字符的个数。
- **样例输入**：`daDSALDdcada3240#`
- **样例输出**：`5 7 4`
- **来源**：字符串

## 3. e19e6e30-74a6-435f-a7af-e70b6d93e1b3 — 字符串连接

- **描述**：给出两个字符串，将它们进行拼接，拼接过程中每个字符只允许出现一次。如 s1="adeab"、s2="fcadex"，连接时 s1 留下 adeb（第2个a出现过了不要），再连接 s2 形成 adebfcx，重复的都过滤掉，但剩余顺序不要调整。
- **输入说明**：两行，每行一个只包含小写英文字母的字符串。
- **输出说明**：一行，连接后的字符串。
- **样例输入**：
  ```
  abc
  daaeb
  ```
- **样例输出**：`abcde`
- **来源**：字符串

## 4. 2753cfba-ff69-4136-a0c5-1fefe872ada0 — 字符串分离

- **描述**：对输入的一行字符串做如下操作：将大写字母反向连成字符串，将小写字母正向连成字符串，最后输出一个字符串。
- **输入说明**：一行，包含若干个字符（个数不超过255，不含空格）。
- **输出说明**：一行，包含所有分离后符合条件的字符连接成的字符串。
- **样例输入**：`7DVesb#Ft%`
- **样例输出**：`FVDesbt`
- **来源**：字符串

## 5. 5a991fc2-fd0c-4858-823b-7e9da9f36702 — 字符串的插入

- **描述**：请将一个字符串 s2，插入到一个字符串 s1 的第 p 个字符之后。
- **输入说明**：输入三行，第1行是字符串 s2，第2行是字符串 s1，第3行是位置 p，p 一定是 1 到 s1 长度之间的整数；字符串均没有空格。
- **输出说明**：输出组合后的字符串。
- **样例输入**：
  ```
  qwe
  jij
  3
  ```
- **样例输出**：`jijqwe`
- **来源**：字符串
