# GESP3-10 练习课：string综合应用 课后题快照

> 测评时导出，题面以本快照为准。

## 1. 86be3151-5b16-4607-b044-b86fd006f53b 字符串压缩
- 描述：输入字符串，输出压缩后的字符串。压缩的方法是把连续的相同字母压缩为"长度+字母"的形式，在本题中，单个的字母不需要压缩。
- 输入：一行，一个字符串，只包含小写英文字母，长度不超过255。
- 输出：（无描述）
- 样例输入：`aaabbbbbx`
- 样例输出：`3a5bx`

## 2. c70aedc5-887a-4267-abd3-b2c2e4f7247f 求英文句子中的最长单词
- 描述：一个英文句子（长度不超过255），只含有字母和空格，输出最长的一个单词。如有多个长度相同的单词，则输出最前面的一个。
- 输入：一个字符串。
- 输出：一个字符串。
- 样例输入：`in which four coins`
- 样例输出：`which`

## 3. 55d1bfb8-9de0-4ec8-9e0d-79ae70c4fc93 找最长单词
- 描述：编写程序，根据给出的一个结束于'.'的字符字串，找出其中最长的含有字母'a'的子串。
- 输入：一行，为一个字符字串，结束于句点'.'。字串中的子串由一个或几个空格隔开。
- 输出：一行。显示找出的最长的含有字母'a'的子串。如果有多个这样的子串，只显示其中的第一个；若没有含字母'a'的子串，则显示'NO'。
- 样例输入：`Her  name is Lilan   and she  is a  happy  student.`
- 样例输出：`Lilan`

## 4. 4fc984ac-bc6c-42f5-bd19-e4fb9ffd51c6 字符串展开
- 描述：如果在输入的字符串中，含有类似于"d-h"或者"4-8"的字符子串，我们就把它当作一种简写，输出时，用连续递增的字母或数字串替代其中的减号，即将上面两个子串分别输出为"defgh"和"45678"。约定：(1) 需要展开的情况：出现减号"-"，减号两侧同为小写字母或同为数字，且按 ASCII 码顺序右边严格大于左边。(2) 右边字符恰好是左边字符的后继，只删除中间的减号，如"d-e"→"de"、"3-4"→"34"。如果右边小于或等于左边，保留减号，如"d-d"→"d-d"、"3-1"→"3-1"。
- 输入：仅有一行包含一个长度不超过200的字符串，仅由数字、小写字母和减号"-"组成。行首和行末均无空格。
- 输出：仅有一行，为展开后的字符串
- 样例输入：`abcs-w-y1234-9s-4zz`
- 样例输出：`abcstuvwxy123456789s-4zz`

## 5. 0ad8f4f7-8212-4645-bf9b-7809895e190b 重叠的字符串
- 描述：输入两个仅有小写字母组成的字符串，请求出两个字符串最长的重复部份的长度。重复部份指的是一个字符串的头部的部分字符和另一个字符串的尾部的部分字符是重叠的。比如：abcdefg 和 fggoodabcde，第一个字符串的头部和第二个字符串的尾部有5个字符"abcde"重叠，第一个字符串尾部和第二个字符串的头部有2个字符"fg"重叠，因此最长重叠部长度为5。
- 输入：输入2行，每行有一个长度不超过100的仅由小写字母组成的字符串。
- 输出：输出两个字符串最长的重叠长度。
- 样例输入：`abcxxxxabcxabcd` 换行 `abcdxabcxxxxabcx`
- 样例输出：`11`
