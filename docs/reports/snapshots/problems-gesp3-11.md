## 1. 邮票组合

- **id**: `bf6c4c8f-e6b9-4c69-8b15-5a54b84fd2d2`
- **difficulty**: medium | **gesp_level**: 3
- **题意**：某人有 m 张 3 分邮票和 n 张 5 分邮票，用其中一张或若干张（也可以 0 张）可以得到多少种不同的大于 0 的邮资？找出所有不重复的大于 0 的方案并排序输出。例：1 张 3 分 + 1 张 5 分 → 3、5、8 共 3 种。
- **输入**：两个整数 m、n（1<=m,n<=100），分别为 3 分和 5 分邮票数量。
- **输出**：两行。第一行输出所有不同的大于 0 的邮资方案，数与数之间用空格隔开；第二行输出方案总数。
- **样例输入**：`2 2`
- **样例输出**：

```
3 5 6 8 10 11 13 16
8
```

## 2. 趣味填空

- **id**: `8d8ec0d5-80de-4f2b-9b68-98d0286438b9`
- **difficulty**: medium | **gesp_level**: 3
- **题意**：给出用等号连接的两个整数（如 `1234＝127`，等号不成立），在左边整数中间某个位置插入一个加号，看能否让等号成立（如 `123+4=127`）。编写程序解决。
- **输入**：只有那个不相等的式子。等号两边的整数都不会超过 2000000000。
- **输出**：存在方案则输出正确的式子；不存在则输出 `Impossible!`（不含引号）。
- **样例输入**：`1234=127`
- **样例输出**：`123+4=127`

## 4. 下载电影

- **id**: `6c0fdf6d-a118-4f0a-950c-2bd5df36ad9d`
- **difficulty**: medium | **gesp_level**: 3
- **题意**：已知接下来 N 个小时每小时的网速，找一段连续的 M 个小时下载电影，使这 M 小时的平均网速尽可能大，输出最大平均网速。
- **输入**：第一行两个整数 N、M（1<=M<=N<=100）；第二行 N 个整数，表示每小时的网速，空格隔开。
- **输出**：一行一个实数，最大平均网速，保留两位小数。
- **样例输入**：

```
6 3
3 6 1 5 6 4
```

- **样例输出**：`5.00`
