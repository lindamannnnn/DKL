## 1. 趣味填空 — `8d8ec0d5-80de-4f2b-9b68-98d0286438b9`
- **标题**：趣味填空
- **来源**：字符串
- **描述**：小华的寒假作业上，有这样一个趣味填空题：给出用等号连接的两个整数，如"1234＝127"。现在这个等号是不成立的。题目让你在左边的整数中间某个位置插入一个加号，看有没有可能让等号成立。以上面的式子为例，如果写成123+4=127，这就可以了。请编程解决。
- **输入**：只有那个不相等的式子。已知，等号两边的整数都不会超过2000000000。
- **输出**：如果存在这样的方案，请输出那个正确的式子。如果不存在解决方案，请输出"Impossible!"（引号中的部分）。
- **样例输入**：`1234=127`
- **样例输出**：`123+4=127`

## 2. 下载电影 — `6c0fdf6d-a118-4f0a-950c-2bd5df36ad9d`
- **标题**：下载电影
- **来源**：数组问题
- **描述**：放暑假了，陈谱想上网下载电影，但网速慢。他了解到接下来 N 个小时的网速情况，想找一段连续的 M 个小时来下载电影，并且希望这 M 个小时的平均网速尽可能大。请编程序帮助他。
- **输入**：第一行包含两个整数 N、M，1<=M<=N<=100；第二行包含 N 个整数，表示第 N 个小时的网速。相邻两数之间用空格隔开。
- **输出**：仅有一行包含一个实数，表示最大的平均网速，保留小数点后两位。
- **样例输入**：
  ```
  6 3
  3 6 1 5 6 4
  ```
- **样例输出**：`5.00`

## 3. 邮票组合 — `bf6c4c8f-e6b9-4c69-8b15-5a54b84fd2d2`
- **标题**：邮票组合
- **来源**：数组问题
- **描述**：某人有 m 张 3 分的邮票和 n 张 5 分的邮票，用这些邮票中的一张或若干张（也可以是0张）可以得到多少种不同的大于 0 的邮资？请找出可能组合的邮资方案总数，并按照由小到大的顺序输出所有不重复的大于0的方案！
- **输入**：两个整数，m 和 n，分别代表了 3 分和 5 分的邮票的数量（1<=m,n<=100）
- **输出**：第一行输出这两种邮票能组合的不同的大于0的邮资方案，数与数之间用空格隔开；第二行输出可能的方案总数。
- **样例输入**：`2 2`
- **样例输出**：
  ```
  3 5 6 8 10 11 13 16
  8
  ```

## 4. 完美的偶数 — `f36273ba-055d-4a64-9237-224990061288`
- **标题**：完美的偶数
- **来源**：数组问题
- **描述**：完美偶数指的是，如果一个数本身是偶数，且这个数是偶数位的数，且这个数的各个位也是偶数，那么这个数就可以称为完美偶数；比如：28 就是完美偶数，而 246 就不是，因为 246 是一个 3 位数。请编程求出，从键盘读入的 n 个数中，哪些数是完美的偶数，输出它们。
- **输入**：第一行是一个整数 n（n<=100）；第二行是 n 个整数（这些整数都是 1~9999 范围内的整数）。
- **输出**：按顺序输出这 n 个数中的完美偶数，每个数一行。
- **样例输入**：
  ```
  5
  26 4286 228 32 1280
  ```
- **样例输出**：
  ```
  26
  4286
  ```

## 5. 既生瑜，何生亮！ — `c52be03d-d14c-438e-a029-28bb7000bcf4`
- **标题**：既生瑜，何生亮！
- **来源**：数组问题、函数问题
- **描述**：某数的平方是 7 位数，且这 7 个数字不相同，如 1267^2=1605289。编写程序，输入 x, y（1000≤x≤y≤9999）在 x~y 的范围内找出所有符合条件的数并打印出来。
- **输入**：一行，两个整数 x, y（1000≤x≤y≤9999），表示查找范围。
- **输出**：若干行，每行一个符合条件的数。
- **样例输入**：`1000 1025`
- **样例输出**：
  ```
  1017
  1023
  1024
  ```
