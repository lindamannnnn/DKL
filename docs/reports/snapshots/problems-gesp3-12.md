## 题 1：`b5dc0866-75bf-485b-8c12-55a1ada0dc74` 订做校服

- **题意**：学校订校服。给出每件价钱 x（x≤100）、班别数 n（n≤10）、n 个班人数（各班 50 人以内），求总价钱。
- **输入**：第一行 x；第二行 n；第三行 n 个整数（各班人数）。
- **输出**：一个整数，全年级订制校服总价钱。
- **样例**：输入 `30 / 6 / 48 50 51 49 50 52` → 输出 `9000`
- **来源标注**：模拟 数组问题

## 题 2：`f8e165bc-8b0a-4e89-a448-c75026f99099` 珠心算测验

- **题意**：给出 n 个互不相同的正整数集合，问其中有多少个数恰好等于集合中另外两个（不同的）数之和。
- **输入**：第一行 n；第二行 n 个正整数，空格隔开。
- **输出**：一个整数，测验题答案。
- **样例**：输入 `4 / 1 2 3 4` → 输出 `2`（1+2=3，1+3=4；加数和被加数必须是集合中两个不同的数）
- **数据范围**：3 ≤ n ≤ 100，正整数 ≤ 10,000
- **来源标注**：NOIP2014 普及组复赛第 1 题 / noip复赛

## 题 3：`c1fac651-d0d7-4116-8197-2283b04e3c67` 小明的电梯

> 🔄 **替换说明（2026-07-21）**：原题 3《木瓜地 USACO》（a8a7ca74-359e-4bc0-ab8b-513d480bb7cb）需二维网格 + 贪心选路，超出本课"一维按规则推进"定位，按任务清单替换为本题（eval 候选首选，一维数组 + 逐站过程模拟，与课内"按指令走路"同型）。旧题保留在题库未删除。新题测试点已补齐为 5 个（1 可见 + 4 隐藏，每点 20 分）。

- **题意**：小明的住的小区只有一个电梯，只要有人按的号，电梯都会停，每到一站停 5 秒；往上走一层需要 6 秒，往下走一层需要 4 秒。每一次电梯的起始点都在第 0 层。对于给出的电梯停靠层数，算出需要的时间。样例：`1 2` → 0 层上 2 层（2×6=12 秒）+ 停 5 秒 = `17`。
- **输入**：输入一个整数 N，随后有 N 个整数，所有的整数都不超过 100。
- **输出**：输出所需要的时间。
- **样例**：输入 `1 2` → 输出 `17`
- **来源标注**：数组（dongfangboyi-id: 1030）

## 题 4：`542e4d05-0126-4d45-9365-6546ac4f9413` 黑色星期五

- **题意**：统计某年份（≥1998）中，"13 号恰好是星期五"出现了几次。已知一年 365 天、闰年 366 天（能被 4 整除且不能被 100 整除，或能被 400 整除）；1998 年 1 月 1 日是星期四。
- **输入**：一行，一个年份（≥1998）。
- **输出**：一行，该年中既是 13 号又是星期五的次数。
- **样例**：输入 `1998` → 输出 `3`
- **来源标注**：蓝桥杯算法训练 / 蓝桥杯 模拟

## 题 5：`0cab568c-e6bc-4a03-adb6-b279dfda572d` 表达式的值

- **题意**：给出一个只含正整数和 `+` 号的表达式，求最终值（结果 ≤ 100000000）。如 1+1=2，1+2+3=6，12+23=35。
- **输入**：仅一行，含有正整数和 + 号的表达式。
- **输出**：仅一行，表达式算出的结果。
- **样例**：输入 `1+1` → 输出 `2`
- **来源标注**：字符串
