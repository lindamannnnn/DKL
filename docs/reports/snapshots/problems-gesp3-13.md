- **id**: `b222a1c4-2c01-4587-a533-9e7de9ccb19d`
- **difficulty**: easy | **gesp_level**: 3

## 2. 柱状图

- **id**: `b5aeb52d-94af-41fc-9768-51ac348cce24`
- **difficulty**: easy | **gesp_level**: 3
- **题意**：用编程模拟柱状图。读入 n 种物品的数量（n ≤ 100，每种物品数量在 1~10 之间），用一颗星代表数量 1，输出每种物品的编号及对应星号条。（来源标注：数组问题）
- **输入**：第一行一个整数 n 代表物品种类；第二行输入每种物品的数量。
- **输出**：如图所示的柱状图，每行格式为 `编号:星号串`。
- **样例输入**：

```
3
3 7 6
```

- **样例输出**：

```
1:***
2:*******
3:******
```

## 3. 相加之和最大，并给出它们的起始位置

- **id**: `40e90f5b-ae4d-4c34-8a80-cf6066e7aedd`
- **difficulty**: medium | **gesp_level**: 3
- **题意**：有一组数首尾相连构成环形（尾部 8 和头部 11 相连）。编程找出相邻的 4 个数，使其相加之和最大，并给出它们的起始位置。（来源标注：数组问题）
- **输入**：第一行一个整数 n（5 ≤ n ≤ 20）；第二行 n 个数。
- **输出**：第一行一个数，即最大的和；第二行一个数，即起始数的位置。
- **样例输入**：

```
20
11 19 9 12 5 20 1 18 4 16 6 10 15 2 17 3 14 7 13 8
```

- **样例输出**：

```
51
1
```

## 4. 计算表达式

- **id**: `05807f57-0bff-4dd6-9065-998efb4f85aa`
- **difficulty**: medium | **gesp_level**: 3
- **题意**：表达式的形式如 `3+5*6-4`，运算数为一位整数，运算符为 +、-、\* 三种（✅ 2026-07-21 已修复：description 原文渲染为"运算符为 +、-、 三种"，乘号 `*` 丢失，已补上），且运算符没有优先级区分，一律自左向右计算。例：3+5*6-4 = 8*6-4 = 48-4 = 44。（来源标注：字符串）
- **输入**：一行，即表达式字符串（长度小于 100）。
- **输出**：一个整数，即表达式的计算结果（结果在 -20000 至 20000 之间）。
- **样例输入**：`3+5*6-4`
- **样例输出**：`44`
