## 1. 八进制转十进制 — `0a61bae4-4809-4bc9-a471-c28af880be7b`
- **标题**：八进制转十进制
- **来源**：进制转换
- **描述**：将一个 20 位以内的八进制数转换为十进制整数。
- **输入**：20 位以内的八进制数。
- **输出**：对应的十进制数。
- **样例输入**：`77777777777777777777`
- **样例输出**：`1152921504606846975`

## 2. 正整数n转换为16进制 — `16f7c96b-bf70-4372-9df2-81a1a2f53e7b`
- **标题**：正整数n转换为16进制
- **来源**：进制转换
- **描述**：读入一个不超过 18 位的非负整数 n，将 n 转换为十六进制（逢 16 进 1，字母大写 A~F）。
- **输入**：一个不超过 18 位的非负整数 n。
- **输出**：该数的十六进制值（大写字母）。
- **样例输入**：`100000000000`
- **样例输出**：`174876E800`

## 3. 10进制转D进制 — `d066386a-037d-4295-95bb-ff57c74d79af`
- **标题**：10进制转D进制
- **来源**：容器 stack、进制转换
- **描述**：输入十进制非负整数 N 和进制 D（D 为 2、8 或 16），用"除 D 取余、倒序"的方法把 N 转为 D 进制数（16 进制用 A~F 大写）。
- **输入**：两个整数 N 和 D（N<=1,000,000,000）。
- **输出**：N 的 D 进制表示。
- **样例输入**：`1348 2`
- **样例输出**：`10101000100`

## 4. 二进制折半交换 — `35c97828-348a-4c5c-a195-ee7fd8619adc`
- **标题**：二进制折半交换
- **来源**：进制转换
- **描述**：给出一个小于 2^32 的正整数，用 32 位二进制表示（不足补前导 0）。前 16 位为"高位"、后 16 位为"低位"，将高低位交换得到新数，输出其十进制。
- **输入**：一个小于 2^32 的正整数。
- **输出**：高低位交换后的新数（十进制）。
- **样例输入**：`1314520`
- **样例输出**：`249036820`

## 5. 2进制中的0和1 — `f94c5696-b78f-4020-8b45-4f06d5ab5249`
- **标题**：2进制中的0和1
- **来源**：进制转换
- **描述**：计算一个整数 n（0<=n<=1,000,000）转换为二进制后，有多少个 0、多少个 1。
- **输入**：一个整数 n。
- **输出**：两个整数（0 的个数和 1 的个数），空格隔开。
- **样例输入**：`13`
- **样例输出**：`1 3`
