## 题1 d066386a-037d-4295-95bb-ff57c74d79af ｜ 10进制转D进制
- **题面**：十进制整数 N 转 D（2、8、16）进制。原理：N = (N div d)×d + N mod d，除 D 取余倒过来。例如 (1348)10=(10101000100)2、(1348)10=(2504)8、(1000)10=(3E8)16（转16进制用 A~F 代表 10~15）。输入任意非负十进制整数（n<=1,000,000,000），输出等值 D 进制数。
- **输入**：两个整数 N 和 D，N 为要转换的十进制非负整数，D 为进制（2、8 或 16）
- **输出**：N 进制转 D 进制的结果（原文如此，意为十进制转 D 进制）
- **样例**：in `1348 2` → out `10101000100`

## 题2 16f7c96b-bf70-4372-9df2-81a1a2f53e7b ｜ 正整数n转换为16进制
- **题面**：读入一个非负整数 n（不超过 18 位），转换为 16 进制。A~F 分别表示 10~15，字母用大写。如 60 的十六进制为 3C。
- **输入**：一个不超过 18 位的非负整数 n
- **输出**：该数的十六进制值
- **样例**：in `100000000000` → out `174876E800`

## 题3 a7151f31-dd26-46d1-828d-badc0d94c937 ｜ A变B
- **题面**：给定两个正整数 A,B（十进制）（0<A,B<2^63），当 A、B 用二进制表示时，问把 A 变成 B 至少需要改变多少位（右对齐看有多少位不相同）。例：A=3,B=6 → 011 vs 110，至少改变 2 位。
- **输入**：两个正整数 A,B，空格隔开
- **输出**：至少需要改变多少位
- **样例**：in `9 12` → out `2`

## 题4 e9152e0f-5765-4176-8c68-4fcedcfca320 ｜ 小 X 与位运算(bignum)
- **题面**：对两个很大很大的二进制数做 and / or / xor 运算，输出结果。规则说明详尽（and 同 1 得 1；or 同 0 得 0；xor 相同得 0 不同得 1；高位不足用 0 补齐，结果忽略前导 0）。数据范围：n 为最长二进制数长度，30% 数据 n≤20，70% n≤1000，100% n≤100000。
- **输入**：三行字符串：二进制数 1、二进制数 2、运算符号（and/or/xor 之一）。输入无前置零，字符个数可能超过 255。
- **输出**：一行字符串，运算结果，不能带前导零（第一个字符不能为 0）。
- **样例**：in `110100` / `11001` / `or` → out `111101`

## 题5 dc314ed7-039b-43f5-b8f3-95bfd4d58525 ｜ 找筷子
- **题面**：餐厅筷子长短不一，数量为奇数，其中只有一只筷子落单，其余都成双，找出落单筷子的长度。
- **输入**：第一行 N（10<=N<=10000）筷子根数；第二行 N 个空格隔开的数（长度 1~1000）。
- **输出**：落单筷子的长度
- **样例**：in `9` / `2 2 1 3 3 3 2 3` → out `2`
- **备注**：样例中 2 出现 3 次、3 出现 4 次，与题面"其余都成双"字面矛盾；按异或性质（落单者出现奇数次）答案仍成立。
