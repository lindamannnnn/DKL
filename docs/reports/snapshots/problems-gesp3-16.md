## 1. 10进制转D进制 — `d066386a-037d-4295-95bb-ff57c74d79af`（⬅ 与第15课重复）
- **标题**：10进制转D进制
- **来源**：容器 stack、进制转换
- **描述**：输入十进制非负整数 N 和进制 D（D 为 2、8 或 16），用"除 D 取余、倒序"把 N 转为 D 进制（16 进制用 A~F 大写）。
- **输入**：两个整数 N 和 D（N<=1,000,000,000）。
- **输出**：N 的 D 进制表示。
- **样例输入**：`1348 2`
- **样例输出**：`10101000100`

## 2. 正整数n转换为16进制 — `16f7c96b-bf70-4372-9df2-81a1a2f53e7b`（⬅ 与第15课重复）
- **标题**：正整数n转换为16进制
- **来源**：进制转换
- **描述**：读入一个不超过 18 位的非负整数 n，转为十六进制（逢 16 进 1，字母大写 A~F）。
- **输入**：一个不超过 18 位的非负整数 n。
- **输出**：该数的十六进制值（大写字母）。
- **样例输入**：`100000000000`
- **样例输出**：`174876E800`

## 3. A变B — `a7151f31-dd26-46d1-828d-badc0d94c937`
- **标题**：A变B
- **来源**：进制转换
- **描述**：给定两个正整数 A、B（0 < A,B < 2^63），当 A、B 用二进制表示时，问把 A 变成 B 至少需要改变多少位（右对齐看有多少位不相同）。
- **输入**：两个正整数 A、B，空格隔开。
- **输出**：把 A 变成 B 至少需要改变的位数。
- **样例输入**：`9 12`
- **样例输出**：`2`（9=1001，12=1100，有 2 位不同）

## 4. （大二进制数位运算）— `e9152e0f-5765-4176-8c68-4fcedcfca320`
- **标题**：（大二进制数之间的位运算，原题名未完整显示，来源"市赛"）
- **来源**：市赛
- **描述**：两个"很大很大的二进制数"做完某种位运算（&/|/^ 之一）后的结果是什么；二进制数长度可达 100000 位，必须用字符串模拟，不能直接用整数类型。
- **输入**：两个大二进制数字符串（及待做运算）。
- **输出**：位运算结果（二进制串）。

## 5. 找筷子 — `dc314ed7-039b-43f5-b8f3-95bfd4d58525`
- **标题**：找筷子
- **来源**：数组问题
- **描述**：N 根筷子（N 为奇数，10≤N≤10000），长度 1~1000 的整数，其中只有一根落单，其余都成双（长度相同）。找出落单的筷子长度。
- **输入**：第一行 N；第二行 N 个用空格隔开的数（筷子长度）。
- **输出**：一行，落单的筷子长度。
- **样例输入**：`9` 换行 `2 2 1 3 3 3 2 3 1`
- **样例输出**：`2`
