## 1. 10进制转D进制

- **id**: `d066386a-037d-4295-95bb-ff57c74d79af`
- **题意**：给定非负十进制整数 N（N≤1,000,000,000）和进制 D（D 为 2、8 或 16），用"除 D 取余、倒序排列"法输出 N 的 D 进制表示。转 16 进制时余数 10~15 用 A~F 表示。例：1348 → (10101000100)₂、(2504)₈；1000 → (3E8)₁₆。
- **输入**：两个整数 N 和 D，N 表示要转换的十进制非负整数，D 代表要转换的进制（2、8 或 16）。
- **输出**：N 进制转 D 进制的结果（原文如此，应为"十进制转 D 进制"）。
- **样例输入**：`1348 2`
- **样例输出**：`10101000100`
- **来源标注**：容器 stack 进制转换
- **备注**：纯进制转换题，与"位运算"主题无关，属 GESP3 进制转换课的复习题。

## 2. 正整数n转换为16进制

- **id**: `16f7c96b-bf70-4372-9df2-81a1a2f53e7b`
- **题意**：读入一个非负整数 n（不超过 18 位），转换为 16 进制输出，A~F 用大写。例：60 → 3C。
- **输入**：一个不超过 18 位的非负整数 n。
- **输出**：该数的十六进制值。
- **样例输入**：`100000000000`
- **样例输出**：`174876E800`
- **来源标注**：进制转换
- **备注**：与第 1 题知识点重复（都是除 D 取余倒排）；18 位上限需要 `long long`（最大约 9.2×10¹⁸，可容纳）。同样是纯进制转换题，与位运算主题无关。

## 3. A变B

- **id**: `a7151f31-dd26-46d1-828d-badc0d94c937`
- **题意**：给定两个正整数 A、B（0<A,B<2⁶³），把 A、B 写成二进制并右对齐，问把 A 变成 B 至少需要改变多少位（即有多少位不同）。例：A=3 (011)，B=6 (110)，需改变 2 位。
- **输入**：两个正整数 A、B，空格隔开。
- **输出**：把 A 变成 B 至少需要改变多少位。
- **样例输入**：`9 12`
- **样例输出**：`2`
- **来源标注**：进制转换
- **备注**：本质是"汉明距离"= A^B 的二进制中 1 的个数，与本课挑战 1（统计 1 的个数）+ 异或性质完全对口。A,B<2⁶³ 恰好能存入 `long long`（最大 2⁶³−1），边界需要小心但可接受。

## 4. 小 X 与位运算(bignum)

- **id**: `e9152e0f-5765-4176-8c68-4fcedcfca320`
- **题意**：输入两个二进制串（长度可达 100000，无前导零）和一个运算符（and / or / xor），对两个二进制数按位运算（高位不足用 0 补齐），输出结果二进制串，不能带前导零。题面用较长篇幅讲解 and/or/xor 规则。
- **输入**：三行。第一行 0/1 字符串（二进制数）；第二行 0/1 字符串；第三行 and / or / xor 之一。二进制串字符个数可能超过 255。
- **输出**：一行 0/1 字符串，运算结果，第一个字符不能为 0。
- **样例输入**：
  ```
  110100
  11001
  or
  ```
- **样例输出**：`111101`
- **数据范围**：30% n≤20；70% n≤1000；100% n≤100000（n 为最长二进制数长度）。
- **来源标注**：市赛
- **备注**：知识上在范围内（字符串处理 + 模拟已教，and/or/xor 规则本课刚教），但属于"字符串大数模拟"，细节多（对齐补 0、去前导零、超长输入），且题面很长。边缘偏难。

## 5. 找筷子

- **id**: `dc314ed7-039b-43f5-b8f3-95bfd4d58525`
- **题意**：餐厅有奇数根筷子，长度不一，其中只有一只筷子落单，其余都成双（长度相同为一双）。请找出这只落单筷子的长度。例：9 根筷子 2 2 1 3 3 3 2 3 1 → 落单的是长度 2（异或全部即得）。
- **输入**：第一行一个数 N，代表筷子根数（10<=N<=10000）。第二行 N 个空格隔开的数，代表筷子长度（1~1000）。
- **输出**：一行，落单的筷子的长度。
- **样例输入**：`9` / `2 2 1 3 3 3 2 3 1`
- **样例输出**：`2`
- **来源标注**：数组问题（dongfangboyi-id: 448）
- **备注**：标准解法是全部异或（xor），也可用计数数组；N 为奇数（题面说数量为奇数，数据范围写 10<=N，评测数据均为奇数）。
