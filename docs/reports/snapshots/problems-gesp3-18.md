# GESP3 第 18 课 课后题快照（练习课：GESP3综合大闯关）

## 1. 分糖果 (4b6acd43-fabc-4c31-ae49-27495035b8d4)  ⚠️ 表述不清
- **题面（规则缺失）**：输入一行五个整数 a,b,c,d,e；输出一行五个整数（5个小朋友剩余糖果数）。**未说明分糖规则。**
- **输入**：`1 2 3 4 5`
- **输出**：`2 1 2 3 2`
- **结论**：description 只有输入输出，无任何"每人怎么分糖"的规则，小明无法推出算法，属表述不清。

## 2. 删除字符串中间的* (8e3060aa-6ddb-4d2c-9c96-092e3dc86e88)
- **题面**：一个含 * 的字符串，删除串中**中间**的 *（保留开头和结尾连续的 *）。
- **输入**：`***ABC123**123*abc***********`
- **输出**：`***ABC123123abc***********`
- **说明**：样例显示首尾连续的 * 保留、只删夹在中间的 *，规则隐蔽易误解成"删所有*"。

## 3. 数组元素的移动 (866897c4-9e0b-4f49-94e4-a55c7460f0ca)
- **题面**：第一行 n(≤10)，第二行 n 个整数，第三行 x；把数组前 x 个元素移到末尾（循环左移 x 位）。
- **输入**：`8` / `1 2 3 4 5 6 7 8` / `1`
- **输出**：`2 3 4 5 6 7 8 1`
- **说明**：数组遍历 + 输出顺序调整，小明数组功底可胜任。

## 4. COUNT (03c23bb2-1ce9-496d-83ef-e70818c32fdf)
- **题面**：正整数 N(≤10000) 表示总页码；输出 10 行，第 k 行是数字 k-1 在 1~N 所有页码中出现的次数。
- **输入**：`11`
- **输出**：10 行：1/4/1/1/1/1/1/1/1/1（即数字0出现1次、1出现4次、2~9各1次）
- **说明**：数位拆解 + 计数桶（cnt[10]），遍历 1~N 每位统计。

## 5. 出现次数最多的小写字母 (616afc61-7a46-404e-baf8-ec4572bceb81)
- **题面**：一个字符串，输出出现次数最多的小写字母。
- **输入**：`aaabbbbbbbbbcdxs`
- **输出**：`b`
- **说明**：计数法 cnt[26]，遍历字符串统计，打擂台取最多。
