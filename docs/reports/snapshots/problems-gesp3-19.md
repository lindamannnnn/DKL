# GESP3 第 19 课 课后题快照（真题练习1：2026年3月）

## 1. 字符串的反码 (342c47f7-aa49-4e2f-aac7-05f6f8976d9e)
- **题面**：长度≤80 的字符串，输出其"反码"（a↔z, b↔y 镜像映射，非字母保留）。
- **输入**：一行字符串。
- **输出**：反码串。
- **样例**：`Hello` → `Svool`（h↔s, e↔v, l↔o, l↔o, o↔l）
- **说明**：逐字符 `'a'+'z'-c` 映射，小明 ASCII 功底可胜任。

## 2. 八进制转换二进制 (8c108e49-e937-494b-b763-6165cc0afd96)
- **题面**：100 位以内的八进制整数，转二进制（每 oct 位→3 位二进制）。
- **输入**：一行八进制串。
- **输出**：二进制串。
- **样例**：`12376532347173217361` → `1010011111110101011010011100111001111011010001111011110001`
- **说明**：同 lesson17 十六转二，需字符串、首组去前导零。

## 3. 小丽找半个回文数 (d536838a-d4d1-4f6c-b6d6-d5cf8539c3d5)  ⚠️ 表述不清
- **题面（术语未定义）**：n 个整数(0~999999999)，输出所有"半个回文数"。"半个回文数"**无任何定义**。
- **输入**：`5` / `121 417 27 100 21`
- **输出**：`417` / `27` / `21`
- **结论**：从样例推不出"半个回文"的明确规则，小明无法下手，属表述不清。

## 4. 字符串加密 (a9a0f023-724f-42a8-bec9-0c0b8335e48b)
- **题面**：一行字符串(<80)，每个字母 ASCII+1 加密，非字母不变。
- **输入**：`Hello! How are you!`
- **输出**：`Ifmmp! Ipx bsf zpv!`
- **说明**：恺撒+1 偏移（非字母保留），小明 GESP3-06 恺撒功底可胜任。

## 5. 小丽找潜在的素数 (f2a91cc3-d72e-4f41-81c0-150e5e3160ba)
- **题面**：n 个 30 位以内二进制数，输出"转十进制后是素数"的个数。
- **输入**：`6` / `1010000` `1011` `1101001` `10111` `111` `1101011`
- **输出**：`4`
- **说明**：二进制转十进制（long long）+ isPrime 判断，小明 GESP2-14 素数 + 进制功底可胜任。
