## 题1  f0444512-adc2-44d2-9654-6747d7bf1474
**标题**：字符统计
**标签**：字符串 ｜ **难度**：easy
**描述**：
输入一串小写字母（以 '.' 为结束标志），统计出每个字母在该字符串中出现的次数（若某字母不出现，则不要输出）。要求：所有项输出在一行，每项以空格隔开。
**输入格式**：输入一行以 '.' 结束的字符串
**输出格式**：按字母顺序输出所有出现过的字母及其出现次数，每项格式为 `字母:次数`，各项之间用一个空格隔开，全部输出在一行（见样例）。
**样例输入**：
```
aaaabbbccc.
```
**样例输出**：
```
a:4 b:3 c:3
```

## 题2  8b1665c8-7c29-4168-9eb8-814b3056fbc5
**标题**：字符替换
**标签**：字符串 ｜ **难度**：easy
**描述**：
把一个字符串中特定的字符全部用给定的字符替换，得到一个新的字符串。
**输入格式**：只有一行，由一个字符串和两个字符组成，中间用单个空格隔开。字符串是待替换的字符串，字符串长度小于等于100个字符，且不含空格等空白符；接下来一个字符为需要被替换的特定字符；接下来一个字符为用于替换的给定字符。
**输出格式**：一行，即替换后的字符串。
**样例输入**：
```
hello-how-are-you o O
```
**样例输出**：
```
hellO-hOw-are-yOu
```

## 题4  cc5c41e2-5f99-46cb-9179-9032d8b054cd
**标题**：小X转进制
**标签**：进制转换/位运算 ｜ **难度**：medium
**描述**：
小X喜欢研究进制转换。在了解了进制转换的一般流程后，小X突然想起了以前学过的回文数（正着读倒着读都一样的数），于是开始思考一个奇怪的问题：1 到 N 中有多少个整数的平方在 M 进制下是回文数呢？小X随手列了几个：2的平方4，10进制表示为4，是回文数；3的平方9，2进制表示为1001，是回文数；9046的平方81830116，16进制表示为4E0A0E4，是回文数。小X觉得要全列出来太难了，希望你帮帮他。
**输入格式**：第一行包含用一个空格隔开的两个整数 N, M。
**输出格式**：第一行包含一个整数，表示满足要求的整数个数。
**数据范围**：对于 30% 的数据，M=10；对于另外 30% 的数据，M=2；对于 100% 的数据，1≤N≤10000，2≤M≤16。
**样例输入**：
```
2 10
```
**样例输出**：
```
2
```
> 样例解释：1²=1（回文）、2²=4（回文），共 2 个。

## 题5  2ea8126d-31a0-4563-a9c6-0c4f1c904d97
**标题**：乐乐的数
**标签**：进制转换/位运算 ｜ **难度**：medium
**描述**：
乐乐最近喜欢研究回文数，假设一个数从左到右读跟从右到左读的结果是一样的，那么我们说这个数是一个回文数。如果一个数在十进制下是回文的，我们说这个数是一重回文数；如果在十进制和二进制下都是回文的，是二重回文数；在三种进制下是回文的，是三重回文数……现在用数字 0..9、字母 'A'..'Z' 分别代表数字 0..35（即 10 用 A 表示，11 用 B 表示……，35 用 Z 表示）。任意给出一个十进制数，乐乐想知道它在 2 至 36 进制里是多少重的回文数。
**输入格式**：输入只有一个 10 进制的整数 n (2<=n<=2000000000)。
**输出格式**：第一行为一个整数 m，表示 n 在 2 至 36 进制里有 m 种是回文的；接下来是 m 行，从小到大输出 n 在哪些进制下是回文的。
**样例输入**：
```
50
```
**样例输出**：
```
3
7
9
24
```
> 样例解释：50 对应的 7 进制数为 101，9 进制数为 55，24 进制数为 22，三种都是回文。
