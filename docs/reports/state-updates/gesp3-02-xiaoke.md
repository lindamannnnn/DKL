## 本课掌握的概念（儿童化语言）

- 往队伍中间**插人**：先让后面的人**从最后面开始**一个个往后退一格，空出位置新人再站进去；退反了方向会把人"踩没"（覆盖）。插完队伍人数 `n++`
- **删除**就是有人出列：从他后面开始**从前往后**一个个往前补一格，和插入方向正好相反；删完 `n--`
- 口诀：**插入从后往前移，删除从前往后移**
- **交换**两个数要像交换两杯水，拿个空杯 `tmp` 倒三次；偷懒用 `swap(a, b)` 一行搞定
- **逆序**用双指针 🦀：左指针站排头、右指针站排尾，交换后各走一步，碰到头就停（`while (l < r)`）
- **逆序对**：排前面的数比后面大就是一对；逆序对总数叫**逆序数**，排好序的数组逆序数是 0；用两层循环枚举每一对 `(i, j)` 数出来
- 会把"找最大值的位置"（上节课打擂台）和"插入"（本课）合起来用：在最大值后面插一个数

## 新暴露的易错点

- 插入/删除后容易忘 `n++` / `n--`（挑战 1 第一次就漏了 `n++`，最后输出少一个数）
- "在最大值**后面**插"翻译成代码是 maxPos+1，前后差一格容易错（课后题 4 第一次插到前面去了）
- 逆序循环条件 `l < r` 顺手写成 `l <= r`（结果虽对但多此一举）
- `pos`、`val` 这类英文缩写没人解释时只能靠猜——目前猜对了，但埋下隐患
