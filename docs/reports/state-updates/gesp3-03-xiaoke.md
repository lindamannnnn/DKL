## 本课掌握的概念

- 数组下标可以当"桶"用：`cnt[x]++` 表示"值 x 又出现一次"（计数数组核心思想）
- 计数数组必须清 0：写在 `main` 外面（全局）自动清 0，最省心
- 桶的数量按值域开：值最大是 V 就开 `cnt[V+1]`（下标 0~V）
- 值太大（上亿）数组开不下，计数法不适用（知道边界，但**不知道替代方法**）
- 扫桶输出：只输出 `cnt[v] > 0` 的（第一次做漏了，看提示后改正并记住）
- 票王 = 在桶上打擂台：`if (cnt[v] > maxC) { maxC = cnt[v]; ans = v; }`
- 并列取小编号的原理：从小编号往大扫 + 判断用 `>`，先当冠军的不被挤掉（自己推理得出，较牢固）
- 桶排序概念：从小到大倒桶，编号是几就输出几次，倒出来自动有序

## 新易错点

- 统计输出时容易忘记过滤 `cnt[v] > 0`，把没出现过的数也输出
- 值域含 0 时（如 0~19），习惯性从 1 号桶开始扫，漏掉 0 号桶
- 遇到"没有 n、固定个数"的输入格式会愣住，需要重读题面才能切换成固定次数循环
- `while (cnt[v]--)` 这种"自减当条件"的写法需要回忆 GESP1-15 的 `while (t--)` 才能看懂，不熟练
