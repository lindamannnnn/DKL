## 新易错点

- **桶大小规则没记住**：范围 1~100 会随手写 `cnt[100]`（检查点 2 答错），"最大值 + 1"完全没进脑子
- **忘记清 0**：挑战 1 在 main 里写 `int cnt[100];` 不初始化，全局数组的优势没记住
- **`>` 和 `>=` 乱用**：打擂台顺手写 `>=`，且挑战 2 样例无并列导致错误没暴露，留下错误认知
- **不读题的老毛病升级**：课后题 3 没有 n，直接把第一个数当 n，程序读 1 个数就结束，错了还怪题目
- 位置从 0 还是从 1 开始数会混；忘记"未找到输出 0"的边界要求
- 输出格式漏看：挑战 2 漏输出次数 maxC
