## 真正掌握的新知识点

- **滑动计数器套路**：`cur` 记当前连续几个、`maxL` 记历史最长；相同就 `cur++`，断开就 `cur = 1`；每步刷新 `maxL`
- **最长连续相同段**：能独立写出（挑战 1 回看 1 次后掌握，课后"连胜王"闭卷独立通过）
- **破纪录时顺手记录元素值**：`if (cur > maxL) { maxL = cur; ans = a[i]; }`，理解"并列时先出现的保留"（严格 `>`）
- **连续递增段**：条件改成 `a[i] == a[i-1] + 1`，套路不变；理解"改判断条件换题型"的思想
- **条件变形迁移（部分）**：能把 `==` 改成 `>`（温度统计员，靠样例纠错后改对）、改成值判断 `a[i]>=90`（评奖要求，需 1 次提示）

## 还不会 / 有漏洞

- **"连续 1"变形不牢**：cur 从 0 开始、只认一种值、断开清 0——是挑战 2 看答案学的，独立复现存疑（课件新授卡片未覆盖）
- **逐段输出（段压缩）不会**：段尾结算、循环结束后补输出最后一段（连胜统计 ❌）
- **右邻居比较 `a[i+1]` 未掌握**：浪尖数需提示（全课程首次出现）
- **局部数组 `a[0]` 是随机值这一点被课件错误说法干扰**：挑战 1 教师卡声称"`a[0]` 是 0"，与 GESP1-10 已学知识矛盾，需复测时确认没记住错误版本
