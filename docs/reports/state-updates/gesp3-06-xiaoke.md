## GESP3-06 字符数组 之后（真正掌握）

- `char a[] = "mike";` 是一排装字符的柜子，电脑自动在末尾加结束旗子 `'\0'`（ASCII 码 0），所以 n 个字母占 n+1 格
- `cout << a` 直接打印整个字符数组；`a[i]` 取单个字符；`(int)a[4]` 能看到旗子的编号 0
- 读入字符串两种方法：`cin >> s` 读到空格就停（读一个单词）；`cin.getline(s, 大小)` 读一整行（含空格）
- 遍历字符串的标准循环：`for (int i = 0; s[i] != '\0'; i++)`——碰到旗子就停
- 四个小助手：`strlen(s)` 数字符（**不含 `\0`**）、`strcat(a,b)` 接尾巴、`strcpy(a,b)` 整个抄入、`strcmp(a,b)` 比字典序（负 = a 小、0 = 相等、正 = a 大）
- `tolower`/`toupper` 大小写互转；`isupper`/`islower`/`isdigit` 判断字符身份
- 数组要比字符串多留格子：`char a[5] = "hello";` 是错的（要 6 格）；比赛习惯开大数组如 `char s[1005]`
- 能独立写出：统计一行中大写/小写/数字个数（getline + 三计数器）、strcmp 三路分支比大小、大小写互换、四类字符统计
- 倒序打印字符串：`for (int i = strlen(s)-1; i >= 0; i--) cout << s[i];`（闭卷需回看 strlen 说明 1 次，判 🟡）
