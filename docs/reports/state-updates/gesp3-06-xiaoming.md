## GESP3-06 字符数组 之后（真正掌握，带漏洞）

- `char a[] = "mike";` 末尾自动加旗子 `'\0'`，n 个字母占 n+1 格（CP2 答对，印象牢）
- `cin.getline(s, 大小)` 读含空格的整行——**是犯错后记住的**（挑战 1 用 `cin >> s` 丢了空格后的数字，改了才会）
- `tolower`/`toupper` 大小写互转（CP4、课后 2 闭卷对）
- `isupper`/`islower`/`isdigit` 判断字符身份，能配合计数器分类统计（课后 1 独立对）
- 遍历循环 `for (int i = 0; s[i] != '\0'; i++)` 会套用
- `strlen(s)` 数长度——**但"不含 `\0`"记不牢**（CP3 闭卷答错，把旗子也数进去了）
- `strcmp(a,b)` 比大小——**符号含义记反过一次**（挑战 2 闭卷错，翻教师卡才改对）
- 数组要多留格子的规则知道（小贴士），但与 strlen 的关系模糊

## 新增"还会困惑的点"

- `strlen` 到底数不数 `\0`（混淆点：旗子占格 vs strlen 不含旗子，两件事他会搅在一起）
- strcmp 返回值正负含义需要现查；"字典序"一词说不清
- 读题漏一半的毛病在字符串题上重现：挑战 1 漏看"可能含空格"、课后 3 漏看"大小写字母合并计数"（输出数错个数）
- 课后 5 用 `cout << strcmp()` 碰巧过样例（glibc 返回值恰为差值），**原理不懂**，逐字符比较的双出口循环写不出——这是侥幸得分，下一课遇到变式会翻车
- 倒序循环起点 `strlen(s)-1` 试错过一次（越界），需提示
