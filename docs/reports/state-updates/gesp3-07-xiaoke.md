# 状态更新片段：小柯 × GESP3-07（2026-07-21）

> 供合并进小柯知识状态文件使用；本片段不直接修改 state 文件。

## 本课掌握的新概念（闭卷验证过）

- `string` 类型：弹性袋子，不用预设长度，不用管 `\0`
- 拼接 `+` 与 `+=`（`s += "cd"`）
- 比较 `==`、`<`（字典序，与字符数组必须 strcmp 的规则区分清楚并默念过）
- `getline(cin, s)` 读整行 vs `cin >> s` 读单词（会用，但两种 getline 写法差异是死记的）
- `s.size()` 求长度（知道空格也算一个字符）
- `s[i]` 下标访问（从 0 开始）
- `s.find(t)` 找子串首位置；`string::npos` 判断未找到（`::` 当整体记号死记）
- `s.replace(起点, 个数, 新内容)`，新内容可长可短
- for + `tolower`/`toupper` 逐格大小写转换（string 版）
- find+replace 循环替换所有子串，`pos += n.size()` 跳过新内容防死循环（在提示一次后能独立复现，课后 5 闭卷 ✅）

## 新易错点

- string 直接 `<` 与字符数组必须 `strcmp` 两套规则并存，需防记混（本课已主动区分，后续复习需巩固）
- `s.find(o, pos)` 双参数形式和 while 条件内赋值写法是"模仿得来"，变式题可能卡壳
- "删除字符"用拼新串（`r += s[i]`）完成，尚不知道 `replace(pos,1,"")` 空串写法
