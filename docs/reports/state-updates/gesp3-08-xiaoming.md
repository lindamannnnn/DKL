## 新增"还会困惑的点"

- `cin.getline(s, 大小)` 和 `getline(cin, s)` 两种写法分不清，可能给 char 数组写 `getline(cin, s)` 造成编译错误
- while 条件里 `(pos = s.find(t, pos))` 的赋值式写法看不懂，只能照抄；独立写"找所有位置"仍有困难
- `pos += n.size()` 为什么不能用 `pos++` 半懂（闭卷写 pos++ 且因样例太弱没暴露）
- 题面陷阱反复中招：漏看"可能含空格"、位置 1 起点、"第一个出现的重复字符"歧义——本质是读题不耐心，非知识缺口
- 多空格分隔的单词计数（数空格+1 的错误直觉已纠正两遍，仍不扎实）
