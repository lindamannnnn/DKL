## GESP3-09 string 使用2 之后（真正掌握）

- `s.substr(起点, 个数)`：从起点下标（从 0 数）开始剪出指定个数的一段，原串不变
- `s.substr(起点)`：只写起点就从起点一直剪到末尾；起点超过长度会报错，别超界
- 题目说"第几个"（从 1 数）要换算成下标：起点 = `l - 1`，个数 = `r - l + 1`（个数会先写成 `r - l`，拿样例比划后能自纠）
- `reverse(s.begin(), s.end())`：整串倒车，`begin()` 车头、`end()` 车尾
- 回文 = 正着读倒着读一样的串；判断法：复制一份（`string rev = s;`）→ 倒车 → `s == rev` 比较（理解"必须复制"的原因：reverse 会真的改变原串）
- 忽略大小写判回文：先 for 循环 `tolower` 统一变小写，再复制倒车比较（结合 07 课已学）
- 能独立写出：按 1 基区间截取子串、忽略大小写回文判断（YES/NO）、去掉结尾标记符（`substr(0, size-1)`）后判回文（TRUE/FALSE）、大小写字母分离后分别反向/正向拼接
- 一次定义多个 string 变量（`string s = "racecar", rev = s;`）能看懂会用
