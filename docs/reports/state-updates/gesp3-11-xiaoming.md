## GESP3-11 枚举算法 之后（真正掌握，比小柯少且有漏洞）

- **枚举三要素**（本课唯一被他吸收的增量）：对象、范围、条件——能复述，写题前会不会真用存疑
- 边界意识有概念但不牢固：知道"31×31=961 所以试到 31"的推理，但 checkpoint"循环几次"第一遍仍靠猜（猜错）
- 水仙花数、百钱百鸡框架记得（GESP2 老本），但细节两处漏洞复现：
  - 十位拆分又写成 `n % 10 / 10`（GESP2 易错点复发，看示例才改回 `n / 10 % 10`）
  - 百钱百鸡漏掉 `z % 3 == 0` 和"从 1 开始"（至少 1 只）
- 下载电影：枚举起点 + 内层求和的框架能写，平均数忘转 double（`sum / m` 整除 WA，提示后改 `(double)`）
- **未掌握**：桶去重（邮票组合）、字符串→整数转换（趣味填空）、互异检查（既生瑜何生亮）——三个迁移点全垮
