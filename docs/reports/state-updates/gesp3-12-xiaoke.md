## GESP3-12 模拟算法 之后（真正掌握）

- **模拟算法核心概念**：模拟 = 程序当演员，题目规则是剧本；和枚举的区别能说清（枚举试所有可能，模拟照规则一步步做）
- **模拟三要素**：状态（现在什么样，用变量记）、转移（每步怎么变）、终止（什么时候停）；能把具体代码归类（`pos += 3` 是转移）
- **一维过程模拟能独立写**：蜗牛爬竿（含"到顶当晚不滑"的 `if (pos < h)` 守卫）闭卷一次写对，0 处差异
- **按指令走路 + 边界**：R/L 一维移动、U/D/L/R 二维网格撞墙不动；`for (char c : s)` 遍历指令、`a[(c-1)%3+1]` 取余轮转下标（发牌）能用
- 数组当"多个状态"的容器：发牌计数、轮流分配

## 新增"还会困惑的点"

- `x += (c == 'R' ? 1 : -1);` 三目运算符嵌进复合赋值，一行两个知识点，要拆开才懂；更习惯挑战 2 的"四个方向四句 if"
- 机器人网格方向：U 是 `x--`（行号越小越靠上）第一遍会写反；D 的边界 `x < n` 和 `x <= n` 要想一下（动之前还没加，用 `<`）
- 跨年/跨月的长链模拟（黑色星期五）步数一多就容易漏步，闰年 2 月特判需要提示
- 字符串逐位拼整数（`cur = cur*10 + (c-'0')`）会忘掉"结尾补加最后一次 cur"（GESP3-11 的脆弱链条本课复现一次）
- 三重枚举里"另外两个不同的数"这种约束，要提示一次才想通 i≠j 就够
