## GESP3-15 数据编码 之后（真正掌握）

- **符号位**：8 位机器数最左边一位是符号位，0 正 1 负，剩 7 位表数值
- **机器数与真值**：`10000101` 这串 0/1 是机器数，它表示的 -5 是真值（靠自己举例想通，定义句本身没读懂）
- **原码**：符号位 + 绝对值的二进制；知道两个缺点（0 有两种写法、直接加法会算错——后者只记住结论，没见过错例）
- **反码**：负数符号位不动、其余逐位取反；能独立推导（如 -5 → `11111010`）
- **补码规则**：负数补码 = 反码 + 1；正数三码合一
- **补码的直觉**：亲手列竖式验算过 +5 与 -5 补码相加溢出成 `00000000`；知道 int 范围 -2147483648~2147483647 与 32 位补码的关系；知道 8 位补码 -128~127 负数多一个的原因
- **补码转真值两条路线**：①小贴士口诀"取反再加 1 得绝对值"（自己闭卷走通的路线）②后 7 位求值减 128（对答案时学的，更短）
- **溢出**：最大值 +1 会绕回最小值（靠 demo 注释理解，能复述现象）
