# 状态更新片段：小明 × GESP3-15 数据编码（2026-07-21 评测后）

## GESP3-15 数据编码 之后（真正掌握）

- **符号位**：最高位 0 正 1 负（掌握最牢的一条，一句话规则合他胃口）
- **原码**：符号位 + 绝对值二进制，能独立推导（checkpoint2 有推导过程）
- **反码**：负数符号位不动其余取反，能推导，但自认"只对了前 3 位后面扫过去的"——逐位严谨性存疑
- **补码 = 反码 + 1 的口诀**：会背， checkpoint4 在草稿纸上做过一次一步进位（`11111001+1`）
- **int 最大值 +1 会变负数**：记住了"溢出绕回"这个现象（觉得好笑所以记住了）

## 新增"还会困惑的点"（比小柯更多、更空心）

- **补码知识整体是空心的**：会背"反码+1"，但"为什么补码相加得 0"从未验算；进位循环页 9 直接跳过 demo，挑战 2 闭卷两次写不出（把补码写成了反码），最终照抄示例——**不能记为掌握**
- **"减 128"捷径**：挑战 1 靠看示例才知道，不理解为什么是 128
- **checkpoint 排除法依赖**：checkpoint5 自认靠排除法选对，"负数为什么多一个"解释不出来——选择题全对造成"我都会"的错觉，挑战课才爆雷
- **"真值""机器数"**：页 3 扫过没懂，挑战 1 题干被迫回翻
- **长题面劝退**：课后题 4（二进制折半交换）读两行就放弃；紧凑代码（挑战 2 demo 一行三子句）直接跳过
- **n=0 边界**（2进制中的0和1）：while 拆位循环对 0 不执行的陷阱，没想到
