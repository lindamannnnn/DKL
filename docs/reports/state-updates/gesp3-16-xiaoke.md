## GESP3-16 位运算 之后（真正掌握）

- **按位与 `&`**：两位都是 1 才是 1；`n & 1` 取末位判奇偶（比 `n % 2` 快）
- **按位或 `|`**：有一个 1 就是 1；**按位异或 `^`**：不同为 1 相同为 0（"找不同"）
- **异或三性质**：`a^a=0`、`a^0=a`、顺序随便换 → "消消乐"：一串数全部异或，成对的消掉，落单的露出来（挑战 2 独立写出 ✅）
- **左移/右移**：`n << k` = n×2ᵏ，`n >> k` = n÷2ᵏ（向下取整）；理解了"二进制左移像十进制末尾添 0"
- **位统计套路**（🟡 半独立）：`while (n > 0) { cnt += n & 1; n >>= 1; }`——if 版能独立写，`+=` 直加和 `>>=` 是看示例学的
- **位运算优先级很低**：`n & 1 == 1` 会先算 `==`，写位运算必加括号
- 课后题迁移：A^B 的 1 的个数 = 两数二进制位差异数（A变B，🟡 连接想到了但写法需瞄一眼）；进制转换+long long 复习稳定 ✅

## 新增"还会困惑的点"

- **`~` 按位取反完全没懂**：课件只有一行 `~n = -(n+1)`，无竖式无示例，取反为什么变负数想不通（卡点 120 秒）
- **"时钟周期"**（故事页）无解释，靠语境忽略
- 字符串大数位运算的对齐补 0 / 去前导零细节（bignum 题）不熟练，独立写会漏
- `~` 没学会导致课程目标"六种位运算"在他笔记里可能记成"五种 + 一个谜"
