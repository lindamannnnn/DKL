## GESP3-17 练习课：进制·编码·位运算 之后（真正掌握）

- **任意进制转换（十进制→d 进制，2≤d≤16）**：短除法通用版，`g = "0123456789ABCDEF"` 查表 + `r = g[n % d] + r` 余数前拼，独立写出 ✅（含 n==0 特判的意识）
- **二进制→十进制滚动乘加**：`r = r * 2 + (c - '0')` 默写级 ✅；知道长串要用 `long long`
- **补码推导链**（🟡 半独立）：绝对值 7 位二进制 → 符号位 → 取反 → 加 1 的规则记得牢，但"加 1 进位"的循环写法仍需瞄一眼示例（本课唯一卡点，90 秒）
- **位统计与异或消消乐**：`while (n>0) { cnt += n & 1; n >>= 1; }`、`ans ^= x` 默写级 ✅（但本课两题与 16 课原题相同，未检验迁移）
- **大数进制转换意识**：20 位八进制主动换 `long long` ✅
- **多组数据 + 前缀判断 + 小写十六进制字母**：能结合样例调试通过（🟡），`c - 'a' + 10` 从 ASCII 大小写差 32 迁移成功

## 新增"还会困惑的点"

- **分组不整除的处理**：100 位二进制转八进制，首组不足 3 位时"左侧补零"是自己看样例悟的，课程没教，下次遇到可能还想不起来
- **去前导零**：十六进制转二进制结果首组的 0 要去掉，第一次会漏
- **补码"加 1"进位循环**：规则懂、代码写不顺，需要再练 1~2 道同类题固化
- 高密度单行 for（`for (int t = -n, i = 0; i < 7; i++, t /= 2)`）要读三遍才能拆开
