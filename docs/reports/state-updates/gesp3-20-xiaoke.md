### 本课真正掌握（新增/巩固）

- 真题节奏：单选 4+4、判断 6、编程 2 的完整卷面结构（第二套 GESP3 真题）
- 机器数/真值综合判断：同一串二进制按原码/无符号解释得不同值（`10001101` = -13 或 141）
- 字符位运算加密：`'G'|6`、`'S'^0`、`'P'+2` 逐位手算
- `sizeof` vs `strlen` 实战辨析（含 `\0`、数组越界危险选项识别）
- `~n = -n - 1` 秒答（16 课公式，本课验证熟练）
- 字符当数组大小：`int b['&']` 合法（字符自动转 ASCII）——由 04 课"字符即数字"推导得出
- 进制判断题：`max <= '1'/'7'/'9'/'F'` 方向推理 + `=`/`==` 陷阱排除
- 补码快捷算法验证：用"反码+1"验证"从右扫第一个 1 后左全取反"等价
- 编程：密码本查表加密（数组开大 20010）、字符转换 ±32（`char()` 外套记得穿）
- 课后：字母桶统计、字符遍历替换、平方回文（短除法转 M 进制 + 回文）、多重回文（2~36 进制，先存后打；注意 2×10⁹ 贴近 int 上限）

### 新增易错点
