## 四、总结

这次自测我一共做了 268 道题，对了 222 道，错了 46 道，正确率 82.8%。我最大的问题是：

1. **看题不仔细**：经常把“能”看成“不能”，把“不是”看成“是”，导致选反。
2. **`printf` 格式搞混**：`%d`、`%2d`、`%02d` 分不清，花括号里原样输出的地方也搞错。
3. **整数除法忘干净**：一遇到 `a/b` 就先按小数除，忘记 C++ 里整数会丢掉小数。
4. **循环控制绕晕**：`break`、`continue` 搭配 `if`，要数好几遍，容易漏算。
5. **题目太长没耐心**：看到一大段文字就不想读，后面的判断题直接空着。

以后我要：先把题目里的关键词圈出来，做 `printf` 题时一个一个 `%` 对参数，算除法时先看是不是 `int`。继续加油！
