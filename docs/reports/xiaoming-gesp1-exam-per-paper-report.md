## 六、总结

本次独立测试共完成 11 套 GESP 一级真题，平均每套正确率 **74.1%**。

作为刚学完 18 节 C++ 基础课的五年级学生，我在大部分基础语法题（如变量定义、
输入输出、简单循环）上表现较好，但在以下方面容易出错：

1. **整数除法与类型转换**：容易忽略 `int / int` 会丢掉小数，以及 `0.0 + a / b` 中
   的运算顺序。
2. **逻辑与关系表达式**：如 `a == b == 0`、`3 < X < 5`、`!(a || b)` 等复合判断
   容易混淆。
3. **`break`/`continue` 与循环边界**：对循环终止条件、跳过语句后的执行路径判断
   不够稳。
4. **计算机常识与历史**：部分题目涉及硬件、操作系统、名人贡献等课外知识，课程
   里没重点讲，我常常靠猜。
5. **代码细节**：如变量初始化、`sum` 未赋值、`switch` 中 `break` 遗漏等，
   容易因为粗心而错。

图片题或代码缺失的题目我直接标记为未作答，没有计入错误。后续复习时，
我会重点练习整数运算、逻辑表达式和循环控制这三块。
