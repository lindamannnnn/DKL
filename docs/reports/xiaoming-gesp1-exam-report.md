## 二、整体感受（小明第一人称）

哎，做完这11套题，我感觉脑袋都要炸了。一开始还行，前面几道什么键盘鼠标、int double我还勉强能蒙对。但越往后越难受，代码越来越长，我看得眼睛都花了。

有好多题我明明知道一点点，比如循环、if、变量名不能数字开头，但是题目稍微拐个弯我就不会了。还有那种什么`a%4==2`判断偶数的，我乍一看觉得对，仔细一想又好像不对，最后就凭感觉选了。

最烦的是那些时事题，什么DeepSeek、哪吒2、诺贝尔奖、鸿蒙，我根本不知道，只能瞎猜。还有历史题，ENIAC、冯·诺依曼、王选，这些名字我听都没听过。

做到后面我真的坐不住，想玩手机。有几道题我直接看选项哪个顺眼就选哪个，根本不想算了。感觉编程比我想象的难多了，我是不是学不会啊……不过有几道我做对了，还是有点开心的，比如那种`i*=2`输出1248的，我一看就知道了。

总的来说，我觉得我还需要多练习，特别是循环次数、运算符优先级、printf格式这些，老是错。

4. **坐不住**：题目一长就不想看了，比如带代码块的题，我看到超过5行就开始烦躁，随便选个答案。
