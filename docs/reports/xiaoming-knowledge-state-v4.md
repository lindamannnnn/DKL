## 课前（完全零基础）

- 电脑可以玩游戏、看视频
- "编程"好像是用电脑做出东西来
- 代码里有很多英文和符号

---

## 学完 01-走进 C++ 后

- 每个 C++ 程序都有固定骨架（五件套）
- `#include <iostream>` 是打开输入输出工具箱
- `using namespace std;` 先照抄，以后懂
- `int main()` 是程序入口，程序从这里开始执行
- `cout << ... << endl;` 可以让电脑"说话"
- `cin >> ...;` 可以让电脑"听"键盘输入
- `int` 是用来装整数的变量盒子
- `=` 在 C++ 里是把右边的值放进左边盒子
- 语句末尾通常要加分号 `;`
- 大括号 `{}` 要成对出现
- `+ - * /` 可以做四则运算，但整数除法会丢掉小数

---

## 学完 02-整数运算 后

- 变量名只能由字母、数字、下划线组成，不能以数字开头
- 不能用 `int`、`return` 这些 C++ 已经占用的词当变量名
- 常量就是固定不变的数，比如 `100`、`3.14`
- `long long` 是用来装超大整数的盒子
- `%` 是取余运算符，得到除法剩下的部分
- `n % 10` 可以得到一个整数的个位
- `n / 10` 可以去掉一个整数的个位
- 拆三位数需要 `%10` 和 `/10` 配合，但独立写还容易搞反

---

## 学完 03-小数运算 后

- `int` 盒子装不下小数，装进去会变成整数
- `double` 是用来装小数的盒子
- `fixed << setprecision(n)` 可以保留 n 位小数
- 用 `fixed`/`setprecision` 时必须加 `#include <iomanip>`
- `(double)` 像给整数穿小数外套，能让整数除法变成小数除法
- 注释是写给人看的，`//` 后面的话电脑会忽略

---

## 学完 04-练习课：计算小达人 后

- 复习了 `cin`、`cout`、整数运算、小数运算
- 算平均分时不能写 `total / 3`，要写 `total / 3.0` 或转成 `double`
- 做计算题要先看清要整数还是小数、保留几位

---

## 学完 05-分支入门 后

- `bool` 是一种只有 `true`/`false` 两种值的盒子，输出显示为 1/0
- `>` `<` `>=` `<=` `==` `!=` 都是比较运算符
- 判断相等必须写 `==`，写 `=` 会变成赋值
- `if (条件) { ... }`：条件成立才执行里面
- `if-else`：条件成立走 `if`，不成立走 `else`
- `n % 2 == 0` 可以判断偶数
- `n % 3 == 0` 可以判断能否被 3 整除

---

## 学完 06-双路分支 后

- `if-else` 二选一，两个大括号里只会执行一个
- 大括号里还能再写 `if`，这叫嵌套
- `? :` 三目运算符是 `if-else` 的简写，能二选一给值

---

## 学完 07-多路分支 后

- `if-else if-else` 是多路分支，只会执行其中一个
- 多分支条件要从高到低排，不然会被"截胡"
- `&&` 表示"并且"，两边都要对
- `||` 表示"或者"，有一个对就对
- `!` 表示"不是"，能把结果反过来
- 不确定优先级时就加小括号 `()`

---

## 学完 08-练习课：分支大冒险 后

- 复习了单分支、双分支、多分支
- 复习了 `&&` 的用法
- 分支顺序很重要，要从高到低判断

---

## 学完 09-字符类型与 switch 后

- `char` 是装一个字符的盒子
- 一个字符要用单引号 `' '`，一句话才用双引号 `" "`
- `'A'`~`'Z'` 是大写，`'a'`~`'z'` 是小写，`'0'`~`'9'` 是数字字符
- 大写转小写要加 32，小写转大写要减 32
- `switch` 适合多选一，根据变量值走不同 `case`
- `case` 末尾一般要加 `break`，不然会"穿透"
- `default` 是上面都不匹配时执行

---

## 学完 10-for 循环 后

- `for` 循环有三个部分：从几开始、继续条件、每次变化
- `i++` 就是 `i = i + 1`
- `i--` 就是 `i = i - 1`
- `for` 可以倒着数
- `for` 后面不能加分号，否则循环体为空
- 循环里可以套 `if` 挑出符合条件的数
- `sum = sum + i` 是累加，意思是把原来的 sum 加上 i 再存回去

---

## 学完 11-循环控制 后

- `break` 会立刻结束整个循环
- `continue` 会跳过本次循环，继续下一次
- `break` 像退出跑道，`continue` 像这一圈不跑完直接下一圈
- 判断质数时可以用 `bool` 做标志位，找到反例就 `break`
- `for(;;)` 中间空着表示一直循环，必须配合 `break`

---

## 学完 12-练习课：循环闯关 后

- 复习了 `for` 循环、`break`、`continue`
- 死循环可能是因为忘了让变量变化
- 空条件的 `for` 要配合 `break` 使用

---

## 学完 13-求和计数 后

- 求和时 `sum` 要从 0 开始
- 求平均要用 总和 ÷ 个数，记得转 `double`
- 计数时 `count` 从 0 开始，满足条件就 `count++`
- 找最大值时先把第一个数当"老大"，看到更大的就换人
- 找最小值时先把第一个数当最小，看到更小的就换人
- 求因子和可以用循环从 1 试到 n

---

## 学完 14-while 循环 后

- `while (条件)` 是先判断、后执行
- 不知道循环次数时用 `while`，知道次数时用 `for`
- `do-while` 至少执行一次
- 读入 0 才停止时，要先读一个数再进入循环
- 用 `while` 也能拆数字：%10 取个位，/10 去掉个位
- `+=` `-=` `*=` `/=` `%=` 是复合赋值，是简写

---

## 学完 15-短除法 后

- 用 `while (t > 0)` 配合 `t--` 可以循环 t 次
- 短除法拆数字：`n % 10` 取个位，`n = n / 10` 去掉个位
- 数位求和：sum 从 0 起，取一个加一次
- 数位乘积：product 从 1 起，取一个乘一次
- 找数字时可以用 `bool found = false` 做标志旗，找到就变 `true` 并 `break`
- 统计次数时用 `count++`，每位都检查

---

## 学完 16-练习课：数字拆解与统计 后

- 复习了求和、计数、最大最小值
- 复习了 `while` 循环拆数字
- 乘积初始必须写 1，不能写 0

---

## 学完 17-C 风格输入输出 后

- `printf` 和 `cout` 一样用来输出
- `scanf` 和 `cin` 一样用来输入
- 用 `printf`/`scanf` 要加 `#include <cstdio>`
- `%d` 填整数，`%f` 填输出小数，`%lf` 填读入小数
- `scanf` 里变量前面必须加 `&`
- `%02d` 可以补零，`%.2f` 可以保留 2 位小数
