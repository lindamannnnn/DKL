## 课程 01：走进 C++

真正掌握的内容：
- C++ 程序像个"小房子"，有固定骨架
- `#include <iostream>` 是工具箱，要先打开才能用 `cin` / `cout`
- `int main()` 是大门，程序从这里开始
- `cout << ...` 是小喇叭，能让电脑在屏幕上"说话"
- 文字要用双引号 `""` 包起来
- `cin >> ...` 是小耳朵，能让电脑"听"键盘输入
- `int` 是装整数的盒子，`=` 是把右边的数放进盒子里
- 很多语句末尾要加分号 `;`
- `+ - * /` 能算整数，但 `/` 会吃掉小数

---

## 课程 02：整数运算

真正掌握的内容：
- CPU 像大脑、内存像黑板、硬盘像书柜（大概知道，容易忘）
- 变量名只能由字母、数字、下划线组成，不能以数字开头
- 不能用 `int`、`return` 这些关键字当变量名
- 整数除以整数，小数部分会被丢掉（`5 / 2 = 2`）
- 数字超过 21 亿要用 `long long`
- `%` 是取余，`17 % 5 = 2`
- `% 10` 能取个位，`/ 10` 能去掉个位
- 拆三位数：先 `%10` 取个位，再 `/10` 去掉，反复做

---

## 课程 03：小数运算

真正掌握的内容：
- `int` 装不下小数，`double` 能装小数
- 保留小数要加 `#include <iomanip>`
- `fixed << setprecision(n)` 能保留 n 位小数
- 整数变小数可以给整数穿 `(double)` 外套：`(double)5 / 2 = 2.5`
- 四舍五入和数学课差不多
- 注释是给人看的，`//` 是单行注释

---

## 课程 04：练习课：计算小达人

真正掌握的内容：
- 复习了 `cin`、`cout`、整数运算、小数运算
- 算平均分要记得把其中一个数变成小数，不然小数会被吃掉
- 做题前要仔细看题目要求保留几位小数、要不要单位换算

（本节没有全新的独立概念，都是综合应用）

---

## 课程 05：分支入门

真正掌握的内容：
- `bool` 是只能装 `true`/`false` 的盒子，输出时显示 1/0
- `>` `<` `>=` `<=` `==` `!=` 是比较大小的符号
- 判断相等要写两个等号 `==`，一个等号 `=` 是"放进去"
- `if (条件) { ... }` 就像一扇门，条件成立才进去
- `if-else` 是二选一
- `n % 2 == 0` 能判断偶数，`n % b == 0` 能判断倍数

---

## 课程 06：双路分支

真正掌握的内容：
- `if-else` 两个大括号里只会执行一个
- 大括号里还能再写 `if`，这叫嵌套（但两层以上容易晕）
- `? :` 是三目运算符，能简单二选一给一个值

---

## 课程 07：多路分支

真正掌握的内容：
- `if - else if - else` 像排队上车，找到一个符合条件的就下车
- `&&` 是"并且"，两边都要对
- `||` 是"或者"，有一个对就对
- `!` 是"不是"，能把结果反过来
- 多分支条件要从高到低排，不然会被"截胡"
- 复杂条件就加小括号，小括号里的先算

---

## 课程 08：练习课：分支大冒险

真正掌握的内容：
- 复习了单分支、双分支、多分支
- 复习了 `==` 和 `=` 的区别
- 复习了 `&&` 的用法
- 多分支写等级判断更熟了

（本节没有全新的独立概念）

---

## 课程 09：字符类型与 switch

真正掌握的内容：
- `char` 是装一个字符的盒子，字符要用单引号 `' '` 包起来
- 双引号 `""` 是一句话，不能装进 `char`
- 每个字符在电脑里有一个编号，叫 ASCII
- `'A'` 编号 65，`'a'` 编号 97，差 32
- 大写转小写要加 32，小写转大写要减 32
- `switch` 适合判断"等于某个固定值"
- `case` 是每一种可能的值，`break` 是停下，`default` 是都不匹配时执行

---

## 课程 10：for 循环

真正掌握的内容：
- `for` 循环有三部分：从几开始、继续条件、每次变化
- `i++` 就是 `i = i + 1`，`i--` 就是 `i = i - 1`
- `for` 可以正着数，也可以倒着数
- `for` 后面不能加分号，否则循环体就空了
- 循环里可以用 `if` 挑符合条件的数
- 累加要先准备一个 `sum = 0` 的桶，每次把数丢进去

---

## 课程 11：循环控制

真正掌握的内容：
- `break` 是直接结束整个循环
- `continue` 是跳过本次，继续下一次
- 用 `bool` 做标志位可以记录"有没有找到"
- 质数是只能被 1 和自己整除的数
- 判断质数可以试到 `i * i <= n`，不用试到 `n-1`
- `for` 中间条件空着会一直循环，要配合 `break` 用

---

## 课程 12：练习课：循环闯关

真正掌握的内容：
- 复习了 `for`、`break`、`continue`
- 用 `continue` 跳过偶数输出奇数
- 用空条件 `for` + `break` 找第一个满足条件的数

（本节没有全新的独立概念）

---

## 课程 13：求和计数

真正掌握的内容：
- 先输入个数 `n`，再用循环一次次读数求和
- 求和时 `sum` 从 0 开始
- 求平均要用 `(double)sum / n`，不然会丢小数
- 计数时 `count` 从 0 开始，满足条件就 `count++`
- 找最大最小值时，先把第一个数当老大/最小，后面看到更大/更小的就换

---

## 课程 14：while 循环

真正掌握的内容：
- `while (条件)` 是先判断条件，条件成立才执行
- `while` 适合"不知道循环几次"的情况
- `do-while` 先执行一次再判断，所以至少执行一次
- `while` 里一定要记得让变量变化，不然会死循环
- 输入 0 才停止的题：先读一个数，不是 0 就进入循环，循环里再读下一个
- `+=` `-=` `*=` `/=` `%=` 是简写，`sum += x` 就是 `sum = sum + x`

---

## 课程 15：短除法

真正掌握的内容：
- `while (t--)` 能循环 t 次，和 `while (t > 0) { ... t--; }` 效果一样
- 用 `while (n > 0)` 配合 `%10` 和 `/10` 可以拆数字
- 数位和：`sum = 0`，每次加 `n % 10`
- 数位积：`product = 1`，每次乘 `n % 10`（不能从 0 开始）
- 找数字：用 `bool found` 做标志，找到了就 `break`
- 统计次数：用 `count`，等于目标就 `count++`

---

真正掌握的内容：
- 复习了求和、计数、最大最小值
- 复习了 `while` 拆数字
- 拆位求和更熟了

（本节没有全新的独立概念）

## 课程 17：C 风格输入输出

真正掌握的内容：
- `printf` / `scanf` 需要 `#include <cstdio>`
- `printf` 像填空题，`%d` 填整数，`%f` 填小数
- `scanf` 读数时变量前面要加 `&`
- `scanf` 读 `double` 用 `%lf`，`printf` 输出 `double` 用 `%f`
- `%05d` 可以补零，`%.2f` 可以保留 2 位小数

---

- 排名补零用 `printf("%03d", n)`
- 小写转大写用 `ch - 32`
