## 卡片：先认识键盘上的符号

<!-- card type:teacher -->
写 C++ 会用到一些特殊符号，先在键盘上找到它们：

| 符号 | 名字 | 在键盘哪 | 这节课用吗？ |
|------|------|----------|--------------|
| `#` | 井号 | 数字 3 上面，按 Shift+3 | ✅ 要用 |
| `(` `)` | 小括号 | 数字 9 和 0 上面 | ✅ 要用 |
| `{` `}` | 大括号 | 字母 P 右边，按 Shift+[ 或 Shift+] | ✅ 要用 |
| `;` | 分号 | 字母 L 右边 | ✅ 要用 |
| `"` | 双引号 | 回车键左边，按 Shift+' | ✅ 要用 |
| `<` `>` | 小于/大于 | 逗号句号旁边，按 Shift+逗号/句号 | ✅ 要用 |

先不用背，用到的时候回来查 🔍

## 卡片：程序是一座小房子

<!-- card type:teacher -->
每个 C++ 程序都有固定的骨架：

- 🧰 `#include <iostream>` —— 打开输入输出工具箱
- 🔮 `using namespace std;` —— 一句魔法咒语，每次写程序都带上它（具体原因以后告诉你）
- 🚪 `int main()` —— 大门，程序从这里开始

> 💡 **函数**就像一段有名字的小程序。`main` 是一个特殊的函数，电脑看到 `main` 就知道"从这里开始执行"。
- 📢 `cout << ...` —— 小喇叭，用来输出
- ✋ `return 0;` —— 说"我做完啦，一切顺利！"
  > 💡 写 `0` 表示"一切顺利"，就像交卷时老师点头说"没问题"。写别的数字，电脑会以为出错了。
<!-- end-card -->

## 卡片 1：创建空盒子（声明）

<!-- card type:teacher -->
第一步：先创建一个空盒子，并贴上标签 `int`。

```cpp
int age;
```

- `int` = 这个盒子只能装**整数**
- `age` = 盒子的名字
- `;` = 这句话说完了（小虫子不能少 🦟）
<!-- end-card -->

## 卡片 2：把东西装进盒子（赋值）

<!-- card type:teacher -->
第二步：把数字 10 放进 `age` 这个盒子里。

```cpp

```

⚠️ 这里的 `=` 不是"等于"，是"放进去"的意思！

## 卡片 3：创建同时装好（初始化）

<!-- card type:teacher -->
也可以一步完成：创建盒子的同时，就把东西放进去。


这叫**初始化**，是最常用的写法。

## 卡片：让电脑听你说话

<!-- card type:teacher -->
👂 `cin` 是小耳朵，让电脑听你输入。

📢 `cout` 是小喇叭，让电脑说话。

> 💡 `cin >> age` 里的 `>>` 像两个小箭头，**朝里指**，表示"把键盘上的数字装进 age 这个盒子里"。
>
> 记住口诀：**cin 朝里装，cout 朝外喊**。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int age;
    cin >> age;
    cout << "你今年 " << age << " 岁啦！" << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：五种算术运算

<!-- card type:teacher -->
C++ 里有 5 种基本运算：

- ➕ `+` 加
- ➖ `-` 减
- ✖️ `*` 乘
- ➗ `/` 除
- 🔄 `%` 取余
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 12;
    int b = 5;
    cout << a + b << endl;
    cout << a - b << endl;
    cout << a * b << endl;
    cout << a / b << endl;
    cout << a % b << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 2：计算总分

<!-- card type:computer -->
🖥️ 小明语文 95 分，数学 98 分，英语 92 分。请计算总分和平均分。
<!-- end-card -->

> ⚠️ 小提醒：`total / 3` 是**整数除法**。如果除不尽，电脑会先把小数部分丢掉。比如 `5 / 2` 结果是 `2`，不是 `2.5`。

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int chinese = 95;
    int math = 98;
    int english = 92;
    int total = chinese + math + english;
    cout << "总分：" << total << endl;
    cout << "平均分：" << total / 3 << endl;
    return 0;
}
```
<!-- end-demo -->

## 小贴士：黑框框不见了

<!-- hint -->
如果运行后黑框框一闪而过，可以在 `return 0;` 前面加一行：

```cpp
system("pause");
```

**只需要抄这一行，放在 `return 0;` 的上面**：

```cpp
system("pause");
return 0;
```

这样黑框框会等你按任意键再关闭（Windows + Dev-C++ 有效）。
