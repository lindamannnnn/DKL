## 卡片：计算机的四个小伙伴

<!-- card type:teacher -->
🧑‍🏫 计算机就像一个小机器人，有四个重要的小伙伴：

- 🧠 **CPU**：大脑，负责思考计算
- 📝 **内存**：书桌，临时放正在用的东西
- 🏚️ **硬盘**：仓库，长期保存文件
- 👀👂 **输入输出设备**：眼睛耳朵嘴巴，让我们和电脑交流

> 💡 比如你算 `12 + 28`：眼睛看到题目（输入设备）→ 大脑计算（CPU）→ 草稿纸记下步骤（内存）→ 把答案写到作业本上（输出设备）→ 作业本保存很久（硬盘）。
<!-- end-card -->

## 卡片：常量是不会变的数

<!-- card type:teacher -->
📦 上节课我们学了变量，它的值可以改变。

**常量**就是固定不变的数，比如 `10`、`100`、`2024`。

```cpp
cout << 100 << endl;   // 100 是常量，永远不会变
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 365 << endl;     // 常量：一年 365 天
    cout << 24 << endl;      // 常量：一天 24 小时
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->

## 卡片：表达式就是算式

<!-- card type:teacher -->
➕ **表达式**就是会算出结果的算式。算的时候和数学课一样：

1. 先算 **乘 `*`、除 `/、取余 `%`**
2. 再算 **加 `+`、减 `-`**
3. 有 **小括号 `()`** 就先算括号里的

```cpp
10 + 5              // 结果是 15
2 + 3 * 4           // 先算 3*4=12，再算 2+12=14
(2 + 3) * 4         // 先算括号 2+3=5，再算 5*4=20
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 3;
    cout << a + b * 2 << endl;    // 先算 b*2=6，再算 a+6=16
    cout << (a + b) * 2 << endl;  // 先算 a+b=13，再算 13*2=26
    return 0;
}
```
<!-- end-demo -->

## 卡片：整数盒子也有大小

<!-- card type:teacher -->
📦 装整数的盒子有不同大小：

- `int`：最常用的整数盒子，能装约 -21亿 到 21亿
- `long long`：更大的整数盒子，能装非常大的数

小学里 `int` 基本够用，数字特别大时才用 `long long`。

> 💡 数字后面加 `LL`，就像给数字贴一个小标签，告诉电脑"这是 long long 类型的数"。
> 
> 💡 `short` 是更小的整数盒子，小学里基本不用，知道有它就行。
<!-- end-card -->

---

## 卡片：什么时候需要大盒子？

<!-- card type:teacher -->
🌍 生活中有些数字很大，会超过 21 亿：

- 地球到太阳的距离：约 149600000000 米
- 一年的秒数：约 31536000 秒（大约 3000 万秒）
- 中国人口：约 1400000000 人

这些数 `int` 装不下，要用 `long long`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 1000000;                     // 一百万，int 能装下
    long long b = 1234567890123LL;       // 超过 21 亿，要用 long long
    cout << a << " " << b << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：整数除法会吃掉小数

<!-- card type:teacher -->
🍰 `int` 盒子里只能装整数。所以整数除以整数，小数部分会被"吃掉"。

```cpp
5 / 2   // 结果是 2，不是 2.5
7 / 3   // 结果是 2，不是 2.333...
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 5 / 2 << endl;   // 输出 2
    cout << 7 / 3 << endl;   // 输出 2
    cout << 10 / 4 << endl;  // 输出 2
    return 0;
}
```
<!-- end-demo -->

## 卡片：% 是取余运算符

<!-- card type:teacher -->
🍬 `%` 表示取余数，就是除法剩下的部分。

```cpp
5 % 2   // 5 除以 2 商 2 余 1，结果是 1
10 % 3  // 10 除以 3 商 3 余 1，结果是 1
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 5 % 2 << endl;    // 输出 1
    cout << 10 % 3 << endl;   // 输出 1
    cout << 8 % 2 << endl;    // 输出 0
    return 0;
}
```
<!-- end-demo -->

## 卡片：拆出每一位

<!-- card type:teacher -->
🍭 反复做 `% 10` 和 `/ 10`，就能把每一位数字拆出来。

```cpp
int n = 1234;
// 个位：n % 10 = 4
// 然后 n = n / 10，变成 123
// 十位：n % 10 = 3
// ...
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 1234;
    cout << "个位：" << n % 10 << endl;  // 4
    n = n / 10;
    cout << "十位：" << n % 10 << endl;  // 3
    n = n / 10;
    cout << "百位：" << n % 10 << endl;  // 2
    n = n / 10;
    cout << "千位：" << n % 10 << endl;  // 1
    return 0;
}
```
<!-- end-demo -->

## 卡片：换个顺序输出

<!-- card type:teacher -->
🔄 我们已经拿到了个位、十位、百位、千位。想倒过来，只要把它们的顺序换一下。

```cpp
int n = 1234;
int a = n % 10;      // a = 4（个位）
n = n / 10;
int b = n % 10;      // b = 3（十位）
n = n / 10;
int c = n % 10;      // c = 2（百位）
n = n / 10;
int d = n % 10;      // d = 1（千位）

// 正着输出：d c b a → 1 2 3 4
// 倒着输出：a b c d → 4 3 2 1
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 1234;
    int a = n % 10;
    n = n / 10;
    int b = n % 10;
    n = n / 10;
    int c = n % 10;
    n = n / 10;
    int d = n % 10;
    
    cout << "正着：" << d << c << b << a << endl;
    cout << "倒着：" << a << b << c << d << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：用 % 判断整除

<!-- card type:teacher -->
✅ 如果一个数 `% 10` 的结果是 0，说明它的个位是 0，能被 10 整除。

同理：
- `% 2 == 0` → 能被 2 整除，是偶数
- `% 3 == 0` → 能被 3 整除
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    cout << n % 10 << endl;        // 个位
    cout << n % 2 << endl;         // 0 是偶数，1 是奇数
    return 0;
}
```
<!-- end-demo -->
