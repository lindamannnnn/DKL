## 卡片：int 盒子装不下小数

<!-- card type:teacher -->
📦 上节课我们学过，`int` 盒子只能装整数。

```cpp
int a = 3.5;   // 不行！int 会把它变成 3
```

要装小数，需要另一种盒子。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 7;
    int b = 2;
    cout << a / b << endl;   // 输出 3，不是 3.5
    return 0;
}
```
<!-- end-demo -->

---

## 卡片：double 是小数盒子

<!-- card type:teacher -->
🔢 `double` 是可以装小数的盒子。小学里我们主要用它。

```cpp
double pi = 3.14;
double height = 1.45;
```

> 💡 `float` 也是小数盒子，但装的小数位数少。我们先用 `double`，更精确。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    double pi = 3.14;
    double r = 3.0;
    double c = 2 * pi * r;    // 计算周长
    cout << c << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：保留几位小数

<!-- card type:teacher -->
✂️ 想让输出固定保留 n 位小数，需要两个帮手：

1. `fixed`：告诉电脑"我要固定小数点格式"
2. `setprecision(n)`：告诉电脑"保留 n 位小数"

它们住在另一个工具箱里：`#include <iomanip>`

```cpp
#include <iomanip>

cout << fixed << setprecision(2) << 3.14159 << endl;   // 输出 3.14
```
<!-- end-card -->

---

## 卡片：fixed 和 setprecision 怎么配合

<!-- card type:teacher -->
🧩 可以分开理解：

- 只用 `setprecision(2)`：控制整个数字的 2 位有效数字
- 加上 `fixed`：控制小数点后的 2 位

对比一下：

```cpp
cout << setprecision(2) << 3.14159 << endl;        // 输出 3.1（2位有效数字）
cout << fixed << setprecision(2) << 3.14159 << endl; // 输出 3.14（2位小数）
```

我们一般两个一起用，表示"保留 2 位小数"。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
#include <iomanip>       // 打开小数工具箱
using namespace std;

int main() {
    double pi = 3.1415926;
    cout << setprecision(2) << pi << endl;            // 3.1
    cout << fixed << setprecision(2) << pi << endl;   // 3.14
    cout << fixed << setprecision(4) << pi << endl;   // 3.1416
    return 0;
}
```
<!-- end-demo -->

## 卡片：四舍六入五凑双

<!-- card type:teacher -->
🎯 计算机保留小数时，常用一种特殊规则：

**口诀**：
> 小于 5，全丢掉；
> 大于 5，进一位；
> 正好等于 5，看前一位：
> 奇数进，偶数丢。

```cpp
2.34 → 2.3   // 4 舍去
2.36 → 2.4   // 6 进一
2.25 → 2.2   // 5 前面是 2（偶数），舍去
2.35 → 2.4   // 5 前面是 3（奇数），进一
2.45 → 2.4   // 5 前面是 4（偶数），舍去
2.55 → 2.6   // 5 前面是 5（奇数），进一
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    cout << fixed << setprecision(1);
    cout << 2.34 << endl;   // 2.3
    cout << 2.36 << endl;   // 2.4
    cout << 2.25 << endl;   // 2.2
    cout << 2.35 << endl;   // 2.4
    return 0;
}
```
<!-- end-demo -->

## 卡片：把整数变成小数

<!-- card type:teacher -->
🔄 整数除以整数，结果还是整数。想让结果有小数，可以把其中一个变成 `double`。

```cpp
cout << 7 / 2 << endl;          // 3
cout << (double)7 / 2 << endl;  // 3.5
```

`(double)` 就像给整数穿了一件小数外套。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 7;
    int b = 2;
    cout << a / b << endl;          // 3
    cout << (double)a / b << endl;  // 3.5
    return 0;
}
```
<!-- end-demo -->

## 卡片：注释是给人类看的说明

<!-- card type:teacher -->
📝 注释是写在代码里的说明，电脑会忽略它，但人类能看懂。

- 单行注释：`// 这是说明`
- 多行注释：`/* 这是说明 */`
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    double r = 3.0;     // 圆的半径
    double pi = 3.14;   // π 的近似值
    /* 下面计算圆的面积 */
    double area = pi * r * r;
    cout << area << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：计算圆的面积

<!-- card type:computer -->
🖥️ 输入圆的半径，输出圆的面积。

> 公式：`面积 = π × 半径 × 半径`，π 取 3.14，保留 2 位小数。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double r;
    cin >> r;
    double pi = 3.14;
    double area = pi * r * r;
    cout << fixed << setprecision(2) << area << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 2：分转元

<!-- card type:computer -->
🖥️ 输入一个整数表示总金额（分），输出转换后的元，保留 2 位小数。

> 比如输入 `185`，输出 `1.85`。
>
> 💡 方法不唯一。你可以用 `(double)fen / 100`，也可以用 `fen / 100.0`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int fen;
    cin >> fen;
    double yuan = (double)fen / 100;   // 方法 1：给 fen 穿小数外套
    // double yuan = fen / 100.0;        // 方法 2：除数写成小数
    cout << fixed << setprecision(2) << yuan << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 3：平均分糖果

<!-- card type:computer -->
🖥️ 小明有 17 颗糖，要平均分给 4 个小朋友。每人分到几颗？保留 2 位小数输出。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int total = 17;
    int people = 4;
    double each = (double)total / people;
    cout << fixed << setprecision(2) << each << endl;
    return 0;
}
```
<!-- end-demo -->

## 小贴士：别忘了小数工具箱

<!-- hint -->
用 `fixed` 和 `setprecision` 的时候，**必须在程序最上面加**：

```cpp
#include <iomanip>
```

不然电脑会不认识 `setprecision`！
