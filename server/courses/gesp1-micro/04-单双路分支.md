## 卡片：bool 只有两种答案

<!-- card type:teacher -->
✅❌ `bool` 是一种特殊的盒子，里面只能装两种答案：

- `true`：真、对、是
- `false`：假、错、否

在 C++ 里，`true` 显示为 `1`，`false` 显示为 `0`。

> 💡 就像开关：开是 1，关是 0。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    bool isSunny = true;
    bool isRainy = false;
    cout << isSunny << " " << isRainy << endl;   // 输出 1 0
    return 0;
}
```
<!-- end-demo -->

## 卡片：关系运算符是比大小

<!-- card type:teacher -->
🔍 关系运算符用来比较两个数，结果是一个 `bool`。

| 符号 | 含义 |
|------|------|
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |
| `==` | 等于 |
| `!=` | 不等于 |

> ⚠️ 判断相等是 `==`，不是 `=`！`=` 是把右边的值放进左边。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 3;
    cout << (a > b) << endl;   // 1（真）
    cout << (a == b) << endl;  // 0（假）
    cout << (a != b) << endl;  // 1（真）
    return 0;
}
```
<!-- end-demo -->

## 卡片：单分支 if

<!-- card type:teacher -->
🛤️ `if` 就像一扇门：条件成立，门就打开，执行里面的代码；条件不成立，就跳过。

```cpp
if (条件) {
    // 条件成立时执行
}
```

> 💡 大括号 `{}` 就像一个小书包，把条件成立时要一起执行的代码装进去。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int age;
    cin >> age;
    if (age >= 18) {
        cout << "你已经成年啦！" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 卡片：双分支 if-else

<!-- card type:teacher -->
🔄 `if-else` 就像岔路口：条件成立走 `if` 这条路，不成立走 `else` 那条路。

```cpp
if (条件) {
    // 条件成立时执行
} else {
    // 条件不成立时执行
}
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 60) {
        cout << "及格啦！" << endl;
    } else {
        cout << "还要努力哦！" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 卡片：判断奇偶

<!-- card type:teacher -->
🔢 上节课学过 `%` 取余。用 `% 2` 可以判断奇偶：

- `n % 2 == 0` → 偶数
- `n % 2 != 0` → 奇数
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n % 2 == 0) {
        cout << "偶数" << endl;
    } else {
        cout << "奇数" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 卡片：判断倍数

<!-- card type:teacher -->
🍭 判断 `a` 是不是 `b` 的倍数，就看 `a % b` 是否等于 0。

```cpp
if (a % b == 0) {
    // a 是 b 的倍数
}
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    if (a % b == 0) {
        cout << a << " 是 " << b << " 的倍数" << endl;
    } else {
        cout << a << " 不是 " << b << " 的倍数" << endl;

}
```

## 卡片：三目运算符

<!-- card type:teacher -->
🎯 三目运算符是 `if-else` 的简短写法，适合简单的二选一。

```cpp
条件 ? 值1 : 值2
```

条件成立，返回值 1；否则返回值 2。

> 💡 如果看不懂，就先用 `if-else`。三目运算符只是让代码更短，不是必须学的。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    int maxNum = (a > b) ? a : b;   // 如果 a>b，maxNum=a，否则 maxNum=b
    cout << "较大的数是：" << maxNum << endl;
    return 0;
}
```
<!-- end-demo -->

## 小贴士：== 和 = 别搞反

<!-- hint -->
- `=` 是赋值：把右边的值放进左边
  ```cpp
  int a = 10;   // 把 10 放进 a
  ```
- `==` 是判断：看两边是否相等
  ```cpp
  if (a == 10)  // a 等于 10 吗？
  ```

很多小朋友会写错，一定要小心！
<!-- end-hint -->
