## 卡片：多分支就像排队上车

<!-- card type:teacher -->
🚌 `if-else if-else` 就像排队上车：

- 先判断第一个条件
- 不成立就判断第二个
- 再不成立就判断第三个
- 最后都不成立，走 `else`

```cpp
if (条件1) {
    // 条件1 成立
} else if (条件2) {
    // 条件2 成立
} else {
    // 都不成立
}
```

> 💡 只会执行其中一个分支，找到就"下车"。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 90) {
        cout << "优秀" << endl;
    } else if (score >= 80) {
        cout << "良好" << endl;
    } else if (score >= 60) {
        cout << "及格" << endl;
    } else {
        cout << "不及格" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 卡片：&& 表示"并且"

<!-- card type:teacher -->
🔗 `&&` 读作"并且"。两边条件都成立，结果才成立。

生活例子：既要完成作业，**并且**要复习，才能出去玩。

```cpp
a > 0 && b > 0   // a 大于 0 并且 b 大于 0
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = -3;
    cout << (a > 0 && b > 0) << endl;   // 0（false）
    cout << (a > 0 && a < 10) << endl;  // 1（true）
    return 0;
}
```
<!-- end-demo -->

## 卡片：|| 表示"或者"

<!-- card type:teacher -->
🔗 `||` 读作"或者"。两边只要有一个成立，结果就成立。

生活例子：只要下雨，**或者**下雪，就不上体育课。

```cpp
a > 0 || b > 0   // a 大于 0 或者 b 大于 0
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = -3;
    cout << (a > 0 || b > 0) << endl;   // 1（true）
    cout << (a < 0 || b < 0) << endl;   // 1（true）
    return 0;
}
```
<!-- end-demo -->

## 卡片：! 表示"不是"

<!-- card type:teacher -->
🔗 `!` 读作"非"或"不是"，作用是把结果反过来。

```cpp
!(a > 0)   // a 不是大于 0，也就是 a <= 0
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    cout << (a > 0) << endl;    // 1
    cout << !(a > 0) << endl;   // 0
    return 0;
}
```
<!-- end-demo -->

## 卡片：运算符优先级

<!-- card type:teacher -->
🧮 一个式子里有多种运算符时，要先算优先级高的。今天我们只记逻辑运算符的优先级：

1. 先算 `!`（非）
2. 再算 `&&`（并且）
3. 最后算 `||`（或者）

> 💡 不确定时，多打小括号 `()`，就不会错！
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 3, c = 8;
    if ((a + b > c) && (c > 0)) {
        cout << "成立" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 卡片：判断闰年

<!-- card type:teacher -->
📅 闰年有两个条件，满足其中一个就是闰年：

1. 能被 4 整除，**并且**不能被 100 整除
2. **或者**能被 400 整除

```cpp
if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
    cout << "闰年" << endl;
} else {
    cout << "平年" << endl;
}
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int year;
    cin >> year;
    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
        cout << "闰年" << endl;
    } else {
        cout << "平年" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 小贴士：多分支顺序很重要

<!-- hint -->
写 `if-else if-else` 时，条件要从高到低排好队。

❌ 错误顺序：
```cpp
if (score >= 60) { ... }
else if (score >= 90) { ... }   // 这行永远执行不到！
```

✅ 正确顺序：
```cpp
if (score >= 90) { ... }
else if (score >= 80) { ... }
else if (score >= 60) { ... }
else { ... }
```
<!-- end-hint -->
