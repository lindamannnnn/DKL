# 课程08：循环控制

> 🎯 目标：学会在循环里"提前结束"和"跳过本次"！

## 故事：找座位

<!-- story -->
小明去电影院找座位。

> 他从第一排开始找，看到空座位就坐下（**break**）。
> 如果这排不是目标排，就跳过继续找（**continue**）。

循环里也有这两个动作！
<!-- end-story -->

## 卡片：break 直接结束循环

<!-- card type:teacher -->
🛑 `break` 就像喊"停！"，循环立刻结束，跳出循环体。

```cpp
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;   // 到 5 就结束
    }
    cout << i << " ";
}
// 输出：1 2 3 4
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 5) {
            break;
        }
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：continue 跳过本次

<!-- card type:teacher -->
⏭️ `continue` 就像喊"这次不算，下次再来"，跳过当前循环，进入下一次。

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;   // 跳过 3
    }
    cout << i << " ";
}
// 输出：1 2 4 5
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 3) {
            continue;
        }
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：break 和 continue 对比

<!-- card type:teacher -->
🆚 两个指令不一样：

- **break**：循环直接结束
- **continue**：跳过本次，继续下一次

就像跑步：
- break = 直接退出跑道
- continue = 这一圈不跑完，直接开始下一圈
<!-- end-card -->

## 卡片：质数与合数

<!-- card type:teacher -->
🔢 大于 1 的整数可以分成两类：

- **质数**：只有 1 和它本身两个因数，比如 2、3、5、7
- **合数**：除了 1 和它本身还有其他因数，比如 4、6、8、9

> 💡 1 既不是质数也不是合数。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    bool isPrime = true;   // 先假设是质数
    
    if (n <= 1) {
        isPrime = false;   // 1 及以下不是质数
    }
    
    for (int i = 2; i < n; i++) {
        if (n % i == 0) {
            isPrime = false;   // 能被整除，不是质数
            break;             // 找到一个就够了
        }
    }
    
    if (isPrime) {
        cout << "质数" << endl;
    } else {
        cout << "合数" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 卡片：标记变量像红绿灯

<!-- card type:teacher -->
🚦 `bool isPrime` 就是一个标记变量：

- 一开始设为 `true`（绿灯：是质数）
- 发现能整除的数，改成 `false`（红灯：不是质数）

标记变量帮我们记住"最后的结果是什么"。
<!-- end-card -->

## 卡片：质数判断可以更快

<!-- card type:teacher -->
⚡ 判断 `n` 是不是质数，其实不用试到 `n-1`，试到 `sqrt(n)` 就够了。

`sqrt(n)` 表示 n 的平方根，需要 `#include <cmath>`。

> 💡 小学里先理解基本判断方法，`sqrt` 优化了解一下就行。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int n;
    cin >> n;
    bool isPrime = true;
    if (n <= 1) isPrime = false;
    for (int i = 2; i <= sqrt(n); i++) {
        if (n % i == 0) {
            isPrime = false;
            break;
        }
    }
    if (isPrime) cout << "质数" << endl;
    else cout << "合数" << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：输出 1~20 的奇数

<!-- card type:computer -->
🖥️ 用 for 循环输出 1 到 20 的所有奇数。

> 提示：偶数就 continue 跳过。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 20; i++) {
        if (i % 2 == 0) {
            continue;   // 跳过偶数
        }
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```
<!-- end-demo -->
