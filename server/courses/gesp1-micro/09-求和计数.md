## 卡片：循环输入求和

<!-- card type:teacher -->
➕ 先输入有多少个数，然后用循环一次次读入，把它们加到总和里。

```cpp
int n;
cin >> n;          // 先输入个数
int sum = 0;
for (int i = 1; i <= n; i++) {
    int x;
    cin >> x;      // 每次读一个数
    sum = sum + x;
}
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        sum = sum + x;
    }
    cout << sum << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：求平均数

<!-- card type:teacher -->
📊 平均数 = 总和 ÷ 个数。

求平均数时，记得把总和转成 `double`，不然整数除法会丢掉小数。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        sum = sum + x;
    }
    cout << "平均数：" << (double)sum / n << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：求最大值

<!-- card type:teacher -->
🏆 先假设第一个数最大，然后逐个比较，发现更大的就更新。

```cpp
int maxNum = -1000000;   // 先设一个很小的数
for (...) {
    if (x > maxNum) {
        maxNum = x;
    }
}
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int maxNum = -1000000;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        if (x > maxNum) {
            maxNum = x;
        }
    }
    cout << "最大值：" << maxNum << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：求最小值

## 挑战 1：求因子和

<!-- card type:computer -->
🖥️ 输入一个整数 n，输出它的所有因子之和。

> 比如 6 的因子是 1、2、3、6，因子和是 12。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        if (n % i == 0) {
            sum = sum + i;
        }
    }
    cout << sum << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 2：求最大最小值

<!-- card type:computer -->
🖥️ 输入 n 个整数，输出它们的最大值和最小值。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int maxNum = -1000000;
    int minNum = 1000000;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        if (x > maxNum) maxNum = x;
        if (x < minNum) minNum = x;
    }
    cout << maxNum << " " << minNum << endl;
    return 0;
}
```
<!-- end-demo -->

---

## 小贴士：初始值要设得够远

<!-- hint -->
求最大值时，初始值要比所有可能的数都小；
求最小值时，初始值要比所有可能的数都大。

如果不知道数有多大，可以用 `int maxNum = -2147483647;` 或直接用第一个数作为初始值。
<!-- end-hint -->
