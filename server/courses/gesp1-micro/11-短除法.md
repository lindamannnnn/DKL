## 卡片：while(t--) 循环 n 次

<!-- card type:teacher -->
🍬 想循环 n 次？可以让 t 从 n 开始，每次减 1，直到变成 0。

```cpp
int t;
cin >> t;
while (t--) {
    cout << "吃一颗糖" << endl;
}
```

`t--` 的意思是：先用 t 的值判断，然后再减 1。

> 如果 t 一开始是 5，就会循环 5 次。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        cout << "*";
    }
    cout << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：拆数字——短除法

<!-- card type:teacher -->
🔢 怎么把 `1234` 拆成 1、2、3、4？

- 取个位：`n % 10`
- 去掉个位：`n = n / 10`

反复做，直到 `n` 变成 0。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    while (n > 0) {
        cout << n % 10 << " ";  // 输出个位
        n = n / 10;             // 去掉个位
    }
    cout << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：数位求和

<!-- card type:teacher -->
➕ 数位求和：把每一位数字加起来。

`1234` 的数位和 = `1 + 2 + 3 + 4 = 10`

```cpp
int sum = 0;
while (n > 0) {
    sum += n % 10;  // 把个位加到 sum
    n /= 10;        // 去掉个位
}
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    while (n > 0) {
        sum += n % 10;
        n /= 10;
    }
    cout << sum << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：判断数字里有没有某个数字

<!-- card type:teacher -->
🔍 比如判断 `12345` 里有没有 `3`。

拆每一位，如果发现某一位等于目标数字，就找到了！

```cpp
bool found = false;
while (n > 0) {
    if (n % 10 == target) {
        found = true;
        break;      // 找到了，提前结束
    }
    n /= 10;
}
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, target;
    cin >> n >> target;
    bool found = false;
    while (n > 0) {
        if (n % 10 == target) {
            found = true;
            break;
        }
        n /= 10;
    }
    if (found) {
        cout << "包含" << endl;
    } else {
        cout << "不包含" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：数位乘积

<!-- card type:computer -->
🖥️ 输入一个整数，输出每一位数字的乘积。

> 比如输入 123，输出 6（1×2×3）。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int product = 1;        // 乘法从 1 开始
    while (n > 0) {
        product *= n % 10;  // 乘上个位
        n /= 10;
    }
    cout << product << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 2：统计某个数字出现几次

<!-- card type:computer -->
🖥️ 输入一个整数 n 和一个数字 d，统计 n 中 d 出现几次。

> 比如 n = 12223，d = 2，输出 3。
<!-- end-card -->

<!-- demo -->
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, d;
    cin >> n >> d;
    int count = 0;
    while (n > 0) {
        if (n % 10 == d) {
            count++;
        }
        n /= 10;
    }
    cout << count << endl;
    return 0;
}
```
<!-- end-demo -->

---

## 小贴士：乘法要从 1 开始

<!-- hint -->
求和时 `sum = 0`。
求乘积时 `product = 1`。

如果乘积从 0 开始，结果就永远是 0 啦！
<!-- end-hint -->
