## 卡片：printf 按格式输出

<!-- card type:teacher -->
🖨️ `printf` 和 `cout` 一样，都是让电脑显示文字。

不一样的是：`printf` 可以在字符串里挖"坑"，用后面的值填进去。

```cpp
#include <cstdio>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

> 💡 `#include <cstdio>` 是 `printf` 和 `scanf` 的家。
<!-- end-card -->

---

## 卡片：scanf 按格式输入

<!-- card type:teacher -->
⌨️ `scanf` 和 `cin` 一样，都是读取输入。

格式：`scanf("占位符", &变量);`

```cpp
#include <cstdio>

int main() {
    int age;
    printf("请输入你的年龄：");
    scanf("%d", &age);
    printf("你的年龄是：%d\n", age);
    return 0;
}
```

> ⚠️ `scanf` 里变量前面必须加 `&`！这是规矩，先记住。
<!-- end-card -->

## 卡片：占位符就是"填空坑"

<!-- card type:teacher -->
🎫 占位符是 `%` 开头的符号，用来占位置。

| 占位符 | 填什么 |
|--------|--------|
| `%d` | 整数 |
| `%f` | 小数 |
| `%c` | 字符 |

```cpp
int a = 10;
double b = 3.14;
printf("a = %d, b = %f\n", a, b);
```

> 输出：`a = 10, b = 3.14`
<!-- end-card -->

## 卡片：控制数字格式

<!-- card type:teacher -->
🎨 想让数字按指定格式显示？

| 写法 | 意思 | 例子 |
|------|------|------|
| `%05d` | 整数宽度 5，不够补 0 | `7` → `00007` |
| `%5d` | 整数宽度 5，不够补空格 | `7` → `    7` |
| `%.2f` | 小数保留 2 位 | `3.14159` → `3.14` |

```cpp
int n = 7;
printf("%05d\n", n);   // 00007
printf("%.2f\n", 3.14159);  // 3.14
```
<!-- end-card -->

## 卡片：时间换算

<!-- card type:teacher -->
⏰ 把总秒数变成"小时:分钟:秒"。

```cpp
int total;
scanf("%d", &total);
int h = total / 3600;       // 1 小时 = 3600 秒
int m = total % 3600 / 60;  // 剩下的秒数里有多少分钟
int s = total % 60;         // 最后剩下的秒数
printf("%02d:%02d:%02d\n", h, m, s);
```

> 输入 3661，输出 `01:01:01`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <cstdio>

int main() {
    int total;
    scanf("%d", &total);
    int h = total / 3600;
    int m = total % 3600 / 60;
    int s = total % 60;
    printf("%02d:%02d:%02d\n", h, m, s);
    return 0;
}
```
<!-- end-demo -->

## 挑战 2：输出成绩

<!-- card type:computer -->
🖥️ 输入一个成绩（小数），按下面格式输出：

```
成绩：95.50 分
```

> 成绩保留 2 位小数。
<!-- end-card -->

<!-- demo -->
```cpp
#include <cstdio>

int main() {
    double score;
    scanf("%lf", &score);
    printf("成绩：%.2f 分\n", score);
    return 0;
}
```
<!-- end-demo -->

---

## 小贴士：小数输入用 %lf

<!-- hint -->
`scanf` 读 `double` 类型的小数时，占位符要用 `%lf`：

```cpp
double x;
scanf("%lf", &x);
```

`printf` 输出小数时用 `%f`。
<!-- end-hint -->
