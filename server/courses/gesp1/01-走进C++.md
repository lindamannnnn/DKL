## 第0关：计算机小故事

<!-- story -->
很久很久以前，人们用算盘和草稿纸计算。

1946 年，世界上第一台电子计算机 **ENIAC** 诞生了，它有一间房子那么大，能每秒做几千次计算。

后来，计算机越来越小、越来越快，从只能科学家用，变成我们每个人家里、书包里的工具。

计算机不会做自己想做的事，它只会严格按照人们的**指令**行动。把很多指令按顺序写下来，就是**程序**。我们学习的 C++，就是一种写程序的语言。
<!-- end-story -->

### 卡片：电脑是怎么工作的？

<!-- card type:teacher -->
🖥️ 一台电脑主要由四部分组成：

| 部件 | 作用 | 比喻 |
|------|------|------|

### 卡片：程序骨架五件套

<!-- card type:teacher -->
每个 C++ 程序都有固定的骨架，就像搭积木一样，先搭好框架再往里放东西。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

一句话一句话看：

- 🧰 `#include <bits/stdc++.h>` —— 打开输入输出工具箱。没有它，`cin` 和 `cout` 就不能用。
- 🔮 `using namespace std;` —— 告诉电脑"我要用标准工具箱里的东西"。现在先跟着写，以后会懂。
- 🚪 `int main()` —— 大门，程序从这里开始。`main` 是一个特殊名字，电脑看到它就知道"从这里执行"。
- 📢 `cout << ...` —— 小喇叭，用来输出文字到屏幕。
- ✋ `return 0;` —— 说"我做完啦，一切顺利！"写 `0` 表示"没问题"。

> 💡 这五句话现在看起来像咒语，没关系！就像学自行车先扶稳车把，先记住它们的样子，后面会越用越熟。
<!-- end-card -->

### 卡片：大括号是一对好朋友

<!-- card type:teacher -->
`{` 和 `}` 是一对好朋友，中间装着 `main` 函数里的命令。

```cpp
int main() {
    // 这里的命令会按顺序执行
    cout << "Hello!" << endl;

}
```

> 💡 养成习惯：写 `{` 的时候，立刻把 `}` 也写好，再往中间填内容。

## 第2关：让电脑说句话

### 卡片：cout 是小喇叭

<!-- card type:teacher -->
📢 `cout` 是小喇叭，用来让电脑"说"出内容。

```cpp
cout << "Hello, World!" << endl;
```

- `<<` 像一个小喇叭口，把右边的内容"喷"到屏幕上。
- `"Hello, World!"` 是一句话，要用双引号包起来。
- `endl` 是"换行"的意思，让后面的内容从新的一行开始。

> 💡 口诀：**cout 朝外喊，双引号里装要说的话。**
<!-- end-card -->

### 报错也不慌：分号别忘了

<!-- card type:tip -->
💡 C++ 里，很多语句末尾都要加分号 `;`，就像一句话末尾要加句号。

如果报错 `expected ';' before ...`，就是忘了加分号！

> 常见漏分号的地方：`#include` 后面不用加，但 `using namespace std;`、`int main()` 里面的语句都要加。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;   // ✅ 有分号

int main() {
    cout << "Hello" << endl;   // ✅ 有分号
    return 0;                   // ✅ 有分号
}
```
<!-- end-demo -->

## 第3关：变量是小盒子

### 卡片：变量是什么

<!-- card type:teacher -->
📦 变量就像一个有名字的小盒子，里面可以装一个数。我们需要的时候，就喊它的名字。

```cpp
int age;
```

- `int` = 这个盒子只能装**整数**
- `age` = 盒子的名字
- `;` = 这句话说完了
<!-- end-card -->

---

### 卡片：把东西装进盒子

<!-- card type:teacher -->
第一步：创建盒子。第二步：把数字放进去。

```cpp
int age;      // 创建一个叫 age 的盒子
age = 10;     // 把 10 放进去
```

⚠️ 这里的 `=` 不是数学里的"等于"，是"放进去"的意思！

> 💡 可以想象成：`age = 10` 就是把数字 10 丢进 age 这个盒子里。
<!-- end-card -->

---

### 报错也不慌：盒子一定要先装东西

<!-- card type:tip -->
💡 如果你创建了一个盒子，但还没往里放东西，就直接输出它，电脑会打印出一个奇怪的数。

```cpp
int age;
cout << age << endl;   // 可能输出 -858993460 之类的奇怪数字
```

这是因为盒子里原来有什么，电脑也不知道。所以 safest 的做法是：**创建盒子的时候立刻初始化**。

```cpp
int age = 0;   // ✅ 先放进去一个 0，再慢慢改
```
<!-- end-card -->

---

### 卡片：创建同时装好

<!-- card type:teacher -->
也可以一步完成：创建盒子的同时，就把东西放进去。

```cpp
int age = 10;
```

这叫**初始化**，是最常用的写法。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int age = 10;
    cout << age << endl;
    return 0;
}
```
<!-- end-demo -->

## 第4关：让电脑听你说话

### 卡片：cin 是小耳朵

<!-- card type:teacher -->
👂 `cin` 是小耳朵，让电脑听你输入。

📢 `cout` 是小喇叭，让电脑说话。

```cpp
cin >> age;
```

- `>>` 像两个小箭头，**朝里指**，表示"把键盘上的数字装进 age 这个盒子里"。

> 💡 口诀：**cin 朝里装，cout 朝外喊。**
<!-- end-card -->

---

```cpp
int main() {

    cin >> age;
    cout << "你今年 " << age << " 岁啦！" << endl;
    return 0;
}
```

运行后，输入一个数字，比如 `10`，按回车，电脑就会说"你今年 10 岁啦！"

## 第5关：小小运算家

### 卡片：四种算术运算

<!-- card type:teacher -->
C++ 里有 4 种最常用的运算：

- ➕ `+` 加
- ➖ `-` 减
- ✖️ `*` 乘
- ➗ `/` 除

> ⚠️ 小提醒：`/` 是**整数除法**。如果除不尽，电脑会先把小数部分丢掉。比如 `5 / 2` 结果是 `2`，不是 `2.5`。这个秘密下节课再细讲！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a = 12;
    int b = 5;
    cout << a + b << endl;   // 17
    cout << a - b << endl;   // 7
    cout << a * b << endl;   // 60
    cout << a / b << endl;   // 2（小数被丢掉了）
    return 0;
}
```
<!-- end-demo -->

---

## 挑战 1：自我介绍

<!-- card type:computer -->
🖥️ 小电脑说：现在轮到你了！写一个程序，输出你的名字和年龄。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "我叫小明，今年 10 岁" << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 程序骨架五件套（`#include`、`using namespace std;`、`int main()`、`cout`、`return 0;`）
- 用 `cout` 输出字符串
- 用 `endl` 换行

**解题思路分步说明**

1. 先写好 `#include <bits/stdc++.h>` 和 `using namespace std;`。
2. 写出 `int main() { ... return 0; }` 这个大门。
3. 在 `main` 里用 `cout << "..." << endl;` 把要说的话打印出来。
4. 检查每一句话末尾都有分号，再按 `F11` 运行。

**容易错的地方**

- 漏写 `#include <bits/stdc++.h>` 或 `using namespace std;`
- 双引号用了中文符号
- 语句末尾忘记加分号 `;`
- `main` 拼错成 `mian`

**关键代码解释**

```cpp
cout << "我叫小明，今年 10 岁" << endl;
```

- `cout` 是小喇叭，把右边的内容显示到屏幕上。
- `<<` 像喇叭口，把字符串 `"我叫小明，今年 10 岁"` 送出去。
- `endl` 让光标跳到下一行。
<!-- end-card -->

## 挑战 2：输入两个数求和

<!-- card type:computer -->
🖥️ 让用户输入两个整数，然后输出它们的和。
<!-- end-card -->

> 💡 运行时，输入两个数之间用**空格**或**回车**隔开，比如输入 `3 5` 然后按回车。

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 变量定义（`int a, b;`）
- 用 `cin` 读取键盘输入
- 算术加法运算

**解题思路分步说明**

1. 在 `main` 里定义两个整数变量 `a` 和 `b`。
2. 用 `cin >> a >> b;` 从键盘读取两个数。
3. 直接计算 `a + b` 并输出。
4. 运行后输入两个整数，中间用空格或回车分开。

**容易错的地方**

- `cin` 的箭头方向写反（写成 `cin << a`）
- 两个输入数之间没有分隔
- 忘记定义变量就直接使用
- 漏写 `using namespace std;`

**关键代码解释**

```cpp
cin >> a >> b;
```

- `cin` 是小耳朵，`>>` 箭头朝里，把键盘输入按顺序放进 `a` 和 `b`。

```cpp
cout << a + b << endl;
```

- 可以直接把表达式 `a + b` 放在 `cout` 里输出，不需要再定义第三个变量。
<!-- end-card -->
