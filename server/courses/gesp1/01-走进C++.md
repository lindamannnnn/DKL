## 🛠️ 知识点一：Dev-C++ 是我们的魔法工具

Dev-C++ 就像一支魔法笔，我们用它写出程序，电脑就能执行。

### 📝 新建第一个程序的步骤

1. 双击打开 Dev-C++。
2. 点击菜单：**文件 → 新建 → 源代码**。
3. 把下面的代码复制进去。

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```
<!-- run -->

4. 按 `Ctrl + S` 保存，文件名写 `hello.cpp`。
5. 按 `F11` 编译并运行。
6. 看到黑框框里显示 `Hello, World!` 就成功啦！🎉

### 💡 小提示

<!-- hint -->
如果运行后黑框框一闪而过，可以在 `return 0;` 前面加一行：

```cpp
system("pause");
```

这样黑框框会等你按任意键再关闭（仅在 Windows + Dev-C++ 环境下有效）。
<!-- end-hint -->

## 🏗️ 知识点二：C++ 程序的基本框架

每个 C++ 程序都像一座小房子，有固定的"骨架"。

```cpp
#include <iostream>      // 引入输入输出工具箱
using namespace std;     // 使用标准命名空间

int main() {             // 主函数，程序的入口
    cout << "Hello, World!" << endl;  // 输出一句话
    return 0;            // 程序正常结束
}
```
<!-- run -->

### 🔍 每一行是什么意思？

| 代码 | 作用 | 小朋友的理解 |
|------|------|-------------|
| `#include <iostream>` | 引入输入输出工具 | 打开工具箱 🧰 |
| `using namespace std;` | 使用标准命名空间 | 省去写 `std::` 的前缀 |
| `int main() { ... }` | 程序从这里开始 | 大门 🚪 |
| `cout << ... << endl;` | 输出内容到屏幕 | 小喇叭 📢 |
| `return 0;` | 正常结束 | 说"我做完啦" ✋ |

## 🧮 知识点三：变量与算术运算

### 变量是什么？

变量就像一个有名字的小盒子，里面可以装一个数。我们需要用的时候，就喊它的名字。

```cpp
#include <iostream>
using namespace std;

int main() {
    int age;      // 准备一个叫 age 的小盒子，用来装整数
    age = 10;     // 把 10 放进 age 这个盒子里
    cout << age;  // 输出 age 盒子里的内容
    return 0;
}
```
<!-- run -->

### 变量的类型

给盒子贴标签，告诉电脑这个盒子能装什么类型的东西。我们第一节课先学整数类型 `int`。

```cpp
int age = 10;    // int 表示整数
```

### 声明、赋值与初始化

| 操作 | 代码 | 说明 |
|------|------|------|
| 声明 | `int age;` | 准备一个装整数的盒子 |
| 赋值 | `age = 10;` | 把 10 放进盒子里 |
| 初始化 | `int age = 10;` | 声明的同时赋值 |

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 10;          // 声明的同时赋值（初始化）
    int score = 95;
    int a = 3, b = 4;      // 同时声明多个变量
    cout << age << " " << score << " " << a << " " << b << endl;
    return 0;
}
```
<!-- run -->

### 赋值语句

赋值语句就是把右边的值交给左边的变量。

```cpp
age = 10;        // 把 10 赋给 age
score = age + 5; // 先算 age + 5，再把结果赋给 score
```

### 算术运算

C++ 中的五种基本算术运算：

| 运算符 | 含义 | 例子 | 结果 |
|--------|------|------|------|
| + | 加 | 5 + 3 | 8 |
| - | 减 | 5 - 3 | 2 |
| * | 乘 | 5 * 3 | 15 |
| / | 除 | 6 / 3 | 2 |
| % | 取余 | 5 % 3 | 2 |

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 12;
    int b = 5;
    cout << "a + b = " << a + b << endl;
    cout << "a - b = " << a - b << endl;
    cout << "a * b = " << a * b << endl;
    cout << "a / b = " << a / b << endl;   // 整数除法，先知道结果即可，下节课详细讲
    cout << "a % b = " << a % b << endl;   // 取余运算，下节课详细讲
    return 0;
}
```

### 挑战 2：计算总分

小明语文考了 95 分，数学考了 98 分，英语考了 92 分。请计算他的总分和平均分。

```cpp
#include <iostream>
using namespace std;

int main() {
    int chinese = 95;
    int math = 98;
    int english = 92;
    int total = chinese + math + english;
    cout << "总分：" << total << endl;
    cout << "平均分：" << total / 3 << endl;
    return 0;
}
```
