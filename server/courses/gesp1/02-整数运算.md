## 🧩 知识点一：计算机是个啥？

计算机就像一个小机器人，它有**大脑**、**工作台**、**仓库**和**手脚**。

### 🧠 计算机的四大部件

| 部件 | 作用 | 生活比喻 | emoji |
|------|------|----------|-------|
| **CPU** | 负责思考、计算、做决策 | 大脑 🧠 | 🧠 |
| **内存 RAM** | 临时存放正在用的东西 | 手边的书桌 | 📝 |
| **硬盘** | 长期保存文件和程序 | 家里的仓库 | 🏚️ |
| **输入输出设备** | 让人和电脑交流 | 眼睛、耳朵、嘴巴 | 👀👂🗣️ |

### 💬 来做个小比喻

- 你想算 `12 + 28 = ?`
- 你的眼睛看到题目（**输入设备**）
- 大脑开始计算（**CPU**）
- 计算时，你在草稿纸上写下步骤（**内存**）
- 最后把答案写到作业本上（**输出设备**）
- 作业本可以保存很久（**硬盘**）

### 🖥️ 操作系统是什么？

计算机除了有这些硬件，还需要一个"大管家"来管理它们，这个管家就是**操作系统**。

Windows、Linux、macOS、安卓、iOS 都是操作系统。操作系统帮我们管理硬件和软件，让电脑能正常工作。

### 🚀 计算机的发展历程

计算机的发展经历了几个阶段：

1. **第一代**：电子管计算机，体积巨大，像一间房子那么大。
2. **第二代**：晶体管计算机，变小了一些。
3. **第三代**：集成电路计算机，更小更快。
4. **第四代**：大规模集成电路计算机，就是我们现在的电脑、手机、平板。

### 🖱️ 计算机的常见操作

我们平时用电脑会做的操作：

- 开机和关机
- 打开软件（比如 Dev-C++）
- 保存文件
- 复制、粘贴
- 运行程序

## 🏷️ 知识点二：标识符、关键字、常量、变量与表达式

### 标识符

标识符就是给变量、函数等起的名字。比如 `age`、`score`、`main` 都是标识符。

标识符命名规则：

1. 只能由字母、数字、下划线组成。
2. 不能以数字开头。
3. 不能和 C++ 关键字重名。

### 关键字

关键字是 C++ 语言保留的特殊单词，有特定含义，不能拿来当变量名。

常见关键字：`int`、`return`、`if`、`else`、`for`、`while` 等。

### 常量

常量就是固定不变的量。比如 `10`、`-5`、`100` 都是整数常量。

```cpp
cout << 100 << endl;   // 100 是常量
```

### 变量

变量就是可以改变的量，我们用一个名字来代表它。

```cpp
int age = 10;    // age 是变量
age = 11;        // age 的值可以改变
```

### 表达式

表达式是由运算符和操作数组成的式子，会计算出一个结果。

```cpp
a + b       // 表达式
age + 5     // 表达式
10 * 2 + 3  // 表达式
```

## 🧮 知识点三：整型变量的类型

### 什么是整型？

整型就是整数类型，能存放像 0、100、-5 这样的整数。

### 常见的整型类型

| 类型 | 名称 | 能表示的范围 | 说明 |
|------|------|-------------|------|
| `short` | 短整型 | 比较小 | 很少用 |
| `int` | 整型 | 约 -21亿 到 21亿 | 最常用 |
| `long` | 长整型 | 和 int 差不多 | 很少用 |
| `long long` | 长长整型 | 非常大 | 数字很大时用 |

小学阶段，我们主要用 `int`。如果数字特别大，比如超过 21 亿，就用 `long long`。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 100;
    long long b = 1234567890123LL;   // 特别大的数
    cout << a << " " << b << endl;
    return 0;
}
```
<!-- run -->

### 选哪个类型？

- 一般整数用 `int`
- 特别大的整数用 `long long`
- 小学阶段 `int` 基本够用

## ➗ 知识点四：算术运算

C++ 中的五种基本算术运算：

| 运算符 | 含义 | 例子 | 结果 |
|--------|------|------|------|
| + | 加 | 5 + 3 | 8 |
| - | 减 | 5 - 3 | 2 |
| * | 乘 | 5 * 3 | 15 |
| / | 除 | 5 / 3 | 1 |
| % | 取余 | 5 % 3 | 2 |

### 特别注意：整数除法

在 C++ 中，整数除以整数，结果还是整数，会**自动去掉小数部分**。

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 5 / 3 << endl;   // 输出 1，不是 1.666...
    cout << 7 / 2 << endl;   // 输出 3，不是 3.5
    return 0;
}
```
<!-- run -->

### 取余运算 %

`%` 表示取余数，就是除法剩下的部分。

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 5 % 3 << endl;   // 5 除以 3 商 1 余 2，输出 2
    cout << 10 % 4 << endl;  // 10 除以 4 商 2 余 2，输出 2
    cout << 8 % 2 << endl;   // 8 除以 2 余 0，输出 0
    return 0;
}
```
<!-- run -->

> 判断一个数能否被另一个数整除，就看 `%` 的结果是不是 0。

### 综合例子

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 17;
    int b = 5;
    cout << "a + b = " << a + b << endl;
    cout << "a - b = " << a - b << endl;
    cout << "a * b = " << a * b << endl;
    cout << "a / b = " << a / b << endl;
    cout << "a % b = " << a % b << endl;
    return 0;
}
```

## 🔢 知识点五：数字拆位

### 怎么拿到一个数的个位？

对一个整数 `% 10`，得到的就是它的个位数字。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 1234;
    cout << n % 10 << endl;   // 输出 4
    return 0;
}
```
<!-- run -->

### 怎么去掉一个数的个位？

对一个整数 `/ 10`，就去掉了它的个位。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 1234;
    cout << n / 10 << endl;   // 输出 123
    return 0;
}
```
<!-- run -->

### 短除法思想

反复地做 `% 10` 和 `/ 10`，就能把每一位数字都拆出来。

我们以 `1234` 为例：

| 步骤 | n 的值 | n % 10（个位） | n = n / 10（去掉个位） |
|------|--------|----------------|------------------------|
| 1 | 1234 | 4 | 123 |
| 2 | 123 | 3 | 12 |
| 3 | 12 | 2 | 1 |
| 4 | 1 | 1 | 0 |

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 1234;
    cout << "个位：" << n % 10 << endl;   // 4
    n = n / 10;
    cout << "十位：" << n % 10 << endl;   // 3
    n = n / 10;
    cout << "百位：" << n % 10 << endl;   // 2
    n = n / 10;
    cout << "千位：" << n % 10 << endl;   // 1
    return 0;
}
```
<!-- run -->

> 这就像吃糖果，每次咬一口（%10），然后扔掉（/10），直到吃完。
