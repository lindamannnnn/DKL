## 卡片：电脑三大件

<!-- card type:teacher -->
🖥️ 在深入学习之前，先认识电脑的三大核心零件：

| 零件 | 作用 | 比喻 |
|------|------|------|
| CPU | 负责运算和控制 | 大脑 |
| 内存（RAM） | 临时存储，程序运行时使用 | 黑板 |
| 硬盘 | 永久存储，断电后数据还在 | 书柜 |

> 💡 我们写的程序运行时会占用内存，变量就住在内存里。程序关闭后，内存里的数据就清空了。
<!-- end-card -->

| 内存 | 黑板 | 临时记东西，下课就擦 |
| 硬盘 | 书柜 | 永久存东西，断电也不丢 |

## 卡片：变量名不是想取就取

<!-- card type:teacher -->
🏷️ 给变量起名字要讲规矩，这些规矩里的词叫**标识符**：

- 只能由字母、数字、下划线 `_` 组成
- 不能以数字开头
- 不能用 C++ 已经占用的词，比如 `int`、`return`、`if`

| 名字 | 对不对 | 原因 |
|------|--------|------|
| `myScore` | ✅ | 字母组合 |
| `_score` | ✅ | 下划线开头 |
| `2score` | ❌ | 数字开头 |
| `my score` | ❌ | 不能有空格 |
| `int` | ❌ | 是关键字 |

> 💡 关键字就是 C++ 自己要用到的词，我们不能抢。常见的有 `int`、`return`、`if`、`else`、`for`、`while`。
<!-- end-card -->

## 卡片：常量是不变的数

<!-- card type:teacher -->
🔒 常量就是值不能改变的量。

```cpp
cout << 100 << endl;     // 100 是整数常量
cout << 3.14 << endl;    // 3.14 是小数常量
cout << 'A' << endl;     // 'A' 是字符常量
```

变量可以换里面的值，常量本身就是固定值，不需要名字也能直接用。
<!-- end-card -->

## 卡片：变量是可以变的盒子

<!-- card type:teacher -->
🔁 变量就像盒子，里面的东西可以换。

```cpp
int age = 10;   // 现在盒子里是 10
age = 11;       // 换成 11
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int score = 90;
    cout << score << endl;
    score = 95;              // 变量可以变
    cout << score << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：整数除法会吃掉小数

<!-- card type:teacher -->
🍰 `int` 盒子里只能装整数。所以整数除以整数，小数部分会被"吃掉"。

```cpp
5 / 2   // 结果是 2，不是 2.5
7 / 3   // 结果是 2，不是 2.333...
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << 5 / 2 << endl;   // 输出 2
    cout << 7 / 3 << endl;   // 输出 2
    cout << 10 / 4 << endl;  // 输出 2
    return 0;
}
```
<!-- end-demo -->

## 卡片：超大整数用 long long

<!-- card type:teacher -->
📦 `int` 能装的整数范围大约是 **-21亿 到 21亿**。如果数字可能超过这个范围，就要用更大的盒子 `long long`。

```cpp
int a = 1000000000;          // 10 亿，int 能装下
long long b = 10000000000LL; // 100 亿，必须用 long long
```

> 💡 为什么加 `LL`？告诉电脑"这是一个超大数字"，防止它先当成 `int` 处理。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long big = 3000000000LL;   // 30 亿
    cout << big << endl;
    return 0;
}
```
<!-- end-demo -->

---

### 小贴士：什么时候用 long long？

<!-- card type:tip -->
💡 记住一个数字：**21 亿**。

- 数字小于 21 亿 → 用 `int`
- 数字可能超过 21 亿 → 用 `long long`

> 比赛时，如果题目说数字很大（比如 10^9 以上），直接用 `long long` 更安全。
<!-- end-card -->

---

### 小练习：该用哪个盒子？

<!-- card type:teacher -->
📦 看这些数字，应该放进 `int` 还是 `long long`？

| 数字 | 选哪个 | 理由 |
|------|--------|------|
| 100 | `int` | 远小于 21 亿 |
| 2500000000 | `long long` | 25 亿，超过 21 亿 |
| 2000000000 | `int` | 20 亿，还没满 |

> 💡 记忆小门槛：**21 亿是 int 的边界，超过就换 long long。**

## 卡片：% 是取余运算符

<!-- card type:teacher -->
🍬 `%` 表示取余数，就是除法剩下的部分。

```cpp
5 % 2   // 5 除以 2 商 2 余 1，结果是 1
10 % 3  // 10 除以 3 商 3 余 1，结果是 1
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << 5 % 2 << endl;    // 输出 1
    cout << 10 % 3 << endl;   // 输出 1
    cout << 8 % 2 << endl;    // 输出 0
    return 0;
}
```
<!-- end-demo -->

## 卡片：拆出个位数字

<!-- card type:teacher -->
🔢 对一个整数 `% 10`，得到的就是它的**个位**。

```cpp
int n = 1234;
cout << n % 10 << endl;   // 输出 4
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n = 2024;
    cout << n % 10 << endl;   // 个位：4
    return 0;
}
```
<!-- end-demo -->

---

### 过渡页：先取再砍，像削铅笔

<!-- card type:teacher -->
✏️ 拆数字就像削铅笔：

1. 先用 `% 10` 看看铅笔尾部露出多少（取个位）。
2. 再用 `/ 10` 削掉这一小段（去掉个位）。
3. 反复削，直到铅笔用完（`n` 变成 0）。

> 💡 记住顺序：**先取余看尾巴，再整除砍尾巴。**
<!-- end-card -->

### 卡片：分步拆解三位数

<!-- card type:teacher -->
🔢 以 `n = 352` 为例，一步步拆：

| 步骤 | 做的事 | n 变成 | 拿到哪位 |
|------|--------|--------|----------|
| 1 | `ge = n % 10` | 352 | 个位 2 |
| 2 | `n = n / 10` | 35 | — |
| 3 | `shi = n % 10` | 35 | 十位 5 |
| 4 | `n = n / 10` | 3 | — |
| 5 | `bai = n % 10` | 3 | 百位 3 |

> 💡 口诀：**先取个位，再砍个位，反复做，直到没有。**

## 挑战 1：输出三位数的每一位

<!-- card type:computer -->
🖥️ 输入一个三位数，输出它的个位、十位、百位。

> 想一想需要几次 `% 10` 和 `/ 10`？
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    cout << "个位：" << n % 10 << endl;
    n = n / 10;
    cout << "十位：" << n % 10 << endl;
    n = n / 10;
    cout << "百位：" << n % 10 << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 取余运算符 `%` 和整数除法 `/`
- 拆数字的"取个位、砍个位"方法

**解题思路分步说明**

1. 读入一个三位数 `n`。
2. `n % 10` 得到当前的个位，输出它。
3. `n = n / 10` 砍掉已经输出的个位，`n` 变成两位数。
4. 再次 `n % 10` 得到原来的十位，输出它。
5. 再次 `n = n / 10` 砍掉十位，`n` 只剩原来的百位，输出它。

**容易错的地方**

- `/` 和 `%` 搞反：把 `/ 10` 当成取个位
- 忘记更新 `n`，导致每次 `% 10` 都取到同一个数字
- 输出顺序搞错，先输出百位再输出个位

**关键代码解释**

```cpp
cout << "个位：" << n % 10 << endl;
n = n / 10;
```

- `n % 10` 取当前最低位（个位）。
- `n = n / 10` 是整数除法，自动去掉末尾数字，为下一次取位做准备。
<!-- end-card -->

---

## 小贴士：/ 和 % 别搞反

<!-- hint -->
- `/ 10` 是**去掉个位**
- `% 10` 是**得到个位**

记住口诀：
> **除号砍尾巴，取余留尾巴。**
<!-- end-hint -->

## 挑战 2：颠倒三位数

<!-- card type:computer -->
🖥️ 输入一个三位数，把它颠倒过来输出。

> 比如输入 `352`，输出 `253`。
>
> 💡 先拆出个位、十位、百位，再重新拼起来：个位×100 + 十位×10 + 百位。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int ge = n % 10;          // 个位
    n = n / 10;
    int shi = n % 10;         // 十位
    int bai = n / 10;         // 百位
    int rev = ge * 100 + shi * 10 + bai;
    cout << rev << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 用 `%` 和 `/` 拆数字
- 位值概念（个位、十位、百位）
- 把拆出来的数字按位权重新组合

**解题思路分步说明**

1. 读入三位数 `n`。
2. 用 `n % 10` 取出个位，存到 `ge`。
3. 用 `n = n / 10` 去掉个位。
4. 用 `n % 10` 取出十位，存到 `shi`。
5. 此时 `n` 已经只剩百位，直接 `bai = n / 10` 也可以。
6. 颠倒后的数 = `ge * 100 + shi * 10 + bai`，输出即可。

**容易错的地方**

- 百位还用 `n % 10`（虽然也能得到，但容易和前面混淆）
- 乘法与加法优先级没加括号导致结果错误
- 如果原数末尾是 0，颠倒后前导 0 不会显示（例如 120 颠倒输出 21，这是正常的整数输出）

**关键代码解释**

```cpp
int rev = ge * 100 + shi * 10 + bai;
```

- `ge * 100` 把原来的个位变成最高位。
- `shi * 10` 把原来的十位留在中间。
- `bai` 保持不变，成为新的个位。
<!-- end-card -->

## 卡片：/ 和 % 还能做时间换算

<!-- card type:teacher -->
⏰ 生活中我们经常要把“总秒数”变回“时:分:秒”。

其实还是用 `/` 和 `%`：
- 总秒数 `/ 3600` → 小时
- 剩余秒数 `/ 60` → 分钟
- 再剩余 `% 60` → 秒

> 💡 口诀：**大单位用除，小单位用余。**
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int total;
    cin >> total;              // 总秒数
    int h = total / 3600;      // 小时
    int m = (total % 3600) / 60; // 分钟
    int s = total % 60;         // 秒
    cout << h << " " << m << " " << s << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：星期几也能用 % 算

<!-- card type:teacher -->
📅 今天是星期 `a`，再过 `b` 天是星期几？

一个星期有 7 天，所以用 `% 7` 就够了：
```cpp
int ans = (a + b) % 7;
```

> ⚠️ 如果题目说 **0 代表星期日**，那 `(a + b) % 7 == 0` 时就要输出 `0`，不要输出 `7`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << (a + b) % 7 << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：最小公倍数——从大到小试

<!-- card type:teacher -->
👫 小杨每 `a` 天值日一次，小红每 `b` 天值日一次，今天两人一起值日，至少再过几天会再次同一天值日？

这就是求 **最小公倍数**。GESP1 不要求背公式，可以这样做：

1. 从 `a` 和 `b` 中较大的那个数开始；
2. 一个一个往后试；
3. 第一个能同时被 `a` 和 `b` 整除的数，就是答案。

```cpp
int ans = a > b ? a : b;   // 从较大的那个数开始
while (ans % a != 0 || ans % b != 0) {
    ans++;
}
```

> 💡 套路：**同时满足两个条件，就用枚举一个一个试。**
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    int ans = a > b ? a : b;   // 从较大的开始
    while (ans % a != 0 || ans % b != 0) {
        ans++;
    }
    cout << ans << endl;
    return 0;
}
```
<!-- end-demo -->
