# 课程03：小数运算

> 🎯 目标：学会用 C++ 算小数，保留小数位，还能给代码写注释！

## 第1关：认识小数盒子

<!-- story -->
小明做数学作业：

> 一个圆的半径是 3 厘米，周长是多少？（π 取 3.14）

他算出来是 `18.84` 厘米。小明想：C++ 能算小数吗？

当然可以！今天我们就来学习！
<!-- end-story -->

---

### 卡片：int 盒子装不下小数

<!-- card type:teacher -->
📦 上节课我们学过，`int` 盒子只能装整数。

```cpp
int a = 3.5;   // 不行！int 会把它变成 3
```

要装小数，需要另一种盒子。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a = 7;
    int b = 2;
    cout << a / b << endl;   // 输出 3，不是 3.5
    return 0;
}
```
<!-- end-demo -->

---

### 卡片：double 是小数盒子

<!-- card type:teacher -->
🔢 `double` 是可以装小数的盒子。小学里我们主要用它。

```cpp
double pi = 3.14;
double height = 1.45;
```

> 💡 `float` 也是小数盒子，但装的小数位数少。我们先用 `double`，更精确。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    double pi = 3.14;
    double r = 3.0;
    double c = 2 * pi * r;    // 计算周长
    cout << c << endl;
    return 0;
}
```
<!-- end-demo -->

## 第2关：保留几位小数

### 卡片：小数也要梳妆打扮

<!-- card type:teacher -->
🤔 小明算出来周长是 `18.84`，但电脑有时候输出 `18.840000` 或 `18.8`，怎么办？

想让电脑按我们的要求显示小数，需要两句口诀一起念：

```cpp
cout << fixed << setprecision(2) << 3.14159 << endl;   // 输出 3.14
```

- `fixed`：固定小数点格式
- `setprecision(2)`：保留 2 位小数
- 它们住在另一个工具箱里：`#include <bits/stdc++.h>`

> 💡 记忆口诀：**fixed 定格式，setprecision 定位数。**
<!-- end-card -->

---

### 卡片：一起用才有效

<!-- card type:teacher -->
🧩 保留 n 位小数的固定写法：

```cpp
#include <bits/stdc++.h>       // 打开小数工具箱

cout << fixed << setprecision(n) << 数字 << endl;
```

例如保留 2 位：

```cpp
cout << fixed << setprecision(2) << 3.14159 << endl;   // 3.14
cout << fixed << setprecision(4) << 3.14159 << endl;   // 3.1416
```

> 💡 小学比赛里，记住"保留几位就写 setprecision(几)"就够了。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
#include <bits/stdc++.h>       // 打开小数工具箱
using namespace std;

int main() {
    double pi = 3.1415926;
    cout << fixed << setprecision(2) << pi << endl;   // 3.14
    cout << fixed << setprecision(4) << pi << endl;   // 3.1416
    return 0;
}
```
<!-- end-demo -->

## 第3关：整数变小数

### 卡片：整数除法会丢尾巴

<!-- card type:teacher -->
🔄 整数除以整数，结果还是整数。想让结果有小数，可以把其中一个变成 `double`。

```cpp
cout << 7 / 2 << endl;          // 3
cout << (double)7 / 2 << endl;  // 3.5
```

`(double)` 就像给整数穿了一件小数外套。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a = 7;
    int b = 2;
    cout << a / b << endl;          // 3
    cout << (double)a / b << endl;  // 3.5
    return 0;
}
```
<!-- end-demo -->

---

### 卡片：四舍五入

<!-- card type:teacher -->
🎯 计算机保留小数时，和数学课一样用"四舍五入"：

```cpp
2.34 → 2.3   // 4 舍去
2.36 → 2.4   // 6 进一
2.35 → 2.4   // 5 进一
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << fixed << setprecision(1);
    cout << 2.34 << endl;   // 2.3
    cout << 2.36 << endl;   // 2.4
    cout << 2.35 << endl;   // 2.4
    return 0;
}
```
<!-- end-demo -->

### 卡片：隐式转换——整数自动变成小数

<!-- card type:teacher -->
🔄 如果把整数放进 `double` 盒子里，C++ 会自动把它变成小数。

```cpp
int a = 5;
double b = a;   // b 变成 5.0
```

但如果两个整数先运算，再放进 `double`，结果仍然是整数除法：

```cpp
int a = 5, b = 2;
double c = a / b;   // a/b 先算得 2，再变成 2.0
```

> 💡 想让结果有小数，必须在运算前就把其中一个变成 `double`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a = 5, b = 2;
    double c = a / b;       // 2.0
    double d = (double)a / b; // 2.5
    cout << c << " " << d << endl;
    return 0;
}
```
<!-- end-demo -->

### 报错也不慌：浮点数有时候不精确

<!-- card type:tip -->
💡 计算机里的小数是用二进制近似存的，有时候会出现一点点误差：

```cpp
cout << fixed << setprecision(15) << 0.1 + 0.2 << endl;
// 可能输出 0.300000000000000，而不是精确的 0.3
```

还有 C++ 保留小数用的是“四舍六入五凑双”：

- `2.34` → `2.3`
- `2.36` → `2.4`
- `2.35` → `2.4`（因为 2.4 的末位是偶数）
- `3.35` → `3.4`（因为 3.4 的末位是偶数）

> 💡 小学比赛里，记住“保留几位就写 setprecision(几)”就够了。如果结果差 0.01，可能是浮点误差，不用慌。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << fixed << setprecision(1);
    cout << 2.35 << endl;   // 2.4
    cout << 3.35 << endl;   // 3.4
    return 0;
}
```
<!-- end-demo -->

---

### 卡片：小数误差不用怕

<!-- card type:teacher -->
🤔 为什么 `0.1 + 0.2` 不是精确的 `0.3`？

你可以把电脑想成一个小学生，它只会用"二进制"记数字。就像我们用十进制写 `1/3 = 0.3333...` 永远写不完一样，电脑用二进制存一些小数时也会"写不完"，所以会有一点点误差。

**你现在只需要记住两点：**
1. 题目说保留几位小数，就写 `fixed << setprecision(几)`。
2. 如果最后答案差 `0.01` 或 `0.0001`，很可能是电脑的小误差，不用慌。

> 💡 "四舍六入五凑双"是 C++ 的一种特殊规则，对小学生来说太绕了。比赛时先用 `setprecision` 保留题目要求的位数，如果和答案差一点点，先检查是不是算错了，再考虑误差。
<!-- end-card -->

## 第4关：注释与实战

### 卡片：注释是给人类看的说明

<!-- card type:teacher -->
📝 注释是写在代码里的说明，电脑会忽略它，但人类能看懂。

- 单行注释：`// 这是说明`
- 多行注释：`/* 这是说明 */`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    double r = 3.0;     // 圆的半径
    double pi = 3.14;   // π 的近似值
    /* 下面计算圆的面积 */
    double area = pi * r * r;
    cout << area << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：计算圆的面积

<!-- card type:computer -->
🖥️ 输入圆的半径，输出圆的面积。

> 公式：`面积 = π × 半径 × 半径`，π 取 3.14，保留 2 位小数。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    double r;
    cin >> r;
    double pi = 3.14;
    double area = pi * r * r;
    cout << fixed << setprecision(2) << area << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 用 `double` 类型存储小数
- 小数乘法运算
- 用 `fixed << setprecision(n)` 保留小数
- 包含头文件 `#include <bits/stdc++.h>`

**解题思路分步说明**

1. 读入圆的半径 `r`（用 `double` 类型）。
2. 定义 `pi = 3.14`。
3. 根据公式 `area = pi * r * r` 计算面积。
4. 使用 `fixed << setprecision(2)` 输出，保留 2 位小数。

**容易错的地方**

- 忘记写 `#include <bits/stdc++.h>`，导致 `setprecision` 报错
- 漏写 `fixed`，结果可能不是想要的小数格式
- π 写成整数 `3`，导致结果没有小数
- 保留位数写错，比如写成 `setprecision(3)`

**关键代码解释**

```cpp
cout << fixed << setprecision(2) << area << endl;
```

- `fixed` 表示"固定小数点格式"。
- `setprecision(2)` 表示保留 2 位小数。
- 这两个要一起用，并且写在要输出的数字前面。
<!-- end-card -->

## 挑战 2：分转元

<!-- card type:computer -->
🖥️ 输入一个整数表示总金额（分），输出转换后的元，保留 2 位小数。

> 比如输入 `185`，输出 `1.85`。
>
> 💡 方法不唯一。你可以用 `(double)fen / 100`，也可以用 `fen / 100.0`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int fen;
    cin >> fen;
    double yuan = (double)fen / 100;   // 方法 1：给 fen 穿小数外套
    // double yuan = fen / 100.0;        // 方法 2：除数写成小数
    cout << fixed << setprecision(2) << yuan << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 整数转小数的除法
- 强制类型转换 `(double)`
- 保留 2 位小数输出

**解题思路分步说明**

1. 读入整数 `fen`，表示总金额的分。
2. 因为 1 元 = 100 分，所以元 = 分 ÷ 100。
3. 如果直接写 `fen / 100`，两个整数相除结果还是整数，会丢失小数。
4. 先把 `fen` 转换成 `double`，或者用 `100.0` 作为除数，再进行除法。
5. 用 `fixed << setprecision(2)` 保留 2 位小数输出。

**容易错的地方**

- 直接写 `fen / 100`，得到整数结果，丢失分
- 忘了保留 2 位小数
- 类型转换的位置放错，比如 `(double)(fen / 100)` 仍然先做了整数除法

**关键代码解释**

```cpp
double yuan = (double)fen / 100;
```

- `(double)fen` 先把整数 `fen` 变成小数。
- 再除以 `100`，结果才是带小数的元。
- 也可以写成 `fen / 100.0`，效果一样。
<!-- end-card -->


不然电脑会不认识 `setprecision`！

## 卡片：温度转换

<!-- card type:teacher -->
🌡️ 真题里经常考温度换算。记住两个公式：

- 摄氏温度 `C = K - 273.15`
- 华氏温度 `F = C × 1.8 + 32`

输入一个开尔文温度 `K`，输出对应的摄氏温度和华氏温度。

> 💡 看到“保留几位小数”就想到 `fixed << setprecision(n)`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    double k;
    cin >> k;
    double c = k - 273.15;
    double f = c * 1.8 + 32;
    cout << fixed << setprecision(2) << c << " " << f << endl;
    return 0;
}
```
<!-- end-demo -->
