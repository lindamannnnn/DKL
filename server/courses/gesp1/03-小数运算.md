## 🧩 知识点一：实数类型 float 和 double

### 什么是实数类型？

实数类型就是可以存放小数的类型。C++ 中常用的有两种：

| 类型 | 名称 | 精度 | 说明 |
|------|------|------|------|
| `float` | 单精度浮点数 | 约 6-7 位有效数字 | 占用空间小 |
| `double` | 双精度浮点数 | 约 15-16 位有效数字 | 更常用，精度更高 |

小学阶段，我们主要用 `double`。

### 声明和初始化

```cpp
#include <iostream>
using namespace std;

int main() {
    double pi = 3.14;
    double radius = 3.0;
    double circumference = 2 * pi * radius;
    cout << circumference << endl;
    return 0;
}
```
<!-- run -->

### float 和 double 的区别

```cpp
#include <iostream>
using namespace std;

int main() {
    float a = 1.0 / 3.0;
    double b = 1.0 / 3.0;
    cout << "float:  " << a << endl;
    cout << "double: " << b << endl;
    return 0;
}
```
<!-- run -->

> 小提示：`double` 能记住更多小数位，所以我们平时写小数程序时优先用 `double`。

## 🔢 知识点二：有效数字与位数保留

### 有效数字

有效数字就是一个数里从第一个非零数字开始，到最后一位数字结束的所有数字。

例如：
- `3.14` 有 3 位有效数字
- `0.50` 有 2 位有效数字
- `123.0` 有 4 位有效数字

### 保留小数位数

在 C++ 中，用 `fixed` 和 `setprecision(n)` 可以保留 n 位小数。

```cpp
#include <iostream>
#include <iomanip>   // 需要包含这个头文件
using namespace std;

int main() {
    double pi = 3.1415926;
    cout << fixed << setprecision(2) << pi << endl;   // 输出 3.14
    cout << fixed << setprecision(4) << pi << endl;   // 输出 3.1416
    return 0;
}
```
<!-- run -->

### 🎯 小口诀

> 保留小数用 `fixed`，后面紧跟 `setprecision(n)`，n 是几位小数！

## 🎯 知识点三：四舍六入五凑双

### 什么是四舍六入五凑双？

我们平时说的"四舍五入"，在计算机里有时候会用更精确的"四舍六入五凑双"规则。

规则：
- 要保留的下一位小于 5，直接舍去（四舍）
- 要保留的下一位大于 5，进一（六入）
- 要保留的下一位等于 5，看保留位的最后一位：
  - 如果是奇数，就进一
  - 如果是偶数，就舍去

### 例子

| 原数 | 保留 1 位小数 | 说明 |
|------|--------------|------|
| 2.34 | 2.3 | 4 舍去 |
| 2.36 | 2.4 | 6 进一 |
| 2.25 | 2.2 | 5 前面是 2（偶数），舍去 |
| 2.35 | 2.4 | 5 前面是 3（奇数），进一 |

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    cout << fixed << setprecision(1);
    cout << 2.34 << endl;   // 2.3
    cout << 2.36 << endl;   // 2.4
    cout << 2.25 << endl;   // 2.2
    cout << 2.35 << endl;   // 2.4
    return 0;
}
```
<!-- run -->

> 为什么用"五凑双"？因为它能让舍入更公平，多次计算时误差更小。就像两个人分糖果，这次你多一颗，下次我多一颗。
>
> ⚠️ 小提示：由于计算机中小数存储有精度限制，某些数字（如 2.45）实际输出可能和理论规则略有不同。上面的例子选的是能正确展示规则的数字。

## 🔄 知识点四：整数类型转为小数类型

### 整数除法的问题

还记得吗？整数除以整数，结果还是整数，小数部分会被丢掉。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 7;
    int b = 2;
    cout << a / b << endl;   // 输出 3，不是 3.5
    return 0;
}
```
<!-- run -->

### 把整数变成小数再除

如果我们想让结果变成小数，可以把其中一个数变成 `double`。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 7;
    int b = 2;
    cout << (double)a / b << endl;   // 输出 3.5
    return 0;
}
```
<!-- run -->

### 隐式转换

如果把整数赋给小数变量，整数会自动变成小数。

```cpp
#include <iostream>
using namespace std;

int main() {
    double x = 10;      // 10 自动变成 10.0
    cout << x << endl;
    return 0;
}
```

## 📝 知识点五：程序的注释

### 什么是注释？

注释是写给人看的说明文字，电脑会忽略它。好的注释能让别人更容易读懂我们的代码。

### 单行注释

用 `//` 开头，后面整行都是注释。

```cpp
int age = 10;   // 年龄
```

### 多行注释

用 `/*` 开头，`*/` 结尾，中间可以写很多行。

```cpp
/*
  这是一个多行注释
  下面计算圆的面积
*/
double area = 3.14 * r * r;
```

### 什么时候写注释？

- 说明一段代码的作用
- 解释复杂的计算
- 提醒自己或别人注意事项

```cpp
#include <iostream>
using namespace std;

int main() {
    double r = 3.0;     // 圆的半径
    double pi = 3.14;   // π 的近似值
    // 计算圆的面积
    double area = pi * r * r;
    cout << area << endl;
    return 0;
}
```
