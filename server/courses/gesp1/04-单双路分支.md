## 🧩 知识点一：布尔判断与 bool 类型

### 什么是布尔？

布尔类型只有两个值：

- `true`：真、对、是
- `false`：假、错、否

```cpp
#include <iostream>
using namespace std;

int main() {
    bool isSunny = true;
    bool isRainy = false;
    cout << isSunny << " " << isRainy << endl;   // 输出 1 0
    return 0;
}
```
<!-- run -->

> 在 C++ 中，`true` 用 `1` 表示，`false` 用 `0` 表示。

## 🔍 知识点二：关系运算符

关系运算符用来比较两个数的大小关系。

| 运算符 | 含义 | 例子 | 结果 |
|--------|------|------|------|
| `>` | 大于 | `5 > 3` | true |
| `<` | 小于 | `5 < 3` | false |
| `>=` | 大于等于 | `5 >= 5` | true |
| `<=` | 小于等于 | `5 <= 3` | false |
| `==` | 等于 | `5 == 5` | true |
| `!=` | 不等于 | `5 != 3` | true |

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 3;
    cout << (a > b) << endl;   // 1
    cout << (a == b) << endl;  // 0
    cout << (a != b) << endl;  // 1
    return 0;
}
```
<!-- run -->

> ⚠️ 注意：判断相等用 `==`，不是 `=`！`=` 是赋值符号。

## 🛤️ 知识点三：单分支 if 与双分支 if-else

### 单分支 if

如果条件成立，就执行里面的代码。

```cpp
#include <iostream>
using namespace std;

int main() {
    int age;
    cin >> age;
    if (age >= 18) {
        cout << "你已经成年啦！" << endl;
    }
    return 0;
}
```
<!-- run -->

### 双分支 if-else

如果条件成立，执行 `if` 里的代码；否则执行 `else` 里的代码。

```cpp
#include <iostream>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 60) {
        cout << "及格啦！" << endl;
    } else {
        cout << "还要努力哦！" << endl;
    }
    return 0;
}
```
<!-- run -->

### 🎯 小口诀

> `if` 判断真，条件成立才执行；带上 `else`，二选一走一边。

## 🔢 知识点四：奇偶判断与倍数判断

### 判断奇偶

一个数除以 2 的余数是 0，就是偶数；否则是奇数。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n % 2 == 0) {
        cout << "偶数" << endl;
    } else {
        cout << "奇数" << endl;
    }
    return 0;
}
```
<!-- run -->

### 判断倍数

判断 `a` 是不是 `b` 的倍数：看 `a % b` 是否等于 0。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    if (a % b == 0) {
        cout << a << " 是 " << b << " 的倍数" << endl;
    } else {
        cout << a << " 不是 " << b << " 的倍数" << endl;
    }
    return 0;
}
```
<!-- run -->

## ❓ 知识点五：三目运算符

三目运算符是 `if-else` 的简写形式。

格式：
```cpp
条件 ? 值1 : 值2
```

如果条件成立，返回值 1；否则返回值 2。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    int maxNum = (a > b) ? a : b;
    cout << "较大的数是：" << maxNum << endl;
    return 0;
}
```
<!-- run -->

> 三目运算符适合简单的二选一情况，复杂判断还是用 `if-else` 更清晰。
