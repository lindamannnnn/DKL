## 本课练习要点

<!-- card type:teacher -->
🧑‍🏫 这节课我们不学新语法，只复习三个老朋友：

- `cin` 和 `cout`：让程序读写数据
- 整数运算：`+ - * / %`，注意整数除法会吃掉小数
- 小数运算：用 `double` 和 `fixed + setprecision` 保留小数

练习时要注意：
1. **审题**：看清输入几个数、输出什么、要不要保留小数。
2. **整数除法**：两个整数相除会自动丢小数，算平均分时记得除以 `3.0` 或 `(double)`。
3. **小数输出**：只要看到"保留几位小数"，就要加 `#include <bits/stdc++.h>`，并写 `fixed << setprecision(n)`。
4. **单位换算**：分和元、秒和分、米和千米，做题前先统一单位。
<!-- end-card -->

## 挑战 1：整数求和热身

<!-- card type:computer -->
🖥️ 输入两个整数，输出它们的和。这是最简单的热身题！

输入：两个整数 a 和 b，用空格隔开。
输出：一个整数，表示 a + b 的结果。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 2：计算平均分

<!-- card type:computer -->
🖥️ 输入语文、数学、英语三科成绩，输出总分和平均分（保留 1 位小数）。

输入：三个整数，分别表示三科成绩。
输出：第一行输出总分，第二行输出平均分（保留 1 位小数）。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    int total = a + b + c;
    double avg = total / 3.0;
    cout << "总分：" << total << endl;
    cout << fixed << setprecision(1) << "平均分：" << avg << endl;
    return 0;
}
```
<!-- end-demo -->

---

### 报错也不慌：整数除法常见错

<!-- card type:tip -->
💡 如果算平均分，千万不要写 `total / 3`！

两个整数相除，小数会被“吃掉”。要写 `total / 3.0` 才能让结果变成小数。
<!-- end-card -->

<!-- demo -->
```cpp
int total = 7;
cout << total / 3;      // 输出 2 ❌ 小数被吃掉
cout << total / 3.0;    // 输出 2.333 ✅ 正确
```
<!-- end-demo -->

## 挑战 3：长方形周长和面积

<!-- card type:computer -->
🖥️ 输入长方形的长和宽，输出它的周长和面积。

输入：两个整数 a 和 b，分别表示长和宽。
输出：两个整数，分别表示周长和面积，中间用空格隔开。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << (a + b) * 2 << " " << a * b << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 4：购物找零

<!-- card type:computer -->
🖥️ 输入商品总价和付款金额，输出应找回的零钱，保留 2 位小数。

输入：两个数 total 和 pay，分别表示总价和付款金额。
输出：一个数，表示找回的零钱。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    double total, pay;
    cin >> total >> pay;
    double change = pay - total;
    cout << fixed << setprecision(2) << change << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 5：平均速度

<!-- card type:computer -->
🖥️ 输入路程（米）和时间（秒），计算平均速度，保留 2 位小数。

输入：两个整数 s 和 t。
输出：一个数，表示平均速度（米/秒）。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int s, t;
    cin >> s >> t;
    double v = (double)s / t;
    cout << fixed << setprecision(2) << v << endl;
    return 0;
}
```
<!-- end-demo -->
