## 卡片：小知识：bool 只有两种答案

<!-- card type:teacher -->
✅❌ `bool` 是一种特殊的盒子，里面只能装两种答案：

- `true`：真、对、是
- `false`：假、错、否

在 C++ 里，`true` 显示为 `1`，`false` 显示为 `0`。

> 💡 就像开关：开是 1，关是 0。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    bool isSunny = true;
    bool isRainy = false;
    cout << isSunny << " " << isRainy << endl;   // 输出 1 0
    return 0;
}
```
<!-- end-demo -->

## 卡片：关系运算符是比大小

<!-- card type:teacher -->
🔍 关系运算符用来比较两个数，比较的结果电脑会自己判断。

| 符号 | 含义 |
|------|------|
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |
| `==` | 等于 |
| `!=` | 不等于 |

> ⚠️ 判断相等是 `==`，不是 `=`！`=` 是把右边的值放进左边。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a = 5, b = 3;
    cout << (a > b) << endl;   // 1（真）
    cout << (a == b) << endl;  // 0（假）
    cout << (a != b) << endl;  // 1（真）
    return 0;
}
```
<!-- end-demo -->

## 卡片：单分支 if

<!-- card type:teacher -->
🛤️ `if` 就像一扇门：条件成立，门就打开，执行里面的代码；条件不成立，就跳过。

```cpp
if (条件) {
    // 条件成立时执行
}
```

> 💡 大括号 `{}` 就像一个小书包，把条件成立时要一起执行的代码装进去。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int age;
    cin >> age;
    if (age >= 18) {
        cout << "你已经成年啦！" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 卡片：双分支 if-else

<!-- card type:teacher -->
🔄 `if-else` 就像岔路口：条件成立走 `if` 这条路，不成立走 `else` 那条路。

```cpp
if (条件) {
    // 条件成立时执行
} else {
    // 条件不成立时执行
}
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 60) {
        cout << "及格啦！" << endl;
    } else {
        cout << "还要努力哦！" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 卡片：判断奇偶

<!-- card type:teacher -->
🔢 上节课学过 `%` 取余。用 `% 2` 可以判断奇偶：

- `n % 2 == 0` → 偶数
- `n % 2 != 0` → 奇数
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n % 2 == 0) {
        cout << "偶数" << endl;
    } else {
        cout << "奇数" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 卡片：判断倍数

<!-- card type:teacher -->
🍭 判断 `a` 是不是 `b` 的倍数，就看 `a % b` 是否等于 0。

```cpp
if (a % b == 0) {
    // a 是 b 的倍数
}
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    if (a % b == 0) {
        cout << a << " 是 " << b << " 的倍数" << endl;
    } else {
        cout << a << " 不是 " << b << " 的倍数" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：判断成绩

<!-- card type:computer -->
🖥️ 输入一个成绩，如果大于等于 60 输出"及格"，否则输出"不及格"。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 60) {
        cout << "及格" << endl;
    } else {
        cout << "不及格" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 关系运算符 `>=`
- 双分支 `if-else` 结构
- 根据条件输出不同结果

**解题思路分步说明**

1. 定义整数变量 `score`，用 `cin` 读入成绩。
2. 判断 `score >= 60` 是否成立。
3. 如果成立，输出"及格"。
4. 如果不成立，输出"不及格"。

**容易错的地方**

- 把 `>=` 写成 `=>`
- `if` 后面的条件没有加小括号
- 大括号只写了左半边，忘记右半边
- 输出文字时缺少双引号

**关键代码解释**

```cpp
if (score >= 60) {
    cout << "及格" << endl;
} else {
    cout << "不及格" << endl;
}
```

- `if (score >= 60)` 判断成绩是否达到 60 分。
- 条件成立执行 `if` 后面大括号里的代码，否则执行 `else` 后面大括号里的代码。
- 两个分支只会走一个。
<!-- end-card -->

## 挑战 2：判断能否被 3 整除

<!-- card type:computer -->
🖥️ 输入一个整数，判断它能否被 3 整除。

> 提示：能被 3 整除，就是 `n % 3 == 0`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n % 3 == 0) {
        cout << "能被 3 整除" << endl;
    } else {
        cout << "不能被 3 整除" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 取余运算符 `%`
- `if-else` 分支结构
- 倍数判断方法

**解题思路分步说明**

1. 读入整数 `n`。
2. 计算 `n % 3`，得到 `n` 除以 3 的余数。
3. 如果余数为 0，说明 `n` 能被 3 整除。
4. 否则，说明不能被 3 整除。

**容易错的地方**

- 用 `n / 3 == 0` 来判断整除（这是错的，得到的是商）
- 把 `==` 写成 `=`，变成赋值
- 判断余数时把条件写成 `n % 3 != 0`

**关键代码解释**

```cpp
if (n % 3 == 0)
```

- `n % 3` 计算 `n` 除以 3 的余数。
- `== 0` 判断余数是否为 0。
- 只有余数为 0 时，`n` 才是 3 的倍数。
<!-- end-card -->

## 报错也不慌：== 和 = 别搞反

<!-- card type:tip -->
💡 判断相等用 `==`，赋值用 `=`。很多小朋友第一次都会写错！

如果报错 `expected primary-expression before '=' token`，很可能就是把 `==` 写成了 `=`。

> 别担心，改过来就好。记住：判断像天平 `==`，赋值像箭头 `=`。
<!-- end-card -->

<!-- demo -->
```cpp
int a = 5;
if (a == 5) {        // ✅ 判断 a 是否等于 5
    cout << "对的";
}
if (a = 5) {         // ❌ 这是把 5 塞进 a
    cout << "错的";
}
```
<!-- end-demo -->

## 小贴士：== 和 = 别搞反

<!-- hint -->
- `=` 是赋值：把右边的值放进左边
  ```cpp
  int a = 10;   // 把 10 放进 a
  ```
- `==` 是判断：看两边是否相等
  ```cpp
  if (a == 10)  // a 等于 10 吗？
  ```

很多小朋友会写错，一定要小心！
<!-- end-hint -->
