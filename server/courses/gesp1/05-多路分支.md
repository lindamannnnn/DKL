## 🛤️ 知识点一：多分支 if-else if-else

### 什么时候用多分支？

当一个事情有多种可能时，用多分支判断。

```cpp
#include <iostream>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 90) {
        cout << "优秀" << endl;
    } else if (score >= 80) {
        cout << "良好" << endl;
    } else if (score >= 60) {
        cout << "及格" << endl;
    } else {
        cout << "不及格" << endl;
    }
    return 0;
}
```
<!-- run -->

### 执行顺序

从上到下依次判断，哪个条件先成立，就执行哪个分支，后面的不再判断。

> 就像排队上车，找到属于你的那一站就下车。

## 🔗 知识点二：逻辑运算符

有时候一个判断需要同时满足多个条件，就要用逻辑运算符。

| 运算符 | 名称 | 含义 | 例子 |
|--------|------|------|------|
| `&&` | 与 | 两边都成立，结果才成立 | `a > 0 && b > 0` |
| `\|\|` | 或 | 只要一边成立，结果就成立 | `a > 0 \|\| b > 0` |
| `!` | 非 | 取反 | `!(a > 0)` |

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = -3;
    cout << (a > 0 && b > 0) << endl;   // 0
    cout << (a > 0 || b > 0) << endl;   // 1
    cout << !(a > 0) << endl;           // 0
    return 0;
}
```
<!-- run -->

### 生活中的例子

- `&&`：既要完成作业，又要复习，才能出去玩。
- `||`：只要下雨或者下雪，就不上体育课。
- `!`：如果不是周末，就要上学。

## 📊 知识点三：运算符优先级

当表达式里有多种运算符时，要按优先级计算。

常见优先级（从高到低）：

1. 算术运算符：`*`、`/`、`%`
2. 算术运算符：`+`、`-`
3. 关系运算符：`>`、`<`、`>=`、`<=`
4. 关系运算符：`==`、`!=`
5. 逻辑运算符：`!`
6. 逻辑运算符：`&&`
7. 逻辑运算符：`||`

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 3, c = 8;
    // 先算 a + b，再和 c 比较
    if (a + b > c && c > 0) {
        cout << "成立" << endl;
    }
    return 0;
}
```
<!-- run -->

> 不确定优先级时，可以多加小括号，让代码更清晰。

## 📅 知识点四：闰年平年判断

闰年规则：
- 能被 4 整除，但不能被 100 整除；或者
- 能被 400 整除。

```cpp
#include <iostream>
using namespace std;

int main() {
    int year;
    cin >> year;
    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
        cout << "闰年" << endl;
    } else {
        cout << "平年" << endl;
    }
    return 0;
}
```
<!-- run -->

### 拆解条件

- `year % 4 == 0`：能被 4 整除
- `year % 100 != 0`：不能被 100 整除
- `year % 400 == 0`：能被 400 整除
- 整体：`能被4整除且不能被100整除` 或者 `能被400整除`
