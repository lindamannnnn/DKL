# 课程06：分支嵌套与多条件

> 🎯 目标：学会在 `if` 里面再写 `if`，以及把多个条件组合起来判断！

---

## 故事：考试成绩评级

<!-- story -->
老师给小明发成绩单：

> 先看是否及格；
> 及格了再看是不是优秀（90 分以上）；
> 没及格就是不及格。

这就需要**先判断一次，再判断一次**，也就是 `if` 里面再写 `if`。

## 卡片：上节课复习

<!-- card type:teacher -->
🔄 上节课我们学了 `if-else` 二选一：

```cpp
if (条件) {
    // 成立时执行
} else {
    // 不成立时执行
}
```

这节课我们在它的基础上继续加深：
- `if` 里面再写 `if`（嵌套）
- 多个条件一起判断（组合条件）
<!-- end-card -->

---

## 卡片：if 里面还能写 if

<!-- card type:teacher -->
🎯 大括号 `{}` 里面可以写任意代码，包括再写一个 `if`。

比如先判断及格，再判断优秀：

```cpp
if (score >= 60) {
    if (score >= 90) {
        cout << "优秀" << endl;
    } else {
        cout << "及格" << endl;
    }
} else {
    cout << "不及格" << endl;
}
```

> 💡 这叫做**嵌套 if**。像俄罗斯套娃，一层套一层。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 60) {
        if (score >= 90) {
            cout << "优秀" << endl;
        } else {
            cout << "及格" << endl;
        }
    } else {
        cout << "不及格" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 卡片：多个条件组合判断

<!-- card type:teacher -->
🧩 有时候一个条件不够，要同时满足好几个条件。

比如“年龄大于 6 岁，并且身高超过 1.2 米”：

```cpp
if (age > 6 && height > 1.2) {
    cout << "可以买儿童票" << endl;
}
```

常用的组合：
- `&&`：并且，两边都要成立
- `||`：或者，一边成立就行

> 💡 复杂条件加小括号，先算小括号里的。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int age;
    double height;
    cin >> age >> height;
    if (age > 6 && height > 1.2) {
        cout << "可以买儿童票" << endl;
    } else {
        cout << "不能买儿童票" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：判断成绩等级

<!-- card type:computer -->
🖥️ 输入一个成绩，按下面规则输出：
- 90 分及以上：优秀
- 60 ~ 89 分：及格
- 60 分以下：不及格
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 60) {
        if (score >= 90) {
            cout << "优秀" << endl;
        } else {
            cout << "及格" << endl;
        }
    } else {
        cout << "不及格" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
🧑‍🏫 评讲逻辑：

- **考察知识点**：嵌套 `if-else` 的使用，根据多个条件分支输出不同结果。
- **解题思路**：
  1. 先判断成绩是否大于等于 60 分，区分及格和不及格两大分支。
  2. 在及格分支里再判断一次是否大于等于 90 分，区分优秀和及格。
- **容易错的地方**：
  - 嵌套层次写乱，大括号 `}` 配对错误。
  - 条件判断顺序写错，导致部分分支永远执行不到。
- **关键代码解释**：
  - `if (score >= 60)`：第一层判断，筛出及格线。
  - `if (score >= 90)`：在及格的基础上再判断优秀。
  - `else`：对应最近的一个 `if`，表示不满足该条件时执行。
<!-- end-card -->

## 挑战 2：判断能否参加运动会

<!-- card type:computer -->
🖥️ 输入年龄和身高，只有年龄 ≥ 10 岁，并且身高 ≥ 1.3 米，才能参加。

输出 `Yes` 或 `No`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int age;
    double height;
    cin >> age >> height;
    if (age >= 10 && height >= 1.3) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
🧑‍🏫 评讲逻辑：

- **考察知识点**：逻辑运算符 `&&`（并且）的使用。
- **解题思路**：
  1. 读入年龄 age 和身高 height。
  2. 判断两个条件是否同时成立：年龄 ≥ 10 并且身高 ≥ 1.3。
  3. 同时成立输出 `Yes`，否则输出 `No`。
- **容易错的地方**：
  - 写成两个独立的 `if`，导致条件判断逻辑错误。
  - 把 `&&` 写成 `||`，变成满足一个条件即可。
  - 身高变量类型用 `int`，导致 1.3 这类小数读入错误。
- **关键代码解释**：
  - `if (age >= 10 && height >= 1.3)`：只有两边都成立，整个条件才成立。
  - `else`：只要有一个条件不成立，就走这里。
<!-- end-card -->

## 报错也不慌：== 和 = 别搞反

<!-- card type:tip -->
💡 判断相等用 `==`，赋值用 `=`。很多小朋友第一次都会写错！

如果报错 `expected primary-expression before '=' token`，很可能就是把 `==` 写成了 `=`。

> 别担心，改过来就好。记住：判断像天平 `==`，赋值像箭头 `=`。
<!-- end-card -->

<!-- demo -->
```cpp
int a = 5;
if (a == 5) {        // ✅ 判断 a 是否等于 5
    cout << "对的";
}
if (a = 5) {         // ❌ 这是把 5 塞进 a
    cout << "错的";
}
```
<!-- end-demo -->
