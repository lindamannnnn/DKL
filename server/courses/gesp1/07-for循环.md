## 🔄 知识点一：for 循环结构

### for 循环的格式

```cpp
for (初始化; 条件; 步进) {
    // 循环体：重复执行的代码
}
```

三个部分：
1. **初始化**：设置循环变量的初始值
2. **条件**：满足条件才继续循环
3. **步进**：每次循环后让循环变量变化

### 例子：数到 5

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```
<!-- run -->

**输出：**
```
1 2 3 4 5
```

### 执行过程

1. `int i = 1`：i 从 1 开始
2. `i <= 5`：判断条件，成立就执行循环体
3. `cout << i`：输出 i
4. `i++`：i 增加 1
5. 回到第 2 步，直到条件不成立

## 🌍 知识点二：全局变量与局部变量

### 局部变量

在函数内部或 `{}` 内部定义的变量，只能在这个范围内使用。

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 3; i++) {
        int x = i * 10;   // x 是局部变量，只在 for 循环内有效
        cout << x << " ";
    }
    // cout << x;   // 错误！x 在外面不能用
    return 0;
}
```
<!-- run -->

### 全局变量

在所有函数外面定义的变量，整个程序都能用。

```cpp
#include <iostream>
using namespace std;

int total = 0;   // 全局变量

int main() {
    total = total + 10;
    cout << total << endl;
    return 0;
}
```
<!-- run -->

> 初学者建议多用局部变量，需要时再使用全局变量。

## ➕ 知识点三：变量自增与自减运算

### 自增 `++`

`i++` 等价于 `i = i + 1`。

```cpp
int i = 5;
i++;       // i 变成 6
```

### 自减 `--`

`i--` 等价于 `i = i - 1`。

```cpp
int i = 5;
i--;       // i 变成 4
```

### 常见用法

```cpp
for (int i = 0; i < 5; i++)   // i 从 0 到 4
for (int i = 5; i >= 1; i--)  // i 从 5 到 1
```

## 🎯 知识点四：循环 + 判断

循环和判断可以配合使用，解决更复杂的问题。

### 例子：输出 1~10 中的偶数

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i % 2 == 0) {
            cout << i << " ";
        }
    }
    cout << endl;
    return 0;
}
```
<!-- run -->

### 例子：累加 1~100

```cpp
#include <iostream>
using namespace std;

int main() {
    int sum = 0;
    for (int i = 1; i <= 100; i++) {
        sum = sum + i;
    }
    cout << sum << endl;
    return 0;
}
```
