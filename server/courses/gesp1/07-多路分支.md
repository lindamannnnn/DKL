## 卡片：多分支就像排队上车

<!-- card type:teacher -->
🚌 `if-else if-else` 就像排队上车：

- 先判断第一个条件
- 不成立就判断第二个
- 再不成立就判断第三个
- 最后都不成立，走 `else`

```cpp
if (条件1) {
    // 条件1 成立
} else if (条件2) {
    // 条件2 成立
} else {
    // 都不成立
}
```

> 💡 只会执行其中一个分支，找到就"下车"。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 90) {
        cout << "优秀" << endl;
    } else if (score >= 80) {
        cout << "良好" << endl;
    } else if (score >= 60) {
        cout << "及格" << endl;
    } else {
        cout << "不及格" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 卡片：&& 表示"并且"

<!-- card type:teacher -->
🔗 `&&` 读作"并且"。两边条件都成立，结果才成立。

生活例子：既要完成作业，**并且**要复习，才能出去玩。

```cpp
a > 0 && b > 0   // a 大于 0 并且 b 大于 0
```

> 💡 口诀：两个 `&` 是并且，两边都要对。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a = 5, b = -3;
    cout << (a > 0 && b > 0) << endl;   // 0（false）
    cout << (a > 0 && a < 10) << endl;  // 1（true）
    return 0;
}
```
<!-- end-demo -->

## 卡片：|| 表示"或者"

<!-- card type:teacher -->
🔗 `||` 读作"或者"。两边条件只要有一个成立，结果就成立。

生活例子：今天下雨，**或者**我没带伞，就要坐公交。

```cpp
a > 0 || b > 0   // a 大于 0 或者 b 大于 0
```

> 💡 口诀：两个 `|` 是或者，有一个对就对。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a = 5, b = -3;
    cout << (a > 0 || b > 0) << endl;   // 1（true，因为 a 对）
    cout << (a < 0 || b < 0) << endl;   // 1（true，因为 b 对）
    return 0;
}
```
<!-- end-demo -->

---

## 卡片：! 表示"不是"

<!-- card type:teacher -->
🚫 `!` 读作"非"或"不是"，用来把结果反过来。

```cpp
!(a > 0)   // a 不大于 0，也就是 a <= 0
!(a == b)  // a 不等于 b
```

> 💡 口诀：`!` 像一把反转剑，真的变假，假的变真。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a = 5;
    cout << !(a > 0) << endl;   // 0（false）
    cout << !(a == 5) << endl;  // 0（false）
    return 0;
}
```
<!-- end-demo -->

## 卡片：运算符优先级

<!-- card type:teacher -->
🥇 一个式子里有多种运算时，C++ 会按优先级先算谁：

| 优先级 | 运算符 | 例子 |
|--------|--------|------|
| 1（最高）| 算术运算 | `* / %` 先算，再算 `+ -` |
| 2 | 关系运算 | `> >= < <= == !=` |
| 3 | 逻辑运算 | `!` 最先，然后 `&&`，最后 `||` |
| 4（最低）| 赋值 | `=` |

```cpp
5 + 3 > 4 && 2 < 7   // 先算 5+3=8，再比 8>4，再比 2<7，最后 &&
```

> 💡 如果不确定，就加小括号 `()`，小括号里的永远先算。
<!-- end-card -->

## 报错也不慌：大括号别配对错

<!-- card type:tip -->
💡 写多分支时，最容易漏掉某个 `}`！

如果电脑报错 "expected `}` before `else`"，说明你的大括号没配对好。

> 小技巧：每个 `{` 下面找个对齐的 `}`，像找朋友一样。
<!-- end-card -->

<!-- demo -->
```cpp
if (score >= 90) {          // 开括号
    cout << "A" << endl;
} else if (score >= 80) {   // 关一个，开一个
    cout << "B" << endl;
} else {                    // 关一个，开一个
    cout << "C" << endl;
}                           // 关最后一个 ✅
```
<!-- end-demo -->

## 挑战 1：成绩等级

<!-- card type:computer -->
🖥️ 输入一个成绩，输出它的等级。

> 90 分以上：优秀  
> 80-89 分：良好  
> 60-79 分：及格  
> 60 分以下：不及格
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 90) {
        cout << "优秀" << endl;
    } else if (score >= 80) {
        cout << "良好" << endl;
    } else if (score >= 60) {
        cout << "及格" << endl;
    } else {
        cout << "不及格" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
🧑‍🏫 评讲逻辑：

- **考察知识点**：多路分支 `if-else if-else` 的结构和条件顺序。
- **解题思路**：
  1. 读入成绩 score。
  2. 按分数从高到低依次判断：先判断 90 分以上，再 80 分以上，再 60 分以上。
  3. 最后都不满足就是不及格。
- **容易错的地方**：
  - 条件顺序写反，比如先写 `score >= 60`，再写 `score >= 90`，导致优秀分支永远执行不到。
  - 漏写 `else`，变成多个独立 `if`，可能输出多个结果。
- **关键代码解释**：
  - `if (score >= 90)`：第一个分支，最高分。
  - `else if (score >= 80)`：前一个条件不成立时才判断。
  - `else`：所有条件都不成立时执行。
<!-- end-card -->

## 挑战 2：判断能否被 3 和 5 同时整除

<!-- card type:computer -->
🖥️ 输入一个整数，判断它能否同时被 3 和 5 整除。

> 提示：要用 `&&`（并且）。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n % 3 == 0 && n % 5 == 0) {
        cout << "能同时被 3 和 5 整除" << endl;
    } else {
        cout << "不能" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
🧑‍🏫 评讲逻辑：

- **考察知识点**：逻辑运算符 `&&`（并且）配合取模运算 `%`。
- **解题思路**：
  1. 读入整数 n。
  2. 判断 `n % 3 == 0 && n % 5 == 0` 是否成立。
  3. 成立输出“能同时被 3 和 5 整除”，否则输出“不能”。
- **容易错的地方**：
  - 写成 `n % 3 == 0 || n % 5 == 0`，变成能被其中一个整除即可。
  - 把 `==` 写成 `=`，导致赋值而不是判断。
  - 忘记 `&&` 两边的条件都要完整写出。
- **关键代码解释**：
  - `n % 3 == 0`：n 除以 3 的余数为 0。
  - `&&`：两边都成立，结果才成立。
  - `else`：只要有一个条件不成立就走这里。
<!-- end-card -->

## 小贴士：多分支顺序很重要

<!-- card type:computer -->
🖥️ 输入一个年份，判断它是不是闰年。

> 闰年规则：能被 4 整除但不能被 100 整除，或者能被 400 整除。
>
> 💡 需要用 `&&`、`||` 和小括号一起配合。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int y;
    cin >> y;
    if ((y % 4 == 0 && y % 100 != 0) || y % 400 == 0) {
        cout << "闰年" << endl;
    } else {
        cout << "平年" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

---

### 卡片：闰年判断走迷宫

<!-- card type:teacher -->
判断闰年就像走迷宫，跟着箭头走：

```
输入年份 y
    │
    ▼
能被 4 整除？
    │
    ├── 否 ──► 平年
    │
    ▼
能被 100 整除？
    │
    ├── 否 ──► 闰年（如 2024）
    │
    ▼
能被 400 整除？
    │
    ├── 是 ──► 闰年（如 2000）
    │
    └── 否 ──► 平年（如 1900）
```

对应代码：
```cpp
if ((y % 4 == 0 && y % 100 != 0) || y % 400 == 0) {
    cout << "闰年" << endl;
} else {
    cout << "平年" << endl;
}
```

> 💡 口诀：**先过 4 的关，再看 100 的坑，400 来救场。**
<!-- end-card -->

## 小贴士：多分支顺序很重要

<!-- hint -->
写 `if-else if-else` 时，条件要从高到低排好队。

❌ 错误顺序：
```cpp
if (score >= 60) { ... }
else if (score >= 90) { ... }   // 这行永远执行不到！
```

✅ 正确顺序：
```cpp
if (score >= 90) { ... }
else if (score >= 80) { ... }
else if (score >= 60) { ... }
else { ... }
```
<!-- end-hint -->

## 卡片：长题不要怕，拆成三句话

<!-- card type:teacher -->
📝 考级真题里有些题目很长，像“商店折扣”“交税”“爱心快递”。别慌，用这三步拆题：

1. **输入什么？** 圈出要读几个数。
2. **怎么算？** 把题目规则写成“如果…就…”。
3. **输出什么？** 注意保留几位小数、输出几行。

> 💡  trick：**先把题目翻译成自己的话，再写代码。**
<!-- end-card -->

## 卡片：多方案比较——分别算，再选最划算的

<!-- card type:teacher -->
🛒 真题里经常问“哪种方案更便宜/更省”。套路是：

1. 按方案 A 算一个结果；
2. 按方案 B 算一个结果；
3. 用 `min` 或 `if` 选更小的那个。

```cpp
int priceA = ...;   // 方案 A
int priceB = ...;   // 方案 B
if (priceA < priceB) {
    cout << priceA << endl;
} else {
    cout << priceB << endl;
}
```

> 💡 分段计费也是同理：先按不同规则算出几个钱，再取最小。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int money;
    cin >> money;
    // 方案 A：满 100 减 20
    int a = money >= 100 ? money - 20 : money;
    // 方案 B：直接打 8 折
    int b = money * 8 / 10;
    // 选便宜的
    if (a < b) cout << a << endl;
    else       cout << b << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：分段计税也是多分支

<!-- card type:teacher -->
💰 像“劳务报酬不超过 800 不扣税，超过 800 的部分扣 20%”，直接翻译成 `if-else`：

```cpp
if (money <= 800) {
    tax = 0;
} else {
    tax = (money - 800) * 0.2;
}
```

> 💡 以后学到循环，可以把 12 个月都这样算一遍，最后把税加起来。这里先看单月怎么算。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    double money;
    cin >> money;
    double tax = 0;
    if (money > 800) {
        tax = (money - 800) * 0.2;
    }
    cout << tax << endl;
    return 0;
}
```
<!-- end-demo -->
