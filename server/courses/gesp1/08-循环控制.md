> 他从第一排开始找，看到空座位就坐下（`break`）。
> 如果这排不是他的目标排，就跳过这排继续找（`continue`）。

循环里的 `break` 和 `continue` 就像这两个动作：一个直接结束，一个跳过当前。

## 🛑 知识点一：continue 和 break

### break

`break` 让循环立刻结束，跳出循环体。

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 5) {
            break;   // 到 5 就结束循环
        }
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```
<!-- run -->

**输出：**
```
1 2 3 4
```

### continue

`continue` 跳过当前循环，直接进入下一次循环。

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 3) {
            continue;   // 跳过 3
        }
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```
<!-- run -->

**输出：**
```
1 2 4 5
```

### 对比

| 语句 | 作用 |
|------|------|
| `break` | 立刻结束整个循环 |
| `continue` | 跳过本次循环，继续下一次 |

## 🔢 知识点二：质数与合数

### 定义

- **质数**：大于 1 的整数，只有 1 和它本身两个因数。例如 2、3、5、7、11。
- **合数**：大于 1 的整数，除了 1 和它本身还有其他因数。例如 4、6、8、9、10。
- 1 既不是质数也不是合数。

### 判断质数

一个数 `n` 是质数，当且仅当它不能被 2 到 `n-1` 之间的任何数整除。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    bool isPrime = true;   // 标记变量，先假设是质数
    if (n <= 1) {
        isPrime = false;   // 1 及以下的数不是质数
    }
    for (int i = 2; i < n; i++) {
        if (n % i == 0) {
            isPrime = false;   // 能被整除，不是质数
            break;             // 找到一个因数就够了
        }
    }
    if (isPrime) {
        cout << "质数" << endl;
    } else {
        cout << "合数" << endl;
    }
    return 0;
}
```

## 🏷️ 知识点三：标记变量 bool

标记变量就像一个红绿灯：
- `true`：绿灯，表示"是"
- `false`：红灯，表示"否"

在上面的质数判断中，`isPrime` 就是标记变量。我们先假设它是质数，一旦发现能整除的数，就把标记改成 `false`。

> 用标记变量可以避免重复判断，让代码更清晰。

## ⚡ 知识点四：质数判断优化

### 优化思路

判断 `n` 是不是质数，不需要从 2 试到 `n-1`，只需要试到 `sqrt(n)` 就够了。

为什么？因为如果 `n = a × b`，那么 `a` 和 `b` 中至少有一个小于等于 `sqrt(n)`。

### sqrt 函数

`sqrt(n)` 表示 n 的平方根，需要包含头文件 `#include <cmath>`。

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int n;
    cin >> n;
    bool isPrime = true;
    if (n <= 1) {
        isPrime = false;
    }
    for (int i = 2; i <= sqrt(n); i++) {
        if (n % i == 0) {
            isPrime = false;
            break;
        }
    }
    if (isPrime) {
        cout << "质数" << endl;
    } else {
        cout << "合数" << endl;
    }
    return 0;
}
```
<!-- run -->

> 优化后，判断大数时速度会快很多！
>
> ⚠️ 小提示：判断质数前一定要先处理 `n <= 1` 的情况，因为 1 既不是质数也不是合数。
