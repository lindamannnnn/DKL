## 卡片：今天复习什么？

<!-- card type:teacher -->
🧑‍🏫 前面三节课，我们学了三种分支：

- 单分支 `if`：条件成立才执行
- 双分支 `if-else`：二选一
- 多分支 `if-else if-else`：多种情况排队选

还有一个逻辑小帮手：`&&`（并且），两边条件都要成立。
<!-- end-card -->

## 本课练习要点

<!-- card type:teacher -->
📝 本节课我们要重点练习：

1. `if-else` 二选一：根据一个条件决定走哪条路。
2. `if-else if-else` 多路分支：多种情况依次判断。
3. `&&` 和 `||` 逻辑组合：多个条件一起判断。
4. 嵌套 `if`：一个分支里再判断一次。

> 💡 每道题都要先想清楚：**条件是什么？成立怎么办？不成立怎么办？**
<!-- end-card -->

## 挑战 1：判断能不能出去玩

<!-- card type:computer -->
🖥️ 输入两个数：作业是否完成（1 表示完成，0 表示没完成）和天气是否好（1 表示好，0 表示不好）。

只有作业完成 **并且** 天气好，才能输出 "可以出去玩"，否则输出 "不能出去玩"。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int homework, weather;
    cin >> homework >> weather;
    if (homework == 1 && weather == 1) {
        cout << "可以出去玩" << endl;
    } else {
        cout << "不能出去玩" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 2：成绩等级多分支

<!-- card type:computer -->
🖥️ 输入一个成绩，输出等级：

- 90 分及以上：A
- 80 ~ 89 分：B
- 60 ~ 79 分：C
- 60 分以下：D
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 90) cout << "A" << endl;
    else if (score >= 80) cout << "B" << endl;
    else if (score >= 60) cout << "C" << endl;
    else cout << "D" << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 3：判断能否组成三角形

<!-- card type:computer -->
🖥️ 输入三条边的长度，判断它们能不能组成一个三角形。

规则：任意两边之和大于第三边。

输入：三个整数 a、b、c。
输出：能组成三角形输出 `Yes`，否则输出 `No`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    if (a + b > c && a + c > b && b + c > a) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 4：判断季节

<!-- card type:computer -->
🖥️ 输入一个月份，判断它属于哪个季节。

- 3、4、5 月：`Spring`
- 6、7、8 月：`Summer`
- 9、10、11 月：`Autumn`
- 12、1、2 月：`Winter`

输入：一个整数 month。
输出：对应的季节英文。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int month;
    cin >> month;
    if (month == 3 || month == 4 || month == 5) {
        cout << "Spring" << endl;
    } else if (month == 6 || month == 7 || month == 8) {
        cout << "Summer" << endl;
    } else if (month == 9 || month == 10 || month == 11) {
        cout << "Autumn" << endl;
    } else {
        cout << "Winter" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 5：今天穿什么衣服

<!-- card type:computer -->
🖥️ 输入今天的温度和天气情况（1 表示晴天，0 表示下雨），给出穿衣建议。

- 温度 ≥ 30 度且晴天：`穿短袖带帽子`
- 温度 ≥ 30 度且下雨：`穿短袖带雨伞`
- 温度 15 ~ 29 度且晴天：`穿长袖`
- 温度 15 ~ 29 度且下雨：`穿长袖带雨伞`
- 温度 < 15 度：`穿外套`

输入：一个整数 temperature 和一个整数 sunny（1 或 0）。
输出：穿衣建议。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int temperature, sunny;
    cin >> temperature >> sunny;
    if (temperature >= 30) {
        if (sunny == 1) {
            cout << "穿短袖带帽子" << endl;
        } else {
            cout << "穿短袖带雨伞" << endl;
        }
    } else if (temperature >= 15) {
        if (sunny == 1) {
            cout << "穿长袖" << endl;
        } else {
            cout << "穿长袖带雨伞" << endl;
        }
    } else {
        cout << "穿外套" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

### 卡片：穿衣决策树

<!-- card type:teacher -->
选衣服就像一棵大树，先按温度分叉，再看天气：

```
        今天穿什么？
            │
    ┌───────┼───────┐
    ▼       ▼       ▼
 ≥30度   15~29度   <15度
    │       │        │
    ▼       ▼        ▼
 看天气   看天气    穿外套
    │       │
    ▼       ▼
 晴天？   晴天？
 /    \   /    \
是    否  是    否
│     │   │     │
短袖  短袖 长袖  长袖
带帽子 带雨伞      带雨伞
```

写代码时，先写最外层的温度判断，再在里面写天气判断，大括号一层一层对应好。

## 报错也不慌：== 和 = 别搞混

<!-- card type:tip -->
💡 判断两个数是否相等，要用两个等号 `==`！

如果写成 `if (a = 10)`，电脑会以为你要把 10 放进 a 里，然后报错。

> 很多小朋友第一次都会写错，不是你的问题，改过来就好！
<!-- end-card -->

<!-- demo -->
```cpp
int a = 5;
if (a == 5) {        // ✅ 判断 a 是否等于 5
    cout << "对的";
}
if (a = 5) {         // ❌ 这是把 5 塞进 a
    cout << "错的";
}
```
<!-- end-demo -->

## 小贴士：分支顺序很重要

<!-- hint -->
写多分支时，条件要从高到低排：

```cpp
if (score >= 90) { ... }
else if (score >= 80) { ... }
else if (score >= 60) { ... }
else { ... }
```

否则高分会被低分条件"截胡"！
<!-- end-hint -->
