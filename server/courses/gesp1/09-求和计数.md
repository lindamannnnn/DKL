## ➕ 知识点一：求和与平均数（循环输入）

### 求和

用一个变量记录总和，每次循环加上新的数。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;          // 先输入有多少个数
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;      // 循环输入每个数
        sum = sum + x;
    }
    cout << "总和：" << sum << endl;
    return 0;
}
```
<!-- run -->

### 求平均数

平均数 = 总和 ÷ 个数。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        sum = sum + x;
    }
    cout << "平均数：" << (double)sum / n << endl;
    return 0;
}
```
<!-- run -->

> 注意：求平均数时要把总和转成 `double`，否则整数除法会丢掉小数。

## 🔢 知识点二：因子和

### 什么是因子？

如果 `a % b == 0`，那么 `b` 就是 `a` 的因子。

例如 12 的因子有：1、2、3、4、6、12。

### 求因子和

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        if (n % i == 0) {
            sum = sum + i;   // i 是 n 的因子，加入总和
        }
    }
    cout << "因子和：" << sum << endl;
    return 0;
}
```

## 📊 知识点三：数据遍历统计

### 统计个数

统计满足条件的数有多少个。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int count = 0;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        if (x >= 60) {
            count++;   // 及格人数加 1
        }
    }
    cout << "及格人数：" << count << endl;
    return 0;
}
```

## 🏆 知识点四：最大值与最小值

### 求最大值

先假设第一个数最大，然后逐个比较。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int maxNum = -1000000;   // 先设一个很小的数
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        if (x > maxNum) {
            maxNum = x;   // 发现更大的数，更新最大值
        }
    }
    cout << "最大值：" << maxNum << endl;
    return 0;
}
```
<!-- run -->

### 求最小值

和求最大值类似，只是比较符号反过来。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int minNum = 1000000;   // 先设一个很大的数
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        if (x < minNum) {
            minNum = x;   // 发现更小的数，更新最小值
        }
    }
    cout << "最小值：" << minNum << endl;
    return 0;
}
```
<!-- run -->

### 更简单的做法

如果知道第一个数一定存在，可以先把第一个数赋给 `maxNum` 和 `minNum`。

```cpp
int maxNum, minNum;
cin >> maxNum;
minNum = maxNum;
```
