## 🎬 开场故事：跑步

小明每天跑步，规则是：

> 只要还没跑够 1000 米，就继续跑。

小明不知道要跑多少圈，只知道一个条件"不到 1000 米就继续"。这种**不知道什么时候结束**的循环，用 `while` 最合适！

## 🔄 知识点一：while 循环

### while 循环的格式

```cpp
while (条件) {
    // 循环体
}
```

只要条件成立，就重复执行循环体。

### 例子：数到 5

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;
    while (i <= 5) {
        cout << i << " ";
        i++;
    }
    cout << endl;
    return 0;
}
```
<!-- run -->

**输出：**
```
1 2 3 4 5
```

### while 和 for 的区别

| 循环 | 特点 | 适合场景 |
|------|------|---------|
| `for` | 知道循环次数 | 数 1 到 100、遍历数组 |
| `while` | 知道循环条件 | 不知道要循环几次，但知道什么时候停止 |

---

## 🔁 知识点二：do-while 循环

### do-while 循环的格式

```cpp
do {
    // 循环体
} while (条件);
```

先执行一次循环体，再判断条件是否继续。

### 例子：至少执行一次

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;
    do {
        cout << i << " ";
        i++;
    } while (i <= 5);
    cout << endl;
    return 0;
}
```
<!-- run -->

### while 和 do-while 的区别

| 循环 | 判断时机 | 至少执行次数 |
|------|---------|-------------|
| `while` | 先判断，后执行 | 0 次 |
| `do-while` | 先执行，后判断 | 1 次 |

## ➕ 知识点三：复合运算符

复合运算符让代码更简洁。

| 复合运算符 | 等价写法 | 例子 |
|-----------|---------|------|
| `+=` | `a = a + b` | `a += 5` |
| `-=` | `a = a - b` | `a -= 3` |
| `*=` | `a = a * b` | `a *= 2` |
| `/=` | `a = a / b` | `a /= 4` |
| `%=` | `a = a % b` | `a %= 10` |

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    a += 5;   // a = 15
    a -= 3;   // a = 12
    a *= 2;   // a = 24
    cout << a << endl;
    return 0;
}
```
