## 卡片：break 直接结束循环

<!-- card type:teacher -->
🛑 `break` 就像喊"停！"，循环立刻结束，跳出循环体。

```cpp
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;   // 到 5 就结束
    }
    cout << i << " ";
}
// 输出：1 2 3 4
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 5) {
            break;
        }
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```
<!-- end-demo -->

## 卡片：continue 跳过本次

<!-- card type:teacher -->
⏭️ `continue` 就像喊"这次不算，下次再来"，跳过当前循环，进入下一次。

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;   // 跳过 3
    }
    cout << i << " ";
}
// 输出：1 2 4 5
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 3) {
            continue;
        }
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```
<!-- end-demo -->

## 报错也不慌：break 和 continue 别搞反

<!-- card type:tip -->
💡 记住这两个中文动作名：

| 英文 | 中文动作名 | 作用 |
|------|-----------|------|
| `break` | **直接退出** | 整个循环立刻停止 |
| `continue` | **跳过本次** | 这次不执行，直接进入下一次 |

> 记不住英文？先看中文动作名：`break` = 直接退出，`continue` = 跳过本次。
<!-- end-card -->

<!-- demo -->
```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) break;      // 直接退出 → 输出：1 2
    cout << i << " ";
}

for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;   // 跳过本次 → 输出：1 2 4 5
    cout << i << " ";
}
```
<!-- end-demo -->

## 卡片：break 和 continue 对比

<!-- card type:teacher -->
🆚 两个指令不一样：

- **break**：循环直接结束
- **continue**：跳过本次，继续下一次

就像跑步：
- break = 直接退出跑道
- continue = 这一圈不跑完，直接开始下一圈
<!-- end-card -->

### 过渡页：用遥控器解决质数问题

<!-- card type:teacher -->
🎮 我们已经学会了循环的两个"遥控器"：

- `break`：找到答案就停止
- `continue`：这次跳过，继续下一次

现在用它们来解决一个经典问题：**判断一个数是不是质数**。

> 💡 思路：先假设它是质数，再逐个找反例；找到反例就用 `break` 停止。
<!-- end-card -->

---

## 卡片：判断质数

<!-- card type:teacher -->
🔢 质数是指大于 1 的数，除了 1 和它自己，不能被其他数整除。

比如：2、3、5、7、11 都是质数。

判断方法：用 2 到 `n-1` 之间的每个数去试除 `n`，如果都不能整除，就是质数。

```cpp
bool isPrime = true;
for (int i = 2; i < n; i++) {
    if (n % i == 0) {
        isPrime = false;   // 找到能整除的数，不是质数
        break;             // 不用继续试了
    }
}
```

> 💡 用 `bool` 做标志位，找到反例就 `break`，这是循环里很常用的技巧。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    bool isPrime = true;
    for (int i = 2; i < n; i++) {
        if (n % i == 0) {
            isPrime = false;
            break;
        }
    }
    if (isPrime && n > 1) {
        cout << "质数" << endl;
    } else {
        cout << "不是质数" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

---

### 卡片：分步拆解质数判断

<!-- card type:teacher -->
🔢 以 `n = 17` 为例，看看循环是怎么工作的：

| i | 17 % i | 发现什么 | isPrime |
|---|--------|----------|---------|
| 2 | 1 | 不能整除 | true |
| 3 | 2 | 不能整除 | true |
| 4 | 1 | 不能整除 | true |
| ... | ... | ... | true |
| 16 | 1 | 不能整除 | true |

因为没找到能整除的数，所以 17 是质数。

再看 `n = 15`：

| i | 15 % i | 发现什么 |
|---|--------|----------|
| 2 | 1 | 不能整除 |
| 3 | 0 | **能整除！不是质数** |

当 `i = 3` 时，`isPrime` 变成 false，立刻 `break`，不用继续试后面的数。

> 💡 `bool` 标志位就像一个开关：默认开着（true），发现反例就关掉（false）。
<!-- end-card -->

## 卡片：质数判断加速版

<!-- card type:teacher -->
🚀 判断 17 是不是质数，真的要试 2、3、4……16 吗？

其实不用试到那么大！

想象一下：如果 17 能拆成 `a × b`，那么 `a` 和 `b` 中一定有一个比较小。

比如 `16 = 2 × 8`，2 比较小；`15 = 3 × 5`，3 比较小。

所以我们只要试到 `i × i <= n` 就可以了，也就是 `i` 自己乘自己不超过 `n`。

```cpp
for (int i = 2; i * i <= n; i++) {
    if (n % i == 0) {
        isPrime = false;
        break;
    }
}
```

> 💡 这样写又快又好懂：如果 `i × i` 已经超过 `n` 了，后面就不用再试了。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    bool isPrime = true;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            isPrime = false;
            break;
        }
    }
    if (isPrime && n > 1) {
        cout << "质数" << endl;
    } else {
        cout << "不是质数" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：输出 1~20 的奇数

<!-- card type:computer -->
🖥️ 用 for 循环输出 1 到 20 的所有奇数。

> 提示：偶数就 continue 跳过。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    for (int i = 1; i <= 20; i++) {
        if (i % 2 == 0) {
            continue;   // 跳过偶数
        }
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
📋 **评讲逻辑**

- **考察知识点**：`for` 循环、`if` 判断、`continue` 跳过本次循环。
- **解题思路**：
  1. 让 `i` 从 1 走到 20；
  2. 如果 `i` 是偶数（`i % 2 == 0`），就执行 `continue` 跳过；
  3. 否则输出这个奇数。
- **容易错的地方**：
  - 把 `continue` 写成 `break`，导致只输出 `1`；
  - 忘了在 `cout` 后面输出空格，导致数字粘在一起；
  - 循环起点或终点写错，漏掉 1 或 19。
- **关键代码解释**：
  ```cpp
  if (i % 2 == 0) {
      continue;   // 偶数跳过，直接进入下一次循环
  }
  cout << i << " ";  // 只输出奇数，每个数后面加空格
  ```
<!-- end-card -->

## 卡片：中间条件空着表示一直循环

<!-- card type:teacher -->
🔄 `for` 循环中间的条件如果空着，电脑会认为"条件永远成立"，就会一直循环下去。

这时候通常要配合 `break` 使用：达到某个目标后，用 `break` 跳出循环。

```cpp
for (int i = 1; ; i++) {   // 中间空着，表示一直循环
    if (i % 7 == 0) {
        break;   // 找到目标，立刻退出
    }
}
```

> ⚠️ 如果忘了写 `break`，程序就会永远跑下去，变成死循环！
<!-- end-card -->

## 挑战 2：找到第一个能被 7 整除的数

<!-- card type:computer -->
🖥️ 从 1 开始找，找到第一个能被 7 整除的数，输出它，然后立刻停止。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    for (int i = 1; ; i++) {   // 中间空着，一直找
        if (i % 7 == 0) {
            cout << i << endl;
            break;   // 找到了，立刻退出
        }
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
📋 **评讲逻辑**

- **考察知识点**：`for` 循环中间条件空着表示无限循环、`break` 退出循环。
- **解题思路**：
  1. 让 `i` 从 1 开始不断递增；
  2. 如果 `i` 能被 7 整除（`i % 7 == 0`），说明找到了；
  3. 输出这个数，并用 `break` 立刻结束循环。
- **容易错的地方**：
  - 中间条件空着却忘记写 `break`，程序变成死循环；
  - 找到目标后没有输出就 `break`；
  - 把 `% 7` 写成 `/ 7`，导致条件判断错误。
- **关键代码解释**：
  ```cpp
  for (int i = 1; ; i++) {   // 中间空着，一直循环
      if (i % 7 == 0) {      // 找到能被 7 整除的数
          cout << i << endl; // 输出 7
          break;             // 找到就退出
      }
  }
  ```
<!-- end-card -->

## 小贴士：别在 for 后面加分号

<!-- hint -->
```cpp
for (int i = 1; i <= 5; i++); { ... }   // 错误！
```

`for` 后面加了分号，循环体就是空的，大括号里的代码只执行一次。

## 🌟 拓展卡片：循环里还能再套一个循环

<!-- card type:teacher -->
🌀 有时候一层循环不够，需要在循环里面再写一个循环，这叫**双重循环**。

> 📝 这是 GESP 二级的知识点，一年级同学作为拓展了解即可。看到“累计相加”这类真题时，能看懂就行。

比如计算：
```
1 + (1+2) + (1+2+3) + ... + (1+2+...+n)
```

外层循环控制“加到几”：
- 第 1 轮加 1
- 第 2 轮加 1+2
- 第 3 轮加 1+2+3

内层循环负责把 1 到 i 累加起来。

```cpp
int total = 0;
for (int i = 1; i <= n; i++) {
    int sum = 0;
    for (int j = 1; j <= i; j++) {
        sum += j;
    }
    total += sum;
}
```

> 💡 外层循环一次，内层循环会完整跑一遍。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int total = 0;
    for (int i = 1; i <= n; i++) {
        int sum = 0;
        for (int j = 1; j <= i; j++) {
            sum += j;
        }
        total += sum;
    }
    cout << total << endl;
    return 0;
}
```
<!-- end-demo -->
