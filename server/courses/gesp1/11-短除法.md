当糖数变成 0 时，比赛结束。这就是 `while(t--)` 的思想！

## 🔁 知识点一：循环 n 次 while(t--)

### 用 t 替换 n

如果我们想循环 n 次，可以用一个变量 t 来代替 n，每次循环 t 减 1，直到 t 变成 0。

```cpp
#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;       // 输入循环次数
    while (t--) {   // t 每次减 1，直到变成 0
        cout << "吃一颗糖" << endl;
    }
    return 0;
}
```
<!-- run -->

### 注意事项

`t--` 是先用 t 的值判断，再减 1。所以 `while(t--)` 会循环 t 次。

```cpp
#include <iostream>
using namespace std;

int main() {
    int t = 3;
    while (t--) {
        // 进入循环体时，t 已经减了 1
        cout << "t = " << t << endl;
    }
    return 0;
}
```
<!-- run -->

**输出：**
```
t = 2
t = 1
t = 0
```

> 循环体里看到 t 是 2、1、0，是因为 `t--` 先判断再减 1。循环结束后，t 变成了 -1。

## 🔢 知识点二：数位求和

### 什么是数位求和？

把一个整数的每一位数字加起来。

例如：`1234` 的数位和是 `1 + 2 + 3 + 4 = 10`。

### 用短除法求数位和

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    while (n > 0) {
        sum = sum + n % 10;   // 加上个位
        n = n / 10;           // 去掉个位
    }
    cout << "数位和：" << sum << endl;
    return 0;
}
```
<!-- run -->

### 执行过程

以 `n = 1234` 为例：

| 步骤 | n | n % 10 | sum | n = n / 10 |
|------|---|--------|-----|------------|
| 1 | 1234 | 4 | 4 | 123 |
| 2 | 123 | 3 | 7 | 12 |
| 3 | 12 | 2 | 9 | 1 |
| 4 | 1 | 1 | 10 | 0 |

## 🔍 知识点三：数字包含判断

### 判断一个数是否包含某个数字

例如：判断 `12345` 是否包含数字 `3`。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n, target;
    cin >> n >> target;
    bool found = false;
    while (n > 0) {
        if (n % 10 == target) {
            found = true;
            break;
        }
        n = n / 10;
    }
    if (found) {
        cout << "包含" << endl;
    } else {
        cout << "不包含" << endl;
    }
    return 0;
}
```
<!-- run -->

> 用 `break` 可以提前结束循环，找到数字后就不需要继续拆位了。
