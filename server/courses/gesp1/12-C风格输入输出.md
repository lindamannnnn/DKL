## 🖨️ 知识点一：printf 与 scanf 的用法

### printf 输出

`printf` 用来按指定格式输出内容。

```cpp
#include <cstdio>
using namespace std;

int main() {
    printf("Hello, World!\n");
    return 0;
}
```
<!-- run -->

### scanf 输入

`scanf` 用来按指定格式读取输入。

```cpp
#include <cstdio>
using namespace std;

int main() {
    int age;
    printf("请输入你的年龄：");
    scanf("%d", &age);
    printf("你的年龄是：%d\n", age);
    return 0;
}
```
<!-- run -->

> ⚠️ 注意：`scanf` 中变量名前必须加 `&` 符号！

## 🎫 知识点二：占位符的概念与使用

占位符就像一个个"坑位"，用后面的值来填充。

| 占位符 | 含义 | 例子 |
|--------|------|------|
| `%d` | 整数 | `printf("%d", 100);` |
| `%lld` | 长长整数 | `printf("%lld", x);` |
| `%f` | 浮点数 | `printf("%f", 3.14);` |
| `%lf` | double 类型（输入用） | `scanf("%lf", &x);` |
| `%c` | 字符 | `printf("%c", 'A');` |
| `%s` | 字符串 | `printf("%s", "Hello");` |

### 多个占位符

```cpp
#include <cstdio>
using namespace std;

int main() {
    int a = 10;
    double b = 3.14;
    char c = 'X';
    printf("a = %d, b = %f, c = %c\n", a, b, c);
    return 0;
}
```

## 🎨 知识点三：格式化输入与输出

### 控制整数宽度

```cpp
#include <cstdio>
using namespace std;

int main() {
    int n = 7;
    printf("%05d\n", n);   // 输出 00007，宽度 5，不足补 0
    printf("%5d\n", n);    // 输出     7，宽度 5，不足补空格
    return 0;
}
```
<!-- run -->

### 控制小数位数

```cpp
#include <cstdio>
using namespace std;

int main() {
    double pi = 3.1415926;
    printf("%.2f\n", pi);   // 输出 3.14
    printf("%.4f\n", pi);   // 输出 3.1416
    return 0;
}
```
<!-- run -->

### scanf 读取多个值

```cpp
#include <cstdio>
using namespace std;

int main() {
    int a, b;
    scanf("%d %d", &a, &b);
    printf("a + b = %d\n", a + b);
    return 0;
}
```
<!-- run -->

## ⏰ 知识点四：时间换算

### 秒转时分秒

输入总秒数，输出小时、分钟、秒。

```cpp
#include <cstdio>
using namespace std;

int main() {
    int total;
    scanf("%d", &total);
    int h = total / 3600;
    int m = total % 3600 / 60;
    int s = total % 60;
    printf("%d时%d分%d秒\n", h, m, s);
    return 0;
}
```
<!-- run -->

### 分钟转小时和分钟

```cpp
#include <cstdio>
using namespace std;

int main() {
    int m;
    scanf("%d", &m);
    printf("%d小时%d分钟\n", m / 60, m % 60);
    return 0;
}
```
