## 本课练习要点

<!-- card type:teacher -->
📝 本节课主要练习前面三节课的循环知识：

- **`for` 循环**：知道要循环多少次时使用，格式要记牢。
- **`break`**：立刻结束整个循环，常用于“找到答案就停”。
- **`continue`**：跳过本次循环，直接进入下一次。
- **循环求和/计数**：注意初始值，`sum` 从 0 开始，`count` 从 0 开始。
- **判断质数**：用标志位 `bool` 配合 `break`，找到能整除的数就不是质数。
- **找第一个满足条件的数**：可以让 `for` 中间条件空着，配合 `break` 退出。

> 💡 做题时先想清楚循环几次、什么时候停，再写代码。
<!-- end-card -->

## 报错也不慌：死循环怎么办？

<!-- card type:tip -->
💡 如果程序一直跑不停，可能是循环条件永远成立！

检查一下：循环里有没有让变量变化的语句？比如 `i++` 或 `n = n / 10`。
<!-- end-card -->

<!-- demo -->
```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << endl;
}
// 千万别忘 i++！否则 i 永远是 1，循环跑不完
```
<!-- end-demo -->

## 挑战 1：输出 1~20 中的奇数

<!-- card type:computer -->
🖥️ 用 `continue` 跳过偶数，输出 1 到 20 的所有奇数。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    for (int i = 1; i <= 20; i++) {
        if (i % 2 == 0) {
            continue;
        }
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 2：找到第一个能被 7 整除的数

<!-- card type:computer -->
🖥️ 从 1 开始数，找到第一个能被 7 整除的数，输出它，然后立刻停止。

> 💡 还记得吗？`for` 中间的条件空着，表示一直循环；找到目标后用 `break` 退出。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    for (int i = 1; ; i++) {   // 中间空着，一直找
        if (i % 7 == 0) {
            cout << i << endl;
            break;   // 找到了，立刻退出
        }
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 3：判断质数

<!-- card type:computer -->
🖥️ 输入一个整数 n，判断它是不是质数。

> 质数是大于 1 的数，除了 1 和它自己，不能被其他数整除。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    bool isPrime = true;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            isPrime = false;
            break;
        }
    }
    if (isPrime && n > 1) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 4：数字金字塔

<!-- card type:computer -->
🖥️ 输入一个整数 n，输出 n 行数字金字塔。

> 第 1 行输出 `1`，第 2 行输出 `1 2`，第 3 行输出 `1 2 3`……
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            cout << j << " ";
        }
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

---

### 卡片：双重循环像俄罗斯套娃

<!-- card type:teacher -->
数字金字塔要用两层循环，外层管"行"，内层管"每行里的数"。

以 `n = 3` 为例：

```
外层 i = 1 时：
    内层 j 从 1 到 1 → 输出 1
    换行

外层 i = 2 时：
    内层 j 从 1 到 2 → 输出 1 2
    换行

外层 i = 3 时：
    内层 j 从 1 到 3 → 输出 1 2 3
    换行
```

**记忆口诀**：
- 外层循环走一次，内层循环跑一圈。
- `cout << endl` 放在内层循环外面、外层循环里面，管换行。
<!-- end-card -->

## 挑战 5：第一个同时被 3 和 7 整除的数

<!-- card type:computer -->
🖥️ 从 1 开始往上找，找到第一个既能被 3 整除、又能被 7 整除的数，输出它并立刻停止。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    for (int i = 1; ; i++) {   // 中间空着，一直找
        if (i % 3 == 0 && i % 7 == 0) {
            cout << i << endl;
            break;   // 找到了，立刻退出
        }
    }
    return 0;
}
```
<!-- end-demo -->

---

## 小贴士：别在 for 后面加分号

<!-- hint -->
```cpp
for (int i = 1; i <= 5; i++); { ... }   // 错误！
```

`for` 后面加了分号，循环体就是空的，大括号里的代码只执行一次。
<!-- end-hint -->
