## 第1关：循环输入求和

40 个同学难道要写 40 个 `cin` 吗？不用！用循环就可以！
<!-- end-story -->

---

### 卡片：循环输入求和

<!-- card type:teacher -->
➕ 先输入有多少个数，然后用循环一次次读入，把它们加到总和里。

```cpp
int n;
cin >> n;          // 先输入个数
int sum = 0;
for (int i = 1; i <= n; i++) {
    int x;
    cin >> x;      // 每次读一个数
    sum = sum + x;
}
```

假设输入 3 个数：5、3、2，变量变化如下：

| 次数 | 输入 x | sum 变化前 | sum 变化后 |
|-----|-------|-----------|-----------|
| 1 | 5 | 0 | 0 + 5 = 5 |
| 2 | 3 | 5 | 5 + 3 = 8 |
| 3 | 2 | 8 | 8 + 2 = 10 |

> 💡 口诀：**sum 从 0 起，来一个加一个。**
<!-- end-card -->

---

### 卡片：动画演练

<!-- card type:teacher -->
🎬 把 `sum = sum + x` 想象成往桶里倒石头：

- 开始前：`sum` 桶是空的，装着 0
- 第一次：倒入 5，桶里变成 5
- 第二次：倒入 3，桶里变成 8
- 第三次：倒入 2，桶里变成 10

所以 `sum = sum + x` 的意思是：**把原来桶里的东西，和新加的东西，一起装回桶里。**
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        sum = sum + x;
    }
    cout << sum << endl;
    return 0;
}
```
<!-- end-demo -->

## 第2关：求平均和计数

### 卡片：求平均数

<!-- card type:teacher -->
📊 平均数 = 总和 ÷ 个数。

求平均数时，记得把总和转成 `double`，不然整数除法会丢掉小数。

```cpp
cout << "平均数：" << (double)sum / n << endl;
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        sum = sum + x;
    }
    cout << "平均数：" << (double)sum / n << endl;
    return 0;
}
```
<!-- end-demo -->

## 第3关：找最大值

### 卡片：先把第一个数当老大

<!-- card type:teacher -->
🏆 求最大值时，先把第一个数当老大，然后逐个比较，发现更大的就换老大。

```cpp
int maxNum;
cin >> maxNum;   // 第一个数当老大
for (...) {
    if (x > maxNum) {
        maxNum = x;   // 发现更大的，换老大
    }
}
```

假设输入 4 个数：3、7、2、5，最大值变化如下：

| 次数 | 输入 x | 当前 maxNum | 比较结果 |
|-----|-------|------------|---------|
| 开始 | 3 | 3 | 第一个数当老大 |
| 1 | 7 | 7 | 7 > 3，换老大 |
| 2 | 2 | 7 | 2 < 7，不换 |
| 3 | 5 | 7 | 5 < 7，不换 |

> 💡 口诀：**第一个当老大，看到更大的就换人。**
<!-- end-card -->

---

### 卡片：为什么要用第一个数

<!-- card type:teacher -->
🤔 能不能把 `maxNum` 先设成 0？

如果所有数都是正数，0 没问题。但如果成绩可能是负数，0 就比所有成绩都大，结果就错了。

所以最安全的办法是：**把第一个输入的数当老大。**
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int maxNum;
    cin >> maxNum;   // 先读第一个数当老大
    for (int i = 2; i <= n; i++) {
        int x;
        cin >> x;
        if (x > maxNum) {
            maxNum = x;
        }
    }
    cout << "最大值：" << maxNum << endl;
    return 0;
}
```
<!-- end-demo -->

### 卡片：最大最小值擂台赛

<!-- card type:teacher -->
找最大最小值就像办一场擂台赛：

```
第一个上台的同学：
    他既是暂时的“最大”，也是暂时的“最小”

第二个同学上台：
    比他高 → 他成为新的“最大”
    比他矮 → 他成为新的“最小”

第三个同学上台：
    再比一次，更新最大或最小

……

最后站在“最大”位置的就是最大值，站在“最小”位置的就是最小值。
```

对应代码：
```cpp
cin >> maxNum;       // 第一个同学先当老大
minNum = maxNum;     // 同时也当最小的
for (int i = 2; i <= n; i++) {
    cin >> x;
    if (x > maxNum) maxNum = x;  // 发现更高的，换老大
    if (x < minNum) minNum = x;  // 发现更矮的，换最小
}
```

> 💡 关键：不要先把 maxNum 设成 0，如果输入有负数，0 会比所有负数都大，就错了！
<!-- end-card -->

## 挑战 1：求因子和

<!-- card type:computer -->
🖥️ 输入一个整数 n，输出它的所有因子之和。

> 比如 6 的因子是 1、2、3、6，因子和是 12。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        if (n % i == 0) {
            sum = sum + i;
        }
    }
    cout << sum << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
📋 **评讲逻辑**

- **考察知识点**：循环枚举、`%` 取模判断因子、累加求和。
- **解题思路**：
  1. 读入整数 `n`；
  2. 让 `i` 从 1 枚举到 `n`；
  3. 如果 `n % i == 0`，说明 `i` 是 `n` 的因子，就把它加到 `sum` 里；
  4. 循环结束后输出 `sum`。
- **容易错的地方**：
  - `sum` 没有初始化为 0，导致结果错误；
  - 循环范围写错，漏掉 `n` 本身；
  - 把取模 `%` 写成除法 `/`。
- **关键代码解释**：
  ```cpp
  int sum = 0;
  for (int i = 1; i <= n; i++) {
      if (n % i == 0) {      // i 是 n 的因子
          sum = sum + i;     // 累加进 sum
      }
  }
  ```
<!-- end-card -->

## 挑战 2：求最大最小值

<!-- card type:computer -->
🖥️ 输入 n 个整数，输出它们的最大值和最小值。

> 💡 用前面学过的方法：先把第一个数既当最大又当最小，再逐个比较。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int maxNum, minNum;
    cin >> maxNum;       // 第一个数先当老大
    minNum = maxNum;     // 同时也当最小的
    for (int i = 2; i <= n; i++) {
        int x;
        cin >> x;
        if (x > maxNum) maxNum = x;
        if (x < minNum) minNum = x;
    }
    cout << maxNum << " " << minNum << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
📋 **评讲逻辑**

- **考察知识点**：循环输入、用第一个数初始化最大/最小值、比较更新。
- **解题思路**：
  1. 先读入 `n`；
  2. 把第一个数同时赋给 `maxNum` 和 `minNum`；
  3. 从第 2 个数循环到第 `n` 个数，每读入一个 `x` 就分别比较；
  4. 比 `maxNum` 大就更新最大，比 `minNum` 小就更新最小。
- **容易错的地方**：
  - 把 `maxNum` 或 `minNum` 初始化为 0，若输入有负数会出错；
  - 循环从 `i = 2` 开始，但终点写成 `< n` 导致少读一个数；
  - 只更新了最大值，忘记同步更新最小值。
- **关键代码解释**：
  ```cpp
  cin >> maxNum;       // 第一个数先当老大
  minNum = maxNum;     // 同时也当最小的
  for (int i = 2; i <= n; i++) {
      int x;
      cin >> x;
      if (x > maxNum) maxNum = x;  // 发现更大的就换人
      if (x < minNum) minNum = x;  // 发现更小的也换人
  }
  ```
<!-- end-card -->

## 报错也不慌：初始值和类型转换

<!-- card type:tip -->
💡 写求和计数程序时，小明最容易踩三个坑：

1. **把 `sum` 初始成 1**：求和要从 0 开始加，从 1 开始会多算 1。
2. **求平均忘记转 `double`**：`sum / n` 会丢掉小数，要写成 `(double)sum / n`。
3. **最大值初始成 0**：如果成绩可能是负数，0 就比所有成绩都大，结果会出错。用第一个数初始化最安全。

> 🛠️ 先检查初始值，再检查有没有转小数，很多问题都能解决！
<!-- end-card -->

<!-- demo -->
```cpp
int sum = 0;              // ✅ 从 0 开始
sum = sum + x;
double avg = (double)sum / n;  // ✅ 先转 double 再除
```
<!-- end-demo -->

## 卡片：多组数据——套一个外层循环

<!-- card type:teacher -->
🔁 真题里常出现这样的输入：

> 第一行一个 `T`，表示有 T 组数据。接下来 T 行，每行一个数。

比如手机电量显示：T 个电量百分比，每个都要判断一次输出什么。

套路就是**两层循环/嵌套处理**：

```cpp
int T;
cin >> T;
for (int t = 1; t <= T; t++) {
    int x;
    cin >> x;
    // 对 x 做判断或计算
    cout << ... << endl;
}
```

> 💡 口诀：**先读 T，再循环 T 次，每次处理一组。**
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    cin >> T;
    for (int t = 1; t <= T; t++) {
        int P;
        cin >> P;
        if (P <= 10) {
            cout << "R" << endl;     // 红色警告
        } else if (P <= 20) {
            cout << "Y" << endl;     // 黄色提醒
        } else {
            cout << "G" << endl;     // 绿色正常
        }
    }
    return 0;
}
```
<!-- end-demo -->
