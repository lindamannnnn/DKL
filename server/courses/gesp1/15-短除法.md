## 第1关：循环 n 次

<!-- story -->
小明参加吃糖比赛，盒子里有 n 颗糖。

> 只要还有糖，就继续吃。每吃一颗，糖就少一颗。

糖数变成 0 时，比赛结束。
<!-- end-story -->

---

### 卡片：循环 n 次吃糖

<!-- card type:teacher -->
🍬 想循环 n 次？可以让 `t` 从 `n` 开始，每循环一次自动减 1，直到减到 0。

```cpp
int t;
cin >> t;
while (t--) {         // t 先用来判断，然后自动减 1
    cout << "吃一颗糖" << endl;
}
```

- `t--` 的意思是：先用 `t` 的值判断，判断完再让 `t` 减 1。
- 如果 `t` 一开始是 5，会依次判断 5、4、3、2、1，共循环 5 次。

> 💡 口诀：**while(t--) 会自动倒数 n 次。**
<!-- end-card -->

---

### 卡片：两种写法一回事

<!-- card type:teacher -->
🔄 `while (t--)` 和老朋友 `while (t > 0) { ... t--; }` 效果一样，只是更简洁。

| 写法 | 循环几次 | 特点 |
|------|---------|------|
| `while (t--) { ... }` | n 次 | 把判断和减 1 合在一起写 |
| `while (t > 0) { ... t--; }` | n 次 | 判断和减 1 分开写 |

两种写法都对，比赛里常看到 `while(t--)`，因为它更短。
<!-- end-card -->

---

### 卡片：while(t--) 逐步看

<!-- card type:teacher -->
假设 `t = 3`，看看 `while(t--)` 是怎么执行的：

```
开始：t = 3

第 1 次：
    判断：t 是 3，3 > 0，进入循环
    执行循环体
    然后 t 变成 2

第 2 次：
    判断：t 是 2，2 > 0，进入循环
    执行循环体
    然后 t 变成 1

第 3 次：
    判断：t 是 1，1 > 0，进入循环
    执行循环体
    然后 t 变成 0

第 4 次：
    判断：t 是 0，0 > 0 不成立，循环结束
```

所以 `while(t--)` 一共执行 **3 次**，也就是 t 原来的值。

> 💡 口诀：先判断，再减 1；减到 0 就停止。
<!-- end-card -->

---

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {         // 循环 t 次
        cout << "*";
    }
    cout << endl;
    return 0;
}
```
<!-- end-demo -->

## 第2关：拆数字

### 卡片：拆数字——短除法

<!-- card type:teacher -->
🔢 怎么把 `1234` 拆成 1、2、3、4？

- 取个位：`n % 10`
- 去掉个位：`n = n / 10`

反复做，直到 `n` 变成 0。

以 `n = 1234` 为例，变量变化如下：

| 循环次数 | n 变化前 | 输出个位 (n%10) | n 变化后 (n/10) |
|---------|---------|----------------|----------------|
| 第 1 次 | 1234 | 4 | 123 |
| 第 2 次 | 123 | 3 | 12 |
| 第 3 次 | 12 | 2 | 1 |
| 第 4 次 | 1 | 1 | 0（循环结束）|

> 💡 口诀：**取个位用 %10，去掉个位用 /10。**
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    while (n > 0) {
        cout << n % 10 << " ";  // 输出个位
        n = n / 10;             // 去掉个位
    }
    cout << endl;
    return 0;
}
```
<!-- end-demo -->

## 第3关：数位求和与乘积

### 卡片：数位求和

<!-- card type:teacher -->
➕ 数位求和：把每一位数字加起来。

`1234` 的数位和 = `1 + 2 + 3 + 4 = 10`

```cpp
int sum = 0;
while (n > 0) {
    sum = sum + n % 10;  // 把个位加到 sum
    n = n / 10;        // 去掉个位
}
```

> 💡 口诀：**sum 从 0 起，取一个加一次，去掉个位继续取。**
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    while (n > 0) {
        sum = sum + n % 10;
        n = n / 10;
    }
    cout << sum << endl;
    return 0;
}
```
<!-- end-demo -->

### 卡片：数位乘积

<!-- card type:teacher -->
✖️ 数位乘积：把每一位数字乘起来。

`123` 的数位积 = `1 × 2 × 3 = 6`

```cpp
int product = 1;   // 乘法要从 1 开始！
while (n > 0) {
    product = product * (n % 10);  // 乘上个位
    n = n / 10;
}
```

> 💡 为什么从 1 开始？因为 0 乘任何数都是 0，如果从 0 开始，结果永远是 0。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int product = 1;        // 乘法从 1 开始
    while (n > 0) {
        product = product * (n % 10);  // 乘上个位
        n = n / 10;
    }
    cout << product << endl;
    return 0;
}
```
<!-- end-demo -->

---

### 小贴士：乘法要从 1 开始

<!-- hint -->
求和时 `sum = 0`。
求乘积时 `product = 1`。

如果乘积从 0 开始，结果就永远是 0 啦！
<!-- end-hint -->

## 第4关：找数字与统计次数

### 卡片：判断数字里有没有某个数字

<!-- card type:teacher -->
🔍 比如判断 `12345` 里有没有 `3`。

拆每一位，如果发现某一位等于目标数字，就找到了！

```cpp
bool found = false;
while (n > 0) {
    if (n % 10 == target) {
        found = true;
        break;      // 找到了，提前结束
    }
    n = n / 10;
}
```

> 💡 `found` 是一个"标志旗"：
> - 一开始 `false`：还没找到
> - 找到了变成 `true`，立刻 `break`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, target;
    cin >> n >> target;
    bool found = false;
    while (n > 0) {
        if (n % 10 == target) {
            found = true;
            break;
        }
        n = n / 10;
    }
    if (found) {
        cout << "包含" << endl;
    } else {
        cout << "不包含" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：数位乘积

<!-- card type:computer -->
🖥️ 输入一个整数，输出每一位数字的乘积。

> 比如输入 123，输出 6（1×2×3）。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int product = 1;
    while (n > 0) {
        product = product * (n % 10);
        n = n / 10;
    }
    cout << product << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
📋 **评讲逻辑**

- **考察知识点**：`while` 拆数字、数位乘积、乘法初始值。
- **解题思路**：
  1. 读入整数 `n`；
  2. 初始化 `product = 1`（乘法要从 1 开始）；
  3. 当 `n > 0` 时，取出个位 `n % 10` 乘到 `product` 上；
  4. 用 `n = n / 10` 去掉个位，继续循环。
- **容易错的地方**：
  - 把 `product` 初始化为 0，导致结果永远是 0；
  - 忘记去掉个位，造成死循环；
  - 当 `n` 为 0 时循环不执行，结果输出 1，需要按题意特判。
- **关键代码解释**：
  ```cpp
  int product = 1;                     // 乘法从 1 开始
  while (n > 0) {
      product = product * (n % 10);    // 乘上个位
      n = n / 10;                      // 去掉个位
  }
  ```
<!-- end-card -->

## 挑战 2：统计某个数字出现几次

<!-- card type:computer -->
🖥️ 输入一个整数 n 和一个数字 d，统计 n 中 d 出现几次。

> 比如 n = 12223，d = 2，输出 3。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, d;
    cin >> n >> d;
    int count = 0;
    while (n > 0) {
        if (n % 10 == d) {
            count++;
        }
        n = n / 10;
    }
    cout << count << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
📋 **评讲逻辑**

- **考察知识点**：`while` 拆数字、计数器、`if` 条件判断。
- **解题思路**：
  1. 读入 `n` 和要查找的数字 `d`；
  2. 初始化计数器 `count = 0`；
  3. 当 `n > 0` 时，取出个位；
  4. 如果个位等于 `d`，`count++`；
  5. 去掉个位，继续检查下一位。
- **容易错的地方**：
  - `count` 初始化为 1 而不是 0；
  - 用赋值号 `=` 代替相等判断 `==`；
  - 找到目标后没有继续拆，漏掉后面相同的数字；
  - 忘记去掉个位导致死循环。
- **关键代码解释**：
  ```cpp
  int count = 0;
  while (n > 0) {
      if (n % 10 == d) {   // 当前位就是要找的数字
          count++;         // 计数加 1
      }
      n = n / 10;          // 去掉个位，继续检查
  }
  ```
<!-- end-card -->

## 报错也不慌：拆数字时死循环

<!-- card type:tip -->
💡 拆数字时最容易出现的 bug 是**忘记去掉个位**，导致 `while` 一直转圈：

```cpp
while (n > 0) {
    cout << n % 10 << endl;
    // 糟糕！忘了写 n = n / 10;
}
```

如果程序跑很久都不出结果，很可能就是这个原因。

另一个常见错误是把乘积初始成 0：

```cpp
int product = 0;   // ❌ 结果永远是 0
int product = 1;   // ✅ 要从 1 开始乘
```

> 🛠️ 检查两点：有没有 `n = n / 10;`，乘积是不是从 1 开始。
<!-- end-card -->

<!-- demo -->
```cpp
while (n > 0) {
    cout << n % 10 << endl;
    n = n / 10;   // ✅ 别忘了去掉个位
}
```
<!-- end-demo -->

## 卡片：拆完还能拼回去——数字替换

<!-- card type:teacher -->
🔄 上节课我们学会了“拆数字”，这节课学“改完再拼回去”。

比如把整数里所有的 `4` 换成 `8`：
- `144` → `188`
- `123` → `123`（没有 4，不变）

方法：
1. 用 `%10` 拆出最后一位；
2. 如果是 `4`，就改成 `8`；
3. 用 `ans = ans * 10 + d` 把这一位拼到新数里；
4. 用 `/10` 去掉旧数的这一位。

```cpp
int ans = 0;
while (n > 0) {
    int d = n % 10;
    if (d == 4) d = 8;
    ans = ans * 10 + d;
    n = n / 10;
}
```

> ⚠️ 这样拼出来的 `ans` 是**倒过来的**！比如 `144` 会变成 `881`。需要再倒一次才能得到 `188`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int ans = 0;
    while (n > 0) {
        int d = n % 10;
        if (d == 4) d = 8;
        ans = ans * 10 + d;
        n = n / 10;
    }
    // 再把 ans 倒回来
    int rev = 0;
    while (ans > 0) {
        rev = rev * 10 + ans % 10;
        ans = ans / 10;
    }
    cout << rev << endl;
    return 0;
}
```
<!-- end-demo -->

---

### 卡片：数字替换分步走

<!-- card type:teacher -->
以 `n = 144` 为例，把 4 换成 8：

**第一步：拆数字（从后往前拆）**
```
n = 144
  │
  ▼ 取个位：d = 144 % 10 = 4
  │  把 4 换成 8
  │  ans = 0 * 10 + 8 = 8
  │  n = 144 / 10 = 14
  │
  ▼ 取个位：d = 14 % 10 = 4
  │  把 4 换成 8
  │  ans = 8 * 10 + 8 = 88
  │  n = 14 / 10 = 1
  │
  ▼ 取个位：d = 1 % 10 = 1
     不需要换
     ans = 88 * 10 + 1 = 881
     n = 1 / 10 = 0
```

**第二步：倒回来**
```
ans = 881
  │
  ▼ 取个位：rev = 0 * 10 + 1 = 1, ans = 88
  ▼ 取个位：rev = 1 * 10 + 8 = 18, ans = 8
  ▼ 取个位：rev = 18 * 10 + 8 = 188, ans = 0
```

最后输出 `188`。

> 💡 记住：`ans = ans * 10 + d` 是从后往前拼，所以第一次拼出来的数是倒的，需要再倒一次。
<!-- end-card -->
