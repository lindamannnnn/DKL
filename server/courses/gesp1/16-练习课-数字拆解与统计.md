## 本课练习要点

<!-- card type:teacher -->
🧑‍🏫 今天我们要重点练习：

- **求和与计数**：`sum` 从 0 开始累加，`count` 从 0 开始统计满足条件的个数。
- **求最大/最小值**：先读第一个数作为初始值，再在循环里比较更新。
- **while 循环**：不知道要循环多少次时，用 `while` 配合条件判断。
- **短除法拆位**：`n % 10` 取个位，`n / 10` 去掉个位，循环直到 `n` 变成 0。
- **避免死循环**：循环体里一定要记得让变量发生变化，比如 `n = n / 10`。

> 💡 口诀：**求和 sum 从 0，计数 count 从 0，拆位先 %10 再 /10。**
<!-- end-card -->

## 报错也不慌：乘积初始为什么是 1？

<!-- card type:tip -->
💡 求和时 `sum = 0`，但求乘积时要写 `product = 1`！

因为如果写 `product = 0`，不管乘什么，结果都是 0。
<!-- end-card -->

<!-- demo -->
```cpp
int product = 1;
product = product * 2;   // 1 * 2 = 2
product = product * 3;   // 2 * 3 = 6
cout << product;         // 输出 6 ✅
```
<!-- end-demo -->

## 第 4 关：拆位求和

<!-- card type:computer -->
🖥️ 输入一个正整数，输出它各位数字之和。

例如输入 123，输出 6（因为 1+2+3=6）。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    while (n > 0) {
        sum = sum + n % 10;   // 取出个位，加入总和
        n = n / 10;           // 去掉个位
    }
    cout << sum << endl;
    return 0;
}
```
<!-- end-demo -->

## 小贴士：while 别忘让变量变化

<!-- hint -->
```cpp
while (n > 0) {
    cout << n % 10 << endl;
    n = n / 10;   // 千万别忘！
}
```

如果忘了让 `n` 变化，`while` 就会永远跑下去，变成死循环。
<!-- end-hint -->

## 挑战 1：优秀成绩统计

<!-- card type:computer -->
🖥️ 老师想统计一次小测验里有多少个优秀成绩。输入一个整数 n，再输入 n 个成绩，统计成绩大于等于 90 分的有多少个。

输入：第一行一个整数 n；第二行 n 个整数，表示每个成绩。
输出：一个整数，表示优秀成绩的数量。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int count = 0;
    for (int i = 1; i <= n; i++) {
        int score;
        cin >> score;
        if (score >= 90) {
            count++;
        }
    }
    cout << count << endl;
    return 0;
}
```

## 挑战 2：最重的西瓜

<!-- card type:computer -->
🖥️ 瓜摊上有 n 个西瓜，每个西瓜重量不一样。输入 n，再输入 n 个重量，找出最重的西瓜是多少千克。

输入：第一行一个整数 n；第二行 n 个整数，表示每个西瓜的重量（千克）。
输出：一个整数，表示最重的西瓜重量。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int maxWeight;
    cin >> maxWeight;          // 先读第一个，假设它最重
    for (int i = 2; i <= n; i++) {
        int w;
        cin >> w;
        if (w > maxWeight) {
            maxWeight = w;
        }
    }
    cout << maxWeight << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 3：数字各位求和

<!-- card type:computer -->
🖥️ 输入一个正整数，把它每一位上的数字加起来，输出总和。并判断这个总和是不是 9 的倍数：如果是，额外输出一行 "Yes"，否则输出 "No"。

例如输入 123，各位和是 6，不是 9 的倍数，输出：
```
6
No
```

输入：一个正整数 n。
输出：第一行是 n 的各位数字之和；第二行是 "Yes" 或 "No"。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    while (n > 0) {
        sum = sum + n % 10;   // 取出个位，加入总和
        n = n / 10;           // 去掉个位
    }
    cout << sum << endl;
    if (sum % 9 == 0) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 4：统计数字里的 0

<!-- card type:computer -->
🖥️ 输入一个正整数，统计它的各位数字里一共有几个 0。

例如输入 1005，里面有 2 个 0，输出 2。

输入：一个正整数 n。
输出：一个整数，表示 n 中数字 0 出现的次数。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int count = 0;
    while (n > 0) {
        if (n % 10 == 0) {
            count++;
        }
        n = n / 10;
    }
    cout << count << endl;
    return 0;
}
```

## 挑战 5：最高和最矮

<!-- card type:computer -->
🖥️ 体育课上量身高，老师想找出全班最高和最矮的同学。输入 n，再输入 n 个身高（厘米），输出最高身高和最矮身高，中间用一个空格隔开。

输入：第一行一个整数 n；第二行 n 个整数，表示每个同学的身高。
输出：两个整数，分别表示最高身高和最矮身高，中间用空格隔开。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int maxHeight, minHeight;
    cin >> maxHeight;          // 先把第一个同学当成最高
    minHeight = maxHeight;     // 也当成最矮
    for (int i = 2; i <= n; i++) {
        int h;
        cin >> h;
        if (h > maxHeight) {
            maxHeight = h;
        }
        if (h < minHeight) {
            minHeight = h;
        }
    }
    cout << maxHeight << " " << minHeight << endl;
    return 0;
}
```
<!-- end-demo -->
