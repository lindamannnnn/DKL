## 第1关：printf 按格式输出

<!-- story -->
小明比赛完了，要打印成绩单：

> 姓名：小明，成绩：95.50 分，排名：003

他想让数字按固定格式显示，比如排名一定要 3 位，不够就补 0。

`printf` 就是专门做这种格式化打印的！
<!-- end-story -->

---

### 卡片：printf 和 cout 是亲兄弟

<!-- card type:teacher -->
🖨️ `printf` 和 `cout` 一样，都是让电脑显示文字。

不一样的是：`printf` 可以在字符串里挖"坑"，用后面的值填进去。

```cpp
#include <bits/stdc++.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

> 💡 `#include <bits/stdc++.h>` 是 `printf` 和 `scanf` 的家。
<!-- end-card -->

---

### 卡片：printf 像做填空题

<!-- card type:teacher -->
📝 `printf` 的用法就像语文里的填空题：

```cpp
int num = 5;          // 整数
float price = 2.5;    // 小数
printf("我有 %d 个苹果，每个 %.2f 元。\\n", num, price);
```

- `%d` 是留给整数的空
- `%.2f` 是留给小数的空
- 后面的 `num`、`price` 就是填进去的答案

> 💡 有几个 `%` 符号，后面就要跟几个值，顺序要对。
<!-- end-card -->

---

### 卡片：挖个坑填数字

<!-- card type:teacher -->
🎫 占位符是 `%` 开头的符号，用来占位置。

| 占位符 | 填什么 |
|--------|--------|
| `%d` | 整数（int） |
| `%lld` | 长整数（long long） |
| `%f` | 小数（float / double） |
| `%lf` | 读 double 时用 |
| `%c` | 字符 |
| `%s` | 字符串（一句话） |

```cpp
int a = 10;
double b = 3.14;
printf("a = %d, b = %f\n", a, b);
```

> 输出：`a = 10, b = 3.14`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>

int main() {
    int a = 10;
    double b = 3.14;
    printf("a = %d, b = %f\n", a, b);
    return 0;
}
```
<!-- end-demo -->

## 第2关：scanf 读取输入

### 卡片：scanf 和 cin 是亲兄弟

<!-- card type:teacher -->
⌨️ `scanf` 和 `cin` 一样，都是读取输入。

格式：`scanf("占位符", &变量);`

```cpp
#include <bits/stdc++.h>

int main() {
    int age;
    printf("请输入你的年龄：");
    scanf("%d", &age);
    printf("你的年龄是：%d\n", age);
    return 0;
}
```

> ⚠️ `scanf` 里变量前面必须加 `&`！这是规矩，先记住。
<!-- end-card -->

---

### 卡片：& 是定位器

<!-- card type:teacher -->
🎯 `&` 可以想象成一个"定位器"：告诉电脑"把这个数字放到 age 这个盒子里"。

```cpp
scanf("%d", &age);   // ✅ 正确，有定位器
scanf("%d", age);    // ❌ 错误，电脑不知道放哪里
```

> 💡 记忆口诀：**scanf 里，变量前面要加 &。**
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>

int main() {
    int n;
    scanf("%d", &n);   // ✅ &n 不能少
    printf("你输入了 %d\n", n);
    return 0;
}
```
<!-- end-demo -->

---

### 卡片：cin/cout 和 scanf/printf 对照表

<!-- card type:teacher -->
| 你要做什么 | C++ 风格（简单） | C 风格（格式化） |
|-----------|----------------|----------------|
| 读一个整数 | `cin >> n;` | `scanf("%d", &n);` |
| 读一个小数 | `cin >> x;` | `scanf("%lf", &x);` |
| 输出一个整数 | `cout << n;` | `printf("%d", n);` |
| 输出一个小数 | `cout << x;` | `printf("%f", x);` |
| 输出保留 2 位小数 | 用 `fixed << setprecision(2)` | `printf("%.2f", x);` |
| 输出前面补 0 | 较麻烦 | `printf("%03d", n);` |

**记忆口诀：**
- `scanf` 里变量前面要加 `&`。
- `scanf` 读小数用 `%lf`，`printf` 输出小数用 `%f`。
- 两套不要混在同一行里！
<!-- end-card -->

### 过渡页：两套输入输出怎么选？

<!-- card type:teacher -->
🚦 你现在会了两套输入输出，别慌，其实很好选：

| 场景 | 用哪套 | 原因 |
|------|--------|------|
| 平时练习、初学 | `cin` / `cout` | 简单，不用记 `&` |
| 需要固定格式（如补 0、保留小数） | `scanf` / `printf` | 格式控制更直接 |
| 读入大数字（如 long long） | `scanf` 用 `%lld` | 更明确 |

> 💡 建议：**初学先用 cin/cout，遇到格式化需求再换 printf/scanf。** 两套不要混在同一行里。
<!-- end-card -->

## 第3关：格式控制与小数陷阱

### 卡片：控制数字格式

<!-- card type:teacher -->
🎨 想让数字按指定格式显示？

| 写法 | 意思 | 例子 |
|------|------|------|
| `%05d` | 整数宽度 5，不够补 0 | `7` → `00007` |
| `%5d` | 整数宽度 5，不够补空格 | `7` → `    7` |
| `%-5d` | 整数宽度 5，靠左对齐 | `7` → `7    ` |
| `%.2f` | 小数保留 2 位 | `3.14159` → `3.14` |

```cpp
int n = 7;
printf("%05d\n", n);   // 00007
printf("%-5d\n", n);   // 7    （左边对齐，右边补空格）
printf("%.2f\n", 3.14159);  // 3.14
```
<!-- end-card -->

---

### 卡片：格式控制小口诀

<!-- card type:teacher -->
🎯 记住这几个常用格式：

| 需求 | 写法 | 例子 |
|------|------|------|
| 整数补 0，宽度 3 | `%03d` | `7` → `007` |
| 整数靠左对齐，宽度 5 | `%-5d` | `7` → `7    ` |
| 小数保留 2 位 | `%.2f` | `3.14159` → `3.14` |
| 小数宽度 8，保留 2 位 | `%8.2f` | `3.14` → `    3.14` |

> 💡 口诀：**% 后面先写宽度，再写点精度，负号表示靠左。**
<!-- end-card -->

---

### 卡片：小数的坑

<!-- card type:teacher -->
⚠️ `scanf` 读 double 用 `%lf`，`printf` 输出 double 用 `%f`。

**容易混淆的对照表：**

| 动作 | double 用什么 | 例子 |
|------|--------------|------|
| `scanf` 读小数 | `%lf` | `scanf("%lf", &x);` |
| `printf` 输出小数 | `%f` | `printf("%f", x);` |

> 💡 记法：
> - **输入要“lf”（long float）**
> - **输出只要“f”**
> 
> 口诀：**scanf 读小数用 lf，printf 输出小数用 f。**
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>

int main() {
    double x;
    scanf("%lf", &x);          // 读小数用 %lf
    printf("%.2f\n", x);       // 输出小数用 %f
    return 0;
}
```
<!-- end-demo -->

### 报错也不慌：scanf 不要忘记 &

<!-- card type:tip -->
💡 用 `scanf` 读整数时，变量前面要加 `&`！

`scanf("%d", &n);` ✅ 正确
`scanf("%d", n);`  ❌ 忘记 & 会出错

> 记住口诀：**scanf 里，变量前面要加 &。**
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>

int main() {
    int n;
    scanf("%d", &n);   // ✅ &n 不能少
    printf("你输入了 %d\n", n);
    return 0;
}
```
<!-- end-demo -->

## 第4关：实战演练

### 卡片：时间换算

<!-- card type:teacher -->
⏰ 把总秒数变成"小时:分钟:秒"。

```cpp
int total;
scanf("%d", &total);
int h = total / 3600;       // 1 小时 = 3600 秒
int left = total % 3600;    // 剩下的秒数
int m = left / 60;          // 剩下的秒数里有多少分钟
int s = left % 60;          // 最后剩下的秒数
printf("%02d:%02d:%02d\n", h, m, s);
```

> 输入 3661，输出 `01:01:01`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>

int main() {
    int total;
    scanf("%d", &total);
    int h = total / 3600;
    int left = total % 3600;
    int m = left / 60;
    int s = left % 60;
    printf("%02d:%02d:%02d\n", h, m, s);
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：输出排名

<!-- card type:computer -->
🖥️ 输入一个整数排名，输出 3 位宽度、不足补 0 的形式。

> 比如输入 7，输出 `007`。

输入：一个整数 n。
输出：3 位宽度、不足补 0 的排名。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>

int main() {
    int n;
    scanf("%d", &n);
    printf("%03d\n", n);
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
🧑‍🏫 评讲逻辑：

- **考察知识点**：`printf` 的整数格式化输出，特别是用 `%03d` 进行前导补零。
- **解题思路**：
  1. 用 `scanf("%d", &n);` 读入排名。
  2. 用 `printf("%03d\n", n);` 输出，其中 `0` 表示不足位时补 0，`3` 表示总宽度为 3。
- **容易错的地方**：
  - 写成 `%3d`，这样会补空格而不是 0，输出会变成 `  7`。
  - 忘记在 `scanf` 里加 `&`。
- **关键代码解释**：
  - `%03d`：`%` 表示占位符，`0` 表示前导补 0，`3` 表示输出宽度，`d` 表示整数。
<!-- end-card -->

## 挑战 2：输出成绩

<!-- card type:computer -->
🖥️ 输入一个成绩（小数），按下面格式输出：

```
成绩：95.50 分
```

> 成绩保留 2 位小数。

输入：一个 double 类型的小数。
输出：按格式输出成绩，保留 2 位小数。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>

int main() {
    double score;
    scanf("%lf", &score);
    printf("成绩：%.2f 分\n", score);
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
🧑‍🏫 评讲逻辑：

- **考察知识点**：`scanf` 读取 `double` 类型、`printf` 保留两位小数，以及 `%lf` 与 `%f` 的区别。
- **解题思路**：
  1. 定义 `double score;`。
  2. 用 `scanf("%lf", &score);` 读入成绩（输入 double 必须用 `%lf`）。
  3. 用 `printf("成绩：%.2f 分\n", score);` 输出（输出 double 用 `%f`，`.2` 表示保留 2 位）。
- **容易错的地方**：
  - `scanf` 读 `double` 时用了 `%f`，会导致读入错误。
  - `printf` 输出时写成 `%.2lf`，虽然很多编译器能跑，但标准写法是 `%.2f`。
  - 忘记 `scanf` 中的 `&`。
- **关键代码解释**：
  - `scanf("%lf", &score);`：`%lf` 是 double 的输入占位符，`&score` 表示把读到的值放进 score 这个变量。
  - `printf("成绩：%.2f 分\n", score);`：`%.2f` 表示保留两位小数输出。
<!-- end-card -->
