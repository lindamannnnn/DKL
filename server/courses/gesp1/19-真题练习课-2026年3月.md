### 卡片：计算机常识小百科

<!-- card type:tip -->
真题选择题里常会问到电脑"硬件"和"软件"，记住这几类：

**硬件**（看得见、摸得着的设备）
- 输入设备：键盘、鼠标、麦克风、摄像头、传感器、遥控器
- 输出设备：屏幕、音箱、打印机
- 存储设备：硬盘、U 盘、内存条
- 控制器：CPU（电脑的大脑）

**软件**（装在电脑里的程序）
- 操作系统：Windows、macOS、Linux、手机里的 Android/iOS
- 应用程序：微信、浏览器、游戏、AI 算法程序

**一句话**：输入设备负责"把信息送进电脑"，软件负责"处理信息"。
<!-- end-card -->

## 挑战1：单选题（一）

<!-- card type:computer -->
🖥️ **第 1 题** 机器人表演时，重力传感器检测重心、摄像头拍摄周围、遥控器接收指令。下面哪项**不能**作为输入设备？

A. 重力传感器  
B. 预装的 AI 算法程序  
C. 遥控器  
D. 摄像头
<!-- end-card -->

<!-- demo -->
💡 **答案：B**

输入设备是用来向计算机输入信息的硬件。AI 算法程序是软件，不是输入设备。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 4 题** `3 * 3 % 2` 的值是多少？

A. 81  
B. 27  
C. 4  
D. 1
<!-- end-card -->

<!-- demo -->
💡 **答案：D**

先算 `3 * 3 = 9`，再算 `9 % 2 = 1`。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 5 题** 整型变量 a、b 的初值都是 4，下面代码的输出是？

```cpp
a, b = 3, 4;
cout << (a + 2) << (b - 2) << endl;
cout << a << b << endl;
```

A. `61` / `43`  
B. `52` / `34`  
C. `62` / `44`  
D. `62` / `32`
<!-- end-card -->

<!-- demo -->
💡 **答案：C**

`a, b = 3, 4;` 不是同时赋值，只有 b 被赋值为 4，a 保持原来的 4。
所以输出 `62` 和 `44`。

## 挑战2：单选题（二）

<!-- card type:computer -->
🖥️ **第 7 题** 下面代码执行时，说法正确的是？

```cpp
int M = 0, N = 0;
cin >> M;
cin >> N;
if (N > M)
    cout << (N - M);
else
    cout << (M - N);
```

A. 输入一正一负，结果一定大于 0  
B. 不管输入什么整数，结果一定大于等于 0  
C. 如果 N 和 M 相等，将不会有输出  
D. 如果输入小数，将按整数部分计算
<!-- end-card -->

<!-- demo -->
💡 **答案：B**

代码输出的是两个数的差（大减小），所以结果总是 ≥ 0。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 11 题** 下面代码用于求正整数的数位和。横线处应填入？

```cpp
int N;
cin >> N;
int tnt = 0;
while (N != 0){
    ______;
    ______;
}
cout << "N的数位和为：" << tnt;
```

A. `tnt += N / 10` 和 `N /= 10`  
B. `tnt += N % 10` 和 `N /= 10`  
C. `tnt += N / 10` 和 `N %= 10`  
D. `tnt = tnt + N % 10` 和 `N %= 10`
<!-- end-card -->

<!-- demo -->
💡 **答案：B**

要取出个位：`N % 10`，然后累加。再去掉个位：`N /= 10`。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 15 题** "双螺旋数"：奇数位的数位和等于偶数位的数位和。下面代码横线处应填入？

```cpp
int i, N, N1 = 0, N2 = 0, N0;
cin >> N;
N0 = N;
while (N){
    ______;
    ______;
}
if (N1 == N2)
    cout << N0 << "是双螺旋数" << endl;
```

A. `N1 += N%10, N /= 10;` 和 `N2 += N%10, N /= 10;`  
B. `N1 += N/10, N /= 10;` 和 `N2 += N/10, N /= 10;`  
C. `N1 += N%10, N %= 10;` 和 `N2 += N%10, N %= 10;`  
D. `N1 += N/10, N %= 10;` 和 `N2 += N/10, N %= 10;`
<!-- end-card -->

<!-- demo -->
💡 **答案：A**

循环中每次取两个数字（一个给 N1，一个给 N2），所以每次都要 `N /= 10`。
先取个位给 N1，再取新的个位给 N2。
<!-- end-demo -->

## 挑战3：判断题

<!-- card type:computer -->
🖥️ 判断下列说法是否正确（√ 或 ×）：

**第 1 题** 电话手表可以打电话、发信息，说明它里面装有操作系统。

**第 3 题** 下面代码成功执行后将输出 0。

```cpp
for (i = 1; i < 10; i++)
    if (i % 3 == 0)
        break;
cout << i;
```

**第 5 题** 执行下面代码，`cout << (N);` 会被执行 0 次或无数次。

```cpp
cin >> N;
while (N)
    cout << (N);
```

**第 6 题** 下面代码能判断输入的正整数是否为对称数（如 121、414）。

```cpp
cin >> n;
old_number = n;
new_number = 0;
while (n != 0){
    new_number = new_number * 10 + n % 10;
    n /= 10;
}
if (old_number == new_number)
    cout << "对称数";
else
    cout << "非对称数";
```

**第 9 题** 下面代码执行后将输出 2500。

```cpp
int cnt = 0;
for (int i = 1; i < 100; i++)
    cnt += i++;
cout << cnt;
```
<!-- end-card -->

<!-- demo -->
💡 **答案：**
- 第 1 题：√（智能设备通常都有操作系统）
- 第 3 题：×（i 到 3 时 break，输出 3）
- 第 5 题：√（N 为 0 时 0 次，N 非 0 时死循环）
- 第 6 题：√（代码通过反转数字判断是否对称）
- 第 9 题：×（i 每次自增 2，累加的是 1, 3, 5...，和是 2500 但循环条件导致最后结果不是 2500；实际输出不是 2500）

## 挑战4：编程题 - 交朋友

<!-- card type:computer -->
🖥️ **题目：** Alice 班上有 4 个小朋友，身高分别是 H1、H2、H3、H4，Alice 是 H1。她想和身高最接近她的人交朋友；如果有多人一样接近，选较矮的那个。输出这个朋友的身高。

**输入：** 4 行，每行一个整数  
**输出：** 一个整数，表示朋友的身高

**样例：**
- 输入：
```
150
165
135
133
```
- 输出：
```
135
```

**解释：** H2=165（差15）、H3=135（差15）、H4=133（差17）。H2 和 H3 都差 15，选较矮的 135。
<!-- end-card -->

---

### 卡片：交朋友题分步攻略

<!-- card type:teacher -->
这道题看起来长，但拆成三步就简单了：

**第一步：算差值**
```
H2 和 Alice 的差 = |H1 - H2|
H3 和 Alice 的差 = |H1 - H3|
H4 和 Alice 的差 = |H1 - H4|
```
用 `if (d < 0) d = -d;` 把负数变成正数。

**第二步：找最小差值**
先假设 H2 最接近，然后一个一个比：
- H3 的差更小 → 换成 H3
- H4 的差更小 → 换成 H4

**第三步：处理平局**
如果有人和当前答案差一样，但身高更矮，就选更矮的：
```cpp
if (d < mnd || (d == mnd && H3 < ans))
```

> 💡 可以先在纸上列出 4 个身高，算出每个差值，再按步骤找答案。
<!-- end-card -->

<!-- demo -->
💡 **参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int H1, H2, H3, H4;
    cin >> H1 >> H2 >> H3 >> H4;

    int ans = H2;
    int d = H1 - H2;
    if (d < 0) d = -d;
    int mnd = d;

    d = H1 - H3;
    if (d < 0) d = -d;
    if (d < mnd || (d == mnd && H3 < ans))
        ans = H3, mnd = d;

    d = H1 - H4;
    if (d < 0) d = -d;
    if (d < mnd || (d == mnd && H4 < ans))
        ans = H4;

    cout << ans << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战5：编程题 - 数字替换

<!-- card type:computer -->
🖥️ **题目：** Alice 不喜欢数字 4，喜欢数字 8。她把一个数中所有的 4 都替换成 8。如果数中不含 4，则不变。输出替换后的数。

**输入：** 一个整数 A  
**输出：** 替换后的整数 B

**样例：**
- 输入：`8459045`
- 输出：`8859085`

**解释：** 原数中有两个 4，都换成 8。
<!-- end-card -->

<!-- demo -->
💡 **参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b = 0, t = 1;
    cin >> a;
    while (a) {
        if (a % 10 == 4)
            b += t * 8;
        else
            b += t * (a % 10);
        a /= 10;
        t *= 10;
    }
    cout << b;
    return 0;
}
```
