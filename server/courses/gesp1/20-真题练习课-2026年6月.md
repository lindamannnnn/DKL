## 挑战1：单选题（一）

<!-- card type:computer -->
🖥️ **第 1 题** 智能温室中，湿度传感器把土壤湿度数据发送给中央控制器。湿度传感器的作用类似于计算机系统中的哪类组件？

A. 处理器  
B. 存储器  
C. 输入设备  
D. 输出设备
<!-- end-card -->

<!-- demo -->
💡 **答案：C（输入设备）**

传感器采集外界信息输入系统，属于输入设备。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 5 题** 下面代码的输出是？

```cpp
int a = 3;
int b = a;
a = 4;
printf("%d %d", a, b);
```

A. `3 3`  
B. `4 3`  
C. `4 4`  
D. `3 4`
<!-- end-card -->

<!-- demo -->
💡 **答案：B**

`b = a` 时 b 得到 3，之后 a 改成 4 不影响 b。所以输出 `4 3`。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 7 题** 下面代码执行时，说法错误的是？

```cpp
int N, M;
cin >> N >> M;
if (N > M)
    cout << "A" << (N - M);
else
    cout << "B" << (M - N);
```

A. 输入 4 3，输出 `A1`  
B. 输入 3 4，输出 `B1`  
C. 输入 3 3，输出 `A0`  
D. 输入 4 4，输出 `B0`
<!-- end-card -->

<!-- demo -->
💡 **答案：C**

输入 3 3 时，N 不大于 M，执行 else，输出 `B0`，不是 `A0`。
<!-- end-demo -->

## 挑战2：单选题（二）

<!-- card type:computer -->
🖥️ **第 11 题** 下面代码判断 N 是否为质数。如果输入 2，将输出什么？

```cpp
int N, i;
cin >> N;
for (i = 2; i < N; i++)
    if (N % i == 0) {
        cout << "1#";
        break;
    } else
        cout << "0#";
```

A. `1#`  
B. `0#1#`  
C. `0#`  
D. 没有输出
<!-- end-card -->

<!-- demo -->
💡 **答案：D**

输入 2 时，`i < N` 即 `2 < 2` 为假，循环一次都不执行，没有输出。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 14 题** 下面代码计算经过 n 秒后的秒针位置（0~59），横线处应填入？

```cpp
int start, n, pos;
cin >> start;
cin >> n;
pos = ______; // L1
if (______) // L2
    cout << n << "秒后回到12点方向" << endl;
else
    cout << n << "秒后指向" << pos << "秒刻度" << endl;
```

A. `(start + n) / 60` 和 `pos == 0`  
B. `(start + n) % 60` 和 `pos == 0`  
C. `(start + n) / 60` 和 `pos <= 0`  
D. `(start + n) % 60` 和 `pos = 0`
<!-- end-card -->

<!-- demo -->
💡 **答案：B**

秒针位置用取模：`pos = (start + n) % 60`。判断是否回到 12 点方向：`pos == 0`。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 15 题** 下面代码判断 N 是否为质数，横线处**不应**填入的是？

```cpp
int N, i;
cin >> N;
if (N <= 1) {
    cout << "NO";
    return 0;
}
for (i = 2; ______; i++) {
    if (N % i == 0) {
        cout << "NO";
        return 0;
    }
}
cout << "YES";
```

A. `i < N`  
B. `i <= N`  
C. `i <= N / 2`  
D. `i * i <= N`
<!-- end-card -->

<!-- demo -->
💡 **答案：B**

如果填 `i <= N`，当 i = N 时，`N % N == 0`，会错误地输出 NO。所以 B 不应该填入。
<!-- end-demo -->

## 挑战3：判断题

<!-- card type:computer -->
🖥️ 判断下列说法是否正确（√ 或 ×）：

**第 1 题** AI 眼镜内置操作系统，可能支持 Wi-Fi 或蓝牙连接。

**第 3 题** 下面代码执行后将输出 19。

```cpp
int i;
for (i = 0; i < 20; i += 3)
    if (i % 3 != 0)
        break;
cout << i;
```

**第 5 题** 下面代码能实现输出正整数 N 的各位数字。

```cpp
int N;
cin >> N;
while (N > 0) {
    cout << (N % 10) << endl;
    N = N / 10;
}
```

**第 8 题** 下面代码执行后将输出 24。

```cpp
int total;
for (int n = 1; n <= 4; n++) {
    total *= n;
}
cout << total;
```

**第 10 题** 删除下面代码中的 `continue` 后，输出与原来相同。

```cpp
int x = 0;
while (x < 4) {
    x++;
    if (x == 2) continue;
    cout << x << ",";
}
```
<!-- end-card -->

<!-- demo -->
💡 **答案：**
- 第 1 题：√（AI 眼镜是智能设备，有操作系统和联网能力）
- 第 3 题：×（i 从 0 开始，i % 3 == 0，不会 break，最后 i 会变成 21，循环条件不满足，输出 21）
- 第 5 题：√（循环每次取个位并输出，再去掉个位）
- 第 8 题：×（total 没有初始化，值不确定）
- 第 10 题：×（原来跳过 x==2，输出 `1,3,4,`；删除 continue 后输出 `1,2,3,4,`）
<!-- end-demo -->

## 挑战4：编程题 - 去旅行

<!-- card type:computer -->
🖥️ **题目：** 小杨从 A 市去 B 市，有三种方案：
1. 直飞 B 市
2. 高铁到 C 市，再飞机到 B 市
3. 高铁到 C 市，再高铁到 B 市

输入 4 个价格，输出最便宜方案的价格。

**输入：** 4 行正整数，分别是：直飞价格、A到C高铁价格、C到B飞机价格、C到B高铁价格  
**输出：** 一个整数，表示最低价格

**样例：**
- 输入：
```
999
105
699
588
```
- 输出：
```
693
```

**解释：** 方案1=999，方案2=105+699=804，方案3=105+588=693，最便宜是 693。
<!-- end-card -->

<!-- demo -->
💡 **参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b, c, d;
    cin >> a >> b >> c >> d;
    int x = a, y = b + c, z = b + d;
    if (x <= y && x <= z)
        cout << x;
    else if (y <= x && y <= z)
        cout << y;
    else
        cout << z;
    cout << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战5：编程题 - 交税

<!-- card type:computer -->
🖥️ **题目：** 计算 12 个月的劳务报酬总税额。规则：
- 每月不超过 800 的部分不扣税
- 超过 800 的部分按 20% 扣税

输入 12 行，每行一个有一位小数的浮点数。输出总税额，保留 2 位小数。

**样例：**
- 输入：
```
932.0
1634.3
1790.4
2172.9
378.1
283.4
2761.9
3583.5
10.1
2324.9
1111.6
3812.3
```
- 输出：
```
2584.76
```
<!-- end-card -->

<!-- demo -->
💡 **参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    double ans = 0.0;
    for (int i = 0; i < 12; ++i) {
        double a;
        cin >> a;
        if (a > 800.0) {
            ans += (a - 800.0) * 0.2;
        }
    }
    printf("%.2f\n", ans);
    return 0;
}
```
<!-- end-demo -->
