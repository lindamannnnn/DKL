# GESP 1级 / CSP01 阶段课程体系规划

本规划参考 `code-master/code/01-课程教学资料/各阶段大纲/CSP01大纲.md`，将 GESP 1级（CSP01 阶段）内容划分为 20 节课（含练习课与真题训练课）。

## 课程目标

面向小学 4-6 年级学生，从零基础到能独立完成 GESP 1级认证考试所需的 C++ 程序设计题目。

## 每节课详细内容

### 课程01：走进 C++
- 计算机发展简史（ENIAC、个人电脑）
- 计算机基本组成：输入/输出设备、CPU、存储器
- Dev-C++ 的安装与使用
- 第一个 C++ 程序：Hello World
- 程序基本框架：`#include`、`using namespace std;`、`main()`、`return 0;`
- 变量类型、声明、赋值与初始化
- `cin` 输入与 `cout` 输出
- 赋值语句
- 算术运算：`+`、`-`、`*`、`/`、`%`

### 课程02：整数运算
- 计算机软硬件组成、常见操作、发展历程
- 标识符、关键字、常量、变量、表达式的概念
- 常量与变量的命名、定义、作用
- 整型变量类型的具体使用
- 整除 `/` 与取余 `%` 的使用
- 数字拆位与数字颠倒
- 时间进位换算（秒 → 时分秒）
- 星期计算（取模）
- 最小公倍数枚举

### 课程03：小数运算
- 实数类型：`float`、`double`
- 有效数字与位数保留
- 四舍六入五凑双
- 整数类型转为小数类型
- 程序的注释
- 温度转换

### 课程04：练习课：计算小达人
- 整数与小数运算综合练习

### 课程05：分支入门
- 布尔判断与布尔变量 `bool`
- 关系运算符
- 单分支 `if` 与双分支 `if-else`
- 奇偶判断与倍数判断
- 三目运算符

### 课程06：分支嵌套与多条件
- `if-else` 嵌套
- 多条件组合判断（`&&` / `||`）
- 三目运算符复习

### 课程07：多路分支
- 多分支 `if-else if-else`
- 逻辑运算符
- 运算符优先级
- 闰年平年判断
- 长题拆读法
- 多方案比较与分段计税

### 课程08：练习课：分支大冒险
- 分支结构综合练习

### 课程09：字符类型与 switch
- ASCII 编码与字符类型 `char`
- 字符判断与转换
- `switch` 结构与 `break`

### 课程10：for 循环
- `for` 循环结构
- 全局变量与局部变量
- 变量自增与自减运算
- 循环 + 判断的使用
- 枚举思想
- 平方和累加

### 课程11：循环控制
- `continue`、`break` 的使用
- 质数与合数
- 标记变量 `bool`
- 质数判断优化：使用 `i * i <= n`（不使用 `sqrt()`）
- 双重循环

### 课程12：练习课：循环闯关
- 循环综合练习

### 课程13：求和计数
- 求和与平均数（循环输入）
- 因子和
- 数据遍历统计
- 最大值与最小值
- 多组数据处理

### 课程14：while 循环
- `while` 与 `do-while` 循环结构
- 复合运算符

### 课程15：短除法
- 循环 n 次 `while(t--)`（用 t 替换 n）
- 数位求和
- 数字包含判断
- 数字重构（拆位 → 替换 → 拼回）

### 课程16：练习课：数字拆解与统计
- 数字拆解综合练习

### 课程17：C风格输入输出
- `printf` 与 `scanf` 的用法
- 占位符的概念与使用
- 格式化输入与输出
- 时间换算

### 课程18：练习课：GESP1 综合大闯关
- GESP1 全部知识综合练习

### 课程19：真题练习课：操作题基础篇
- 历年 GESP1 真题操作题基础训练
- 输入输出、分支、循环、整数除法、枚举

### 课程20：真题练习课：操作题进阶篇
- 历年 GESP1 真题操作题进阶训练
- 枚举陷阱、时间换算、数字重构、多方案比较、长题拆读
