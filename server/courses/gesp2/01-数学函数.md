## 🛠️ 知识点一：绝对值函数 `abs()`

`abs()` 来自 `<cstdlib>`，它的作用是把一个数变成“正数”：负数变正，正数不变。

```cpp
#include <iostream>
#include <cstdlib>
using namespace std;

int main() {
    cout << abs(-7) << endl;   // 输出 7
    cout << abs(7) << endl;    // 输出 7
    cout << abs(0) << endl;    // 输出 0
    return 0;
}
```
<!-- run -->

### 🔍 注意

`abs()` 通常用于**整数**。如果给小数求绝对值，可能会出错，要用 `fabs()`（本课不要求掌握）。

## 🛠️ 知识点二：平方根函数 `sqrt()`

`sqrt()` 来自 `<cmath>`，用来求一个数的平方根。

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    cout << sqrt(9) << endl;    // 输出 3
    cout << sqrt(2) << endl;    // 输出约 1.41421
    cout << sqrt(0) << endl;    // 输出 0
    return 0;
}
```
<!-- run -->

### 🔍 注意

`sqrt()` 的返回结果是**小数（double）**。如果想保存到整数变量里，需要用强制类型转换，下节课会详细讲。

## 🛠️ 知识点三：最大值 `max()` 和最小值 `min()`

`max()` 和 `min()` 来自 `<algorithm>`，用来比较两个数的大小。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a = 5, b = 8;
    cout << max(a, b) << endl;  // 输出 8
    cout << min(a, b) << endl;  // 输出 5
    cout << max(12, 3) << endl; // 输出 12
    return 0;
}
```
<!-- run -->

### 💡 小提示

<!-- hint -->
`max()` 和 `min()` 一次只能比较**两个数**。如果想比较三个数，可以嵌套使用：

```cpp
int biggest = max(a, max(b, c));
```
<!-- end-hint -->

## 🛠️ 知识点四：四舍五入函数 `round()`

`round()` 来自 `<cmath>`，作用是把一个小数四舍五入为最接近的整数。

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    cout << round(3.4) << endl;  // 输出 3
    cout << round(3.5) << endl;  // 输出 4
    cout << round(3.6) << endl;  // 输出 4
    cout << round(-2.5) << endl; // 输出 -2
    return 0;
}
```
<!-- run -->

### 🔍 注意

`round()` 的返回值虽然是整数形式，但类型是**小数类型（double）**。如果想得到 `int`，可以赋值给 `int` 变量，C++ 会自动转换。

```cpp
int x = round(3.7);  // x 的值是 4
```

## 🛠️ 知识点五：随机数函数 `rand()` / `srand()`

`rand()` 来自 `<cstdlib>`，可以生成一个随机整数。`srand()` 用来设置“种子”，让每次运行结果不同。

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    srand(time(0));            // 用当前时间做种子
    cout << rand() << endl;    // 输出一个随机整数
    return 0;
}
```
<!-- run -->

### 💡 如何生成指定范围的随机数？

想生成 **0 ~ 99** 的随机数：

```cpp
int x = rand() % 100;
```

想生成 **1 ~ 100** 的随机数：

```cpp
int x = rand() % 100 + 1;
```

想生成 **a ~ b** 的随机数：

```cpp
int x = rand() % (b - a + 1) + a;
```

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    srand(time(0));
    cout << rand() % 10 + 1 << endl;       // 1 ~ 10
    cout << rand() % 100 + 1 << endl;      // 1 ~ 100
    return 0;
}
```
<!-- run -->

### 🔍 注意

- `srand(time(0))` 只需要在程序开头调用**一次**。
- `time(0)` 来自 `<ctime>`，表示当前时间。
