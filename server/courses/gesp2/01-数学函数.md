## abs：绝对值

<!-- card type:teacher -->
🧑‍🏫 `abs(x)` 求 `x` 的绝对值。

比如 `abs(-7)` 等于 `7`，`abs(5)` 还是 `5`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    cout << abs(-7) << endl;  // 7
    cout << abs(5) << endl;   // 5
    return 0;
}
```
<!-- end-demo -->

## max 与 min：比大小

<!-- card type:teacher -->
🧑‍🏫 `max(a, b)` 返回较大的那个，`min(a, b)` 返回较小的那个。

注意：两个参数的类型必须一致！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    cout << max(3, 7) << endl;  // 7
    cout << min(3, 7) << endl;  // 3
    return 0;
}
```
<!-- end-demo -->

## sqrt：开平方

<!-- card type:teacher -->
🧑‍🏫 `sqrt(x)` 求 `x` 的平方根，**返回值是 double**！

如果传入整数，也会自动变成小数结果。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    cout << sqrt(16) << endl;   // 4
    cout << sqrt(2.0) << endl;  // 约1.414
    return 0;
}
```
<!-- end-demo -->

## floor / ceil / round：取整三姐妹

<!-- card type:teacher -->
🧑‍🏫
- `floor(x)`：向下取整（地板），`floor(3.9) = 3`。
- `ceil(x)`：向上取整（天花板），`ceil(3.1) = 4`。
- `round(x)`：四舍五入，`round(3.5) = 4`。

负数要特别注意：`floor(-3.1) = -4`！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    cout << floor(3.9) << endl;  // 3
    cout << ceil(3.1) << endl;   // 4
    cout << round(3.4) << endl;  // 3
    cout << round(3.5) << endl;  // 4
    return 0;
}
```
<!-- end-demo -->

## rand 与 srand：随机数

<!-- card type:teacher -->
🧑‍🏫 `rand()` 生成一个随机整数，`srand(time(0))` 用当前时间当“种子”洗牌。

> 💡 `time(0)` 是什么？它就是"现在的时刻"（电脑里的时钟），每次运行都不一样，所以能让随机数每次都不一样。你暂时不用管它怎么算出来的，记住"洗牌要写 `srand(time(0))`"就行。

生成 `[a, b]` 范围内随机整数的公式是：

`rand() % (b - a + 1) + a`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    srand(time(0));               // 洗牌
    cout << rand() % 6 + 1 << endl; // 1~6
    return 0;
}
```
<!-- end-demo -->

## 挑战1

<!-- card type:computer -->
🖥️ 输入两个整数 a 和 b，输出较大的那个。

**输入样例：** `3 7`

**输出样例：** `7`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    int a, b;
    cin >> a >> b;
    cout << max(a, b) << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战2

<!-- card type:computer -->
🖥️ 模拟掷两枚六面骰子，输出点数及总和。

**输出格式：** `骰子1: X, 骰子2: Y, 合计: Z`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    srand(time(0));
    int d1 = rand() % 6 + 1, d2 = rand() % 6 + 1;
    cout << "骰子1: " << d1 << ", 骰子2: " << d2 << ", 合计: " << d1 + d2 << endl;
    return 0;
}
```
<!-- end-demo -->

## 小贴士

<!-- card type:tip -->
💡 `sqrt()` 返回的是 `double`，判断完全平方数时建议用 `round(sqrt(n))` 再平方验证，避免浮点误差。

💡 随机数一定要记得 `srand(time(0))` 洗牌，否则每次运行结果都一样。
<!-- end-card -->
