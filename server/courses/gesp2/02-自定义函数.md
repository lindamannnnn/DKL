## 照抄一台机器

<!-- card type:teacher -->
🧑‍🏫 先别急着创造，我们先“照抄”一台能算加法的机器。

看下面这段代码，把它原样敲进电脑，运行看看。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

int main()

    return 0;
}
```

## 函数的定义

<!-- card type:teacher -->
🧑‍🏫 自定义函数有“四件套”：

1. 返回类型
2. 函数名
3. 参数列表
4. 函数体

`return` 把结果传回调用处。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int square(int n)
{
    return n * n;
}

int main()
{
    cout << square(4) << endl;  // 16
    return 0;
}
```
<!-- end-demo -->

## 前置声明

<!-- card type:teacher -->
🧑‍🏫 如果函数写在 `main()` 后面，编译器会“不认识”它。

> 💡 “编译器”就是把你的 C++ 代码翻译成电脑能运行的程序的工具。它读代码是从上往下的，读到 `main()` 里调用一个还没见过的函数，就会报错。

在前面加一行“预告”，只写函数头，末尾加分号。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int add(int a, int b);  // 前置声明

int main()
{
    cout << add(2, 4) << endl;  // 6
    return 0;
}

int add(int a, int b)
{
    return a + b;
}
```
<!-- end-demo -->

## 形参与实参

<!-- card type:teacher -->
🧑‍🏫 函数定义里的参数叫**形参**，调用时传进去的叫**实参**。

C++ 默认是**值传递**：函数里修改形参，**不会**影响外面的实参。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

void tryChange(int x)
{
    x = 100;  // 只改了形参
}

int main()
{
    int a = 5;
    tryChange(a);
    cout << a << endl;  // 还是 5
    return 0;
}
```
<!-- end-demo -->

## 作用域：全局与局部

<!-- card type:teacher -->
🧑‍🏫 函数外面定义的变量叫**全局变量**，整个程序都能用。

函数里面定义的变量叫**局部变量**，只在该函数里有效。

同名时，**局部优先**！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int x = 10;            // 全局变量

void show()
{
    int x = 20;        // 局部变量
    cout << x << endl; // 20
}

int main()
{
    cout << x << endl;  // 10
    show();
    return 0;
}
```
<!-- end-demo -->

## void 函数

<!-- card type:teacher -->
🧑‍🏫 如果函数不需要返回结果，返回类型写 `void`。

`void` 函数不需要写 `return` 返回值。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

void printStar(int n)
{
    for (int i = 0; i < n; i++)
        cout << "*";
    cout << endl;
}

int main()
{
    printStar(5);  // *****
    return 0;
}
```
<!-- end-demo -->

## 小知识：三目运算符 `?:`

<!-- card type:teacher -->
🧑‍🏫 有时候我们要在函数里返回“二选一”的结果，用 `if-else` 要写很多行。

C++ 提供了一个简写符号：`?:`，也叫**三目运算符**。

格式：

```cpp
条件 ? 值A : 值B
```

意思是：如果条件成立，结果取值 A；否则取值 B。

它只能表达“二选一”，适合简短分支，不要嵌套太多层！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int myMax(int a, int b)
{
    return a > b ? a : b;   // 如果 a>b，返回 a，否则返回 b
}

int main()
{
    int x, y;
    cin >> x >> y;
    cout << myMax(x, y) << endl;
    return 0;
}
```
<!-- end-demo -->

## 小试牛刀：if-else 变 `?:`

<!-- card type:teacher -->
🧑‍🏫 下面这段 `if-else` 能不能用 `?:` 写得更短？试试看：

```cpp
int myAbs(int n)
{
    if (n >= 0)
        return n;
    else
        return -n;
}
```

答案：

```cpp
int myAbs(int n)
{
    return n >= 0 ? n : -n;
}
```

记住：先看条件，再看 `?` 后面的值，最后看 `:` 后面的值。
<!-- end-card -->

## 挑战1

<!-- card type:computer -->
🖥️ 定义函数 `int square(int n)`，返回 n 的平方。

在 `main` 中输入 n，输出结果。

**输入样例：** `7`

**输出样例：** `49`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int square(int n)
{
    return n * n;
}

int main()

    cin >> n;
    cout << square(n) << endl;
    return 0;
}
```

## 挑战2

<!-- card type:computer -->
🖥️ 定义函数 `void printStars(int n)`，打印 n 个 `*`。

在 `main` 中输入宽 w 和高 h，打印 w×h 的星号矩形。

**输入样例：** `4 3`

**输出样例：**
```
****
****
****
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

void printStars(int n)
{
    for (int i = 0; i < n; i++)
        cout << "*";
    cout << endl;
}

int main()
{
    int w, h;
    cin >> w >> h;
    for (int i = 0; i < h; i++)
        printStars(w);
    return 0;
}
```
<!-- end-demo -->

## 小贴士

<!-- card type:tip -->
💡 嵌套 if 时一定要加大括号，避免“悬空 else”找错对象。

💡 函数名最好有意义，比如 `square` 比 `f` 更容易读懂。

💡 函数里修改形参不会改外面的实参，这是 C++ 的值传递规则。

💡 三目运算符 `?:` 适合简短二选一，太长还是乖乖写 `if-else`。
<!-- end-card -->
