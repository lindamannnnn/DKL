## 🛠️ 知识点一：函数是什么？

函数是一段可以重复使用的代码块。它有一个名字，可以被程序其他地方调用。

### 📝 函数的基本结构

```cpp
返回类型 函数名(参数列表) {
    // 函数体
    return 返回值;
}
```

### 例子：写一个求两数之和的函数

```cpp
#include <iostream>
using namespace std;

// 函数定义
int add(int a, int b) {
    int s = a + b;
    return s;
}

int main() {
    int x = 3, y = 5;
    int result = add(x, y);  // 函数调用
    cout << result << endl;  // 输出 8
    return 0;
}
```
<!-- run -->

### 🔍 每一部分的名字

| 部分 | 例子 | 说明 |
|------|------|------|
| 返回类型 | `int` | 函数返回什么类型的结果 |
| 函数名 | `add` | 调用函数时用的名字 |
| 参数 | `int a, int b` | 函数需要的数据 |
| 函数体 | `{ ... }` | 具体执行的代码 |
| return | `return s;` | 把结果送回调用处 |

## 🛠️ 知识点二：函数的定义与调用

### 定义函数

定义函数就是“把积木搭好”。

```cpp
int square(int n) {
    return n * n;
}
```

### 调用函数

调用函数就是“使用搭好的积木”。

```cpp
int main() {
    cout << square(4) << endl;  // 输出 16
    cout << square(5) << endl;  // 输出 25
    return 0;
}
```

```cpp
#include <iostream>
using namespace std;

int square(int n) {
    return n * n;
}

int main() {
    cout << square(4) << endl;
    cout << square(5) << endl;
    return 0;
}
```

## 🛠️ 知识点三：函数声明（前置声明）

有时候，我们把函数写在 `main()` 后面。这时需要在 `main()` 前面先“预告”一下，这就是**函数声明**。

```cpp
#include <iostream>
using namespace std;

// 函数声明
int add(int a, int b);

int main() {
    cout << add(3, 5) << endl;  // 输出 8
    return 0;
}

// 函数定义
int add(int a, int b) {
    return a + b;
}
```
<!-- run -->

### 🔍 声明和定义的区别

- **声明**：只写函数头，告诉编译器“这个函数存在”，以分号结尾。
- **定义**：写完整的函数体，说明函数具体做什么。

```cpp
int add(int a, int b);        // 声明
int add(int a, int b) { ... } // 定义
```

## 🛠️ 知识点四：形参和实参

### 什么是形参？

函数定义时括号里的变量叫**形式参数**（简称形参）。

```cpp
int add(int a, int b) {  // a 和 b 是形参
    return a + b;
}
```

### 什么是实参？

函数调用时传给函数的具体值叫**实际参数**（简称实参）。

```cpp
add(3, 5);  // 3 和 5 是实参
```

```cpp
#include <iostream>
using namespace std;

int add(int a, int b) {  // 形参
    return a + b;
}

int main() {
    int x = 10, y = 20;
    cout << add(x, y) << endl;  // x 和 y 是实参，输出 30
    cout << add(100, 200) << endl;  // 100 和 200 是实参，输出 300
    return 0;
}
```
<!-- run -->

### 🔍 重要规则

- 实参的值会“拷贝”给形参。
- 函数内部改变形参的值，**不会影响**外面的实参。

## 🛠️ 知识点五：全局作用域与局部作用域

### 局部变量

在函数内部定义的变量，只能在这个函数内部使用，称为**局部变量**。

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 10;  // x 是 main 函数里的局部变量
    cout << x << endl;
    return 0;
}
```

### 全局变量

在函数外部定义的变量，整个程序都能使用，称为**全局变量**。

```cpp
#include <iostream>
using namespace std;

int g = 100;  // 全局变量

int main() {
    cout << g << endl;  // 输出 100
    return 0;
}
```

```cpp
#include <iostream>
using namespace std;

int g = 100;  // 全局变量

void test() {
    cout << "在 test 函数里：" << g << endl;
}

int main() {
    cout << "在 main 函数里：" << g << endl;
    test();
    return 0;
}
```
<!-- run -->

### 🔍 当全局变量和局部变量同名时

如果函数内部也有一个叫 `g` 的局部变量，函数会优先使用**局部变量**。

```cpp
#include <iostream>
using namespace std;

int g = 100;  // 全局变量

void test() {
    int g = 5;  // 局部变量
    cout << g << endl;  // 输出 5
}

int main() {
    test();
    cout << g << endl;  // 输出 100
    return 0;
}
```
<!-- run -->

### 💡 小提示

<!-- hint -->
尽量避免使用全局变量，因为它可能被程序任何地方修改，容易出错。能用局部变量解决就用局部变量。
<!-- end-hint -->

## 🛠️ 知识点六：`void` 函数——不返回结果的函数

有些函数只做事，不返回结果，比如打印一句话。这时返回类型写 `void`。

```cpp
#include <iostream>
using namespace std;

void sayHello() {
    cout << "你好！" << endl;
}

int main() {
    sayHello();  // 调用函数
    sayHello();  // 再次调用
    return 0;
}
```
<!-- run -->

### 🔍 注意

`void` 函数不需要写 `return` 语句，也可以写 `return;` 表示提前结束。
