## 🛠️ 知识点一：流程图

流程图是用图形表示算法步骤的工具。

### 常用图形

| 图形 | 含义 | 例子 |
|------|------|------|
| 椭圆 | 开始 / 结束 | 开始 |
| 矩形 | 处理步骤 | a = a + 1 |
| 菱形 | 判断 | a > 0 ? |
| 平行四边形 | 输入 / 输出 | 输入 a |
| 箭头 | 流程方向 | → |

### 例子：判断一个数是正数还是负数

```
开始
  │
  ▼
输入 n
  │
  ▼
┌─────────┐
│ n > 0 ? │
└────┬────┘
     │
   是 / 否
   │      │
   ▼      ▼
输出正数 输出非正数
   │      │
   ▼      ▼
  结束   结束
```

## 🛠️ 知识点二：ASCII 编码与转换

计算机内部用数字表示字符，这种对应关系叫 **ASCII 编码**。

### 常见字符的 ASCII 值

| 字符 | ASCII 值 |
|------|----------|
| '0'  | 48 |
| '9'  | 57 |
| 'A'  | 65 |
| 'Z'  | 90 |
| 'a'  | 97 |
| 'z'  | 122 |
| 空格 | 32 |

### 字符与整数互相转换

在 C++ 中，`char` 类型和 `int` 类型可以直接转换。

```cpp
#include <iostream>
using namespace std;

int main() {
    char c = 'A';
    cout << (int)c << endl;  // 输出 65

    int x = 66;
    cout << (char)x << endl; // 输出 B

    cout << (int)'0' << endl; // 输出 48
    return 0;
}
```
<!-- run -->

### 💡 小应用：字符转数字

输入一个数字字符，如 `'5'`，如何得到整数 5？

```cpp
char c = '5';
int n = c - '0';  // '5' 的 ASCII 是 53，'0' 是 48，53 - 48 = 5
```

```cpp
#include <iostream>
using namespace std;

int main() {
    char c;
    cin >> c;
    int n = c - '0';
    cout << n << endl;  // 如果输入 5，输出 5
    return 0;
}
```

## 🛠️ 知识点三：强制类型转换

强制类型转换就是手动把一个类型的值变成另一个类型。

### 语法

```cpp
(目标类型)表达式
```

### 例子

```cpp
#include <iostream>
using namespace std;

int main() {
    double a = 3.8;
    int b = (int)a;      // 强制把 double 转成 int，小数部分直接舍弃
    cout << b << endl;   // 输出 3

    int x = 7;
    double y = (double)x / 2;  // 先把 x 转成 double，再做除法
    cout << y << endl;   // 输出 3.5

    return 0;
}
```
<!-- run -->

### 🔍 注意

- `(int)3.8` 得到 3，不是四舍五入。
- 如果想四舍五入，要用 `round()`。

## 🛠️ 知识点四：隐式类型转换

当不同类型一起运算时，C++ 会自动把小类型“升级”成大类型，这叫**隐式类型转换**。

### 常见情况

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    double b = 2.0;
    cout << a / 2 << endl;    // 整数除法，输出 2
    cout << a / b << endl;    // a 自动转成 double，输出 2.5

    char c = 'A';
    cout << c + 1 << endl;    // c 自动转成 int，输出 66
    cout << (char)(c + 1) << endl; // 输出 B

    return 0;
}
```
<!-- run -->

### 🔍 规则小结

- `int` 和 `double` 运算 → 结果是 `double`
- `char` 和 `int` 运算 → `char` 先变成 `int`
- 赋值时把大类型赋给小类型 → 可能丢失精度

## 🛠️ 知识点五：周期偏移量

很多生活中的问题有周期性，比如星期、钟表、月份。我们可以用取模运算 `%` 解决。

### 例子：今天是星期几？

假设今天是星期三（用 3 表示），问 10 天后是星期几？

```cpp
#include <iostream>
using namespace std;

int main() {
    int today = 3;      // 星期三
    int days = 10;
    int future = (today + days) % 7;  // 周期是 7
    cout << future << endl;  // 输出 6，星期六
    return 0;
}
```
<!-- run -->

### 💡 小口诀

<!-- hint -->
周期问题三步走：
1. 找到周期长度。
2. 用 `(起始 + 偏移) % 周期` 计算。
3. 根据余数判断结果。
<!-- end-hint -->
