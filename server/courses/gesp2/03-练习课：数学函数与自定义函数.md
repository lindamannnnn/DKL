## 本课练习要点

<!-- card type:teacher -->
🧑‍🏫 这节课我们不学新语法，重点复习：
- 数学函数：`abs`、`sqrt`、`max`、`min`、`round`、`rand`
- 自定义函数：定义、调用、声明
- 形参、实参与值传递

练习时要注意：
1. 审题：看清输入、输出、保留小数
2. `sqrt()` 返回 `double`，判断完全平方数时小心浮点误差
3. 函数内修改形参，外面的实参**不会**变
4. 随机数别忘了 `srand(time(0))`
<!-- end-card -->

## 挑战 1：三数最大值

<!-- card type:computer -->
🖥️ 输入三个整数 a、b、c，输出最大的那个。

**输入样例：** `3 7 5`

**输出样例：** `7`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int a, b, c;
    cin >> a >> b >> c;
    cout << max(a, max(b, c)) << endl;  // 嵌套比大小
    return 0;
}
```
<!-- end-demo -->

## 挑战 2：自己的绝对值函数

<!-- card type:computer -->
🖥️ 不调用 `abs()`，自己定义 `int myAbs(int n)`，返回 n 的绝对值。

**输入样例：** `-8`

**输出样例：** `8`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int myAbs(int n)
{
    if (n >= 0)
        return n;
    else
        return -n;
}

int main()
{
    int n;
    cin >> n;
    cout << myAbs(n) << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 3：函数判断完全平方数

<!-- card type:computer -->
🖥️ 定义函数 `bool isSquare(int n)`，判断 n 是否为完全平方数。

在 `main` 中输入 n，输出 `YES` 或 `NO`。

**输入样例 1：** `16`

**输出样例 1：** `YES`

**输入样例 2：** `15`

**输出样例 2：** `NO`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

bool isSquare(int n)
{
    double x = sqrt(n);      // 先开平方，得到小数
    int sq = round(x);       // 四舍五入成整数
    return sq * sq == n;     // 再平方，看是不是原来的数
}

int main()
{
    int n;
    cin >> n;
    if (isSquare(n))
        cout << "YES" << endl;
    else
        cout << "NO" << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 4：函数模拟掷骰子

<!-- card type:computer -->
🖥️ 定义 `int roll()` 函数，每次返回 1~6 的随机整数。

在 `main` 中调用两次，输出点数和总和。

**输出格式：** `骰子1: X, 骰子2: Y, 合计: Z`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int roll()
{
    return rand() % 6 + 1;
}

int main()
{
    srand(time(0));
    int d1 = roll();
    int d2 = roll();
    cout << "骰子1: " << d1 << ", 骰子2: " << d2 << ", 合计: " << d1 + d2 << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 5：函数求两数平方和

<!-- card type:computer -->
🖥️ 定义函数 `int square(int n)`，返回 n 的平方。

在 `main` 中输入两个整数 a、b，输出 `a*a + b*b`。

**输入样例：** `3 4`

**输出样例：** `25`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int square(int n)
{
    return n * n;
}

int main()
{
    int a, b;
    cin >> a >> b;
    cout << square(a) + square(b) << endl;
    return 0;
}
```
<!-- end-demo -->

## 小贴士

<!-- card type:tip -->
💡 练习课常见坑提醒：
- `max(3, 7.0)` 会报错，参数类型要一致！
- `sqrt()` 的返回值是 `double`，强转前想想是否需要 `round`。
- 函数写在 `main` 后面时，记得在前面加前置声明。
- `void` 函数没有返回值，调用时也不要 `cout << voidFunc()`。
<!-- end-card -->
