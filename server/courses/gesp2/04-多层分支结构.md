## 🛠️ 知识点一：程序设计语言分类

人类和计算机交流要使用**程序设计语言**。根据与计算机的“距离”，可以分为三类。

### 1. 机器语言

- 由 0 和 1 组成，计算机能直接看懂。
- 人类很难阅读和编写。

```
10110000 01100001
```

### 2. 汇编语言

- 用助记符代替 0 和 1，比如 `MOV`、`ADD`。
- 仍然和硬件关系密切，难度较大。

```asm
MOV A, 5
ADD A, 3
```

### 3. 高级语言

- 接近人类语言，容易学习和使用。
- 需要编译或解释才能运行。

```cpp
cout << 5 + 3;
```

### 编译型与解释型

| 类型 | 特点 | 例子 |
|------|------|------|
| 编译型 | 先全部翻译成机器语言，再运行 | C++、C |
| 解释型 | 一行一行翻译运行 | Python、JavaScript |

## 🛠️ 知识点三：if 语句的嵌套

在 `if` 的里面再放一个 `if`，就是**嵌套分支**。

### 例子：判断成绩等级

```cpp
#include <iostream>
using namespace std;

int main() {
    int score;
    cin >> score;

    if (score >= 60) {
        if (score >= 90) {
            cout << "优秀" << endl;
        } else {
            cout << "及格" << endl;
        }
    } else {
        cout << "不及格" << endl;
    }

    return 0;
}
```
<!-- run -->

### 🔍 执行流程

- 先判断 `score >= 60`
- 如果成立，再判断 `score >= 90`
- 如果不成立，直接输出“不及格”

## 🛠️ 知识点四：if...else if...else 多分支

当有多种情况时，可以用 `if...else if...else`。

```cpp
#include <iostream>
using namespace std;

int main() {
    int score;
    cin >> score;

    if (score >= 90) {
        cout << "A" << endl;
    } else if (score >= 80) {
        cout << "B" << endl;
    } else if (score >= 70) {
        cout << "C" << endl;
    } else if (score >= 60) {
        cout << "D" << endl;
    } else {
        cout << "E" << endl;
    }

    return 0;
}
```
<!-- run -->

### 🔍 注意

条件按**从上到下的顺序**判断，一旦某个条件成立，后面的条件就**不再执行**。

## 🛠️ 知识点五：switch 语句

当判断一个变量等于多个固定值时，`switch` 比多层 `if` 更清晰。

```cpp
#include <iostream>
using namespace std;

int main() {
    int day;
    cin >> day;

    switch (day) {
        case 1:
            cout << "星期一" << endl;
            break;
        case 2:
            cout << "星期二" << endl;
            break;
        case 3:
            cout << "星期三" << endl;
            break;
        case 4:
            cout << "星期四" << endl;
            break;
        case 5:
            cout << "星期五" << endl;
            break;
        default:
            cout << "周末" << endl;
    }

    return 0;
}
```
<!-- run -->

### 🔍 重要规则

- `switch` 后面括号里必须是整数或字符表达式。
- 每个 `case` 后面通常要加 `break`，否则会“穿透”到下一个 case。
- `default` 表示以上情况都不匹配时的默认分支。

## 🛠️ 知识点六：switch 的嵌套

`switch` 里面也可以再嵌套 `if` 或另一个 `switch`。

```cpp
#include <iostream>
using namespace std;

int main() {
    int season;
    cin >> season;

    switch (season) {
        case 1:
            cout << "春" << endl;
            break;
        case 2:
            cout << "夏" << endl;
            break;
        case 3:
            cout << "秋" << endl;
            break;
        case 4:
            cout << "冬" << endl;
            break;
        default:
            if (season < 1 || season > 4) {
                cout << "输入错误" << endl;
            }
    }

    return 0;
}
```
<!-- run -->

### 💡 小提示

<!-- hint -->
嵌套太多层会让代码难读。如果分支超过三层，可以考虑用 `if...else if...else` 或拆成多个函数。
<!-- end-hint -->
