# 课程04：数据类型转换

> 🎯 目标：理解 ASCII 编码和强制类型转换，让字符与数字互相变身。

## 故事：密码锁

<!-- story -->
🔐 密室逃脱的密码锁提示：

“A 的后面两位字母是什么？”

A → B → C，答案是 C！

但计算机不认识字母，只认识数字。

在计算机眼中，'A' = 65，'B' = 66，'C' = 67……

所以 `'A' + 2 = 67 = 'C'`！

这就是 ASCII 编码的魔法 ✨
<!-- end-story -->

## ASCII 编码

<!-- card type:teacher -->
🧑‍🏫 ASCII 是字符和数字的翻译表，记住三个关键数字：

- `'0'` = 48
- `'A'` = 65
- `'a'` = 97

大小写字母相差 32。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    char c = 'A';
    cout << (int)c << endl;         // 65
    cout << (char)(c + 1) << endl;  // B
    return 0;
}
```
<!-- end-demo -->

## 强制类型转换

<!-- card type:teacher -->
🧑‍🏫 `(目标类型)表达式` 可以临时改变数据类型。

就像把 5 块糖平均分给 2 个人，整数除法每人只能算 2 块；把其中一个数变成小数，才能得到 2.5 块。

注意：`(double)a / b` 和 `(double)(a / b)` 结果不一样！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    int a = 5, b = 2;
    cout << a / b << endl;         // 2
    cout << (double)a / b << endl; // 2.5
    return 0;
}
```
<!-- end-demo -->

## 隐式类型转换

<!-- card type:teacher -->
🧑‍🏫 混合运算时，C++ 会自动把低精度类型提升为高精度类型。

比如 `int` 和 `double` 一起算，结果会变成 `double`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    int a = 3;
    double b = 1.5;
    cout << a + b << endl;  // 4.5
    return 0;
}
```
<!-- end-demo -->

## 挑战2

<!-- card type:computer -->
🖥️ 输入一个字母，如果是大写就转成小写，如果是小写就转成大写，其他字符不变。

**输入样例：** `A`

**输出样例：** `a`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    char c;
    cin >> c;
    if (c >= 'A' && c <= 'Z')
        cout << (char)(c + 32) << endl;  // 大写转小写
    else if (c >= 'a' && c <= 'z')
        cout << (char)(c - 32) << endl;  // 小写转大写
    else
        cout << c << endl;
    return 0;
}
```
<!-- end-demo -->

## 小贴士

<!-- card type:tip -->
💡 `(double)a / b` 得小数，`(double)(a / b)` 先整除再转，结果可能不对。

💡 字符数字转整数：`数字字符 - '0'`。

💡 字符和整数可以互相转换，运算时 C++ 会先把字符变成整数。
<!-- end-card -->
