# 课程05：多层循环语句

> 🎯 目标：掌握嵌套循环的执行流程、数位处理和枚举思想，能用二重循环解决经典问题

## 故事：机器人

<!-- story -->
扫地机器人是怎么打扫房间的？

它先横向扫完第一行，再往下移一格，继续扫第二行……

外层控制“行”，内层控制“列”，这就是嵌套循环 🤖
<!-- end-story -->

## 回顾

<!-- card type:teacher -->
🧑‍🏫 单层 `for` 循环是“一条路走到头”。

如果需要同时控制行和列，就要 `for` 套 `for`：外层每走 1 步，内层完整跑一遍。
<!-- end-card -->

## 嵌套循环

<!-- card type:teacher -->
🔄 外层循环变一次，内层循环跑一圈。

总次数 = 外层次数 × 内层次数。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int i = 1; i <= 3; i++) {          // 外层：行
        for (int j = 1; j <= 3; j++) {      // 内层：列
            cout << i * j << " ";           // 打印乘积
        }
        cout << endl;                       // 内层结束换行
    }
    return 0;
}
```
<!-- end-demo -->

## 数位处理

<!-- card type:teacher -->
🔢 用 `/` 和 `%` 可以拆出每一位数字：

- 个位：`n % 10`
- 十位：`n / 10 % 10`
- 百位：`n / 100 % 10`
- 千位：`n / 1000 % 10`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 357;
    int bai = n / 100;          // 百位
    int shi = n / 10 % 10;      // 十位
    int ge  = n % 10;           // 个位
    cout << bai << " " << shi << " " << ge << endl;
    return 0;
}
```
<!-- end-demo -->

## 暴力枚举

<!-- card type:teacher -->
🔍 枚举就是把所有可能列出来，再逐一判断。

只要范围不大，就可以用循环“暴力”解决。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int n = 10; n <= 99; n++) {
        int shi = n / 10;       // 十位
        int ge  = n % 10;       // 个位
        if (shi + ge == 10) cout << n << " ";
    }
    return 0;
}
```
<!-- end-demo -->

## 百钱百鸡

<!-- card type:teacher -->
🐔 公鸡 5 元/只，母鸡 3 元/只，小鸡 1 元/3 只。

用 100 元买 100 只鸡，各买多少？

思路：先用二重循环枚举公鸡和母鸡，再用总数推出小鸡数。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    // 公鸡最多 20 只：5 * 20 = 100 元
    for (int c = 0; c <= 20; c++) {
        // 母鸡最多 33 只：3 * 33 = 99 元
        for (int h = 0; h <= 33; h++) {
            int ch = 100 - c - h;           // 小鸡由总数推出
            if (ch % 3 == 0 && 5*c + 3*h + ch/3 == 100)
                cout << c << " " << h << " " << ch << endl;
        }
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战1：输出矩形

<!-- card type:computer -->
🖥️ 输入行数 r 和列数 c，输出由 `*` 组成的矩形。

**输入样例：** `3 5`

**输出样例：**
```
*****
*****
*****
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int r, c; cin >> r >> c;
    for (int i = 1; i <= r; i++) {
        for (int j = 1; j <= c; j++) cout << "*";
        cout << endl;               // 每行结束换行
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**考察知识点：** 双重循环控制行和列。

**思路：** 外层控制行数，内层控制每行星号数。

**易错点：** 内层循环结束后忘记 `cout << endl;`。

**关键代码：** `for (int j = 1; j <= c; j++) cout << "*";` 打印一行 c 个星号。
<!-- end-card -->

## 挑战2：水仙花数

<!-- card type:computer -->
🖥️ 输出所有三位水仙花数。

水仙花数：各位数字的立方和等于该数本身。

**输出样例：** `153 370 371 407`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int n = 100; n <= 999; n++) {
        int a = n / 100;        // 百位
        int b = n / 10 % 10;    // 十位
        int c = n % 10;         // 个位
        if (a*a*a + b*b*b + c*c*c == n) cout << n << " ";
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**考察知识点：** 数位拆分与枚举结合。

**思路：** 枚举所有三位数，拆出百位、十位、个位，验证立方和条件。

**易错点：** 十位拆分错，记住先 `/10` 去掉个位，再 `%10` 取末位。

**关键代码：** `a*a*a + b*b*b + c*c*c == n` 判断立方和是否等于原数。
<!-- end-card -->

## 小贴士

<!-- card type:tip -->
💡 嵌套循环总次数 = 外层次数 × 内层次数，注意效率。

💡 能用数学关系直接算出的变量，就少写一层循环，速度提升很多倍。
<!-- end-card -->
