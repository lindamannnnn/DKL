## 🛠️ 知识点一：嵌套循环

一个循环里面再写一个循环，就叫**嵌套循环**。

### 例子：打印 3 行 4 列的星星

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 3; i++) {      // 外层循环：控制行
        for (int j = 1; j <= 4; j++) {  // 内层循环：控制列
            cout << "* ";
        }
        cout << endl;  // 每行结束换行
    }
    return 0;
}
```
<!-- run -->

**输出：**

```
* * * * 
* * * * 
* * * * 
```

### 🔍 执行过程

1. 外层 `i = 1`，内层 `j` 从 1 到 4 打印 4 个星。
2. 换行，外层 `i = 2`，内层再次从 1 到 4。
3. 重复直到外层结束。

## 🛠️ 知识点二：用循环拆分数字的每一位

一个整数可以通过 `% 10` 取个位，再通过 `/ 10` 去掉个位。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 1234;

    while (n > 0) {
        int digit = n % 10;  // 取出最后一位
        cout << digit << " ";
        n = n / 10;          // 去掉最后一位
    }

    return 0;
}
```
<!-- run -->

**输出：**

```
4 3 2 1
```

### 💡 小口诀

<!-- hint -->
拆数字，两步走：
1. `% 10` 取个位。
2. `/ 10` 去掉个位。
循环做，直到数字变成 0。
<!-- end-hint -->

### 例子：求一个数各位数字之和

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 1234;
    int sum = 0;

    while (n > 0) {
        sum = sum + n % 10;
        n = n / 10;
    }

    cout << sum << endl;  // 输出 10
    return 0;
}
```

## 🛠️ 知识点三：嵌套循环 + 数位处理

嵌套循环和数位处理可以结合起来解决更复杂的问题。

### 例子：找出 100 ~ 999 中各位数字之和等于 15 的数

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int n = 100; n <= 999; n++) {
        int x = n;          // 用临时变量保存 n
        int sum = 0;

        while (x > 0) {
            sum = sum + x % 10;
            x = x / 10;
        }

        if (sum == 15) {
            cout << n << " ";
        }
    }

    return 0;
}
```
<!-- run -->

### 🔍 注意

拆数字时要用临时变量 `x` 代替 `n`，否则循环变量 `n` 会被改变，导致循环出错。

## 🛠️ 知识点四：枚举法

枚举法就是把所有可能的情况一一列举出来，再判断是否符合条件。

### 例子：1 ~ 100 中能被 3 和 5 同时整除的数

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 100; i++) {
        if (i % 3 == 0 && i % 5 == 0) {
            cout << i << " ";
        }
    }
    return 0;
}
```
<!-- run -->

### 🔍 枚举法步骤

1. 确定范围。
2. 逐个检查。
3. 输出符合条件的。

## 🛠️ 知识点五：百钱百鸡问题

### 问题

公鸡 5 元一只，母鸡 3 元一只，小鸡 1 元三只。用 100 元买 100 只鸡，问各买多少只？

### 思路

设公鸡 `x` 只，母鸡 `y` 只，小鸡 `z` 只：

- `x + y + z = 100`
- `5x + 3y + z/3 = 100`
- `z` 必须是 3 的倍数

用两层循环枚举 `x` 和 `y`，`z` 由总数算出。

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int x = 0; x <= 20; x++) {       // 公鸡最多 20 只
        for (int y = 0; y <= 33; y++) {   // 母鸡最多 33 只
            int z = 100 - x - y;          // 小鸡数量

            if (z % 3 == 0 && 5 * x + 3 * y + z / 3 == 100) {
                cout << "公鸡：" << x << " 母鸡：" << y << " 小鸡：" << z << endl;
            }
        }
    }

    return 0;
}
```
<!-- run -->

### 🔍 关键技巧

- 根据价格确定每种鸡的最大数量，减少枚举范围。
- 利用总数关系减少一层循环。

## 🛠️ 知识点六：百钱百鸡变形

### 变形题

有 30 元钱，买苹果（2 元/个）、香蕉（1 元/根）、橘子（0.5 元/个），正好花完 30 元，一共买 30 个水果。问可能买多少？

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int a = 0; a <= 15; a++) {       // 苹果最多 15 个
        for (int b = 0; b <= 30; b++) {   // 香蕉最多 30 根
            int c = 30 - a - b;           // 橘子数量

            // 橘子单价 0.5 元，两边同乘 2 避免小数
            if (4 * a + 2 * b + c == 60) {
                cout << "苹果：" << a << " 香蕉：" << b << " 橘子：" << c << endl;
            }
        }
    }

    return 0;
}
```
<!-- run -->

### 💡 小提示

<!-- hint -->
遇到“多少钱买多少东西”的问题，先找等量关系，再用循环枚举。注意钱数可能是小数时，可以把等式两边同时扩大，变成整数运算更稳妥。
<!-- end-hint -->
