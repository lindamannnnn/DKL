## 🎬 开场故事：小画家的秘密

小明想用 `*` 画一幅画。他发现：

- 画直线时，只要行号等于列号。
- 画斜线时，行号加列号等于一个固定数。

原来，图形打印的秘诀就是**找规律**！

---

## 🛠️ 知识点一：认识坐标

在图形打印中，我们通常用行号 `i` 和列号 `j` 来表示每个字符的位置。

```
      j=1 j=2 j=3 j=4 j=5
i=1    *   .   .   .   .
i=2    .   *   .   .   .
i=3    .   .   *   .   .
i=4    .   .   .   *   .
i=5    .   .   .   .   *
```

### 行号和列号的关系

- 反斜边（左上到右下）：`i == j`
- 正斜边（右上到左下）：`i + j == n + 1`（n 为行数）

---

## 🛠️ 知识点二：反斜边规律

反斜边从左上角延伸到右下角，特点是**行号等于列号**。

### 例子：打印 5 阶反斜边

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (i == j) {
                cout << "*";
            } else {
                cout << " ";
            }
        }
        cout << endl;
    }
    return 0;
}
```
<!-- run -->

**输出：**

```
*    
 *   
  *  
   * 
    *
```

## 🛠️ 知识点三：正斜边规律

正斜边从右上角延伸到左下角，特点是**行号 + 列号 = 固定值**。

### 例子：打印 5 阶正斜边

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (i + j == n + 1) {
                cout << "*";
            } else {
                cout << " ";
            }
        }
        cout << endl;
    }
    return 0;
}
```
<!-- run -->

**输出：**

```
    *
   * 
  *  
 *   
*    
```

### 🔍 为什么是和等于 n + 1？

- 第 1 行第 n 列：`1 + n = n + 1`
- 第 n 行第 1 列：`n + 1 = n + 1`

## 🛠️ 知识点四：图形拆解

复杂图形可以拆成几个简单图形，分别实现后再组合。

### 例子：打印 X 形

X 形由反斜边和正斜边叠加而成。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (i == j || i + j == n + 1) {
                cout << "*";
            } else {
                cout << " ";
            }
        }
        cout << endl;
    }
    return 0;
}
```
<!-- run -->

**输出：**

```
*   *
 * * 
  *  
 * * 
*   *
```

### 🔍 拆解思路

X = 反斜边 + 正斜边

## 🛠️ 知识点五：利用对称性

对称图形可以先画一半，再“镜像”出另一半。

### 例子：打印菱形

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;

    // 上半部分（包括中间行）
    for (int i = 1; i <= n; i++) {
        // 打印空格
        for (int j = 1; j <= n - i; j++) {
            cout << " ";
        }
        // 打印星星
        for (int k = 1; k <= 2 * i - 1; k++) {
            cout << "*";
        }
        cout << endl;
    }

    // 下半部分
    for (int i = n - 1; i >= 1; i--) {
        for (int j = 1; j <= n - i; j++) {
            cout << " ";
        }
        for (int k = 1; k <= 2 * i - 1; k++) {
            cout << "*";
        }
        cout << endl;
    }

    return 0;
}
```
<!-- run -->

**输出：**

```
    *
   ***
  *****
 *******
*********
 *******
  *****
   ***
    *
```

### 🔍 对称性分析

- 第 i 行有 `2*i - 1` 个星。
- 第 i 行前面有 `n - i` 个空格。
- 上下部分关于中间行对称。

## 🛠️ 知识点六：空心图形

空心图形只打印边界，内部留空。

### 例子：空心正方形

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (i == 1 || i == n || j == 1 || j == n) {
                cout << "*";
            } else {
                cout << " ";
            }
        }
        cout << endl;
    }
    return 0;
}
```
<!-- run -->

**输出：**

```
*****
*   *
*   *
*   *
*****
```

### 🔍 规律

- 第一行、最后一行全打印。
- 中间行只在第一列和最后一列打印。
