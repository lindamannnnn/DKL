## 本课练习要点

<!-- card type:teacher -->
🧑‍🏫 这节课重点练习多层分支：

- `if` 里再套 `if`，处理层层条件。
- `else` 总是和最近的未配对 `if` 匹配，不确定就加 `{}`。
- `switch` 里每个 `case` 结束要写 `break`，否则会“穿透”（一直往下执行后面的 case，停不下来）。
- 固定值用 `switch`，范围判断用 `if...else if`。
<!-- end-card -->

## 小知识：整数也能当开关

<!-- card type:teacher -->
🧑‍🏫 在 C++ 里，`if` 后面不一定非要写 `==` 或 `!=`。

对于一个整数：
- 如果它是 `0`，C++ 认为它表示“假”。
- 如果它不是 `0`（比如 `1`、`-1`、`100`），C++ 认为它表示“真”。

所以下面两种写法效果一样：

```cpp
if (card != 0)   // 第一种写法
if (card)        // 第二种写法，更短
```

但第二种写法像谜语，初学者看到容易懵。建议先学会第一种，熟练了再用第二种。

## 挑战 1：身高体重分类

<!-- card type:computer -->
🖥️ 输入身高 h（cm）和体重 w（kg），按规则输出体型：

- h < 150 且 w < 45：小体型
- h ≥ 175 且 w ≥ 70：大体型
- 其他：中体型

**输入样例：** `160 55`

**输出样例：** `中体型`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int h, w;
    cin >> h >> w;
    if (h < 150 && w < 45) cout << "小体型" << endl;
    else if (h >= 175 && w >= 70) cout << "大体型" << endl;
    else cout << "中体型" << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 2：四象限判断

<!-- card type:computer -->
🖥️ 输入点 (x, y)，判断它在哪个象限，或在坐标轴上。

**输入样例：** `3 -2`

**输出样例：** `第四象限`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int x, y;
    cin >> x >> y;
    if (x == 0 || y == 0) cout << "坐标轴" << endl;
    else if (x > 0 && y > 0) cout << "第一象限" << endl;
    else if (x < 0 && y > 0) cout << "第二象限" << endl;
    else if (x < 0 && y < 0) cout << "第三象限" << endl;
    else cout << "第四象限" << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 3：游乐园售票

<!-- card type:computer -->
🖥️ 输入年龄 age 和是否有年卡 card（0=无，1=有），计算票价：

- 年龄 < 6：0 元
- 6~12 岁：40 元
- 13~60 岁：80 元
- 年龄 > 60：30 元
- 有年卡再打 5 折

**输入样例：** `15 1`

**输出样例：** `40`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int age, card;
    cin >> age >> card;
    int price;
    if (age < 6) price = 0;
    else if (age <= 12) price = 40;
    else if (age <= 60) price = 80;
    else price = 30;
    if (card) price /= 2;
    cout << price << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 4：成绩分级（switch 版）

<!-- card type:computer -->
🖥️ 输入一个成绩 score（0~100），用 `switch` 按等级输出：

- 90~100：A
- 80~89：B
- 70~79：C
- 60~69：D
- 0~59：F

**输入样例：** `85`

**输出样例：** `B`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int score;
    cin >> score;
    int g = score / 10;
    switch (g) {
        case 10: case 9: cout << "A" << endl; break;
        case 8: cout << "B" << endl; break;
        case 7: cout << "C" << endl; break;
        case 6: cout << "D" << endl; break;
        default: cout << "F" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 5：三数最大值与等级

<!-- card type:computer -->
🖥️ 输入三个整数，先找出最大值，再按规则输出等级：

- 最大值 ≥ 100：S级
- 50~99：A级
- 0~49：B级
- < 0：C级

**输入样例：** `30 80 60`

**输出样例：** `80 A级`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int a, b, c;
    cin >> a >> b >> c;
    int mx = max(a, max(b, c));
    cout << mx << " ";
    if (mx >= 100) cout << "S级" << endl;
    else if (mx >= 50) cout << "A级" << endl;
    else if (mx >= 0) cout << "B级" << endl;
    else cout << "C级" << endl;
    return 0;
}
```
<!-- end-demo -->

## 小贴士

<!-- card type:tip -->
💡 嵌套 if 时，哪怕只有一条语句，也建议加 `{}`，避免“悬空 else”陷阱（就是 `else` 不知道该跟哪个 `if` 配对，结果配错了）。

💡 `switch` 的 `break` 像刹车，漏掉就会一路滑到下一个 case。

💡 复杂条件拆成多层判断，比写一长串 `&&` 更容易读懂。
