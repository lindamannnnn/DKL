## 🛠️ 知识点一：复杂图形的拆解方法

看到一个复杂图形时，可以按以下步骤思考：

### 拆解四步法

1. **看整体**：图形有几行？是什么形状？
2. **分行看**：每一行有多少个字符？有多少空格？
3. **找规律**：行号 `i` 和字符数量有什么关系？
4. **分块写**：把图形拆成上下、左右或几个简单图形，分别实现。

### 例子：分析一个沙漏形

```
*****
 ***
  *
 ***
*****
```

可以拆成：
- 上半部分：星号递减，空格递增
- 中间一行
- 下半部分：星号递增，空格递减

## 🛠️ 知识点二：复杂图形实现——沙漏

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 3;

    // 上半部分
    for (int i = n; i >= 1; i--) {
        for (int j = 1; j <= n - i; j++) {
            cout << " ";
        }
        for (int k = 1; k <= 2 * i - 1; k++) {
            cout << "*";
        }
        cout << endl;
    }

    // 下半部分
    for (int i = 2; i <= n; i++) {
        for (int j = 1; j <= n - i; j++) {
            cout << " ";
        }
        for (int k = 1; k <= 2 * i - 1; k++) {
            cout << "*";
        }
        cout << endl;
    }

    return 0;
}
```
<!-- run -->

**输出：**

```
*****
 ***
  *
 ***
*****
```

### 🔍 拆解思路

- 上半部分：`i` 从 n 到 1，星号 `2*i-1`。
- 下半部分：`i` 从 2 到 n，避免中间行重复。
- 空格：`n - i`。

## 🛠️ 知识点三：复杂图形实现——空心菱形

空心菱形 = 菱形的外框，内部为空。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;

    // 上半部分
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n - i; j++) {
            cout << " ";
        }
        for (int k = 1; k <= 2 * i - 1; k++) {
            if (k == 1 || k == 2 * i - 1) {
                cout << "*";
            } else {
                cout << " ";
            }
        }
        cout << endl;
    }

    // 下半部分
    for (int i = n - 1; i >= 1; i--) {
        for (int j = 1; j <= n - i; j++) {
            cout << " ";
        }
        for (int k = 1; k <= 2 * i - 1; k++) {
            if (k == 1 || k == 2 * i - 1) {
                cout << "*";
            } else {
                cout << " ";
            }
        }
        cout << endl;
    }

    return 0;
}
```
<!-- run -->

**输出：**

```
    *
   * *
  *   *
 *     *
*       *
 *     *
  *   *
   * *
    *
```

### 🔍 拆解思路

- 先按实心菱形打印。
- 在每一行中，只在第一个和最后一个位置打印 `*`，其余为空格。

## 🛠️ 知识点四：复杂图形实现——数字三角形

```
    1
   121
  12321
 1234321
123454321
```

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;

    for (int i = 1; i <= n; i++) {
        // 空格
        for (int j = 1; j <= n - i; j++) {
            cout << " ";
        }

        // 递增数字
        for (int k = 1; k <= i; k++) {
            cout << k;
        }

        // 递减数字
        for (int k = i - 1; k >= 1; k--) {
            cout << k;
        }

        cout << endl;
    }

    return 0;
}
```
<!-- run -->

### 🔍 拆解思路

每一行可以拆成三部分：
1. 前面的空格
2. 从 1 递增到 i
3. 从 i-1 递减到 1

## 🛠️ 知识点五：复杂图形实现——箭头

```
  *
 ***
*****
  *
  *
  *
  *
```

可以拆成：
- 上面的三角形
- 下面的矩形竖线

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 3;

    // 箭头头部（三角形）
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n - i; j++) {
            cout << " ";
        }
        for (int k = 1; k <= 2 * i - 1; k++) {
            cout << "*";
        }
        cout << endl;
    }

    // 箭杆
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n - 1; j++) {
            cout << " ";
        }
        cout << "*" << endl;
    }

    return 0;
}
```
<!-- run -->

### 🔍 拆解思路

- 头部：等腰三角形。
- 箭杆：n 行，每行中间一个星。

## 🛠️ 知识点六：综合技巧

### 技巧 1：先画草图

在纸上画出图形，标上行号和列号，再找规律。

### 技巧 2：用变量代替固定值

把行数、列数用变量 `n` 表示，方便修改图形大小。

### 技巧 3：模块化

复杂图形拆成函数，每个函数负责一部分。

```cpp
#include <iostream>
using namespace std;

void printSpaces(int n) {
    for (int i = 1; i <= n; i++) {
        cout << " ";
    }
}

int main() {
    printSpaces(5);
    cout << "*" << endl;
    return 0;
}
```
