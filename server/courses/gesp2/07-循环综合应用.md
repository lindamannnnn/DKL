## 循环找规律

<!-- card type:teacher -->
🔍 很多问题表面上复杂，其实有规律藏在数字里。

用循环把数字列出来，再用 `if` 判断筛选，就能找到答案。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int n = 10; n <= 99; n++) {
        int shi = n / 10;       // 十位
        int ge  = n % 10;       // 个位
        if (shi * ge >= shi + ge) cout << n << " ";
    }
    return 0;
}
```
<!-- end-demo -->

## 完全数

<!-- card type:teacher -->
✨ **完全数**：一个数等于它所有**真因子**之和。

真因子就是能整除它、但比它小的所有数。

比如 6：
- 1 能整除 6（6 ÷ 1 = 6）
- 2 能整除 6（6 ÷ 2 = 3）
- 3 能整除 6（6 ÷ 3 = 2）
- 6 也能整除 6，但真因子不包括它自己

所以 6 的真因子是 1、2、3，加起来 1+2+3=6，等于它自己，所以 6 是完全数。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int n = 2; n <= 1000; n++) {
        int sum = 0;
        for (int i = 1; i < n; i++)
            if (n % i == 0) sum += i;   // i 是因子
        if (sum == n) cout << n << " ";
    }
    return 0;
}
```
<!-- end-demo -->

## 回文数

<!-- card type:teacher -->
🔁 **回文数**正读反读相同，如 121、1331。

判断方法：把数字“倒过来”拼成一个新数，看是否和原数相等。

以 1234 为例：

| 步骤 | x 的个位 | rev 的变化 | x 去掉个位 |
|------|----------|------------|------------|
| 初始 | 1234     | 0          | —          |
| 第 1 次 | 4        | 0×10+4 = 4 | 123        |
| 第 2 次 | 3        | 4×10+3 = 43 | 12         |
| 第 3 次 | 2        | 43×10+2 = 432 | 1          |
| 第 4 次 | 1        | 432×10+1 = 4321 | 0          |

最后 `rev = 4321`，和原来的 1234 不一样，所以 1234 不是回文数。

如果是 1221，最后 `rev = 1221`，和自己相等，就是回文数。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int n = 10; n <= 9999; n++) {
        int x = n, rev = 0;
        while (x > 0) {
            rev = rev * 10 + x % 10;    // 倒序累加
            x = x / 10;
        }
        if (rev == n) cout << n << " ";
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战1：完全数

<!-- card type:computer -->
🖥️ 输出 1 到 1000 内的所有完全数。

完全数：等于它所有真因子之和。

**输出样例：** `6 28 496`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int n = 2; n <= 1000; n++) {
        int sum = 0;
        for (int i = 1; i < n; i++)
            if (n % i == 0) sum += i;   // 累加因子
        if (sum == n) cout << n << " ";
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**考察知识点：** 循环枚举与因子判断。

**思路：** 对每个数 n，枚举 1 到 n-1 中所有因子并求和，再和 n 比较。

**易错点：** 内层循环要用不同的变量名，不要和外层 `n` 搞混。

**关键代码：** `if (n % i == 0) sum += i;` 把因子 i 加入总和。
<!-- end-card -->

## 挑战2：鸡兔同笼

<!-- card type:computer -->
🖥️ 输入鸡兔总头数 h 和总腿数 f，输出鸡和兔各有多少只。

若有多组解，输出每组；若无解，不输出。

**输入样例：** `3 8`

**输出样例：** `2 1`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int h, f; cin >> h >> f;        // 头数和腿数
    for (int j = 0; j <= h; j++) {  // 枚举鸡的数量
        int t = h - j;              // 兔的数量
        if (2 * j + 4 * t == f)
            cout << j << " " << t << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**考察知识点：** 枚举法解决实际问题。

**思路：** 枚举鸡的数量，兔的数量用总数减；验证腿数是否匹配。

**易错点：** 兔的腿数是 4，鸡的腿数是 2，不要写反。

**关键代码：** `if (2 * j + 4 * t == f)` 验证腿数总和。
<!-- end-card -->
