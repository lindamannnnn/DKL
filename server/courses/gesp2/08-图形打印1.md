## 回顾

<!-- card type:teacher -->
🧑‍🏫 打印图形靠两层循环：

外层控制行（i），内层控制列（j），一行画完记得换行！
<!-- end-card -->

## 反斜边

<!-- card type:teacher -->
↘️ 反斜边从左上到右下，行号等于列号时就在这条线上。

记住口诀：**i 等于 j，反斜边！**
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++)
            cout << (i == j ? '*' : ' ');
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 正斜边

<!-- card type:teacher -->
↗️ 正斜边从左下到右上，行号加列号等于同一个常数。

对于 n×n 方阵，常数是 `n + 1`。

以 n=5 为例，看看哪些位置满足 `i + j == 6`：

```
     j=1  j=2  j=3  j=4  j=5
i=1    2    3    4    5    6  ← 只有 (1,5) 等于 6
i=2    3    4    5    6    7  ← 只有 (2,4) 等于 6
i=3    4    5    6    7    8  ← 只有 (3,3) 等于 6
i=4    5    6    7    8    9  ← 只有 (4,2) 等于 6
i=5    6    7    8    9   10  ← 只有 (5,1) 等于 6
```

把这些位置连起来，就是一条从左下到右上的斜线！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++)
            cout << (i + j == n + 1 ? '*' : ' ');
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 拆解法

<!-- card type:teacher -->
🔨 复杂图形拆成两部分：先画前面的空格，再画后面的星号。

每行 = 空格 + 星号！
<!-- end-card -->

<!-- demo -->
```
n=4 的等腰三角形：
   *      第1行：3 空格，1 星
  ***     第2行：2 空格，3 星
 *****    第3行：1 空格，5 星
*******   第4行：0 空格，7 星

规律：空格数 = n - i，星号数 = 2 * i - 1
```
<!-- end-demo -->

## 等腰三角形

<!-- card type:teacher -->
📐 等腰三角形是对称图形，第 i 行：

空格 `n - i` 个，星号 `2 * i - 1` 个。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n - i; j++) cout << " ";     // 空格
        for (int j = 1; j <= 2 * i - 1; j++) cout << "*"; // 星号
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 边框矩形

<!-- card type:teacher -->
🖼️ 边框矩形只在最外圈画星号，内部是空格。

判断条件：第一行、最后一行、第一列、最后一列。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, m; cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++)
            cout << (i==1||i==n||j==1||j==m ? '*' : ' ');
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战1：等腰三角形

<!-- card type:computer -->
🖥️ 输入 n，打印 n 行居中等腰三角形。

**输入样例：** `4`

**输出样例：**
```
   *
  ***
 *****
*******
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n - i; j++) cout << " ";     // 前导空格
        for (int j = 1; j <= 2 * i - 1; j++) cout << "*"; // 星号
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**考察知识点：** 双重循环 + 图形拆解：每行分成“空格”和“星号”两部分。

**思路：** 第 i 行先打印 `n-i` 个空格，再打印 `2*i-1` 个星号。

**易错点：** 内层循环结束忘记 `cout << endl;`，导致所有行粘成一行。

**关键代码：** `for (int j = 1; j <= n - i; j++) cout << " ";` 打印前面的空格，让星号居中。
<!-- end-card -->

## 挑战2：矩形边框

<!-- card type:computer -->
🖥️ 输入 n 行 m 列，打印只有边框的矩形（内部为空格）。

**输入样例：** `4 6`

**输出样例：**
```
******
*    *
*    *
******
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, m; cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++)
            cout << (i==1||i==n||j==1||j==m ? '*' : ' ');
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**考察知识点：** 条件判断打印边框。

**思路：** 只要位置在第一行、最后一行、第一列或最后一列，就输出 `*`。

**易错点：** 判断条件漏写 `||`，只判断了部分边框。

**关键代码：** `i==1 || i==n || j==1 || j==m` 判断是否为边框。
<!-- end-card -->
