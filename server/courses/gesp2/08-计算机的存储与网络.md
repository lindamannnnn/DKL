## 🎬 开场故事：电脑的“记忆”和“邮局”

电脑就像一个勤劳的小助手：

- 它的“记忆”分好几种：有的记忆永远不忘（ROM），有的记忆一关机就忘（RAM），还有的记忆反应特别快（CACHE）。
- 电脑之间“聊天”靠网络，网络就像一个大大的邮局系统，负责把信息准确送到目的地。

今天我们就来了解电脑的“记忆”和“邮局”！

## 🛠️ 知识点一：计算机的存储

### ROM（只读存储器）

- **Read Only Memory**
- 断电后数据不会丢失。
- 出厂时写入，用户一般不能修改。
- 存储电脑的启动程序，如 BIOS。

### RAM（随机存取存储器）

- **Random Access Memory**
- 断电后数据会丢失。
- 就是平时说的“内存”。
- 电脑运行时，程序和数据都放在这里。

### CACHE（高速缓存）

- 速度非常快，但容量很小。
- 位于 CPU 和内存之间。
- 存放 CPU 最常用的小部分数据，让计算更快。

### 三者的比较

| 存储器 | 速度 | 容量 | 断电后数据 |
|--------|------|------|------------|
| CACHE | 最快 | 最小 | 丢失 |
| RAM | 快 | 中等 | 丢失 |
| ROM | 较慢 | 小 | 不丢失 |

### 生活比喻

| 存储器 | 比喻 |
|--------|------|
| CACHE | 桌面上的常用文具 |
| RAM | 书桌抽屉 |
| ROM | 家里的房产证 |
| 硬盘 | 书柜和仓库 |

## 🛠️ 知识点二：计算机网络分类

### 按覆盖范围分类

| 类型 | 英文简称 | 覆盖范围 | 例子 |
|------|----------|----------|------|
| 局域网 | LAN | 一栋楼或一个房间 | 教室里的 Wi-Fi |

| 结构 | 特点 | 例子 |
|------|------|------|
| 总线型 | 所有设备连在一条线上 | 老式局域网 |
| 星型 | 所有设备连到一个中心设备 | 家庭路由器 |
| 环型 | 设备连成一圈 | 令牌环网 |
| 网状型 | 设备之间有多条连接 | 互联网骨干网 |

## 🛠️ 知识点三：TCP/IP 四层模型

TCP/IP 模型是互联网使用的主要模型，分为四层。

| 层级 | 名称 | 主要功能 | 例子 |
|------|------|----------|------|
| 第 4 层 | 应用层 | 为用户提供各种网络服务 | HTTP、FTP、DNS |
| 第 3 层 | 传输层 | 负责数据的可靠传输 | TCP、UDP |
| 第 2 层 | 网络层 | 负责数据的路由和寻址 | IP、路由器 |
| 第 1 层 | 网络接口层 | 负责物理传输 | 网线、Wi-Fi |

### 发送一封信的比喻

| 层级 | 作用 |
|------|------|
| 应用层 | 你写好信的内容 |
| 传输层 | 把信装进信封，确认能送到 |
| 网络层 | 在信封上写地址，选择路线 |
| 网络接口层 | 信通过邮车或飞机运走 |

## 🛠️ 知识点四：OSI 七层模型

OSI 模型是一个更详细的网络参考模型，分为七层。

| 层级 | 名称 | 主要功能 |
|------|------|----------|
| 第 7 层 | 应用层 | 用户直接使用，如浏览器、邮件 |
| 第 6 层 | 表示层 | 数据格式转换、加密 |
| 第 5 层 | 会话层 | 建立、管理、终止会话 |
| 第 4 层 | 传输层 | 可靠传输、错误恢复 |
| 第 3 层 | 网络层 | 寻址和路由 |
| 第 2 层 | 数据链路层 | 相邻设备间的数据传输 |
| 第 1 层 | 物理层 | 比特流的物理传输 |

### TCP/IP 与 OSI 的对应关系

```
OSI 七层                    TCP/IP 四层
─────────────────────────────────────────────
应用层
表示层  ──────────────────  应用层
会话层
─────────────────────────────────────────────
传输层  ──────────────────  传输层
─────────────────────────────────────────────
网络层  ──────────────────  网络层
─────────────────────────────────────────────
数据链路层 ───────────────  网络接口层
物理层
```

## 🛠️ 知识点五：IP 地址

IP 地址是网络中设备的“门牌号”。

### IPv4 地址

- 由 32 位二进制组成，通常写成 4 个十进制数，用点分隔。
- 每个数范围是 0 ~ 255。
- 例子：`192.168.1.1`

### 网络位和主机位

IP 地址可以分为两部分：

- **网络位**：标识设备所在的网络。
- **主机位**：标识网络中的具体设备。

### 子网掩码

子网掩码用来区分网络位和主机位。

| 子网掩码 | 含义 |
|----------|------|
| 255.255.255.0 | 前 24 位是网络位，后 8 位是主机位 |
| 255.255.0.0 | 前 16 位是网络位，后 16 位是主机位 |

### 例子

IP 地址：`192.168.1.10`
子网掩码：`255.255.255.0`

- 网络地址：`192.168.1.0`
- 主机地址：`10`

## 🛠️ 知识点六：子网划分初步

### 为什么划分子网？

一个大的网络可以分成多个小网络，方便管理，也更安全。

### 简单例子

学校有一个大网络 `192.168.0.0`，可以分成：

| 子网 | 范围 |
|------|------|
| 教学楼 | `192.168.1.x` |
| 办公楼 | `192.168.2.x` |
| 图书馆 | `192.168.3.x` |

其中 `x` 表示该子网中的具体设备。

### 💡 小提示

<!-- hint -->
子网划分是网络工程师的工作。作为初学者，我们只要理解“大网络可以分成小网络”这个概念即可。
<!-- end-hint -->
