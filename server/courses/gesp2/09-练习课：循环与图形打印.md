## 本课练习要点

<!-- card type:teacher -->
🧑‍🏫 这节课我们不学新语法，重点复习：
- 嵌套循环：外层控制行，内层控制列
- 数位处理：`n % 10` 取个位，`n / 10 % 10` 取十位
- 图形拆解：每行 = 空格 + 字符
- 对称图形与对角线规律：`i==j`、`i+j==n+1`

练习时要注意：
1. 审题：看清输入、输出、保留小数
2. 内层循环结束记得换行 `cout << endl`
3. 图形题先在草稿纸上标出 (i, j) 再写代码
4. 枚举时注意循环上界，避免超时
<!-- end-card -->

## 挑战 1：右三角形

<!-- card type:computer -->
🖥️ 输入 n，输出 n 行右三角形，第 i 行有 i 个 `*`。

**输入样例：** `4`
**输出样例：**
```
*
**
***
****
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {      // 外层控制行
        for (int j = 1; j <= i; j++)    // 内层控制星号
            cout << "*";
        cout << endl;                   // 每行结束换行
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 2：等腰三角形

<!-- card type:computer -->
🖥️ 输入 n，输出 n 行居中等腰三角形。

第 i 行：`n-i` 个空格 + `2*i-1` 个 `*`。

**输入样例：** `4`
**输出样例：**
```
   *
  ***
 *****
*******
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n - i; j++) cout << " ";   // 前导空格
        for (int j = 1; j <= 2 * i - 1; j++) cout << "*"; // 星号
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 3：矩形边框

<!-- card type:computer -->
🖥️ 输入 n 行 m 列，打印只有边框的矩形（内部为空格）。

**输入样例：** `4 6`
**输出样例：**
```
******
*    *
*    *
******
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

bool isBorder(int i, int j, int n, int m)
{   // 判断是否为边框
    return i == 1 || i == n || j == 1 || j == m;
}

int main()
{
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++)
            cout << (isBorder(i, j, n, m) ? '*' : ' ');
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 4：各位数字之和

<!-- card type:computer -->
🖥️ 输入一个正整数 n（不超过 9999），输出它各位数字之和。

**输入样例：** `1234`

**输出样例：** `10`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int n;
    cin >> n;
    int sum = 0;
    while (n > 0) {       // 反复取末位
        sum += n % 10;    // 累加个位
        n /= 10;          // 去掉个位
    }
    cout << sum << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战 5：水仙花数

<!-- card type:computer -->
🖥️ 输出所有三位水仙花数（各位数字的立方和等于该数本身）。

**输出样例：** `153 370 371 407`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    for (int n = 100; n <= 999; n++) {     // 枚举三位数
        int a = n / 100;        // 百位
        int b = n / 10 % 10;    // 十位
        int c = n % 10;         // 个位
        if (a*a*a + b*b*b + c*c*c == n)
            cout << n << " ";
    }
    cout << endl;
    return 0;
}
```
<!-- end-demo -->

## 小贴士

<!-- card type:tip -->
💡 练习课常见坑提醒：
- 图形题最容易漏 `cout << endl`，结果所有行粘在一起。
- 取十位：`n / 10 % 10`，先去掉个位，再取最后一位。
- 空格数要算准，建议在草稿纸上先画一画。
- 双重循环总次数 = 外层次数 × 内层次数，范围太大程序会变慢。
