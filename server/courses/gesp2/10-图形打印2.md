# 课程10：图形打印2

> 🎯 目标：学会拆解复杂图形，用分段和组合方法打印梯形、空心图形和沙漏等图案

## 故事：拼积木

<!-- story -->
🏗️ 建筑师设计摩天大楼，不会从顶层画到一层。

他会把楼分成：地基层、标准层、顶层，分别设计，再拼装起来！

复杂图形也是一样：先分成几块，每块找规律，再把代码拼起来！
<!-- end-story -->

## 回顾

<!-- card type:teacher -->
🧑‍🏫 上节课我们学了等腰三角形和边框矩形。

等腰三角形第 i 行：空格 `n-i` 个，星号 `2*i-1` 个。

菱形 = 上半正三角 + 下半倒三角。
<!-- end-card -->

## 图形三步法

<!-- card type:teacher -->
🎯 遇到复杂图形不要慌：

1. 画样例：手画 n=4 或 n=5
2. 标数据：每行标空格数、字符数
3. 找规律：写出和行号 i 的关系式
<!-- end-card -->

<!-- demo -->
```
// n=4 的等腰梯形
   ****    第1行：3 空格，4 星
  ******   第2行：2 空格，6 星
 ********  第3行：1 空格，8 星
********** 第4行：0 空格，10 星

规律：空格 = n - i，星号 = 2 * i + 2
```
<!-- end-demo -->

## 梯形

<!-- card type:teacher -->
📐 等腰梯形每行星号比上一行多 2，空格比上一行少 1。

第 i 行：空格 `n - i` 个，星号 `2 * i + 2` 个。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 4;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n - i; j++) cout << " ";     // 空格
        for (int j = 1; j <= 2 * i + 2; j++) cout << "*"; // 星号
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 空心菱形

<!-- card type:teacher -->
💎 空心菱形只有边缘有星号：

- 第 1 行/最后行：1 个星号
- 中间行：2 个星号，中间是空格

我们用**正数循环**，每一行只记两个位置：左边 `*` 在第几列，右边 `*` 在第几列。

以 n=3 为例，一共打印 `2*n-1 = 5` 行：

```
     列 1 2 3 4 5
行 1   . . + . .    左=3, 右=3
行 2   . + . + .    左=2, 右=4
行 3   + . . . +    左=1, 右=5
行 4   . + . + .    左=2, 右=4
行 5   . . + . .    左=3, 右=3
```

规律：
- 上半（i ≤ n）：左 = n-i+1，右 = n+i-1
- 下半（i > n）：左 = i-n+1，右 = 3n-i-1
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= 2*n-1; i++) {
        int left, right;
        if (i <= n) {
            left = n - i + 1;   // 上半：左星位置
            right = n + i - 1;  // 上半：右星位置
        } else {
            int k = i - n;      // 下半离中间有几行
            left = k + 1;       // 下半：左星位置
            right = 2*n - k - 1;// 下半：右星位置
        }
        for (int j = 1; j <= 2*n-1; j++) {
            if (j == left || j == right) cout << "*";
            else cout << " ";
        }
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 双三角形

<!-- card type:teacher -->
⏳ 沙漏 = 上倒三角 + 下正三角。

分段处理，注意中间行不要重复打印。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    // 上半：倒三角
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j < i; j++) cout << " ";
        for (int j = 1; j <= 2*(n-i)+1; j++) cout << "*";
        cout << endl;
    }
    // 下半：正三角，从 n-1 开始避免重复
    for (int i = n-1; i >= 1; i--) {
        for (int j = 1; j < i; j++) cout << " ";
        for (int j = 1; j <= 2*(n-i)+1; j++) cout << "*";
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战1：空心等腰三角形

<!-- card type:computer -->
🖥️ 输入 n，打印空心等腰三角形。

只有边框是 `*`，内部是空格。

**输入样例：** `5`

**输出样例：**
```
    *
   * *
  *   *
 *     *
*********
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n-i; j++) cout << " ";     // 前导空格
        if (i == 1) cout << "*";                         // 顶点
        else if (i == n) {
            for (int j = 1; j <= 2*n-1; j++) cout << "*"; // 底边
        } else {
            cout << "*";
            for (int j = 1; j <= 2*i-3; j++) cout << " "; // 内部空格
            cout << "*";
        }
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**考察知识点：** 复杂图形分段输出。

**思路：** 顶点行、底边行、中间行分别处理。

**易错点：** 中间行内部空格数算错，导致左右边框对不齐。

**关键代码：** `for (int j = 1; j <= 2*i-3; j++) cout << " ";` 是中间行两个星号之间的空格。
<!-- end-card -->

## 挑战2：Z 字形

<!-- card type:computer -->
🖥️ 输入 n，打印 Z 字形。

第 1 行和最后行是完整 n 个 `*`，中间行只在副对角线上输出 `*`。

**输入样例：** `4`

**输出样例：**
```
****
  * 
 *  
****
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++)
            cout << (i==1 || i==n || i+j==n+1 ? '*' : ' ');
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**考察知识点：** 组合条件判断打印图形。

**思路：** 第一行、最后一行全打印；中间行只在 `i+j==n+1` 时打印。

**易错点：** 中间行的条件写成 `i==j`（主对角线），图案会变成 N。

**关键代码：** `cout << (i==1 || i==n || i+j==n+1 ? '*' : ' ');` 三个条件满足任意一个就输出 `*`。
<!-- end-card -->
