# 课程11：计算机的存储与网络

> 🎯 目标：理解计算机存储层次、网络分类和基本网络模型，能判断常见存储与网络概念

## 故事：图书馆

<!-- story -->
📚 想象一个图书馆系统：

你手边的书桌 = **高速缓存（Cache）**：最快，但放的书最少。

图书馆的书架 = **内存（RAM）**：速度中等，开馆时可用，闭馆清空。

图书馆仓库 = **硬盘**：容量最大，找书最慢，永久保存。

这就是计算机的存储三层结构！
<!-- end-story -->

## 回顾

<!-- card type:teacher -->
🧑‍🏫 计算机运行程序需要中央处理器、内存和硬盘配合。

中央处理器负责计算，内存临时存放数据，硬盘永久保存文件。

网络让计算机之间可以互相通信。
<!-- end-card -->

## 存储层次

<!-- card type:teacher -->
💾 计算机存储从快到慢、从小到大：

- 高速缓存（Cache）：速度最快，容量最小，中央处理器专用
- 内存（RAM）：可读写，断电后数据丢失
- 只读存储器（ROM）：断电后数据保留，出厂时写入
- 硬盘/固态硬盘：容量最大，永久保存
<!-- end-card -->

<!-- demo -->
```
速度：  高速缓存 > 内存 > 只读存储器 > 硬盘
容量：  硬盘 > 内存 > 只读存储器 > 高速缓存
断电：  只读存储器和硬盘保留数据，内存和高速缓存丢失数据

记忆比喻：
只读存储器 = 刻在石头上的字（只读、永久）
内存 = 白板上的字（可擦写、关机清除）
```
<!-- end-demo -->

## 网络分类

<!-- card type:teacher -->
🌐 按覆盖范围，网络分为三种：

- 局域网（LAN）：局部区域，如家庭 WiFi、校园网
- 城域网（MAN）：一个城市范围，如城市有线电视网络
- 广域网（WAN）：跨城市、跨国家，如互联网（Internet）
<!-- end-card -->

<!-- demo -->
```
局域网：像班级里的小圈子，范围小、速度快
城域网：像整个城市的公交系统，覆盖一座城市
广域网：像连接全世界的航线，范围最大

英文缩写：
LAN = Local Area Network（局部网络）
MAN = Metropolitan Area Network（城市网络）
WAN = Wide Area Network（广域网络）
```
<!-- end-demo -->

## TCP/IP 四层

<!-- card type:teacher -->
📡 网络通信常用“TCP/IP 模型”，从上到下分四层：

- 应用层：直接为用户提供服务，如浏览网页、收发邮件
- 传输层：负责端到端通信，如可靠传输、快速传输
- 网络层：负责寻址和路由，让数据找到目的地
- 网络接口层：负责物理传输，如网线、WiFi
<!-- end-card -->

<!-- demo -->
```
写信比喻：
应用层 = 你写的信的内容
传输层 = 选择挂号信（可靠）还是普通信（快速）
网络层 = 写上收件人地址和邮编
网络接口层 = 信纸变成电波或卡车运走

常见协议：
应用层：HTTP/HTTPS（网页）、FTP（文件传输）
传输层：TCP（可靠）、UDP（快速）
网络层：IP（地址寻址）
网络接口层：以太网、WiFi
```
<!-- end-demo -->

## OSI 七层

<!-- card type:teacher -->
🥞 OSI 模型把网络通信细分为七层，从底到顶口诀是：

**物数网传会表应**

（物理层、数据链路层、网络层、传输层、会话层、表示层、应用层）

不过对我们来说，只要记住口诀和“它把网络通信分得很细”就够了。重点是 TCP/IP 四层，那是实际用得更多的模型。
<!-- end-card -->

<!-- demo -->
```
OSI 七层速记表：

7 应用层     ← 使用各种网络服务（如浏览器、邮件）
6 表示层     ← 加密、格式转换
5 会话层     ← 管理一次连接
4 传输层     ← 端到端传输
3 网络层     ← 地址寻址、路由选择
2 数据链路层 ← 局域网内寻址
1 物理层     ← 网线、光纤、无线电波

口诀：物数网传会表应
```
<!-- end-demo -->

## IP 地址

<!-- card type:teacher -->
🌐 IP 地址就像计算机的门牌号，用点分十进制表示，如 `192.168.1.1`。

常见分类：
- A 类：1 ~ 126
- B 类：128 ~ 191
- C 类：192 ~ 223

`127.0.0.1` 是本机回环地址，用来测试自己。

**生活类比**：
- 家庭路由器给的 `192.168.x.x` 就像小区里的门牌号，只在小区里有效（私有地址）。
- 公网 IP 就像全国统一的地址，能在整个互联网上找到你。
- `127.0.0.1` 就像对着镜子喊自己，不用出门就能测试。
<!-- end-card -->

<!-- demo -->
```
192.168.1.1 → C 类地址，常用于家庭路由器（小区门牌号，私有）
10.0.0.1    → A 类地址（大公司内部用，私有）
8.8.8.8     → A 类地址（公网，谷歌的 DNS）
127.0.0.1   → 本机回环地址（代表自己）

记忆：看第一个数字判断类别
```
<!-- end-demo -->

## 挑战1：存储分类判断

<!-- card type:computer -->
🖥️ 判断下列项目属于哪种存储：

1. 手机只读存储器（ROM/闪存）
2. 电脑运行时的 8GB 内存
3. 中央处理器内部的 L1 高速缓存
4. 1TB 移动硬盘
<!-- end-card -->

<!-- demo -->
```
1. 只读存储器（ROM）：只读，断电保留
2. 内存（RAM）：可读写，断电丢失
3. 高速缓存（Cache）：速度最快，中央处理器专用
4. 辅助存储器/硬盘：容量大，永久保存
```
<!-- end-demo -->

<!-- card type:teacher -->
**考察知识点：** 存储层次结构和各类存储的特点。

**思路：** 从速度、容量、断电是否保留三个角度判断。

**易错点：** 把只读存储器和内存搞混，只读存储器断电保留，内存断电丢失。

**关键概念：** 内存（RAM）是程序运行时的临时空间；只读存储器（ROM）存储固件和系统。
<!-- end-card -->

## 挑战2：IP 地址分析

<!-- card type:computer -->
🖥️ 分析以下 IP 地址：

1. `192.168.0.1`：类别？公网还是私网？
2. `8.8.8.8`：类别？
3. `127.0.0.1`：特殊含义？
<!-- end-card -->

<!-- demo -->
```
1. C 类地址，私网（192.168.x.x 是私有地址段）
2. A 类地址（8 在 1~126 范围内），公网
3. 回环地址，代表本机自身
```
<!-- end-demo -->

<!-- card type:teacher -->
**考察知识点：** IP 地址分类和特殊地址。

**思路：** 看第一个数字判断 A/B/C 类，记住常见私有地址段。

**易错点：** 看到 192 开头就认为是私网，其实还要看第二段是否是 168。

**关键概念：** A 类 1~126，B 类 128~191，C 类 192~223。127.0.0.1 是本机回环地址。
<!-- end-card -->
