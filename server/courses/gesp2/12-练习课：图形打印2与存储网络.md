## 挑战 1：向右的直角三角形

<!-- card type:computer -->
🖥️ 输入 n，打印向右靠齐的直角三角形（第 i 行有 i 个 `*`，右对齐）。

**输入样例：** `4`
**输出样例：**
```
   *
  **
 ***
****
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n - i; j++) cout << " ";  // 前导空格
        for (int j = 1; j <= i; j++) cout << "*";      // 星号
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 2：空心等腰三角形

<!-- card type:computer -->
🖥️ 输入 n，打印空心等腰三角形。边框用 `*`，内部为空格。

> 💪 这题和 L10 学过的一样！先**不看下面的代码**，自己写一遍，再来对答案。

**输入样例：** `5`
**输出样例：**
```
    *
   * *
  *   *
 *     *
*********
```
<!-- end-card -->

<!-- card type:teacher -->
🧑‍🏫 先不看下面的代码，自己用普通循环写一遍，再来对答案。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n - i; j++) cout << " ";   // 前导空格
        if (i == 1) {
            for (int j = 1; j <= 1; j++) cout << "*";    // 顶点
        } else if (i == n) {
            for (int j = 1; j <= 2*n-1; j++) cout << "*"; // 底边
        } else {
            cout << "*";                                   // 左边框
            for (int j = 1; j <= 2*i-3; j++) cout << " ";  // 内部空格
            cout << "*";                                   // 右边框
        }
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

void spaces(int k)
{   // 打印 k 个空格
    for (int j = 1; j <= k; j++) cout << " ";
}

void stars(int k)
{   // 打印 k 个星号
    for (int j = 1; j <= k; j++) cout << "*";
}

int main()
{
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        spaces(n - i);
        if (i == 1) stars(1);
        else if (i == n) stars(2*n-1);
        else { stars(1); spaces(2*i-3); stars(1); }
        cout << endl;
    }
    return 0;
}
```

## 挑战 3：Z 字形图案

<!-- card type:computer -->
🖥️ 输入 n，打印 Z 字形（第1行和最后一行是完整的 n 个 `*`，中间行只有副对角线上的 `*`）。

> 💪 这题和 L10 学过的一样！先**不看下面的代码**，自己写一遍，再来对答案。

**输入样例：** `4`
**输出样例：**
```
****
  * 
 *  
****
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

bool onZ(int i, int j, int n)
{   // 判断 (i,j) 是否在 Z 字形上
    return i == 1 || i == n || i + j == n + 1;
}

int main()
{
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++)
            cout << (onZ(i, j, n) ? '*' : ' ');
        cout << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 4：存储器分类器

<!-- card type:computer -->
🖥️ 输入一个数字，判断它属于哪种存储器：
- 1：Cache
- 2：RAM
- 3：ROM
- 4：硬盘

输出该存储器的特点（速度/断电保留）。

**输入样例：** `2`

**输出样例：** `RAM：速度快，断电丢失`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int x;
    cin >> x;
    switch (x) {
        case 1: cout << "Cache：速度最快，断电丢失" << endl; break;
        case 2: cout << "RAM：速度快，断电丢失" << endl; break;
        case 3: cout << "ROM：只读，断电保留" << endl; break;
        case 4: cout << "硬盘：容量大，断电保留" << endl; break;
        default: cout << "未知" << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 5：网络类型分类器

<!-- card type:computer -->
🖥️ 输入一个场景编号，输出对应的网络类型：
- 1：家里 WiFi
- 2：城市地铁 WiFi
- 3：跨国公司总部的全球网络
- 4：学校机房

**输入样例：** `3`

**输出样例：** `WAN`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int x;
    cin >> x;
    switch (x) {
        case 1: cout << "LAN" << endl; break;
        case 2: cout << "MAN" << endl; break;
        case 3: cout << "WAN" << endl; break;
        case 4: cout << "LAN" << endl; break;
        default: cout << "未知" << endl;
    }
    return 0;
}
```

## 小贴士

<!-- card type:tip -->
💡 练习课常见坑提醒：
- 复杂图形先画样例，把每行的空格数和字符数标清楚。
- 空心图形只在边界输出 `*`，内部输出空格。
- RAM 和 ROM 最大的区别：断电后 RAM 丢数据，ROM 保留。
- TCP/IP 四层口诀：**应传网接**（应用、传输、网络、接口）。
- 网络分类口诀：LAN 局域、MAN 城域、WAN 广域。
- IP 地址分类：A类 1~126，B类 128~191，C类 192~223，127 是回环地址。
