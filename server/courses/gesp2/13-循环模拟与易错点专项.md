## 画表格三步法

<!-- card type:teacher -->
🎯 遇到"读代码写结果"，三步走：

1. 画表头：写出每个变量的名字
2. 逐行填：每跑一圈，填一次变量的值
3. 看结果：最后读要输出的值

口诀：**一变就记一行，最后读答案**。
<!-- end-card -->

<!-- demo -->
```
int s = 0;
for (int i = 1; i <= 4; i++) s += i;

草稿纸：
 圈数 | i | s
  1  | 1 | 1
  2  | 2 | 3
  3  | 3 | 6
  4  | 4 | 10
输出：10
```
<!-- end-demo -->

## break 和 continue

<!-- card type:teacher -->
⛔ `break`：整个循环立刻结束，后面都不跑了。

⏭️ `continue`：只跳过这一圈，马上进入下一圈。

记法：continue 是"这次算了"，break 是"不玩了"。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 3) continue;   // 跳过 3
        cout << i << " ";       // 输出 1 2 4 5
    }
    return 0;
}
```
<!-- end-demo -->

## 逗号表达式

<!-- card type:teacher -->
🤔 逗号能把几件事写一句里，从左到右做，整个式子的值是**最右边那个**。

`x = (1, 2, 3);` 之后，x 等于 3。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x;
    x = (5, 10);        // 逗号表达式，取最右边
    cout << x;          // 输出 10
    return 0;
}
```
<!-- end-demo -->

## 坑1：整数除法

<!-- card type:teacher -->
⚠️ 整数除以整数，小数部分会被丢掉。

`5 / 2` 得 2，`5.0 / 2` 得 2.5。只要有一个是小数，结果就是小数。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    cout << 5 / 2 << endl;    // 2
    cout << 5.0 / 2 << endl;  // 2.5
    return 0;
}
```
<!-- end-demo -->

## 坑2：字符也是数字

<!-- card type:teacher -->
🔤 字符在电脑里是 ASCII 数字。`'5'` 是 53。

`'5' + 1` 是 54（不是 6！），转回字符才是 `'6'`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char c = '5';
    cout << c + 1 << endl;         // 54（数字）
    cout << (char)(c + 1);         // 6（字符）
    return 0;
}
```
<!-- end-demo -->

## 辗转相除法

<!-- card type:teacher -->
🌀 求最大公约数（GCD）最快的办法：

大数 ÷ 小数取余数，再用小数 ÷ 余数……除到余数是 0，最后的除数就是答案。

例：gcd(12,18)：18%12=6，12%6=0，答案是 6。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 12, b = 18;
    while (b != 0) {
        int r = a % b;
        a = b; b = r;
    }
    cout << a;   // 输出 6
    return 0;
}
```
<!-- end-demo -->

## 最小公倍数

<!-- card type:teacher -->
⭐ 有了最大公约数，最小公倍数（LCM）一步算出来：

`lcm = a * b / gcd(a, b)`

例：12 和 18，gcd=6，lcm = 12*18/6 = 36。
<!-- end-card -->

<!-- checkpoint -->
<!-- quiz: choice -->

B. 12
C. 24
<!-- answer: B -->
<!-- end-checkpoint -->

## 挑战1：2的倍数非3的倍数

<!-- card type:computer -->
🖥️ 输入 n，输出 1~n 中是 2 的倍数但不是 3 的倍数的数，每行一个。

**输入样例：** `10`

**输出样例：**
```
2
4
8
10
```

> 💪 先不看下面的代码，自己用 continue 写一遍！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        if (i % 2 != 0) continue;  // 不是2的倍数，跳过
        if (i % 3 == 0) continue;  // 是3的倍数，跳过
        cout << i << endl;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战4：超过平均身高

<!-- card type:computer -->
🖥️ 输入 3 个人的身高（整数厘米），输出平均身高（保留1位小数），再输出有几个人超过平均身高。

**输入样例：**
```
170 160 180
```
**输出样例：**
```
170.0
1
```

> 💪 提示：先求和算出平均，再一个一个比。平均要保留小数，记得先转 double！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a, b, c;
    cin >> a >> b >> c;
    double avg = (a + b + c) / 3.0;   // 除以 3.0，结果才是小数
    int cnt = 0;
    if (a > avg) cnt++;
    if (b > avg) cnt++;
    if (c > avg) cnt++;
    printf("%.1f\n", avg);   // 保留1位小数
    cout << cnt;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**关键：** `(a+b+c)/3.0` 用 3.0 做除数，平均身高才有小数；如果写 `/3` 就变成整数除法，小数被丢掉了——这正是本课的坑1！
<!-- end-card -->

## 嵌套循环套 break

<!-- card type:teacher -->
🪆 最难的题来了：双层循环里套 break！

记住铁律：**break 只跳出它所在的那一层**，外层照样跑。

我们还是画表格，一行一行跟着算，别靠猜。
<!-- end-card -->

<!-- demo -->
```
int cnt = 0;
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) break;   // 只跳出内层 j
        cnt++;
    }
}

画表格（每一圈都记）：
 i | j | 发生什么      | cnt
 1 | 1 | cnt++        | 1
 1 | 2 | break 跳出内层 |
 2 | 1 | cnt++        | 2
 2 | 2 | break 跳出内层 |
 3 | 1 | cnt++        | 3
 3 | 2 | break 跳出内层 |
循环结束：i=4, j 只到过 2
输出 cnt = 3
```
<!-- end-demo -->

<!-- checkpoint -->
<!-- quiz: choice -->
上题代码运行结束后，外层变量 i 的值是多少？
A. 3
B. 4
C. 2
<!-- answer: B -->
<!-- end-checkpoint -->

<!-- card type:tip -->
💡 内层 break 后，外层 for 的 `i++` 照常执行，所以 i 最后还是会"冲过头"变成 4。别被内层的 break 骗了！
<!-- end-card -->

## 坑4：浮点精度

<!-- card type:teacher -->
🌊 小数在电脑里存得"不太准"。

`0.1 + 0.2` 不等于 `0.3`，而是 `0.30000000000000004`！

所以判断两个小数相等，别用 `==`，要看它们差得够不够小。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    double x = 0.1 + 0.2;
    cout << (x == 0.3) << endl;        // 0（不相等！）
    cout << (abs(x - 0.3) < 0.0001);   // 1（差很小就算相等）
    return 0;
}
```
<!-- end-demo -->

<!-- checkpoint -->
<!-- quiz: choice -->
判断 double 变量 x 是否等于 0.3，正确的写法是？
A. if (x == 0.3)
B. if (abs(x - 0.3) < 0.0001)
C. if (x = 0.3)
<!-- answer: B -->
<!-- end-checkpoint -->

## 小贴士

<!-- card type:tip -->
💡 读代码写结果：画表格，一变记一行，最后读答案。

💡 break 只跳出当前一层循环，外层继续跑。

💡 判断输出先盯类型：int 还是 double，决定有没有小数。

💡 小数判断相等别用 `==`，用 `abs(a-b) < 0.0001`。

💡 嵌套循环套 break：画表格一行行算，break 只跳内层，外层 i 照样 +1。
