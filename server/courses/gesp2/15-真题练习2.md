<!-- card type:computer -->
🖥️ **第 6 题** 输入 4 时，下面程序输出的最后一行是什么？

```cpp
int n;
cin >> n;
for (int i = n; i > 0; i--) {
    for (int j = 0; j < i; j++)
        cout << j + 1 << ' ';
    cout << endl;
}
```

A. `0`  
B. `1`  
C. `1 2`  
D. `1 2 3 4`
<!-- end-card -->

<!-- demo -->
💡 **答案：B**

i 从 4 变到 1：
- i=4：`1 2 3 4`
- i=3：`1 2 3`
- i=2：`1 2`
- i=1：`1`

最后一行是 `1`。

<!-- card type:computer -->
🖥️ **第 15 题** 演讲比赛有 8 位评委打分（0~10 整数），计分规则是去掉一个最高分和一个最低分。下面说法正确的是？

```cpp
for (int i = 0; i < 10; i++) {
    int id, score;
    scanf("%d", &id);

    int max_score = 0, min_score = 100;
    int total_score = 0;

    for (int j = 1; j < 9; j++) {
        scanf("%d", &score);
        if (max_score < score) max_score = score;
        if (min_score > score) min_score = score;
        total_score += score;
    }

    total_score = total_score - max_score - min_score;
    printf("%d号选手最后成绩是：%d", id, total_score);
}
```

A. 代码能完成题目要求  
B. `min_score` 应改为 0  
C. `max_score < score` 要改成 `<=`  
D. 减法赋值方式不对
<!-- end-card -->

<!-- demo -->
💡 **答案：A**

最高分初始为 0，最低分初始为 100，分数范围 0~10，所以初始值合理。循环 8 次读取分数并更新最大最小值，最后减去最大最小值得到最终成绩，逻辑正确。

## 挑战4：编程题 - 完全平方数计数

<!-- card type:computer -->
🖥️ **题目：** 完全平方数是可以表示为某个正整数平方的数，例如 9 = 3×3。给定 l 和 r，求 [l, r] 中有多少个完全平方数。

**输入：** 两行，分别是 l 和 r  
**输出：** 一个整数，表示完全平方数个数

**样例：**
- 输入：
```
1
21
```
- 输出：
```
4
```

**解释：** 1, 4, 9, 16 是完全平方数。
<!-- end-card -->

<!-- demo -->
💡 **参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int ans = 0, l, r;
    cin >> l >> r;
    for (int i = 1; i * i <= r; ++i) {
        if (i * i >= l)
            ans++;
    }
    cout << ans << endl;
    return 0;
}
```
<!-- end-demo -->

## 挑战5：编程题 - 菱形

<!-- card type:computer -->
🖥️ **题目：** 输入正整数 n，在 (2n-1) × (2n-1) 的画布中画一个边长为 n 的菱形。空白处用 `.`，菱形的边用 `+`。

**输入：** 一个正整数 n  
**输出：** 2n-1 行图形

**样例：** n = 3
```
..+..
.+.+
+...+
.+.+
..+..
```
<!-- end-card -->

<!-- demo -->
💡 **参考代码：**

不用记四条直线方程，只要记每一行左右两个 `+` 的位置：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= 2 * n - 1; ++i) {
        int left, right;
        if (i <= n) {
            left = n - i + 1;    // 上半：左 + 位置
            right = n + i - 1;   // 上半：右 + 位置
        } else {
            int k = i - n;       // 下半离中间有几行
            left = k + 1;        // 下半：左 + 位置
            right = 2 * n - k - 1; // 下半：右 + 位置
        }
        for (int j = 1; j <= 2 * n - 1; ++j) {
            if (j == left || j == right)
                cout << '+';
            else
                cout << '.';
        }
        cout << '\n';
    }
    return 0;
}
```
