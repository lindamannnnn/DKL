# GESP 2级 / CSP02 阶段课程体系规划

本规划参考 `code-master/code/01-课程教学资料/各阶段大纲/CSP02大纲.md`，将 GESP 2级（CSP02 阶段）内容划分为 10 节课，其中 01~08 为核心课程，09~10 为真题训练与阶段测试。

## 课程目标

面向小学 4-6 年级学生，在 GESP 1级基础上进一步学习数学函数、自定义函数、数据类型转换、多层分支与循环、图形打印及计算机存储与网络知识，能独立完成 GESP 2级认证考试所需的基础题目。

## 每节课详细内容

### 课程01：数学函数
- 绝对值函数 `abs()`
- 平方根函数 `sqrt()`
- 最大值 `max()` 与最小值 `min()`
- 四舍五入函数 `round()`
- 随机数函数 `rand()` / `srand()`
- 生成指定范围的随机数

### 课程02：自定义函数 1
- 函数的定义、调用与声明
- 形参与实参
- 全局作用域与局部作用域
- `void` 函数

### 课程03：数据类型转换
- 流程图的概念与绘制
- ASCII 编码与字符/整数转换
- 强制类型转换 `(类型)表达式`
- 隐式类型转换
- 周期偏移量与取模运算

### 课程04：多层分支结构
- 程序设计语言分类：机器语言、汇编语言、高级语言
- 编译型语言与解释型语言
- 常见高级语言简介
- `if` 嵌套、`if...else if...else`、`switch` 嵌套

### 课程05：多层循环语句
- 嵌套循环的执行顺序
- 用循环拆分数字的每一位
- 枚举法思想
- 百钱百鸡问题与变形

### 课程06：图形打印 1
- 反斜边规律（`i == j`）
- 正斜边规律（`i + j == n + 1`）
- X 形、菱形、空心正方形的打印
- 图形的拆解与对称

### 课程07：图形打印 2
- 复杂图形的拆解四步法
- 沙漏、空心菱形、数字三角形的实现
- 箭头图形的拆分
- 模块化打印函数

### 课程08：计算机的存储与网络
- ROM、RAM、CACHE 的区别与作用
- 计算机网络分类（LAN/MAN/WAN、拓扑结构）
- TCP/IP 四层模型
- OSI 七层模型及与 TCP/IP 的对应关系
- IP 地址格式与子网划分初步

### 课程09：GESP 二级真题训练
- 选择题训练
- 判断题训练
- 编程题训练

### 课程10：C2 阶段测试
- 选择题测试
- 判断题测试
- 编程题测试
