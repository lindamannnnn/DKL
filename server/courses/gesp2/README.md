## 课程目标

面向小学 4-6 年级学生，在 GESP 1级基础上进一步学习数学函数、自定义函数、数据类型转换、多层分支与循环、图形打印及计算机存储与网络知识，能独立完成 GESP 2级认证考试所需的题目。
