# 课程01：一维数组

> 🎯 目标：学会用数组管理"一排"数据，会定义、初始化、遍历数组，还能找出最大值和它的位置。

## 卡片：什么是数组

<!-- card type:teacher -->
🧑‍🏫 数组就像**一排编了号的储物柜** 🗄️

一个名字（比如 `a`）管理整排柜子，每个柜子里放一个数据，按**编号**取用。

这样存 50 个成绩，只需要一个名字，不用写 50 个变量啦！
<!-- end-card -->

---

## 卡片：数组的定义

<!-- card type:teacher -->
🧑‍🏫 定义数组的语法是：`类型 数组名[大小];`

比如 `int a[5];` 就是向电脑申请 5 个连在一起的 int 柜子，柜子的名字叫 `a`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[5];        // 5 个储物柜
    a[0] = 90;       // 0 号柜放 90
    a[2] = 70;       // 2 号柜放 70
    cout << a[0] << " " << a[2] << endl;  // 90 70
    return 0;
}
```
<!-- end-demo -->

## 卡片：下标从 0 开始

<!-- card type:teacher -->
🧑‍🏫 储物柜的编号叫**下标**，它从 **0** 开始数！

`int a[5]` 的 5 个柜子编号是 `a[0]` 到 `a[4]`。

⚠️ 写 `a[5]` 就**越界**了——电脑不会报错，但会读到乱糟糟的数据！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[5] = {90, 85, 70, 48, 91};
    cout << a[0] << endl;  // 90（第 1 个）
    cout << a[4] << endl;  // 91（第 5 个）
    return 0;
}
```
<!-- end-demo -->

## 卡片：数组初始化

<!-- card type:teacher -->
🧑‍🏫 定义时可以用大括号 `{}` 直接装满柜子：

- `int a[5] = {90, 85, 70, 48, 91};` 全装满
- `int a[5] = {1, 2};` 只装前 2 个，**其余自动补 0**
- `int a[5] = {0};` 全部变成 0

> 💡 写在 `main` 外面（全局）的数组，会自动全部初始化为 0，比赛时常这么干！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[5] = {1, 2};
    cout << a[1] << " " << a[4] << endl;  // 2 0
    return 0;
}
```
<!-- end-demo -->

## 卡片：循环遍历数组

<!-- card type:teacher -->
🧑‍🏫 数组最好的朋友就是 `for` 循环——让循环变量 `i` 当下标，一口气读写整排柜子！

> 💡 比赛里习惯让下标**从 1 开始**，这样"第 i 个"就是 `a[i]`，和题目说法一一对应。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];   // 读入
    for (int i = 1; i <= n; i++) cout << a[i] << " ";  // 输出
    return 0;
}
```
<!-- end-demo -->

---

## 卡片：查找最大值

<!-- card type:teacher -->
🧑‍🏫 找最大值就像**打擂台** 🥊

先让第 1 个元素当"擂主"（`maxv = a[1]`），后面每个人上台挑战，赢了就换人当擂主。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[6] = {0, 90, 85, 70, 48, 91}, maxv = a[1];
    for (int i = 2; i <= 5; i++)
        if (a[i] > maxv) maxv = a[i];
    cout << maxv << endl;  // 91
    return 0;
}
```
<!-- end-demo -->

---

## 卡片：最大值的位置

<!-- card type:teacher -->
🧑‍🏫 想知道最大值**站在几号柜**？多带一个小本本 `pos` 记位置。

每次换擂主时，顺手把号码也记下来：`pos = i;`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[6] = {0, 90, 85, 70, 48, 91}, maxv = a[1], pos = 1;
    for (int i = 2; i <= 5; i++)
        if (a[i] > maxv) { maxv = a[i]; pos = i; }
    cout << maxv << " " << pos << endl;  // 91 5
    return 0;
}
```
<!-- end-demo -->

---

## 挑战 1：数组输入输出

<!-- card type:computer -->
🖥️ 输入 n 个整数存入数组，再按原顺序输出。

**输入：** 第一行 n，第二行 n 个整数

**输入样例：** `5` 换行 `90 85 70 48 91`

**输出样例：** `90 85 70 48 91`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) cout << a[i] << " ";
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 数组的定义（`int a[105]`，多留点余量）
- for 循环遍历数组输入、输出

**解题思路分步说明**

1. 先读入 n，知道要读几个数。
2. 第一个循环：`i` 从 1 到 n，把每个数读进 `a[i]`。
3. 第二个循环：`i` 从 1 到 n，把 `a[i]` 依次输出。

**容易错的地方**

- 数组开小了：n 最大 100，开 `a[105]` 才保险
- 循环写成 `i < n`，漏掉最后一个数
- 输出时忘记数字之间的空格

**关键代码解释**

```cpp
for (int i = 1; i <= n; i++) cin >> a[i];
```

- 循环变量 `i` 就是柜子的编号
- 每跑一圈，把一个数放进 `a[i]` 这个柜子
<!-- end-card -->

## 挑战 2：最大值的位置

<!-- card type:computer -->
🖥️ 输入 n 个整数，找出最大值和它所在的位置（位置从 1 开始数）。

**输入样例：** `5` 换行 `90 85 91 48 91`

**输出样例：** `91 3`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int maxv = a[1], pos = 1;
    for (int i = 2; i <= n; i++)
        if (a[i] > maxv) { maxv = a[i]; pos = i; }
    cout << maxv << " " << pos << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 打擂台法找最大值
- 用 `pos` 同步记录位置

**解题思路分步说明**

1. 读入 n 个数到数组。
2. 假设 `a[1]` 是擂主：`maxv = a[1]`，`pos = 1`。
3. 从 `a[2]` 开始逐个挑战，发现更大的就换擂主、记号码。
4. 循环结束，输出擂主的值和号码。

**容易错的地方**

- 忘记同时更新 `pos`，只记了最大值
- `maxv` 写成 0：如果数组里全是负数就找不到正确答案了，要用 `a[1]` 当起点
- 有两个相同最大值时题目要第一个位置，所以判断用 `>` 不用 `>=`

**关键代码解释**

```cpp
if (a[i] > maxv) { maxv = a[i]; pos = i; }
```

- 挑战者 `a[i]` 比擂主强，才换擂主
- 换擂主的同时，把它的编号 `i` 记到 `pos` 里
<!-- end-card -->
