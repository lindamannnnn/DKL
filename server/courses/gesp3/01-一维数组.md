## 卡片：什么是数组

<!-- card type:teacher -->
🧑‍🏫 数组就像**一排编了号的储物柜** 🗄️

一个名字（比如 `a`）管理整排柜子，每个柜子里放一个数据，按**编号**取用。

这样存 50 个成绩，只需要一个名字，不用写 50 个变量啦！
<!-- end-card -->

---

## 卡片：数组的定义

<!-- card type:teacher -->
🧑‍🏫 定义数组的语法是：`类型 数组名[大小];`

比如 `int a[5];` 就是向电脑申请 5 个连在一起的 int 柜子，柜子的名字叫 `a`。

⚠️ 注意：中括号里的"大小"必须是一个**固定的数字**，不能写变量！`int a[n];` 是错误的——电脑申请柜子的时候就要知道一共几个。比赛里通常把数组开大一点、多留余量，比如 `int a[105];`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[5];        // 5 个储物柜
    a[0] = 90;       // 0 号柜放 90
    a[2] = 70;       // 2 号柜放 70
    cout << a[0] << " " << a[2] << endl;  // 90 70
    return 0;
}
```
<!-- end-demo -->

## 卡片：下标从 0 开始

<!-- card type:teacher -->
🧑‍🏫 储物柜的编号叫**下标**，它从 **0** 开始数！

`int a[5]` 的 5 个柜子编号是 `a[0]` 到 `a[4]`。

⚠️ 写 `a[5]` 就**越界**了——"越界"就是"超出柜子的编号范围"。电脑不会报错，但会读到乱糟糟的数据！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[5] = {90, 85, 70, 48, 91};
    cout << a[0] << endl;  // 90（第 1 个）
    cout << a[4] << endl;  // 91（第 5 个）
    return 0;
}
```
<!-- end-demo -->

## 卡片：越界会闯大祸

<!-- card type:teacher -->
🧑‍🏫 数组在内存里是**一排紧挨着的格子**。一个 int 占 4 个字节（字节是电脑量内存的"小格子"）。

所以 `a[n]` 的位置 = 起点 + n × 4 个字节。电脑找格子时只管"从起点走 n 格"，**根本不检查有没有走出数组**！

越界三大后果：① 读到脏数据（别人格子里的垃圾）② 改掉别的变量的值（悄悄搞破坏）③ 程序直接崩溃（这种崩溃有个名字叫**段错误**，记住名字就行）💥
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[3] = {10, 20, 30};
    cout << a[2] << endl;  // 30，正常
    cout << a[5] << endl;  // 越界！读到脏数据，还可能闯更大的祸
    return 0;
}
```
<!-- end-demo -->

## 卡片：数组初始化

<!-- card type:teacher -->
🧑‍🏫 定义时可以用大括号 `{}` 直接装满柜子：

- `int a[5] = {90, 85, 70, 48, 91};` 全装满
- `int a[5] = {1, 2};` 只装前 2 个，**其余自动补 0**
- `int a[5] = {0};` 全部变成 0

> 💡 写在 `main` 外面（全局）的数组，会自动全部初始化为 0，比赛时常这么干！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[5] = {1, 2};
    cout << a[1] << " " << a[4] << endl;  // 2 0
    return 0;
}
```
<!-- end-demo -->

## 卡片：大数组放外面

<!-- card type:teacher -->
🧑‍🏫 `main` 里面定义的局部数组，住在一个叫**栈**的小房间，地方很挤——开 `int b[10000000];` 这么大，房间直接挤爆，程序崩溃！这叫**爆栈**。

`main` 外面（全局）的数组住大操场，地方宽敞，还自动清 0。

🏆 竞赛秘诀：**大数组一律开全局**，局部只开小数组。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[100005];           // 全局：地方大，自动清 0
int main() {
    // int b[10000000];  // ❌ 栈里开这么大，爆栈崩溃！
    int b[1005] = {0};   // ✅ 局部只开小数组
    cout << a[100000] + b[1004] << endl;  // 0
    return 0;
}
```
<!-- end-demo -->

## 卡片：为什么从 1 用

<!-- card type:teacher -->
🧑‍🏫 柜子的天生编号从 0 开始，可比赛题目爱说"第 1 个数、第 2 个数"，怎么办？

妙招：**故意让 0 号柜空着占位**，从 1 号柜开始装！这样"第 i 个数"正好住在 `a[i]`，和题目说法一一对应，再也不怕数错。

🧠 口诀：**定义从 0 数，比赛从 1 用**。
<!-- end-card -->

<!-- checkpoint -->

B. 存放第一个数
C. 存放最大的数
<!-- answer: A -->

## 卡片：循环遍历数组

<!-- card type:teacher -->
🧑‍🏫 数组最好的朋友就是 `for` 循环——让循环变量 `i` 当下标，一口气读写整排柜子！

一个一个全都看一遍，这个动作就叫**遍历**（"遍"就是"全部"的意思）。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];   // 读入
    for (int i = 1; i <= n; i++) cout << a[i] << " ";  // 输出
    return 0;
}
```
<!-- end-demo -->

## 卡片：查找最大值

<!-- card type:teacher -->
🧑‍🏫 找最大值就像**打擂台** 🥊

先让第 1 个元素当"擂主"（`maxv = a[1]`），后面每个人上台挑战，赢了就换人当擂主。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[6] = {0, 90, 85, 70, 48, 91}, maxv = a[1];  // 0 号柜空着占位，成绩放 1~5 号柜
    for (int i = 2; i <= 5; i++)
        if (a[i] > maxv) maxv = a[i];
    cout << maxv << endl;  // 91
    return 0;
}
```
<!-- end-demo -->

---

## 卡片：最大值的位置

<!-- card type:teacher -->
🧑‍🏫 想知道最大值**站在几号柜**？多带一个小本本 `pos` 记位置。

每次换擂主时，顺手把号码也记下来：`pos = i;`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[6] = {0, 90, 85, 70, 48, 91}, maxv = a[1], pos = 1;  // 0 号柜空着占位，成绩放 1~5 号柜
    for (int i = 2; i <= 5; i++)
        if (a[i] > maxv) { maxv = a[i]; pos = i; }
    cout << maxv << " " << pos << endl;  // 91 5
    return 0;
}
```
<!-- end-demo -->

---

## 挑战 1：数组输入输出

<!-- card type:computer -->
🖥️ 输入 n 个整数存入数组，再按原顺序输出。

**输入：** 第一行 n，第二行 n 个整数

**输入样例：** `5` 换行 `90 85 70 48 91`

**输出样例：** `90 85 70 48 91`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) cout << a[i] << " ";
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 数组的定义（`int a[105]`，多留点余量）
- for 循环遍历数组输入、输出

**解题思路分步说明**

1. 先读入 n，知道要读几个数。
2. 第一个循环：`i` 从 1 到 n，把每个数读进 `a[i]`。
3. 第二个循环：`i` 从 1 到 n，把 `a[i]` 依次输出。

**容易错的地方**

- 数组开小了：n 最大 100，开 `a[105]` 才保险
- 循环写成 `i < n`，漏掉最后一个数
- 输出时忘记数字之间的空格

**关键代码解释**

```cpp
for (int i = 1; i <= n; i++) cin >> a[i];
```

- 循环变量 `i` 就是柜子的编号
- 每跑一圈，把一个数放进 `a[i]` 这个柜子
<!-- end-card -->

## 挑战 2：最大值的位置

<!-- card type:computer -->
🖥️ 输入 n 个整数，找出最大值和它所在的位置（位置从 1 开始数）。

**输入样例：** `5` 换行 `90 85 91 48 91`

**输出样例：** `91 3`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int maxv = a[1], pos = 1;
    for (int i = 2; i <= n; i++) if (a[i] > maxv) { maxv = a[i]; pos = i; }
    cout << maxv << " " << pos << endl; return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 打擂台法找最大值
- 用 `pos` 同步记录位置

**解题思路分步说明**

1. 读入 n 个数到数组。
2. 假设 `a[1]` 是擂主：`maxv = a[1]`，`pos = 1`。
3. 从 `a[2]` 开始逐个挑战，发现更大的就换擂主、记号码。
4. 循环结束，输出擂主的值和号码。

**容易错的地方**

- 忘记同时更新 `pos`，只记了最大值
- `maxv` 写成 0：如果数组里全是负数就找不到正确答案了，要用 `a[1]` 当起点
- 有两个相同最大值时题目要第一个位置，所以判断用 `>` 不用 `>=`

**关键代码解释**

```cpp
if (a[i] > maxv) { maxv = a[i]; pos = i; }
```

- 挑战者 `a[i]` 比擂主强，才换擂主
- 换擂主的同时，把它的编号 `i` 记到 `pos` 里
<!-- end-card -->

## 挑战 3：逆序输出

<!-- card type:computer -->
🖥️ 输入 n 个整数存入数组，**从后往前**输出。

**输入：** 第一行 n，第二行 n 个整数

**输入样例：** `5` 换行 `1 2 3 4 5`

**输出样例：** `5 4 3 2 1`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = n; i >= 1; i--) cout << a[i] << " ";
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- for 循环**倒着走**：`i` 从 n 开始，`i--` 一路减到 1

**解题思路分步说明**

1. 正常读入 n 个数到 `a[1] ~ a[n]`。
2. 输出时让 `i` 从 n 倒着走到 1，挨个输出 `a[i]`。

**容易错的地方**

- 循环写成 `i >= 0`，把空着的 0 号柜也输出了（从 1 用起时 0 号柜是空位）
- 起始写成 `i = n - 1`，漏掉最后一个数

**关键代码解释**

```cpp
for (int i = n; i >= 1; i--) cout << a[i] << " ";
```

- 正序遍历是 `i++`，逆序遍历就是 `i--`
- 数组不用真的反过来，倒着读就行！
<!-- end-card -->

## 挑战 4：第二大数

<!-- card type:computer -->
🖥️ 输入 n 个**各不相同**的整数，找出第二大的数（排第 2 名的那个）。

**输入样例：** `5` 换行 `90 85 70 48 91`

**输出样例：** `90`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int m1 = max(a[1], a[2]), m2 = min(a[1], a[2]);
    for (int i = 3; i <= n; i++)
        if (a[i] > m1) { m2 = m1; m1 = a[i]; } else if (a[i] > m2) m2 = a[i];
    cout << m2 << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 维护两个变量：冠军 `m1` 和亚军 `m2`，一趟遍历同时找

**解题思路分步说明**

1. 先让前两个数比一比，大的当冠军 `m1`，小的当亚军 `m2`。
2. 后面每个数 `a[i]`：比冠军强，就把冠军挤成亚军、自己当冠军；只比亚军强，就换亚军。
3. 遍历完，`m2` 就是第二名。

**容易错的地方**

- 换冠军时忘了 `m2 = m1`，老冠军被直接丢掉
- 想"先排序再找第 2 个"：排序更慢，还会打乱原顺序；一趟遍历两个变量就够了

**关键代码解释**

```cpp
if (a[i] > m1) { m2 = m1; m1 = a[i]; } else if (a[i] > m2) m2 = a[i];
```

- 新冠军登基，老冠军退位当亚军
- 进不了前二，`a[i]` 直接淘汰
<!-- end-card -->
