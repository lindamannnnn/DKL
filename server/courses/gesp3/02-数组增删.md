## 卡片：插入要后移

<!-- card type:teacher -->
🧑‍🏫 想在第 pos 个位置前插入新元素，先把 pos 及后面的元素**从后往前**挨个后移一格，空出位置再放新元素。

⚠️ 方向必须是**从后往前**！从前往后移会把还没移走的数据覆盖掉。

移完别忘了 `n++`，元素总数多了一个。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[8] = {0, 1, 3, 5, 7}, n = 4;
    for (int i = n; i >= 2; i--) a[i + 1] = a[i];
    a[2] = 9; n++;
    for (int i = 1; i <= n; i++) cout << a[i] << " ";  // 1 9 3 5 7
    return 0;
}
```
<!-- end-demo -->

## 卡片：删除要前移

<!-- card type:teacher -->
🧑‍🏫 删除第 pos 个元素，从 pos 开始**从前往后**，让后面的人往前补一格：`a[i] = a[i+1]`。

方向和插入正好相反！删完记得 `n--`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[8] = {0, 1, 3, 5, 7}, n = 4;
    for (int i = 2; i < n; i++) a[i] = a[i + 1];
    n--;
    for (int i = 1; i <= n; i++) cout << a[i] << " ";  // 1 5 7
    return 0;
}
```
<!-- end-demo -->

## 卡片：交换两个数

<!-- card type:teacher -->
🧑‍🏫 交换两个变量，就像交换两杯水：要拿个空杯 `tmp` 过渡，分三步走。

偷懒办法：C++ 自带 `swap(a, b)`，一行搞定！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 3, b = 5, tmp;
    tmp = a; a = b; b = tmp;   // 三步交换：a=5 b=3
    swap(a, b);                // 一行又换回：a=3 b=5
    cout << a << " " << b << endl;  // 3 5
    return 0;
}
```
<!-- end-demo -->

## 卡片：数组逆序

<!-- card type:teacher -->
🧑‍🏫 逆序用**双指针**夹逼 🦀：左指针 `l` 站排头，右指针 `r` 站排尾。

交换 `a[l]` 和 `a[r]`，然后 `l++`、`r--` 各走一步，直到两人相遇就停。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[6] = {0, 1, 2, 3, 4, 5};
    int l = 1, r = 5;
    while (l < r) { swap(a[l], a[r]); l++; r--; }
    for (int i = 1; i <= 5; i++) cout << a[i] << " ";  // 5 4 3 2 1
    return 0;
}
```
<!-- end-demo -->

## 卡片：什么是逆序数

<!-- card type:teacher -->
🧑‍🏫 排在前面的数比后面的数大，它俩就组成一对**逆序对** 😈

逆序对的总数叫**逆序数**：数组越乱逆序数越大，排好序的数组逆序数是 0。

用两层循环枚举每一对 `(i, j)`，就能数出来。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[5] = {0, 2, 4, 1, 3}, cnt = 0;
    for (int i = 1; i <= 4; i++)
        for (int j = i + 1; j <= 4; j++)
            if (a[i] > a[j]) cnt++;
    cout << cnt << endl; return 0;  // 3
}
```
<!-- end-demo -->

## 挑战 1：位置插入

<!-- card type:computer -->
🖥️ 输入 n 个整数存入数组，再在 pos 位置前插入 val，输出插入后的 n+1 个数。

**输入：** 第一行 n，第二行 n 个整数，第三行 pos 和 val

**输入样例：** `4` 换行 `1 3 5 7` 换行 `2 9`

**输出样例：** `1 9 3 5 7`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n, pos, val; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    cin >> pos >> val;
    for (int i = n; i >= pos; i--) a[i + 1] = a[i];
    a[pos] = val; n++;
    for (int i = 1; i <= n; i++) cout << a[i] << " ";
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 数组指定位置插入元素（从后往前后移）
- 插入后数组长度 `n++`

**解题思路分步说明**

1. 读入 n 个数，再读 pos 和 val。
2. `i` 从 n 倒着走到 pos，每个元素后移一格。
3. 空出 pos 位置，放入 val，`n++`。
4. 从头到尾输出新数组。

**容易错的地方**

- 循环方向写反：必须 `i--` 从后往前，否则数据被覆盖
- 忘记 `n++`，最后一个元素输不出来
- 数组开得刚好 n，插入后越界

**关键代码解释**

```cpp
for (int i = n; i >= pos; i--) a[i + 1] = a[i];
```

- 从最后一个元素开始，一个个往后挪
- 先挪后面的，前面的数据才不会被覆盖
<!-- end-card -->

## 挑战 2：数组逆序

<!-- card type:computer -->
🖥️ 输入 n 个整数，把数组真正逆序（不是倒着输出哦），再从头到尾输出。

**输入样例：** `5` 换行 `1 2 3 4 5`

**输出样例：** `5 4 3 2 1`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int l = 1, r = n;
    while (l < r) { swap(a[l], a[r]); l++; r--; }
    for (int i = 1; i <= n; i++) cout << a[i] << " ";
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- `swap` 交换两个元素
- 双指针两端夹逼实现逆序

**解题思路分步说明**

1. 读入 n 个数。
2. 左指针 `l = 1`，右指针 `r = n`。
3. 当 `l < r`：交换两指针位置的元素，`l++`、`r--`。
4. 指针相遇后输出数组。

**容易错的地方**

- 循环条件写成 `l <= r`：奇数个元素时中间那个会和自己交换，虽然结果没错但多此一举
- 交换后忘记移动指针，死循环
- 用倒序循环直接输出，没有真正修改数组（题目不允许）

**关键代码解释**

```cpp
while (l < r) { swap(a[l], a[r]); l++; r--; }
```

- 每次交换一对"对称位置"的元素
- 两个指针向中间靠拢，相遇即完成
<!-- end-card -->

## 小贴士

<!-- card type:tip -->
💡 口诀：**插入从后往前移，删除从前往后移**——方向记反就全乱套！

💡 交换忘了用临时变量，直接 `a=b; b=a;`，两个都会变成 b 的值！

💡 插入后元素会变多，数组开 `a[105]` 留足余量。
