## 卡片：下标当桶用

<!-- card type:teacher -->
🧑‍🏫 数组下标不只表示"第几个"，还能直接当**数据的值**用！

`cnt[v]` 就表示"值 v 出现了几次"。读到 x 就 `cnt[x]++`，像往 x 号桶里投一个球 ⚽
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int cnt[10];
int main() {
    int a[6] = {3, 7, 3, 2, 3, 7};
    for (int i = 0; i < 6; i++) cnt[a[i]]++;
    cout << cnt[2] << " " << cnt[3] << " " << cnt[7] << endl;  // 1 3 2
    return 0;
}
```
<!-- end-demo -->

## 卡片：桶要先清空

<!-- card type:teacher -->
🧑‍🏫 计数数组必须全部从 0 开始！写在 `main` 外面（全局）会自动清 0，最省心。

⚠️ 桶的数量看**值的范围**：值最大是 100，就开 `cnt[101]`（下标 0~100）。

值太大（比如上亿）数组开不下，就不能用这个方法啦！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int cnt[101] = {0};          // 全部清 0
    cnt[90]++; cnt[90]++; cnt[60]++;
    cout << cnt[90] << " " << cnt[61] << endl;  // 2 0
    return 0;
}
```
<!-- end-demo -->

## 卡片：谁是票王

<!-- card type:teacher -->
🧑‍🏫 统计完后扫一遍桶：哪个桶里的球最多，哪个值就是"票王" 🏆

还是打擂台：`cnt[v]` 比当前冠军多，就换它当冠军。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int cnt[10];
int main() {
    int a[6] = {3, 7, 3, 2, 3, 7}, ans = 0;
    for (int i = 0; i < 6; i++) cnt[a[i]]++;
    for (int v = 1; v <= 9; v++) if (cnt[v] > cnt[ans]) ans = v;
    cout << ans << " " << cnt[ans] << endl; return 0;  // 3 3
}
```
<!-- end-demo -->

## 卡片：桶排序

<!-- card type:teacher -->
🧑‍🏫 把桶**从小到大**依次打开，每个桶里有几个球，就把桶的编号输出几次。

倒出来的数自动排好队——这就是**桶排序**，超快 ⚡
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int cnt[10];
int main() {
    int a[5] = {3, 1, 4, 1, 5};
    for (int i = 0; i < 5; i++) cnt[a[i]]++;
    for (int v = 0; v <= 9; v++)
        while (cnt[v]--) cout << v << " ";  // 1 1 3 4 5
}
```
<!-- end-demo -->

## 挑战 1：统计票数

<!-- card type:computer -->
🖥️ 输入 n 个整数（范围 1~100），从小到大输出每个出现过的数和它的次数。

**输入：** 第一行 n，第二行 n 个整数

**输入样例：** `6` 换行 `3 1 3 2 1 3`

**输出样例：** `1 2` 换行 `2 1` 换行 `3 3`（每行：数字 次数）
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int cnt[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) { int x; cin >> x; cnt[x]++; }
    for (int v = 1; v <= 100; v++)
        if (cnt[v] > 0) cout << v << " " << cnt[v] << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 计数数组 `cnt[x]++` 统计频次
- 按下标顺序输出统计结果

**解题思路分步说明**

1. 定义全局计数数组 `cnt[105]`（自动清 0）。
2. 每读入一个 x，就 `cnt[x]++`。
3. 从 1 到 100 扫描，`cnt[v] > 0` 的就输出 v 和次数。

**容易错的地方**

- 计数数组忘了清 0（写在 `main` 里面又不初始化，会读出垃圾值）
- 数组只开到 `cnt[100]`，值 100 越界
- 没出现过的数也输出了（要先判断 `cnt[v] > 0`）

**关键代码解释**

```cpp
for (int i = 1; i <= n; i++) { int x; cin >> x; cnt[x]++; }
```

- 不用存原数组，边读边往桶里投球
- `cnt[x]++`：x 号桶多一个球
<!-- end-card -->

## 挑战 2：票王是谁

<!-- card type:computer -->
🖥️ 输入 n 个整数（范围 1~100），找出出现次数最多的数；若并列，输出最小的那个。

**输入样例：** `7` 换行 `1 2 3 2 1 2 3`

**输出样例：** `2 3`（出现最多的数 和 它的次数）
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int cnt[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) { int x; cin >> x; cnt[x]++; }
    int maxC = 0, ans = 0;
    for (int v = 1; v <= 100; v++)
        if (cnt[v] > maxC) { maxC = cnt[v]; ans = v; }
    cout << ans << " " << maxC << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 计数数组统计频次
- 在桶上"打擂台"找最大值

**解题思路分步说明**

1. 边读边统计：`cnt[x]++`。
2. 从 1 到 100 扫描桶，`cnt[v]` 比 `maxC` 大就换冠军。
3. 输出冠军编号 `ans` 和次数 `maxC`。

**容易错的地方**

- 判断写成 `>=`：并列时会留下大编号，题目要小编号，必须用 `>`
- `maxC` 没从 0 开始，或扫桶范围漏掉某些值
- 把"出现最多的值"和"最大的值"搞混

**关键代码解释**

```cpp
if (cnt[v] > maxC) { maxC = cnt[v]; ans = v; }
```

- 桶 v 的球比冠军多，才换冠军
- 从小往大扫，并列时先到的（小编号）自动获胜
<!-- end-card -->

## 小贴士

<!-- card type:tip -->
💡 `cnt[x]++` 里的 x 是**值**，不是"第几个"——下标当桶用！

💡 值的范围太大（比如 10 亿）数组开不下，就不能用计数法。

💡 找票王从小编号往大扫、判断用 `>`，并列时自动留下小编号。
