## 挑战 1：最大最小差

<!-- card type:computer -->
🖥️ 输入 n 个整数，输出最大值与最小值的差。

**输入：** 第一行 n，第二行 n 个整数

**输入样例：** `5` 换行 `4 9 2 7 5`

**输出样例：** `7`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int mx = a[1], mn = a[1];
    for (int i = 2; i <= n; i++) {
        mx = max(mx, a[i]); mn = min(mn, a[i]);
    }
    cout << mx - mn << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- for 循环遍历数组
- 打擂台同时找最大值和最小值

**解题思路分步说明**

1. 读入 n 个数到数组。
2. 让 `a[1]` 同时当最大、最小擂主。
3. 从 `a[2]` 开始逐个挑战，更大换 `mx`，更小换 `mn`。
4. 输出 `mx - mn`。

**容易错的地方**

- `mx`、`mn` 初始写成 0：数组里全是负数或全大于 0 时会出错，要用 `a[1]` 当起点
- 循环从 `i = 1` 开始多比一次自己（不错但没必要），从 2 开始更规范

**关键代码解释**

```cpp
mx = max(mx, a[i]); mn = min(mn, a[i]);
```

- `max(a, b)` 返回较大的那个，`min` 返回较小的
- 一行同时守两个擂台
<!-- end-card -->

## 挑战 2：删除一个数

<!-- card type:computer -->
🖥️ 输入 n 个整数和位置 pos，删除第 pos 个数，输出剩下的 n-1 个数。

**输入样例：** `5` 换行 `1 3 5 7 9` 换行 `3`

**输出样例：** `1 3 7 9`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n, pos; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    cin >> pos;
    for (int i = pos; i < n; i++) a[i] = a[i + 1];
    n--;
    for (int i = 1; i <= n; i++) cout << a[i] << " ";
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 删除数组指定位置的元素（从前往后前移）

**解题思路分步说明**

1. 读入 n 个数和 pos。
2. `i` 从 pos 走到 n-1，每个位置用后一个元素覆盖：`a[i] = a[i+1]`。
3. `n--`，输出前 n 个元素。

**容易错的地方**

- 循环方向写反：删除必须**从前往后**，从后往前会把数据盖错
- 忘记 `n--`，把已经移走的末尾元素也输出了
- 循环写成 `i <= n`，越界读到 `a[n+1]`

**关键代码解释**

```cpp
for (int i = pos; i < n; i++) a[i] = a[i + 1];
```

- 从被删位置开始，后面的人依次往前补一格
- 到 `i = n-1` 为止，最后一个空位不用管
<!-- end-card -->

## 挑战 3：投票统计

<!-- card type:computer -->
🖥️ 输入 n 张选票（候选人编号 1~100），输出得票最多的候选人编号和票数；并列时输出小编号。

**输入样例：** `5` 换行 `1 2 1 3 2`

**输出样例：** `1 2`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int cnt[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) { int x; cin >> x; cnt[x]++; }
    int ans = 1;
    for (int v = 2; v <= 100; v++)
        if (cnt[v] > cnt[ans]) ans = v;
    cout << ans << " " << cnt[ans] << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 计数数组 `cnt[x]++` 统计票数
- 扫桶打擂台找"票王"

**解题思路分步说明**

1. 每读一张票 x，`cnt[x]++`。
2. 先假设 1 号是票王：`ans = 1`。
3. 从 2 号扫到 100 号，谁的票比 `cnt[ans]` 多就换人。
4. 输出 `ans` 和 `cnt[ans]`。

**容易错的地方**

- 判断写成 `>=`：并列时会留下大编号，题目要小编号
- 计数数组没清 0（写全局自动清 0 最保险）
- 输出成票数和编号顺序颠倒

**关键代码解释**

```cpp
if (cnt[v] > cnt[ans]) ans = v;
```

- 挑战者票数**严格更多**才换票王
- 从小往大扫，并列时小编号先当上票王就不会被换掉
<!-- end-card -->

## 挑战 4：数组逆序

<!-- card type:computer -->
🖥️ 输入 n 个整数，把数组真正逆序后从头到尾输出。

**输入样例：** `6` 换行 `1 3 5 7 9 11`

**输出样例：** `11 9 7 5 3 1`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int l = 1, r = n;
    while (l < r) { swap(a[l], a[r]); l++; r--; }
    for (int i = 1; i <= n; i++) cout << a[i] << " ";
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- `swap` 交换元素
- 双指针两端夹逼实现逆序

**解题思路分步说明**

1. 读入 n 个数。
2. 左指针 `l = 1`，右指针 `r = n`。
3. 当 `l < r`：交换两指针位置的元素，然后 `l++`、`r--`。
4. 指针相遇后输出整个数组。

**容易错的地方**

- 交换后忘记移动指针，变成死循环
- 直接从后往前输出（没有真正修改数组，题目不允许）
- 用临时变量交换时忘记先存 `tmp`

**关键代码解释**

```cpp
while (l < r) { swap(a[l], a[r]); l++; r--; }
```

- 每轮交换一对对称位置的元素
- 两个指针向中间走，相遇时恰好换完
<!-- end-card -->

## 挑战 5：删除所有 x

<!-- card type:computer -->
🖥️ 输入 n 个整数和一个值 x，删除数组中**所有**等于 x 的数，输出剩下的数。

**输入样例：** `6` 换行 `1 3 2 3 4 3` 换行 `3`

**输出样例：** `1 2 4`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n, x; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    cin >> x;
    int m = 0;
    for (int i = 1; i <= n; i++)
        if (a[i] != x) { m++; a[m] = a[i]; }
    for (int i = 1; i <= m; i++) cout << a[i] << " ";
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 删除满足条件的所有元素
- "筛选装柜"技巧：把要留的重新装箱

**解题思路分步说明**

1. 读入 n 个数和 x。
2. 准备计数器 `m = 0`，表示新数组已装几个。
3. 遍历原数组，不等于 x 的就先 `m++` 再装进 `a[m]`。
4. 输出前 m 个元素。

**容易错的地方**

- 用"发现就前移删除"的写法也能做，但删完要退回重看当前位置，容易漏判
- 输出时用原来的 n 而不是新的 m
- `m++` 和 `a[m] = a[i]` 顺序写反：要先加 1 再装柜，不然元素会装进 0 号空柜，输出全错位

**关键代码解释**

```cpp
if (a[i] != x) { m++; a[m] = a[i]; }
```

- `m++` 先让新柜子编号加 1，`a[m] = a[i]` 再把元素装进去
- 留下的元素按原顺序重新排好，等于 x 的自然被挤掉
<!-- end-card -->
