## 回顾

<!-- card type:teacher -->
🧑‍🏫 上节课学了计数法：`cnt[x]++` 能统计 x **一共**出现了几次。

可它分不清这些 x 是不是**挨着**出现的。想知道"最长连续几次"，需要新武器！
<!-- end-card -->

---

## 卡片：连续和总数

<!-- card type:teacher -->
🧑‍🏫 注意区分两个问题：

- **总次数**：2 在整个数组里出现几回 → 用计数桶 `cnt[2]`
- **最长连续**：2 最多**挨着**出现几回 → 要数"连续段"

今天解决的是第二种！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int cnt[5];
int main() {
    int a[8] = {0, 1, 2, 2, 3, 3, 3, 2};
    for (int i = 1; i <= 7; i++) cnt[a[i]]++;
    cout << cnt[2] << endl;  // 3（总次数，不是连续次数）
    return 0;
}
```
<!-- end-demo -->

## 卡片：滑动计数器

<!-- card type:teacher -->
🧑‍🏫 法宝登场 ✨：一个计数器 `cur` 记录**当前连续了几个**，一个冠军本 `maxL` 记录**历史最长**。

- 和前面一样：`cur++`
- 和前面不同：`cur = 1`（重新数）
- 每一步：`maxL = max(maxL, cur)`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[8] = {0, 1, 2, 2, 3, 3, 3, 2}, cur = 1, maxL = 1;
    for (int i = 2; i <= 7; i++) {
        if (a[i] == a[i-1]) cur++; else cur = 1;
        if (cur > maxL) maxL = cur;
    }
    cout << maxL << endl;  // 3
}
```
<!-- end-demo -->

## 卡片：记下冠军

<!-- card type:teacher -->
🧑‍🏫 想知道最长连续段是**哪个数**创造的？刷新纪录时顺手记下 `a[i]` 就行。

注意只在**打破纪录**时记，并列时先出现的保留。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[8] = {0, 1, 2, 2, 3, 3, 3, 2}, cur = 1, maxL = 1, ans = a[1];
    for (int i = 2; i <= 7; i++) {
        if (a[i] == a[i-1]) cur++; else cur = 1;
        if (cur > maxL) { maxL = cur; ans = a[i]; }
    }
    cout << ans << " " << maxL << endl;  // 3 3
}
```
<!-- end-demo -->

## 卡片：连续递增段

<!-- card type:teacher -->
🧑‍🏫 "连续"不只是相同：后一个**恰好比前一个大 1**，也算连续（递增段）📈

判断条件改一下就行：`a[i] == a[i-1] + 1`，套路完全一样！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[8] = {0, 1, 2, 3, 1, 2, 4, 5}, cur = 1, maxL = 1;
    for (int i = 2; i <= 7; i++) {
        if (a[i] == a[i-1] + 1) cur++; else cur = 1;
        if (cur > maxL) maxL = cur;
    }
    cout << maxL << endl;  // 3
}
```
<!-- end-demo -->

## 挑战 1：最长连续段

<!-- card type:computer -->
🖥️ 输入 n 个整数，找出连续相同次数最多的那个数，输出它和连续次数；并列取先出现的。

**输入：** 第一行 n，第二行 n 个整数

**输入样例：** `7` 换行 `1 2 2 3 3 3 2`

**输出样例：** `3 3`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, a[1005]; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int cur = 1, maxL = 1, ans = a[1];
    for (int i = 2; i <= n; i++) {
        if (a[i] == a[i-1]) cur++; else cur = 1;
        if (cur > maxL) { maxL = cur; ans = a[i]; }
    }
    cout << ans << " " << maxL << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 滑动计数器找最长连续相同段
- 破纪录时同步记录元素的值

**解题思路分步说明**

1. 读入 n 个数，设 `cur = 1`、`maxL = 1`、`ans = a[1]`。
2. 从第 2 个开始：和前一个相同 `cur++`，不同 `cur = 1`。
3. `cur` 破纪录时更新 `maxL`，并记下 `ans = a[i]`。
4. 输出 `ans` 和 `maxL`。

**容易错的地方**

- 从 `i = 1` 开始比较 `a[0]`：下标从 1 用时 `a[0]` 是 0，可能误判，要从 2 开始
- 断开时写成 `cur = 0`：新的一段从当前元素算起，应该是 1
- 判断用 `>=`：并列时后出现的会覆盖先出现的

**关键代码解释**

```cpp
if (a[i] == a[i-1]) cur++; else cur = 1;
```

- 和前一个相同，连续段延长一格
- 不同则段断了，从当前元素重新数 1 个
<!-- end-card -->

## 挑战 2：最长连续 1

<!-- card type:computer -->
🖥️ 输入 n 个 0 或 1（1 表示赢、0 表示输），求最长连胜纪录，即最长连续 1 的长度。

**输入样例：** `8` 换行 `1 0 1 1 0 1 1 1`

**输出样例：** `3`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[1005];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int cur = 0, maxL = 0;
    for (int i = 1; i <= n; i++) {
        if (a[i] == 1) { cur++; maxL = max(maxL, cur); } else cur = 0;
    }
    cout << maxL << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 滑动计数器的变形：只关心某一种值（1）的连续段

**解题思路分步说明**

1. 读入 n 个 0/1。
2. 遍历每个数：是 1 就 `cur++` 并刷新 `maxL`；是 0 就 `cur = 0`。
3. 遍历结束输出 `maxL`。

**容易错的地方**

- 这题 `cur` 和 `maxL` 从 **0** 开始（可能全是 0，一场没赢）
- 遇到 0 忘记重置 `cur`，把断开的连胜接起来了
- 只在遇到 0 时才更新 `maxL`：最后一段连胜会漏掉，要边数边更新

**关键代码解释**

```cpp
if (a[i] == 1) { cur++; maxL = max(maxL, cur); } else cur = 0;
```

- 赢一场，连胜加一，顺手看看破没破纪录
- 输一场，连胜清零重新数
<!-- end-card -->

## 小贴士

<!-- card type:tip -->
💡 万能套路：`cur` 记当前、`maxL` 记历史，断开就重置，每步刷纪录。

💡 数"相同段"初始 `cur = 1`；数"连续 1"初始 `cur = 0`——想清楚第一个元素算不算一段。

💡 想换题型？改判断条件就行：`a[i]==a[i-1]` 相同段、`a[i]==a[i-1]+1` 递增段。
