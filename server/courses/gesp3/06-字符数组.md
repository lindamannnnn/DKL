## 卡片：char 密码表

<!-- card type:teacher -->
🧑‍🏫 每个字符在电脑里都是一个数字，对照表叫 **ASCII 码** 🔢

记住三组就够：`'0'` 是 48、`'A'` 是 65、`'a'` 是 97，同组的字符号码是连续的。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char c = 'A';
    cout << c << endl;        // A
    cout << (int)c << endl;   // 65（它的密码）
    cout << (char)(c + 2);    // C（65+2=67）
    return 0;
}
```
<!-- end-demo -->

## 卡片：大小写差 32

<!-- card type:teacher -->
🧑‍🏫 大小写字母的密码藏着一个小秘密：同一个字母，小写比大写正好大 **32**！

所以 `'A' + 32` 就是 `'a'`，`'m' - 32` 就是 `'M'`，不用函数也能手动变身 🔑
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char c = 'B';
    cout << (char)(c + 32) << endl;  // b（大写变小写）
    char d = 'm';
    cout << (char)(d - 32);          // M（小写变大写）
    return 0;
}
```
<!-- end-demo -->

## 卡片：字符数组

<!-- card type:teacher -->
🧑‍🏫 `char a[] = "mike";` 就是一排装字母的柜子。

电脑会自动在末尾加一个看不见的小旗子 `'\0'`（ASCII 码 0），表示"字符串到此结束" 🚩

所以 "mike" 有 4 个字母，却占了 **5 个格子**！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char a[] = "mike";       // 自动加 \0，共 5 格
    cout << a << endl;        // mike
    cout << a[1] << endl;     // i
    cout << (int)a[4];        // 0（小旗子 \0）
    return 0;
}
```
<!-- end-demo -->

## 卡片：一格一格装

<!-- card type:teacher -->
🧑‍🏫 除了用 `"mike"` 一整串装柜，还可以一格一格亲手装：

`char a[5] = {'m', 'i', 'k', 'e', '\0'};`

⚠️ 亲手装时，最后一格一定要放上小旗子 `'\0'`！忘了它，电脑不知道在哪儿停，会读出乱码 👻
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char a[5] = {'m', 'i', 'k', 'e', '\0'};
    cout << a << endl;      // mike
    cout << strlen(a);      // 4
    return 0;
}
```
<!-- end-demo -->

## 卡片：读入字符串

<!-- card type:teacher -->
🧑‍🏫 两种读法要分清：

- `cin >> s`：读到空格就停，适合读一个单词
- `cin.getline(s, 100)`：读**一整行**，空格也能读进来
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char s[100];
    cin.getline(s, 100);   // 输入 hi c++
    cout << s << endl;        // hi c++（空格也在）
    return 0;
}
```
<!-- end-demo -->

## 卡片：量长度比大小

<!-- card type:teacher -->
🧑‍🏫 两个小助手函数：

- `strlen(s)`：数有几个字符（不含 `\0`）
- `strcmp(a, b)`：比**字典序**——像查词典一样，一个字母一个字母比大小；负数 a 小、0 相等、正数 a 大
- 它只给"谁大谁小"，想知道具体差多少？得自己一个字母一个字母去减 🔢
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char a[] = "apple", b[] = "banana";
    cout << strlen(a) << endl;     // 5
    if (strcmp(a, b) < 0) cout << "a 排前面";
    return 0;
}
```
<!-- end-demo -->

## 卡片：接尾巴抄作业

<!-- card type:teacher -->
🧑‍🏫 还有两个小助手函数：

- `strcat(a, b)`：把 b **接**到 a 的尾巴上
- `strcpy(a, b)`：把 b 整个**抄**进 a，连小旗子 `\0` 一起抄

⚠️ a 的柜子要够大，不然新内容装不下！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char a[20] = "hello";
    strcat(a, " world");   // 接到尾巴上
    cout << a << endl;          // hello world
    return 0;
}
```
<!-- end-demo -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char a[20] = "hello";
    strcpy(a, "hi");      // a 被整个抄成 hi
    cout << a << endl;         // hi
    cout << strlen(a);    // 2（旧内容被盖掉了）
    return 0;
}
```
<!-- end-demo -->

## 卡片：sizeof 数格子

<!-- card type:teacher -->
🧑‍🏫 GESP 高频考点 ⭐ `strlen` 和 `sizeof` 长得像，本领完全不同：

- `strlen(a)`：数小旗子 `\0` **之前**有几个字符（货物数）
- `sizeof(a)`：数柜子**一共**有几个格子（定义时分的总字节数）

`char a[10] = "hi"`：货物 2 件，格子 10 个！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char a[10] = "hello";
    cout << strlen(a) << endl;  // 5（货物数）
    cout << sizeof(a);          // 10（格子总数）
    return 0;
}
```
<!-- end-demo -->

## 卡片：亲手数长度

<!-- card type:teacher -->
🧑‍🏫 不用 strlen，我们也能自己数长度：

准备计数器，从 0 号格开始一格一格往后看，看到小旗子 `\0` 就停下 ✋

不靠小旗子谁也数不清——这就是 `\0` 的厉害之处！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char s[] = "apple";
    int len = 0;
    while (s[len] != '\0') len++;
    cout << len;   // 5
    return 0;
}
```
<!-- end-demo -->

## 卡片：大小写变身

<!-- card type:teacher -->
🧑‍🏫 变身魔法两兄弟 ✨

- `tolower('A')` 变 `'a'`：大写变小写
- `toupper('b')` 变 `'B'`：小写变大写

不是字母的字符交给它们，会原样还回来，不用担心！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    cout << (char)tolower('B') << endl;  // b
    cout << (char)toupper('m') << endl;  // M
    cout << (char)tolower('5');          // 5（不是字母，原样返回）
    return 0;
}
```
<!-- end-demo -->

## 卡片：五个小侦探

<!-- card type:teacher -->
🧑‍🏫 五个小侦探打听字符身份 🕵️ 答"是"返回 true，"不是"返回 false：

- `isalpha(c)` 是字母吗、`isdigit(c)` 是数字吗
- `isupper(c)` 是大写吗、`islower(c)` 是小写吗
- `isspace(c)` 是空格或换行吗

不用背拼写，用的时候翻回来查就行！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char s[] = "HeLLo";
    for (int i = 0; s[i] != '\0'; i++)
        if (isupper(s[i])) s[i] = tolower(s[i]);
    cout << s << endl;   // hello
    return 0;
}
```
<!-- end-demo -->

## 卡片：字母绕圈走

<!-- card type:teacher -->
🧑‍🏫 恺撒密码：把每个字母**向后挪 k 格**，挪过 `'z'` 就从 `'a'` 重新绕圈 🎡

秘诀公式：`(c - 'a' + k) % 26 + 'a'`

- `- 'a'`：先把字母变成 0~25 的号码
- `+ k` 再 `% 26`：挪 k 格，超过 25 就绕回 0
- `+ 'a'`：把号码变回字母
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char c = 'y';
    int k = 3;
    cout << (char)((c - 'a' + k) % 26 + 'a');  // b（y→z→a→b）
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：统计字母数字

<!-- card type:computer -->
🖥️ 输入一行字符串（可能含空格），统计大写字母、小写字母、数字各有多少个。

**输入样例：** `Hello 123`

**输出样例：** `1 4 3`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
char s[1005];
int main() {
    cin.getline(s, 1005);
    int up = 0, lo = 0, dig = 0;
    for (int i = 0; s[i] != '\0'; i++)
        if (isupper(s[i])) up++;
        else if (islower(s[i])) lo++;
        else if (isdigit(s[i])) dig++;
    cout << up << " " << lo << " " << dig << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 用 `cin.getline` 读含空格的一整行
- 遍历字符数组，用 `isupper` / `islower` / `isdigit` 分类计数

**解题思路分步说明**

1. 用 `cin.getline` 把整行读进字符数组 `s`。
2. 准备三个计数器 `up`、`lo`、`dig`，从 0 开始。
3. 循环看每个字符：是大写 `up++`，是小写 `lo++`，是数字 `dig++`。
4. 循环条件 `s[i] != '\0'`：碰到结束小旗子就停。

**容易错的地方**

- 用 `cin >> s` 读入，空格后的内容全丢了
- 循环条件写成 `i < 1005`：没读到的格子都是 `'\0'`，虽然不会数错，但白白多转上千圈；用 `s[i] != '\0'` 看到小旗子就停才聪明
- 忘记把计数器初始化为 0

**关键代码解释**

```cpp
for (int i = 0; s[i] != '\0'; i++)
```

- `i` 是柜子编号，从 0 开始一格一格往后看
- 看到小旗子 `'\0'` 就说明字符串看完了，循环结束
<!-- end-card -->

## 挑战 2：字符串比大小

<!-- card type:computer -->
🖥️ 输入两个不含空格的字符串，比较它们的字典序：前面的小输出 `<`，相等输出 `=`，前面的大输出 `>`。

**输入样例：** `apple banana`

**输出样例：** `<`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
char a[105], b[105];
int main() {
    cin >> a >> b;
    int r = strcmp(a, b);
    if (r < 0) cout << "<" << endl;
    else if (r == 0) cout << "=" << endl;
    else cout << ">" << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- `strcmp` 比较两个字符串的字典序
- 字典序：一个字母一个字母比 ASCII 码，像查词典一样

**解题思路分步说明**

1. 两个字符串都不含空格，用 `cin >> a >> b` 读入。
2. 调用 `strcmp(a, b)`，把结果存进 `r`。
3. `r < 0` 说明 a 小，`r == 0` 说明相等，`r > 0` 说明 a 大，分别输出 `<`、`=`、`>`。

**容易错的地方**

- 把返回值的含义记反：负数是 **a 小**，不是 a 大
- 直接用 `a < b` 比较字符数组，这样比的是地址不是内容，必须用 `strcmp`
- 数组开太小，题目说 100 以内就开 `a[105]` 才保险

**关键代码解释**

```cpp
int r = strcmp(a, b);
```

- 电脑从 0 号格开始逐格比较 a 和 b 的字母
- 遇到第一对不同的字母就分出胜负，返回正负数
<!-- end-card -->
