## 卡片：char 密码表

<!-- card type:teacher -->
🧑‍🏫 每个字符在电脑里都是一个数字，对照表叫 **ASCII 码** 🔢

记住三组就够：`'0'` 是 48、`'A'` 是 65、`'a'` 是 97，同组的字符号码是连续的。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char c = 'A';
    cout << c << endl;        // A
    cout << (int)c << endl;   // 65（它的密码）
    cout << (char)(c + 2);    // C（65+2=67）
    return 0;
}
```
<!-- end-demo -->

## 卡片：字符数组

<!-- card type:teacher -->
🧑‍🏫 `char a[] = "mike";` 就是一排装字母的柜子。

电脑会自动在末尾加一个看不见的小旗子 `'\0'`（ASCII 码 0），表示"字符串到此结束" 🚩

所以 "mike" 有 4 个字母，却占了 **5 个格子**！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char a[] = "mike";       // 自动加 \0，共 5 格
    cout << a << endl;        // mike
    cout << a[1] << endl;     // i
    cout << (int)a[4];        // 0（小旗子 \0）
    return 0;
}
```
<!-- end-demo -->

## 卡片：读入字符串

<!-- card type:teacher -->
🧑‍🏫 两种读法要分清：

- `cin >> s`：读到空格就停，适合读一个单词
- `cin.getline(s, 100)`：读**一整行**，空格也能读进来
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char s[100];
    cin.getline(s, 100);   // 输入 hi c++
    cout << s << endl;        // hi c++（空格也在）
    return 0;
}
```
<!-- end-demo -->

---

## 卡片：常用小助手

<!-- card type:teacher -->
🧑‍🏫 四个小助手函数：

- `strlen(s)`：数有几个字符（不含 `\0`）
- `strcat(a, b)`：把 b 接到 a 的尾巴上
- `strcpy(a, b)`：把 b 整个抄进 a
- `strcmp(a, b)`：比字典序，负数 a 小、0 相等、正数 a 大
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char a[] = "apple", b[] = "banana";
    cout << strlen(a) << endl;     // 5
    if (strcmp(a, b) < 0) cout << "a 排前面";
    return 0;
}
```
<!-- end-demo -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char a[20] = "hello";
    strcat(a, " world");   // 接到尾巴上
    cout << a << endl;          // hello world
    return 0;
}
```
<!-- end-demo -->

## 卡片：大小写变身

<!-- card type:teacher -->
🧑‍🏫 变身魔法与侦探工具 🕵️

- `tolower('A')` 变 `'a'`，`toupper('b')` 变 `'B'`
- `isupper(c)`、`islower(c)`、`isdigit(c)`：打听字符是哪种身份
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char s[] = "HeLLo";
    for (int i = 0; s[i] != '\0'; i++)
        if (isupper(s[i])) s[i] = tolower(s[i]);
    cout << s << endl;   // hello
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：统计字母数字

<!-- card type:computer -->
🖥️ 输入一行字符串（可能含空格），统计大写字母、小写字母、数字各有多少个。

**输入样例：** `Hello 123`

**输出样例：** `1 4 3`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
char s[1005];
int main() {
    cin.getline(s, 1005);
    int up = 0, lo = 0, dig = 0;
    for (int i = 0; s[i] != '\0'; i++)
        if (isupper(s[i])) up++;
        else if (islower(s[i])) lo++;
        else if (isdigit(s[i])) dig++;
    cout << up << " " << lo << " " << dig << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 用 `cin.getline` 读含空格的一整行
- 遍历字符数组，用 `isupper` / `islower` / `isdigit` 分类计数

**解题思路分步说明**

1. 用 `cin.getline` 把整行读进字符数组 `s`。
2. 准备三个计数器 `up`、`lo`、`dig`，从 0 开始。
3. 循环看每个字符：是大写 `up++`，是小写 `lo++`，是数字 `dig++`。
4. 循环条件 `s[i] != '\0'`：碰到结束小旗子就停。

**容易错的地方**

- 用 `cin >> s` 读入，空格后的内容全丢了
- 循环条件写成 `i < 1005`，会把空格后面的垃圾也数进去
- 忘记把计数器初始化为 0

**关键代码解释**

```cpp
for (int i = 0; s[i] != '\0'; i++)
```

- `i` 是柜子编号，从 0 开始一格一格往后看
- 看到小旗子 `'\0'` 就说明字符串看完了，循环结束
<!-- end-card -->

## 挑战 2：字符串比大小

<!-- card type:computer -->
🖥️ 输入两个不含空格的字符串，比较它们的字典序：前面的小输出 `<`，相等输出 `=`，前面的大输出 `>`。

**输入样例：** `apple banana`

**输出样例：** `<`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
char a[105], b[105];
int main() {
    cin >> a >> b;
    int r = strcmp(a, b);
    if (r < 0) cout << "<" << endl;
    else if (r == 0) cout << "=" << endl;
    else cout << ">" << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- `strcmp` 比较两个字符串的字典序
- 字典序：一个字母一个字母比 ASCII 码，像查词典一样

**解题思路分步说明**

1. 两个字符串都不含空格，用 `cin >> a >> b` 读入。
2. 调用 `strcmp(a, b)`，把结果存进 `r`。
3. `r < 0` 说明 a 小，`r == 0` 说明相等，`r > 0` 说明 a 大，分别输出 `<`、`=`、`>`。

**容易错的地方**

- 把返回值的含义记反：负数是 **a 小**，不是 a 大
- 直接用 `a < b` 比较字符数组，这样比的是地址不是内容，必须用 `strcmp`
- 数组开太小，题目说 100 以内就开 `a[105]` 才保险

**关键代码解释**

```cpp
int r = strcmp(a, b);
```

- 电脑从 0 号格开始逐格比较 a 和 b 的字母
- 遇到第一对不同的字母就分出胜负，返回正负数
<!-- end-card -->

## 小贴士

<!-- card type:tip -->
💡 数组要比字符串长度多留格子：`char a[5] = "hello";` 是错的，"hello" 加 `\0` 要 6 格！

💡 含空格的整行输入用 `cin.getline(s, 大小)`，只读一个单词才用 `cin >> s`。
