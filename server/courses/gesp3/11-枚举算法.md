> 🎯 目标：认识算法的三种描述方式（自然语言、流程图、伪代码），学会枚举法——把所有可能的答案排好队逐个检查，会定对象、范围和验证条件。

## 卡片：算法的三种说法

<!-- card type:teacher -->
🧑‍🏫 算法就是解题的步骤。把步骤"说"出来，有三种说法 🗣️

- **自然语言**：用大白话把步骤说清楚
- **流程图**：用图形框画出步骤的走向
- **伪代码**：像代码又不是代码的"草稿"

伪代码长这样（找 n 的因数）：

    读入 n
    让 i 从 1 数到 n：
        如果 n 能被 i 整除，就输出 i

GESP 的选择、判断题经常考认流程图，一定要会读！
<!-- end-card -->

---

## 卡片：流程图怎么读

<!-- card type:teacher -->
🧑‍🏫 流程图里的框各有分工 📦

- 圆角框：开始 / 结束
- 矩形框：处理步骤（计算、赋值）
- 菱形框：判断，分出"是"和"否"两个出口
- 箭头：指出执行的先后顺序

比如"判断一个数是不是偶数"：

```
( 开始 ) → [ 读入 n ] → < n%2==0? > —是→ 输出"偶数" → ( 结束 )
                               ↓ 否
                          输出"奇数"
```
<!-- end-card -->

## 卡片：什么是枚举

<!-- card type:teacher -->
🧑‍🏫 枚举法 = **所有可能排成队，一个一个来检查** ✅

符合要求的留下，不符合的扔掉。办法虽然"笨"，但电脑速度快，不怕试！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int i = 1; i <= 100; i++)   // 每个数都试试
        if (i % 3 == 0) cout << i << " ";  // 是 3 的倍数就留下
    return 0;
}
```
<!-- end-demo -->

## 卡片：枚举三要素

<!-- card type:teacher -->
🧑‍🏫 写枚举前先想清楚三件事 📋

1. **对象**：谁是候选答案？（比如每个整数 `i`）
2. **范围**：从哪里试到哪里？（比如 1~n）
3. **条件**：满足什么才算对？（比如 `n % i == 0`）
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++)           // 范围：1~n
        if (n % i == 0) cout << i << " ";  // 条件：能整除
    return 0;
}
```
<!-- end-demo -->

## 卡片：边界怎么定

<!-- card type:teacher -->
🧑‍🏫 范围要**刚刚好**：漏了会丢答案，太大会浪费时间 ⏰

找 1000 以内的完全平方数：因为 31×31=961、32×32=1024，所以 `i` 试到 31 就够，不用试 1000 个数！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int i = 1; i * i <= 1000; i++)  // i*i 超 1000 就停
        cout << i * i << " ";
    return 0;
}
```
<!-- end-demo -->

## 卡片：双层枚举

<!-- card type:teacher -->
🧑‍🏫 一个问题里有**两个**未知量？那就套两层 `for`！

外层每走一步，内层完整跑一圈，每种搭配都不放过 🤝
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int a = 1; a <= 3; a++)       // 十位
        for (int b = 1; b <= 3; b++)   // 个位
            cout << a * 10 + b << " "; // 11 12 13 21 ...
    return 0;
}
```
<!-- end-demo -->

## 卡片：枚举数组下标

<!-- card type:teacher -->
🧑‍🏫 枚举的不一定是"数字"——数组每个格子都有编号（下标）🗂️

把**下标**当候选答案来枚举，就能在数组里"按条件找出住在几号柜"！比如找出所有大于 0 的数在几号。

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[6] = {0, 5, -3, 0, 8, -1};
    for (int i = 1; i <= 5; i++)        // 枚举下标 1~5
        if (a[i] > 0) cout << i << " ";  // 正数在几号：1 4
    return 0;
}
```
<!-- end-demo -->

## 卡片：电脑有多快

<!-- card type:teacher -->
🧑‍🏫 电脑 1 秒钟大约能算 **1 亿次（10⁸ 次）**操作，这是竞赛的"超时红线" ⚡

一次加法、一次比较，大约各算 1 次操作。题目一般要求 1 秒内跑完，跑不完就叫**超时**，裁判会直接判错！

枚举前先估算循环一共要跑多少次：

| 循环层数 | 总次数 | n 大约能到 |
|---|---|---|
| 一重 | n | 1 亿 |
| 两重 | n×n | 1 万 |
| 三重 | n×n×n | 500 |

超过 1 亿次就可能超时，得想办法缩小范围！
<!-- end-card -->

## 卡片：剪枝小妙招

<!-- card type:teacher -->
🧑‍🏫 **剪枝**：枚举时提前跳过不可能是答案的情况 ✂️

就像给果树剪掉结不出果子的枝条，省得白浇水！比如找 a+b+c=100 的组合：定了 a 和 b，c 直接算出来，第三层循环就剪掉了。

示范代码里 `b` 从 `a` 开始、还要求 `c >= b`：这是让 a≤b≤c——3+5+92 和 5+3+92 是同一种分法，只数一次，不重复！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int a = 1; a <= 100; a++)
        for (int b = a; b <= 100; b++) {   // b 从 a 开始，不回头
            int c = 100 - a - b;    // c 直接算，剪掉一层循环
            if (c >= b) cout << a << " " << b << " " << c << endl;   // a≤b≤c 不重复
        }
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：水仙花数

<!-- card type:computer -->
🖥️ 水仙花数是这样的三位数：每位数字的立方和等于它本身（比如 153 = 1³+5³+3³）。

输出所有水仙花数，每行一个。（本题没有输入）

**输出样例（前两行）：** `153` 换行 `370`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int n = 100; n <= 999; n++) {
        int a = n / 100, b = n / 10 % 10, c = n % 10;
        if (a*a*a + b*b*b + c*c*c == n)
            cout << n << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 单层枚举：把 100~999 的每个三位数都检查一遍
- 数位拆解：`n / 100` 取百位，`n / 10 % 10` 取十位，`n % 10` 取个位

**解题思路分步说明**

1. 枚举对象：每个三位数 `n`；范围：100~999。
2. 拆出百位 `a`、十位 `b`、个位 `c`。
3. 验证条件：三个立方加起来等于 `n`，就输出。

**容易错的地方**

- 范围写成 `n < 999`，漏掉了对 999 的检查（虽然 999 不是水仙花数，但习惯上要把范围包全）
- 十位写错：是 `n / 10 % 10`，先除 10 再取余，别写成 `n % 10 / 10`

**关键代码解释**

```cpp
int a = n / 100, b = n / 10 % 10, c = n % 10;
```

- 整数除法会丢掉小数部分：`153 / 100` 得 1
- `153 / 10` 得 15，再 `% 10` 得 5，十位就到手了
<!-- end-card -->

## 挑战 2：百钱百鸡

<!-- card type:computer -->
🖥️ 100 文钱买 100 只鸡：公鸡 5 文一只，母鸡 3 文一只，小鸡 1 文买 3 只。

每种鸡至少买 1 只，请输出所有买法：每行 `公鸡数 母鸡数 小鸡数`。

**输出样例（第一行）：** `4 18 78`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int x = 1; x <= 19; x++)
        for (int y = 1; y <= 32; y++) {
            int z = 100 - x - y;
            if (z > 0 && z % 3 == 0 && 5*x + 3*y + z/3 == 100)
                cout << x << " " << y << " " << z << endl;
        }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 双层枚举：公鸡、母鸡两个未知量套两层循环
- 边界设计：公鸡最多 19 只（买 20 只就花光 100 文了），母鸡最多 32 只

**解题思路分步说明**

1. 枚举公鸡 `x`（1~19）、母鸡 `y`（1~32）。
2. 小鸡直接算：`z = 100 - x - y`，省掉一层循环。
3. 验证三条：`z > 0`、`z` 是 3 的倍数、总钱数正好 100。

**容易错的地方**

- 小鸡数量 `z` 必须是 3 的倍数（1 文买 3 只，不能拆开买）
- 忘记每种鸡至少 1 只：循环从 0 开始会多出错解
- 边界随手写：x 试到 100 也能对，但又慢又不专业，要养成算边界的习惯

**关键代码解释**

```cpp
int z = 100 - x - y;
```

- 总共 100 只鸡，定了公鸡和母鸡，小鸡就被"算"出来了
- 三层循环变两层，608 次尝试就搞定，又快又清楚
<!-- end-card -->

## 小贴士

<!-- card type:tip -->
💡 枚举第一原则：**宁可多试，不能漏掉**，范围一定要把答案包进去！

💡 能算出来的就别枚举：小鸡 `z = 100 - x - y` 直接算，少一层循环快很多。

💡 提前跳过不可能的答案，有个正式名字叫**剪枝**——剪得越多，程序跑得越快！
