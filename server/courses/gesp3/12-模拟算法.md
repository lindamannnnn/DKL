## 故事：蜗牛爬竹竿

<!-- story -->
一只蜗牛要爬 10 米高的竹竿：白天爬 3 米，晚上滑下 2 米，爬到顶就胜利！

几天能到顶？小柯不列算式，他在纸上"演"：第 1 天到 3 米、滑到 1 米；第 2 天到 4 米、滑到 2 米……

让电脑照着规则也"演"一遍——这就是**模拟算法** 🎬

## 卡片：什么是模拟

<!-- card type:teacher -->
🧑‍🏫 模拟 = 程序当演员，题目规则是剧本 🎭

每走一步就更新一次"现场情况"，演到最后，答案自然出现。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int hp = 10, cnt = 0;      // 小怪血量、出刀次数
    while (hp > 0) { hp -= 3; cnt++; }  // 每刀砍 3 点
    cout << cnt << endl;       // 4 刀解决
    return 0;
}
```
<!-- end-demo -->

## 卡片：模拟三要素

<!-- card type:teacher -->
🧑‍🏫 模拟也要先想清楚三件事 📋

1. **状态**：现在是什么样？用变量记下来
2. **转移**：每一步按规则怎么变？
3. **终止**：什么情况下停下来？
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int pos = 0, day = 0;                  // 状态：位置、天数
    while (pos < 10) { day++; pos += 3; }  // 转移 + 终止判断
    cout << day << endl;                   // 4 天到顶
    return 0;
}
```
<!-- end-demo -->

## 卡片：按指令走路

<!-- card type:teacher -->
🧑‍🏫 机器人听指令走路：坐标是状态，每条指令是一次转移 🤖

读完一条指令就改一次坐标，读完全部指令就知道终点啦。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x = 1;                 // 从 1 号格出发
    string s = "RRL";          // 指令：右、右、左
    for (int i = 0; i < (int)s.size(); i++)
        x += (s[i] == 'R' ? 1 : -1);
    cout << x << endl;         // 停在 2 号格
    return 0;
}
```
<!-- end-demo -->

## 卡片：数组记状态

<!-- card type:teacher -->
🧑‍🏫 演员太多，一个变量记不住？请数组帮忙！🗄️

发牌游戏里，`a[1]`、`a[2]`、`a[3]` 分别记 3 个人各拿到几张牌。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[4] = {0};            // 3 个人的牌数
    for (int c = 1; c <= 7; c++)
        a[(c - 1) % 3 + 1]++;  // 轮流发给 1~3 号
    cout << a[1] << a[2] << a[3] << endl;  // 322
    return 0;
}
```
<!-- end-demo -->

## 卡片：围圈报数

<!-- card type:teacher -->
🧑‍🏫 报数出圈游戏：n 个人围成一圈，数到 m 的人出局，谁留到最后？🥁

两大法宝：

1. `alive[]` 数组当"名牌"：`true` 表示还在圈里，`false` 表示已出局
2. 环形下标 `cur = (cur + 1) % n`：走到队尾自动绕回队首，队伍就像一张圆形餐桌，头尾相接！
3. 为了配合 `%` 绕圈，代码里人从 0 号数起，输出时再 `+1` 变回我们的编号。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    bool alive[6]; int cur = 0, cnt = 0, left = 5;
    for (int i = 0; i < 5; i++) alive[i] = true;   // 5 人都在圈里（从 0 号数起）
    while (left > 1) {
        if (alive[cur]) cnt++;                     // 活着的人才报数
        if (cnt == 3) { alive[cur] = false; left--; cnt = 0; }   // 数到 3 出局
        cur = (cur + 1) % 5;                       // 队尾绕回队首
    }
    for (int i = 0; i < 5; i++) if (alive[i]) { cout << i + 1 << endl; return 0; }   // 4 号
}
```
<!-- end-demo -->

## 挑战 1：蜗牛爬竿

<!-- card type:computer -->
🖥️ 蜗牛爬 `h` 米高的竹竿：白天爬 `u` 米，晚上滑下 `d` 米；如果白天已经爬到顶，当晚就不再滑。输入 `h u d`，输出第几天到顶。

**输入样例：** `10 3 2`

**输出样例：** `8`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int h, u, d;
    cin >> h >> u >> d;
    int pos = 0, day = 0;
    while (pos < h) {
        day++; pos += u;
        if (pos < h) pos -= d;
    }
    cout << day << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 模拟三要素：状态是 `pos` 和 `day`，转移是白天 +u、晚上 -d，终止是 `pos >= h`
- 用 `while` 循环一天一天往下演

**解题思路分步说明**

1. 只要 `pos < h` 就继续演：`day` 加 1，白天位置加 `u`。
2. 白天爬到顶（`pos >= h`）就结束了，当晚不能再滑。
3. 没到顶才滑下 `d` 米，进入下一天。

**容易错的地方**

- 爬到顶还滑：第 8 天白天到 10 米就结束了，再滑 2 米答案就错了，所以用 `if (pos < h)` 守住
- 把 `day++` 写到循环外面，天数少算一天

**关键代码解释**

```cpp
if (pos < h) pos -= d;
```

- 这行是"终止条件"的具体落实：到顶就不滑
- 顺序不能反：先爬、再判断、最后才滑
<!-- end-card -->

## 挑战 2：机器人走方格

<!-- card type:computer -->
🖥️ 机器人在 `n×m` 方格里，从第 1 行第 1 列出发，按指令移动：U=上、D=下、L=左、R=右。指令会撞墙就原地不动。输出最终位置（行 列）。

**输入样例：** `5 5` 换行 `RRDDUULL`

**输出样例：** `1 1`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, m, x = 1, y = 1; string s; cin >> n >> m >> s;
    for (int i = 0; i < (int)s.size(); i++) {
        if (s[i] == 'U' && x > 1) x--;   // 上
        if (s[i] == 'D' && x < n) x++;   // 下
        if (s[i] == 'L' && y > 1) y--;   // 左
        if (s[i] == 'R' && y < m) y++;   // 右
    }
    cout << x << " " << y << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 模拟按指令移动：坐标 `x y` 是状态，每条指令是一次转移
- 边界判断：撞墙时指令作废、原地不动

**解题思路分步说明**

1. 状态：行 `x`、列 `y`，都从 1 开始。
2. 逐条读指令：U 让行减 1、D 让行加 1、L 让列减 1、R 让列加 1。
3. 每次移动前先查边界：比如 U 要求 `x > 1` 才能动。

**容易错的地方**

- 行和列搞混：上下动的是行 `x`，左右动的是列 `y`
- 忘记判断撞墙，坐标变成 0 或者超过 n、m
- 把 U 的"上"写成 `x++`：行号越小越靠上，所以上是 `x--`

**关键代码解释**

```cpp
if (s[i] == 'U' && x > 1) x--;
```

- `&&` 两边都满足才移动：是指令 U，并且没贴着上边墙
- 四个方向各写一句，清楚又不容易错
<!-- end-card -->

## 卡片：方向数组

<!-- card type:teacher -->
🧑‍🏫 上下左右要写四个 if？太累啦！把四个方向装进两个数组 🎒

`dx` 存行的变化、`dy` 存列的变化，再给方向编个号（0 右、1 下、2 左、3 上），选几号方向就走哪边——像遥控器选台一样方便！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int dx[4] = {0, 1, 0, -1};   // 0右 1下 2左 3上 的行变化
    int dy[4] = {1, 0, -1, 0};   // 0右 1下 2左 3上 的列变化
    int x = 1, y = 1, dir = 1;   // 在 (1,1)，选 1 号方向"下"
    x += dx[dir]; y += dy[dir];  // 一行代码走一格，不用写四个 if
    cout << x << " " << y << endl;   // 2 1：向下走了一格
    return 0;
}
```
<!-- end-demo -->
