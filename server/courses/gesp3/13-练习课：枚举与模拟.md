## 本课练习要点

<!-- card type:teacher -->
🧑‍🏫 这节课不学新知识，重点复习两大算法：

- **枚举三要素**：对象（谁候选）、范围（从哪到哪）、条件（怎样算对）
- **枚举技巧**：范围算准别浪费，能算的变量直接算
- **模拟三要素**：状态（变量记现状）、转移（按规则变）、终止（何时停）
- **模拟技巧**：撞墙判断放前面，最后一步要当心

练习时注意：
1. 先写出三要素，再动手写代码
2. 双重循环别慌：外层走一步，内层跑一圈
3. 模拟题先拿样例在纸上"演"一遍，再对照代码
<!-- end-card -->

## 挑战 1：找因数

<!-- card type:computer -->
🖥️ 输入正整数 `n`，从小到大输出它的所有因数，用空格分隔。

**输入样例：** `12`

**输出样例：** `1 2 3 4 6 12`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++)
        if (n % i == 0) cout << i << " ";
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 单层枚举：对象是 `i`，范围 1~n，条件 `n % i == 0`

**解题思路分步说明**

1. 读入 `n`。
2. `i` 从 1 试到 n，每个都当候选因数。
3. 能整除 `n` 的就是因数，立刻输出。

**容易错的地方**

- 范围写成 `i < n`，漏掉 `n` 本身（n 一定是自己的因数）
- 忘记数字之间要输出空格

**关键代码解释**

```cpp
if (n % i == 0) cout << i << " ";
```

- `%` 是取余数，余数为 0 说明正好整除
- 找到就输出，不用存起来，枚举就是这么干脆
<!-- end-card -->

## 挑战 2：银行叫号

<!-- card type:computer -->
🖥️ 银行有 `n` 位顾客排队，第 i 位办业务要 `t` 分钟。柜员从 0 时刻起连续服务，输出每位顾客办完业务的时刻，每行一个。

**输入样例：** `3` 换行 `5 3 8`

**输出样例：** `5` 换行 `8` 换行 `16`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, t = 0; cin >> n;
    for (int i = 1; i <= n; i++) {
        int x; cin >> x;
        cout << (t += x) << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 模拟过程：状态是"当前时刻" `t`，每位顾客服务完就更新一次
- 边读边算，不用数组也能模拟

**解题思路分步说明**

1. 状态 `t = 0`：柜台从 0 时刻开工。
2. 每读一个顾客的服务时间 `x`，就把 `t` 加上 `x`。
3. 加完之后的 `t` 就是这位顾客办完的时刻，直接输出。

**容易错的地方**

- 先输出再加：`t` 要先 `+= x` 再输出，顺序反了会少算当前这位
- `t` 忘记初始化为 0，起手就是一个随机数

**关键代码解释**

```cpp
cout << (t += x) << endl;
```

- `t += x` 是转移：时间往前推进 `x` 分钟
- 括号让"先加再输出"写成一句，拆开写也一样
<!-- end-card -->

## 挑战 3：数字里的 7

<!-- card type:computer -->
🖥️ 输入正整数 `n`，数一数 1~n 里有几个数带有数字 7（比如 7、17、27 都算）。

**输入样例：** `30`

**输出样例：** `3`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, cnt = 0; cin >> n;
    for (int i = 1; i <= n; i++) {
        int x = i; bool has7 = false;
        while (x > 0) { if (x % 10 == 7) has7 = true; x /= 10; }
        if (has7) cnt++;
    }
    cout << cnt << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 双层配合：外层枚举每个数 `i`，内层用 `while` 把 `i` 逐位拆开检查
- 数位拆解：`x % 10` 看个位，`x /= 10` 去掉个位

**解题思路分步说明**

1. 外层枚举：`i` 从 1 到 n，逐个检查。
2. 内层拆解：把 `i` 复制给 `x`，一位一位剥下来看是不是 7。
3. 只要有一位是 7，计数器 `cnt` 就加 1。

**容易错的地方**

- 直接拆 `i`：`i /= 10` 会把循环变量毁掉，要复制给 `x` 再拆
- 找到 7 还继续计数：一个数只算一次，用 `has7` 标记最稳

**关键代码解释**

```cpp
while (x > 0) { if (x % 10 == 7) has7 = true; x /= 10; }
```

- 每圈干两件事：检查个位、去掉个位
- `x` 变成 0 说明所有位都检查完了
<!-- end-card -->

## 挑战 4：轮流发牌

<!-- card type:computer -->
🖥️ `n` 张牌（编号 1~n）按顺序轮流发给 `m` 个人，每人每次 1 张，发完为止。输出每个人各拿到几张牌，空格分隔。

**输入样例：** `7 3`

**输出样例：** `3 2 2`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int a[105];
int main() {
    int n, m; cin >> n >> m;
    for (int c = 1; c <= n; c++) a[(c - 1) % m + 1]++;
    for (int i = 1; i <= m; i++) cout << a[i] << " ";
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 用数组记状态：`a[i]` 表示第 `i` 个人拿到几张牌
- 模拟轮流动作：`(c - 1) % m + 1` 算出第 `c` 张牌发给谁

**解题思路分步说明**

1. 状态：数组 `a`，一开始全是 0（写在 `main` 外面自动清 0）。
2. 转移：第 `c` 张牌发给 `(c - 1) % m + 1` 号，对应格子加 1。
3. 发完 `n` 张后，把 `a[1]` 到 `a[m]` 依次输出。

**容易错的地方**

- 直接用 `c % m`：第 3、6 张会算成 0 号，而题目人从 1 号开始数
- 数组开在 `main` 里面又不清零，牌数会混入随机值

**关键代码解释**

```cpp
a[(c - 1) % m + 1]++;
```

- `(c - 1) % m` 得到 0~m-1 的循环序号，加 1 正好对上 1~m 号
- 一张牌对应一次 `++`，发牌过程就演完了
<!-- end-card -->

## 挑战 5：弹球反弹

<!-- card type:computer -->
🖥️ 小球在 1~n 号格子间运动，从 `p` 号格出发，每步走 `v` 格；越过两端就反弹（比如从 10 号格走出 13，会弹回 7 号格）。输入 `n p v t`，走 `t` 步后小球在几号格？

**输入样例：** `10 8 5 1`

**输出样例：** `7`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, p, v, t; cin >> n >> p >> v >> t;
    int dir = 1;
    for (int i = 0; i < t; i++) {
        p += dir * v;
        if (p > n) { p = 2 * n - p; dir = -1; }
        if (p < 1) { p = 2 - p; dir = 1; }
    }
    cout << p << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 模拟三要素：状态是位置 `p` 和方向 `dir`，转移是每步 `p += dir * v`，终止是走完 `t` 步
- 反弹处理：越界后把位置"折回来"，同时方向掉头

**解题思路分步说明**

1. 状态：`p` 记位置，`dir = 1` 表示往右、`-1` 表示往左。
2. 每走一步：`p += dir * v`。
3. 查反弹：`p > n` 就从右边折回 `2 * n - p`、方向变 -1；`p < 1` 就从左边折回 `2 - p`、方向变 1。
4. 走完 `t` 步输出 `p`。

**容易错的地方**

- 反弹后忘记改方向，小球会"穿墙"一直跑
- 折回公式记错：右端是 `2 * n - p`，左端是 `2 - p`，拿样例 `10 8 5 1` 手算验证最保险

**关键代码解释**

```cpp
if (p > n) { p = 2 * n - p; dir = -1; }
```

- 超过 n 多少，就从 n 往回退多少：13 超出 10 三格，退到 7
- 改方向是和折回同样重要的一步，两行缺一不可
<!-- end-card -->

## 小贴士

<!-- card type:tip -->
💡 枚举先写三要素（对象、范围、条件），再套循环；拿不准范围就宁大勿小。

💡 模拟先拿样例在纸上"演"一遍，再对照代码：状态、转移、终止一个都不能少。

💡 数组下标从 1 开始，和题目的"第几个人"一一对齐，最不容易错。
