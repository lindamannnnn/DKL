## 本课练习要点

<!-- card type:teacher -->
🧑‍🏫 这节课不学新知识，重点复习 11、12 课的全部本领，把它们串起来 🔗

- **枚举三种描述**：自然语言、流程图、伪代码（真题常考读流程图）
- **枚举三要素**：对象、范围、条件；**剪枝**提前跳过不可能的答案
- **规模量化**：1 秒约 1 亿次操作，O(n)≤1亿、O(n²)≤1万、O(n³)≤500
- **模拟特征词**："每一步/每一轮""按照规则""重复直到""经过 N 次操作后"
- **约瑟夫围圈报数**：`alive[]` 记谁还在，`(cur+1)%n` 环形绕圈
- **方向数组**：`dx[]/dy[]` 把上下左右装进数组，一行走一格

练习时注意：
1. 先写出三要素，再动手写代码
2. 双重循环别慌：外层走一步，内层跑一圈
3. 模拟题先拿样例在纸上"演"一遍，再对照代码
<!-- end-card -->

## 挑战 1：找因数

<!-- card type:computer -->
🖥️ 输入正整数 `n`，从小到大输出它的所有因数，用空格分隔。

**输入样例：** `12`

**输出样例：** `1 2 3 4 6 12`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++)
        if (n % i == 0) cout << i << " ";
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 单层枚举：对象是 `i`，范围 1~n，条件 `n % i == 0`

**解题思路分步说明**

1. 读入 `n`。
2. `i` 从 1 试到 n，每个都当候选因数。
3. 能整除 `n` 的就是因数，立刻输出。

**容易错的地方**

- 范围写成 `i < n`，漏掉 `n` 本身（n 一定是自己的因数）
- 忘记数字之间要输出空格

**关键代码解释**

```cpp
if (n % i == 0) cout << i << " ";
```

- `%` 是取余数，余数为 0 说明正好整除
- 找到就输出，不用存起来，枚举就是这么干脆
<!-- end-card -->

## 挑战 2：银行叫号

<!-- card type:computer -->
🖥️ 银行有 `n` 位顾客排队，第 i 位办业务要 `t` 分钟。柜员从 0 时刻起连续服务，输出每位顾客办完业务的时刻，每行一个。

**输入样例：** `3` 换行 `5 3 8`

**输出样例：** `5` 换行 `8` 换行 `16`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, t = 0; cin >> n;
    for (int i = 1; i <= n; i++) {
        int x; cin >> x;
        cout << (t += x) << endl;
    }
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 模拟过程：状态是"当前时刻" `t`，每位顾客服务完就更新一次
- 边读边算，不用数组也能模拟

**解题思路分步说明**

1. 状态 `t = 0`：柜台从 0 时刻开工。
2. 每读一个顾客的服务时间 `x`，就把 `t` 加上 `x`。
3. 加完之后的 `t` 就是这位顾客办完的时刻，直接输出。

**容易错的地方**

- 先输出再加：`t` 要先 `+= x` 再输出，顺序反了会少算当前这位
- `t` 忘记初始化为 0，起手就是一个随机数

**关键代码解释**

```cpp
cout << (t += x) << endl;
```

- `t += x` 是转移：时间往前推进 `x` 分钟
- 括号让"先加再输出"写成一句，拆开写也一样
<!-- end-card -->

## 挑战 3：数字里的 7

<!-- card type:computer -->
🖥️ 输入正整数 `n`，数一数 1~n 里有几个数带有数字 7（比如 7、17、27 都算）。

**输入样例：** `30`

**输出样例：** `3`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, cnt = 0; cin >> n;
    for (int i = 1; i <= n; i++) {
        int x = i; bool has7 = false;
        while (x > 0) { if (x % 10 == 7) has7 = true; x /= 10; }
        if (has7) cnt++;
    }
    cout << cnt << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 双层配合：外层枚举每个数 `i`，内层用 `while` 把 `i` 逐位拆开检查
- 数位拆解：`x % 10` 看个位，`x /= 10` 去掉个位

**解题思路分步说明**

1. 外层枚举：`i` 从 1 到 n，逐个检查。
2. 内层拆解：把 `i` 复制给 `x`，一位一位剥下来看是不是 7。
3. 只要有一位是 7，计数器 `cnt` 就加 1。

**容易错的地方**

- 直接拆 `i`：`i /= 10` 会把循环变量毁掉，要复制给 `x` 再拆
- 找到 7 还继续计数：一个数只算一次，用 `has7` 标记最稳

**关键代码解释**

```cpp
while (x > 0) { if (x % 10 == 7) has7 = true; x /= 10; }
```

- 每圈干两件事：检查个位、去掉个位
- `x` 变成 0 说明所有位都检查完了
<!-- end-card -->

## 挑战 4：报数出圈

<!-- card type:computer -->
🖥️ `n` 个人围成一圈，从 1 号开始依次报数 1、2、3…… 数到 3 的人出圈，下一个人重新从 1 报起。输出最后留在圈里的人的编号。

**输入样例：** `5 3`

**输出样例：** `4`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, m; cin >> n >> m;
    int left = n, cur = 0, cnt = 0; bool alive[105];
    for (int i = 0; i < n; i++) alive[i] = true;
    while (left > 1) {
        if (alive[cur]) { cnt++; if (cnt == m) { alive[cur] = false; left--; cnt = 0; } }
        cur = (cur + 1) % n;
    }
    for (int i = 0; i < n; i++) if (alive[i]) { cout << i + 1 << endl; return 0; }
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 约瑟夫围圈：用 `alive[]` 记录谁还在圈里
- 环形下标 `cur = (cur + 1) % n`：走到队尾自动绕回队首
- 为了配合 `%` 绕圈，人从 0 号数起，输出时再 `+1`

**解题思路分步说明**

1. 状态：`alive[i]` 表示第 i 个人（从 0 数起）是否还在；`left` 记剩余人数。
2. 转移：每走到一个活人 `cnt` 加 1；数到 `m` 就让他出圈、`left` 减 1、计数清零。
3. 终止：只剩 1 人时停下，输出他还活着的编号 `+1`。

**容易错的地方**

- 忘记 `% n` 绕圈：走到最后一人不会自动回到开头
- 出圈后没把 `cnt` 清零，下一轮数数会错位
- 直接输出 `cur`：因为从 0 数起，要 `+1` 才是题目里的编号

**关键代码解释**

```cpp
cur = (cur + 1) % n;
```

- `cur + 1` 走到下一个人
- `% n` 让编号在 0~n-1 之间循环，到队尾自动回队首
<!-- end-card -->

## 挑战 5：方向数组走格子

<!-- card type:computer -->
🖥️ 机器人在 `n×m` 网格里站在第 1 行第 1 列，按指令 `'U/D/L/R'`（上/下/左/右）移动，撞墙就不动。用**方向数组** `dx/dy` 实现，输出最后位置（行 列）。

**输入样例：** `5 5` 换行 `RRDDUULL`

**输出样例：** `1 1`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, m, x = 1, y = 1; string s; cin >> n >> m >> s;
    int dx[4] = {0, 1, 0, -1}, dy[4] = {-1, 0, 1, 0};  // 0上1下2右3左
    for (int i = 0; i < (int)s.size(); i++) {
        int d = s[i] == 'U' ? 0 : s[i] == 'D' ? 1 : s[i] == 'R' ? 2 : 3;
        int nx = x + dx[d], ny = y + dy[d];
        if (nx >= 1 && nx <= n && ny >= 1 && ny <= m) { x = nx; y = ny; }
    }
    cout << x << " " << y << endl;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 方向数组：`dx[]` 存行的变化、`dy[]` 存列的变化，方向编号 0上1下2右3左
- 把"上下左右"四个 if 压缩成一行 `x += dx[d]`、`y += dy[d]`

**解题思路分步说明**

1. 状态：行 `x`、列 `y`，都从 1 开始。
2. 把指令字母翻译成方向编号 `d`（U→0，D→1，R→2，L→3）。
3. 用 `dx[d]`、`dy[d]` 算出下一步位置，撞墙（超出 1~n、1~m）就不更新。

**容易错的地方**

- 方向编号和实际变化对不上：上让行减 1，所以 `dx[0] = -1`、`dy[0] = 0`
- 忘记先判断撞墙，坐标冲出网格变成 0 或越界
- 把 U 写成让行加 1：行号越小越靠上，上是 `x - 1`

**关键代码解释**

```cpp
int nx = x + dx[d], ny = y + dy[d];
```

- `d` 决定走哪个方向，`dx[d]`/`dy[d]` 就是这一步的行、列变化量
- 先算出新位置 `nx, ny`，再判断撞墙，安全又清楚
<!-- end-card -->
