## 卡片：什么是进制

<!-- card type:teacher -->
🧑‍🏫 我们平时用的是**十进制**：每位 0~9，满 10 进 1。

电脑用**二进制**：每位只有 0 和 1，满 2 进 1。

还有**八进制**（0~7）和**十六进制**（0~9 加 A~F，A 表示 10，F 表示 15）。

同一个数，换种进制只是换了种"写法"，大小不变！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 255;
    cout << dec << n << endl;  // 255（十进制）
    cout << oct << n << endl;  // 377（八进制）
    cout << hex << n << endl;  // ff（十六进制）
    return 0;
}
```
<!-- end-demo -->

## 卡片：按权展开

<!-- card type:teacher -->
🧑‍🏫 二进制怎么变成十进制？每一位都有自己的**身价**（权）！

从右往左，各位的权依次是 1、2、4、8……（不停乘 2）。

`1011` = 1×8 + 0×4 + 1×2 + 1×1 = **11**，把每位乘上自己的权再加起来就行啦！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s = "1011";   // 一个二进制数
    int r = 0;
    for (char c : s) r = r * 2 + (c - '0');
    cout << r << endl;   // 11
    return 0;
}
```
<!-- end-demo -->

## 卡片：短除法

<!-- card type:teacher -->
🧑‍🏫 十进制怎么变回二进制？用**短除法**：不停除以 2，记下余数。

13 ÷ 2 = 6 余 **1**，6 ÷ 2 = 3 余 **0**，3 ÷ 2 = 1 余 **1**，1 ÷ 2 = 0 余 **1**。

⚠️ 余数要**从下往上**（倒着）读：13 = `1101`！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 13;
    string r = "";
    while (n > 0) { r = (char)('0' + n % 2) + r; n /= 2; }
    cout << r << endl;  // 1101（新余数放最前面）
    return 0;
}
```
<!-- end-demo -->

## 卡片：快速转换

<!-- card type:teacher -->
🧑‍🏫 二进制和八进制、十六进制之间有"近路" 🚀

**3 位二进制 = 1 位八进制**，**4 位二进制 = 1 位十六进制**（因为 2³=8，2⁴=16）。

从右往左分组，每组单独算：`1101 0110` 中 `1101`=D、`0110`=6，合起来就是十六进制 `D6`！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string g = "1101";                 // 4 位二进制一组
    int v = 0;
    for (char c : g) v = v * 2 + (c - '0');
    string d = "0123456789ABCDEF";
    cout << d[v] << endl;              // D
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：十进制转二进制

<!-- card type:computer -->
🖥️ 输入一个正整数 n，输出它的二进制表示。

**输入样例：** `13`

**输出样例：** `1101`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    string r = "";
    while (n > 0) {
        r = (char)('0' + n % 2) + r;
        n /= 2;
    }
    cout << r << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 短除法：不断除以 2 取余数
- 字符串拼接：把新余数放到结果**最前面**

**解题思路分步说明**

1. 读入 n，准备一个空字符串 `r` 装答案。
2. 循环：`n % 2` 得到余数，拼到 `r` 的最前面；再让 `n /= 2`。
3. n 变成 0 时循环结束，输出 `r`。

**容易错的地方**

- 余数拼错方向：写成 `r = r + ...` 得到的就是倒序的 `1011`，必须放最前面
- 余数变字符：`n % 2` 是数字 0/1，要加 `'0'` 才能拼进字符串
- 循环条件写成 `n >= 0` 会死循环，应该是 `n > 0`

**关键代码解释**

```cpp
r = (char)('0' + n % 2) + r;
```

- `'0' + n % 2` 把余数 0/1 变成字符 `'0'`/`'1'`
- 拼在 `r` 的前面，正好实现"余数倒着读"
<!-- end-card -->

## 挑战 2：二进制转十六进制

<!-- card type:computer -->
🖥️ 输入一个二进制字符串（长度是 4 的倍数），输出它的十六进制表示（大写字母）。

**输入样例：** `11010110`

**输出样例：** `D6`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s, d = "0123456789ABCDEF", r = "";
    cin >> s;
    for (int i = 0; i < (int)s.size(); i += 4) {
        int v = 0;
        for (int j = 0; j < 4; j++) v = v * 2 + (s[i + j] - '0');
        r += d[v];
    }
    cout << r << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 4 位二进制对应 1 位十六进制的快速转换
- 双重循环：外层分组，内层算每组的价值

**解题思路分步说明**

1. 外层循环每次跳 4 格，把字符串切成 4 位一组。
2. 内层循环把这 4 位用"乘 2 加当前位"的办法算出一个 0~15 的数 `v`。
3. 用 `d[v]` 查出对应的十六进制字符，拼到答案后面。

**容易错的地方**

- 下标算错：第 i 组的第 j 位是 `s[i + j]`，不是 `s[j]`
- 10~15 要用字母：用 `"0123456789ABCDEF"` 这张"对照表"就不会错
- 内层算价值时忘记 `v * 2`，只加不乘结果全错

**关键代码解释**

```cpp
for (int j = 0; j < 4; j++) v = v * 2 + (s[i + j] - '0');
```

- 从左到右扫这 4 位，每扫一位：`v` 先乘 2，再加上这一位的值
- 4 位扫完，`v` 就是这一组的十进制值（0~15）
<!-- end-card -->
