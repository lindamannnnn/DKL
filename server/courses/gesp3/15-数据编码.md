## 回顾

<!-- card type:teacher -->
🧑‍🏫 进制转换告诉我们：电脑里的一切都是二进制，每位只有 0 和 1。

还记得吗？8 位二进制能表示 2⁸ = 256 种不同的状态，比如 `00000101` 就是 5。
<!-- end-card -->

---

## 卡片：符号位

<!-- card type:teacher -->
🧑‍🏫 电脑用**固定的位数**存整数，比如 8 位。最左边那位叫**符号位**：

**0 表示正数，1 表示负数**，剩下 7 位表示数值大小。

这样存起来的数叫**机器数**，它真正代表的数值叫**真值**。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 5;
    string s = "";
    for (int i = 0; i < 8; i++) { s = (char)('0' + n % 2) + s; n /= 2; }
    cout << s << endl;   // 00000101：符号位 0，是正数 5
    return 0;
}
```
<!-- end-demo -->

## 卡片：原码

<!-- card type:teacher -->
🧑‍🏫 第一种办法叫**原码**：符号位 + 绝对值的二进制，最好懂！

+5 的原码是 `00000101`，-5 的原码是 `10000101`，只差最左边的符号位。

⚠️ 缺点：0 有两种写法（`00000000` 和 `10000000`），而且原码直接做加法会算错！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 5;                            // 数值部分
    string v = "";
    for (int i = 0; i < 7; i++) { v = (char)('0' + n % 2) + v; n /= 2; }
    cout << "0" + v << endl;  // +5 的原码 00000101
    cout << "1" + v << endl;  // -5 的原码 10000101
    return 0;
}
```
<!-- end-demo -->

## 卡片：反码

<!-- card type:teacher -->
🧑‍🏫 第二种办法叫**反码**，规则很简单：

**正数**：反码和原码一样。**负数**：符号位不动，其余每一位 0 变 1、1 变 0！

-5 的原码 `10000101` → 反码 `11111010`（只有最左边的 1 没变）。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string v = "0000101";   // 5 的 7 位数值
    string f = "1";         // 符号位 1 保持不变
    for (char c : v) f += (c == '0' ? '1' : '0');
    cout << f << endl;      // -5 的反码 11111010
    return 0;
}
```
<!-- end-demo -->

## 卡片：补码

<!-- card type:teacher -->
🧑‍🏫 第三种办法叫**补码**，也是电脑真正在用的办法 ⭐

**正数**：补码和原码一样。**负数**：补码 = 反码 + 1！

-5 的反码 `11111010` + 1 → 补码 `11111011`。

神奇的是：+5 和 -5 的补码加起来正好是 `00000000`（多出来的进位扔掉），等于 0，算对了！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string f = "11111010";   // -5 的反码
    int carry = 1;           // 要加 1
    for (int i = 7; i >= 1 && carry; i--) {
        if (f[i] == '0') { f[i] = '1'; carry = 0; } else f[i] = '0';
    }
    cout << f << endl;       // -5 的补码 11111011
    return 0;
}
```
<!-- end-demo -->

## 卡片：补码速推法

<!-- card type:teacher -->
🧑‍🏫 推导负数补码还有第二条路，常常更快 ⚡

从原码**从右往左找第一个 1**：这位不变，它左边的非符号位全部取反，符号位照旧。

推演 -5：原码 `10000101` → 最右边的 1 就是"第一个 1"，它不动；左边的 `000010` 全取反变 `111101` → 补码 `11111011`，和"反码 + 1"算出来一模一样！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int v = 256 - 5;   // 8 位补码里，-5 存的值等于 256 - 5
    string s = "";
    for (int i = 0; i < 8; i++) { s = (char)('0' + v % 2) + s; v /= 2; }
    cout << s << endl;   // 11111011：电脑里 -5 真的是这样存的
    return 0;
}
```
<!-- end-demo -->

## 卡片：补码的本领

<!-- card type:teacher -->
🧑‍🏫 补码有三个超能力，所以全世界的电脑都选它 🦸

1️⃣ 0 只有一种写法 `00000000`，不再有 +0 和 -0 的混乱。

2️⃣ 加法和减法统一：减去一个数 = 加上它的补码，电脑只要会做加法就行！

3️⃣ 省出来的编码能多表示一个数：8 位补码能表示 -128~127，负数比正数多一个。

这就是为什么 `int`（32 位补码）的范围是 -2147483648 ~ 2147483647！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 2147483647;   // int 的最大值
    cout << a << endl;    // 2147483647
    cout << a + 1 << endl;  // -2147483648：绕回最小值，溢出啦！
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：补码转真值

<!-- card type:computer -->
🖥️ 输入一个 8 位二进制补码字符串，输出它代表的真值（十进制数，范围 -128~127）。

**输入样例：** `11111011`

**输出样例：** `-5`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s; cin >> s;
    int v = 0;
    for (int i = 1; i < 8; i++) v = v * 2 + (s[i] - '0');
    if (s[0] == '0') cout << v << endl;
    else cout << v - 128 << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 补码和真值的关系：负数补码的真值 = 后 7 位的值 - 128
- 按权展开求二进制串的值

**解题思路分步说明**

1. 先算出后 7 位（下标 1~7）表示的数值 `v`。
2. 如果符号位是 0，这是正数，直接输出 `v`。
3. 如果符号位是 1，这是负数，输出 `v - 128`。

**容易错的地方**

- 循环从下标 0 开始：符号位不能算进数值，要从下标 1 开始
- 忘记判断符号位：正负要分两种情况输出
- 为什么是减 128：负数的补码 = 256 + 真值（8 位），而 `v` = 128 + 真值，所以真值 = `v - 128`

**关键代码解释**

```cpp
for (int i = 1; i < 8; i++) v = v * 2 + (s[i] - '0');
```

- 从第 2 位开始扫，每扫一位：`v` 乘 2 再加这一位
- 扫完后 `v` 就是后 7 位的十进制值
<!-- end-card -->

## 挑战 2：负数的三种编码

<!-- card type:computer -->
🖥️ 输入一个负整数 n（-128 ≤ n ≤ -1），输出它的 8 位原码、反码、补码，各占一行。

**输入样例：** `-5`

**输出样例：** 三行依次是 `10000101`、`11111010`、`11111011`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    string v = "";
    for (int t = -n, i = 0; i < 7; i++, t /= 2) v = (char)('0' + t % 2) + v;
    string fan = "1";
    for (char c : v) fan += (c == '0' ? '1' : '0');
    string bu = fan;
    for (int i = 7, c = 1; i >= 1 && c; i--) { if (bu[i] == '0') { bu[i] = '1'; c = 0; } else bu[i] = '0'; }
    cout << "1" + v << endl << fan << endl << bu << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 原码、反码、补码三种编码的推导链条
- 二进制加 1 的进位处理

**解题思路分步说明**

1. 用短除法把 `-n`（绝对值）转成 7 位二进制 `v`。
2. 原码 = 符号位 `1` 加上 `v`。
3. 反码 = 符号位不变，`v` 里每一位取反。
4. 补码 = 反码加 1：从右往左扫，遇到 0 变 1 就停，遇到 1 变 0 继续进位。

**容易错的地方**

- 数值部分必须是 7 位：不够要在左边补 0
- 反码的符号位不能取反：要先把 `"1"` 放好再逐位翻转 `v`
- 加 1 时忘了进位传递：遇到连续的 1 要一直往左进

**关键代码解释**

```cpp
for (int i = 7, c = 1; i >= 1 && c; i--) { if (bu[i] == '0') { bu[i] = '1'; c = 0; } else bu[i] = '0'; }
```

- `c` 是进位，一开始是 1（要加的那个 1）
- 遇到 `0`：变成 `1`，进位消失，循环结束
- 遇到 `1`：变成 `0`，进位继续往左传
<!-- end-card -->

---

## 小贴士

<!-- card type:tip -->
💡 记口诀：**正数三码合一；负数反码 = 符号位不动其余取反，补码 = 反码 + 1**。

💡 由补码求真值也有口诀：符号位是 1 就是负数，把补码"取反再加 1"就得到它的绝对值。
<!-- end-card -->
