# 课程16：位运算

> 🎯 目标：学会六种位运算 `&` `|` `^` `~` `<<` `>>`，会用它们判断奇偶、快速乘除、统计二进制位。

---

## 故事：二进制魔法

<!-- story -->
小柯做了一个"猜奇偶"程序，写的是 `if (n % 2 == 1)`。

电脑得意地说："我有个更快的魔法：`n & 1`，一个时钟周期就出答案，比除法快多啦！"⚡

"这是什么咒语？"小柯瞪大了眼睛。

——这就是**位运算**：直接对二进制的每一位施魔法！🪄
<!-- end-story -->

---

## 回顾

<!-- card type:teacher -->
🧑‍🏫 我们知道了：整数在电脑里就是一串 0 和 1，比如 12 是 `1100`，10 是 `1010`。

位运算就是把这些位**一位对一位**地算，每一位互不影响，所以快得像闪电！
<!-- end-card -->

---

## 卡片：按位与 &

<!-- card type:teacher -->
🧑‍🏫 `&` 读作"按位与"：**两位都是 1，结果才是 1**，否则是 0。

```
  1100  (12)
& 1010  (10)
= 1000  (8)
```

妙用：`n & 1` 能看最后一位是几——是 1 就是奇数，是 0 就是偶数！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 12, b = 10;   // 1100 和 1010
    cout << (a & b) << endl;       // 8
    cout << (7 & 1) << " " << (8 & 1) << endl;  // 1 0（7 奇 8 偶）
    return 0;
}
```
<!-- end-demo -->

## 卡片：按位或和异或

<!-- card type:teacher -->
🧑‍🏫 还有两个好兄弟：

`|` 按位或：**有一个是 1，结果就是 1**（都是 0 才是 0）。

`^` 按位异或：**两位不同才是 1，相同就是 0**（像个"找不同"游戏）。

```
  1100  (12)     1100  (12)
| 1010  (10)   ^ 1010  (10)
= 1110  (14)   = 0110  (6)
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 12, b = 10;   // 1100 和 1010
    cout << (a | b) << endl;  // 1110 = 14
    cout << (a ^ b) << endl;  // 0110 = 6
    return 0;
}
```
<!-- end-demo -->

## 卡片：异或消消乐

<!-- card type:teacher -->
🧑‍🏫 异或有三条神奇性质：

`a ^ a = 0`（自己消掉自己）、`a ^ 0 = a`（和 0 异或不变）、顺序随便换。

所以一串数全部异或起来，**成对出现的数两两消成 0，落单的那个就露出来啦**！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[5] = {2, 3, 2, 3, 5}, ans = 0;
    for (int i = 0; i < 5; i++) ans ^= a[i];
    cout << ans << endl;   // 5：2 和 3 都成对消掉啦
    return 0;
}
```
<!-- end-demo -->

## 卡片：左移和右移

<!-- card type:teacher -->
🧑‍🏫 `<<` 左移：所有位往左挪，右边补 0。**左移 k 位 = 乘 2 的 k 次方**！

`>>` 右移：所有位往右挪，末尾扔掉。**右移 k 位 = 除以 2 的 k 次方**（向下取整）。

比如 `3 << 2` = 12（3×4），`12 >> 2` = 3（12÷4）。还有 `~` 按位取反，`~n = -(n+1)`。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 3;
    cout << (a << 1) << " " << (a << 2) << endl;    // 6 12
    cout << (12 >> 1) << " " << (12 >> 2) << endl;  // 6 3
    return 0;
}
```
<!-- end-demo -->

## 卡片：位运算小抄

<!-- card type:teacher -->
🧑‍🏫 位运算十大招式，一张小抄全收好 📜

1️⃣ 判奇偶：`n & 1`　2️⃣ 2 的 k 次方：`1 << k`　3️⃣ 取第 k 位：`(n >> k) & 1`
4️⃣ 第 k 位置 1：`n | (1 << k)`　5️⃣ 第 k 位置 0：`n & ~(1 << k)`　6️⃣ 第 k 位翻转：`n ^ (1 << k)`
7️⃣ 只留最低位的 1（lowbit）：`n & (-n)`　8️⃣ 去掉最低位的 1：`n & (n - 1)`
9️⃣ 数 1 的个数：`__builtin_popcount(n)`　🔟 快速乘除：`n << k`、`n >> k`

负数以补码存储（补码 = 取反 + 1），所以 `-n` 正好等于 `~n + 1`，招式 7 就靠它成立；招式 8 还能判断 2 的幂：`n > 0 && (n & (n - 1)) == 0`！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 12;                             // 1100
    cout << (n & -n) << endl;               // 4：只留最低位的 1
    cout << (n & (n - 1)) << endl;          // 8：1100 变 1000
    cout << __builtin_popcount(n) << endl;  // 2：有 2 个 1
    return 0;
}
```
<!-- end-demo -->

## 卡片：枚举所有子集

<!-- card type:teacher -->
🧑‍🏫 把整数的二进制看成一个集合：哪位是 1，哪件物品就"入选" 🎁

`sub = (sub - 1) & mask` 能从大到小点出所有子集：`sub - 1` 会把最低位的 1 变 0、更低位全变 1，再 `& mask` 把集合外的位挡回去——所以每个子集恰好出现一次，不重不漏！
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int mask = 5;                    // 101：0 号和 2 号物品组成的集合
    for (int sub = mask; ; sub = (sub - 1) & mask) {
        cout << sub << " ";          // 5 4 1 0：子集不重不漏
        if (sub == 0) break;
    }
    return 0;
}
```
<!-- end-demo -->

## 挑战 1：统计 1 的个数

<!-- card type:computer -->
🖥️ 输入一个正整数 n，输出它的二进制表示里有几个 1。

**输入样例：** `13`

**输出样例：** `3`（13 = `1101`，有 3 个 1）
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    int cnt = 0;
    while (n > 0) {
        cnt += n & 1;
        n >>= 1;
    }
    cout << cnt << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- `n & 1` 取出二进制最后一位
- `n >>= 1` 右移一位（相当于 `n /= 2`）

**解题思路分步说明**

1. 每次用 `n & 1` 看 n 的最后一位是 0 还是 1，是 1 就计数加一。
2. 用 `n >>= 1` 把 n 右移一位，扔掉刚看过的末位。
3. 循环到 n 变成 0，所有位都检查完了，输出计数。

**容易错的地方**

- 循环条件写成 `n >= 0`：0 永远满足，会死循环，要写 `n > 0`
- 忘记右移：不右移的话永远在看同一位
- `n & 1` 的结果是 0 或 1，直接加到计数器里就行，不用写 if

**关键代码解释**

```cpp
cnt += n & 1;
n >>= 1;
```

- 第一行：末位是 1 就加 1，是 0 就加 0
- 第二行：全体右移一格，准备看下一位
<!-- end-card -->

## 挑战 2：找落单的数

<!-- card type:computer -->
🖥️ 输入 n 个整数（n 是奇数），其他数都恰好出现两次，只有一个数出现一次，输出它。

**输入样例：** `5` 换行 `2 3 2 3 5`

**输出样例：** `5`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    int ans = 0, x;
    for (int i = 0; i < n; i++) {
        cin >> x;
        ans ^= x;
    }
    cout << ans << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 异或的性质：`a ^ a = 0`、`a ^ 0 = a`、顺序可以随便换
- 边读边算的循环技巧

**解题思路分步说明**

1. 准备 `ans = 0`（0 和任何数异或都不改变它）。
2. 每读入一个数，就和 `ans` 异或一次。
3. 成对的数两两异或消成 0，最后 `ans` 里只剩下落单的那个数。

**容易错的地方**

- `ans` 忘初始化为 0：里面是随机值，答案就错了
- 想先存进数组再排序：也能做，但异或一遍搞定，又快又省内存
- 以为异或只能对两个数用：连续异或完全没问题，顺序不影响结果

**关键代码解释**

```cpp
ans ^= x;
```

- 等价于 `ans = ans ^ x`
- 每个数都在 `ans` 上"盖章"一次；同一个数盖两次章就抵消，只盖一次的留到最后
<!-- end-card -->

## 小贴士

<!-- card type:tip -->
💡 位运算符号**优先级很低**：`n & 1 == 1` 会先算 `1 == 1`！保险写法是加括号：`(n & 1) == 1`。

💡 常用小抄：`n & 1` 判奇偶、`1 << k` 是 2 的 k 次方、`(n >> k) & 1` 取第 k 位。
