## 本课练习要点

<!-- card type:teacher -->
🧑‍🏫 这节课不学新知识，重点复习第 14~16 课：

- 进制转换：短除法（十进制→R 进制）、按权展开（R 进制→十进制）、4 位二进制 = 1 位十六进制
- 数据编码：符号位（0 正 1 负）、原码 / 反码 / 补码、负数补码 = 反码 + 1
- 位运算：`&` 与、`|` 或、`^` 异或、`<<` 左移、`>>` 右移

练习时注意：
1. 短除法的余数要倒着读，拼字符串时新余数放最前面
2. 十六进制用 `"0123456789ABCDEF"` 查表，不怕 10~15
3. 负数编码先写绝对值的 7 位二进制，再一步步推原码、反码、补码
4. 位运算优先级低，和比较运算混用时记得加括号
<!-- end-card -->

## 挑战 1：转成任意进制

<!-- card type:computer -->
🖥️ 输入正整数 n 和目标进制 d（2 ≤ d ≤ 16），输出 n 的 d 进制表示（10~15 用大写 A~F）。

**输入样例：** `255 16`

**输出样例：** `FF`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, d; cin >> n >> d;
    string g = "0123456789ABCDEF", r = "";
    if (n == 0) r = "0";
    while (n > 0) { r = g[n % d] + r; n /= d; }
    cout << r << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 短除法的通用版：除以 d 取余，而不是只会除以 2
- 用查表字符串处理 10~15 的字母

**解题思路分步说明**

1. 读入 n 和 d，余数是几就取 `g` 里的第几个字符。
2. 循环：余数字符拼到结果最前面，n 再除以 d。
3. 特判 n = 0 时直接输出 `0`。

**容易错的地方**

- 余数拼错方向：必须放最前面，否则整个数是倒的
- 忘记 n = 0 的特判：循环一次都不跑，会输出空串
- 自己写 if 把 10 变 A：又慢又容易错，查表一行搞定

**关键代码解释**

```cpp
r = g[n % d] + r;
```

- `n % d` 是余数（0~15），`g[n % d]` 直接查出对应字符
- 拼在最前面，实现余数倒序
<!-- end-card -->

## 挑战 2：二进制转十进制

<!-- card type:computer -->
🖥️ 输入一个只含 0 和 1 的二进制字符串，输出它对应的十进制数。

**输入样例：** `1101`

**输出样例：** `13`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s; cin >> s;
    long long r = 0;
    for (char c : s) r = r * 2 + (c - '0');
    cout << r << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 按权展开的滚动写法：从左到右，每次乘 2 加当前位
- 字符转数字：`c - '0'`

**解题思路分步说明**

1. 答案 `r` 从 0 开始。
2. 从左到右扫每一位：`r` 先乘 2（已有位全体升值），再加上当前位。
3. 扫完输出 `r`。

**容易错的地方**

- 顺序搞反：必须先乘 2 再加新位，写成 `r + c * 2` 就全错了
- 字符串很长时 `int` 装不下：用 `long long` 更保险
- `c - '0'` 漏写：字符 `'1'` 的 ASCII 码是 49，直接加会得天文数字

**关键代码解释**

```cpp
for (char c : s) r = r * 2 + (c - '0');
```

- 每来一位，旧值乘 2：相当于之前所有位的权都翻倍
- 加上新位，正好和按权展开的结果一模一样
<!-- end-card -->

## 挑战 3：负数的补码

<!-- card type:computer -->
🖥️ 输入一个负整数 n（-128 ≤ n ≤ -1），输出它的 8 位补码（最高位是符号位）。

**输入样例：** `-5`

**输出样例：** `11111011`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    string v = "";
    for (int t = -n, i = 0; i < 7; i++, t /= 2) v = (char)('0' + t % 2) + v;
    string f = "1";
    for (char c : v) f += (c == '0' ? '1' : '0');
    for (int i = 7, c = 1; i >= 1 && c; i--) { if (f[i] == '0') { f[i] = '1'; c = 0; } else f[i] = '0'; }
    cout << f << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 负数补码的推导链：绝对值二进制 → 原码 → 反码 → 补码
- 二进制加 1 的进位模拟

**解题思路分步说明**

1. 短除法把绝对值 `-n` 转成 7 位二进制 `v`。
2. 符号位放 `1`，后面 `v` 逐位取反，得到反码 `f`。
3. 给 `f` 加 1：从右往左，遇 0 变 1 就停，遇 1 变 0 继续进位。

**容易错的地方**

- 数值位数不对：8 位补码 = 1 位符号 + 7 位数值，`v` 必须是 7 位
- 取反时动了符号位：符号位从头到尾都是 1
- 加 1 时提前停：遇到连续的 1 要一直进位，直到碰到 0

**关键代码解释**

```cpp
for (int i = 7, c = 1; i >= 1 && c; i--) { if (f[i] == '0') { f[i] = '1'; c = 0; } else f[i] = '0'; }
```

- `c` 是进位，初始为 1 表示"要加 1"
- 这一位是 0：变 1，进位用完，循环结束；是 1：变 0，进位继续往左
<!-- end-card -->

## 挑战 4：是不是 2 的幂

<!-- card type:computer -->
🖥️ 输入一个正整数 n，判断它是不是 2 的幂（像 1、2、4、8、16 这样，二进制里只有一个 1 的数）。是就输出 `YES`，不是就输出 `NO`。

**输入样例：** `8`

**输出样例：** `YES`

（小测试：`12` 应该输出 `NO`）
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    if (n > 0 && (n & (n - 1)) == 0) cout << "YES";
    else cout << "NO";
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 位运算 `n & (n - 1)`：把二进制最低位的那个 1 变成 0
- 2 的幂的特征：二进制里恰好只有一个 1

**解题思路分步说明**

1. 如果一个数是 2 的幂，它的二进制只有一个 1。
2. `n & (n - 1)` 会把这个唯一的 1 抹掉，结果变成 0。
3. 再排除 n = 0（0 不是 2 的幂），所以条件是 `n > 0 && (n & (n - 1)) == 0`。

**容易错的地方**

- 漏掉 `n > 0`：n = 0 时 `0 & (-1)` 也是 0，会错误判成 YES
- 忘记加括号：位运算优先级低，`==` 先算，必须写成 `(n & (n - 1)) == 0`

**关键代码解释**

```cpp
if (n > 0 && (n & (n - 1)) == 0)
```

- `n & (n - 1)` 抹掉最低位的 1；只剩一个 1 的数抹完正好是 0
- `n > 0` 先把 0 这个例外挡在门外
<!-- end-card -->

## 挑战 5：清零某一位

<!-- card type:computer -->
🖥️ 输入整数 n 和 k（0 ≤ k ≤ 30），把 n 的二进制第 k 位（从右边第 0 位开始数）变成 0，其他位原样不动，输出结果。

**输入样例：** `13 0`（13 是 `1101`，把第 0 位清 0 得 `1100`）

**输出样例：** `12`

（小测试：`12 3` 应该输出 `4`）
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, k; cin >> n >> k;
    cout << (n & ~(1 << k)) << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- `1 << k`：造出一个"只有第 k 位是 1"的掩码
- `~(1 << k)`：把掩码取反，变成"只有第 k 位是 0、其余全是 1"
- `n & 掩码`：用与运算把第 k 位按成 0，其他位保留

**解题思路分步说明**

1. `1 << k` 得到一个第 k 位是 1 的数。
2. `~(1 << k)` 取反，得到"第 k 位是 0、其余全是 1"的掩码。
3. `n & 掩码`：n 的第 k 位被 0 盖住变成 0，其他位和 1 相与保持不变。

**容易错的地方**

- 写成 `n & (1 << k)`：这会把其他位全清 0、只留第 k 位，方向反了
- 忘记对掩码取反 `~`：直接用 `1 << k` 去与，结果完全不对
- `<<` 优先级低于 `~`，加括号更稳：`~(1 << k)`

**关键代码解释**

```cpp
cout << (n & ~(1 << k)) << endl;
```

- `1 << k` 造掩码，`~` 翻面成"第 k 位为 0"
- `n` 与它相与，精准清零第 k 位，其他位毫发无损

## 小贴士

<!-- card type:tip -->
💡 进制题两把钥匙：**短除法**（十进制→其他，余数倒读）和**滚动乘加**（其他→十进制，乘 R 加当前位）。

💡 位运算口诀：`& 1` 判奇偶、`<< 1` 乘 2、`>> 1` 除 2、`^` 消成对。和 `==` 混用一定加括号！
