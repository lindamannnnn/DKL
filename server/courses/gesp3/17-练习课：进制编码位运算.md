## 本课练习要点

<!-- card type:teacher -->
🧑‍🏫 这节课不学新知识，重点复习第 14~16 课：

- 进制转换：短除法（十进制→R 进制）、按权展开（R 进制→十进制）、4 位二进制 = 1 位十六进制
- 数据编码：符号位（0 正 1 负）、原码 / 反码 / 补码、负数补码 = 反码 + 1
- 位运算：`&` 与、`|` 或、`^` 异或、`<<` 左移、`>>` 右移

练习时注意：
1. 短除法的余数要倒着读，拼字符串时新余数放最前面
2. 十六进制用 `"0123456789ABCDEF"` 查表，不怕 10~15
3. 负数编码先写绝对值的 7 位二进制，再一步步推原码、反码、补码
4. 位运算优先级低，和比较运算混用时记得加括号

## 挑战 1：转成任意进制

<!-- card type:computer -->
🖥️ 输入正整数 n 和目标进制 d（2 ≤ d ≤ 16），输出 n 的 d 进制表示（10~15 用大写 A~F）。

**输入样例：** `255 16`

**输出样例：** `FF`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, d; cin >> n >> d;
    string g = "0123456789ABCDEF", r = "";
    if (n == 0) r = "0";
    while (n > 0) { r = g[n % d] + r; n /= d; }
    cout << r << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 短除法的通用版：除以 d 取余，而不是只会除以 2
- 用查表字符串处理 10~15 的字母

**解题思路分步说明**

1. 读入 n 和 d，余数是几就取 `g` 里的第几个字符。
2. 循环：余数字符拼到结果最前面，n 再除以 d。
3. 特判 n = 0 时直接输出 `0`。

**容易错的地方**

- 余数拼错方向：必须放最前面，否则整个数是倒的
- 忘记 n = 0 的特判：循环一次都不跑，会输出空串
- 自己写 if 把 10 变 A：又慢又容易错，查表一行搞定

**关键代码解释**

```cpp
r = g[n % d] + r;
```

- `n % d` 是余数（0~15），`g[n % d]` 直接查出对应字符
- 拼在最前面，实现余数倒序
<!-- end-card -->

## 挑战 2：二进制转十进制

<!-- card type:computer -->
🖥️ 输入一个只含 0 和 1 的二进制字符串，输出它对应的十进制数。

**输入样例：** `1101`

**输出样例：** `13`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s; cin >> s;
    long long r = 0;
    for (char c : s) r = r * 2 + (c - '0');
    cout << r << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 按权展开的滚动写法：从左到右，每次乘 2 加当前位
- 字符转数字：`c - '0'`

**解题思路分步说明**

1. 答案 `r` 从 0 开始。
2. 从左到右扫每一位：`r` 先乘 2（已有位全体升值），再加上当前位。
3. 扫完输出 `r`。

**容易错的地方**

- 顺序搞反：必须先乘 2 再加新位，写成 `r + c * 2` 就全错了
- 字符串很长时 `int` 装不下：用 `long long` 更保险
- `c - '0'` 漏写：字符 `'1'` 的 ASCII 码是 49，直接加会得天文数字

**关键代码解释**

```cpp
for (char c : s) r = r * 2 + (c - '0');
```

- 每来一位，旧值乘 2：相当于之前所有位的权都翻倍
- 加上新位，正好和按权展开的结果一模一样
<!-- end-card -->

## 挑战 3：负数的补码

<!-- card type:computer -->
🖥️ 输入一个负整数 n（-128 ≤ n ≤ -1），输出它的 8 位补码（最高位是符号位）。

**输入样例：** `-5`

**输出样例：** `11111011`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    string v = "";
    for (int t = -n, i = 0; i < 7; i++, t /= 2) v = (char)('0' + t % 2) + v;
    string f = "1";
    for (char c : v) f += (c == '0' ? '1' : '0');
    for (int i = 7, c = 1; i >= 1 && c; i--) { if (f[i] == '0') { f[i] = '1'; c = 0; } else f[i] = '0'; }
    cout << f << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 负数补码的推导链：绝对值二进制 → 原码 → 反码 → 补码
- 二进制加 1 的进位模拟

**解题思路分步说明**

1. 短除法把绝对值 `-n` 转成 7 位二进制 `v`。
2. 符号位放 `1`，后面 `v` 逐位取反，得到反码 `f`。
3. 给 `f` 加 1：从右往左，遇 0 变 1 就停，遇 1 变 0 继续进位。

**容易错的地方**

- 数值位数不对：8 位补码 = 1 位符号 + 7 位数值，`v` 必须是 7 位
- 取反时动了符号位：符号位从头到尾都是 1
- 加 1 时提前停：遇到连续的 1 要一直进位，直到碰到 0

**关键代码解释**

```cpp
for (int i = 7, c = 1; i >= 1 && c; i--) { if (f[i] == '0') { f[i] = '1'; c = 0; } else f[i] = '0'; }
```

- `c` 是进位，初始为 1 表示"要加 1"
- 这一位是 0：变 1，进位用完，循环结束；是 1：变 0，进位继续往左
<!-- end-card -->

## 挑战 4：统计 1 的个数

<!-- card type:computer -->
🖥️ 输入一个正整数 n，用位运算输出它的二进制表示里有几个 1。

**输入样例：** `13`

**输出样例：** `3`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    int cnt = 0;
    while (n > 0) {
        cnt += n & 1;
        n >>= 1;
    }
    cout << cnt << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- `n & 1` 取出末位，`n >>= 1` 右移丢掉末位
- 逐位检查的循环套路

**解题思路分步说明**

1. 用 `n & 1` 检查末位：是 1 计数加一，是 0 加零。
2. 用 `n >>= 1` 右移，把检查过的末位扔掉。
3. n 变成 0 时全部检查完，输出计数。

**容易错的地方**

- 死循环：循环条件必须是 `n > 0`，而且循环里要真的右移
- 手写 if 判断：`n & 1` 结果就是 0 或 1，直接累加最简洁
- 转成字符串再数：也能对，但题目要求练位运算，考试时也更快

**关键代码解释**

```cpp
cnt += n & 1;
n >>= 1;
```

- 两行一套组合拳：看末位、扔末位
- 重复到 n 为 0，每个 1 都被数到一次
<!-- end-card -->

## 挑战 5：找落单的数

<!-- card type:computer -->
🖥️ 输入 n 个整数（n 是奇数），其他数都恰好出现两次，只有一个数出现一次，输出它。

**输入样例：** `5` 换行 `2 3 2 3 5`

**输出样例：** `5`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    int ans = 0, x;
    for (int i = 0; i < n; i++) {
        cin >> x;
        ans ^= x;
    }
    cout << ans << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 异或三性质：`a ^ a = 0`、`a ^ 0 = a`、交换律和结合律
- 边读边处理，不用数组

**解题思路分步说明**

1. `ans` 从 0 出发。
2. 每读一个数就异或进 `ans`。
3. 出现两次的数互相抵消，最后剩下的就是只出现一次的数。

**容易错的地方**

- `ans` 没初始化：必须从 0 开始
- 想靠排序找落单：可行但麻烦，异或一遍扫完最快
- 担心顺序影响：异或满足交换律、结合律，先来后到无所谓

**关键代码解释**

```cpp
ans ^= x;
```

- 每个数在 `ans` 上盖一次章，同一个数盖两次就抵消
- 只有落单数的章留到最后
