## 本课练习要点

<!-- card type:teacher -->
🧑‍🏫 这节课不学新知识，重点复习 GESP3 的 12 个知识点：
- 一维数组：下标从 0 开始，比赛常从 1 用起
- 数组增删：插入从后往前挪，删除从前往后盖
- 数组计数法：值域小就能开桶，`cnt[x]++`
- 连续性元素：相同就 `cur++`；断掉时看数什么——数连续 1 归 `0`，数相同段归 `1`（一段至少有 1 个）
- 字符数组：以 `\0` 结尾，`strlen` 数长度
- string：`substr` 截取、`find` 查找、`replace` 替换
- 枚举：定范围、定顺序、逐个验证
- 模拟：按题目规则一步步照做
- 进制转换：短除法取余，倒着读
- 数据编码：负数补码 = 取反 + 1
- 位运算：`&` 与、`|` 或、`^` 异或、`<<` 左移、`>>` 右移、`~` 取反

练习时要注意：
1. 数组开大一点，下标别越界
2. `string::npos` 表示"没找到"
3. 位运算优先级低，拿不准就加括号

## 挑战 1：谁出现最多

<!-- card type:computer -->
🖥️ 输入 n 个整数（1 ≤ n ≤ 100，每个数在 1~100 之间），输出出现次数最多的数和它的次数。如果有并列，输出最小的那个数。

**输入样例：** `7` 换行 `3 1 3 2 3 1 2`

**输出样例：** `3 3`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int cnt[105];
int main() {
    int n, x; cin >> n;
    for (int i = 1; i <= n; i++) { cin >> x; cnt[x]++; }
    int best = 0, ans = 1;
    for (int v = 1; v <= 100; v++)
        if (cnt[v] > best) { best = cnt[v]; ans = v; }
    cout << ans << " " << best << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 一维数组的读入与遍历
- 数组计数法（开桶统计次数）

**解题思路分步说明**

1. 开一个大桶 `cnt[105]`，全部自动是 0。
2. 每读到一个数 `x`，就在 `cnt[x]` 上加 1。
3. 按 1→100 的顺序检查每个桶，次数更多就换新擂主。

**容易错的地方**

- 并列时取最小的数：按从小到大检查、用 `>` 而不用 `>=`，就能自动做到
- 桶要开在 `main` 外面，才能自动清零

**关键代码解释**

```cpp
if (cnt[v] > best) { best = cnt[v]; ans = v; }
```

- `cnt[v]` 比擂主强才换，一样强不换，所以小号永远先当擂主
<!-- end-card -->

## 挑战 2：最长连续 1

<!-- card type:computer -->
🖥️ 输入一串只由 `0` 和 `1` 组成的字符串（长度 ≤ 100），求最长的连续 `1` 有多少个。

**输入样例：** `11011101`

**输出样例：** `3`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
char s[105];
int main() {
    cin >> s;
    int cur = 0, best = 0;
    for (int i = 0; s[i]; i++) {
        if (s[i] == '1') { cur++; best = max(best, cur); }
        else cur = 0;
    }
    cout << best << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 字符数组的读入与遍历（`s[i]` 为 `\0` 时循环结束）
- 连续性元素：当前长度 `cur` 与历史最好 `best`

**解题思路分步说明**

1. 从头到尾看每个字符。
2. 是 `1`：队伍变长 `cur++`，顺手挑战纪录 `best`。
3. 是 `0`：队伍断掉，`cur` 清零重新数。

**容易错的地方**

- `cur` 清零写成 `cur = 1` 就错了：0 本身不算 1
- 循环条件写 `i < strlen(s)` 也能对，但 `s[i]` 更简洁

**关键代码解释**

```cpp
for (int i = 0; s[i]; i++)
```

- `s[i]` 遇到结束标记 `\0`（数值 0）就停下，正好数完整串
<!-- end-card -->

## 挑战 3：敏感词替换

<!-- card type:computer -->
🖥️ 输入一行文本 `s` 和一个敏感词 `t`（都不含空格，长度 ≤ 100），把 `s` 中所有出现的 `t` 替换成同样多个 `*`，输出替换后的文本。

**输入样例：** `aabbaabb` 换行 `aa`

**输出样例：** `**bb**bb`
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s, t; cin >> s >> t;
    int p = s.find(t);
    while (p != string::npos) {
        s.replace(p, t.size(), t.size(), '*');
        p = s.find(t, p + t.size());
    }
    cout << s << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- string 的 `find`（找位置）和 `replace`（替换）
- `string::npos` 表示"没找到"

**解题思路分步说明**

1. 用 `s.find(t)` 找敏感词第一次出现的位置 `p`。
2. 找到了就用 `replace` 换成一串 `*`。
3. 从 `p + t.size()` 继续往后找，直到找不到为止。

**容易错的地方**

- 继续找时不能从 `p` 开始，否则刚换的 `*` 附近可能重复匹配，会死循环
- `replace` 的四个参数：位置、删几个、放几个、放什么字符

**关键代码解释**

```cpp
s.replace(p, t.size(), t.size(), '*');
```

- 这是 `replace` 的另一种用法：07 课学的是 `replace(位置, 个数, "新串")`，把一段换成新内容；这里的四参数版本不换新串，而是填进若干个相同字符
- 四个参数分别是：位置、删几个、放几个、放什么字符
- 从位置 `p` 删掉 `t.size()` 个字符，放进 `t.size()` 个 `*`
<!-- end-card -->

## 挑战 4：进制转换器

<!-- card type:computer -->
🖥️ 输入一个正整数 n（1 ≤ n ≤ 65535），输出四行：n 的二进制、十六进制（大写字母）、二进制中 1 的个数、n 是不是 2 的幂（是输出 `YES`，否则 `NO`）。

**输入样例：** `26`

**输出样例：**
```
11010
1A
3
NO
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, cnt = 0; cin >> n;
    string bin = "", hx = "", d = "0123456789ABCDEF";
    for (int t = n; t; t /= 2) bin = char('0' + t % 2) + bin;
    for (int t = n; t; t /= 16) hx = d[t % 16] + hx;
    for (int t = n; t; t >>= 1) cnt += t & 1;
    cout << bin << "\n" << hx << "\n" << cnt << "\n";
    cout << ((n & (n - 1)) == 0 ? "YES" : "NO") << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 进制转换：短除法取余，结果倒着拼
- 位运算：`t & 1` 看最低位，`t >>= 1` 去掉最低位
- 数据编码：二进制就是计算机存数的方式

**解题思路分步说明**

1. 转二进制：不断 `% 2` 取余、`/ 2` 缩小，余数拼到前面。
2. 转十六进制：同理，只是换成 `% 16`、`/ 16`，用 `d` 查字母。
3. 数 1 的个数：每次看最低位 `t & 1`，再右移一位。
4. 2 的幂：二进制只有一个 1，`n & (n - 1)` 正好是 0。

**容易错的地方**

- 余数要拼到字符串**前面**，拼后面就倒了
- `n & (n - 1)` 一定要加括号，位运算优先级比 `==` 低

**关键代码解释**

```cpp
for (int t = n; t; t >>= 1) cnt += t & 1;
```

- 每一圈看一位、扔一位，`t` 变 0 就看完了
<!-- end-card -->

## 挑战 5：删数逆序统计

<!-- card type:computer -->
🖥️ 输入 n 个整数（1 ≤ n ≤ 100，每个数在 0~100 之间），先删去所有 0，再把剩下的数逆序输出（空格分隔），最后输出出现次数最多的数和次数（并列取最小）。

**输入样例：** `7` 换行 `3 0 1 3 0 3 2`

**输出样例：**
```
2 3 3 1 3
3 3
```
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int b[105], cnt[105];
int main() {
    int n, m = 0, x; cin >> n;
    for (int i = 1; i <= n; i++) { cin >> x; if (x) { m++; b[m] = x; cnt[x]++; } }
    for (int i = m; i >= 1; i--) { if (i < m) cout << " "; cout << b[i]; }
    int best = 0, ans = 0;
    for (int v = 1; v <= 100; v++)
        if (cnt[v] > best) { best = cnt[v]; ans = v; }
    cout << "\n" << ans << " " << best << endl;
    return 0;
}
```
<!-- end-demo -->

<!-- card type:teacher -->
**这道题考察什么知识点**

- 模拟：按题目规则一步步照做（删 0 → 逆序 → 统计）
- 数组删除：不是真的擦除，而是把要的数重新收进新数组
- 枚举 + 计数法：枚举 1~100 每个值，看谁桶里最多

**解题思路分步说明**

1. 读数时顺手过滤：不是 0 才收进 `b`，同时 `cnt[x]++`。
2. 从 `b[m]` 倒着输出到 `b[1]`，就是逆序。
3. 枚举每个值 `v`，桶里最多又最小的就是答案。

**容易错的地方**

- 逆序输出时空格位置：第一个数前面不加空格
- 别忘了数组可能全被删光，程序也要能正常结束

**关键代码解释**

```cpp
if (x) { m++; b[m] = x; cnt[x]++; }
```

- `if (x)` 就是"如果 x 不是 0"：留下它、顺便给它投一票
- `m++` 和 `b[m] = x` 分两行写：先多准备一个格子，再把 x 放进去

<!-- card type:tip -->
💡 计数法口诀：值域小，就开桶；一边读，一边投。

💡 进制转换口诀：除基取余，倒序拼接。
