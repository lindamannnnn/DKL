## 挑战1：单选题（一）

<!-- card type:computer -->
🖥️ **第 2 题** a、b 是整型变量，各自有互不相同的初始值。下列程序实现了什么效果？

```cpp
a = a ^ b;
b = a ^ b;
a = a ^ b;
```

A. a、b 的值从始至终都没有改变  
B. a、b 的值实现了互换  
C. a、b 的值互换了以后，又还回去了，相当于没有变化  
D. a、b 的值最后和原值不一样，没有任何意义
<!-- end-card -->

<!-- demo -->
💡 **答案：B**

这是著名的"异或交换术"，不用临时变量就能交换两个数。
`a ^ b ^ b = a`，异或两次就还原，所以三步之后 a、b 正好互换。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 3 题** 关于下列程序段，说法正确的是？

```cpp
char str1[] = "Hello";
char str2[] = {'H','e','l','l','0'};
```

A. 字符数组 str1 和 str2 完全相同  
B. 输出它们的程序多次执行将输出不同的结果  
C. 字符数组 str1 和 str2 不相等  
D. 这两个赋值方式完全相同
<!-- end-card -->

<!-- demo -->
💡 **答案：C**

睁大眼睛看 str2 的最后一个字符：它是**数字 0**，不是字母 o！
而且 str2 没有结束标记 `\0`，内容根本不一样，所以选 C。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 5 题** 8 位二进制下，十进制数 -15 的补码是？

A. `11110000`  
B. `10001111`  
C. `10010000`  
D. `11110001`
<!-- end-card -->

<!-- demo -->
💡 **答案：D**

负数补码 = 取反 + 1：
- +15 是 `00001111`
- 取反得 `11110000`
- 再加 1 得 `11110001`
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 7 题** 二进制数 `10110101` 是某数的 8 位补码，该数的十进制是？

A. -73  
B. -75  
C. -77  
D. 75
<!-- end-card -->

<!-- demo -->
💡 **答案：B**

最高位是 1，说明是负数。把它"减 1 再取反"还原：
- 减 1：`10110100`
- 取反：`01001011` = 75
- 所以原数是 **-75**
<!-- end-demo -->

## 挑战2：单选题（二）

<!-- card type:computer -->
🖥️ **第 10 题** 执行以下 C++ 代码后，sub 的值是？

```cpp
string str = "GESP2026";
string sub = str.substr(4, 2);
```

A. `20`  
B. `02`  
C. `2026`  
D. `026`
<!-- end-card -->

<!-- demo -->
💡 **答案：A**

`substr(4, 2)` 表示从下标 4 开始取 2 个字符。
下标 4 是 `2`，下标 5 是 `0`，所以 sub 是 `20`。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 12 题** 执行以下代码后，输出结果是？

```cpp
char s[10] = "abcde";
int a = sizeof(s) / sizeof(s[0]);
int b = strlen(s);
cout << a - b;
```

A. 4  
B. 5  
C. 6  
D. 10
<!-- end-card -->

<!-- demo -->
💡 **答案：B**

`sizeof(s)` 是整个柜子的大小：10 个格子，所以 a = 10。
`strlen(s)` 是实际住了几个字符：`abcde` 共 5 个，所以 b = 5。
a - b = 10 - 5 = **5**。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 14 题** 用枚举法解决"鸡兔同笼问题：头共 35 个，脚共 94 只，求鸡和兔的数量"，以下枚举逻辑最合理的是？

A. 枚举鸡的数量 x（0~35），兔的数量 y=35-x，判断 `2*x + 4*y == 94`  
B. 枚举兔的数量 y（0~94），鸡的数量 x=35-y，判断 `2*x + 4*y == 94`  
C. 枚举所有整数 x（0~100）和 y（0~100），判断 `x+y==35 && 2*x+4*y==94`  
D. 枚举脚的总数 sum（0~94），判断 `sum == 94`
<!-- end-card -->

<!-- demo -->
💡 **答案：A**

头一共 35 个，所以鸡最多 35 只，枚举 0~35 就够了。
兔 = 35 - 鸡，一层循环搞定，不用双重循环，范围也最小。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **第 15 题** 模拟"字符串加密"：规则为"每个字符 ASCII 码 + 3，若超过 z（122）则从 a 重新开始"，以下代码中横线处正确的条件判断是？

```cpp
for (int i = 0; i < str.length(); i++) {
    // 需补充条件：
    _______________________
    else {
        str[i] += 3;
    }
}
```

A. `if (str[i] > 122) str[i] = str[i] + 3 - 26;`  
B. `if (str[i] > 122) str[i] = str[i] - 26;`  
C. `if (str[i] + 3 > 122) str[i] = str[i] - 26;`  
D. `if (str[i] + 3 > 'z') str[i] = 'a' + (str[i] + 3 - 'z') - 1;`
<!-- end-card -->

<!-- demo -->
💡 **答案：D**

要**先算 +3 会不会越界**，再决定怎么走，所以条件是 `str[i] + 3 > 'z'`。
越界后从 `a` 重新数：超出 `'z'` 几个，就从 `'a'` 往后数几个，记得减 1。
A、B 判断的是没加 3 之前的值；C 越界后忘了 +3。
<!-- end-demo -->

## 挑战3：判断题

<!-- card type:computer -->
🖥️ 判断下列说法是否正确（√ 或 ×）：

**第 1 题** 定义 `int arr[5] = {1,2,3};`，则 `arr[3]` 的值为 0，`arr[5]` 是合法下标。

**第 3 题** 定义 `int arr[] = {1,2,3};`，则 `sizeof(arr)` 的结果为 12（int 占 4 字节）。

**第 6 题** 已知大写字符 A 的 ASCII 编码的十六进制表示为 `0x41`，则字符 m 的 ASCII 编码的八进制表示为 `155`。

**第 8 题** 执行下面代码后，由于在 0~255 范围内 char 类型和 int 类型可以互换，因此 x 和 y 相等。

```cpp
char x = '1';
int y = 1;
```

**第 9 题** 在 C++ 语言中，表达式 `((0xf0 + 0x15) == 255)` 的值为 true。

**第 10 题** 如果 a 为 int 类型的变量，且 a 的二进制最低位为 0，则表达式 `((a & 3 & 1) == 0)` 的值为 true。
<!-- end-card -->

<!-- demo -->
💡 **答案：**
- 第 1 题：×（`arr[3]` 确实是 0，但合法下标只有 0~4，`arr[5]` 越界了，整句话错）
- 第 3 题：√（3 个 int × 4 字节 = 12）
- 第 6 题：√（`0x41` 是 A，小写 a 是 `0x61`，m 比 a 大 12，是 `0x6D` = 十进制 109 = 八进制 155）
- 第 8 题：×（字符 `'1'` 的 ASCII 是 49，不是数字 1，x 和 y 不相等）
- 第 9 题：×（`0xf0` = 240，`0x15` = 21，加起来是 261，不是 255）
- 第 10 题：√（`&` 从左往右算，`a & 3 & 1` 等于 `a & 1`；最低位是 0，结果就是 0）
<!-- end-demo -->

## 挑战4：编程题-回文串

<!-- card type:computer -->
🖥️ **编程题 1：二进制回文串**

对于一个正整数，把它转换成不含前导零的二进制表示，如果这个二进制序列从左向右读与从右向左读完全相同，就称它为二进制回文数。例如 9 的二进制是 `1001`，是回文；12 的二进制是 `1100`，不是回文。

**任务：** 给定正整数 n，计算 1 到 n 范围内二进制回文数的数量。

**输入：** 一行，一个正整数 n（1 ≤ n ≤ 100000）

**输出：** 一行，二进制回文数的数量

**样例：** 输入 `15` → 输出 `6`

**解释：** 1 到 15 中，1、3、5、7、9、15 是二进制回文数。
<!-- end-card -->

<!-- demo -->
💡 **参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, ans = 0, a[20]; cin >> n;
    for (int i = 1; i <= n; i++) {
        int t = i, len = 0; bool ok = true;
        while (t) { a[len++] = t % 2; t /= 2; }
        for (int j = 0; j < len - 1 - j; j++)
            if (a[j] != a[len - 1 - j]) ok = false;
        ans += ok;
    }
    cout << ans << endl; return 0;
}
```

思路：枚举 1~n 每个数 → 除 2 取余拆出二进制位 → 首尾双指针比对。回文正着反着一样，拆出来是倒序也不怕。
<!-- end-demo -->

## 挑战5：编程题-凯撒密码

<!-- card type:computer -->
🖥️ **编程题 2：凯撒密码**

凯撒密码把明文中的每个字母按固定数目偏移后替换成密文。例如偏移量是 3 时，A 变 D，B 变 E，……，X 变 A，Y 变 B，Z 变 C。

现在给你一个已破解的明文与对应密文，以及一段相同偏移量的待破解密文，请输出它对应的明文。

**输入：** 三行，依次是已破解明文、已破解密文、待破解密文（长度均不超过 1000，全是大写字母）

**输出：** 一行，待破解密文对应的明文

**样例输入：**
```
ABCDEFGVWXYZ
DEFGHIJYZABC
WKHTXLFNEURZQIRAMXPSVRYHUWKHODCBGRJ
```

**样例输出：**
```
THEQUICKBROWNFOXJUMPOVERTHELAZYDOG
```

**解释：** 由样例得偏移量为 `'D' - 'A' = 3`，密文 W 减 3 是 T，K 减 3 是 H，以此类推。
<!-- end-card -->

<!-- demo -->
💡 **参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s1, s2, s3; cin >> s1 >> s2 >> s3;
    int d = (s1[0] - s2[0] + 26) % 26;
    for (int i = 0; i < s3.size(); i++)
        cout << char((s3[i] - 'A' + d) % 26 + 'A');
    return 0;
}
```

思路：s1[0] 和 s2[0] 一减就知道偏移量 d（`+26` 再 `%26` 防止负数）。解密 = 密文每个字母往前挪 d 格，`% 26` 让 Z 后面绕回 A。
<!-- end-demo -->

## 小贴士

<!-- card type:tip -->
💡 补码换算口诀：负数补码 = 取反加 1；补码还原 = 减 1 取反。

💡 `sizeof` 看柜子大小，`strlen` 数实际住的字符，考试最爱混着考！

💡 枚举题先看选项里的范围，范围最小、循环最少的往往是对的。

💡 编程题字母绕圈问题，记住公式：`(x - 'A' + d + 26) % 26 + 'A'`。
