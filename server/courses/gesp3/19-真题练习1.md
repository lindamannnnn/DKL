## 卡片：2的n次方小卡

<!-- card type:teacher -->
🧑‍🏫 2 的 n 次方 = 2 连续乘 n 次：2³ = 2×2×2 = 8；2⁴ = 16。
电脑里常说"32 位整数"，意思是这个数用 32 个二进制位存放；32 位无符号最大能到 2³² ≈ 40 亿（4,294,967,295）。
记住：2 的 n 次方就是"n 个 2 相乘"，幂越大数越大！

## 挑战4：编程题-回文串

<!-- card type:computer -->
🖥️ **编程题 1：二进制回文串**

对于一个正整数，把它转换成不含前导零的二进制表示，如果这个二进制序列从左向右读与从右向左读完全相同，就称它为二进制回文数。例如 9 的二进制是 `1001`，是回文；12 的二进制是 `1100`，不是回文。

**任务：** 给定正整数 n，计算 1 到 n 范围内二进制回文数的数量。

**输入：** 一行，一个正整数 n（1 ≤ n ≤ 100000）

**输出：** 一行，二进制回文数的数量

**样例：** 输入 `15` → 输出 `6`

**解释：** 1 到 15 中，1、3、5、7、9、15 是二进制回文数。
<!-- end-card -->

<!-- card type:tip -->
🤔 先想一想：遮住下面的答案，自己先做 5 分钟，再往下看！
<!-- end-card -->

<!-- demo -->
💡 **参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, ans = 0, a[20]; cin >> n;
    for (int i = 1; i <= n; i++) {
        int t = i, len = 0; bool ok = true;
        while (t) { a[len++] = t % 2; t /= 2; }
        for (int j = 0; j < len - 1 - j; j++)
            if (a[j] != a[len - 1 - j]) ok = false;
        ans += ok;
    }
    cout << ans << endl; return 0;
}
```

思路：枚举 1~n 每个数 → 除 2 取余拆出二进制位 → 首尾双指针比对。回文正着反着一样，拆出来是倒序也不怕。
<!-- end-demo -->

## 卡片：字母循环移位

<!-- card type:teacher -->
🧑‍🏫 凯撒密码要把字母"绕圈"移动：A 往后移 3 格变成 D，Z 往后移 1 格绕回 A。

万能绕圈公式：第 k 个字母 = `(x - 'A' + d + 26) % 26 + 'A'`

`x - 'A'` 把字母变成 0~25 的号码；`+ d` 偏移；`+ 26` 再 `% 26` 防止变负数后还能绕圈；最后 `+ 'A'` 变回字母。
<!-- end-card -->

<!-- demo -->
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char x = 'Y';
    int d = 3;                        // 往后移 3 格
    char y = (x - 'A' + d + 26) % 26 + 'A';
    cout << y << endl;                // B（Y→Z→A→B，绕了一圈）
    return 0;
}
```
<!-- end-demo -->

## 挑战5：编程题-凯撒密码

<!-- card type:computer -->
🖥️ **编程题 2：凯撒密码**

凯撒密码把明文中的每个字母按固定数目偏移后替换成密文。例如偏移量是 3 时，A 变 D，B 变 E，……，X 变 A，Y 变 B，Z 变 C。

现在给你一个已破解的明文与对应密文，以及一段相同偏移量的待破解密文，请输出它对应的明文。

**输入：** 三行，依次是已破解明文、已破解密文、待破解密文（长度均不超过 1000，全是大写字母）

**输出：** 一行，待破解密文对应的明文

**样例输入：**
```
ABCDEFGVWXYZ
DEFGHIJYZABC
WKHTXLFNEURZQIRAMXPSVRYHUWKHODCBGRJ
```

**样例输出：**
```
THEQUICKBROWNFOXJUMPOVERTHELAZYDOG
```

**解释：** 由样例得偏移量为 `'D' - 'A' = 3`，密文 W 减 3 是 T，K 减 3 是 H，以此类推。
<!-- end-card -->

<!-- card type:tip -->
🤔 先想一想：遮住下面的答案，自己先做 5 分钟，再往下看！
<!-- end-card -->

<!-- demo -->
💡 **参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s1, s2, s3; cin >> s1 >> s2 >> s3;
    int d = (s1[0] - s2[0] + 26) % 26;
    for (int i = 0; i < s3.size(); i++)
        cout << char((s3[i] - 'A' + d) % 26 + 'A');
    return 0;
}
```

思路：s1[0] 和 s2[0] 一减就知道偏移量 d（`+26` 再 `%26` 防止负数）。解密 = 密文每个字母往前挪 d 格，`% 26` 让 Z 后面绕回 A。
<!-- end-demo -->

<!-- card type:computer -->
🖥️ **编程题 1（2025-12）：密码强度**

小柯设密码，系统要检查够不够强：密码长度 ≥ 8，且**同时**含有大写字母和数字，才算强密码，输出 `Y`；否则输出 `N`。可能有多组测试。

**输入：** 每组一行一个密码字符串（长度不超过 100）
**输出：** 每组一行 `Y` 或 `N`

**样例输入：**
```
PAs1s2an
ab1da3cd
Pa2
```
**样例输出：**
```
Y
N
N
```
<!-- end-card -->

<!-- card type:tip -->

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
```

## 挑战11：编程题-最低报价

<!-- card type:computer -->
🖥️ **编程题 2（2025-12）：最低报价**

有 M 种商品（编号 1~M）。商家陆续给出 N 条报价：每种商品 K 有一个价格 P。对每种商品，只留下**最便宜**的那条报价，求 1~M 所有商品最低价之和。

**输入：** 第一行 M、N；接下来 N 行，每行 K P
**输出：** 一个整数，最低价之和

**样例输入：**
```
5 3
1 10
2 5
1 8
```
**样例输出：**
```
13
```
（商品1最低 8，商品2最低 5，商品3~5 无报价记为 0，8+5=13）
<!-- end-card -->

<!-- card type:tip -->
🤔 先想一想：遮住下面的答案，自己先做 5 分钟，再往下看！
<!-- end-card -->

<!-- demo -->
💡 **参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[100005];
int main() {
    int m, n; cin >> m >> n;
    for (int i = 0; i <= m; i++) a[i] = 1e9;
    for (int i = 0; i < n; i++) { int k, p; cin >> k >> p; a[k] = min(a[k], p); }
    int t = 0; for (int k = 1; k <= m; k++) t += a[k];
    cout << t << endl;
    return 0;
}
```

思路：用数组 `a[k]` 记商品 k 的最低价（先初始化成一个超大数），每读一条报价就用 `min` 更新；最后把 1~M 全部加起来。
<!-- end-demo -->
