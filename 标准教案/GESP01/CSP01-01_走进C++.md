# CSP01-01 走进C++

## 一、课程简介（5分钟）

**🎯 课程目标：**
1. 掌握 Dev-C++ 编程环境的基本使用，建立编写程序的标准习惯。
2. 熟练默写 C++ 的基本程序框架，理解代码入口与出口。
3. 认识计算机世界的"容器"——变量，掌握主流变量的声明、赋值与初始化。
4. 攻克基础的输入输出（`cin`/`cout`）与常用算术运算。

**📚 核心知识点：**
1. Dev-C++ 的使用与基本程序框架
2. 变量的类型（如 `int`）、声明、赋值与初始化
3. 赋值语句与局部变量的随机值问题
4. 基础输入（`cin`）、输出（`cout`）与换行
5. 核心算术运算（`+`、`-`、`*`、`/`、`%`）

## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

### 2. 知识点讲解

**🔴 知识点 1、2：Dev-C++ 与基本程序框架**

带领学生双击打开 Dev-C++，敲下人生第一段魔法代码：

```cpp
#include <iostream>
using namespace std;
int main() {
    // 这是魔法生效的地方
    return 0;
}
```

> **深度演示**：将代码故意少写分号或写成中文符号，展示报错红线，让学生知道"编译器是个挑剔的老师"。

---

**🔴 知识点 3、4、6：什么是变量与赋值？**

> "在黑板上画一个箱子，外面贴个标签叫 `a`，告诉计算机这只能装整数，这就叫 `int a;`（声明）。"
>
> "把苹果放进去：`a = 5;`（赋值）。"
>
> **提问互动**：如果不往里面放东西直接输出呢？（老师演示局部变量未初始化时打印出奇怪的随机值，强调初始化的重要性！）

---

**🔴 知识点 5：输入输出 `cin`/`cout`**

> `cout` 是大喇叭，向屏幕输出内容，用法：`cout << "Hello" << endl;`（`endl` 就是回车换行）。
>
> `cin` 是吸尘器，把键盘敲击吸进箱子里，用法：`cin >> a;`。

---

**🔴 知识点 7：算术运算重难点**

普通的加减乘除大家都懂，重点讲解除法和取模：

> **重点**：详细讲解**整除 `/`**（只保留整数部分，砍掉小数）和**取模 `%`**（取余数）。

```cpp
cout << 10 / 3;  // 输出 3，不是 3.33！
cout << 10 % 3;  // 输出 1（余数）
```

### 3. GESP真题演练 ⚡

1. **（2024年09月一级）** 在 C++ 中，下列表达式错误的是（　　）。
   - A. `cout << "Hello,GESP!" << endl;`
   - B. `cout << 'Hello,GESP!' << endl;`
   > **解析**：单引号只能装单个字符，长句必须用双引号。选 **B**。

2. **（2024年09月一级）** C++ 表达式 `10 - 3 * 2` 的值是（　　）。
   > **解析**：极速抢答，运算优先级和数学里一样先乘后减！结果是 **4**。

3. **（2024年09月一级）** 假设 $N$ 为正整数 10，则 `cout << (N / 3 + N % 3)` 将输出（　　）。
   > **解析**：`10 / 3 = 3`（向零取整），`10 % 3 = 1`，加起来是 **4**。

### 4. 进阶扩展

如何不用第三个变量交换两个箱子里的数字？

> **黑板推演**：先讲常规操作（引入 `temp`），演示牛奶和雪碧交换杯子的物理过程。

```cpp
int a = 3, b = 5, temp;
// 三步推演：
temp = a;
a = b;
b = temp;
cout << a << " " << b;  // 输出 5 3
```

## 四、课堂练习（45分钟）

**🎈 课堂练习（阶梯式进阶，老师巡班指导）**

---

### 练习 1：【打印 Hello World】

输出一行文字 `Hello, World!`。

**输入格式：** 无输入。

**输出格式：** 输出一行 `Hello, World!`

**输出样例：**
```
Hello, World!
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

> **提示**：注意字符串必须用**双引号**括起来，`endl` 是换行。

---

### 练习 2：【基础算术输出】

直接输出以下 5 个算式的结果，每个结果占一行：
`3 + 7`、`10 - 4`、`6 * 8`、`15 / 4`、`15 % 4`

**输入格式：** 无输入。

**输出样例：**
```
10
6
48
3
3
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    cout << 3 + 7 << endl;
    cout << 10 - 4 << endl;
    cout << 6 * 8 << endl;
    cout << 15 / 4 << endl;
    cout << 15 % 4 << endl;
    return 0;
}
```

> **重点**：`15 / 4 = 3`（整数除法砍掉小数），`15 % 4 = 3`（余数）。

---

### 练习 3：【读入两数求和】

读入两个整数 a 和 b，输出它们的和。

**输入格式：** 一行，两个整数 a 和 b（用空格隔开）。

**输出格式：** 输出 a + b 的值。

**输入样例：**
```
3 7
```

**输出样例：**
```
10
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
```

---

### 练习 4：【输入与计算】

读入两个整数 a 和 b，分别输出它们的：和、差、积、整除结果、取模结果，每行一个。

**输入格式：** 一行，两个正整数 a 和 b（b ≠ 0，1 ≤ a, b ≤ 1000）。

**输入样例：**
```
10 3
```

**输出样例：**
```
13
7
30
3
1
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    cout << a - b << endl;
    cout << a * b << endl;
    cout << a / b << endl;
    cout << a % b << endl;
    return 0;
}
```

---

### 练习 5：【综合：交换两个变量】

读入两个整数 a 和 b，将它们的值交换后输出（先输出 b 原来的值，再输出 a 原来的值）。

**输入格式：** 一行，两个整数 a 和 b。

**输入样例：**
```
3 5
```

**输出样例：**
```
5 3
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b, temp;
    cin >> a >> b;
    temp = a;
    a = b;
    b = temp;
    cout << a << " " << b << endl;
    return 0;
}
```

> **思路**：交换两个变量需要借助第三个"中间变量" `temp`，就像倒换两杯饮料需要一个空杯子。

**🔥 拓展习题（尖子生挑战，7 道）：**

---

### 拓展 1：【计算圆的面积】

已知圆的半径 r，输出圆的面积（精确到整数，pi 取 3）。

**输入样例：** `5`　　**输出样例：** `75`

> **提示**：面积 = pi × r × r，用整数运算，pi 直接用 3 代替。

---

### 拓展 2：【时间换算】

输入总秒数 n，输出换算后的"小时:分钟:秒"格式。

**输入样例：** `3723`　　**输出样例：** `1:2:3`

> **提示**：小时 = n / 3600，分钟 = (n % 3600) / 60，秒 = n % 60。

---

### 拓展 3：【数字拆位】

输入一个三位数，分三行输出它的百位、十位、个位数字。

**输入样例：** `352`　　**输出样例：**
```
3
5
2
```
> **提示**：百位 = n / 100，十位 = n / 10 % 10，个位 = n % 10。

---

### 拓展 4：【温度换算】

已知摄氏温度 C，按公式 `F = C * 9 / 5 + 32` 输出对应的华氏温度（整数计算）。

**输入样例：** `100`　　**输出样例：** `212`

---

### 拓展 5：【计算平均分（整数版）】

输入三门课成绩（整数），输出平均分（整数，直接截断小数）。

**输入样例：** `85 90 92`　　**输出样例：** `89`

---

### 拓展 6：【判断末位】

输入一个正整数 n，判断其个位是否为 0（输出 YES 或 NO）。

**输入样例：** `130`　　**输出样例：** `YES`

> **提示**：`n % 10 == 0` 则个位为 0。（这道题需要用到下节课的 `if` 语句，可提前探索！）

---

### 拓展 7：【变量自增】

设 `a = 5`，分别计算 `a++`（先输出再加）和 `++a`（先加再输出）的结果差异，用程序验证并理解。

```cpp
#include <iostream>
using namespace std;
int main() {
    int a = 5;
    cout << a++ << endl;  // 先输出 5，a 变为 6
    cout << a   << endl;  // 此时 a = 6
    int b = 5;
    cout << ++b << endl;  // 先加变为 6，再输出 6
    return 0;
}
```
> **思考**：`a++` 和 `++a` 有什么区别？在不同场景下分别用哪个更合适？
