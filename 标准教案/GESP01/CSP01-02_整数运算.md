### 2. 知识点讲解

**🔴 知识点 1：计算机基础常识**

CPU（大脑）、内存（黑板）、硬盘（书柜）是三大核心组件。

> **互动提问**：大家能说说 CPU、内存、硬盘分别是干什么的吗？
> - CPU：负责运算和控制
> - 内存（RAM）：临时存储，程序运行时使用，断电清空
> - 硬盘：永久存储，断电保留

---

**🔴 知识点 2、3：标识符、关键字与常量、变量**

| 概念 | 说明 | 示例 |
|------|------|------|
| 关键字 | C++ 内置的保留词，不能用作变量名 | `int`、`return`、`if` |
| 标识符 | 程序员自定义的名字 | `myScore`、`num` |
| 常量 | 值不可改变的量 | `3.14`、`'A'`、`100` |
| 变量 | 值可以改变的"箱子" | `int a = 5;` |

> **注意**：标识符命名规则——只能用字母、数字、下划线，且不能以数字开头。`int`、`return` 是关键字，不能用作变量名。

---

**🔴 知识点 4：整型变量 `int` 与 `long long`**

```cpp
int a = 100;             // 约 -21亿 到 21亿
long long b = 100LL;     // 约 -900京 到 900京，超大数必须用这个
```

> **重点提醒**：当题目中的数字可能超过 21 亿时，必须用 `long long`，否则会"整数溢出"，计算结果完全错误！
>
> 赋值超大常量时建议加 `LL` 后缀：`long long x = 3000000000LL;`

---

**🔴 知识点 5：整除 `/` 与取余 `%`**

```cpp
int a = 17, b = 5;
cout << a / b;   // 输出 3（向零截断，砍掉小数部分）
cout << a % b;   // 输出 2（余数）
```

> **拆位口诀**（超级重要，要求背诵！）：
> - 个位数字：`n % 10`
> - 十位数字：`n / 10 % 10`
> - 百位数字：`n / 100 % 10`
>
> **黑板推演**：以 `n = 352` 为例，逐步演算各位数字。

---

**🔴 知识点 6：数字拆位与颠倒**

以三位数 `abc` 为例，颠倒为 `cba`：

```cpp
int n = 352;
int ge  = n % 10;               // 个位：2
int shi = n / 10 % 10;          // 十位：5
int bai = n / 100;              // 百位：3
int rev = ge * 100 + shi * 10 + bai;  // 颠倒：253
cout << rev;
```

> **黑板推演**：用方格画出 352 被拆成 3、5、2，再重新拼装成 253 的过程。

### 4. 进阶扩展

如何不借助任何字符串，只用数学运算把一个任意整数"翻转"？

> **黑板推演**：以 `n = 1234` 为例，用循环反复取末位、去末位：
> - 第1步：末位 = `1234 % 10 = 4`，`n = 1234 / 10 = 123`，`rev = 0 * 10 + 4 = 4`
> - 第2步：末位 = `123 % 10 = 3`，`n = 12`，`rev = 4 * 10 + 3 = 43`
> - 第3步：末位 = `12 % 10 = 2`，`n = 1`，`rev = 43 * 10 + 2 = 432`
> - 第4步：末位 = `1 % 10 = 1`，`n = 0`，`rev = 432 * 10 + 1 = 4321`

```cpp
int n, rev = 0;
cin >> n;
while (n > 0) {
    rev = rev * 10 + n % 10;
    n /= 10;
}
cout << rev;  // 输出 4321
```

### 练习 1：【整除与取余入门】

输入两个正整数 a 和 b，分两行输出 `a / b` 和 `a % b` 的结果。

**参考代码：**
```cpp
#include <iostream>

int main() {
    int a, b;
    cin >> a >> b;
    cout << a / b << endl;
    cout << a % b << endl;
    return 0;
}
```

### 练习 2：【数字拆位】

输入一个三位数 n，分三行输出它的百位、十位、个位数字。

**输入格式：** 一行，一个三位数 n（100 ≤ n ≤ 999）。

**输入样例：**
```
352
```

**输出样例：**
```
3
5
2
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    cout << n / 100 << endl;       // 百位
    cout << n / 10 % 10 << endl;   // 十位
    cout << n % 10 << endl;        // 个位
    return 0;
}
```

> **思路**：熟记拆位口诀：个位 `%10`，十位 `/10 %10`，百位 `/100`。

### 练习 3：【数字颠倒】

输入一个三位数，输出其各位数字颠倒后的三位数（注意：颠倒后的个位变百位，百位变个位）。

**输入格式：** 一行，一个三位数 n（100 ≤ n ≤ 999，且颠倒后仍为三位数，即个位不为 0）。

**输入样例：**
```
352
```

**输出样例：**
```
253
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    int ge  = n % 10;
    int shi = n / 10 % 10;
    int bai = n / 100;
    cout << ge * 100 + shi * 10 + bai << endl;
    return 0;
}
```

### 练习 4：【long long 大数计算】

输入两个较大的正整数 a 和 b（可能超过 10 亿），输出它们的乘积。

**输入格式：** 一行，两个整数 a 和 b（1 ≤ a, b ≤ 1,000,000,000）。

**输入样例：**
```
1000000000 2
```

**输出样例：**
```
2000000000000000000
```

> **重要提示**：`1000000000 * 2 = 2 * 10^9`，已超过 `int` 的范围，必须使用 `long long`！

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    long long a, b;
    cin >> a >> b;
    cout << a * b << endl;
    return 0;
}
```

> **易错点**：如果用 `int a, b;` 接收输入再相乘，即使结果用 `long long` 存，中间乘法也会溢出！必须在读入时就用 `long long`。

有 n 个学生，每 k 个分为一组，求：需要多少完整的组？剩余几名学生？

**输入格式：** 一行，两个正整数 n 和 k（1 ≤ k ≤ n ≤ 10000）。

**输入样例：**
```
37 5
```

**输出样例：**
```
7
2
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n, k;
    cin >> n >> k;
    cout << n / k << endl;   // 完整组数
    cout << n % k << endl;   // 剩余人数
    return 0;
}
```
