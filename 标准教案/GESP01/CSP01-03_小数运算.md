### 2. 知识点讲解

**🔴 知识点 1：实数类型 `float` 与 `double`**

```cpp
float  f = 3.14f;     // 单精度，约 7 位有效数字，占 4 字节
double d = 3.14159;   // 双精度，约 15-16 位有效数字，占 8 字节
```

| 类型 | 占用字节 | 有效数字 | 常用场景 |
|------|---------|---------|---------|
| `float` | 4 字节 | ~7 位 | 精度要求不高时 |
| `double` | 8 字节 | ~15-16 位 | **竞赛中强烈推荐使用** |

> **GESP 考点**：竞赛中几乎所有小数都用 `double`，`float` 精度不够，容易产生误差！
>
> **注意**：`float` 字面量要加 `f` 后缀：`3.14f`；`double` 直接写 `3.14` 即可。

---

**🔴 知识点 2：有效数字与位数保留**

默认情况下，`cout` 只输出 6 位有效数字。想控制小数位数，需引入 `<iomanip>`：

```cpp
#include <iostream>
#include <iomanip>
using namespace std;
int main() {
    double pi = 3.14159265358979;
    cout << pi << endl;                        // 输出 3.14159（默认6位）
    cout << fixed << setprecision(2) << pi << endl;  // 输出 3.14
    cout << fixed << setprecision(4) << pi << endl;  // 输出 3.1416
    return 0;
}
```

> **关键**：`fixed` 表示固定小数位数格式，`setprecision(n)` 设置保留 n 位小数（会四舍五入）。
>
> **一旦设置后，后续所有 `cout` 输出的小数都会按此格式，除非重新设置。**

---

**🔴 知识点 3："四舍六入五凑双"与浮点数近似存储**

你以为 `setprecision` 就是普通的四舍五入？其实 C++ 遵循"银行家舍入"：

> - 四舍六入：到 5 时，若后一位非 0，则进位；若为 0，则看保留的最后一位是奇数还是偶数——奇数进位，偶数舍去。
> - 示例：`2.5` → `2`，`3.5` → `4`（最近的偶数）

**更重要的是浮点数存储误差：**

```cpp
cout << fixed << setprecision(15) << 0.1 + 0.2 << endl;
// 输出 0.300000000000000044...（不是精确的 0.3！）
```

> **GESP 考点**：浮点数在计算机中是用二进制近似存储的，存在精度误差。因此，**永远不要用 `==` 判断两个浮点数是否相等**！应用差值绝对值与极小量（如 `1e-9`）比较。

---

**🔴 知识点 4：整数转小数（类型转换）**

**隐式转换（自动）**：混合运算时，C++ 自动把低精度类型提升：

```cpp
int a = 5, b = 2;
double result = a / b;       // 先整除得 2，再转为 2.0，结果是 2.0！
double result2 = (double)a / b;  // 先把 a 转为 5.0，再除，结果是 2.5
```

> **常见陷阱**：`int / int` 永远是整数除法！必须至少有一个操作数为 `double`，才能得到小数结果。

**显式转换（强制）**：
```cpp
int x = 7;
double y = (double)x / 2;   // 3.5，推荐写法
double z = x / 2.0;          // 3.5，也可以
```

> **百分数技巧**：`(double)score / total * 100` → 先转换再乘，避免整除。

---

**🔴 知识点 5：程序的注释**

注释是程序员给自己和他人看的说明，不影响程序运行：

```cpp
// 单行注释：这是一行注释

/*
 * 多行注释：
 * 这里可以写很多行
 * 适合大段说明
 */

int main() {
    int score = 95; // 成绩变量
    return 0;
}
```

> **好习惯**：每个变量、每段关键代码都要写注释，比赛调试时救自己！

### 3. GESP真题演练 ⚡

1. **（2024年03月一级）** 以下代码的输出结果是（　　）。
   ```cpp
   #include <iostream>
   #include <iomanip>
   using namespace std;
   int main() {
       double x = 3.1415;
       cout << fixed << setprecision(2) << x << endl;
   }
   ```
   A. `3.14`　　B. `3.15`　　C. `3.1`　　D. `3.1415`
   > **解析**：`setprecision(2)` 保留 2 位小数，四舍五入后 `3.1415` → **`3.14`**。选 A。

2. **（2023年09月一级）** 下列关于 `double` 和 `float` 说法正确的是（　　）。
   - A. `float` 精度比 `double` 高
   - B. `double` 比 `float` 占用更多内存，精度更高
   - C. 两者完全相同
   - D. `int` 可以直接赋值给 `double` 但会丢失精度
   > **解析**：`double` 占 8 字节，`float` 占 4 字节，`double` 精度更高。选 **B**。

3. **判断题**：`int a = 5, b = 2; double r = a / b;` 执行后，r 的值是 2.5。（　　）
   > **解析**：**错误**。`a / b` 是整数除法，结果为 2，再赋值给 `double` 得 2.0，不是 2.5。答案是 **×**。

### 4. 进阶扩展

如何计算一个分数（如 15/7）保留 3 位小数的结果？

> **黑板推演**：有同学会写 `15 / 7`，结果是整数 2，完全不对！正确写法：

```cpp
#include <iostream>
#include <iomanip>
using namespace std;
int main() {
    int a = 15, b = 7;
    cout << fixed << setprecision(3) << (double)a / b << endl;
    // 输出 2.143
    return 0;
}
```

### 练习 2：【平均分计算】

读入三个科目的整数成绩，输出保留 2 位小数的平均分。

**输入样例：** `85 92 78`

**输出样例：** `85.00`

**参考代码：**
```cpp
#include <iostream>
#include <iomanip>
using namespace std;
int main() {
    int a, b, c;
    cin >> a >> b >> c;
    double avg = (double)(a + b + c) / 3;
    cout << fixed << setprecision(2) << avg << endl;
    return 0;
}
```

> **注意**：必须用 `(double)` 进行强制类型转换，否则 `(a+b+c)/3` 是整数除法！

#include <iostream>

### 作业 3：【两点距离】

输入两个点的坐标 (x1,y1) 和 (x2,y2)（整数），输出两点之间的距离，保留 4 位小数。

> **提示**：需要包含 `<cmath>`，使用 `sqrt()` 函数。

**输入样例：** `0 0 3 4`　　**输出样例：** `5.0000`

**参考代码：**
```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;
int main() {
    double x1, y1, x2, y2;
    cin >> x1 >> y1 >> x2 >> y2;
    double dist = sqrt((x2-x1)*(x2-x1) + (y2-y1)*(y2-y1));
    cout << fixed << setprecision(4) << dist << endl;
    return 0;
}
```
