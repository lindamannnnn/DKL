# CSP01-04 单双路分支

## 一、课程简介（5分钟）

**🎯 课程目标：**
1. 理解布尔类型 `bool` 与布尔判断的概念，掌握真假值的运算。
2. 熟练使用 6 种关系运算符进行条件判断。
3. 掌握单路分支 `if` 与双路分支 `if-else` 的结构与使用场景。
4. 掌握三目运算符的写法，能进行奇偶与倍数判断。

**📚 核心知识点：**
1. 布尔判断与布尔变量 `bool`（`true`/`false`，与 0/1 的关系）
2. 6 种关系运算符（`>`、`>=`、`<`、`<=`、`==`、`!=`）
3. 单路分支 `if`：条件成立时执行，格式与注意事项
4. 双路分支 `if-else`：二选一执行
5. 奇偶判断（`n % 2`）与倍数判断（`n % k == 0`）
6. 三目运算符 `条件 ? 值1 : 值2`

## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> "同学们，你们见过闯红灯的路口监控吗？
>
> 摄像头一直在问一个问题：'这辆车现在是不是闯红灯了？'
>
> 如果是，就拍照、记录、扣分；如果不是，什么都不做，放行。
>
> 这就是 `if` 语句的精髓——**满足条件才执行，不满足就跳过**！"

### 2. 知识点讲解

**🔴 知识点 1：布尔类型 `bool`**

`bool` 是一种只有两种值的特殊类型：`true`（真，等同于 1）和 `false`（假，等同于 0）。

```cpp
bool flag = true;
bool ok = false;
cout << flag << endl;  // 输出 1
cout << ok << endl;    // 输出 0
```

> **GESP 考点**：C++ 中，任何非 0 的整数都代表 `true`，0 代表 `false`。
> ```cpp
> bool a = 5;    // a = true（输出 1）
> bool b = -3;   // b = true（输出 1，非 0 即真）
> bool c = 0;    // c = false（输出 0）
> ```

---

**🔴 知识点 2：关系运算符（6 种）**

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `>` | 大于 | `5 > 3` | `true`（1）|
| `>=` | 大于等于 | `3 >= 3` | `true`（1）|
| `<` | 小于 | `5 < 3` | `false`（0）|
| `<=` | 小于等于 | `3 <= 5` | `true`（1）|
| `==` | 等于 | `3 == 3` | `true`（1）|
| `!=` | 不等于 | `3 != 3` | `false`（0）|

> **超高频易错点**：赋值用 `=`，判断相等必须用 `==`！写成 `if(a = 5)` 是赋值，永远为真！这是 GESP 频繁考查的陷阱。

代码演示：

```cpp
int a = 4, b = 7, c = -5;
cout << (a < b) << endl;    // 1
cout << (a > b) << endl;    // 0
cout << (c <= 0) << endl;   // 1
cout << (5 != 9) << endl;   // 1
cout << (a == 4) << endl;   // 1
```

---

**🔴 知识点 3：单路分支 `if`**

```cpp
if (条件) {
    // 只有条件为 true 时才执行
}
// 无论条件真假，都会执行这里
```

示例——判断成绩是否优秀：

```cpp
int score;
cin >> score;
if (score >= 90) {
    cout << "优秀！" << endl;
}
cout << "考试结束。" << endl;  // 无论成绩如何都输出
```

> **注意**：当 `if` 里只有一条语句时，可以省略大括号，但**强烈建议初学者保留大括号**，避免逻辑错误。

---

**🔴 知识点 4：双路分支 `if-else`**

```cpp
if (条件) {
    // 条件为 true 时执行
} else {
    // 条件为 false 时执行
}
```

示例——判断奇偶：

```cpp
int n;
cin >> n;
if (n % 2 == 0) {
    cout << n << " 是偶数" << endl;
} else {
    cout << n << " 是奇数" << endl;
}
```

> **流程图解读**：`if-else` 像一条分叉路，条件成立走左路，不成立走右路，两路最终再汇合。

---

**🔴 知识点 5：奇偶判断与倍数判断**

```cpp
// 奇偶判断
if (n % 2 == 0) cout << "偶数";
else cout << "奇数";

// 倍数判断（判断 n 是否是 k 的倍数）
if (n % k == 0) cout << n << " 是 " << k << " 的倍数";
```

> **GESP 常考**：判断 n 是 3 的倍数且是 5 的倍数（即 15 的倍数）：`n % 15 == 0` 或 `n % 3 == 0 && n % 5 == 0`（`&&` 下节课学）。

---

**🔴 知识点 6：三目运算符**

格式：`条件 ? 值1 : 值2`——条件为真取值1，假取值2。

```cpp
int a = 2, b = 3;
int maxVal = (a > b) ? a : b;   // maxVal = 3
cout << maxVal << endl;

// 等价于：
int maxVal2;
if (a > b) maxVal2 = a;
else maxVal2 = b;
```

> **GESP 考点**：三目运算符是 `if-else` 的简写，常用于求两数最大值、最小值等一行搞定的场景。

### 3. GESP真题演练 ⚡

1. **（2024年09月一级）** 造成以下程序编译错误的是哪条语句？
   ```cpp
   if(a + b > 0)  cout << "positive" << endl;     // 语句c
   else (a + b < 0) cout << "negative" << endl;   // 语句d
   ```
   > **解析**：`else` 后面不加任何条件，`(a+b<0)` 是多余的，语法错误在**语句 d**。

2. **（2023年06月一级）** 下列代码中，变量 `flag` 输出的值是（　　）。
   ```cpp
   bool flag = (10 % 3 == 1);
   cout << flag;
   ```
   A. `0`　　B. `1`　　C. `true`　　D. `false`
   > **解析**：`10 % 3 = 1`，`1 == 1` 为 `true`，`bool` 输出为整数 **1**。选 B。

3. **（2024年03月一级）** `int a = 5;` 执行 `if(a = 3) cout << "yes"; else cout << "no";` 输出什么？
   > **解析**：`a = 3` 是**赋值**，值为 3（非 0，即 true），所以输出 **yes**。这道题考查赋值与判断的混淆！

### 4. 进阶扩展

用三目运算符求三个数中的最大值：

```cpp
int a, b, c;
cin >> a >> b >> c;
int maxAB = (a > b) ? a : b;              // 先求 a、b 最大值
int maxABC = (maxAB > c) ? maxAB : c;    // 再与 c 比
cout << maxABC << endl;
```

> **黑板推演**：输入 3 5 4，逐步演算：maxAB = 5，maxABC = max(5, 4) = 5。

### 练习 2：【倍数判断】

输入两个正整数 a 和 k，判断 a 是否是 k 的倍数，是则输出 `YES`，否则输出 `NO`。

**输入样例：** `12 4`　　**输出样例：** `YES`

**参考代码：**
```cpp
#include <iostream>

int main() {
    int a, k;

    else cout << "NO" << endl;

```

### 练习 3：【比大小（求两数最大值）】

输入两个整数 a 和 b，输出其中较大的数（若相等则输出任意一个）。

**输入样例：** `5 8`　　**输出样例：** `8`

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;
    if (a > b) cout << a << endl;
    else cout << b << endl;
    return 0;
}
```

> **进阶写法（三目运算符）：** `cout << (a > b ? a : b) << endl;`

### 练习 4：【成绩评级】

输入一个整数成绩 score（0-100），如果 >= 60 输出 `Pass`，否则输出 `Fail`。

**输入样例：** `75`　　**输出样例：** `Pass`

**参考代码：**

### 练习 5：【装苹果（上取整问题）】

有 a 个苹果，每个篮子能装 b 个，问至少需要多少个篮子？

**输入格式：** 两个正整数 a 和 b。

**输入样例：** `16 3`　　**输出样例：** `6`

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;
    // 方法一：if 判断余数
    int baskets = a / b;
    if (a % b > 0) baskets++;
    cout << baskets << endl;
    return 0;
}
```

> **思路**：上取整公式 `(a + b - 1) / b` 是竞赛中的常用技巧，等价于上面的 `if` 写法。

### 作业 1：【正负判断】

输入一个整数，输出它是正数（`positive`）、负数（`negative`）还是零（`zero`）。

**参考代码：**

```cpp
#include <iostream>

    else if (n < 0) cout << "negative" << endl;
    else cout << "zero" << endl;

```

### 作业 2：【绝对值】

输入一个整数 n，输出其绝对值。

**输入样例：** `-5`　　**输出样例：** `5`

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    if (n < 0) n = -n;
    cout << n << endl;
    return 0;
}
```

---

### 作业 3：【三数最大值（三目运算符）】

输入三个整数，用三目运算符（不用 if）输出最大值。

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b, c;
    cin >> a >> b >> c;
    int m = (a > b) ? a : b;
    m = (m > c) ? m : c;
    cout << m << endl;
    return 0;
}
```
