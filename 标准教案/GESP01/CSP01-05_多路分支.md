### 2. 知识点讲解

**🔴 知识点 1：多路分支 `if - else if - else`**

语法结构：

```cpp
if (条件1) {
    // 条件1 成立时执行
} else if (条件2) {
    // 条件1 不成立，条件2 成立时执行
} else if (条件3) {
    // 以此类推...
} else {
    // 以上所有条件都不成立时执行
}
```

成绩评级示例：

```cpp
int score;
cin >> score;
if (score >= 90) {
    cout << "优秀" << endl;
} else if (score >= 80) {
    cout << "良好" << endl;
} else if (score >= 60) {
    cout << "及格" << endl;
} else {
    cout << "不及格" << endl;
}
```

> **执行原则**：从第一个 `if` 开始逐一判断，**一旦某个条件成立，执行对应代码块后直接跳出整个结构，不再判断后面的条件**。因此 `score >= 80` 这个条件隐含了"score < 90"的前提！

---

**🔴 知识点 2：逻辑运算符**

| 运算符 | 名称 | 含义 | 示例 | 结果 |
|--------|------|------|------|------|
| `&&` | 逻辑与 | 两边都为 true 结果才为 true | `3>1 && 5>2` | `true` |
| `\|\|` | 逻辑或 | 两边有一个为 true 结果就为 true | `3>1 \|\| 5<2` | `true` |
| `!` | 逻辑非 | 取反，true 变 false，false 变 true | `!(3>5)` | `true` |

```cpp
int x = 5;
cout << (x > 1 && x < 10) << endl;   // 1（5 在 1 到 10 之间）
cout << (x < 0 || x > 3) << endl;    // 1（5 > 3 成立）
cout << !(x == 5) << endl;           // 0（x 确实等于 5，取反为 false）
```

> **短路规则（GESP 考点）**：
> - `&&`：左边为 `false` 时，**直接短路**，不再计算右边
> - `||`：左边为 `true` 时，**直接短路**，不再计算右边

---

**🔴 知识点 3：运算符优先级**

从高到低（记住方向即可，括号永远最高）：

| 优先级 | 类型 | 示例 |
|--------|------|------|
| 最高 | 括号 `()` | 改变所有计算顺序 |
| ↑ | 单目运算符 | `!`、`-`（负号）、`++`、`--` |
| ↑ | 算术运算符 | `*`、`/`、`%` 高于 `+`、`-` |
| ↑ | 关系运算符 | `>`、`>=`、`<`、`<=` 高于 `==`、`!=` |
| ↑ | 逻辑与 | `&&` |
| ↑ | 逻辑或 | `\|\|` |
| 最低 | 赋值运算符 | `=`、`+=` 等 |

```cpp
// 示例：不加括号时的优先级
bool ret = 3 + 2 > 4 && 10 % 3 == 1;
// 等价于：((3+2) > 4) && ((10%3) == 1) → (5>4) && (1==1) → true && true → true
```

> **建议**：只要你不确定优先级，就**加括号**！代码可读性更好，也不容易出错。

**🔴 知识点 4：闰年平年判断**

闰年规则（重要！必须全记）：
- **普通闰年**：年份能被 4 整除，但不能被 100 整除
- **世纪闰年**：年份能被 400 整除

```cpp
int year;
cin >> year;
if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
    cout << year << " 是闰年" << endl;
} else {
    cout << year << " 是平年" << endl;
}
```

> **验证测试**：2000 年（能被400整除）是闰年；1900 年（被100整除但不被400整除）是平年；2024年（被4整除且不被100整除）是闰年。

### 3. GESP真题演练 ⚡

1. **（2024年09月一级）** 表达式 `a>0 && b>0` 与 `!(a<=0 || b<=0)` 的逻辑是否等价？
   > **解析**：用德摩根定律：`!(A || B) = !A && !B`，所以 `!(a<=0 || b<=0)` = `a>0 && b>0`，**完全等价**。答案是 **√**。

2. **（2023年03月一级）** 下列代码中，当输入 `85` 时，输出的是？
   ```cpp
   if (score >= 90) cout << "A";
   else if (score >= 80) cout << "B";
   else if (score >= 70) cout << "C";
   else cout << "D";
   ```
   > **解析**：score = 85，第一个条件 `>= 90` 不成立，第二个 `>= 80` 成立，输出 **B**，后续不再判断。

3. **判断题**：`a && b || c` 等价于 `(a && b) || c`，而不是 `a && (b || c)`。（　　）
   > **解析**：**正确**，`&&` 优先级高于 `||`，所以先算 `a&&b`，再与 `c` 进行 `||` 运算。答案是 **√**。

### 练习 4：【三数排序输出】

输入三个整数 a、b、c，从小到大输出。

**输入样例：** `5 1 3`　　**输出样例：** `1 3 5`

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b, c, t;
    cin >> a >> b >> c;
    // 冒泡思路：三次比较确保有序
    if (a > b) { t=a; a=b; b=t; }
    if (a > c) { t=a; a=c; c=t; }
    if (b > c) { t=b; b=c; c=t; }
    cout << a << " " << b << " " << c << endl;
    return 0;
}
```
