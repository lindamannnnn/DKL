# CSP01-08 循环控制

## 一、课程简介（5分钟）

**🎯 课程目标：**
1. 掌握 `continue` 和 `break` 在循环中的精确用法与区别。
2. 理解质数与合数的概念，掌握质数判断的基础方法与优化方法。

**📚 核心知识点：**
1. `continue`：跳过本次循环剩余部分，进入下次循环
2. `break`：立即跳出当前循环（或 switch）
3. 质数与合数的定义（大于1的自然数）
4. 标记变量 `bool`（flag 技术）
5. 质数判断优化：只需枚举到 `sqrt(n)`
6. `sqrt()` 函数的引入与使用（`<cmath>`）

## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> "想象你在检查一批鸡蛋，100个鸡蛋一个个检查。
>
> 如果某个鸡蛋有裂缝——`continue`，跳过这一个，继续检查下一个。
>
> 如果发现了整箱坏掉的——`break`，停！这箱不要了，直接结束检查。
>
> 这就是 `continue`（跳过）和 `break`（直接停）的区别！"

### 2. 知识点讲解

**🔴 知识点 1：`continue` —— 跳过本次**

```cpp
// 输出 1-10 中所有不是 3 的倍数的数
for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) continue;  // 跳过，直接进入下次循环
    cout << i << " ";
}
// 输出：1 2 4 5 7 8 10
```

> **执行流程**：遇到 `continue` → 跳过循环体剩余部分 → 执行更新（i++）→ 判断条件 → 继续...

---

**🔴 知识点 2：`break` —— 直接跳出**

```cpp
// 找到第一个大于 100 的 7 的倍数
for (int i = 1; ; i++) {        // 条件留空代表无限循环
    if (i % 7 == 0 && i > 100) {
        cout << i << endl;      // 找到了
        break;                   // 立即退出循环
    }
}
// 输出：105
```

> **关键区别**：
> - `continue`：跳过**本次**循环的剩余代码，循环**继续进行**
> - `break`：**彻底跳出**当前循环，循环**立即结束**

---

**🔴 知识点 3：质数与合数**

- **质数（素数）**：只有 1 和本身两个因子的大于 1 的自然数（如：2, 3, 5, 7, 11...）
- **合数**：除 1 和本身外还有其他因子的大于 1 的自然数（如：4, 6, 8, 9...）
- **特别注意**：1 既不是质数也不是合数！

---

**🔴 知识点 4：标记变量 `bool`（flag 技巧）**

判断 n 是否是质数：

```cpp
int n;
cin >> n;
bool isPrime = true;        // 假设 n 是质数（flag）
if (n < 2) isPrime = false; // 特殊情况：小于 2 不是质数
for (int i = 2; i < n; i++) {
    if (n % i == 0) {
        isPrime = false;    // 发现因子，标记为非质数
        break;              // 找到一个就够了，立即退出
    }
}
if (isPrime) cout << n << " 是质数";
else cout << n << " 不是质数";
```

> **flag 技巧**：用一个布尔变量记录当前"状态"，在循环中根据情况修改状态，循环结束后再判断状态。这是竞赛中超实用的编程范式！

---

**🔴 知识点 5：质数判断优化**

暴力枚举到 n-1 时间复杂度为 O(n)。实际上：

> **优化思路**：如果 n 有因子 d（d ≠ 1, d ≠ n），一定满足 d ≤ √n。因此只需枚举到 √n 即可！

---

**🔴 知识点 6：`sqrt()` 函数**

```cpp
#include <cmath>    // 必须包含这个头文件！

int n = 25;
cout << sqrt(n) << endl;    // 输出 5（返回 double 类型）
```

优化后的质数判断：

```cpp
#include <iostream>
#include <cmath>
using namespace std;
int main() {
    int n;
    cin >> n;
    bool isPrime = (n >= 2);
    for (int i = 2; i <= sqrt(n); i++) {   // 只枚举到 √n
        if (n % i == 0) {
            isPrime = false;
            break;
        }
    }
    cout << (isPrime ? "YES" : "NO") << endl;
    return 0;
}
```

> **竞赛中更常见的写法**：`for (int i = 2; i * i <= n; i++)` 用乘法代替 `sqrt()`，避免浮点误差！

### 3. GESP真题演练 ⚡

1. **（2024年09月一级）** 以下代码中，循环体执行了几次？
   ```cpp
   for (int i = 0; i < 10; i++) {
       if (i == 5) break;
       if (i % 2 == 0) continue;
       cout << i;
   }
   ```
   > **解析**：i = 0：偶数 continue；i=1：输出 1；i=2：continue；i=3：输出 3；i=4：continue；i=5：break。循环体共执行 **5 次**（i=0,1,2,3,4），输出 `13`。

2. **（2023年06月一级）** 1 既不是质数也不是合数，以下哪个代码能正确判断 n 是否是质数？
   > **解析**：需要先处理 `n < 2` 的情况（返回 false），再从 2 枚举到 sqrt(n)。

3. **判断题**：`continue` 和 `break` 都只影响最内层的循环。（　　）
   > **解析**：**正确**。在嵌套循环中，`break` 和 `continue` 只作用于直接包含它们的那一层循环。答案是 **√**。

### 练习 4：【统计质数个数】

### 作业 1：【跳过 5 的倍数求和】

输入正整数 n，计算 1 到 n 中所有不是 5 的倍数的整数之和。

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    long long sum = 0;
    for (int i = 1; i <= n; i++) {
        if (i % 5 == 0) continue;
        sum += i;
    }
    cout << sum << endl;
    return 0;
}
```

### 作业 2：【找互质对】

判断两个正整数 a, b 是否互质（GCD=1），枚举 2 到 min(a,b) 判断是否有公因子，输出 YES/NO。

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b; cin >> a >> b;
    bool ok = true;
    int mn = (a < b) ? a : b;
    for (int i = 2; i <= mn; i++) {
        if (a % i == 0 && b % i == 0) { ok = false; break; }
    }
    cout << (ok ? "YES" : "NO") << endl;
    return 0;
}
```
