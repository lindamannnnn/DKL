### 2. 知识点讲解

**🔴 知识点 1：求和与平均数（循环输入）**

**模式：输入 n 个数，求和求平均**

```cpp
int n;
cin >> n;
long long sum = 0;       // 求和变量，必须初始化为 0！
for (int i = 0; i < n; i++) {
    int x;
    cin >> x;            // 每次读入一个数
    sum += x;            // 累加到 sum
}
double avg = (double)sum / n;  // 注意：转 double 再除
cout << sum << endl;
cout << fixed << setprecision(2) << avg << endl;
```

> **GESP 考点**：输入 n 个数时，循环变量从 0 到 n-1（共 n 次）或从 1 到 n 均可，注意对应关系。

---

**🔴 知识点 2：因子和**

因子（约数）：能整除 n 的正整数。求 n 的所有因子之和：

```cpp
int n;
cin >> n;
int factorSum = 0;
for (int i = 1; i <= n; i++) {
    if (n % i == 0) {       // i 是 n 的因子
        factorSum += i;
    }
}
cout << factorSum << endl;
// 例如 n=12，因子：1,2,3,4,6,12，因子和 = 28
```

> **真因子和（不含自身）**：把上面改为 `i < n` 即可。若真因子和等于 n 本身，则 n 是完全数（6, 28, 496...）。

**🔴 知识点 3：数据遍历统计**

**常见统计任务模板**：

```cpp
int n; cin >> n;
int cnt = 0;     // 计数
long long sum = 0; // 求和
for (int i = 0; i < n; i++) {
    int x; cin >> x;
    sum += x;
    if (x % 2 == 0) cnt++;  // 统计满足条件的数量
}
cout << sum << endl;
cout << cnt << endl;
```

**🔴 知识点 4：最大值与最小值（擂台法）**

用"擂台"思想：让第一个数上台，后续每个数和擂主比，赢了就换人：

```cpp
int n; cin >> n;
int maxVal, minVal;
cin >> maxVal;       // 先读第一个数作为初始擂主
minVal = maxVal;
for (int i = 1; i < n; i++) {
    int x; cin >> x;
    if (x > maxVal) maxVal = x;  // 更大就更新最大值
    if (x < minVal) minVal = x;  // 更小就更新最小值
}
cout << "最大值: " << maxVal << endl;
cout << "最小值: " << minVal << endl;
```

> **注意**：也可以将 maxVal 初始化为 `INT_MIN`（最小整数），minVal 初始化为 `INT_MAX`（最大整数），需包含 `<climits>`。

**综合模板**（n 个数，输出最大值、最小值、平均值）：

```cpp
#include <iostream>
#include <iomanip>
#include <climits>
using namespace std;
int main() {
    int n; cin >> n;
    long long sum = 0;
    int maxVal = INT_MIN, minVal = INT_MAX;
    for (int i = 0; i < n; i++) {
        int x; cin >> x;
        sum += x;
        if (x > maxVal) maxVal = x;
        if (x < minVal) minVal = x;
    }
    cout << "最大值: " << maxVal << endl;
    cout << "最小值: " << minVal << endl;
    cout << fixed << setprecision(2) << "平均值: " << (double)sum / n << endl;
    return 0;
}
```

### 3. GESP真题演练 ⚡

1. **（2024年09月一级）** 以下代码计算了什么？
   ```cpp
   int n = 6, s = 0;
   for (int i = 1; i <= n; i++)
       if (n % i == 0) s += i;
   cout << s;
   ```
   > **解析**：这是求 n=6 的所有因子之和：因子为 1,2,3,6，所以 s = **12**。

2. **判断题**：在循环中将 maxVal 初始化为第一个输入值，比初始化为 0 更通用。（　　）
   > **解析**：**正确**。若所有数都是负数，初始化为 0 会导致最大值错误。初始化为第一个值或 `INT_MIN` 更安全。答案是 **√**。

3. **（2023年06月一级）** 输入 5 个数：3 1 4 1 5，下列代码输出是？
   ```cpp
   int x, s = 0;
   for (int i = 0; i < 5; i++) { cin >> x; s += x; }
   cout << s;
   ```
   > **解析**：3+1+4+1+5 = **14**。

### 4. 进阶扩展

边输入边更新最大值（流式统计，输入 -1 结束）：

```cpp
int x, maxVal = INT_MIN, cnt = 0;
long long sum = 0;
while (cin >> x && x != -1) {  // 读到 -1 就停止
    sum += x;
    cnt++;
    if (x > maxVal) maxVal = x;
}
cout << "共 " << cnt << " 个数，最大值：" << maxVal << "，平均：";
cout << fixed << setprecision(2) << (double)sum / cnt << endl;
```

### 练习 5：【综合统计】

输入 n 个整数，输出：正数的个数、负数的个数、零的个数、所有数之和。

**输入样例：**
```
6
3 -1 0 4 -2 0
```
**输出样例：**
```
2
2
2
4
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    int pos = 0, neg = 0, zero = 0;
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        int x; cin >> x;
        sum += x;
        if (x > 0) pos++;
        else if (x < 0) neg++;
        else zero++;
    }
    cout << pos << endl << neg << endl << zero << endl << sum << endl;
    return 0;
}
```

```cpp
#include <iostream>

}
```
