# CSP01-10 while循环

## 一、课程简介（5分钟）

**🎯 课程目标：**
1. 掌握 `while` 循环和 `do-while` 循环的语法与执行特点。
2. 理解 `while` 与 `for` 循环的适用场景差异。
3. 掌握复合赋值运算符（`+=`、`-=`、`*=`、`/=`、`%=`）的用法。

**📚 核心知识点：**
1. `while` 循环结构：先判断后执行，条件为假则一次都不执行
2. `do-while` 循环结构：先执行后判断，至少执行一次
3. `while` vs `for` vs `do-while` 的选用原则
4. 复合赋值运算符：`+=`、`-=`、`*=`、`/=`、`%=`

## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> "想象你在挖矿，不知道挖到哪层会挖到矿石。
>
> 你的策略是：'只要没挖到矿石，就继续挖一层'。
>
> 这就是 while 循环——**只要条件成立，就一直做**！
>
> 而 do-while 是：'先挖一铲子，再看看有没有矿'——至少干一次活！"

### 2. 知识点讲解

**🔴 知识点 1：`while` 循环结构**

```cpp
while (条件) {
    循环体;    // 只要条件为 true，就反复执行
    // 必须有让条件趋向 false 的语句，否则死循环！
}
```

执行顺序：
1. 判断条件 → true 则执行循环体，false 则跳出
2. 执行循环体
3. **回到步骤 1** 重新判断

```cpp
// 输出 1 到 5（while 版）
int i = 1;           // 初始化（在循环外！）
while (i <= 5) {
    cout << i << " ";
    i++;             // 更新（在循环内！）
}
// 输出：1 2 3 4 5
```

> **与 for 循环对比**：
> ```cpp
> // 这两段代码完全等价
> for (int i = 1; i <= 5; i++) cout << i << " ";
> 
> int i = 1;
> while (i <= 5) { cout << i << " "; i++; }
> ```
>
> **适用场景**：循环次数未知时（如"读到 0 停止"）用 while；次数明确时用 for。

---

**🔴 知识点 2：`do-while` 循环结构**

```cpp
do {
    循环体;    // 先执行一次，再判断
} while (条件);  // 注意：这里有分号！
```

```cpp
// 用 do-while 读入一个正整数（非正则重新输入）
int n;
do {
    cout << "请输入正整数：";
    cin >> n;
} while (n <= 0);
cout << "输入成功：" << n << endl;
```

> **关键区别**：
> - `while`：先判断，**可能一次都不执行**（条件一开始就为 false 时）
> - `do-while`：先执行，**至少执行一次**
>
> **实际竞赛中 `do-while` 使用较少，但 GESP 会考查其执行次数问题。**

---

**🔴 知识点 3：`while` vs `for` vs `do-while`**

| 特性 | `for` | `while` | `do-while` |
|------|-------|---------|-----------|
| 执行次数 | 0 或多次 | 0 或多次 | **至少 1 次** |
| 适用场景 | 次数已知 | 次数未知，先判断 | 至少做一次，先执行 |
| 三要素位置 | 集中在 for 头部 | 分散在循环外和内 | 分散 |

---

**🔴 知识点 4：复合赋值运算符**

| 写法 | 等价于 | 说明 |
|------|--------|------|
| `a += b` | `a = a + b` | 加法赋值 |
| `a -= b` | `a = a - b` | 减法赋值 |
| `a *= b` | `a = a * b` | 乘法赋值 |
| `a /= b` | `a = a / b` | 整除赋值 |
| `a %= b` | `a = a % b` | 取模赋值 |

```cpp
int n = 100;
n /= 2;    // n = 50
n += 30;   // n = 80
n %= 9;    // n = 80 % 9 = 8
cout << n; // 输出 8
```

> **GESP 考点**：复合赋值运算符在循环中出现频率极高，如 `sum += x`、`n /= 10`（数字拆位中常见）。

### 3. GESP真题演练 ⚡

1. **（2024年09月一级）** 以下代码执行后 n 的值是？
   ```cpp
   int n = 100;
   while (n > 1) n /= 2;
   cout << n;
   ```
   > **解析**：100→50→25→12→6→3→1，当 `n=1` 时条件 `n>1` 为 false，退出。`n = 1`。输出 **1**。

2. **（2023年06月一级）** `do-while` 和 `while` 的本质区别是什么？
   > **解析**：`do-while` 先执行循环体再判断条件，至少执行一次；`while` 先判断，若初始条件为 false 则循环体一次都不执行。

3. **判断题**：`n += 5` 等价于 `n = n + 5`。（　　）
   > **解析**：**正确**。复合赋值运算符是简化写法。答案是 **√**。

### 4. 进阶扩展

`while` 循环经典应用——辗转相除求最大公约数：

```cpp
int a, b;
cin >> a >> b;
while (b != 0) {
    int r = a % b;
    a = b;
    b = r;
}
cout << a << endl;   // 循环结束时 a 就是 GCD
```

> **黑板推演**：a=48, b=18：
> - 第1步：r = 48%18 = 12，a=18, b=12
> - 第2步：r = 18%12 = 6，a=12, b=6
> - 第3步：r = 12%6 = 0，a=6, b=0
> - b=0，退出，GCD = **6**

### 练习 1：【while 倒计时】

输入正整数 n，用 while 循环从 n 倒数到 1，每个数字占一行。

**输入样例：** `5`

**输出样例：**
```
5
4
3
2
1
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    while (n >= 1) {
        cout << n << endl;
        n--;
    }
    return 0;
}
```

---

### 练习 2：【复合运算符练习】

输入整数 n，反复执行以下操作直到 n 等于 1：如果 n 是偶数，`n /= 2`；如果 n 是奇数，`n = n * 3 + 1`。统计操作次数并输出（Collatz 猜想）。

**输入样例：** `6`　　**输出样例：** `8`（6→3→10→5→16→8→4→2→1，共8步）

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    long long n; cin >> n;
    int cnt = 0;
    while (n != 1) {
        if (n % 2 == 0) n /= 2;
        else n = n * 3 + 1;
        cnt++;
    }
    cout << cnt << endl;
    return 0;
}
```

### 练习 3：【数字拆位（while 版）】

输入正整数 n，用 while 循环逐位输出其各位数字（从个位到最高位），每位占一行。

**输入样例：** `1234`

**输出样例：**

**参考代码：**
```cpp
#include <iostream>

int main() {
```

### 练习 4：【最大公约数（GCD）】

输入两个正整数，用辗转相除法输出它们的最大公约数。

**输入样例：** `48 18`　　**输出样例：** `6`

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b; cin >> a >> b;
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    cout << a << endl;
    return 0;
}
```

### 练习 5：【do-while 菜单模拟】

模拟一个简单菜单：用 do-while 循环，读入用户的选择（1=继续，0=退出），每次打印"已选择 X"，直到选 0 为止，输出共循环了几次。

**输入样例：** `1 1 1 0`

**输出样例：** `3`（输入了 3 次 1 然后选 0）

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int choice, cnt = 0;
    do {
        cin >> choice;
        if (choice != 0) cnt++;
    } while (choice != 0);
    cout << cnt << endl;
    return 0;
}
```

### 作业 1：【while 求和】

输入正整数 n，用 while 循环求 1 到 n 的和。

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    long long sum = 0;
    int i = 1;
    while (i <= n) { sum += i; i++; }
    cout << sum << endl;
    return 0;
}
```

---

### 作业 2：【n 的位数】

输入正整数 n，输出它有多少位（如 123 是 3 位数）。

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    int cnt = 0;
    while (n > 0) { n /= 10; cnt++; }
    cout << cnt << endl;
    return 0;
}
```

---

### 作业 3：【GCD 与 LCM】

输入两个正整数，用辗转相除法求 GCD，再利用 `lcm = a * b / gcd` 求 LCM（最小公倍数），分两行输出。

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    long long a, b; cin >> a >> b;
    long long x = a, y = b;
    while (y != 0) { long long r = x % y; x = y; y = r; }
    cout << x << endl;
    cout << a / x * b << endl;
    return 0;
}
```
