### 2. 知识点讲解

**🔴 知识点 1：`while(t--)` 循环 n 次**

`t--` 是后置自减：先读取 t 的值用于判断，再将 t 减 1。

```cpp
int t = 3;
while (t--) {
    cout << "执行一次" << endl;
}
// 过程：
// t=3(true) → 执行 → t变为2
// t=2(true) → 执行 → t变为1
// t=1(true) → 执行 → t变为0
// t=0(false) → 退出
// 共执行 3 次
```

等价于：`for (int i = 0; i < t; i++) { ... }`

> **GESP/NOI 竞赛模板**：
> ```cpp
> int t;
> cin >> t;
> while (t--) {
>     // 处理每组数据
>     int n; cin >> n;
>     // ...
> }
> ```

---

**🔴 知识点 2：数位求和**

求一个整数各位数字之和（如 1234 → 1+2+3+4 = 10）：

```cpp
int n;
cin >> n;
int digitSum = 0;
while (n > 0) {
    digitSum += n % 10;   // 加上个位
    n /= 10;              // 去掉个位
}
cout << digitSum << endl;
```

> **黑板推演**：n = 1234
> - 1234 % 10 = 4，1234 / 10 = 123
> - 123 % 10 = 3，123 / 10 = 12
> - 12 % 10 = 2，12 / 10 = 1
> - 1 % 10 = 1，1 / 10 = 0
> - 结果：4+3+2+1 = **10**

---

**🔴 知识点 3：数字包含判断**

判断整数 n 中是否含有数字 d：

```cpp
int n, d;
cin >> n >> d;
bool found = false;
int temp = n;    // 保留原值，用 temp 拆位
while (temp > 0) {
    if (temp % 10 == d) {
        found = true;
        break;
    }
    temp /= 10;
}
cout << (found ? "包含" : "不包含") << endl;
```

> **注意**：数字 0 的特殊情况——如果 n=10，含有数字 0，但 while(n>0) 不包含最后的 0！
>
> 特殊处理：如果 d=0，直接判断 n 是否有余数为 0 的某一位，或先转成字符串处理。

---

**综合应用：数位求和 + t 组数据**

```cpp
#include <iostream>
using namespace std;
int main() {
    int t;
    cin >> t;
    while (t--) {
        int n; cin >> n;
        int sum = 0;
        if (n == 0) { cout << 0 << endl; continue; }
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }
        cout << sum << endl;
    }
    return 0;
}
```

### 3. GESP真题演练 ⚡

1. **（2024年09月一级）** `while(t--)` 中 t 初始为 5，循环体共执行几次？
   > **解析**：t 依次为 5,4,3,2,1（均大于0），共执行 **5** 次。t 最后变为 -1。

2. **（2023年06月一级）** 以下代码对数 n = 2023 的数位求和结果是？
   ```cpp
   int n = 2023, s = 0;
   while (n > 0) { s += n % 10; n /= 10; }
   cout << s;
   ```
   > **解析**：3 + 2 + 0 + 2 = **7**。

3. **判断题**：`while(t--)` 和 `for(int i=0; i<t; i++)` 对循环体执行次数的效果完全相同，但执行后 t 的值不同。（　　）
   > **解析**：**正确**。for 循环结束后 i=t（原值），而 while(t--) 结束后 t 变为 -1。答案是 **√**。

### 4. 进阶扩展

数码积（各位数字乘积），遇到 0 直接输出 0：

```cpp
int n; cin >> n;
long long product = 1;
bool hasZero = false;
while (n > 0) {
    int d = n % 10;
    if (d == 0) { hasZero = true; break; }
    product *= d;
    n /= 10;
}
cout << (hasZero ? 0 : product) << endl;
```

### 练习 5：【含某数位的数字统计】

输入正整数 n 和数字 d，统计 1 到 n 中有多少个整数的数位中含有数字 d。

**输入样例：** `20 2`　　**输出样例：** `3`（2,12,20）

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n, d; cin >> n >> d;
    int cnt = 0;
    for (int num = 1; num <= n; num++) {
        int temp = num;
        while (temp > 0) {
            if (temp % 10 == d) { cnt++; break; }
            temp /= 10;
        }
    }
    cout << cnt << endl;
    return 0;
}
```

### 作业 3：【多组数据判质数】

第一行输入 T，接下来 T 行每行一个整数 n，判断是否是质数，输出 YES/NO。

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int t; cin >> t;
    while (t--) {
        int n; cin >> n;
        bool ok = (n >= 2);
        for (int i = 2; i * i <= n; i++)
            if (n % i == 0) { ok = false; break; }
        cout << (ok ? "YES" : "NO") << endl;
    }
    return 0;
}
```
