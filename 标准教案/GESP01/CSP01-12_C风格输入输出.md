# CSP01-12 C风格输入输出

## 一、课程简介（5分钟）

**🎯 课程目标：**
1. 掌握 `printf` 和 `scanf` 的基本用法。
2. 理解占位符的概念与常用格式符（`%d`、`%lld`、`%f`、`%lf`、`%c`、`%s`）。
3. 掌握格式化输入输出的完整写法，特别是宽度、精度控制。
4. 综合运用时间换算等实际问题。

**📚 核心知识点：**
1. `printf` 格式：`printf("格式字符串", 变量1, 变量2, ...)`
2. 占位符（格式符）：`%d`（int）、`%lld`（long long）、`%f`（float）、`%lf`（double）、`%c`（char）、`%s`（字符串）
3. 格式控制：宽度 `%nd`、精度 `%.nf`、左对齐 `%-nd`
4. `scanf` 格式：`scanf("格式字符串", &变量1, &变量2, ...)`（注意取地址 `&`）
5. 时间换算综合应用

### 2. 知识点讲解

**🔴 知识点 1：`printf` 基础用法**

```cpp
#include <cstdio>   // 使用 printf/scanf 需要包含此头文件
// 也可以用 #include <iostream> 或 bits/stdc++.h

printf("Hello, World!\n");            // 输出字符串，\n 是换行符
printf("整数：%d\n", 42);            // %d 对应 int
printf("长整数：%lld\n", 1000000000LL);  // %lld 对应 long long
printf("小数：%f\n", 3.14);          // %f 输出 float 或 double（默认6位小数）
printf("保留2位小数：%.2f\n", 3.14159); // %.2f 保留 2 位小数
printf("字符：%c\n", 'A');           // %c 对应 char
printf("两个数：%d %d\n", 10, 20);   // 多个占位符
```

---

**🔴 知识点 2：占位符（格式符）完整列表**

| 格式符 | 对应类型 | 说明 |
|--------|---------|------|
| `%d` | `int` | 十进制整数 |
| `%lld` | `long long` | 长整数（64位）|
| `%f` | `float`/`double` | 浮点数，默认6位小数 |
| `%lf` | `double` | 在 scanf 中读 double 必须用 %lf！|
| `%c` | `char` | 单个字符 |
| `%s` | 字符串 | C 风格字符串 |
| `%o` | `int` | 八进制整数 |
| `%x` | `int` | 十六进制整数 |

> **GESP 重要区别**：
> - `printf` 中输出 `double` 用 `%f` 或 `%.2f` 均可
> - `scanf` 中读入 `double` **必须用 `%lf`**，用 `%f` 读入 double 是错误的！

---

**🔴 知识点 3：格式控制（宽度与精度）**

```cpp
printf("%5d\n", 42);     // 宽度5，右对齐：   42
printf("%-5d|\n", 42);   // 宽度5，左对齐：42   |
printf("%05d\n", 42);    // 宽度5，用0填充：00042
printf("%.3f\n", 3.14159); // 保留3位小数：3.142
printf("%8.2f\n", 3.14);   // 宽度8，保留2位小数：    3.14
```

---

**🔴 知识点 4：`scanf` 基础用法**

```cpp
int a;
scanf("%d", &a);    // 注意：& 是取地址符，必须加！

double d;
scanf("%lf", &d);   // 读 double 必须用 %lf

int x, y;
scanf("%d %d", &x, &y);   // 读两个整数

char c;
scanf(" %c", &c);   // 注意引号内的空格，用来跳过空白字符（含换行）
```

> **极重要**：`scanf` 读变量时必须加 `&`（取地址），忘了会导致运行时错误！这是 GESP 必考陷阱。
>
> **例外**：`scanf("%s", str)` 读字符串时，str 是数组名（本身就是地址），不加 `&`。

---

**🔴 知识点 5：时间换算综合应用**

输入总秒数，换算为时:分:秒格式：

```cpp
#include <cstdio>
int main() {
    int t;
    scanf("%d", &t);
    int h = t / 3600;
    int m = t % 3600 / 60;
    int s = t % 60;
    printf("%02d:%02d:%02d\n", h, m, s);  // %02d：宽度2，用0填充
    return 0;
}
// 输入：3723   输出：01:02:03
```

### 3. GESP真题演练 ⚡

1. **（2024年09月一级）** `printf("%.3f\n", 3.14159);` 输出的是？
   A. `3.141`　　B. `3.142`　　C. `3.14159`　　D. `3.14`
   > **解析**：保留 3 位小数，四舍五入，3.14159 → **3.142**。选 B。

2. **（2023年06月一级）** 以下哪段代码可以正确读入一个 double 类型的变量 x？
   - A. `scanf("%f", &x);`（x 是 double）
   - B. `scanf("%lf", &x);`（x 是 double）
   > **解析**：scanf 读 double 必须用 `%lf`，用 `%f` 读 double 是未定义行为。选 **B**。

3. **（2024年03月一级）** `printf("%5d", 42)` 的输出是？
   > **解析**：宽度 5，右对齐，不足用空格填充：`   42`（前面 3 个空格）。

### 4. 进阶扩展

```cpp
#include <cstdio>

    return 0;
}
```

### 练习 2：【scanf 读入并计算】

用 scanf 读入两个整数，用 printf 输出它们的和、差、积，每行一个。

**输入样例：** `10 3`

**输出样例：**
```
13
7
30
```

**参考代码：**
```cpp
#include <cstdio>
int main() {
    int a, b;
    scanf("%d %d", &a, &b);
    printf("%d\n", a + b);
    printf("%d\n", a - b);
    printf("%d\n", a * b);
    return 0;
}
```

---

### 练习 3：【格式化输出表格】

输入 5 个整数，按右对齐宽度 6 的格式每行一个输出。

**输入样例：** `1 23 456 7890 12345`

**输出样例：**
```
     1
    23
   456
  7890
 12345
```

**参考代码：**
```cpp
#include <cstdio>
int main() {
    for (int i = 0; i < 5; i++) {
        int x; scanf("%d", &x);
        printf("%6d\n", x);
    }
    return 0;
}
```

---

### 练习 4：【时间换算】

输入总秒数 t（正整数），输出格式化的"时:分:秒"，每段都保持两位数（不足两位前补 0）。

**输入样例：** `3723`　　**输出样例：** `01:02:03`

**参考代码：**
```cpp
#include <cstdio>
int main() {
    int t; scanf("%d", &t);
    printf("%02d:%02d:%02d\n", t/3600, t%3600/60, t%60);
    return 0;
}
```

---

### 练习 5：【混合类型综合输出】

输入一个整数 a、一个 double 数 b 和一个字符 c，格式化输出：整数宽度 5，小数保留 3 位，字符直接输出。

**输入样例：** `42 3.14159 G`

**输出样例：** `   42 3.142 G`

**参考代码：**
```cpp
#include <cstdio>
int main() {
    int a; double b; char c;
    scanf("%d %lf %c", &a, &b, &c);
    printf("%5d %.3f %c\n", a, b, c);
    return 0;
}
```

```cpp
#include <cstdio>
```

### 作业 2：【日期格式化】

输入年月日（三个整数），按 `YYYY-MM-DD` 格式输出（月和日不足两位补 0）。

**输入样例：** `2024 3 6`　　**输出样例：** `2024-03-06`

**参考代码：**
```cpp
#include <cstdio>
int main() {

    printf("%04d-%02d-%02d\n", y, m, d);
    return 0;
}
```

### 作业 3：【小数格式对比】

用 printf 分别以 `%f`、`%.2f`、`%10.4f` 三种格式输出圆周率 3.14159265，观察输出差异。

**参考代码：**
```cpp
#include <cstdio>
int main() {
    double pi = 3.14159265;
    printf("%f\n", pi);
    printf("%.2f\n", pi);
    printf("%10.4f\n", pi);
    return 0;
}
```
