### Part A：选择题训练 ⚡（每题 2 分）

---

**A1.（2024年09月 GESP 一级第1题）** 以下关于 C++ 语言的说法，**错误**的是？
- A. C++ 是 C 语言的超集，兼容大部分 C 语言语法
- B. C++ 支持面向对象编程
- C. C++ 程序必须有 `main` 函数作为执行入口
- D. C++ 程序可以不包含任何头文件也能正常编译运行

> **解析**：D 错误。如果程序使用了 `cout`、`cin`、`printf` 等函数，必须包含对应头文件；但如果程序只有 `int main(){ return 0; }` 这种最简框架可以不包含头文件。选 **D**。

---

**A2.（2024年09月 GESP 一级第2题）** 以下代码的执行结果是？
```cpp
int a = 10, b = 3;
cout << a / b << " " << a % b;
```
- A. `3 1`　　B. `3.33 1`　　C. `3 3`　　D. `4 1`

> **解析**：`int / int` 整除，`10/3=3`，`10%3=1`。选 **A**。

---

**A3.（2024年03月 GESP 一级）** 变量 `a` 经过 `a += 3; a *= 2; a -= 1;` 三次操作后等于 15，则 a 初始值是？

> **解析**：设初始值为 x，则 `((x+3)*2)-1 = 15` → `(x+3)*2 = 16` → `x+3 = 8` → `x = 5`。答案是 **5**。

---

**A4.（2023年09月 GESP 一级）** 判断整数 n 能被 3 整除但不能被 9 整除的正确条件是？
- A. `n % 3 == 0 && n % 9 != 0`
- B. `n % 3 == 0 || n % 9 != 0`
- C. `n % 3 != 0 && n % 9 == 0`
- D. `n % 9 == 0`

> **解析**：需要同时满足"被 3 整除"AND"不被 9 整除"，使用 `&&`。选 **A**。

---

**A5.（2024年09月 GESP 一级）** 以下关于 `switch` 语句的描述，正确的是？
- A. switch 后面的括号内可以是浮点数表达式
- B. 省略 default 语句会导致编译错误
- C. 如果某个 case 省略 break，程序会继续执行下一个 case 的代码
- D. 每个 case 后面的值可以是变量

> **解析**：C 正确（穿透现象）。A 错（switch 只支持整数/字符类型）；B 错（default 可选）；D 错（case 后必须是常量）。选 **C**。

---

**A6.（2023年06月 GESP 一级）** 以下代码的输出是？
```cpp
for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) continue;
    if (i == 7) break;
    cout << i << " ";
}
```
> **解析**：i=1(输出)，2(输出)，3(continue跳过)，4(输出)，5(输出)，6(continue跳过)，7(break退出)。
> 输出：**1 2 4 5**

---

**A7.（2024年03月 GESP 一级）** `printf("%-8.2f", 3.14)` 的输出是（_=空格）？
- A. `__3.14__`　　B. `3.14____`　　C. `____3.14`　　D. `3.1400__`

> **解析**：`%-8.2f`：左对齐（-），宽度 8，保留 2 位小数。3.14 保留 2 位是 `3.14`，左对齐后右边补空格：`3.14    `（4个空格）。选 **B**。

---

**A8.（2023年09月 GESP 一级）** 输入一个字符 c，下列哪段代码能判断 c 是小写字母并将其转为大写输出？
- A. `if (c >= 'a' && c <= 'z') cout << c - 32;`
- B. `if (c >= 'a' && c <= 'z') cout << (char)(c - 32);`
- C. `if (c >= 65 && c <= 90) cout << (char)(c + 32);`
- D. `if (c >= 'A' && c <= 'Z') cout << (char)(c + 32);`

> **解析**：B 正确——判断小写范围，转大写是 -32，需要强转为 char 输出字母。A 不加强转输出整数；C判断的是大写范围；D判断大写转小写（方向反了）。选 **B**。

### Part B：判断题训练（每题 1 分）

**B1.** `long long` 类型的变量最大可以存储约 9×10¹⁸ 的整数。（　　）
> **答案**：**√**。long long 占 8 字节，最大值约 9.2×10¹⁸。

**B2.** `do-while` 循环的循环体至少执行一次，即使条件初始为 false。（　　）
> **答案**：**√**。do-while 是先执行后判断。

**B3.** 在 `scanf` 中读入 `double` 类型变量，应使用 `%f` 格式符。（　　）
> **答案**：**×**。scanf 读 double 必须用 `%lf`，`%f` 用于 float。

**B4.** `bool` 类型变量只能赋值 `true` 或 `false`，赋值整数会报错。（　　）
> **答案**：**×**。C++ 中可以将整数赋值给 bool，非 0 为 true，0 为 false。

**B5.** 全局变量在没有显式初始化时，其默认值为 0。（　　）
> **答案**：**√**。全局变量自动初始化为 0（整型），局部变量不会。

**C2.【奇偶统计】**

输入 n 个整数，分别统计其中奇数、偶数的个数，输出两行。

**输入样例：**
```
5
1 2 3 4 5
```
**输出样例：**
```
3
2
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    int odd = 0, even = 0;
    for (int i = 0; i < n; i++) {
        int x; cin >> x;
        if (x % 2 == 0) even++;
        else odd++;
    }
    cout << odd << endl << even << endl;
    return 0;
}
```

---

**C3.【质数判断】**

输入一个整数 n，判断是否为质数，是输出 `YES`，否则输出 `NO`。

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    bool ok = (n >= 2);
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) { ok = false; break; }
    cout << (ok ? "YES" : "NO") << endl;
    return 0;
}
```

### 作业 2：【成绩统计】

输入 n 个成绩（0-100 整数），输出最高分、最低分和平均分（保留 2 位小数）。

**参考代码：**
```cpp
#include <iostream>
#include <iomanip>
#include <climits>
using namespace std;
int main() {
    int n; cin >> n;
    int mx = INT_MIN, mn = INT_MAX;
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        int x; cin >> x;
        if (x > mx) mx = x;
        if (x < mn) mn = x;
        sum += x;
    }
    cout << mx << endl << mn << endl;
    cout << fixed << setprecision(2) << (double)sum / n << endl;
    return 0;
}
```
