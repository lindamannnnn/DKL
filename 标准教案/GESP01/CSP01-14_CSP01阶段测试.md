### 第一部分：选择题（共 10 题，每题 3 分，共 30 分）

**1.** 下列关于 C++ 基本数据类型，说法**正确**的是？
- A. `float` 的精度高于 `double`
- B. `long long` 占 4 个字节
- C. `char` 类型本质上是一种整数类型
- D. `bool` 类型只能赋值 0 或 1

> **答案：C**
> 解析：char 本质是整数，ASCII 编码。A错（double精度更高）；B错（long long 占8字节）；D错（任意整数均可赋给bool）。

---

**2.** 执行 `int a = 7, b = 2; double c = a / b;` 后，c 的值是？
- A. `3.5`　　B. `3`　　C. `3.0`　　D. `4.0`

> **答案：C**
> 解析：`a/b` 是整数除法，结果为整数 3，再赋给 double 得到 3.0（不是 3.5！）。

**3.** 下列代码输出是？
```cpp
int x = 10;
cout << x++ << " " << ++x;
```
- A. `10 12`　　B. `11 12`　　C. `10 11`　　D. `11 11`

> **答案：A**
> 解析：`x++` 输出当前值 10，x变为11；`++x` 先将x变为12再输出12。输出 `10 12`。

**4.** 关于以下代码，描述正确的是？
```cpp
switch (n) {
    case 1: cout << "one";
    case 2: cout << "two"; break;
    case 3: cout << "three";
}
```
当 n = 1 时，输出是？
- A. `one`　　B. `onetwo`　　C. `onetwothree`　　D. `two`

> **答案：B**
> 解析：case 1 没有 break，发生穿透，继续执行 case 2 的 `cout << "two"`，遇到 break 退出。输出 `onetwo`。

**5.** 下列选项中，能判断年份 y 是闰年的正确条件是？
- A. `y % 4 == 0`
- B. `y % 4 == 0 || y % 400 == 0`
- C. `(y % 4 == 0 && y % 100 != 0) || y % 400 == 0`
- D. `y % 100 != 0 || y % 400 == 0`

> **答案：C**
> 解析：标准闰年判断：普通闰年（能被4整除但不能被100整除）或世纪闰年（能被400整除）。

**6.** 以下 for 循环执行了多少次循环体？
```cpp
for (int i = 1; i <= 100; i *= 2) { ... }
```
- A. 6　　B. 7　　C. 8　　D. 100

> **答案：B**
> 解析：i = 1, 2, 4, 8, 16, 32, 64（7个值均 ≤ 100），下一个 128 > 100，退出。共 **7** 次。

**7.** 关于 `scanf` 和 `printf`，描述**错误**的是？
- A. `scanf` 读取变量时需要在变量前加 `&`
- B. `printf("%.2f", 3.14159)` 输出 `3.14`
- C. `scanf` 读取 `double` 类型，格式符应使用 `%lf`
- D. `printf` 输出 `double` 类型，格式符必须使用 `%lf`

> **答案：D**
> 解析：`printf` 输出 double 用 `%f` 即可（C 语言中 float 传参会提升为 double），不必用 `%lf`。

---

**8.** 以下代码不超过 5 行内，计算结果 a 等于多少？
```cpp
int a = 1;
for (int i = 1; i <= 5; i++) a *= i;
```
- A. `5`　　B. `15`　　C. `120`　　D. `25`

> **答案：C**
> 解析：1×2×3×4×5 = 120（5的阶乘）。

**9.** 以下哪个表达式能把大写字母 c 转换为对应的小写字母？
- A. `c + 32`
- B. `(char)(c + 32)`
- C. `c - 32`
- D. `(char)(c - 32)`

> **答案：B**
> 解析：大写转小写加32，需强转为char才能以字符形式输出。

**10.** 以下关于循环的说法，**正确**的有几个？
① for 循环和 while 循环都可能一次都不执行循环体
② do-while 循环的循环体至少执行一次
③ break 只能跳出最内层的循环
④ continue 会跳出当前整个循环
- A. 1个　　B. 2个　　C. 3个　　D. 4个

> **答案：C**（正确的是①②③）
> 解析：④错误——continue 只跳过本次循环的剩余部分，不退出整个循环。

### 第二部分：判断题（共 10 题，每题 2 分，共 20 分）

**11.** `int a;` 声明后，`a` 的值始终为 0。（　　）
> **答案：×**　解析：局部变量不初始化则值为随机数（垃圾值），只有全局变量默认为 0。

**12.** `10 / 3` 在 C++ 中的结果为浮点数 3.3333...（　　）
> **答案：×**　解析：两个整数相除，结果是整数 3（截断小数）。

**13.** 逻辑运算符 `&&` 的优先级低于 `||`。（　　）
> **答案：×**　解析：`&&` 优先级高于 `||`。

**14.** `'0'` 对应的 ASCII 码值是 48。（　　）
> **答案：√**　解析：字符 '0' 的 ASCII 码为 48，'9' 为 57。

**15.** `while(0)` 的循环体一次都不会执行。（　　）
> **答案：√**　解析：条件为 0（false），直接不进入循环。

**16.** `printf("%d", 3.14)` 能正确输出 3。（　　）
> **答案：×**　解析：格式不匹配（double 用 %d 输出），是未定义行为，结果不可预测。

**17.** `n % 2 == 0` 能判断 n 是否为偶数，包括负数的情况。（　　）
> **答案：√**　解析：C++ 中负数取模结果符号与被除数一致，如 `-4 % 2 == 0` 为 true。

**18.** 闰年的判断中，2100 年是闰年。（　　）
> **答案：×**　解析：2100 被 100 整除但不被 400 整除，是平年。

**19.** `break` 语句在 `switch` 中和在循环中的作用完全相同。（　　）
> **答案：×**　解析：作用类似但位置不同——switch 中 break 跳出 switch 块；循环中 break 跳出循环。

**20.** `scanf("%lf", &x)` 中，如果 x 是 double 类型，这段代码是正确的。（　　）
> **答案：√**　解析：scanf 读 double 用 %lf，加 & 取地址，写法正确。

**编程题 1：【水仙花数】（25分）**

水仙花数是指一个 3 位数，其各位数字的立方和等于该数本身。例如：$153 = 1^3 + 5^3 + 3^3$，因此 153 是水仙花数。

请编写程序，输出所有三位数中的水仙花数，每个占一行。

**输出样例（前两行）：**
```
153
370
...
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    for (int n = 100; n <= 999; n++) {
        int a = n / 100;         // 百位
        int b = n / 10 % 10;    // 十位
        int c = n % 10;         // 个位
        if (a*a*a + b*b*b + c*c*c == n) {
            cout << n << endl;
        }
    }
    return 0;
}
// 输出：153 370 371 407
```

**评分要点：**
- 能正确枚举 100-999（5分）
- 能正确拆出三位数的百位、十位、个位（10分）
- 能正确计算立方和并与原数比较（5分）
- 输出格式正确（5分）

**编程题 2：【多组数据处理】（25分）**

第一行输入正整数 T（1 ≤ T ≤ 100），接下来 T 行，每行输入一个正整数 n（2 ≤ n ≤ 10000）。

对每个 n，输出其是否是质数（`YES` 或 `NO`），以及其是否是完全平方数（即存在整数 k 使得 k² = n，输出 `SQ` 或 `NSQ`），两个结果用空格分隔，每行一组答案。

**输入样例：**
```
4
2
4
7
9
```

**输出样例：**
```
YES NSQ
NO SQ
YES NSQ
NO SQ
```

**参考代码：**
```cpp
#include <iostream>
#include <cmath>
using namespace std;
int main() {
    int t; cin >> t;
    while (t--) {
        int n; cin >> n;
        // 判断质数
        bool isPrime = (n >= 2);
        for (int i = 2; i * i <= n; i++)
            if (n % i == 0) { isPrime = false; break; }
        // 判断完全平方数
        int sq = (int)sqrt((double)n);
        bool isSq = (sq * sq == n);
        cout << (isPrime ? "YES" : "NO") << " ";
        cout << (isSq ? "SQ" : "NSQ") << endl;
    }
    return 0;
}
```

**评分要点：**
- 正确使用 while(t--) 或等效写法（5分）
- 质数判断逻辑正确（10分）
- 完全平方数判断正确（5分）
- 输出格式正确（5分）

## 📌 教师讲评参考

### 本次测试重点考查的易错点：

1. **第2题**：整数除法后赋给 double 得到的是 `3.0` 而非 `3.5`，类型转换必须在除法**之前**进行。

2. **第4题**：switch 穿透是必考陷阱，建议在黑板上演示执行流程。

3. **第7题**：`printf` 和 `scanf` 中格式符的混用场景——printf 输出 double 用 `%f`，scanf 读入 double 必须用 `%lf`。

4. **第10题**：`continue` 与 `break` 的区别频繁被混淆，需再次强调。

5. **编程题1**：拆位技巧（`/100`、`/10%10`、`%10`）是基础必会操作，得分率应达到 80% 以上。

6. **编程题2**：`while(t--)` + 双重判断的综合题，检验对整个 CSP01 阶段的掌握程度。

### 后续建议：
- 错题率高的知识点（如 switch、printf/scanf）应在 CSP02 开始前安排专项复习。
- 鼓励编程题满分的学生尝试拓展：把质数判断优化为埃拉托斯特尼筛法。
