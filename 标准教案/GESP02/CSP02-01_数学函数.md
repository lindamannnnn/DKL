# CSP02-01 数学函数

## 一、课程简介（5分钟）

**🎯 课程目标：**
1. 掌握 `<cmath>` 头文件中常用数学函数的调用方式与参数类型。
2. 理解取整类函数（`floor`/`ceil`/`round`）与整除取余的区别，避免精度陷阱。
3. 掌握随机数函数 `rand()` / `srand()` 的使用，能生成指定范围内的随机整数。
4. 综合运用数学函数解决实际计算问题，应对 GESP 二级选择判断题。

**📚 核心知识点：**
1. 绝对值函数：`abs()`（`<cmath>` / `<cstdlib>`）
2. 平方根函数：`sqrt()`（返回 `double`，注意精度）
3. 最大值/最小值函数：`max()` / `min()`（`<algorithm>`）
4. 四舍五入函数：`round()`，以及 `floor()`（向下取整）、`ceil()`（向上取整）
5. 随机数函数：`rand()` 与 `srand(time(0))` 种子初始化
6. 函数调用的基本格式：`返回值 = 函数名(参数);`

### 2. 知识点讲解

**🔴 知识点 1：头文件与基本使用格式**

使用数学函数前，必须引入对应头文件：

```cpp
#include <cmath>       // sqrt, abs（浮点版）, round, floor, ceil
#include <algorithm>   // max, min
#include <cstdlib>     // rand, srand, abs（整数版）
#include <ctime>       // time()，配合 srand 使用
```

函数调用格式：

```cpp
返回值类型 结果 = 函数名(参数);
// 例如：
double r = sqrt(25.0);   // r = 5.0
```

> **注意**：`sqrt()` 的参数和返回值都是 `double`，传入整数会自动转换，但返回的是小数！

---

**🔴 知识点 2：绝对值函数 `abs()`**

```cpp
#include <cmath>
int a = abs(-7);       // a = 7（整数绝对值）
double b = abs(-3.14); // b = 3.14（浮点绝对值，需 <cmath>）
```

> **GESP 考点**：`abs()` 在不引入 `<cmath>` 时，只对整数有效；对浮点数必须用 `<cmath>` 版本，否则结果可能出错。

---

**🔴 知识点 3：平方根函数 `sqrt()`**

```cpp
double r = sqrt(16.0);   // r = 4.0
double r2 = sqrt(2.0);   // r2 ≈ 1.41421
int n = (int)sqrt(9.0);  // n = 3（强制转换为整数）
```

> **精度陷阱**：用 `sqrt()` 判断完全平方数时，推荐写法：
> ```cpp
> int sq = (int)round(sqrt(n));
> if (sq * sq == n) // 是完全平方数
> ```
> 直接 `(int)sqrt(n)` 有时因浮点误差会少 1！

---

**🔴 知识点 4：最大值 `max()` 与最小值 `min()`**

```cpp
#include <algorithm>
int a = max(3, 7);      // a = 7
int b = min(3, 7);      // b = 3
double c = max(1.5, 2.3); // c = 2.3（需要同类型！）
```

> **提问互动**：`max(3, 7.0)` 会怎样？（编译报错！两个参数类型必须一致）
>
> 解决方案：`max((double)3, 7.0)` 或 `max(3.0, 7.0)`。

---

**🔴 知识点 5：四舍五入 `round()` / 向下取整 `floor()` / 向上取整 `ceil()`**

```cpp
round(3.4)  // = 3.0（四舍五入）
round(3.5)  // = 4.0
floor(3.9)  // = 3.0（向下取整，地板）
floor(-3.1) // = -4.0（注意负数！）
ceil(3.1)   // = 4.0（向上取整，天花板）
ceil(-3.9)  // = -3.0
```

| 函数 | 含义 | 3.1 | 3.9 | -3.1 | -3.9 |
|------|------|-----|-----|------|------|
| `floor()` | 向下取整（≤） | 3 | 3 | **-4** | **-4** |
| `ceil()`  | 向上取整（≥） | 4 | 4 | **-3** | **-3** |
| `round()` | 四舍五入 | 3 | 4 | -3 | -4 |

> **黑板推演**：在数轴上画出 3.1、3.9、-3.1，标出 floor 和 ceil 的结果，帮助学生直观理解为何负数取整"反直觉"。

---

**🔴 知识点 6：随机数 `rand()` 与 `srand()`**

```cpp
#include <cstdlib>
#include <ctime>

srand(time(0));          // 以当前时间为种子，保证每次运行结果不同
int r = rand();          // 生成 0 到 RAND_MAX（约 32767）的随机整数

// 生成 [a, b] 范围内的随机整数：
int x = rand() % (b - a + 1) + a;
// 例如：生成 1-6（骰子）
int dice = rand() % 6 + 1;
```

> **提问互动**：如果不写 `srand(time(0))`，每次运行 `rand()` 的结果相同还是不同？（相同！因为种子固定为 0）
>
> **类比**：`srand` 就像"洗牌"，`rand()` 就是"摸牌"。不洗牌，每次摸的顺序一样。

### 3. GESP真题演练 ⚡

1. **（GESP二级选择题）** 以下代码输出什么？
   ```cpp
   #include <cmath>
   #include <iostream>
   using namespace std;
   int main() {
       cout << floor(3.7) << " " << ceil(3.2) << endl;
   }
   ```
   > **解析**：`floor(3.7)=3`，`ceil(3.2)=4`，输出 **3 4**。

2. **（GESP二级判断题）** `sqrt(4)` 的返回值是整数类型。（判断对错）
   > **解析**：**错**。`sqrt()` 始终返回 `double` 类型，`sqrt(4)` 返回 `2.0`，不是整数 `2`。

3. **（GESP二级选择题）** 生成 [5, 15] 之间随机整数的正确写法是？
   - A. `rand() % 15 + 5`　　B. `rand() % 11 + 5`　　C. `rand() % 10 + 5`
   > **解析**：范围共 11 个数（5到15），答案是 **B**。公式：`rand() % (b-a+1) + a = rand() % 11 + 5`。

### 4. 进阶扩展

**幂函数 `pow()` 与取整配合：**

```cpp
#include <cmath>
// pow(底数, 指数)
double p = pow(2, 10);   // p = 1024.0（2^10）
double p2 = pow(3, 4);   // p2 = 81.0

// 注意：pow 返回 double，整数运算推荐直接写 2*2*2...
// 竞赛中慎用 pow 做整数运算，存在精度问题！
```

> **黑板推演**：如果你想判断 n 是不是 2 的整数次幂，用 `pow` 与 `round` 配合，或者用位运算 `n & (n-1) == 0` 更安全。

### 练习 3：【判断完全平方数】

输入正整数 n，判断 n 是否为完全平方数，是则输出 `YES`，否则输出 `NO`。

**输入样例1：** `16`　　**输出样例1：** `YES`

**输入样例2：** `15`　　**输出样例2：** `NO`

**参考代码：**
```cpp
#include <iostream>
#include <cmath>
using namespace std;
int main() {
    int n;
    cin >> n;
    int sq = (int)round(sqrt((double)n));
    if (sq * sq == n) cout << "YES" << endl;
    else cout << "NO" << endl;
    return 0;
}
```

> **思路**：用 `round` 防止浮点误差（如 `sqrt(9)` 可能算出 `2.9999...`）。

**参考代码：**
```cpp
#include <iostream>
#include <cmath>
using namespace std;
int main() {
    int cents;
    cin >> cents;
    double yuan = cents / 100.0;
    cout << (int)round(yuan) << endl;
    return 0;
}
```

### 练习 5：【模拟掷骰子】

模拟掷两枚六面骰子（点数 1-6），输出两枚骰子的点数及其和。每次运行结果随机。

**输出格式：** `骰子1: X, 骰子2: Y, 合计: Z`

**参考代码：**
```cpp
#include <iostream>

#include <ctime>

int main() {
    srand(time(0));
    int d1 = rand() % 6 + 1;

}
```

### 作业 2：【向上取整的商】

输入两个正整数 a 和 b，输出 a ÷ b 向上取整的结果（即需要多少个 b 才能装下 a）。

**输入样例：** `10 3`　　**输出样例：** `4`（10÷3=3.33…，向上取整=4）

**参考代码：**
```cpp
#include <iostream>
#include <cmath>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;
    cout << (int)ceil((double)a / b) << endl;
    return 0;
}
```

> **小技巧**：整数向上取整也可以用 `(a + b - 1) / b`，不需要浮点数！
