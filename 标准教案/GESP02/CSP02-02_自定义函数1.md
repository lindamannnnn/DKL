# CSP02-02 自定义函数1

## 一、课程简介（5分钟）

**🎯 课程目标：**
1. 掌握自定义函数的定义格式（返回类型、函数名、参数列表、函数体）。
2. 理解函数的调用与声明（前置声明解决顺序问题）。
3. 区分形参与实参，理解值传递的本质。
4. 区分全局变量与局部变量的作用域，理解同名变量的优先级。

**📚 核心知识点：**
1. 函数定义格式：`返回类型 函数名(形参列表) { 函数体; return 返回值; }`
2. 函数调用：`变量 = 函数名(实参);`
3. 函数声明（前置声明）：解决调用在定义之前的问题
4. 形参（形式参数）与实参（实际参数）的区别
5. 全局作用域与局部作用域：变量的可见范围
6. `void` 类型函数（无返回值）

### 2. 知识点讲解

**🔴 知识点 1：函数的定义格式**

```cpp
返回类型 函数名(类型1 参数名1, 类型2 参数名2, ...) {
    // 函数体
    return 返回值;  // 返回类型为 void 时不需要
}
```

示例——定义一个求两数之和的函数：

```cpp
int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(3, 5);   // 调用函数
    cout << result << endl;   // 输出 8
    return 0;
}
```

> **黑板推演**：画出调用流程：
> `main` 调用 `add(3, 5)` → 进入 add 函数 → a=3, b=5 → 计算 a+b=8 → return 8 → 回到 main，result=8

---

**🔴 知识点 2：函数声明（前置声明）**

如果函数定义在 `main` **后面**，需要在前面加一行声明：

```cpp
int add(int a, int b);  // 前置声明（只写函数头，加分号）

int main() {
    cout << add(3, 5) << endl;
    return 0;
}

int add(int a, int b) {  // 实际定义在后面
    return a + b;
}
```

> **为什么需要声明**：C++ 编译器从上到下读代码，如果看到 `add(3, 5)` 时还没见过 `add` 的定义，就会报错。
>
> 前置声明告诉编译器：**"这个函数等会儿会定义，你先信我一次！"**

---

**🔴 知识点 3：形参与实参**

```cpp
int square(int x) {   // x 是形参（形式参数）
    return x * x;
}

int main() {
    int n = 5;
    cout << square(n) << endl;  // n 是实参（实际参数）
    cout << square(3) << endl;  // 字面量也可以是实参
    return 0;
}
```

**值传递**：实参的值被**复制**给形参，函数内部修改形参**不影响**实参！

```cpp
void tryChange(int x) {
    x = 100;  // 只改了形参的拷贝！
}

int main() {
    int a = 5;
    tryChange(a);
    cout << a << endl;  // 输出 5（a 没有变！）
    return 0;
}
```

> **GESP 考点**：值传递是 C++ 函数传参的默认方式，函数内修改形参不影响原变量，这是高频考点！

---

**🔴 知识点 4：全局作用域与局部作用域**

```cpp
int global = 100;   // 全局变量：整个程序可见

void func() {
    int local = 5;   // 局部变量：只在 func 内可见
    cout << global;  // 可以访问全局变量
    cout << local;   // 可以访问局部变量
}

int main() {
    cout << global;  // 可以访问全局变量
    // cout << local; // 错误！local 在 func 内，main 看不到
    return 0;
}
```

**同名变量的优先级：**

```cpp
int x = 10;         // 全局变量

void show() {
    int x = 20;     // 局部变量，与全局同名
    cout << x;      // 输出 20（局部优先！）
}

int main() {
    cout << x;      // 输出 10（使用全局变量）
    show();
    return 0;
}
```

> **规则**：局部变量优先于全局变量（就近原则）。竞赛中尽量避免同名变量，容易出错！

---

**🔴 知识点 5：void 类型（无返回值函数）**

```cpp
void printStar(int n) {   // 返回类型为 void，不需要 return
    for (int i = 0; i < n; i++) cout << "*";
    cout << endl;
}

int main() {
    printStar(5);   // 调用，不需要接收返回值
    return 0;
}
// 输出：*****
```

### 3. GESP真题演练 ⚡

1. **（GESP二级判断题）** 函数内对形参的修改会影响实参的值。
   > **解析**：**错**。C++ 默认值传递，形参是实参的拷贝，修改形参不影响实参。

2. **（GESP二级选择题）** 以下代码输出什么？
   ```cpp
   int f(int x) { return x * 2; }
   int main() {
       int a = 3;
       cout << f(a) << " " << a << endl;
   }
   ```
   > **解析**：`f(a)` 返回 6，a 本身不变，输出 **6 3**。

3. **（GESP二级判断题）** 全局变量在程序的任何位置都可以被访问和修改。
   > **解析**：**对**。全局变量在整个程序运行期间存在，且可被所有函数访问和修改。

### 4. 进阶扩展

**函数复用——一函多用：**

```cpp
int gcd(int a, int b) {
    while (b) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}

int lcm(int a, int b) {
    return a / gcd(a, b) * b;  // 复用 gcd 函数求 lcm！
}

int main() {
    cout << gcd(12, 8) << endl;   // 4
    cout << lcm(12, 8) << endl;   // 24
    return 0;
}
```

> **黑板推演**：体现了函数的最大价值——**封装复用**。写一次，多次调用，不重复造轮子！

### 练习 2：【函数求最大公约数】

定义函数 `int gcd(int a, int b)` 用辗转相除法求最大公约数，输入两个正整数，输出 gcd。

**输入样例：** `24 36`　　**输出样例：** `12`

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int gcd(int a, int b) {
    while (b) { int t = a % b; a = b; b = t; }
    return a;
}
int main() {
    int a, b; cin >> a >> b;
    cout << gcd(a, b) << endl;
    return 0;
}
```

### 练习 3：【函数判断是否为素数】

定义函数 `bool isPrime(int n)` 判断 n 是否为素数（质数），main 中输入 n，输出 `YES` 或 `NO`。

**输入样例：** `17`　　**输出样例：** `YES`

**参考代码：**
```cpp
#include <iostream>
#include <cmath>
using namespace std;
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i <= (int)sqrt(n); i++) {
        if (n % i == 0) return false;
    }
    return true;
}
int main() {
    int n; cin >> n;
    cout << (isPrime(n) ? "YES" : "NO") << endl;
    return 0;
}
```

### 练习 4：【函数打印星号行】

定义 `void printStars(int n)` 打印 n 个 `*`（不换行），用它在 main 中打印宽度为 w 的星号矩形（输入 w 和 h，共 h 行，每行 w 个 `*`）。

**输入样例：** `4 3`
**输出样例：**
```
****
****
****
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
void printStars(int n) {
    for (int i = 0; i < n; i++) cout << "*";
    cout << endl;
}
int main() {
    int w, h; cin >> w >> h;
    for (int i = 0; i < h; i++) printStars(w);
    return 0;
}
```

### 练习 5：【综合：求 1~n 中所有素数之和】

输入 n，利用 `isPrime` 函数，求 1 到 n 中所有素数的和。

**输入样例：** `10`　　**输出样例：** `17`（2+3+5+7=17）

**参考代码：**
```cpp
#include <iostream>
#include <cmath>
using namespace std;
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i <= (int)sqrt(n); i++)
        if (n % i == 0) return false;
    return true;
}
int main() {
    int n; cin >> n;
    long long sum = 0;
    for (int i = 2; i <= n; i++)
        if (isPrime(i)) sum += i;
    cout << sum << endl;
    return 0;
}
```

```cpp
int myAbs(int n) {
```

### 作业 2：【函数求阶乘】

定义函数 `long long factorial(int n)` 求 n!，输入 n（≤15），输出 n!。

**参考代码：**
```cpp
#include <iostream>
using namespace std;
long long factorial(int n) {
    long long result = 1;
    for (int i = 1; i <= n; i++) result *= i;
    return result;
}
int main() {
    int n; cin >> n;
    cout << factorial(n) << endl;
    return 0;
}
```

```cpp
#include <iostream>
```
