### 2. 知识点讲解

**🔴 知识点 1：流程图的概念与基本符号**

流程图是描述算法逻辑的图形工具，使用统一符号：

| 图形 | 名称 | 用途 |
|------|------|------|
| 椭圆形 | 起止框 | 程序的开始和结束 |
| 矩形 | 处理框 | 计算、赋值等操作 |
| 菱形 | 判断框 | 条件判断（有"是/否"两条路） |
| 平行四边形 | 输入/输出框 | 输入数据或输出结果 |
| 箭头 | 流线 | 表示执行顺序 |

> **黑板推演**：在黑板上画出"输入 n，判断奇偶，输出结果"的流程图：
>
> 开始 → 输入 n → ◇ n%2==0? → 是：输出"偶数" / 否：输出"奇数" → 结束

---

**🔴 知识点 2：ASCII 编码与字符转换**

ASCII（美国标准信息交换码）为每个字符分配一个整数：

| 字符 | ASCII值 | 字符 | ASCII值 | 字符 | ASCII值 |
|------|---------|------|---------|------|---------|
| `'0'` | 48 | `'A'` | 65 | `'a'` | 97 |
| `'1'` | 49 | `'B'` | 66 | `'b'` | 98 |
| `'9'` | 57 | `'Z'` | 90 | `'z'` | 122 |

```cpp
char c = 'A';
cout << (int)c << endl;      // 输出 65（char → int）
cout << (char)(c + 1);       // 输出 'B'（int → char）

// 数字字符转整数：
char digit = '7';
int num = digit - '0';       // num = 7（利用 ASCII 差值）

// 大写转小写：
char upper = 'G';
char lower = upper + 32;     // lower = 'g'（相差 32）
// 或者：char lower = upper - 'A' + 'a';
```

> **GESP 考点**：`'0'` 的 ASCII 是 48，`'A'` 是 65，`'a'` 是 97。大小写字母相差 **32**。这三个数字要能直接记住！

---

**🔴 知识点 3：强制类型转换**

语法：`(目标类型)表达式`

```cpp
int a = 5, b = 2;
cout << a / b << endl;          // 输出 2（整数除法！）
cout << (double)a / b << endl;  // 输出 2.5（强转 a 为 double）
cout << (double)(a / b) << endl;// 输出 2.0（先整除，再转，结果不同！）

double x = 3.9;
int n = (int)x;                  // n = 3（截断小数，不是四舍五入！）
```

> **⚠️ 易错警告**：
> - `(double)a / b` → 先转 a，再除 → **2.5** ✅
> - `(double)(a / b)` → 先整除，再转 → **2.0** ❌（常见错误！）

---

**🔴 知识点 4：隐式类型转换**

C++ 混合运算时，低精度自动升级为高精度：

```cpp
int a = 3;
double b = 1.5;
double c = a + b;   // a 自动转 double，c = 4.5

int x = 1, y = 2;
double z = x + y;   // 先整数加法得 3，再转 double → 3.0（还是丢失精度！）
double w = (double)x + y;  // 正确做法！w = 1.5？ 不对，是 3.0。
// 注意：x/y 都是整数，x+y=3，然后隐式转 double 也是 3.0，不是 1.5！
```

转换优先级（低 →  高）：

```
int → long → long long → float → double
```

> **黑板推演**：在运算中，任何数与 `double` 相加，结果都是 `double`。`1 + 1.0 = 2.0`，`'A' + 0 = 65`（char 升为 int）。

**🔴 知识点 5：周期偏移量**

经典题型：星期几、月份、字母循环移位等——涉及"到头了绕回来"的周期问题。

**通用模型**：`结果 = (x - base + offset) % period + base`

```cpp
// 例1：今天是周三（3），过 10 天是周几？
// 周一=1...周日=7，但取模通常从0开始，所以先减1
int today = 3;  // 周三
int days = 10;
int answer = (today - 1 + days) % 7 + 1;  // = (2+10)%7+1 = 5+1 = 6，周六

// 例2：凯撒密码（字母循环移位）
char c = 'X';
int shift = 5;
char result = (c - 'A' + shift) % 26 + 'A';  // X+5 = C（循环回到开头）
// X=23, (23+5)%26=2, 'A'+2='C'
```

> **提问互动**：如果 'Z' 右移 3 位是什么字母？（'C'）用公式算一遍！

### 4. 进阶扩展

**凯撒密码的解密程序：**

```cpp
#include <iostream>
using namespace std;
char encrypt(char c, int shift) {
    if (c >= 'A' && c <= 'Z')
        return (c - 'A' + shift) % 26 + 'A';
    if (c >= 'a' && c <= 'z')
        return (c - 'a' + shift) % 26 + 'a';
    return c;  // 非字母不变
}
int main() {
    string s;
    int shift;
    cin >> s >> shift;
    for (char c : s) cout << encrypt(c, shift);
    cout << endl;
    return 0;
}
```

> **黑板推演**：输入 `Hello 3`，H→K, e→h, l→o, l→o, o→r，输出 `Khoor`。这就是凯撒密码！
