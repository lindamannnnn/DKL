| 类别 | 举例 | 特点 |
|------|------|------|

**🔴 知识点 2：if 嵌套结构**

```cpp
if (条件1) {
    if (条件2) {
        // 条件1 且 条件2 都满足
    } else {
        // 条件1 满足，条件2 不满足
    }
} else {
    // 条件1 不满足
}
```

实际例子——游乐园售票：

```cpp
int age; bool hasCard;
cin >> age >> hasCard;
if (hasCard) {
    cout << "年卡用户：免费" << endl;
} else {
    if (age < 6) {
        cout << "价格：0元" << endl;
    } else if (age <= 18) {
        cout << "价格：50元" << endl;
    } else {
        cout << "价格：100元" << endl;
    }
}
```

> **黑板推演**：给几组输入（有卡/无卡，不同年龄），让同学追踪代码执行路径。

**🔴 知识点 3：悬空 else（Dangling Else）陷阱**

```cpp
// 问题代码（格式迷惑性！）
if (a > 0)
    if (b > 0)
        cout << "a>0 且 b>0";
    else
        cout << "???";  // 这个 else 属于哪个 if？
```

**C++ 规则**：`else` 始终与**最近的、未配对的**  `if` 匹配！

```cpp
// 等价于：
if (a > 0) {
    if (b > 0)
        cout << "a>0 且 b>0";
    else
        cout << "a>0 但 b<=0";  // else 属于内层 if！
}
// 如果 a <= 0，什么都不输出！
```

**如何写清楚**：务必加大括号！

```cpp
if (a > 0) {
    if (b > 0) {
        cout << "a>0 且 b>0";
    }
} else {
    cout << "a<=0";  // 这样 else 才属于外层 if
}
```

> **⚠️ 竞赛建议**：哪怕只有一条语句，嵌套时**一律加花括号 `{}`**，杜绝悬空 else 错误！

**🔴 知识点 4：switch 嵌套**

```cpp
int op, mode;
cin >> op >> mode;
switch (op) {
    case 1:
        switch (mode) {
            case 1: cout << "操作1-模式1"; break;
            case 2: cout << "操作1-模式2"; break;
        }
        break;
    case 2:
        cout << "操作2"; break;
    default:
        cout << "未知操作";
}
```

> **注意**：外层 switch 和内层 switch 各自的 `break` 要写完整。

**if 与 switch 的选择建议**：

| 场景 | 推荐 |
|------|------|
| 连续范围判断（如 0<x<10） | `if...else if` |
| 固定值判断（如 1,2,3,4） | `switch` |
| 多层带范围的复合条件 | `if` 嵌套 |

### 3. GESP真题演练 ⚡

1. **（GESP二级判断题）** Python 是编译型语言。
   > **解析**：**错**。Python 是解释型语言，逐行解释执行，不需要预先编译。

2. **（GESP二级选择题）** 以下代码，当 `a=5, b=-1` 时，输出什么？
   ```cpp
   if (a > 0)
       if (b > 0) cout << "A";
       else cout << "B";
   else cout << "C";
   ```
   > **解析**：a>0 满足，进入内层；b>0 不满足，执行 `else cout<<"B"`（else 属于内层 if），输出 **B**。

3. **（GESP二级选择题）** `switch` 语句中，若某个 `case` 没有 `break`，则：
   - A. 跳过该 case
   - B. 只执行该 case
   - C. 继续执行下一个 case 的代码（穿透）
   - D. 编译报错
   > **解析**：**C**，switch 会从匹配的 case 继续向下穿透执行，直到 break 或右括号。

### 4. 进阶扩展

**实战：成绩多级评定系统**

```cpp
int score;
cin >> score;
if (score >= 0 && score <= 100) {
    if (score >= 90) {
        cout << "A (优秀)" << endl;
    } else if (score >= 80) {
        cout << "B (良好)" << endl;
    } else if (score >= 70) {
        cout << "C (中等)" << endl;
    } else if (score >= 60) {
        cout << "D (及格)" << endl;
    } else {
        cout << "F (不及格)" << endl;
    }
} else {
    cout << "输入无效" << endl;
}
```

> **用 switch 版本实现**：`switch (score / 10)` 将分数÷10，90-100都映射到case 10/9，分情况处理。
>
> ```cpp
> switch (score / 10) {
>     case 10: case 9: cout << "A"; break;
>     case 8: cout << "B"; break;
>     case 7: cout << "C"; break;
>     case 6: cout << "D"; break;
>     default: cout << "F";
> }
> ```
>
> 注意 `case 10: case 9:` 的写法——case 连续穿透实现"或"逻辑！

输入体重 w（kg）和身高 h（m），计算 BMI = w/(h*h)，按以下分级输出：

```cpp
#include <iostream>
```

### 作业 2：【判断三角形类型】

```cpp
#include <iostream>
```

### 作业 3：【switch 月份天数】

输入年份 y 和月份 m，用 switch 输出该月的天数（注意闰年 2 月）。

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int y, m; cin >> y >> m;
    int days;
    switch (m) {
        case 4: case 6: case 9: case 11: days = 30; break;
        case 2:
            days = ((y%4==0&&y%100!=0)||y%400==0) ? 29 : 28; break;
        default: days = 31;
    }
    cout << days << endl;
    return 0;
}
```
