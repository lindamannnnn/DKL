# CSP02-05 多层循环语句

## 一、课程简介（5分钟）

**🎯 课程目标：**
1. 掌握嵌套循环（for 套 for）的执行流程，能正确分析双重循环的执行次数。
2. 掌握数位处理技术（取百位/十位/个位），解决数字拆分类问题。
3. 深入理解"百钱百鸡"问题，学会"暴力枚举"穷举策略。
4. 能综合运用嵌套循环解决计数、统计、判断类复合问题。

**📚 核心知识点：**
1. 嵌套循环结构：外层每执行1次，内层完整执行一轮
2. 嵌套循环的执行次数：外层 m 次 × 内层 n 次 = m×n 次
3. 数位处理：`/` 和 `%` 提取各数位（百位/十位/个位）
4. 暴力枚举思想：逐一尝试所有可能，逐一判断
5. 百钱百鸡模型：多约束条件下的枚举策略（优化到二重循环）

### 2. 知识点讲解

**🔴 知识点 1：嵌套循环结构与执行流程**

```cpp
for (int i = 1; i <= 外层次数; i++) {
    for (int j = 1; j <= 内层次数; j++) {
        // 内层循环体
    }
    // 外层循环体（内层结束后执行）
}
```

执行规律：

- 外层 `i=1` → 内层 `j` 完整跑一遍（内层次数次）→ 内层结束
- 外层 `i=2` → 内层 `j` 再完整跑一遍 → …
- 总执行次数 = 外层次数 × 内层次数

```cpp
// 示例：输出乘法口诀表
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        cout << j << "*" << i << "=" << i*j << "\t";
    }
    cout << endl;
}
```

> **黑板推演**：用表格追踪 i=1,2,3 时 j 的变化范围，体会内层循环的"重置"机制。

**🔴 知识点 2：数位处理（取百位/十位/个位）**

对于三位数 n：

```cpp
int n = 357;
int bai = n / 100;        // 百位：3
int shi = n / 10 % 10;   // 十位：5（先÷10去掉个位，再%10取最后一位）
int ge  = n % 10;         // 个位：7

cout << bai << " " << shi << " " << ge << endl;  // 3 5 7
```

推广到四位数 1234：

```cpp
int n = 1234;
int q = n / 1000;          // 千位：1
int b = n / 100 % 10;      // 百位：2
int s = n / 10 % 10;       // 十位：3
int g = n % 10;             // 个位：4
```

> **规律口诀**：
> - **个位**：`n % 10`
> - **十位**：`n / 10 % 10`
> - **百位**：`n / 100 % 10`
> - **千位**：`n / 1000 % 10`（依此类推）

**经典应用——水仙花数（自恋数）**：

```cpp
// 三位数中各位数字的立方和等于该数本身
for (int n = 100; n <= 999; n++) {
    int a = n/100, b = n/10%10, c = n%10;
    if (a*a*a + b*b*b + c*c*c == n) {
        cout << n << " ";
    }
}
// 输出：153 370 371 407
```

**🔴 知识点 3：暴力枚举思想**

枚举算法：在解的可能范围内，**逐一列举**每种情况，**逐一判断**是否满足条件。

适用场景：解的范围有限，可以在合理时间内全部尝试。

```cpp
// 例：找出所有两位数中，各位数字之和为 10 的数
for (int n = 10; n <= 99; n++) {
    int shi = n / 10;
    int ge  = n % 10;
    if (shi + ge == 10) {
        cout << n << " ";
    }
}
// 输出：19 28 37 46 55 64 73 82 91
```

**🔴 知识点 4：百钱百鸡问题**

经典题目：公鸡5元/只，母鸡3元/只，小鸡1元/3只，用100元买100只鸡，各买多少只？

**三重循环暴力（慢）**：

```cpp
for (int cock = 0; cock <= 20; cock++) {       // 公鸡 0~20
    for (int hen = 0; hen <= 33; hen++) {       // 母鸡 0~33
        for (int chick = 0; chick <= 100; chick++) {  // 小鸡
            if (cock+hen+chick==100 && 5*cock+3*hen+chick/3==100 && chick%3==0) {
                cout << cock << " " << hen << " " << chick << endl;
            }
        }
    }
}
```

**优化为二重循环（快）**：小鸡数可由前两个推算

```cpp
for (int cock = 0; cock <= 20; cock++) {
    for (int hen = 0; hen <= 33; hen++) {
        int chick = 100 - cock - hen;      // 小鸡数直接算出
        if (chick >= 0 && chick % 3 == 0  // 小鸡必须是3的倍数
            && 5*cock + 3*hen + chick/3 == 100) {
            cout << "公鸡:" << cock << " 母鸡:" << hen 
                 << " 小鸡:" << chick << endl;
        }
    }
}
```

> **黑板推演**：为什么 cock 最多 20？（$5 \times 20 = 100$，超过20就超预算了）
>
> 优化前：$20 \times 33 \times 100 = 66000$ 次；优化后：$20 \times 33 = 660$ 次！快 100 倍！

### 3. GESP真题演练 ⚡

1. **（GESP二级选择题）** 以下代码输出几次 `*`？
   ```cpp
   for (int i = 1; i <= 4; i++)
       for (int j = 1; j <= i; j++)
           cout << "*";
   ```
   > **解析**：i=1时1次，i=2时2次，i=3时3次，i=4时4次，共 **1+2+3+4=10** 次。

   > **解析**：**对**。`537/10=53`，`53%10=3`，即十位数字。

3. **（GESP二级选择题）** 三重循环枚举百钱百鸡，优化为二重循环的关键是？
   - A. 使用 break 提前退出
   - B. 利用约束条件推算第三个变量
   - C. 减少循环上界
   - D. 使用函数封装
   > **解析**：**B**。小鸡数 = 100 - 公鸡 - 母鸡，通过数学关系消去一层循环。

### 4. 进阶扩展

**素数筛法初步（埃拉托斯特尼筛法）**：

```cpp
const int N = 100;
bool notPrime[N+1] = {false};  // false=素数候选
notPrime[0] = notPrime[1] = true;

for (int i = 2; i <= N; i++) {
    if (!notPrime[i]) {
        // i 是素数，标记 i 的所有倍数为合数
        for (int j = 2*i; j <= N; j += i) {
            notPrime[j] = true;
        }
    }
}
```

> **黑板推演**：以 1-20 为例，用黑板逐步演示筛法过程，体现嵌套循环的强大：两重循环，把 1-100 内所有素数全部找出来！

### 练习 1：【输出矩形】

输入行数 r 和列数 c，输出一个由 `*` 组成的矩形。

**输入样例：** `3 5`
**输出样例：**
```
*****
*****
*****
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int r, c; cin >> r >> c;
    for (int i = 1; i <= r; i++) {
        for (int j = 1; j <= c; j++) cout << "*";
        cout << endl;
    }
    return 0;
}
```

#include <iostream>

### 练习 4：【完全数】

输出 1 到 1000 内所有完全数（等于真因子之和，如 6=1+2+3）。

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    for (int n = 2; n <= 1000; n++) {
        int sum = 1;  // 1 是任何数的因子
        for (int i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                sum += i;
                if (i != n/i) sum += n/i;
            }
        }
        if (sum == n) cout << n << " ";
    }
    cout << endl;
    return 0;
}
```

### 练习 5：【百钱百鸡变形】

```cpp
#include <iostream>

int main() {
    for (int c = 1; c <= 14; c++) {
        for (int h = 1; h <= 25; h++) {
            int ch = 100 - c - h;
            if (ch >= 1 && 7*c + 4*h + 2*ch == 100) {
                cout << "公:" << c << " 母:" << h << " 小:" << ch << endl;
            }
        }
    }
    return 0;
}
```
