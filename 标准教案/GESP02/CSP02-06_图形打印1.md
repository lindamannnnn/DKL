# CSP02-06 图形打印1

## 一、课程简介（5分钟）

**🎯 课程目标：**
1. 掌握正斜边（左下到右上）规律，能用 `i + j = 常数` 判断斜边位置。
2. 掌握反斜边（左上到右下）规律，能用 `i - j = 常数`（或 `i == j`）判断对角线。
3. 掌握图形拆解策略：将复杂图形分解为"空格 + 字符"两部分分别处理。
4. 理解对称图形的行列关系，能灵活推算输出规律。

**📚 核心知识点：**
1. 正斜边规律：当 `i + j == 常数` 时，该位置在正斜边上
2. 反斜边（主对角线）规律：当 `i == j` 时，该位置在主对角线上
3. 图形拆解：每行 = 前缀空格 + 星号（或反过来）
4. 对称图形：等腰三角形的空格数 = `n - i`（第 i 行），星号数 = `2*i - 1`
5. 边框矩形：当 `i==1 || i==n || j==1 || j==m` 时输出字符，否则输出空格

## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> "想象一个坐标系，把图形的每个格子看成 (行i, 列j)。
>
> 当 `i == j` 时，格子在主对角线上。
>
> 当 `i + j == n+1` 时，格子在副对角线上。
>
> 所有图形题，都是在找：**什么坐标条件，应该输出什么字符！**"

### 2. 知识点讲解

**🔴 知识点 1：反斜边（主对角线）规律**

`i == j` 的位置构成从左上到右下的反斜边（正方向对角线）：

```cpp
int n = 5;
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n; j++) {
        if (i == j) cout << "*";
        else cout << " ";
    }
    cout << endl;
}
```

输出：
```
*    
 *   
  *  
   * 
    *
```

> **推广**：`i - j == k`（常数）意味着平行于主对角线的斜线。

---

**🔴 知识点 2：正斜边（副对角线）规律**

`i + j == n + 1` 的位置构成从左下到右上的正斜边（反方向对角线）：

```cpp
int n = 5;
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n; j++) {
        if (i + j == n + 1) cout << "*";
        else cout << " ";
    }
    cout << endl;
}
```

输出：
```
    *
   * 
  *  
 *   
*    
```

> **总结对比**：
> - 主对角线（\方向）：`i == j` 或 `i - j == 常数`
> - 副对角线（/方向）：`i + j == n+1` 或 `i + j == 常数`

---

**🔴 知识点 3：图形拆解——每行"空格+星号"**

等腰三角形（第 i 行：`n-i` 个空格 + `2i-1` 个星号）：

```cpp
int n; cin >> n;
for (int i = 1; i <= n; i++) {
    // 打印空格
    for (int j = 1; j <= n - i; j++) cout << " ";
    // 打印星号
    for (int j = 1; j <= 2 * i - 1; j++) cout << "*";
    cout << endl;
}
```

n=4 的效果：
```
   *
  ***
 *****
*******
```

> **推导过程（黑板推演）**：
> - i=1：3个空格 + 1个`*`
> - i=2：2个空格 + 3个`*`
> - i=3：1个空格 + 5个`*`
> - i=4：0个空格 + 7个`*`
>
> 规律：空格数 = `n - i`，星号数 = `2*i - 1`，总宽度恒为 `2*n - 1`！

---

**🔴 知识点 4：边框矩形（镂空图形）**

只打印矩形边框，内部用空格填充：

```cpp
int n, m; cin >> n >> m;
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (i == 1 || i == n || j == 1 || j == m)
            cout << "*";
        else
            cout << " ";
    }
    cout << endl;
}
```

> **条件分析**：`i==1` 第一行，`i==n` 最后一行，`j==1` 第一列，`j==m` 最后一列——满足任意一个就是边框！

---

**🔴 知识点 5：对称图形分析**

倒三角形（第 i 行：`i-1` 个空格 + `2*(n-i)+1` 个星号）：

```cpp
int n; cin >> n;
for (int i = 1; i <= n; i++) {
    for (int j = 1; j < i; j++) cout << " ";        // 空格
    for (int j = 1; j <= 2*(n-i)+1; j++) cout << "*"; // 星号
    cout << endl;
}
```

n=4：
```
*******
 *****
  ***
   *
```

### 3. GESP真题演练 ⚡

1. **（GESP二级选择题）** 在 n×n 的矩阵中，主对角线的元素满足哪个条件？（行列均从1开始）
   - A. `i + j == n`　B. `i == j`　C. `i + j == n+1`　D. `i - j == 1`
   > **解析**：**B**，主对角线即行号等于列号。

2. **（GESP二级程序填空）** 打印 n 行等腰三角形，第 i 行有多少个星号？
   > **解析**：`2*i - 1` 个。

3. **（GESP二级判断题）** 等腰三角形每行的总字符宽度（空格+星号）相同。
   > **解析**：**对**，总宽度 = `2*n - 1`（固定值）。

### 4. 进阶扩展

**X 形图案（两条对角线的叠加）**：

```cpp
int n; cin >> n;  // n 为奇数
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n; j++) {
        // 主对角线 或 副对角线
        if (i == j || i + j == n + 1) cout << "*";
        else cout << " ";
    }
    cout << endl;
}
```

> **黑板推演**：n=5 时，分析哪些 (i,j) 满足两个条件之一，画出 X 形。

### 练习 3：【矩形边框】

输入 n 行 m 列，打印只有边框的矩形（内部为空格）。

### 练习 4：【斜线图案】

输入 n，打印 n×n 方格中的主对角线（用 `*`，其余位置用 `.` 填充）。

**输入样例：** `4`
**输出样例：**
```
*...
.*..
..*. 
...*
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            cout << (i == j ? '*' : '.');
        }
        cout << endl;
    }
    return 0;
}
```

---

### 练习 5：【菱形】

输入奇数 n，打印 n 行的实心菱形（上半部分 n/2+1 行正三角，下半部分 n/2 行倒三角）。

**输入样例：** `5`
**输出样例：**
```
  *
 ***
*****
 ***
  *
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    int half = n / 2;
    // 上半部分
    for (int i = 1; i <= half+1; i++) {
        for (int j = 1; j <= half-i+1; j++) cout << " ";
        for (int j = 1; j <= 2*i-1; j++) cout << "*";
        cout << endl;
    }
    // 下半部分
    for (int i = half; i >= 1; i--) {
        for (int j = 1; j <= half-i+1; j++) cout << " ";
        for (int j = 1; j <= 2*i-1; j++) cout << "*";
        cout << endl;
    }
    return 0;
}
```

**🌟 内容收尾：**

> "图形打印的核心就是找规律——看 (i, j) 满足什么条件时输出 `*`！
>
> 三个固定套路要牢记：
>
> **对角线**：主对角线 `i==j`，副对角线 `i+j==n+1`！
>
> **等腰三角**：前 `n-i` 个空格 + `2*i-1` 个星号！
>
> **边框**：`i==1 || i==n || j==1 || j==m`！
>
> 下节课图形打印2，我们挑战更复杂的图形——复杂图形拆解组合大法！"
