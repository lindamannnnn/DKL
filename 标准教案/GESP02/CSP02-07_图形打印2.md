### 2. 知识点讲解

**🔴 知识点 1：图形分析三步法**

1. **画样例**：手画 n=4 或 n=5 时的图形
2. **标数据**：每行标出空格数、字符数
3. **找规律**：分析这些数据和行号 i 的关系式

```
示例：n=4 的等腰梯形
    ****     第1行：3空格，4星
   ******    第2行：2空格，6星
  ********   第3行：1空格，8星
 **********  第4行：0空格，10星

归纳：第i行空格 = n-i，星号 = 2*(n+i-1)-2*n+2 → 化简为 2*i+2
```

---

**🔴 知识点 2：梯形（平行四边形变种）**

```cpp
// 上底 a，总行数 n：第 i 行有 a + 2*(i-1) 个星号
int n = 4, a = 4;
for (int i = 1; i <= n; i++) {
    // 空格：从 n-i 开始
    for (int j = 1; j <= n - i; j++) cout << " ";
    // 星号：底边 a + 两侧各扩展 (i-1)
    for (int j = 1; j <= a + 2 * (i - 1); j++) cout << "*";
    cout << endl;
}
```

---

**🔴 知识点 3：空心菱形**

分析每行的输出：
- 第1行/最后行：只有1个 `*`（中心点）
- 中间行：两个 `*`，之间是空格

```cpp
int n; cin >> n;  // n 为奇数，半径 r = n/2
int r = n / 2;
for (int i = -r; i <= r; i++) {
    int spaces = abs(i);        // 左边空格数
    int stars_gap = r - spaces; // 两星之间的空格数
    // 打印左边空格
    for (int j = 0; j < spaces; j++) cout << " ";
    cout << "*";
    if (stars_gap > 0) {
        for (int j = 0; j < 2 * stars_gap - 1; j++) cout << " ";
        cout << "*";
    }
    cout << endl;
}
```

---

**🔴 知识点 4：双三角形（沙漏、蝴蝶）**

沙漏图形 = 上倒三角 + 下正三角：

```cpp
int n; cin >> n;
// 上：倒三角（第i行，i从1到n）
for (int i = 1; i <= n; i++) {
    for (int j = 1; j < i; j++) cout << " ";
    for (int j = 1; j <= 2*(n-i)+1; j++) cout << "*";
    cout << endl;
}
// 下：正三角（从第2行开始，避免重复中间行）
for (int i = n-1; i >= 1; i--) {
    for (int j = 1; j < i; j++) cout << " ";
    for (int j = 1; j <= 2*(n-i)+1; j++) cout << "*";
    cout << endl;
}
```

---

**🔴 知识点 5：调试技巧——用数字替换字符验证规律**

```cpp
// 调试版：打印每行的行号和字符数，验证规律是否正确
for (int i = 1; i <= n; i++) {
    cout << "第" << i << "行: 空格=" << (n-i) << " 星号=" << (2*i-1) << endl;
}
// 确认无误后，替换为实际输出代码
```

> **实战建议**：竞赛中遇到图形题，先用 n=3 或 n=4 手画出来，逐行列出每类字符的数量，找规律后再写代码！

### 3. GESP真题演练 ⚡

1. **（GESP二级程序分析）** 以下代码当 n=3 时输出什么图形？
   ```cpp
   for (int i = 1; i <= n; i++) {
       for (int j = n; j > i; j--) cout << " ";
       for (int j = 1; j <= 2*i-1; j++) cout << "*";
       cout << endl;
   }
   ```
   > **解析**：等腰三角形，n=3：
   > ```
   >   *
   >  ***
   > *****
   > ```

2. **（GESP二级判断题）** 打印空心矩形时，边框上的点满足条件 `i==1 || i==n || j==1 || j==m`。
   > **解析**：**对**。

3. **（GESP二级选择题）** 菱形图案（n=5行）中，第3行（最宽行）有多少个 `*`？
   > **解析**：第3行（中间行，i=3，half=2）有 `2*3-1=5` 个星号，但菱形最宽行是 `2*half+1 = 2*2+1 = 5` 个 `*`。答案是 **5**。

### 4. 进阶扩展

**递推图形——帕斯卡三角形（杨辉三角）**：

```cpp
#include <iostream>
using namespace std;
int C[20][20];
int main() {
    int n; cin >> n;
    for (int i = 0; i < n; i++) {
        C[i][0] = C[i][i] = 1;
        for (int j = 1; j < i; j++)
            C[i][j] = C[i-1][j-1] + C[i-1][j];
    }
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n-i-1; j++) cout << " ";
        for (int j = 0; j <= i; j++) {
            if (j > 0) cout << " ";
            cout << C[i][j];
        }
        cout << endl;
    }
    return 0;
}
```

> **黑板推演**：帕斯卡三角形 = 二项式展开系数 = C(n,k)，每个数等于上一行左上+右上的和。

### 练习 1：【向右的直角三角形】

输入 n，打印向右靠齐的直角三角形（第 i 行有 i 个 `*`，右对齐）。

**输出样例：**
```

  **
 ***
****
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n-i; j++) cout << " ";
        for (int j = 1; j <= i; j++) cout << "*";
        cout << endl;
    }
    return 0;
}
```

---

### 练习 2：【空心等腰三角形】

输入 n，打印空心等腰三角形（边框用 `*`，内部空格）。

**输入样例：** `5`
**输出样例：**
```
    *
   * *
  *   *
 *     *
*********
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        // 前空格
        for (int j = 1; j <= n-i; j++) cout << " ";
        if (i == 1) {
            cout << "*";  // 顶点
        } else if (i == n) {
            for (int j = 1; j <= 2*n-1; j++) cout << "*";  // 底边
        } else {
            cout << "*";  // 左边
            for (int j = 1; j <= 2*i-3; j++) cout << " ";  // 内部空格
            cout << "*";  // 右边
        }
        cout << endl;
    }
    return 0;
}
```

### 练习 4：【Z 字形图案】

### 作业 2：【数字蝴蝶】

输入 n，打印蝴蝶图形，但用数字代替星号（第 i 行的数字是 i）。

**输入样例：** `3`
**输出样例：**
```
1    1
22  22
333333
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) cout << i;
        for (int j = 1; j <= 2*(n-i); j++) cout << " ";

        cout << endl;
    }

```

### 作业 3：【空心菱形】

输入奇数 n，打印空心菱形（只有边框用 `*`，内部为空格）。

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    int r = n / 2;
    for (int i = -r; i <= r; i++) {
        int sp = abs(i);
        int inner = r - sp;
        for (int j = 0; j < sp; j++) cout << " ";
        cout << "*";
        if (inner > 0) {
            for (int j = 0; j < 2*inner-1; j++) cout << " ";
            cout << "*";
        }
        cout << endl;
    }
    return 0;
}
```
