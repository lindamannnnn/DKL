# CSP02-08 计算机的存储与网络

## 一、课程简介（5分钟）

**🎯 课程目标：**
1. 区分 ROM、RAM、Cache 的功能与特性，理解计算机存储层次结构。
2. 了解计算机网络的分类（LAN、MAN、WAN）及典型应用场景。
3. 理解 TCP/IP 四层模型与 OSI 七层模型的对应关系，掌握各层功能。
4. 理解 IP 地址的格式与分类，了解子网划分的基本概念。

**📚 核心知识点：**
1. 存储分层：Cache（高速缓存）→ RAM（内存）→ ROM（只读存储器） → 磁盘
2. 网络分类：局域网 LAN / 城域网 MAN / 广域网 WAN
3. TCP/IP 四层模型：应用层 / 传输层 / 网络层 / 网络接口层
4. OSI 七层模型：应用层 / 表示层 / 会话层 / 传输层 / 网络层 / 数据链路层 / 物理层
5. IP 地址：点分十进制格式（如 192.168.1.1），A/B/C 类地址范围

## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> "想象一个图书馆系统：
>
> 你手边的书桌 = **Cache（高速缓存）**：最快，但放的书最少。
>
> 图书馆的书架 = **RAM（内存）**：速度中等，开馆时可用（断电消失）。
>
> 图书馆仓库 = **硬盘**：容量最大，但找书最慢，永久保存。
>
> 这就是计算机存储的三层结构！"

### 2. 知识点讲解

**🔴 知识点 1：计算机存储层次**

| 存储类型 | 全称 | 特点 | 断电后数据 |
|---------|------|------|-----------|
| Cache | 高速缓存 | 速度最快，容量最小，CPU专用 | 丢失 |
| RAM | 随机存取存储器（内存） | 速度快，容量中等，可读写 | **丢失** |
| ROM | 只读存储器 | 速度慢，出厂时写入，**只读** | **保留** |
| 硬盘/SSD | 辅助存储器 | 容量最大，断电保留 | 保留 |

> **GESP 高频考点**：
> - ROM 是**只读**的，存储 BIOS/固件，**断电不丢失**
> - RAM 是内存，程序运行时使用，**断电丢失**
> - Cache 在 CPU 内部或紧邻 CPU，速度比内存快得多（如 L1/L2/L3 缓存）
>
> **类比记忆**：ROM = "刻在石头上"（只读、永久），RAM = "白板上的字"（可读写、关机清除）

---

**🔴 知识点 2：计算机网络分类**

按覆盖范围分类：

| 类型 | 英文 | 覆盖范围 | 典型例子 |
|------|------|---------|---------|
| 局域网 | LAN | 几十米到数千米（校园、公司） | 校园网、家庭 WiFi |
| 城域网 | MAN | 一个城市范围 | 城市有线电视网络 |
| 广域网 | WAN | 跨国、跨洲 | 互联网（Internet） |

> **记忆口诀**：LAN 局域（Local），MAN 城市（Metropolitan），WAN 广（Wide）

---

**🔴 知识点 3：TCP/IP 四层模型**

| 层次（从上到下） | 功能 | 典型协议 |
|-----------------|------|---------|
| 应用层 | 直接为用户提供服务 | HTTP, HTTPS, FTP, SMTP |
| 传输层 | 端到端通信，数据分段 | TCP（可靠）, UDP（快速） |
| 网络层 | IP 寻址，路由选择 | IP, ICMP |
| 网络接口层 | 物理传输，帧封装 | 以太网, WiFi |

> **记忆技巧**：从应用到物理，从上层到底层——**应传网接**（应用、传输、网络、接口）
>
> **TCP vs UDP**：TCP 像快递（有确认回执，可靠但慢），UDP 像广播（不管对方收到没有，快但可能丢包）

---

**🔴 知识点 4：OSI 七层模型**

| 层次（从上到下）| 功能 | 对应 TCP/IP |
|----------------|------|------------|
| 7 应用层 | 提供具体网络服务 | 应用层 |
| 6 表示层 | 数据格式转换、加密 | 应用层 |
| 5 会话层 | 管理会话（登录/退出） | 应用层 |
| 4 传输层 | 端到端传输 | 传输层 |
| 3 网络层 | 逻辑寻址、路由 | 网络层 |
| 2 数据链路层 | 帧传输、MAC 地址 | 网络接口层 |
| 1 物理层 | 比特流传输、实体连接 | 网络接口层 |

> **记忆口诀（从物理到应用）**：**物数网传会表应**（物理、数据链路、网络、传输、会话、表示、应用）

---

**🔴 知识点 5：IP 地址与子网划分**

**IP 地址格式**：点分十进制，4 组 0-255 的数字：

```
192 . 168 . 1 . 100
 |      |    |   |
 A部分  B部分 C   D
       网络部分 | 主机部分
```

**IPv4 地址分类（A/B/C 类）**：

| 类别 | 第一字节范围 | 适用场景 |
|------|------------|---------|
| A 类 | 1 ~ 126 | 大型网络（网络数少，主机数多） |
| B 类 | 128 ~ 191 | 中型网络 |
| C 类 | 192 ~ 223 | 小型网络（网络数多，主机数少） |

特殊 IP：
- `127.0.0.1`：本机回环地址（localhost）
- `192.168.x.x`：私网地址（家庭/公司内网常用）

> **GESP 考点**：`192.168.1.1` 是 **C 类**地址（192开头），常见于家庭路由器。`127.0.0.1` 是**回环地址**，ping 自己用。

### 3. GESP真题演练 ⚡

1. **（GESP二级判断题）** RAM 中的数据在断电后可以保留。
   > **解析**：**错**。RAM（内存）是易失性存储器，断电后数据丢失。

2. **（GESP二级选择题）** 在 OSI 七层模型中，负责路由选择的是哪一层？
   - A. 物理层　B. 数据链路层　C. 网络层　D. 传输层
   > **解析**：**C**，网络层负责 IP 寻址和路由选择。

3. **（GESP二级选择题）** IP 地址 `10.0.0.1` 属于哪类地址？
   - A. A类　B. B类　C. C类　D. 回环地址
   > **解析**：**A**，第一字节 10，在 1~126 范围内，是 A 类地址。

### 4. 进阶扩展

**子网掩码与子网划分基础**：

子网掩码（如 `255.255.255.0`）用来区分 IP 地址中的网络部分和主机部分：

```
IP 地址：  192.168.1.100   二进制：11000000.10101000.00000001.01100100
子网掩码：255.255.255.  0  二进制：11111111.11111111.11111111.00000000
网络地址：192.168.1.  0  （IP AND 子网掩码的结果）
主机地址范围：192.168.1.1 ~ 192.168.1.254
广播地址：192.168.1.255
```

> **CIDR 简写**：`192.168.1.0/24` 表示子网掩码前 24 位是 1，即 `255.255.255.0`

---

### 练习 1：【存储分类判断】

判断下列各项属于哪种存储器：
1. 手机 ROM（闪存）：存储操作系统固件  
2. 电脑运行时的内存（8GB）
3. CPU 内部的 L1 Cache
4. 移动硬盘（1TB）

> **答案**：
> 1. ROM（非易失，出厂写入）
> 2. RAM（易失，临时存储）
> 3. Cache（最快，CPU 专用）
> 4. 辅助存储器（外存）

---

### 练习 2：【网络分类匹配】

将下列场景与网络类型（LAN/MAN/WAN）对应：
1. 跨国公司总部与各国分部互联  
2. 一所学校的所有电脑联网  
3. 某城市的地铁免费 WiFi 覆盖中心城区  

> **答案**：1→ WAN，2→ LAN，3→ MAN

---

### 练习 3：【OSI 层次判断】

HTTPS 协议工作在 OSI 哪一层？TCP 协议工作在哪一层？以太网（Ethernet）工作在哪些层？

> **答案**：HTTPS → 应用层（第7层）；TCP → 传输层（第4层）；以太网 → 数据链路层（第2层）+ 物理层（第1层）

---

### 练习 4：【IP 地址分析】

分析下列 IP 地址：
1. `192.168.0.1`：类别？是公网还是私网？  
2. `8.8.8.8`：是 Google 的 DNS 服务器，类别？  
3. `127.0.0.1`：特殊含义？  

> **答案**：
> 1. C 类地址，私网（192.168.x.x 是私有地址段）
> 2. A 类地址（8 在 1~126 范围内），公网
> 3. 回环地址（loopback），代表本机自身

---

### 练习 5：【综合知识问答（小组抢答）】

1. RAM 和 ROM 的最大区别是什么？
2. TCP 和 UDP 各有什么特点，分别适合什么场合？
3. 家庭路由器的 IP 通常是多少？（192.168.1.1）这属于哪类地址？
4. OSI 七层中，加密和解密通常在哪层处理？（表示层）
