## 三、真题训练（90分钟）

### Part 1：选择题（每题2分，共20分）

---

**第1题**：下列关于函数的描述中，错误的是？

A. 函数可以没有参数  
B. 函数必须有返回值  
C. 同一个程序中可以定义多个函数  
D. 函数定义在 main 之后使用，需要前置声明  

> **答案**：**B**。`void` 类型函数没有返回值，函数不必须有返回值。

---

**第2题**：以下代码的输出结果是？

```cpp
#include <cmath>
#include <iostream>
using namespace std;
int main() {
    cout << (int)ceil(3.1) << " " << (int)floor(3.9) << endl;
}
```

A. `4 4`　B. `4 3`　C. `3 3`　D. `3 4`

> **答案**：**B**。`ceil(3.1)=4.0`，`floor(3.9)=3.0`，强转 int 后输出 `4 3`。

---

**第3题**：字符 `'z'` 的 ASCII 码值是多少？（`'a'` = 97）

A. 119　B. 120　C. 121　D. 122

> **答案**：**D**。`'a'=97`, `'z' = 97 + 25 = 122`。

---

**第4题**：以下代码执行完后，变量 a 的值是？

```cpp
void change(int x) { x = 100; }
int main() {
    int a = 5;
    change(a);
}
```

A. 100　B. 5　C. 0　D. 编译错误

> **答案**：**B**。值传递，形参 x 的修改不影响实参 a，a 仍为 5。

---

**第5题**：以下哪个 IP 地址属于 B 类？

A. `10.1.1.1`　B. `172.16.0.1`　C. `192.168.1.1`　D. `127.0.0.1`

> **答案**：**B**。第一字节 172 在 128~191 范围内，是 B 类地址。

---

**第6题**：`rand() % 50 + 10` 生成的随机数范围是？

A. `[0, 50)`　B. `[10, 60)`　C. `[10, 59]`　D. `[1, 50]`

> **答案**：**C**。`rand()%50` 的范围是 `[0,49]`，加 10 后是 `[10,59]`。

---

**第7题**：OSI 七层模型中，负责加密解密的是哪一层？

A. 会话层　B. 传输层　C. 表示层　D. 应用层

> **答案**：**C**。表示层负责数据格式转换、加密解密。

---

**第8题**：以下关于 switch 语句的描述正确的是？

A. case 后面的值可以是浮点数  
B. 每个 case 必须有 break  
C. switch 可以嵌套使用  
D. default 必须放在最后  

> **答案**：**C**。switch 支持嵌套。A错（case只支持整数/字符），B错（break可省略但会穿透），D错（default可在任意位置）。

---

**第9题**：以下双重循环共执行内层循环体多少次？

```cpp
for (int i = 1; i <= 5; i++)
    for (int j = i; j <= 5; j++)
        cout << "*";
```

A. 15　B. 25　C. 10　D. 20

> **答案**：**A**。i=1:5次，i=2:4次，i=3:3次，i=4:2次，i=5:1次，共 5+4+3+2+1=**15** 次。

---

**第10题**：以下关于 RAM 和 ROM 的描述，正确的是？

A. RAM 是只读存储器，断电保留数据  
B. ROM 是随机存取存储器，可读写  
C. RAM 断电后数据丢失，ROM 断电后数据保留  
D. Cache 比 RAM 容量更大  

> **答案**：**C**。RAM（内存）易失，ROM（只读存储器）非易失。

**编程题 1：字母移位**

**题目描述**：

输入一个仅含大写英文字母的字符串 s 和一个整数 k（0 ≤ k ≤ 25），将字符串中每个字母向后循环移动 k 位（'Z' 的下一位是 'A'），输出加密后的字符串。

**输入格式**：第一行字符串 s（长度 1~100），第二行整数 k。

**输出格式**：输出加密后的字符串。

**样例输入**：
```
HELLO
3
```

**样例输出**：
```
KHOOR
```

**参考代码**：
```cpp
#include <iostream>
using namespace std;
int main() {
    string s; int k;
    cin >> s >> k;
    for (int i = 0; i < (int)s.size(); i++) {
        cout << (char)((s[i] - 'A' + k) % 26 + 'A');
    }
    cout << endl;
    return 0;
}
```

---

**编程题 2：图形打印**

**题目描述**：

输入正整数 n，打印如下图形（n=4时）：

```
*      *
**    **
***  ***
********
```

规律：第 i 行有 i 个 `*`，中间 `2*(n-i)` 个空格，再 i 个 `*`（第 n 行全是 `*`，无间距）。

**输入格式**：一个正整数 n（2 ≤ n ≤ 10）。

**输出格式**：n 行蝴蝶图案。

**参考代码**：
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) cout << "*";
        for (int j = 1; j <= 2*(n-i); j++) cout << " ";
        for (int j = 1; j <= i; j++) cout << "*";
        cout << endl;
    }
    return 0;
}
```
