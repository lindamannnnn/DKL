## 一、课程简介（5分钟）

**🎯 课程目标：**
1. 掌握"模拟执行"方法：用草稿纸画表格，逐行跟踪循环变量的值，攻克 break/continue 类阅读题。

**📚 核心知识点：**
1. 循环模拟三步：画表头（变量名）→ 逐行填值 → 看结果
2. break vs continue：跳出整层 vs 跳过本次
3. 逗号表达式：从左到右依次算，整个式子的值是最右边那个
4. 类型陷阱：`5/2=2`、`5.0/2=2.5`、`'5'+4`、`(int)3.9=3`、int 读小数会出错
5. 辗转相除法：`gcd(a,b) = gcd(b, a%b)`，直到余数为 0；`lcm = a*b/gcd`

### 2. 知识点讲解

**🔴 知识点 1：循环模拟三步法（本课最重要）**

遇到"下面代码的输出是什么"这类题，别在脑子里空想，动手画表：

1. **画表头**：把每个变量的名字写在表格最上面
2. **逐行填**：循环每跑一圈，就把每个变量当时的值填进一行
3. **看结果**：循环结束后，看要输出的那个值

```
例：int s = 0;
    for (int i = 1; i <= 4; i++) s += i;
    cout << s;

草稿纸表格：
  圈数 | i | s
  ----|---|----
  第1圈 | 1 | 1
  第2圈 | 2 | 3
  第3圈 | 3 | 6
  第4圈 | 4 | 10
输出：10
```

> **口诀**：一变就记一行，最后读答案。

---

**🔴 知识点 2：break 与 continue**

- `break`：**整个循环立刻结束**，后面的圈都不跑了。
- `continue`：**只跳过这一圈剩下的部分**，马上进入下一圈。

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;  // i=3 这一圈跳过，不打印
    cout << i << " ";      // 输出 1 2 4 5
}
```

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) break;     // i=3 时整个循环结束
    cout << i << " ";      // 输出 1 2
}
```

> **记忆法**：continue 是"这次算了"，break 是"不玩了，全结束"。

---

**🔴 知识点 3：逗号表达式（冷僻但要认识）**

逗号可以把几件事写在一句里，**从左到右依次做，整个式子的值是最右边那个**。

```cpp
int a = 1, b = 2;      // 定义多个变量（这是定义，不是逗号表达式）
a = (1, 2, 3);         // 逗号表达式：a 的值是 3（最右边）
```

```cpp
int x;
x = (5, 10);           // x = 10
cout << x;             // 输出 10
```

> **注意**：定义变量时的逗号（`int a=1, b=2;`）和逗号表达式不是一回事，但都合法，考试见到别慌。

---

**🔴 知识点 4：and / or / not 就是 && / || / !**

C++ 里逻辑运算符有另一套"英文写法"，意思完全一样：

| 英文写法 | 符号写法 | 意思 |
|---------|---------|------|
| `and`   | `&&`    | 并且 |
| `or`    | `\|\|`  | 或者 |
| `not`   | `!`     | 取反 |

```cpp
if (a > 0 and b > 0)   // 等价于 if (a > 0 && b > 0)
if (a == 0 or b == 0)  // 等价于 if (a == 0 || b == 0)
```

---

**🔴 知识点 5：类型细节四大坑**

**坑 1：整数除法丢掉小数**
```cpp
cout << 5 / 2;     // 2（整数除以整数，小数被丢掉）
cout << 5.0 / 2;   // 2.5（只要有一个是小数，结果就是小数）
```

**坑 2：字符也是数字（ASCII）**
```cpp
char c = '5';
cout << c + 1;     // '5' 的 ASCII 是 53，53+1=54，输出 54
cout << (char)(c + 1);  // 强制转回字符，输出 '6'
```

**坑 3：(int) 直接砍掉小数（不是四舍五入）**
```cpp
cout << (int)3.9;   // 3（直接砍掉，不是 4！）
cout << (int)-3.9;  // -3（往 0 的方向砍）
```

**坑 4：int 变量读小数**
```cpp
int x;
// 用户输入 3.5，x 只会读到 3，剩下的 .5 会留在缓冲区捣乱
```

> **实战建议**：判断"输出是什么"时，先盯紧每个变量的类型（int 还是 double），再决定结果有没有小数。

---

**🔴 知识点 6：辗转相除法求最大公约数**

两个数的最大公约数（GCD），用"辗转相除"最快：

> 大数 ÷ 小数，取余数；再用 小数 ÷ 余数 …… 一直除到余数是 0，最后那个除数就是最大公约数。

```
例：求 gcd(12, 18)
18 % 12 = 6
12 % 6  = 0   → 余数为 0，结束
答案：6
```

```cpp
int gcd(int a, int b) {
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}
```

**最小公倍数（LCM）**：`lcm = a * b / gcd(a, b)`

> **黑板推演**：12 和 18，gcd=6，lcm = 12*18/6 = 36。

1. **（GESP二级选择题）** 执行下面代码，输出是什么？

   int cnt = 0;

3. **（GESP二级选择题）** `cout << 7 / 2;` 和 `cout << 7.0 / 2;` 输出分别是？
   > **解析**：前者输出 **3**（整数除法），后者输出 **3.5**。

4. **（GESP二级程序分析）** 求 gcd(24, 36)。
   > **解析**：36%24=12，24%12=0，答案 **12**。

### 4. 进阶扩展

**嵌套循环的 break（只跳出一层）**：

```cpp
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) break;   // 只跳出内层 j 循环，外层 i 继续
        cout << i << j << " ";
    }
}
// 输出：11 21 31（每个内层只打印 j=1 就 break）
```

> **提醒**：break 只能跳出**当前这一层**循环，外层不受影响。这是考试最爱考的陷阱！

### 练习 2：【输出 2 的倍数但非 3 的倍数】

输入 n，输出 1~n 中是 2 的倍数但不是 3 的倍数的数，每行一个。

**输入样例：** `10`
**输出样例：**
```

4
8
10
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        if (i % 2 != 0) continue;  // 不是 2 的倍数，跳过
        if (i % 3 == 0) continue;  // 是 3 的倍数，跳过
        cout << i << endl;
    }
    return 0;
}
```

### 练习 4：【求最大公约数】

输入两个自然数 M、N，用辗转相除法输出它们的最大公约数。

**输入样例：** `12 18`
**输出样例：** `6`

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b; cin >> a >> b;
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    cout << a << endl;
    return 0;
}
```

### 练习 5：【超过平均身高】

全家 n 口人，输入每人的身高（整数厘米），输出平均身高（保留 1 位小数），再输出有几个人超过平均身高。

**输入样例：**
```
3
170 160 180
```
**输出样例：**
```
170.0
1
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    int h[100], sum = 0;
    for (int i = 0; i < n; i++) { cin >> h[i]; sum += h[i]; }
    double avg = (double)sum / n;   // 关键：先转成 double 再除，才有小数
    int cnt = 0;
    for (int i = 0; i < n; i++) if (h[i] > avg) cnt++;
    printf("%.1f\n", avg);
    cout << cnt << endl;
    return 0;
}
```

```cpp
#include <iostream>

int gcd(int a, int b) {
    while (b) { int r = a % b; a = b; b = r; }

int main() {

    cout << a / gcd(a, b) * b << endl;  // 先除后乘，防溢出

```
