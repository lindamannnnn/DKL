### 2. 知识点讲解

#### 2.1 数组的定义

**语法格式：**

```cpp
类型 数组名[大小];
```

**举例：**

```cpp
int a[5];   // 定义一个能存放5个整数的数组
```

> 理解：向系统申请 5 个连续的 int 空间，用 `a` 代表这片空间的起始位置

**各组成部分说明：**

| 部分 | 含义 |
|------|------|
| `int` | 元素的数据类型 |
| `a` | 数组名（变量名） |
| `[]` | 表示这是一个数组 |
| `5` | 数组能存多少个元素（容量） |

---

#### 2.2 下标访问元素

数组用**下标**（索引）访问每个元素，**下标从 0 开始**，到 `大小-1` 结束：

```cpp
int a[5];
a[0] = 90;   // 第1个元素
a[1] = 85;   // 第2个元素
a[2] = 70;   // 第3个元素
a[3] = 48;   // 第4个元素
a[4] = 91;   // 第5个元素

cout << a[0];   // 输出 90
cout << a[2];   // 输出 70
```

> ⚠️ 注意：`a[5]` 越界！最大下标是 `a[4]`。访问越界不会报错，但会产生不可预期的结果！

| 下标 | 0 | 1 | 2 | 3 | 4 |
|------|---|---|---|---|---|
| 值   | 90 | 85 | 70 | 48 | 91 |

---

#### 2.3 数组初始化

**方式一：定义时用大括号初始化**

```cpp
int a[5] = {90, 85, 70, 48, 91};
```

**方式二：只初始化部分，其余自动为 0**

```cpp
int a[5] = {1, 2};    // a[0]=1, a[1]=2, a[2]=a[3]=a[4]=0
```

**方式三：全部初始化为 0**

```cpp
int a[5] = {0};    // 所有元素都是 0
```

> 💡 技巧：数组定义在**全局**（main函数外面）时，自动初始化为 0；定义在 main 函数内部则是随机值，需要手动初始化！

---

#### 2.4 循环遍历（输入与输出）

**输入 n 个数到数组：**

```cpp
int n, a[105];
cin >> n;
for (int i = 1; i <= n; i++) {
    cin >> a[i];
}
```

**输出数组所有元素：**

```cpp
for (int i = 1; i <= n; i++) {
    cout << a[i] << " ";
}
```

> 💡 竞赛中常用下标从 1 开始，这样和题目中的"第 i 个"一一对应，更直观。

---

#### 2.5 元素值的查找（最大值/最小值）

**思路：** 假设第一个元素是最大值，然后用循环逐个比较，如果发现更大的就更新。

```cpp
int a[6] = {0, 90, 85, 70, 48, 91};  // 下标从1开始
int maxval = a[1];    // 假设第一个最大
for (int i = 2; i <= 5; i++) {
    if (a[i] > maxval) {
        maxval = a[i];
    }
}
cout << "最大值：" << maxval;  // 输出 91
```

---

#### 2.6 元素位置的查找（下标查找）

**思路：** 同时记录最大值出现的下标位置。

```cpp
int a[6] = {0, 90, 85, 70, 48, 91};
int maxval = a[1], pos = 1;    // 同时记录最大值和位置
for (int i = 2; i <= 5; i++) {
    if (a[i] > maxval) {
        maxval = a[i];
        pos = i;       // 更新最大值时同步更新位置
    }
}
cout << "最大值：" << maxval << "，位置：" << pos;
```

> 提问：如果数组里有多个相同的最大值，上面代码会输出哪个位置？（第一个）  
> 如果想输出最后一个最大值的位置，代码如何修改？（把 `>` 改成 `>=`）

### 3. GESP 真题演练 ⚡

**抢答题 1（选择题）：**

> 以下定义数组并初始化的语句中，正确的是（ ）
>
> A. `int a(5);`  
> B. `int a[5] = {1, 2, 3, 4, 5, 6};`  
> C. `int a[5] = {1, 2, 3};`  
> D. `int a[];`
>
> **答案：C**  
> 解析：A 是函数调用语法，不能定义数组；B 初始化元素数超过数组大小；D 没有给出大小；C 合法，剩余元素自动补 0。

**判断题 2：**

> 数组 `int a[5]` 可以通过 `a[5]` 访问第5个元素。（ ）
>
> **答案：✗（错误）**  
> 解析：下标从 0 开始，第5个元素是 `a[4]`；`a[5]` 属于越界访问，是非法的。

**抢答题 3（选择题）：**

> 执行 `int a[4]={0}; a[1]=5;` 后，`a[0]+a[1]+a[2]+a[3]` 的值是（ ）
>
> A. 0  B. 5  C. 不确定  D. 20
>
> **答案：B**  
> 解析：全部初始化为 0，再把 a[1] 赋值为 5，所以总和是 0+5+0+0=5。

### 4. 进阶扩展

**数组越界问题深入理解：**

数组在内存中是连续存储的，`a[n]` 本质上是从 `a` 的地址开始，向后移动 `n*4` 个字节（int 类型占 4 字节）。

越界访问会读/写到不属于自己的内存，可能造成：
- 读取到脏数据
- 修改其他变量的值
- 程序崩溃（段错误）

> 🔑 竞赛建议：数组大小定义时多留一些余量，一般写 `a[N+10]` 而不是 `a[N]`

**全局数组 vs 局部数组：**

```cpp
// 全局数组（推荐用于竞赛）
int a[100005];    // 可以很大，自动初始化为0

int main() {
    // 局部数组（在函数内定义，有栈空间限制，不要太大）
    int b[1005];
    // b 的值不确定，需要手动初始化
}
```


### 练习 2（基础）：求数组的最大值和最小值

**题目描述：**

输入 n 个整数，求其中的最大值和最小值。

**输入格式：**
- 第一行一个整数 n（1 ≤ n ≤ 100）
- 第二行 n 个整数（每个整数范围 -1000 到 1000）

**输出格式：**
- 第一行输出最大值
- 第二行输出最小值

**样例输入：**
```
5
90 85 70 48 91
```

**样例输出：**
```
91
48
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;

int a[105];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    
    int maxv = a[1], minv = a[1];
    for (int i = 2; i <= n; i++) {
        if (a[i] > maxv) maxv = a[i];
        if (a[i] < minv) minv = a[i];
    }
    cout << maxv << endl;
    cout << minv << endl;
    return 0;
}
```

### 练习 3（综合）：查找最大值的位置

**题目描述：**

输入 n 个整数，找出最大值，并输出其所在的位置（位置从 1 开始编号）。若有多个相同最大值，输出第一个的位置。

**输入格式：**
- 第一行一个整数 n（1 ≤ n ≤ 100）

**输出格式：**
- 输出最大值及其位置，格式：`最大值 位置`

```
91 3
```

```cpp

int main() {

        if (a[i] > maxv) {
```

- 第一行一个整数 n（1 ≤ n ≤ 100）

**输出格式：**

### 练习 5（进阶）：找出第二大的数

**题目描述：**

输入 n 个**各不相同**的整数，找出其中第二大的数（即排第 2 名的数）。

**输入格式：**
- 第一行一个整数 n（2 ≤ n ≤ 100）
- 第二行 n 个各不相同的整数

**输出格式：**
- 输出第二大的数

**样例输入：**
```
5
90 85 70 48 91
```

**样例输出：**
```
90
```

**思路分析：**

维护两个变量：最大值 `max1` 和第二大值 `max2`，遍历时分两种情况更新。

**题解代码：**

```cpp
#include <iostream>
using namespace std;

int a[105];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    
    int max1, max2;
    // 初始化：把前两个元素分配给 max1 和 max2
    if (a[1] > a[2]) { max1 = a[1]; max2 = a[2]; }
    else { max1 = a[2]; max2 = a[1]; }
    
    for (int i = 3; i <= n; i++) {
        if (a[i] > max1) {
            max2 = max1;
            max1 = a[i];
        } else if (a[i] > max2) {
            max2 = a[i];
        }
    }
    cout << max2 << endl;
    return 0;
}
```

#### 作业 1：求平均值

**题目描述：**

输入 n 个整数，求它们的平均值（结果保留两位小数）。

**输入格式：**
- 第一行一个整数 n（1 ≤ n ≤ 100）
- 第二行 n 个整数

**输出格式：**
- 输出平均值，保留两位小数

**样例输入：**
```
4
10 20 30 40
```

**样例输出：**
```
25.00
```

**题解代码：**

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int a[105];

int main() {
    int n;
    cin >> n;
    double sum = 0;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        sum += a[i];
    }
    cout << fixed << setprecision(2) << sum / n << endl;
    return 0;
}
```

#### 作业 2：找出特定元素

**题目描述：**

输入 n 个整数和一个查找目标 x，判断 x 是否在数组中。如果在，输出 `YES`；否则输出 `NO`。

**输入格式：**
- 第一行一个整数 n（1 ≤ n ≤ 100）
- 第二行 n 个整数
- 第三行整数 x

**输出格式：**
- `YES` 或 `NO`

**样例输入：**
```
5
1 2 3 4 5
3
```

**样例输出：**
```
YES
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;

int a[105];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int x;
    cin >> x;
    bool found = false;
    for (int i = 1; i <= n; i++) {
        if (a[i] == x) { found = true; break; }
    }
    cout << (found ? "YES" : "NO") << endl;
    return 0;
}
```
