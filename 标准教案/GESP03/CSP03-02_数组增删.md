## 一、课程简介（5分钟）

### 🎯 课程目标

1. 掌握在数组指定位置**插入**元素的方法（元素后移）

- 插入元素：从末尾向前将元素后移，再赋值
- 删除元素：从目标位置向后将元素前移
- 元素交换：使用临时变量 `swap` 或 `std::swap`
- 数组逆序：双指针两端对称交换
- 逆序数：数组中逆序对的数量

### 2. 知识点讲解

#### 2.1 元素插入

**问题：** 数组 `a[1..n]`，在第 `pos` 位**之前**插入值 `val`。

**思路：** 从第 n 个元素开始，依次向后移动一位，直到 `pos` 位置空出来，再赋值。

```cpp
// 在位置 pos 插入值 val，原数组 n 个元素
void insert(int a[], int &n, int pos, int val) {
    // 从末尾向前，将元素后移
    for (int i = n; i >= pos; i--) {
        a[i + 1] = a[i];
    }
    a[pos] = val;  // 插入新元素
    n++;            // 数组长度加1
}
```

**示意图（插入前→插入后）：**

```
原数组（下标1~4）：  1  3  5  7
在位置2前插入 9：
先后移：            1  3  3  5  7  （从右往左）
                   1  9  3  5  7  （赋值）
```

> ⚠️ 注意：循环必须**从后向前**！如果从前向后，前面元素移动后会覆盖后面的数据！

---

#### 2.2 元素删除

**问题：** 删除数组 `a[1..n]` 中第 `pos` 位的元素。

**思路：** 从第 `pos+1` 个元素开始，依次向前移动一位，覆盖被删除的位置。

```cpp
// 删除位置 pos 的元素
void remove(int a[], int &n, int pos) {
    // 从 pos+1 开始向前移动
    for (int i = pos; i < n; i++) {
        a[i] = a[i + 1];
    }
    n--;  // 数组长度减1
}
```

**示意图（删除位置2的元素 3）：**

```
原数组：  1  3  5  7
删除3：   1  5  5  7  （从左往右覆盖）
         1  5  7     （长度减1）
```

> ⚠️ 注意：循环必须**从前向后**！

---

#### 2.3 元素交换

**问题：** 交换数组中两个位置 `i` 和 `j` 的元素。

**方法一：** 使用临时变量

```cpp
int tmp = a[i];
a[i] = a[j];
a[j] = tmp;
```

**方法二：** 使用 `swap` 函数（推荐）

```cpp
swap(a[i], a[j]);  // C++ 标准库函数，需要 #include <algorithm>
```

---

#### 2.4 数组逆序

**问题：** 将数组 `a[1..n]` 逆序（头尾互换）。

**思路：** 使用双指针，左指针 `l=1` 从左出发，右指针 `r=n` 从右出发，互相交换，直到相遇。

```cpp
int l = 1, r = n;
while (l < r) {
    swap(a[l], a[r]);
    l++;
    r--;
}
```

**示意图：**

```
      l               r
初始：  1   3   5   7   9
交换：  9   3   5   7   1
          l       r
交换：  9   7   5   3   1
              lr（相遇，停止）
```

---

#### 2.5 逆序数的概念

**定义：** 在数组中，如果一个数前面有比它大的数，那么这两个数就构成一个"逆序对"。数组中所有逆序对的数量就是**逆序数**。

**例子：** 数组 `2 4 1 3`

- `(2,1)`：2 > 1，逆序对
- `(4,1)`：4 > 1，逆序对
- `(4,3)`：4 > 3，逆序对

共 3 个逆序对，逆序数 = 3

**暴力计算逆序数（O(n²)）：**

```cpp
int cnt = 0;
for (int i = 1; i <= n; i++) {
    for (int j = i + 1; j <= n; j++) {
        if (a[i] > a[j]) cnt++;
    }
}
cout << cnt << endl;
```

> 💡 提示：逆序数越大，说明数组越"乱"，排序需要的操作次数越多。有序数组的逆序数为 0。

### 3. GESP 真题演练 ⚡

**判断题 1：**

> 删除数组第 k 个元素时，for 循环应该从 k 到 n，执行 `a[i] = a[i+1]`。（ ）
>
> **答案：✓（正确）**  
> 解析：删除时从前向后覆盖，从位置 k 开始，把 k+1 覆盖到 k，k+2 覆盖到 k+1，以此类推。

**抢答题 2（选择题）：**

> 将元素插入到数组第 k 个位置，for 循环遍历方向是（ ）
>
> A. 从1到n，执行 a[i+1]=a[i]  
> B. 从n到k，执行 a[i+1]=a[i]  
> C. 从k到n，执行 a[i]=a[i+1]  
> D. 从n到1，执行 a[i+1]=a[i]
>
> **答案：B**  
> 解析：插入时必须从后往前移，从 n 到 k，把 a[i] 复制到 a[i+1]，最后 a[k] 才能安全写入新值。

**抢答题 3：**

> 数组 `3 1 4 1 5` 的逆序数是多少？
>
> **答案：3**  
> 逆序对：(3,1)、(3,1)、(4,1) —— 共 3 对。

### 4. 进阶扩展

**逆序的应用：**

判断一个字符串是否是回文（下节课字符串内容的铺垫）——把字符数组逆序后，和原数组比较，如果相同则是回文。

```cpp
// 示例：判断数字逆序后是否相同（数字回文）
int a[105], b[105];
int n;
cin >> n;
for (int i = 1; i <= n; i++) { cin >> a[i]; b[i] = a[i]; }

// 逆序 b
int l = 1, r = n;
while (l < r) { swap(b[l], b[r]); l++; r--; }

// 比较 a 和 b
bool ok = true;
for (int i = 1; i <= n; i++) {
    if (a[i] != b[i]) { ok = false; break; }
}
cout << (ok ? "YES" : "NO") << endl;
```

**黑板推演：插入操作关键点**

> 插入时 for 循环方向：从右往左（n → pos），保证数据不被覆盖  
> 删除时 for 循环方向：从左往右（pos → n-1），将后面数据往前填  
> 数组逆序：双指针对称交换，最多只需 n/2 次操作

### 练习 1（基础）：在数组中插入元素

**题目描述：**

给定数组，在指定位置插入一个元素，输出插入后的数组。

**输入格式：**
- 第一行整数 n（1 ≤ n ≤ 100）
- 第二行 n 个整数
- 第三行两个整数 pos 和 val，表示在位置 pos 前插入值 val

**输出格式：**
- 输出插入后的 n+1 个整数，空格分隔

**样例输入：**
```
4
1 3 5 7
2 9
```

**样例输出：**
```
1 9 3 5 7
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;

int a[105];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    
    int pos, val;
    cin >> pos >> val;
    
    // 从后往前后移
    for (int i = n; i >= pos; i--) {
        a[i + 1] = a[i];
    }
    a[pos] = val;
    n++;
    
    for (int i = 1; i <= n; i++) {
        if (i > 1) cout << " ";
        cout << a[i];
    }
    cout << endl;
    return 0;
}
```

### 练习 4（综合）：删除所有值等于 x 的元素

**题目描述：**

输入 n 个整数和一个值 x，删除数组中所有等于 x 的元素，输出剩余元素。

**输入格式：**
- 第一行整数 n（1 ≤ n ≤ 100）
- 第二行 n 个整数
- 第三行整数 x

**输出格式：**
- 删除后的数组，空格分隔（若全删完输出空行）

**样例输入：**
```
6
1 3 2 3 4 3
3
```

**样例输出：**
```
1 2 4
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;

int a[105];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int x;
    cin >> x;
    
    int i = 1;
    while (i <= n) {
        if (a[i] == x) {
            // 删除位置 i
            for (int j = i; j < n; j++) a[j] = a[j + 1];
            n--;
        } else {
            i++;
        }
    }
    
    for (int i = 1; i <= n; i++) {
        if (i > 1) cout << " ";
        cout << a[i];
    }
    cout << endl;
    return 0;
}
```
