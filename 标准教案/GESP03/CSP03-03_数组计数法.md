### 1. 新知导入 🎬

> 期末选举班长，候选人有3号、7号、2号三位同学，全班30个同学各投一票。

> 读到 7 号的票，就让 `cnt[7]++`；
> 读到 2 号的票，就让 `cnt[2]++`！
>
> 最后看 `cnt[2]`、`cnt[3]`、`cnt[7]` 里各有多少票，统计完毕！

### 2. 知识点讲解

#### 2.1 下标的特殊用途

数组下标不仅可以表示"第几个元素"，还可以**直接映射数据的值**。

- 普通用法：`a[i]` 表示第 i 个数据
- 计数用法：`cnt[v]` 表示值 v 出现了多少次

关键：**用值作为下标**，用元素存储**频次**。

---

#### 2.2 数组计数法基本实现

```cpp
#include <iostream>
using namespace std;

int cnt[1001] = {0};  // 计数数组，下标范围覆盖数据值域

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        cnt[x]++;    // 将值 x 对应的桶+1
    }
    
    // 输出每个值出现的次数
    for (int v = 0; v <= 1000; v++) {
        if (cnt[v] > 0) {
            cout << v << " 出现了 " << cnt[v] << " 次" << endl;
        }
    }
    return 0;
}
```

---

#### 2.3 数组计数法的适用条件

> ⚠️ 重要：并不是所有情况都适合用计数法！

| 条件 | 适用 | 不适用 |
|------|------|--------|
| 数据值域范围 | 小（≤ 10⁶，数组开得下） | 极大（如值域 10¹⁸） |
| 数据个数 | 可以很多（无限制） | — |
| 数据类型 | 整数（可作为下标） | 小数、字符串 |

**典型适用场景：**

- 统计 1000 个学生的分数（分数范围 0~100），用 `cnt[0..100]`
- 统计选票（候选人编号 1~100），`cnt[1..100]`

**典型不适用场景：**

- 数据是身份证号、浮点数（无法直接作为下标）
- 数据值域超大（如值域 1~10⁹，无法开这么大的数组）

---

#### 2.4 用计数法找出现次数最多的数

```cpp
int cnt[1001] = {0};
int n;
cin >> n;
for (int i = 1; i <= n; i++) {
    int x; cin >> x;
    cnt[x]++;
}

int maxCnt = 0, ans = 0;
for (int v = 0; v <= 1000; v++) {
    if (cnt[v] > maxCnt) {
        maxCnt = cnt[v];
        ans = v;
    }
}
cout << "出现最多的数是 " << ans << "，出现了 " << maxCnt << " 次" << endl;
```

---

#### 2.5 桶排序（计数排序）

用计数数组可以实现超快的排序（对整数）：

```cpp
// 桶排序：从小到大输出所有数
for (int v = 0; v <= 1000; v++) {
    for (int j = 0; j < cnt[v]; j++) {
        cout << v << " ";
    }
}
```

> 📊 黑板推演：
>
> 输入：`3 1 4 1 5 9 2 6 5 3`（10个数）  
> 计数后：cnt[1]=2, cnt[2]=1, cnt[3]=2, cnt[4]=1, cnt[5]=2, cnt[6]=1, cnt[9]=1  
> 按下标遍历输出：`1 1 2 3 3 4 5 5 6 9` ✓ 已排序！

### 3. GESP 真题演练 ⚡

**抢答题 1（选择题）：**

> 使用数组计数法统计 n 个数字（范围 1~100）的出现次数，计数数组应定义为（ ）
>
> A. `int cnt[n]`  
> B. `int cnt[101]`  
> C. `int cnt[1000]`  
> D. `int cnt[n+1]`
>
> **答案：B**  
> 解析：数据范围是 1~100，所以下标最大为 100，`cnt[101]` 可覆盖 0~100 全部下标。

**判断题 2：**

> 数组计数法中，`cnt[x]++` 表示将第 x 个元素加1。（ ）
>
> **答案：✗（错误）**  
> 解析：`cnt[x]++` 表示将**值为 x 的数据的计数**加 1，下标 x 对应的是数据的值，不是第几个元素。

**抢答题 3：**

> 有 5 个人投票，票号分别是 `2 1 2 3 1`，使用数组计数法后，cnt[1]=？cnt[2]=？cnt[3]=？
>
> **答案：** cnt[1]=2，cnt[2]=2，cnt[3]=1

### 4. 进阶扩展

**用计数数组去重（输出没有重复元素的序列）：**

```cpp
int cnt[1001] = {0};
int n;
cin >> n;
for (int i = 1; i <= n; i++) {
    int x; cin >> x;
    cnt[x]++;
}
// 只要 cnt[v] > 0 就说明 v 出现过
for (int v = 0; v <= 1000; v++) {
    if (cnt[v] > 0) cout << v << " ";
}
```

**计数法的时间复杂度分析：**

> 计数法时间复杂度：O(n + V)，其中 V 是数值范围  
> 比较排序（如冒泡）：O(n²)  
> 当 n 很大、V 不太大时，计数法远快于比较排序！

### 练习 1（基础）：统计每个数字出现次数

**题目描述：**

输入 n 个整数（范围 1~100），统计每个数出现的次数，按数字从小到大输出（只输出出现过的数字）。

**输入格式：**
- 第一行整数 n（1 ≤ n ≤ 1000）
- 第二行 n 个整数（每个整数 1~100）

**输出格式：**
- 每行格式：`数字 次数`

**样例输入：**
```
6
3 1 3 2 1 3
```

**样例输出：**
```
1 2
2 1
3 3
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int cnt[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        int x; cin >> x;
        cnt[x]++;
    }
    for (int v = 1; v <= 100; v++) {
        if (cnt[v] > 0) cout << v << " " << cnt[v] << endl;
    }
    return 0;
}
```

### 练习 3（综合）：桶排序

**题目描述：**

对 n 个整数（范围 0~1000）进行从小到大排序并输出。要求使用计数排序（桶排序）实现。

**输入格式：**
- 第一行整数 n（1 ≤ n ≤ 10000）
- 第二行 n 个整数

- 排好序的整数，空格分隔


```cpp
#include <iostream>
using namespace std;
int cnt[1005];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) { int x; cin >> x; cnt[x]++; }
```

### 练习 4（综合）：数字去重

**题目描述：**

输入 n 个整数（范围 1~100），将其中重复的数字去掉，只保留每个数字第一次出现，按出现顺序输出。

**输入格式：**
- 第一行整数 n（1 ≤ n ≤ 1000）
- 第二行 n 个整数

**输出格式：**
- 去重后的数字，空格分隔

**样例输入：**
```
6
3 1 3 2 1 3
```

**样例输出：**
```
3 1 2
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int a[1005];
bool seen[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    bool first = true;
    for (int i = 1; i <= n; i++) {
        if (!seen[a[i]]) {
            seen[a[i]] = true;
            if (!first) cout << " ";
            cout << a[i];
            first = false;
        }
    }
    cout << endl;
    return 0;
}
```

### 练习 5（进阶）：区间计数

**题目描述：**

输入 n 个整数（范围 1~1000）和多组查询 [l, r]，对每组查询输出数组中值在 [l, r] 范围内的元素个数。

**输入格式：**
- 第一行整数 n（1 ≤ n ≤ 10000）
- 第二行 n 个整数
- 第三行整数 q（查询次数）
- 接下来 q 行，每行两整数 l r

**输出格式：**
- 每组查询结果一行

**样例输入：**
```
6
1 3 2 5 4 3
2
1 3
3 5
```

**样例输出：**
```
4
4
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int cnt[1005];
int sum[1005]; // 前缀和
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) { int x; cin >> x; cnt[x]++; }
    for (int v = 1; v <= 1000; v++) sum[v] = sum[v-1] + cnt[v];
    int q; cin >> q;
    while (q--) {
        int l, r; cin >> l >> r;
        cout << sum[r] - sum[l-1] << endl;
    }
    return 0;
}
```

输入一行只包含小写字母的字符串，统计每个字母出现的次数，按字母顺序输出（只输出出现的字母）。


**题解代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;
int cnt[26];
int main() {
    string s; cin >> s;
    for (char c : s) cnt[c - 'a']++;
    for (int i = 0; i < 26; i++) {
        if (cnt[i] > 0) cout << (char)('a'+i) << " " << cnt[i] << endl;
    }
    return 0;
}
```

#### 作业 2：判断是否有重复数字

输入 n 个整数（1~100），判断其中是否有重复的数字，有则输出 `YES`，否则 `NO`。

```
4
```
