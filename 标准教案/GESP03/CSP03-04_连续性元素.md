# CSP03-04 连续性元素

## 一、课程简介（5分钟）

### 🎯 课程目标

1. 理解"连续性"的概念：相同值连续出现或数值连续递增/递减
2. 掌握找出"连续出现次数最多的值"的算法思路
3. 掌握找出"最长连续区间"的算法思路
4. 能区分计数法和连续性算法的适用场景

### 📚 核心知识点

- 连续元素的定义：相邻元素相同或差值为 1
- 滑动窗口（区间）思想：维护当前段的开始位置和长度
- 计数器重置策略：遇到不连续时重置计数
- 最长连续区间的更新：比较并保存历史最大值
- 与计数法的区别：计数法统计频次，连续性算法统计最长连续段

### 2. 知识点讲解

#### 2.1 连续出现次数最多的值

**问题：** 数组中，哪个值连续出现的次数最多？出现几次？

**算法思路：**

1. 初始化：当前值 = `a[1]`，当前连续长度 `cur = 1`，历史最大 `maxLen = 1`
2. 从第 2 个元素开始遍历：
   - 如果 `a[i] == a[i-1]`：连续，`cur++`
   - 否则：断开，`cur = 1`（重置为1，因为新的连续段从 a[i] 开始）
3. 每次更新 `maxLen = max(maxLen, cur)`

```cpp
int a[105];
int n;
cin >> n;
for (int i = 1; i <= n; i++) cin >> a[i];

int cur = 1, maxLen = 1, ans = a[1];
for (int i = 2; i <= n; i++) {
    if (a[i] == a[i-1]) {
        cur++;
        if (cur > maxLen) {
            maxLen = cur;
            ans = a[i];  // 更新最长连续段的值
        }
    } else {
        cur = 1;  // 重置
    }
}
cout << "连续最多的值：" << ans << "，连续次数：" << maxLen << endl;
```

**示例演示：**

```
数组：  1  2  2  3  3  3  2  2
下标：  1  2  3  4  5  6  7  8

遍历：
i=2: a[2]=2 != a[1]=1 → cur=1
i=3: a[3]=2 == a[2]=2 → cur=2, maxLen=2, ans=2
i=4: a[4]=3 != a[3]=2 → cur=1
i=5: a[5]=3 == a[4]=3 → cur=2
i=6: a[6]=3 == a[5]=3 → cur=3, maxLen=3, ans=3
i=7: a[7]=2 != a[6]=3 → cur=1
i=8: a[8]=2 == a[7]=2 → cur=2

结果：连续最多的值是 3，连续 3 次。
```

#### 2.2 连续出现的区间

**问题：** 输出数组中每个"连续段"的起始位置、结束位置和元素值。

```cpp
int a[105], n;
cin >> n;
for (int i = 1; i <= n; i++) cin >> a[i];

int start = 1;  // 当前连续段的起始位置
for (int i = 2; i <= n + 1; i++) {
    // i == n+1 作为哨兵，触发最后一段的输出
    if (i == n + 1 || a[i] != a[i-1]) {
        // 当前段：从 start 到 i-1
        cout << "值 " << a[i-1] << "：位置 " << start << " 到 " << i-1
             << "，共 " << i-start << " 次" << endl;
        start = i;  // 新段从 i 开始
    }
}
```

**示例：**

```
输入：5 1 1 2 2 2 输出：
值 1：位置 1 到 2，共 2 次
值 2：位置 3 到 5，共 3 次
```

#### 2.3 最长连续递增子序列

**问题：** 从头到尾，找出最长的连续递增（每步加 1）子序列。

```cpp
int cur = 1, maxLen = 1, best_end = 1;
for (int i = 2; i <= n; i++) {
    if (a[i] == a[i-1] + 1) {
        cur++;
        if (cur > maxLen) {
            maxLen = cur;
            best_end = i;  // 记录最长段的末尾
        }
    } else {
        cur = 1;
    }
}
// 最长递增段从 best_end - maxLen + 1 到 best_end
cout << "最长连续递增长度：" << maxLen << endl;
```

### 4. 进阶扩展

**"连续段压缩"（RLE 编码思想）：**

将连续相同元素压缩为"值+次数"的形式，这是数据压缩中的"游程编码"（RLE, Run-Length Encoding）。

```cpp
// 游程编码
int start = 1;
for (int i = 2; i <= n + 1; i++) {
    if (i == n + 1 || a[i] != a[i-1]) {
        cout << a[i-1] << "×" << (i - start) << " ";
        start = i;
    }
}
```

**黑板推演：**

> 数组：`1 1 1 2 2 3 1 1`  
> 游程编码：`1×3 2×2 3×1 1×2`  
> 原来 8 个数，压缩成 4 组，节省空间！

### 练习 1（基础）：最长连续相同段

**题目描述：**

输入 n 个整数，找出连续相同次数最多的那个数，输出该数和连续次数。

**输入格式：**
- 第一行整数 n（1 ≤ n ≤ 1000）
- 第二行 n 个整数

**输出格式：**
- 输出连续次数最多的值和次数，若有多个并列取第一个出现的

**样例输入：**
```
7
1 2 2 3 3 3 2
```

**样例输出：**
```
3 3
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int a[1005];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int cur=1, maxLen=1, ans=a[1];
    for (int i=2; i<=n; i++) {
        if (a[i] == a[i-1]) {
            cur++;
            if (cur > maxLen) { maxLen=cur; ans=a[i]; }
        } else cur=1;
    }
    cout << ans << " " << maxLen << endl;
    return 0;
}
```

### 练习 4（综合）：最长连续递增子序列

**题目描述：**

输入 n 个整数，求最长连续严格递增（相邻差大于0）子序列的长度及起始位置（1-indexed）。

**输入格式：**
- 第一行整数 n（1 ≤ n ≤ 1000）
- 第二行 n 个整数

**输出格式：**
- 最长递增子序列的长度和起始位置

**样例输入：**
```
7
1 2 3 1 2 4 5
```

**样例输出：**
```
4 4
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int a[1005];
int main() {
    int n; cin>>n;
    for(int i=1;i<=n;i++) cin>>a[i];
    int cur=1, maxLen=1, bestStart=1, curStart=1;
    for(int i=2;i<=n;i++) {

        } else {
            cur=1; curStart=i;
        }

}
```

## 五、课堂总结（5分钟）🌟

> 今天我们攻克了"连续性元素"问题！
>
> 核心技巧：
> - 遍历数组，维护"**当前连续长度 cur**"和"**历史最大 maxLen**"
> - 遇到相同/满足条件的相邻元素：`cur++`
> - 遇到断开：`cur = 1`（重置）
> - 每步更新：`if (cur > maxLen) maxLen = cur`
>
> 这种模式叫**"滑动计数"**，在很多连续性问题中都会用到！
>

#### 作业 3：连续递增段数目

输入 n 个整数，统计其中有多少个"连续严格递增段"（长度至少为 2）。

**样例输入：**
```
7
1 2 1 2 3 1 2
```

```cpp
#include <iostream>

    for(int i=1;i<=n;i++) cin>>a[i];

            cur++;
            if(!inSeg) { cnt++; inSeg=true; }
        } else {
            cur=1; inSeg=false;
        }
    }

}
```

**提示（核心算法）：**
```cpp
int maxSum = a[1], curSum = a[1];
for (int i = 2; i <= n; i++) {
    curSum = max(a[i], curSum + a[i]);
    maxSum = max(maxSum, curSum);
}
```
