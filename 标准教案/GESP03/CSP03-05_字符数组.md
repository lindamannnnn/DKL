### 2. 知识点讲解

#### 2.1 char 类型与 ASCII 码

`char` 是 C++ 中存储单个字符的类型，每个字符对应一个整数（ASCII 码）。

```cpp
char c = 'A';
cout << c << endl;        // 输出 A
cout << (int)c << endl;   // 输出 65（强制转换为 int 查看 ASCII）
```

**常用 ASCII 码记忆：**

| 字符 | ASCII 码 |
|------|---------|
| `'0'`~`'9'` | 48~57 |
| `'A'`~`'Z'` | 65~90 |
| `'a'`~`'z'` | 97~122 |
| `' '`（空格） | 32 |
| `'\0'`（空字符） | 0 |

> 💡 规律：`'a' - 'A' = 32`，所以大写转小写加 32，小写转大写减 32！

---

#### 2.2 字符数组的定义与初始化

**方式一：逐字符初始化**

```cpp
char a[5] = {'m', 'i', 'k', 'e', '\0'};
```

**方式二：字符串常量初始化（推荐）**

```cpp
char a[] = "mike";   // 自动加 '\0'，实际长度是 5
char b[10] = "hello";
```

> ⚠️ 注意：用字符串常量初始化时，系统会自动在末尾加 `'\0'`，所以数组大小要比字符串长度多 1！

**字符数组的内存结构（"mike"）：**

| 下标 | 0 | 1 | 2 | 3 | 4 |
|------|---|---|---|---|---|
| 字符 | m | i | k | e | \0 |
| ASCII | 109 | 105 | 107 | 101 | 0 |

---

#### 2.3 字符串结束符 `\0`

`\0` 是 ASCII 码为 0 的特殊字符，用来标记字符串的结束位置。

大多数字符串函数（如 `strlen`、`printf`）都靠识别 `\0` 来确定字符串长度。

```cpp
char a[10] = "hello";
// a[0]='h', a[1]='e', ..., a[4]='o', a[5]='\0'
// a[6]~a[9] 未定义（随机值）

cout << strlen(a);  // 输出 5（\0 之前的字符数）
cout << sizeof(a);  // 输出 10（数组分配的总空间）
```

---

#### 2.4 输入字符数组

```cpp
char name[100];

// 方式1：cin >> name（遇空格停止）
cin >> name;

// 方式2：cin.getline（可以读含空格的字符串）
cin.getline(name, 100);   // 最多读 99 个字符

// 方式3：gets（可以读含空格，但不安全，了解即可）
// gets(name);
```

> 💡 如果要读取含空格的一整行，用 `cin.getline(name, 大小)`！

---

#### 2.5 常用字符数组函数（需要 `#include <cstring>`）

**① strlen — 字符串长度**

```cpp
char s[] = "hello";
int len = strlen(s);  // 5（不含 \0）
```

**② strcpy — 字符串复制**

```cpp
char dest[20];
strcpy(dest, "hello");  // 将 "hello" 复制到 dest
```

**③ strcat — 字符串连接**

```cpp
char s1[30] = "hello";
char s2[] = " world";
strcat(s1, s2);  // s1 变为 "hello world"
```

**④ strcmp — 字符串比较**

```cpp
int r = strcmp("abc", "abd");
// r < 0：前者小；r == 0：相等；r > 0：前者大
```

> 字符串比较是按**字典序**（逐字符比较 ASCII 码）！

---

#### 2.6 字符大小写转换（需要 `#include <cctype>`）

```cpp
char c = tolower('A');   // 'a'（大写→小写）
char d = toupper('b');   // 'B'（小写→大写）

// 批量转换字符数组
char s[] = "Hello World";
for (int i = 0; s[i] != '\0'; i++) {
    s[i] = tolower(s[i]);  // 全转小写
}
// s 变为 "hello world"
```

**字符判断函数：**

```cpp
isalpha(c)   // 是否是字母
isdigit(c)   // 是否是数字
isupper(c)   // 是否是大写
islower(c)   // 是否是小写
isspace(c)   // 是否是空白字符（空格、\t、\n）
```

### 3. GESP 真题演练 ⚡

**抢答题 1（选择题）：**

> `char a[] = "hello";`，执行 `strlen(a)` 的返回值是？
>
> A. 4  B. 5  C. 6  D. 10
>
> **答案：B**  
> 解析：strlen 返回 `\0` 之前的字符数，"hello" 有 5 个字母，返回 5。

**判断题 2：**

> `char a[5] = "hello";` 是合法的定义。（ ）
>
> **答案：✗（错误）**  
> 解析："hello" 有 5 个字母，加上 `\0` 共 6 个字节，但数组 `a` 只有 5 个空间，会溢出！应定义为 `char a[6]`。

**抢答题 3：**

> 执行以下代码，输出是什么？
> ```cpp
> char c = 'B';
> cout << (char)(c + 32);
> ```
>
> **答案：** 输出 `b`  
> 解析：`'B'` 的 ASCII 是 66，加 32 等于 98，即 `'b'`。

### 4. 进阶扩展

**手动实现 strlen（理解底层）：**

```cpp
int myStrlen(char s[]) {
    int len = 0;
    while (s[len] != '\0') len++;
    return len;
}
```

> 📌 黑板推演：遍历字符数组，每读一个非 `\0` 的字符就计数 +1，直到遇到 `\0` 停止。

**字符数组遍历的两种方式：**

```cpp
char s[] = "hello";
int n = strlen(s);

// 方式1：用 strlen 控制循环
for (int i = 0; i < n; i++) cout << s[i];

// 方式2：用 \0 作为终止条件（更通用）
for (int i = 0; s[i] != '\0'; i++) cout << s[i];
```

**题目描述：**

**输入格式：**
- 一行字符串（长度 ≤ 1000）

- 字符串长度

**样例输入：**
```
hello
```

**样例输出：**

```
5
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
char s[1005];
int main() {
    cin >> s;
    int len = 0;
    while (s[len] != '\0') len++;
    cout << len << endl;
    return 0;
}
```

### 练习 2（基础）：统计大小写字母和数字

**题目描述：**

输入一行字符串（可能含空格），分别统计其中大写字母、小写字母、数字和其他字符的个数。

**输入格式：**
- 一行字符串（长度 ≤ 1000）

**输出格式：**
- 四行，依次输出大写字母数、小写字母数、数字数、其他字符数

**样例输入：**
```
Hello World! 123
```

**样例输出：**
```
2
8
3
3
```

**题解代码：**

```cpp
#include <iostream>
#include <cctype>
using namespace std;
char s[1005];
int main() {
    cin.getline(s, 1005);
    int up=0, lo=0, dig=0, oth=0;
    for (int i = 0; s[i] != '\0'; i++) {
        if (isupper(s[i])) up++;
        else if (islower(s[i])) lo++;
        else if (isdigit(s[i])) dig++;
        else oth++;
    }
    cout << up << endl << lo << endl << dig << endl << oth << endl;
    return 0;
}
```

### 练习 3（综合）：字符串大小写互换

**题目描述：**

输入一个字符串，将其中所有大写字母转为小写，小写字母转为大写，其他字符不变，输出结果。

**输入格式：**
- 一行字符串（长度 ≤ 1000）

**输出格式：**
- 转换后的字符串

**样例输入：**
```
Hello World!
```

**样例输出：**
```
hELLO wORLD!
```

**题解代码：**

```cpp
#include <iostream>
#include <cctype>
using namespace std;
char s[1005];
int main() {
    cin.getline(s, 1005);
    for (int i = 0; s[i] != '\0'; i++) {
        if (isupper(s[i])) s[i] = tolower(s[i]);
        else if (islower(s[i])) s[i] = toupper(s[i]);
    }
    cout << s << endl;
    return 0;
}
```

### 练习 4（综合）：字符串比较

**题目描述：**

输入两个字符串，判断它们的字典序关系：输出 `<`、`=` 或 `>`。

**输入格式：**
- 两行，每行一个字符串（长度 ≤ 100）

**输出格式：**
- 输出 `<`、`=` 或 `>`

**样例输入：**
```
apple
banana
```

**样例输出：**
```
<
```

**题解代码：**

```cpp
#include <iostream>
#include <cstring>
using namespace std;
char a[105], b[105];
int main() {
    cin >> a >> b;
    int r = strcmp(a, b);
    if (r < 0) cout << "<" << endl;
    else if (r == 0) cout << "=" << endl;
    else cout << ">" << endl;
    return 0;
}
```

### 练习 5（进阶）：判断字符串是否为回文

**题目描述：**

输入一个只含小写字母的字符串，判断它是否是回文串（正读和倒读相同）。

**输入格式：**
- 一行字符串（长度 ≤ 1000，只含小写字母）

**输出格式：**
- `YES` 或 `NO`

**样例输入：**
```
racecar
```

**样例输出：**
```
YES
```

**题解代码：**

```cpp
#include <iostream>
#include <cstring>
using namespace std;
char s[1005];
int main() {
    cin >> s;
    int n = strlen(s);
    bool ok = true;
    int l = 0, r = n - 1;
    while (l < r) {
        if (s[l] != s[r]) { ok = false; break; }
        l++; r--;
    }
    cout << (ok ? "YES" : "NO") << endl;
    return 0;
}
```

#### 作业 2：统计某字符出现次数

输入字符串和一个字符 c，统计 c 在字符串中出现了多少次。

**样例输入：**
```
hello world
l
```
**样例输出：** `3`

```cpp
#include <iostream>
using namespace std;
char s[1005];
int main() {
    cin.getline(s, 1005);
    char c; cin >> c;
    int cnt = 0;
    for (int i = 0; s[i]; i++) if (s[i] == c) cnt++;
    cout << cnt << endl;
    return 0;
}
```

#### 作业 3：字符串拼接

输入两个字符串，手动将它们拼接（不用 strcat），输出结果。

**样例输入：**
```
hello
world
```
**样例输出：** `helloworld`

```cpp
#include <iostream>
#include <cstring>
using namespace std;
char a[1005], b[1005], c[2005];
int main() {
    cin >> a >> b;
    int la = strlen(a), lb = strlen(b);
    for (int i = 0; i < la; i++) c[i] = a[i];
    for (int i = 0; i < lb; i++) c[la+i] = b[i];
    c[la+lb] = '\0';
    cout << c << endl;
    return 0;
}
```
