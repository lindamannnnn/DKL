# CSP03-09 模拟算法

## 一、课程简介（5分钟）

### 🎯 课程目标

1. 理解模拟算法的核心思想：让程序忠实地模拟现实过程
2. 识别适合用模拟算法解决的题目特征
3. 掌握模拟算法的设计步骤和编程技巧
4. 能够独立分析模拟题并实现代码

### 📚 核心知识点

- 模拟算法的定义：按照题目描述的规则，一步步模拟执行
- 适用模拟法的题目特征：有明确规则，可以一步步执行
- 模拟的三要素：状态定义、状态转移、终止条件
- 常见模拟场景：游戏规则模拟、数学运算模拟、时钟日历模拟
- 模拟编程的注意点：边界条件、循环不变量、特殊情况

### 2. 知识点讲解

#### 2.1 模拟算法的特征

适合用模拟法的题目通常有：

✅ 题目描述了明确的操作规则  
✅ 操作次数有限（或有明确终止条件）  
✅ 按规则逐步执行就能得到答案  
✅ 很难找到数学规律的"直接公式"

```
题目特征词汇（出现这些词，大概率是模拟题）：
- "每一步/每一轮/每次"
- "按照规则"
- "重复直到"
- "经过N次操作后"
```

---

#### 2.2 模拟算法的设计步骤

1. **读懂题目**：弄清每一步的规则
2. **定义状态**：用变量记录程序的当前状态
3. **实现转移**：按规则更新状态
4. **确定终止**：满足什么条件停下来

---

#### 2.3 经典示例：蜗牛爬竿

```cpp
int height = 10;  // 竿高
int pos = 0;      // 当前位置
int day = 0;      // 天数

while (pos < height) {
    day++;
    pos += 3;       // 白天爬 3 米
    if (pos >= height) break;  // 爬上了！
    pos -= 2;       // 晚上滑落 2 米
}
cout << day << endl;  // 输出 8
```

---

#### 2.4 经典示例：约瑟夫问题（报数游戏）

n 个人围成一圈，从第 1 个人开始每次报数，报到 m 的人出圈，问最后剩下哪个人？

```cpp
int n, m;
cin >> n >> m;

bool alive[105] = {};   // 所有人都在（全false = 未出圈）
int count = 0;          // 当前报数
int cur = 0;            // 当前位置
int remaining = n;      // 剩余人数

while (remaining > 1) {
    cur = (cur % n);     // 循环到下一个位置
    if (!alive[cur]) {   // 如果未出圈
        count++;
        if (count == m) {
            alive[cur] = true;  // 出圈
            remaining--;
            count = 0;
        }
    }
    cur++;
}

// 找最后一个未出圈的人
for (int i = 0; i < n; i++) {
    if (!alive[i]) cout << i + 1 << endl;
}
```

---

#### 2.5 模拟的注意事项

> 📌 常见容易出错的地方：
>
> - **边界条件**：第一步/最后一步是否特殊？
> - **循环控制**：用 while 还是 for？终止条件是什么？
> - **溢出越界**：模拟坐标时是否在有效范围内？
> - **顺序问题**：多个操作的顺序是否正确？

### 4. 进阶扩展

**方向数组（模拟移动的利器）：**

在模拟方向性移动时（上下左右），可以用"方向数组"简化代码：

```cpp
int dx[] = {0, 0, 1, -1};   // 上下右左的 x 偏移
int dy[] = {1, -1, 0, 0};   // 上下右左的 y 偏移

// 向上移动一格：
int x = 3, y = 3;
int dir = 0;  // 方向 0 = 上
x += dx[dir];
y += dy[dir];
```

> 📌 黑板推演：定义好方向数组后，移动时只需 `x += dx[dir]`，代码优雅且易于扩展到更多方向！

### 练习 1（基础）：银行叫号模拟

**题目描述：**

银行有 n 个客户按顺序到达（每人服务需要 t 分钟），所有客户排在一个队列里，服务员从 0 时刻开始连续服务，输出每位客户结束服务的时刻。

**输入格式：**
- 第一行整数 n（1 ≤ n ≤ 100）
- 第二行 n 个整数，第 i 个数是第 i 位客户需要的服务时间（1 ≤ t ≤ 60）

**输出格式：**
- n 行，每行一个整数，第 i 行是第 i 位客户结束服务的时刻

**样例输入：**
```
3
5 3 8
```

**样例输出：**
```
5
8
16
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    int time = 0;
    for (int i = 1; i <= n; i++) {
        int t; cin >> t;
        time += t;
        cout << time << endl;
    }
    return 0;
}
```

### 练习 2（基础）：模拟发牌

**题目描述：**

n 张牌（编号 1~n），按顺序发给 m 个人（循环发，每人每次得1张），全部发完后，输出每个人手中的牌（按得牌顺序）。

**输入格式：**
- 第一行整数 n 和 m（1 ≤ m ≤ n ≤ 100）

**输出格式：**
- m 行，第 i 行是第 i 个人拥有的牌（按得牌顺序），空格分隔

**样例输入：**
```
7 3
```

**样例输出：**
```
1 4 7
2 5
3 6
```

**题解代码：**

```cpp
#include <iostream>
#include <vector>
using namespace std;
int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> hands(m + 1);
    for (int card = 1; card <= n; card++) {
        int person = (card - 1) % m + 1;
        hands[person].push_back(card);
    }
    for (int i = 1; i <= m; i++) {
        for (int j = 0; j < hands[i].size(); j++) {
            if (j > 0) cout << " ";
            cout << hands[i][j];
        }
        cout << endl;
    }
    return 0;
}
```

### 练习 3（综合）：蜗牛爬竿

**题目描述：**

蜗牛爬高度为 h 米的竹竿：第一天爬 u 米（不滑落），之后每天白天爬 u 米，晚上滑落 d 米（白天爬上则不滑落），求到达顶端需要几天。

**输入格式：**
- 三个整数 h u d（1 ≤ d < u ≤ h ≤ 1000）

**输出格式：**
- 天数

**样例输入：**
```
10 3 2
```

**样例输出：**
```
8
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int main() {
    int h, u, d;
    cin >> h >> u >> d;
    int pos = 0, day = 0;
    while (pos < h) {
        day++;
        pos += u;
        if (pos >= h) break;
        pos -= d;
    }
    cout << day << endl;
    return 0;
}
```

### 练习 4（综合）：模拟走迷宫

**题目描述：**

一个机器人在 n×m 的网格中移动，从 (1,1) 出发，按照给定的指令序列移动（U=上，D=下，L=左，R=右）。遇到边界则忽略该指令。输出最终坐标。

**输入格式：**
- 第一行 n m（网格大小）
- 第二行指令序列（只含U/D/L/R）

**输出格式：**
- 两个整数：最终行坐标和列坐标

**样例输入：**
```
5 5
RRDDUULL
```

**样例输出：**
```
1 1
```

**题解代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
    int n, m;
    cin >> n >> m;
    string cmd;
    cin >> cmd;
    int x = 1, y = 1;
    for (char c : cmd) {
        if (c == 'U' && x > 1) x--;
        else if (c == 'D' && x < n) x++;
        else if (c == 'L' && y > 1) y--;
        else if (c == 'R' && y < m) y++;
    }
    cout << x << " " << y << endl;
    return 0;
}
```

### 练习 5（进阶）：模拟击鼓传花

**题目描述：**

n 个人围圈，从第 k 个人开始顺时针传花，每传 m 次拿到花的人出圈，求出圈顺序。

**输入格式：**
- 第一行 n k m（1 ≤ k ≤ n ≤ 100，1 ≤ m ≤ 100）

**输出格式：**
- n 个人按出圈顺序排列（编号1-indexed）

**样例输入：**
```
5 1 3
```

**样例输出：**
```
3 1 5 2 4
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, k, m;
    cin >> n >> k >> m;
    bool alive[105] = {};
    int cur = k - 1;   // 从第k个人（0-indexed）
    int remaining = n;
    while (remaining > 0) {
        int count = 0;
        while (count < m) {
            if (!alive[cur]) count++;
            if (count < m) cur = (cur + 1) % n;
        }
        cout << cur + 1;
        alive[cur] = true;
        remaining--;
        if (remaining > 0) cout << " ";
        cur = (cur + 1) % n;
    }
    cout << endl;
    return 0;
}
```

#### 作业 2：弹球模拟

球在 1~n 的一排格子里运动，从位置 p 出发，每次移动 v（方向可变），碰壁反弹，求 t 步后的位置。

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, p, v, t;
    cin >> n >> p >> v >> t;
    int dir = 1;  // 1=右，-1=左
    for (int i = 0; i < t; i++) {
        p += dir * v;
        if (p > n) { p = 2*n - p; dir = -1; }
        if (p < 1) { p = 2 - p; dir = 1; }
    }
    cout << p << endl;
    return 0;
}
```

#### 作业 3：模拟栈

实现简单栈操作：push x（压入 x），pop（弹出栈顶），top（查看栈顶）。输入 q 条命令，输出每个 top 和 pop 的结果。

**题解代码（简化版）：**

```cpp
#include <iostream>
#include <string>
using namespace std;
int stk[1005], top_idx = 0;
int main() {
    int q; cin >> q;
    while (q--) {
        string op; cin >> op;
        if (op == "push") { int x; cin >> x; stk[++top_idx] = x; }
        else if (op == "pop") { cout << stk[top_idx--] << endl; }
        else if (op == "top") { cout << stk[top_idx] << endl; }
    }
    return 0;
}
```
