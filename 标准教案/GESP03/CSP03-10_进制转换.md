# CSP03-10 进制转换

## 一、课程简介（5分钟）

### 🎯 课程目标

1. 理解不同进制的含义与表示方式
2. 掌握十进制与 X 进制之间的相互转换
3. 掌握二进制与 2 的倍数进制（八进制、十六进制）的快速转换
4. 掌握 X 进制到 Y 进制的转换方法

### 📚 核心知识点

- 进制的概念：R 进制中每位的权值是 R 的幂次
- 十进制转 R 进制：连除取余（短除法）
- R 进制转十进制：按权展开求和
- 二进制与八进制：3位二进制 = 1位八进制
- 二进制与十六进制：4位二进制 = 1位十六进制
- X 进制转 Y 进制：先转十进制，再转目标进制

### 2. 知识点讲解

#### 2.1 进制的概念

R 进制中：每位数字范围是 `0 ~ R-1`，每位的**权值**是 R 的幂次。

**十进制 1234 的展开：**

```
1234 = 1×10³ + 2×10² + 3×10¹ + 4×10⁰
     = 1000 + 200 + 30 + 4
```

**二进制 1011₂ 转十进制：**

```
1011₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰
      = 8 + 0 + 2 + 1 = 11₁₀
```

---

#### 2.2 十进制转 R 进制（短除法）

**方法：** 不断除以 R 取余，将余数**从下往上**排列。

**示例：** 13₁₀ 转二进制

```
13 ÷ 2 = 6 ... 余 1   ← 最低位
 6 ÷ 2 = 3 ... 余 0
 3 ÷ 2 = 1 ... 余 1
 1 ÷ 2 = 0 ... 余 1   ← 最高位

从下往上读余数：1101₂
验证：8 + 4 + 0 + 1 = 13 ✓
```

**代码实现：**

```cpp
void toBase(int n, int base) {
    if (n == 0) { cout << 0; return; }
    string result = "";
    string digits = "0123456789ABCDEF";  // 0~15的表示
    while (n > 0) {
        result = digits[n % base] + result;  // 余数放前面
        n /= base;
    }
    cout << result;
}
```

---

#### 2.3 R 进制转十进制（按权展开）

**方法：** 从高位到低位，依次乘以 R 的幂次后求和。

**公式：** `d[k]*R^k + d[k-1]*R^(k-1) + ... + d[1]*R + d[0]`

**代码实现（字符串表示的 R 进制数转十进制）：**

```cpp
int fromBase(string s, int base) {
    int result = 0;
    for (char c : s) {
        int digit;
        if (c >= '0' && c <= '9') digit = c - '0';
        else digit = c - 'A' + 10;  // 处理 A~F
        result = result * base + digit;
    }
    return result;
}
```

> 💡 这就是"Horner法则"：`result = result * base + digit`，从左到右扫描，每次乘以进制再加当前位。

---

#### 2.4 二进制与八进制的快速转换

**规律：** 3 位二进制恰好对应 1 位八进制（2³ = 8）

| 八进制 | 二进制 |
|--------|--------|
| 0 | 000 |
| 1 | 001 |
| 2 | 010 |
| 3 | 011 |
| 4 | 100 |
| 5 | 101 |
| 6 | 110 |
| 7 | 111 |

**示例：** 二进制 `110101₂` 转八进制

```
分组（从右往左，3位一组）：110 | 101
110₂ = 6₈，101₂ = 5₈
结果：65₈
```

---

#### 2.5 二进制与十六进制的快速转换

**规律：** 4 位二进制恰好对应 1 位十六进制（2⁴ = 16）

| 十六进制 | 十进制 | 二进制 |
|----------|--------|--------|
| 0~9 | 0~9 | 0000~1001 |
| A | 10 | 1010 |
| B | 11 | 1011 |
| C | 12 | 1100 |
| D | 13 | 1101 |
| E | 14 | 1110 |
| F | 15 | 1111 |

**示例：** 二进制 `11010110₂` 转十六进制

```
分组（从右往左，4位一组）：1101 | 0110
1101₂ = D₁₆，0110₂ = 6₁₆
结果：D6₁₆
```

---

#### 2.6 X 进制转 Y 进制

**通用方法：** X进制 → 十进制 → Y进制（两步走）

```cpp
// 示例：二进制转十六进制
string binToHex(string bin) {
    int decimal = fromBase(bin, 2);   // 二进制转十进制
    string hex = "";
    toBase(decimal, 16, hex);         // 十进制转十六进制
    return hex;
}
```

### 练习 4（综合）：二进制转十六进制

**题目描述：**

输入一个二进制字符串（长度是 4 的倍数），将其转换为十六进制表示（大写字母）。

**输入格式：**
- 一行二进制字符串（长度 4~64，是 4 的倍数）

**输出格式：**
- 对应的十六进制表示

**样例输入：**
```
11010110
```

**样例输出：**
```
D6
```

**题解代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
    string s; cin >> s;
    string digits = "0123456789ABCDEF";
    string result = "";
    for (int i = 0; i < s.size(); i += 4) {
        int val = 0;
        for (int j = 0; j < 4; j++) {
            val = val * 2 + (s[i + j] - '0');
        }
        result += digits[val];
    }
    cout << result << endl;
    return 0;
}
```

### 练习 5（进阶）：X 进制转 Y 进制

**题目描述：**

输入两个进制数 from 和 to（2 ≤ from, to ≤ 16），以及一个 from 进制的数（用大写字母A~F表示10~15），将其转换为 to 进制表示。

**输入格式：**
- 第一行两个整数 from to
- 第二行输入 from 进制的数

**输出格式：**
- to 进制表示

**样例输入：**
```
8 2
37
```

**样例输出：**
```
11111
```

**题解代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;
int fromBase(string s, int base) {
    int result = 0;
    string digits = "0123456789ABCDEF";
    for (char c : s) {
        int d = digits.find(c);
        result = result * base + d;
    }
    return result;
}
string toBase(int n, int base) {
    if (n == 0) return "0";
    string digits = "0123456789ABCDEF";
    string result = "";
    while (n > 0) {
        result = digits[n % base] + result;
        n /= base;
    }
    return result;
}
int main() {
    int from, to;
    cin >> from >> to;
    string s; cin >> s;
    int decimal = fromBase(s, from);
    cout << toBase(decimal, to) << endl;
    return 0;
}
```
