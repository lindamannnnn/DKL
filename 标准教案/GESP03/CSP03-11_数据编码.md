# CSP03-11 数据编码

## 一、课程简介（5分钟）

### 🎯 课程目标

1. 理解"机器数"的概念：计算机中数的存储形式
2. 理解带符号整数的三种编码方式：原码、反码、补码
3. 掌握正负数的原码、反码、补码推导方法
4. 了解补码在计算机中的实际应用

### 📚 核心知识点

- 机器数：计算机中存储数字的二进制格式（包含符号位）
- 原码：符号位 + 绝对值的二进制（最直观的表示）
- 反码：正数的反码 = 原码；负数的反码 = 符号位不变，其余位取反
- 补码：正数的补码 = 原码；负数的补码 = 反码 + 1
- 补码的意义：统一了加减法运算，是现代计算机实际使用的编码

### 2. 知识点讲解

#### 2.1 机器数的概念

**机器数**：计算机中实际存储的带符号整数的二进制形式。

- 使用固定位数（如 8 位、32 位）
- 最高位（最左位）是**符号位**：0 = 正，1 = 负
- 剩余位表示数值

**真值**：机器数对应的实际数学值（即我们平时说的那个数）。

---

#### 2.2 原码

**定义：** 符号位 + 绝对值的二进制表示

```
+5  的原码（8位）= 0 0000101
-5  的原码（8位）= 1 0000101
+0  的原码（8位）= 0 0000000
-0  的原码（8位）= 1 0000000   ← 问题：0有两种表示！
```

**优点：** 直观，易于理解
**缺点：** 0 有两种表示（+0、-0）；加减法需要单独处理符号，运算复杂

---

#### 2.3 反码

**正数的反码** = 原码（不变）

**负数的反码** = 符号位不变，其余位全部取反（0变1，1变0）

```
+5  的原码 = 0 0000101   反码 = 0 0000101（不变）
-5  的原码 = 1 0000101   反码 = 1 1111010（符号位不变，其余取反）
```

**验证：** +5 + (-5) = 0

```
  0 0000101  (+5反码)
+ 1 1111010  (-5反码)
-----------
  1 1111111  = -127的反码？？（还是不对！）
```

> 反码解决了部分问题，但 0 还是有两种表示（`0 0000000` 和 `1 1111111`），加减法仍有问题。

---

#### 2.4 补码

**正数的补码** = 原码（不变）

**负数的补码** = 反码 + 1

```
+5  的原码 = 0 0000101   补码 = 0 0000101（不变）
-5  的反码 = 1 1111010   补码 = 1 1111011（反码+1）
```

**验证：** +5 + (-5) = 0（补码相加）

```
  0 0000101  (+5补码)
+ 1 1111011  (-5补码)
-----------
 10 0000000  ← 最高位进位溢出（9位），丢弃！
  0 0000000  = 0 ✓
```

> 用补码 +5 + (-5) = 0，完全正确！

---

#### 2.5 三种编码对比（以 8 位为例）

| 真值 | 原码 | 反码 | 补码 |
|------|------|------|------|
| +5 | 0 0000101 | 0 0000101 | 0 0000101 |
| -5 | 1 0000101 | 1 1111010 | 1 1111011 |
| +0 | 0 0000000 | 0 0000000 | 0 0000000 |
| -0 | 1 0000000 | 1 1111111 | （不存在）|
| -128 | 不可表示 | 不可表示 | 1 0000000 |

> 💡 补码的优势：  
> ① 0 只有唯一编码（解决了+0和-0的问题）  
> ② 加减法统一（减法 = 加上相反数的补码）  
> ③ 可以多表示一个数（-128，8位原码无法表示）  
> 这就是为什么 **int 的范围是 -2³¹ 到 2³¹-1** 而不是 -(2³¹-1) 到 2³¹-1！

---

#### 2.6 推导口诀

**原码 → 补码（负数）：**

方法一：反码 + 1

方法二：从右往左找第一个 1，该位不变，该位左边所有非符号位取反

**补码 → 原码（负数）：**

补码 - 1 = 反码，再取反 = 原码

或者：再做一次"求补"操作（对补码再取补，结果就是原码）

### 4. 进阶扩展

**溢出现象：**

在有符号 8 位整数中，127 + 1 = ?

```
  0 1111111  (127的补码)
+ 0 0000001  (1的补码)
-----------
  1 0000000  ← 这是 -128 的补码！
```

> 127 + 1 = -128（溢出！）这就是 `INT_MAX + 1` 会变成 `INT_MIN` 的原因！

**黑板推演：补码的本质**

> 8 位无符号整数的范围是 0~255（2⁸ = 256 个数）  
> 把高半（128~255）"重新解释"为 -128~-1，就得到了有符号整数 -128~127！  
> 这是补码的本质：充分利用二进制状态，统一编码正负数。

## 四、课堂练习（45分钟）🎈

### 练习 1（基础）：求正数的原码、反码、补码

**题目描述：**

输入一个正整数 n（1 ≤ n ≤ 127），以 8 位二进制形式输出其原码、反码、补码。

**输入格式：**
- 一个整数 n

**输出格式：**
- 三行分别输出原码、反码、补码（8位，最高位是符号位）

**样例输入：**
```
5
```

**样例输出：**
```
00000101
00000101
00000101
```

**题解代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;
string toBin8(int n) {
    string s = "";
    for (int i = 7; i >= 0; i--) s += (char)('0' + ((n >> i) & 1));
    return s;
}
int main() {
    int n; cin >> n;
    cout << toBin8(n) << endl;  // 正数原=反=补
    cout << toBin8(n) << endl;
    cout << toBin8(n) << endl;
    return 0;
}
```

### 练习 2（基础）：求负数的原码、反码、补码

**题目描述：**

输入一个负整数 n（-128 ≤ n ≤ -1），以 8 位二进制形式输出其原码、反码、补码。

**输入格式：**
- 一个负整数 n

**输出格式：**
- 三行分别输出原码、反码、补码

**样例输入：**
```
-5
```

**样例输出：**
```
10000101
11111010
11111011
```

**题解代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;
string toBin7(int n) {  // 7位数值部分
    string s = "";
    for (int i = 6; i >= 0; i--) s += (char)('0' + ((n >> i) & 1));
    return s;
}
int main() {
    int n; cin >> n;
    int abs_n = -n;
    string val = toBin7(abs_n);
    
    // 原码：1 + 绝对值
    string yuanma = "1" + val;
    cout << yuanma << endl;
    
    // 反码：符号位不变，其余取反
    string fanma = "1";
    for (char c : val) fanma += (c == '0' ? '1' : '0');
    cout << fanma << endl;
    
    // 补码：反码 + 1
    int carry = 1;
    string buma = fanma;
    for (int i = 7; i >= 1 && carry; i--) {
        if (buma[i] == '0') { buma[i] = '1'; carry = 0; }
        else buma[i] = '0';
    }
    cout << buma << endl;
    return 0;
}
```

### 练习 3（综合）：补码转真值

**题目描述：**

输入一个 8 位二进制补码字符串，输出对应的真值（十进制有符号整数，范围 -128~127）。

**输入格式：**
- 一个 8 位二进制字符串

**输出格式：**
- 对应的十进制有符号整数

**样例输入：**
```
11111011
```

**样例输出：**
```
-5
```

**题解代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
    string s; cin >> s;
    if (s[0] == '0') {
        // 正数：直接按位求值
        int val = 0;
        for (char c : s) val = val*2 + (c-'0');
        cout << val << endl;
    } else {
        // 负数：补码转原码
        // 方法：对补码再求补（取反+1）= 绝对值
        string tmp = s;
        for (int i = 1; i < 8; i++) tmp[i] = (tmp[i]=='0'?'1':'0');
        int carry = 1;
        for (int i = 7; i >= 1 && carry; i--) {
            if (tmp[i]=='0') { tmp[i]='1'; carry=0; }
            else tmp[i]='0';
        }
        int val = 0;
        for (int i = 1; i < 8; i++) val = val*2 + (tmp[i]-'0');
        cout << -val << endl;
    }
    return 0;
}
```

### 练习 4（综合）：整数溢出分析

**题目描述：**

8 位有符号整数的范围是 -128~127。输入两个 8 位有符号整数 a 和 b（-128 ≤ a, b ≤ 127），判断 a+b 是否会在 8 位有符号整数范围内溢出，若不溢出输出结果，否则输出 `OVERFLOW`。

**输入格式：**
- 两个整数 a b

**输出格式：**
- 结果或 `OVERFLOW`

**样例输入：**
```
100 50
```

**样例输出：**
```
OVERFLOW
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;
    int sum = a + b;
    if (sum < -128 || sum > 127) cout << "OVERFLOW" << endl;
    else cout << sum << endl;
    return 0;
}
```

### 练习 5（进阶）：手动实现补码加法

**题目描述：**

输入两个 8 位补码字符串（最高位为符号位），用二进制加法计算它们的补码之和，输出结果补码（忽略第 9 位进位）。同时输出对应的真值（范围 -128~127）。

**输入格式：**
- 两行 8 位二进制字符串（补码）

**输出格式：**
- 两行：结果补码、结果真值

**样例输入：**
```
00000101
11111011
```

**样例输出：**
```
00000000
0
```

**题解代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
    string a, b;
    cin >> a >> b;
    string result(8, '0');
    int carry = 0;
    for (int i = 7; i >= 0; i--) {
        int sum = (a[i]-'0') + (b[i]-'0') + carry;
        result[i] = '0' + sum % 2;
        carry = sum / 2;
    }
    // 忽略最高位进位
    cout << result << endl;
    // 转真值
    if (result[0] == '0') {
        int val = 0;
        for (char c : result) val = val*2 + (c-'0');
        cout << val << endl;
    } else {
        string tmp = result;
        for (int i = 1; i < 8; i++) tmp[i] = (tmp[i]=='0'?'1':'0');
        int carry2 = 1;
        for (int i = 7; i >= 1 && carry2; i--) {
            if (tmp[i]=='0'){tmp[i]='1';carry2=0;}
            else tmp[i]='0';
        }
        int val = 0;
        for (int i = 1; i < 8; i++) val = val*2 + (tmp[i]-'0');
        cout << -val << endl;
    }
    return 0;
}
```
