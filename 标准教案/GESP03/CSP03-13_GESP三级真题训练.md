## 三、GESP 三级真题演练（55分钟）

### 📚 选择题专项（15题）

**以下为 GESP 三级风格选择题，每题 2 分：**

**第1题：**

> 定义 `int a[5] = {1, 2, 3};`，则 `a[4]` 的值是？
>
> A. 3  B. 1  C. 0  D. 不确定
>
> **答案：C**  
> 解析：用 `{}` 初始化，未指定的部分自动为 0，所以 `a[3]=a[4]=0`。

---

**第2题：**

> 以下代码执行后，数组 `a` 变为？
> ```cpp
> int a[5] = {1, 2, 3, 4, 5};
> for(int i=1; i<=4; i++) a[i-1] = a[i];
> ```
>
> A. {2,3,4,5,5}  B. {1,1,2,3,4}  C. {2,3,4,5,0}  D. {1,2,3,4,5}
>
> **答案：A**  
> 解析：这是删除第0个元素的操作（从前往后覆盖），`a` 变为 `{2,3,4,5,5}`，最后一个5未被覆盖。

---

**第3题：**

> 在 n 个数中用计数法找出现次数最多的数，适用条件是？
>
> A. 数字个数少，范围不限  
> B. 数字范围小（适合开数组），个数不限  
> C. 数字完全随机  
> D. 只适用于排好序的数组
>
> **答案：B**

---

**第4题：**

> `char a[] = "hello";`，`strlen(a)` 的返回值是？
>
> A. 4  B. 5  C. 6  D. 10
>
> **答案：B**

---

**第5题：**

> `string s = "abcdefg"; s.substr(2, 3)` 的结果是？
>
> A. "abc"  B. "bcd"  C. "cde"  D. "def"
>
> **答案：C**  
> 解析：从下标 2 开始，取 3 个字符："cde"

---

**第6题：**

> 十进制 25 的二进制表示是？
>
> A. 10011  B. 11001  C. 11000  D. 10101
>
> **答案：B**  
> 解析：25 = 16+8+1 = 11001₂

---

**第7题：**

> -8 的 8 位补码是？
>
> A. 11111000  B. 10001000  C. 11110111  D. 11111001
>
> **答案：A**  
> 解析：+8原码=00001000，取反=11110111，加1=11111000

---

**第8题：**

> `6 ^ 3` 的结果是（`^` 表示异或）？
>
> A. 5  B. 6  C. 4  D. 7
>
> **答案：A**  
> 解析：6=110₂，3=011₂，110^011=101₂=5

---

**第9题：**

> 下列哪个表达式可以快速判断 n 是否是 2 的整数次幂？
>
> A. `n % 2 == 0`  B. `n & (n-1) == 0`  C. `n >> 1 == 0`  D. `~n == 0`
>
> **答案：B**  
> 解析：2 的幂次二进制只有 1 个 1，`n & (n-1)` 去掉最低位的 1 变为 0。注意需加上 `n > 0`。

---

**第10题：**

> 枚举算法中，"剪枝"的目的是？
>
> A. 减少代码行数  B. 跳过不可能是答案的情况，提高效率  C. 让循环更美观  D. 增加答案的准确性
>
> **答案：B**

---

**第11题：**

> 使用模拟算法解题时，首先要做的是？
>
> A. 找数学公式  B. 确定枚举范围  C. 理清题目的操作规则和状态变化  D. 决定使用排序
>
> **答案：C**

---

**第12题：**

> 以下操作中，哪个会将整数 n 的第 3 位（从 0 计）清零？
>
> A. `n & (1 << 3)`  B. `n | (1 << 3)`  C. `n & ~(1 << 3)`  D. `n ^ (1 << 3)`
>
> **答案：C**  
> 解析：`~(1<<3)` 使第3位为0其余为1，与 n 按位与后第3位必为0。

---

**第13题：**

> 二进制数 `1010 0110` 对应的十六进制数是？
>
> A. `A6`  B. `6A`  C. `B6`  D. `A5`
>
> **答案：A**  
> 解析：1010₂=A₁₆，0110₂=6₁₆，合并=A6₁₆

---

**第14题：**

> 字符 `'A'` 的 ASCII 码是 65，则 `'Z'` 的 ASCII 码是？
>
> A. 90  B. 91  C. 89  D. 92
>
> **答案：A**  
> 解析：A~Z 是连续的 26 个字母，A=65，Z=65+25=90

---

**第15题：**

> 数组 `{3,1,4,4,1,5,9}` 中，连续相同次数最多的值和次数是？
>
> A. 1，2  B. 4，2  C. 3，1  D. 4，1
>
> **答案：B**  
> 解析：4 连续出现 2 次（第3、4位），是最长连续段。

### 💻 编程题专项（3题）

**编程题一（简单）：字符串逆序**

输入一行字符串（不含空格），将其逆序后输出。

**样例：** 输入 `hello` → 输出 `olleh`

**题解代码：**

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;
int main() {
    string s; cin >> s;
    reverse(s.begin(), s.end());
    cout << s << endl;
    return 0;
}
```

**编程题二（中等）：进制转换**

输入整数 n（1 ≤ n ≤ 10^6）和目标进制 base（2 ≤ base ≤ 16），输出 n 的 base 进制表示（10以上用A~F表示）。

**样例：** 输入 `255 16` → 输出 `FF`

**题解代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
    int n, base;
    cin >> n >> base;
    if (n == 0) { cout << 0; return 0; }
    string digits = "0123456789ABCDEF";
    string result = "";
    while (n > 0) {
        result = digits[n % base] + result;
        n /= base;
    }
    cout << result << endl;
    return 0;
}
```

**编程题三（较难）：数组操作综合**

输入 n 个整数组成的数组，执行以下操作：
1. 删去所有值为 0 的元素
2. 将剩余数组逆序
3. 统计逆序后数组中出现次数最多的元素（多个并列取最小）

输出最终数组（空格分隔），换行后输出出现次数最多的元素及其次数。

**样例输入：**
```
7
3 0 1 3 0 3 2
```

**样例输出：**
```
2 3 3 1 3
3 3
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int a[105], b[105], cnt[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    
    // 删去0
    int m = 0;
    for (int i = 1; i <= n; i++) if (a[i] != 0) b[++m] = a[i];
    
    // 逆序
    int l = 1, r = m;
    while (l < r) { swap(b[l], b[r]); l++; r--; }
    
    // 统计频次
    for (int i = 1; i <= m; i++) cnt[b[i]]++;
    
    // 输出数组
    for (int i = 1; i <= m; i++) {
        if (i > 1) cout << " ";
        cout << b[i];
    }
    cout << endl;
    
    // 找最多的
    int maxC = 0, ans = 0;
    for (int v = 0; v <= 100; v++) {
        if (cnt[v] > maxC) { maxC = cnt[v]; ans = v; }
    }
    cout << ans << " " << maxC << endl;
    return 0;
}
```
