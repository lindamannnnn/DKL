## 三、编程题（共 3 题，共 50 分）

### 编程题一（10分）：统计字符类型

**题目描述：**

输入一行字符串（可含空格，长度不超过 200），统计其中大写字母、小写字母、数字、其他字符的个数。

**输入格式：**
- 一行字符串

**输出格式：**
- 四行，依次输出大写字母数、小写字母数、数字数、其他字符数

**样例输入：**
```
Hello World! 2024
```

**样例输出：**
```
2
8
4
3
```

**参考代码：**

```cpp
#include <iostream>
#include <cctype>
using namespace std;
char s[205];
int main() {
    cin.getline(s, 205);
    int up=0, lo=0, dig=0, oth=0;
    for (int i=0; s[i]; i++) {
        if (isupper(s[i])) up++;
        else if (islower(s[i])) lo++;
        else if (isdigit(s[i])) dig++;
        else oth++;
    }
    cout << up << endl << lo << endl << dig << endl << oth << endl;
    return 0;
}
```

**评分标准：**
- 能正确读取含空格输入：3分
- 四类字符判断正确：4×1=4分  
- 输出格式正确：3分

### 编程题二（15分）：数组综合操作

**题目描述：**

输入 n 个整数（1 ≤ n ≤ 100，每个整数 1~100），执行以下三步：

1. 找出现次数最多的数 x（若有多个相同取最小的）
2. 删除数组中所有等于 x 的元素
3. 将剩余数组逆序输出

**输入格式：**
- 第一行整数 n
- 第二行 n 个整数

**输出格式：**
- 逆序后的数组（若数组为空则输出一个空行），数字间空格分隔
- 然后输出被删除的数和其出现次数（格式：`删除: x 次数: k`）

**样例输入：**
```
7
3 1 3 2 3 1 2
```

**样例输出：**
```
2 1 2 1
删除: 3 次数: 3
```

**参考代码：**

```cpp
#include <iostream>
using namespace std;
int a[105], cnt[105];
int main() {
    int n; cin >> n;
    for (int i=1;i<=n;i++) { cin>>a[i]; cnt[a[i]]++; }
    
    // 找出现最多的数
    int maxC=0, x=0;
    for (int v=1;v<=100;v++) if(cnt[v]>maxC){maxC=cnt[v];x=v;}
    
    // 删除所有等于 x 的元素
    int m=0;
    int b[105];
    for (int i=1;i<=n;i++) if(a[i]!=x) b[++m]=a[i];
    
    // 逆序输出
    for (int i=m;i>=1;i--) {
        if(i<m) cout<<" ";
        cout<<b[i];
    }
    cout<<endl;
    
    cout<<"删除: "<<x<<" 次数: "<<maxC<<endl;
    return 0;
}
```

**评分标准：**
- 找出现最多的数：4分
- 删除操作：4分
- 逆序输出：4分
- 输出格式：3分

### 编程题三（20分）：进制信息综合

**题目描述：**

输入一个正整数 n（1 ≤ n ≤ 65535），完成以下任务：

1. 输出 n 的二进制表示
2. 输出 n 的十六进制表示（大写字母）
3. 输出 n 的二进制中 1 的个数
4. 输出 n 的补码（16位，最高位是符号位，正数输出0开头）
5. 若 n 是 2 的幂次，输出 `YES`，否则输出 `NO`

**输入格式：**
- 一个正整数 n

**输出格式：**
- 五行，分别对应上述五项

**样例输入：**
```
26
```

**样例输出：**
```
11010
1A
3
0000000000011010
NO
```

**参考代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;

string toBin(int n, int bits) {
    string s = "";
    for (int i = bits-1; i >= 0; i--) s += (char)('0' + ((n >> i) & 1));
    return s;
}

string toHex(int n) {
    if (n == 0) return "0";
    string digits = "0123456789ABCDEF";
    string s = "";
    while (n > 0) { s = digits[n%16] + s; n /= 16; }
    return s;
}

int main() {
    int n; cin >> n;
    cout << toBin(n, 0).substr(toBin(n,16).find('1')) << endl;  // 去除前导0
    // 简化版：
    string bin = "";
    int tmp = n;
    while (tmp > 0) { bin = (char)('0'+tmp%2) + bin; tmp /= 2; }
    cout << bin << endl;  // 二进制
    cout << toHex(n) << endl;  // 十六进制
    int cnt = 0;
    tmp = n;
    while (tmp > 0) { cnt += tmp&1; tmp >>= 1; }
    cout << cnt << endl;  // 1的个数
    cout << toBin(n, 16) << endl;  // 16位补码（正数不变）
    cout << (n > 0 && (n & (n-1)) == 0 ? "YES" : "NO") << endl;  // 2的幂
    return 0;
}
```

**简化参考代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
    int n; cin >> n;
    
    // 1. 二进制
    string bin = "";
    int tmp = n;
    while (tmp > 0) { bin = (char)('0'+tmp%2) + bin; tmp >>= 1; }
    cout << bin << endl;
    
    // 2. 十六进制
    string digits = "0123456789ABCDEF";
    string hex = "";
    tmp = n;
    while (tmp > 0) { hex = digits[tmp%16] + hex; tmp /= 16; }
    cout << hex << endl;
    
    // 3. 1 的个数
    int cnt = 0;
    tmp = n;
    while (tmp > 0) { cnt += tmp & 1; tmp >>= 1; }
    cout << cnt << endl;
    
    // 4. 16位补码（n为正数直接转16位二进制）
    string comp = "";
    for (int i = 15; i >= 0; i--) comp += (char)('0' + ((n >> i) & 1));
    cout << comp << endl;
    
    // 5. 是否2的幂次
    cout << (n > 0 && (n & (n-1)) == 0 ? "YES" : "NO") << endl;
    
    return 0;
}
```

**评分标准：**
- 任务1（二进制）：4分
- 任务2（十六进制）：4分
- 任务3（统计1）：3分
- 任务4（16位补码）：5分
- 任务5（2的幂判断）：4分
