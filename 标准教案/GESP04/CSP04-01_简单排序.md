# CSP04-01 简单排序

## 一、课程简介（5分钟）

### 🎯 课程目标

1. 理解排序的本质概念，掌握三种简单排序算法（冒泡、选择、插入）的核心思路
2. 能够手写三种排序算法的完整代码，并分析每种算法的特点
3. 掌握时间复杂度 O(n²) 和空间复杂度 O(1) 的初步概念
4. 了解排序算法的稳定性含义，能区分三种算法的稳定性

### 📚 核心知识点

- 冒泡排序：相邻比较与交换，每轮将最大值"冒泡"至末尾
- 选择排序：每轮选出最小值放到对应位置
- 插入排序：将元素逐个插入已排序子序列的合适位置
- 时间复杂度：O(n²) 的含义与推导
- 空间复杂度：O(1) 原地排序的概念
- 排序稳定性：相同元素相对顺序是否改变

### 1. 新知导入 🎬

> 想象一下，你手里拿着一副扑克牌，顺序是乱的：`7 3 9 2 5`。
>
> 现在你想把它们整理成从小到大的顺序，你会怎么做？

>
> **方法二（选择思路）：** 每次在剩下的牌里挑出最小的，放到最左边——一轮找一张，n 轮找完！

> **方法三（插入思路）：** 每次取一张新牌，插入到左边已排好序的牌里合适的位置——就像打麻将摸牌整理！
>
> 三种方法都能排好牌，但各有特点。让我们用代码实现它们！

### 2. 知识点讲解

#### 2.1 冒泡排序（Bubble Sort）

**核心思想：** 相邻两个元素比较，大的往后"冒泡"。每一趟把当前最大值沉到末尾。

**推演过程（以 5 3 8 1 为例，升序）：**

> **第 1 趟：**
> - 比较 a[1]=5 和 a[2]=3，5>3，交换 → `3 5 8 1`
> - 比较 a[2]=5 和 a[3]=8，5<8，不换 → `3 5 8 1`
> - 比较 a[3]=8 和 a[4]=1，8>1，交换 → `3 5 1 8`
> - 最大值 8 已到最后！
>
> **规律：** n 个数进行 n-1 趟，第 i 趟比较到 a[n-i]。

**核心代码（升序）：**

```cpp
// n 个数存于 a[1..n]
for (int i = 1; i <= n - 1; i++) {        // 共 n-1 趟
    for (int j = 1; j <= n - i; j++) {    // 第 i 趟比较到 a[n-i]
        if (a[j] > a[j + 1]) {            // 升序：前大后小则交换
            swap(a[j], a[j + 1]);
        }
    }
}
```

> 💡 降序只需将 `>` 改为 `<` 即可。

**互动提问：**

> - 问：n=4 时，一共进行多少次比较？（3+2+1=6 次）
> - 问：如果数据已经完全有序，还需要比较多少次？（仍然 n(n-1)/2 次，但可以优化：加一个 flag，如果某趟一次都没交换就提前退出）

---

#### 2.2 选择排序（Selection Sort）

**核心思想：** 每趟在未排序部分找出最小值，与未排序部分的第一个元素交换。

**推演过程（以 5 3 8 1 为例）：**

> **第 1 趟：** 在 a[1..4] 中找最小值 → a[4]=1，与 a[1]=5 交换 → `1 3 8 5`
>
> **第 2 趟：** 在 a[2..4] 中找最小值 → a[2]=3，无需交换 → `1 3 8 5`
>
> **第 3 趟：** 在 a[3..4] 中找最小值 → a[4]=5，与 a[3]=8 交换 → `1 3 5 8`

**核心代码（升序）：**

```cpp
for (int i = 1; i <= n - 1; i++) {
    int minPos = i;                      // 假设未排序部分第一个最小
    for (int j = i + 1; j <= n; j++) {  // 在 a[i+1..n] 中寻找更小的
        if (a[j] < a[minPos]) {
            minPos = j;                  // 更新最小值位置
        }
    }
    if (minPos != i) {                   // 如果最小值不是当前位置，则交换
        swap(a[i], a[minPos]);
    }
}
```

> 特点：每趟至多交换一次，**交换次数少**，但比较次数和冒泡一样多。

---

#### 2.3 插入排序（Insertion Sort）

**核心思想：** 将第 i 个元素插入到前面已经排好序的 a[1..i-1] 中。

**类比：** 就像整理扑克牌，每次摸一张牌，从右往左找它该插入的位置。

**推演过程（以 5 3 8 1 为例）：**

> - 初始：a[1]=5 认为已排好
> - 插入 a[2]=3：3 < 5，5 后移，3 插到位置 1 → `3 5 8 1`
> - 插入 a[3]=8：8 > 5，直接在位置 3 → `3 5 8 1`
> - 插入 a[4]=1：1 < 8 → 8 后移，1 < 5 → 5 后移，1 < 3 → 3 后移，1 插到位置 1 → `1 3 5 8`

**核心代码（升序）：**

```cpp
for (int i = 2; i <= n; i++) {      // 从第 2 个元素开始
    for (int j = i; j > 1; j--) {  // 向前比较，找到合适位置
        if (a[j] < a[j - 1]) {
            swap(a[j], a[j - 1]);
        } else {
            break;                   // 已找到位置，提前退出
        }
    }
}
```

> 💡 插入排序对**几乎有序**的数据效率很高，最好情况是 O(n)！

---

#### 2.4 时间复杂度与空间复杂度分析

**时间复杂度 O(n²)：**

> 三种排序都有两层循环，内层循环与外层循环都与 n 相关：
>
> 总比较次数 ≈ (n-1) + (n-2) + ... + 1 = n(n-1)/2
>
> 当 n 很大时（如 n=10000），需要约 5000 万次运算，速度明显变慢。
>
> 所以这三种排序适合数据量**不超过 10000** 的情形，更大的数据需要 sort 或归并排序。

**空间复杂度 O(1)：**

> 三种排序都是**原地排序**，只需要一个 `swap` 临时变量，不需要额外数组空间。

**稳定性：**

| 算法 | 稳定性 | 原因 |
|------|--------|------|
| 冒泡排序 | ✅ 稳定 | 相等元素不交换，相对顺序不变 |
| 插入排序 | ✅ 稳定 | 相等时不交换，保持顺序 |
| 选择排序 | ❌ 不稳定 | 可能把相等元素跳过并交换 |

> 💡 稳定性的意义：当按成绩排序时，成绩相同的学生保持原来的名字顺序，这就是"稳定"。

### 3. GESP 真题演练 ⚡

**抢答题 1（选择题）：**

> 对于冒泡排序，将 n 个元素从小到大排序，需要进行（ ）趟比较。
>
> A. n      B. n-1      C. n+1      D. n/2
>
> **答案：B**
>
> 解析：每趟将当前最大值移到末尾，n 个元素只需 n-1 趟，最后一趟只剩 1 个元素，已经有序。

**判断题 2：**

> 选择排序是一种稳定的排序算法。（ ）
>
> **答案：✗（错误）**
>
> 解析：选择排序在每轮找到最小值后会和前面的元素交换，可能破坏相同元素的相对顺序，所以是不稳定的排序。

**抢答题 3（选择题）：**

> 下面关于三种简单排序算法，说法正确的是（ ）
>
> A. 冒泡排序的时间复杂度是 O(n)
> B. 选择排序每趟最多交换一次
> C. 插入排序在任何情况下都需要 O(n²) 次比较
> D. 三种算法空间复杂度均为 O(n)
>
> **答案：B**
>
> 解析：选择排序每趟只找一次最小值并与首元素交换一次。A 错，应是 O(n²)；C 错，当数组已排好序时，插入排序只需 O(n) 比较；D 错，三种均为 O(1)。

### 4. 进阶扩展

**冒泡排序优化（提前终止）：**

```cpp
for (int i = 1; i <= n - 1; i++) {
    bool swapped = false;               // 记录本趟是否发生交换
    for (int j = 1; j <= n - i; j++) {
        if (a[j] > a[j + 1]) {
            swap(a[j], a[j + 1]);
            swapped = true;
        }
    }
    if (!swapped) break;               // 本趟没发生交换，说明已有序，提前结束
}
```

> 黑板推演：若数组已排好序，第一趟一次都不交换，swapped 仍为 false，直接退出，仅用 O(n) 时间！

**题目描述：**

**输入格式：**

- 从小到大输出 n 个整数，用空格分隔

```

```

```cpp
#include <iostream>
using namespace std;

int a[1005];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    
    for (int i = 1; i <= n - 1; i++) {
        for (int j = 1; j <= n - i; j++) {
            if (a[j] > a[j + 1]) swap(a[j], a[j + 1]);
        }
    }
    for (int i = 1; i <= n; i++) {
        if (i > 1) cout << " ";
        cout << a[i];
    }
```

### 练习 3（综合）：计算排序后的逆序对数

**题目描述：**

给定 n 个整数，先用插入排序将其从小到大排序，统计排序过程中总共进行了多少次交换操作，最后输出排序后的数组和交换次数。

**输入格式：**
- 第一行一个整数 n（1 ≤ n ≤ 1000）
- 第二行 n 个整数

**输出格式：**
- 第一行：排序后的 n 个整数，用空格分隔
- 第二行：交换次数

**样例输入：**
```
5
5 3 8 1 4
```

**样例输出：**
```
1 3 4 5 8
6
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;

int a[1005];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    
    int cnt = 0;
    for (int i = 2; i <= n; i++) {
        for (int j = i; j > 1; j--) {
            if (a[j] < a[j - 1]) {
                swap(a[j], a[j - 1]);
                cnt++;
            } else break;
        }
    }
    for (int i = 1; i <= n; i++) {
        if (i > 1) cout << " ";
        cout << a[i];
    }
    cout << endl;
    cout << cnt << endl;
    return 0;
}
```

### 练习 5（进阶）：成绩排名

**题目描述：**

输入 n 个学生的姓名和成绩，按成绩从高到低输出（成绩相同的按输入顺序排列，即稳定排序）。

**输入格式：**
- 第一行一个整数 n（1 ≤ n ≤ 100）
- 接下来 n 行，每行一个姓名（不含空格）和一个整数成绩

**输出格式：**
- 按成绩从高到低输出每个学生的姓名和成绩

**样例输入：**
```
4
Alice 85
Bob 92
Carol 85
Dave 78
```

**样例输出：**
```
Bob 92
Alice 85
Carol 85
Dave 78
```

**思路分析：**

需要用稳定排序（冒泡或插入），冒泡排序当成绩相等时不交换，保证稳定性。

**题解代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;

string name[105];
int score[105];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> name[i] >> score[i];
    
    // 冒泡排序（降序，稳定）
    for (int i = 1; i <= n - 1; i++) {
        for (int j = 1; j <= n - i; j++) {
            if (score[j] < score[j + 1]) {   // 严格小于才交换，保证稳定性
                swap(score[j], score[j + 1]);
                swap(name[j], name[j + 1]);
            }
        }
    }
    for (int i = 1; i <= n; i++) {
        cout << name[i] << " " << score[i] << endl;
    }
    return 0;
}
```

给定 n 个整数，求其中"逆序对"的数量（i < j 但 a[i] > a[j] 的对数）。

**提示：** 冒泡排序的交换次数就等于逆序对数，统计 swap 的次数即可。

---

#### 挑战 4：最少交换次数排序

给定 1 到 n 的排列（每个数各出现一次），求最少需要多少次交换能使其有序。

**提示：** 分析置换环，每个长度为 k 的环需要 k-1 次交换。

---

#### 挑战 5：鸡尾酒排序（双向冒泡）

普通冒泡只从左到右，每趟只能将最大值移到末尾。鸡尾酒排序每趟先从左到右把最大值移到末尾，再从右到左把最小值移到开头。实现鸡尾酒排序。

**提示：** 用两个指针 left 和 right 控制未排序范围，交替向两端收缩。

---

#### 挑战 6：区间排序

给定数组 a[1..n]，每次操作可以给出 l, r，对 a[l..r] 进行升序排序。读入 m 个操作，输出最终数组。

**提示：** 每次操作在 l 到 r 范围内用任意排序算法排序即可。

---

#### 挑战 7：排序可视化（模拟输出）

实现冒泡排序，每次进行一次 swap 后输出当前数组状态（每行输出一次），最后输出总 swap 次数。

**提示：** 在 swap 之后立刻输出整个数组，用计数器统计 swap 次数。
