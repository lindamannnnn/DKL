# CSP04-02 二维数组

## 一、课程简介（5分钟）

### 🎯 课程目标

1. 理解二维数组的本质——用"行列"下标管理一张"表格"
2. 掌握二维数组的定义、初始化、遍历与访问方式

- 二维数组的定义语法：`类型 数组名[行数][列数]`

- 初始化：整体初始化 `{{...},{...}}` 与默认初始化
- 循环遍历：双重 for 循环（外层遍历行，内层遍历列）
- 多维数组：三维数组的定义与理解
- 内存计算：`sizeof(数组) / sizeof(元素类型)`

### 2. 知识点讲解

#### 2.1 二维数组的定义

**语法格式：**

```cpp
类型 数组名[行数][列数];
```

**举例：**

```cpp
int score[3][3];    // 3行3列，存3个学生的3科成绩
int a[4][5];        // 4行5列，共20个元素
double matrix[10][10];  // 10行10列，浮点数矩阵
```

> 💡 理解：`score[3][3]` 就是申请了 3×3=9 个 int 类型的连续内存空间，并排列成 3 行 3 列的逻辑结构。

---

#### 2.2 下标访问元素

**格式：** `数组名[行下标][列下标]`

- 行下标范围：0 到 行数-1
- 列下标范围：0 到 列数-1

```cpp
int score[3][3];
score[0][0] = 85;   // 第1行第1列（第1个同学的语文）
score[0][1] = 92;   // 第1行第2列（第1个同学的数学）
score[1][2] = 95;   // 第2行第3列（第2个同学的英语）

cout << score[0][0];  // 输出 85
```

> ⚠️ 越界警告：`score[3][0]` 和 `score[0][3]` 都是越界！行下标最大为 2，列下标最大为 2！

**图示（score[3][3]）：**

| | [0] | [1] | [2] |
|--|-----|-----|-----|
| **[0]** | score[0][0] | score[0][1] | score[0][2] |
| **[1]** | score[1][0] | score[1][1] | score[1][2] |
| **[2]** | score[2][0] | score[2][1] | score[2][2] |

---

#### 2.3 二维数组的初始化

**方式一：分行初始化（最直观）**

```cpp
int score[3][3] = {
    {85, 92, 78},   // 第1行：同学1的三科成绩
    {90, 88, 95},   // 第2行：同学2的三科成绩
    {72, 85, 80}    // 第3行：同学3的三科成绩
};
```

**方式二：部分初始化（其余自动为 0）**

```cpp
int a[3][3] = {{1, 2}, {3}};
// a[0][0]=1, a[0][1]=2, a[0][2]=0
// a[1][0]=3, a[1][1]=0, a[1][2]=0
// a[2][0]=0, a[2][1]=0, a[2][2]=0
```

**方式三：全部初始化为 0**

```cpp
int a[100][100] = {0};   // 所有元素都是 0
```

> 💡 技巧：竞赛中常把二维数组定义为**全局变量**，自动初始化为 0，省去初始化麻烦！

---

#### 2.4 循环遍历二维数组

**读入数据（外层行，内层列）：**

```cpp
int n, m;        // n 行 m 列
cin >> n >> m;
for (int i = 1; i <= n; i++) {       // 遍历每一行
    for (int j = 1; j <= m; j++) {   // 遍历该行的每一列
        cin >> a[i][j];
    }
}
```

**输出数据（逐行输出，每行换行）：**

```cpp
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        cout << a[i][j];
        if (j < m) cout << " ";
    }
    cout << endl;    // 每行结束换行
}
```

> 提问：如果我想只遍历第 2 行，代码怎么写？
>
> ```cpp
> for (int j = 1; j <= m; j++) cout << a[2][j] << " ";
> ```
>
> 如果我只想遍历第 3 列呢？
>
> ```cpp
> for (int i = 1; i <= n; i++) cout << a[i][3] << " ";
> ```

---

#### 2.5 多维数组

C++ 也支持三维甚至更高维的数组，但实际中很少用到超过三维。

**三维数组定义：**

```cpp
int a[3][4][5];    // 3层 × 4行 × 5列，共 3×4×5=60 个元素
// 可以想象成一本书：3章，每章4页，每页5个格子
```

**访问：**

```cpp
a[2][1][3] = 100;  // 第3层，第2行，第4列
```

> 实际竞赛中，二维数组用最多（矩阵、棋盘、地图），三维数组偶尔用（dp 状态压缩等）。

---

#### 2.6 内存容量计算

**数组占用内存（字节数）：**

```cpp
int a[3][4];
sizeof(a)              // = 3 × 4 × 4 = 48 字节（int 占 4 字节）
sizeof(a) / sizeof(int)  // = 12，元素个数
```

**计算公式：** 内存大小 = 行数 × 列数 × 单个元素字节数

| 数组定义 | 元素个数 | 内存大小 |
|---------|---------|---------|
| `int a[3][4]` | 12 | 48 字节 |
| `long long b[2][5]` | 10 | 80 字节 |
| `double c[4][4]` | 16 | 128 字节 |
| `char d[10][20]` | 200 | 200 字节 |

---

#### 2.7 二维数组与一维数组的关系

**二维数组可以看作"多个一维数组"：**

```cpp
int a[3][4];
// a[0] 是第一行，由 4 个元素组成的一维数组
// a[1] 是第二行，由 4 个元素组成的一维数组
// a[2] 是第三行，由 4 个元素组成的一维数组
```

**内存中的连续存储（行优先）：**

```
a[0][0] a[0][1] a[0][2] a[0][3] | a[1][0] a[1][1] ... | a[2][0] ...
```

> 二维数组在内存中是**连续排列**的，先存第 0 行的所有元素，再存第 1 行，以此类推。这种存储方式称为**行优先**。

### 3. GESP 真题演练 ⚡

**抢答题 1（选择题）：**

> 定义 `int a[3][4];`，以下访问中，**不越界**的是（ ）
>
> A. `a[3][0]`  B. `a[0][4]`  C. `a[2][3]`  D. `a[-1][0]`
>
> **答案：C**
>
> 解析：行下标 0~2，列下标 0~3。A 中行下标 3 越界；B 中列下标 4 越界；D 负数越界；C 中 a[2][3] 合法。

**判断题 2：**

> 二维数组 `int a[3][4]` 在内存中共占 24 个字节。（ ）
>
> **答案：✗（错误）**
>
> 解析：共 3×4=12 个 int 元素，每个 int 占 4 字节，总共 12×4=48 字节。

**抢答题 3（选择题）：**

> 执行以下代码后，`a[1][1]` 的值是（ ）
>
> ```cpp
> int a[3][3] = {{1, 2}, {3}};
> ```
>
> A. 0  B. 1  C. 2  D. 3
>
> **答案：A**
>
> 解析：`{3}` 只初始化了 a[1][0]=3，a[1][1] 未初始化，自动为 0。

### 4. 进阶扩展

**矩阵转置：**

将 n×n 的方阵沿主对角线翻转（行列互换），是二维数组的经典操作。

```cpp
// 原地转置（只需遍历上三角部分）
for (int i = 1; i <= n; i++) {
    for (int j = i + 1; j <= n; j++) {
        swap(a[i][j], a[j][i]);
    }
}
```

> 黑板推演：
>
> 原矩阵：
> ```
> 1 2 3
> 4 5 6
> 7 8 9
> ```
> 转置后：
> ```
> 1 4 7
> 2 5 8
> 3 6 9
> ```
>
> 规律：`a[i][j]` 和 `a[j][i]` 互换！只需遍历上三角（i < j）部分，避免重复交换。

### 练习 1（基础）：二维数组输入输出

**题目描述：**

输入一个 n 行 m 列的整数矩阵，原样输出。

**输入格式：**
- 第一行两个整数 n 和 m（1 ≤ n, m ≤ 10）
- 接下来 n 行，每行 m 个整数

**输出格式：**
- n 行 m 列的矩阵，同一行用空格分隔

**样例输入：**
```
3 3
1 2 3
4 5 6
7 8 9
```

**样例输出：**
```
1 2 3
4 5 6
7 8 9
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;

int a[15][15];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            cin >> a[i][j];
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (j > 1) cout << " ";
            cout << a[i][j];
        }
        cout << endl;
    }
    return 0;
}
```

**输入格式：**
- 第一行整数 n（1 ≤ n ≤ 10）

- 转置后的 n×n 矩阵

```

```cpp
#include <iostream>

#### 作业 2：对角线元素求和

3

15

```cpp
#include <iostream>

#### 挑战 5：矩阵权重最大路径

在 n×m 的矩阵中，从 [1][1] 出发，每步只能向右或向下走，到达 [n][m]，求路径上所有元素之和的最大值。

**提示：** 动态规划，`dp[i][j] = a[i][j] + max(dp[i-1][j], dp[i][j-1])`。

#### 挑战 6：二维前缀和

预处理二维前缀和数组，快速回答：矩形区域 (r1,c1) 到 (r2,c2) 内所有元素的总和是多少？

**提示：** `prefix[i][j] = prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1] + a[i][j]`。

#### 挑战 7：杨辉三角

用二维数组生成并输出杨辉三角的前 n 行（每个数等于左上和正上的数之和，边界为 1）。

**提示：** `a[i][j] = a[i-1][j-1] + a[i-1][j]`，初始化 `a[i][0] = a[i][i] = 1`。
