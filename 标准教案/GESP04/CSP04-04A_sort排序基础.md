>

### 2. 知识点讲解

#### 2.1 sort 函数的基本结构

**使用前需要引入头文件：**

```cpp
#include <algorithm>
```

**基本语法：**

```cpp
sort(起始地址, 结束地址);          // 升序排序（默认）
sort(起始地址, 结束地址, 比较器);  // 自定义排序
```

> 💡 **重要规则：** sort 的排序范围是**左闭右开**区间 `[起始, 结束)`，即排序到**结束地址的前一个**元素！

**示例（下标从 0 开始）：**

```cpp
int a[105];
int n;
cin >> n;
for (int i = 0; i < n; i++) cin >> a[i];

sort(a, a + n);    // 对 a[0] 到 a[n-1] 升序排序
// 等价于：sort(&a[0], &a[n]);
```

**示例（下标从 1 开始）：**

```cpp
sort(a + 1, a + n + 1);    // 对 a[1] 到 a[n] 升序排序
```

---

#### 2.2 多种数据类型排序

sort 可以对各种数据类型排序：

```cpp
int a[100];
sort(a, a + n);                    // int 数组

double b[100];
sort(b, b + n);                    // double 数组

char c[100];
sort(c, c + n);                    // char 数组（按 ASCII 码）

string s[100];
sort(s, s + n);                    // string 数组（字典序）
sort(s, s + n, greater<string>()); // string 降序
```

**string 内部字符排序：**

```cpp
string t = "dcba";
sort(t.begin(), t.end());    // t 变为 "abcd"
```

> 💡 `t.begin()` 和 `t.end()` 是 string 的迭代器，分别指向首字符和末字符之后的位置。

---

#### 2.3 区间排序

sort 可以只对数组的一部分进行排序，其他部分保持不变：

```cpp
int a[10] = {0, 5, 3, 8, 1, 9, 2, 7, 4, 6};  // 下标0-9
sort(a + 2, a + 6);  // 只对 a[2]..a[5] 排序，即 3 8 1 9 → 1 3 8 9
// 结果：a = {0, 5, 1, 3, 8, 9, 2, 7, 4, 6}
```

> 🔑 竞赛技巧：这在需要部分排序的题目中非常有用，比如"对前 k 个元素排序"。

**区间排序的常见应用：**

```cpp
// 对前 k 个元素排序
sort(a, a + k);

// 对后 k 个元素排序
sort(a + n - k, a + n);

// 对中间某段排序（第 l 个到第 r 个）
sort(a + l, a + r + 1);  // 注意：sort 是左闭右开，所以写 a + r + 1
```

---

#### 2.4 降序排序

**方法一：使用 `greater<类型>()`**

```cpp
sort(a, a + n, greater<int>());      // int 数组降序
sort(a, a + n, greater<double>());   // double 数组降序
sort(s, s + n, greater<string>());   // string 数组降序
```

> ⚠️ 注意：`greater<int>` 后面的 `()` **不能省略**！这是一个函数对象（比较器）。

**方法二：升序排后反向输出（简单粗暴）**

```cpp
sort(a, a + n);
for (int i = n - 1; i >= 0; i--) cout << a[i] << " ";
```

**方法三：自定义 cmp 函数**

```cpp
bool cmp(int a, int b) {
    return a > b;  // 降序：大的在前
}
sort(a, a + n, cmp);
```

---

#### 2.5 经典应用：计算中位数

**中位数定义：** 将数据按大小顺序排列，居于中间位置的数。

- 奇数个：最中间的那个
- 偶数个：中间两个数的平均值

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a[100];
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    sort(a, a + n);  // 先排序

    if (n % 2 == 1) {
        // 奇数个：取中间
        cout << a[n / 2] << endl;
    } else {
        // 偶数个：取中间两个的平均
        cout << (a[n / 2 - 1] + a[n / 2]) / 2.0 << endl;
    }
    return 0;
}
```

---

#### 2.6 经典应用：计算最小差值

**问题：** 求数组中两两之间差值的最小绝对值。

**思路：** 排序后，最小差值一定出现在相邻元素之间。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a[100];
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    sort(a, a + n);  // 先排序

    int ans = a[1] - a[0];  // 初始化为第一个差值
    for (int i = 1; i + 1 < n; i++) {
        if (a[i + 1] - a[i] < ans) {
            ans = a[i + 1] - a[i];
        }
    }
    cout << ans << endl;
    return 0;
}
```

> 💡 为什么排序后只需检查相邻元素？
> 因为排序后，数值接近的元素一定相邻，最小差值不可能出现在不相邻的元素之间。

#### 2.7 奇偶分组排序

**问题：** 将数组分为前半部分奇数、后半部分偶数，两部分各自从小到大排序。

**思路：**
1. 先把所有奇数放到 b 数组前半部分
2. 把所有偶数放到 b 数组后半部分
3. 分别对两部分排序

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a[100], b[100];
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    // 第一步：选出所有奇数
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] % 2 == 1) {
            b[cnt++] = a[i];
        }
    }
    sort(b, b + cnt);  // 奇数部分排序

    // 第二步：选出所有偶数
    int temp = cnt;
    for (int i = 0; i < n; i++) {
        if (a[i] % 2 == 0) {
            b[cnt++] = a[i];
        }
    }
    sort(b + temp, b + n);  // 偶数部分排序

    // 输出
    for (int i = 0; i < n; i++) {
        cout << b[i] << " ";
    }
    return 0;
}
```

#### 2.8 sort 的时间复杂度

| 算法 | 时间复杂度 | 适用规模 |
|------|-----------|---------|
| 冒泡/选择/插入 | O(n²) | n ≤ 5000 |
| C++ sort | O(n log n) | n ≤ 10^7 |

> 执行 `sort(a, a+5)` 后，以下说法正确的是（ ）
>
> A. 对 a[0] 到 a[5] 进行升序排序
> B. 对 a[0] 到 a[4] 进行升序排序
> C. 对 a[1] 到 a[5] 进行升序排序
> D. 对整个数组 a 进行降序排序

> **答案：B**
>
> 解析：sort 的范围是左闭右开，`sort(a, a+5)` 排序 a[0] 到 a[4]（共5个），不包含 a[5]。

**判断题 2：**

> 使用 sort 必须 `#include <iostream>`。（ ）
>
> **答案：✗（错误）**
>
> 解析：sort 在 `<algorithm>` 头文件中，需要 `#include <algorithm>`。

**抢答题 3（选择题）：**

> 以下哪个写法能对 `int a[10]` 中 a[2] 到 a[7] 进行降序排序？
>
> A. `sort(a+2, a+7, greater<int>())`
> B. `sort(a+2, a+8, greater<int>())`
> C. `sort(a+2, a+7)`
> D. `sort(a, a+7, greater<int>())`
>
> **答案：B**
>
> 解析：要排 a[2] 到 a[7]，结束地址是 a[8]（左闭右开），加上降序比较器，所以是 B。

**抢答题 4：**

> 输入 `5 2 6 19 -1 3 2 3 5 7` 共 10 个数，执行以下代码后输出什么？

> sort(a, a + 10);
> cout << a[9] - a[0];
> ```
>
> **答案：20**
>
> 解析：排序后 a[0] 是最小值 -1，a[9] 是最大值 19，差值为 20。

合唱队有 n 人，前 k 人是高声部，后 n-k 人是低声部。将高声部按身高从低到高排列，低声部按身高从高到低排列。

**输入格式：**
- 第一行两个整数 n 和 k（1 ≤ k < n ≤ 100）

**输出格式：**
一行，n 个整数，排序后的身高

```
10 6
180 175 169 178 192 170 179 173 184 178

```

```cpp
#include <iostream>

using namespace std;
int h[105];
int main() {
    int n, k;

    for (int i = 0; i < n; i++) cin >> h[i];
    sort(h, h + k);                          // 高声部升序

    sort(s, s + 5);  // 字符串数组排序
    for (int i = 0; i < 5; i++) cout << s[i] << endl;
    return 0;
}
```

### 🔥 拓展习题（尖子生挑战，7道）

#### 拓展 1：前 K 名的平均数

**题目描述：**
输入 n 个成绩，计算前 K 名（最高分 K 个）的平均成绩，保留两位小数。

**关键提示：**
降序排序后取前 K 个求平均。

---

#### 拓展 2：交叉排序

**题目描述：**
给定 n 个数，先将第 l1 到 r1 从小到大排序，再将第 l2 到 r2 从大到小排序，输出最终数组。

**关键提示：**
注意 sort 的区间是左闭右开，`sort(a + l - 1, a + r)` 表示对第 l 到 r 个元素排序。

---

#### 拓展 3：奇偶排序

**题目描述：**
将数组分成前奇后偶两部分，奇数部分从小到大，偶数部分从大到小。

**关键提示：**
先把奇数和偶数分开到两个数组，分别排序后再合并。

---

#### 拓展 4：第 K 大数

**题目描述：**
求数组中第 K 大的数（注意：不是第 K 个数，而是排序后从大到小第 K 个）。

**关键提示：**
降序排序后取 a[K-1]。

---

#### 拓展 5：去重排序

**题目描述：**
输入 n 个数，去重后按升序输出。

**关键提示：**
排序后遍历，只输出与前一个不同的数。

---

#### 拓展 6：最接近的一对数

**题目描述：**
找出数组中差值最小的一对数，输出这两个数（小的在前）。

**关键提示：**
排序后检查相邻元素，记录最小差值对应的下标。

---

#### 拓展 7：区间最值查询

**题目描述：**
给定数组，多次查询某个区间 [l, r] 的最大值和最小值。

**关键提示：**
每次查询时，可以将区间复制到临时数组排序后取首尾。数据量大时需要更优算法。
