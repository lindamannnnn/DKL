### 2. 知识点讲解

#### （1）sort 区间回顾——左闭右开

首先，我们来回顾一个容易出错的知识点。

> 如果我们希望将数组中第 2 个元素到第 5 个元素这一段进行排序：
>
> ```cpp
> sort(a + 2, a + 5);  // 这样写对吗？
> ```
>
> **答案是：不对！**
>
> `sort` 的区间设定是 **左闭右开** 的：
> ```cpp
> sort(起点, 终点);    // 排序区间 [起点, 终点)
> sort(a + i, a + j);  // 排序 a[i], a[i+1], ..., a[j-1]
> ```
>
> 请注意，**终点位置的元素是不会进入排序的**！
>
> 所以，要对第 2 到第 5 个元素排序（下标 1 到 4），应该写：
> ```cpp
> sort(a + 1, a + 5);  // 排序 a[1], a[2], a[3], a[4]
> ```

#### （2）自定义比较函数 cmp

`sort` 函数的第三个参数可以传入我们自己定义的比较函数。

```cpp
bool cmp(int x, int y) {
    return x > y;  // 当 x > y 时，返回 true，表示 x 应该排在 y 前面
}

int main() {
    int a[100], n;
    // 读入数据...
    sort(a, a + n, cmp);  // 使用自定义 cmp 函数排序
}
```

> **cmp 函数的核心规则：**
>
> - `cmp` 有两个参数，类型与待排序数组元素类型一致
> - 返回值为 `true` 时，表示 **第一个参数应该排在第二个参数前面**
> - 返回值为 `false` 时，表示 **第一个参数不应该排在第二个参数前面**（注意：不代表第二个一定要在第一个前面）
>
> **记忆口诀：** `return true` 意味着"第一个放前面"。

#### （3）降序排序实现

下面是一个完整的降序排序示例：

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

bool cmp(int x, int y) {
    return x > y;  // 大的在前，实现降序
}

int main() {
    int arr[10] = {2, 5, 3, 4, 1, 9, 10, 7, 8, 6};

    // 从小到大排序
    sort(arr, arr + 10);

    // 从大到小排序（使用自定义 cmp）
    sort(arr, arr + 10, cmp);

    for (int i = 0; i < 10; i++) {
        cout << arr[i] << " ";
    }
    return 0;
}
```

#### （4）多关键字排序——奇偶排序 I

**问题：** 将数组分为前偶后奇两部分，每部分内部从小到大排序。

**分析排序规则：**
- 第一关键字：奇偶性（偶数在前，奇数在后）
- 第二关键字：数值大小（小的在前）

```cpp
bool mycmp(int a, int b) {
    if (a % 2 != b % 2) {      // 如果奇偶性不同
        return a % 2 < b % 2;  // 偶数(余0)在前，奇数(余1)在后
    }
    return a < b;              // 奇偶性相同，按值从小到大
}
```

> **关键理解：**
>
> 当 `a % 2 != b % 2` 时，
> - 如果 `a` 是偶数（a % 2 == 0），`b` 是奇数（b % 2 == 1）
> - 那么 `a % 2 < b % 2`（0 < 1）成立，返回 true，a 排在 b 前面 ✓

#### （5）多关键字排序——奇偶排序 II

**问题：** 奇数在前，偶数在后，奇数部分从小到大，偶数部分从大到小。

```cpp
bool mycmp(int a, int b) {
    if (a % 2 != b % 2) {      // 奇偶性不同
        return a % 2 > b % 2;  // 奇数(余1)在前，偶数(余0)在后
    }
    if (a % 2 == 1) {          // 都是奇数
        return a < b;          // 从小到大
    } else {                   // 都是偶数
        return a > b;          // 从大到小
    }
}
```

> **多关键字排序的设计思路：**
>
> 1. 先判断第一关键字是否不同，不同则按第一关键字排序
> 2. 第一关键字相同，再按第二关键字排序
> 3. 以此类推...

#### （6）自定义排序总结

将 `cmp` 理解为：**排序后的数组要满足的条件**。

```cpp
bool cmp(int x, int y) {
    return x > y;
}
```

意思是：对于排序后的数组中任意相邻的两个元素，如果取左边为 x，右边为 y，那么必须满足 `x > y`。

这不就是从大到小排序吗？

再看复杂一点的：

```cpp
bool cmp(int a, int b) {
    if (a % 2 != b % 2) {
        return a % 2 < b % 2;  // 偶数在前，奇数在后
    }
    if (a % 2 == 0) {
        return a > b;          // 偶数从大到小
    } else {
        return a < b;          // 奇数从小到大
    }
}
```

**含义：**
1. 奇偶性不同：偶数在前，奇数在后
2. 都是偶数：从大到小
3. 都是奇数：从小到大

#### （7）Lambda 表达式（现代 C++ 写法）

C++11 之后，可以用 **lambda** 作为比较器，写法更简洁，不需要额外定义 cmp 函数。

```cpp
// 降序排序（lambda 写法）
sort(a, a + n, [](int x, int y) { return x > y; });

// 多关键字排序：先成绩降序，再名字升序
sort(stu, stu + n, [](Student& a, Student& b) {
    if (a.score != b.score) return a.score > b.score;
    return a.name < b.name;
});
```

> **黑板推演：**
>
> ```cpp
> [](int x, int y) { return x > y; }
> ```
>
> 这个 lambda 等价于之前写的独立 cmp 函数：
> ```cpp
> bool cmp(int x, int y) {
>     return x > y;
> }
> ```
>
> 只是把它直接"内联"进了 sort 的参数里，更方便。
>
> **语法格式：**
> ```cpp
> [捕获列表](参数列表) { 函数体 }
> ```
>
> - `[ ]`：捕获列表（简单排序通常留空）
> - `(int x, int y)`：参数列表，和 cmp 函数一样
> - `{ return x > y; }`：函数体，返回比较结果

> **对比示例：**
>
> | 方式 | 代码 |
> |------|------|
> | 传统函数 | `bool cmp(int a, int b){ return a > b; }` + `sort(a, a+n, cmp);` |
> | Lambda | `sort(a, a+n, [](int a, int b){ return a > b; });` |
>
> Lambda 直接在 sort 里写规则，代码更紧凑，适合比较逻辑简单、只用一次的场景。

### 4. 进阶扩展

#### （1）余数排序

将 N 个正整数按除以 3 的余数从小到大排序，余数相同按值排序。

**排序规则：**
- 第一关键字：除以 3 的余数（0 → 1 → 2）
- 第二关键字：数值大小

```cpp
bool cmp(int a, int b) {
    if (a % 3 != b % 3) {
        return a % 3 < b % 3;
    }
    return a < b;
}
```

#### （2）字符串排序

按字符串长度从小到大排序，长度相同按字典序排序。

```cpp
bool cmp(string a, string b) {
    if (a.size() != b.size()) {
        return a.size() < b.size();
    }
    return a < b;  // 字符串可以直接比较字典序
}
```

#### （3）整数数位和排序

按各位数字之和从小到大排序，和相同按数值排序。

```cpp
int bitadd(int a) {
    return a / 1000 + a / 100 % 10 + a / 10 % 10 + a % 10;
}

bool cmp(int a, int b) {
    int c = bitadd(a);
    int d = bitadd(b);
    if (c != d) return c < d;
    return a < b;
}
```

#### （4）排序与贪心——买苹果问题

**问题：** 用 m 元钱买到尽可能多的苹果。

**贪心策略：** 优先买便宜的苹果。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int price[100], n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++) {
        cin >> price[i];
    }
    sort(price, price + n);  // 从小到大排序
    int ans = 0, sum = 0;
    for (int i = 0; i < n; i++) {
        sum += price[i];
        if (sum <= m) {
            ans++;
        } else {
            break;
        }
    }
    cout << ans << endl;
    return 0;
}
```

### 🎈 课堂练习 2：正负分组排序

**题目描述：**
将 N 个整数按如下规则排序：负数在前，正数在后，负数部分从小到大排序，正数部分从大到小排序。保证输入中没有 0。

**输入格式：**
第一行一个整数 N（1 ≤ N ≤ 100）
第二行 N 个整数（-10000 < a[i] < 10000，且 a[i] ≠ 0）

**输出格式：**
一行，排序后的 N 个整数

**样例输入：**
```
6
-1 2 -3 1 -2 3
```

**样例输出：**
```
-3 -2 -1 3 2 1
```

**参考代码：**
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

bool cmp(int a, int b) {
    if ((a < 0) != (b < 0)) {  // 异号
        return a < b;           // 负数 < 正数
    }
    if (a < 0) {               // 都是负数
        return a < b;           // 从小到大
    }
    return a > b;              // 都是正数，从大到小
}

int main() {
    int n, a[105];
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    sort(a, a + n, cmp);
    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    return 0;
}
```

### 🎈 课堂练习 5：整数数位和排序（进阶）

**题目描述：**
将 N 个正整数按照各位数字之和从小到大排序，和相同按数值从小到大排序。

**输入格式：**
第一行一个整数 N（1 ≤ N ≤ 100）
第二行 N 个正整数（均小于 10000）

**输出格式：**
一行，排序后的 N 个整数

**样例输入：**
```
4
20 12 1 11
```

**样例输出：**
```
1 11 20 12
```

**解释：**
- 1：数位和 = 1
- 11：数位和 = 2
- 20：数位和 = 2
- 12：数位和 = 3

**参考代码：**
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int a[105];

int bitadd(int x) {
    int sum = 0;
    while (x > 0) {
        sum += x % 10;
        x /= 10;
    }
    return sum;
}

bool cmp(int a, int b) {
    int sa = bitadd(a);
    int sb = bitadd(b);
    if (sa != sb) {
        return sa < sb;
    }
    return a < b;
}

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    sort(a, a + n, cmp);
    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    return 0;
}
```

#### 课后作业 1：01串排序

**题目描述：**
将 `01` 串首先按长度排序，长度相同时，按 1 的个数多少进行排序，1 的个数相同时再按 ASCII 码值排序（字典序）。

**输入格式：**
第一行一个整数 n（1 ≤ n ≤ 100）
接下来 n 行，每行一个 01 串（长度不超过 256）

**输出格式：**
输出 n 行，排序后的字符串

**样例输入：**
```
6
10011111
00001101
1010101
1
0
1100
```

**样例输出：**
```
0
1
1100
1010101
00001101
10011111
```

**参考代码：**
```cpp
#include <iostream>
#include <algorithm>
#include <string>
using namespace std;

string s[105];

int count1(string a) {
    int cnt = 0;
    for (int i = 0; i < a.size(); i++) {
        if (a[i] == '1') cnt++;
    }
    return cnt;
}

bool cmp(string a, string b) {
    if (a.size() != b.size()) {
        return a.size() < b.size();
    }
    int ca = count1(a);
    int cb = count1(b);
    if (ca != cb) {
        return ca < cb;
    }
    return a < b;
}

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> s[i];
    }
    sort(s, s + n, cmp);
    for (int i = 0; i < n; i++) {
        cout << s[i] << endl;
    }
    return 0;
}
```

#### 课后作业 2：书架

**题目描述：**
巧克力有 N 头奶牛，每头奶牛有自己的高度 Hi。书架高度为 B。奶牛可以叠罗汉，直到总高度不低于书架高度。找出使用奶牛数目最少的方案。

**输入格式：**
第一行：空格隔开的整数 N 和 B
第 2 ~ N+1 行：每行一个整数 Hi

**输出格式：**
能达到书架高度所使用奶牛的最少数目

**样例输入：**
```
6 40
6
18
11
13
19
11
```

**样例输出：**
```
3
```

**参考代码：**
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int a[20010];

int main() {
    int n, b;
    cin >> n >> b;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    sort(a, a + n);  // 从小到大排序
    int ans = 0;
    // 从最高的奶牛开始选（贪心）
    for (int i = n - 1; i >= 0 && b > 0; i--) {
        b -= a[i];
        ans++;
    }
    cout << ans << endl;
    return 0;
}
```
