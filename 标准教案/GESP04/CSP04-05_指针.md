## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> 想象内存就像一排格子（就像酒店的房间号），每个格子有一个**地址编号**，存放着一个值。
>
> ```
> 内存地址：  1000  1004  1008  1012  ...
> 变量：       a=5   b=8   c=3   ...
> ```
>
> 当我们写 `int a = 5;` 时，系统在内存某处（假设地址 1000）存放了值 5，用变量名 `a` 来引用它。
>
> **普通变量：** 用名字找到值（`a` → 5）
>
> **指针：** 存储的是地址，通过地址再找到值（`p` → 1000 → 5）
>
> 类比：普通变量像"直接告诉你答案"，指针像"告诉你去第1000号房间找答案"！

### 2. 知识点讲解

#### 2.1 取地址运算符 `&`

`&变量名` 可以获取该变量在内存中的地址：

```cpp
int a = 5;
cout << a;    // 输出值：5
cout << &a;   // 输出地址：类似 0x61fe0c（十六进制内存地址）
```

> 💡 `&` 在这里是"取地址"的意思，和之前学的引用传递中的 `&` 不同（要看上下文）！

---

#### 2.2 指针的定义与赋值

**指针类型语法：** `类型* 指针名;`

```cpp
int a = 5;
int* p;       // 定义一个指向 int 类型的指针 p
p = &a;       // 让 p 存储变量 a 的地址

// 或者合并成一行：
int* p = &a;
```

> ⚠️ 注意：`int* p` 和 `int *p` 效果完全相同，只是星号位置不同，都合法。
>
> 但 `int* p, q;` 中只有 p 是指针，q 是普通 int！若要两个都是指针要写 `int *p, *q;`

**各类型指针：**

```cpp
double d = 3.14;
char c = 'A';

double* pd = &d;   // 指向 double 的指针
char* pc = &c;     // 指向 char 的指针
```

> 🔑 规则：指针类型必须和所指变量类型一致！不能把 `int*` 指针指向 `double` 变量（不严格模式下会有警告）。

---

#### 2.3 解引用运算符 `*`

通过指针访问或修改它指向的值，用 `*指针名`：

```cpp
int a = 5;
int* p = &a;

cout << *p;     // 解引用：输出 p 指向的值，即 5
*p = 10;        // 通过指针修改值：a 变为 10
cout << a;      // 输出 10
```

> 💡 `*p` 读作"p 所指向的值"，它和 `a` 完全等价——修改 `*p` 就是修改 `a`！

**指针操作图示：**

```
a:  [  5  ]   地址：1000
p:  [ 1000 ]  地址：2000   (* 解引用后得到 5)
```

---

#### 2.4 指针运算与地址偏移

指针可以做加减法，**移动**到相邻的内存地址：

```cpp
int a[5] = {10, 20, 30, 40, 50};
int* p = &a[0];    // p 指向 a[0]

cout << *p;        // 10（a[0]）
cout << *(p + 1);  // 20（a[1]）
cout << *(p + 2);  // 30（a[2]）

p++;               // p 移动到 a[1]
cout << *p;        // 20
```

> 🔑 `p + n` 不是地址加 n，而是地址加 `n × sizeof(类型)` 字节！
>
> 对于 `int*`，`p + 1` 相当于地址 + 4（int 占 4 字节）。

**指针差：**

```cpp
int* p1 = &a[0];
int* p2 = &a[3];
cout << p2 - p1;   // 输出 3（相差 3 个 int 的距离）
```

---

#### 2.5 指针与数组的关系

**数组名就是首元素的地址！**

```cpp
int a[5] = {10, 20, 30, 40, 50};

// 以下写法完全等价：
a[2]        ↔   *(a + 2)
&a[2]       ↔   a + 2
```

**示例：**

```cpp
int a[5] = {10, 20, 30, 40, 50};
cout << a;       // a 数组的首地址（等价于 &a[0]）
cout << a + 1;   // a[1] 的地址
cout << *(a+3);  // 40（等价于 a[3]）
```

> 这就解释了为什么 `sort(a+1, a+n+1)` 中 `a+1` 是 `a[1]` 的地址，`a+n+1` 是 `a[n]` 后面那个元素的地址！

---

#### 2.6 空指针

```cpp
int* p = nullptr;   // 空指针，不指向任何变量
// C 风格：int* p = NULL;
```

> ⚠️ 对空指针解引用（`*p`）会导致程序崩溃（段错误）！使用指针前一定要确保它不为 nullptr。

### 4. 进阶扩展

**用指针遍历数组（另一种写法）：**

```cpp
int a[5] = {1, 2, 3, 4, 5};
// 传统下标写法
for (int i = 0; i < 5; i++) cout << a[i] << " ";
// 指针写法
for (int* p = a; p < a + 5; p++) cout << *p << " ";
```

> 黑板推演：
>
> - 初始 p 指向 a[0]（地址 1000）
> - 每次 `p++`，p 跳到下一个 int，即 +4 字节
> - 当 p 到达 a+5（地址 1020）时循环结束
>
> 这种写法在某些场景下效率略高，也是理解 sort 参数的基础！

**二维数组的指针（了解即可）：**

```cpp
int a[3][4];
int* p = &a[0][0];  // 指向二维数组首元素
// a[i][j] 等价于 *(p + i * 4 + j)
```

### 练习 1（基础）：指针读写变量

**题目描述：**

定义两个整数变量 a, b，通过指针 pa, pb 分别指向它们，然后交换 a 和 b 的值（通过指针操作），输出交换后的结果。

**输入格式：** 一行两个整数 a 和 b

**输出格式：** 交换后的 a 和 b，空格分隔

**样例输入：**
```
5 8
```

**样例输出：**
```
8 5
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;
    int* pa = &a;
    int* pb = &b;
    // 通过指针交换
    int tmp = *pa;
    *pa = *pb;
    *pb = tmp;
    cout << a << " " << b << endl;
    return 0;
}
```

### 练习 2（基础）：用指针遍历数组

**题目描述：**

输入 n 个整数到数组，用指针方式（`int* p = a; while(p < a+n)`）遍历并输出其总和。

**输入格式：**
- 第一行 n，第二行 n 个整数

**输出格式：** 总和

**样例输入：**
```
5
1 2 3 4 5
```

**样例输出：**
```
15
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int a[105];
int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];
    long long sum = 0;
    for (int* p = a; p < a + n; p++) sum += *p;
    cout << sum << endl;
    return 0;
}
```

### 练习 3（综合）：最大值位置

**题目描述：**

输入 n 个整数，用指针找到最大值并输出其值和下标（从 1 开始）。

**输入格式：** 第一行 n，第二行 n 个整数（1 ≤ n ≤ 100）

**输出格式：** 最大值和其下标，空格分隔

**样例输入：**
```
5
3 7 1 9 4
```

**样例输出：**
```
9 4
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int a[105];
int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];
    int* maxPtr = a;
    for (int* p = a + 1; p < a + n; p++) {
        if (*p > *maxPtr) maxPtr = p;
    }
    cout << *maxPtr << " " << (maxPtr - a + 1) << endl;
    return 0;
}
```

### 练习 4（综合）：指针区间反转

**题目描述：**

输入 n 个整数和两个区间端点 l, r，将数组 a[l..r] 的元素用指针方式反转（两端指针向中间靠拢，交换元素），输出反转后的完整数组。

**输入格式：**
- 第一行 n, l, r（1 ≤ l ≤ r ≤ n ≤ 100）
- 第二行 n 个整数

**输出格式：** 反转后的数组，空格分隔

**样例输入：**
```
6 2 5
1 2 3 4 5 6
```

**样例输出：**
```
1 5 4 3 2 6
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int a[105];
int main() {
    int n, l, r;
    cin >> n >> l >> r;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int* left = a + l;
    int* right = a + r;
    while (left < right) {
        int tmp = *left;
        *left = *right;
        *right = tmp;
        left++;
        right--;
    }
    for (int i = 1; i <= n; i++) {
        if (i > 1) cout << " ";
        cout << a[i];
    }
    cout << endl;
    return 0;
}
```

### 练习 5（进阶）：指针统计奇偶

**题目描述：**

输入 n 个整数，用指针遍历，统计奇数和偶数的个数，并分别计算它们的总和。

**输入格式：** 第一行 n，第二行 n 个整数

**输出格式：**
- 第一行：奇数个数 奇数之和
- 第二行：偶数个数 偶数之和

**样例输入：**
```
6
1 2 3 4 5 6
```

**样例输出：**
```
3 9
3 12
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int a[105];
int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];
    int oddCnt = 0, evenCnt = 0;
    long long oddSum = 0, evenSum = 0;
    for (int* p = a; p < a + n; p++) {
        if (*p % 2 != 0) { oddCnt++; oddSum += *p; }
        else { evenCnt++; evenSum += *p; }
    }
    cout << oddCnt << " " << oddSum << endl;
    cout << evenCnt << " " << evenSum << endl;
    return 0;
}
```

#include <iostream>

    return 0;
}
