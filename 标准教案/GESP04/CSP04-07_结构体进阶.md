# CSP04-07 结构体进阶

## 一、课程简介（5分钟）

### 🎯 课程目标

1. 掌握结构体指针的定义与 `->` 运算符的使用
2. 理解结构体嵌套（结构体内包含另一个结构体）的定义与访问
3. 掌握将结构体作为函数参数的三种方式及其区别
4. 理解 `const` 在结构体函数参数中的使用场景

### 📚 核心知识点

- 结构体指针：`Student* p = &stu;`
- 箭头运算符：`p->成员名`（等价于 `(*p).成员名`）
- 结构体嵌套：结构体成员可以是另一个结构体类型
- 结构体做函数参数（值传递、引用传递、指针传递）
- `const` 引用参数：`const Student& s`（只读，不可修改）

## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> 上节课我们用 `.` 访问结构体成员：`stu.name`。
>
> 但当我们使用的是**结构体指针**时（*p 是一个结构体），怎么访问成员？
>
> 方法一：`(*p).name`（先解引用，再用 `.`）——括号必须写，因为 `.` 优先级高
>
> 方法二：`p->name`（箭头运算符，更简洁直观）
>
> 这就像快递：`.` 是直接拿货，`->` 是先找到地址再拿货！

---

### 2. 知识点讲解

#### 2.1 结构体指针与 `->` 运算符

**定义结构体指针：**

```cpp
Student stu = {1001, "小明", 95};
Student* p = &stu;   // p 是指向 Student 的指针
```

**访问成员（两种等价方式）：**

```cpp
cout << (*p).name;   // 先解引用，再访问成员（括号必须写！）
cout << p->name;     // 箭头运算符，等价且更简洁
```

**修改成员：**

```cpp
p->score = 100;      // 通过指针修改 stu.score
cout << stu.score;   // 输出 100
```

**示例代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Student {
    int id;
    string name;
    int score;
};

int main() {
    Student stu = {1001, "小明", 95};
    Student* p = &stu;
    
    cout << p->id << " " << p->name << " " << p->score << endl;
    p->score = 100;
    cout << "修改后：" << stu.score << endl;  // 100
    return 0;
}
```

> 🔑 总结：`p->x` 等价于 `(*p).x`，箭头运算符更常用、更易读。

---

#### 2.2 结构体嵌套

结构体的成员可以是另一个结构体类型：

**定义嵌套结构体：**

```cpp
struct Address {
    string province;  // 省份
    string city;      // 城市
};

struct Student {
    int id;
    string name;
    Address addr;     // 嵌套 Address 结构体
};
```

**访问嵌套成员（用两次 `.`）：**

```cpp
Student stu;
stu.id = 1001;
stu.name = "小明";
stu.addr.province = "广东";
stu.addr.city = "广州";

cout << stu.addr.city;   // 输出：广州
```

**初始化嵌套结构体：**

```cpp
Address addr = {"广东", "广州"};
Student stu = {1001, "小明", addr};
// 或直接：
Student stu2 = {1001, "小明", {"广东", "广州"}};
```

---

#### 2.3 结构体作为函数参数

**方式一：值传递（复制一份，修改不影响原变量）**

```cpp
void printStudent(Student s) {      // 传入的是副本
    cout << s.name << " " << s.score << endl;
    s.score = 0;                    // 修改副本，原变量不变
}
```

> ⚠️ 缺点：结构体较大时，复制开销大！

**方式二：引用传递（不复制，直接操作原变量）**

```cpp
void addScore(Student& s, int delta) {    // 传入的是引用
    s.score += delta;                      // 直接修改原变量
}

addScore(stu, 5);  // stu.score 增加 5
```

**方式三：指针传递（传地址，通过 `->` 访问）**

```cpp
void addScore2(Student* p, int delta) {
    p->score += delta;
}

addScore2(&stu, 5);  // 传入 stu 的地址
```

---

#### 2.4 `const` 在函数参数中的使用

当函数**只读**结构体（不修改），应该用 `const` 引用，既避免拷贝开销，又保护数据不被修改：

```cpp
// const 引用：不复制，又保证只读
void printStudent(const Student& s) {
    cout << s.name << " " << s.score << endl;
    // s.score = 0;   // 错误！const 引用不能修改成员
}
```

> 🔑 最佳实践：
> - 只读 → `const Student& s`（高效且安全）
> - 需要修改 → `Student& s`（引用传递）
> - 不关心效率 → `Student s`（值传递，最简单）

**在 sort 的 cmp 函数中推荐写法：**

```cpp
bool cmp(const Student& a, const Student& b) {
    return a.score > b.score;
}
```

### 3. GESP 真题演练 ⚡

**抢答题 1（选择题）：**

> 设 `Student* p = &stu;`，以下访问 score 成员正确的是（ ）
>
> A. `p.score`   B. `*p.score`   C. `(*p).score`   D. `p*score`
>
> **答案：C**（`p->score` 也正确，但不在选项中）
>
> 解析：p 是指针，不能用 `.`，需要先解引用 `*p`，再用 `.` 访问成员，即 `(*p).score`。注意括号不可省。

**判断题 2：**

> `p->name` 和 `(*p).name` 完全等价。（ ）
>
> **答案：✓（正确）**
>
> 解析：`->` 运算符就是"先解引用，再点运算"的简写，两种写法完全等价。

**抢答题 3（选择题）：**

> 以下函数参数声明中，既能避免拷贝开销，又能保证函数内不修改原变量的是（ ）
>
> A. `void f(Student s)`
> B. `void f(Student& s)`
> C. `void f(const Student& s)`
> D. `void f(Student* s)`
>
> **答案：C**
>
> 解析：A 是值传递，有拷贝开销；B 是引用传递，可修改原变量；C 是 const 引用，无拷贝+只读；D 是指针传递，可通过 `->` 修改原变量。

### 4. 进阶扩展

**结构体数组与指针结合：**

```cpp
Student stu[5];
Student* p = stu + 1;    // 指向 stu[1]

cout << p->name;         // stu[1].name
p++;                     // 移动到 stu[2]
cout << p->score;        // stu[2].score
```

> 黑板推演：结构体数组在内存中也是连续存储的，每个元素大小为 `sizeof(Student)`。
>
> `p + 1` = 地址 + `sizeof(Student)` 字节，这样就移动到了下一个结构体元素。

**const 指针参数：**

```cpp
void print(const Student* p) {
    cout << p->name << " " << p->score << endl;
    // p->score = 0;  // 错误！const 指针不能修改所指向的值
}

print(&stu);   // 传入地址
```

```cpp
    cout << p->x << " " << p->y << endl;
    p->x += 10; p->y += 10;
    cout << p->x << " " << p->y << endl;
    return 0;
}
```

### 练习 3（综合）：用引用传参修改结构体

**题目描述：**

定义 Student 结构体，编写两个函数：`addBonus(Student& s, int b)` 给成绩加奖励分，`printInfo(const Student& s)` 输出信息。输入 n 个学生，每个学生加 5 分奖励后输出。

**输入格式：** n，然后 n 行姓名和成绩

**输出格式：** n 行姓名和加奖励后的成绩

**样例输入：** `3\nAlice 85\nBob 90\nCarol 78`  **样例输出：** `Alice 90\nBob 95\nCarol 83`

**题解代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;
struct Student { string name; int score; };
void addBonus(Student& s, int b) { s.score += b; }
void printInfo(const Student& s) { cout << s.name << " " << s.score << endl; }
Student stu[105];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> stu[i].name >> stu[i].score;
    for (int i = 1; i <= n; i++) addBonus(stu[i], 5);
    for (int i = 1; i <= n; i++) printInfo(stu[i]);
    return 0;
}
```

### 练习 4（综合）：通过指针传参排序

**题目描述：**

编写函数 `swap_student(Student* a, Student* b)` 通过指针交换两个学生结构体，然后对 n 个学生用冒泡排序（调用该函数）按成绩升序排列后输出。

**样例输入：** `3\nAlice 85\nBob 92\nCarol 78`  **样例输出（升序）：** `Carol 78\nAlice 85\nBob 92`

**题解代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;
struct Student { string name; int score; } stu[105];
void swapStudent(Student* a, Student* b) {
    Student tmp = *a; *a = *b; *b = tmp;
}
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> stu[i].name >> stu[i].score;
    for (int i = 1; i < n; i++)
        for (int j = 1; j <= n - i; j++)
            if (stu[j].score > stu[j+1].score)
                swapStudent(&stu[j], &stu[j+1]);
    for (int i = 1; i <= n; i++) cout << stu[i].name << " " << stu[i].score << endl;
}
```

### 练习 5（进阶）：嵌套结构体多关键字排序

**题目描述：**

每个学生有姓名、所在城市和成绩，先按城市名字典序升序，城市相同按成绩降序排列，输出排序结果。

**样例输入：** `4\nAlice Shanghai 85\nBob Beijing 92\nCarol Shanghai 90\nDave Beijing 88`

**样例输出：** `Bob Beijing 92\nDave Beijing 88\nCarol Shanghai 90\nAlice Shanghai 85`

**题解代码：**

```cpp
#include <iostream>
#include <algorithm>
#include <string>
using namespace std;
struct Student { string name, city; int score; } stu[105];
bool cmp(const Student& a, const Student& b) {
    if (a.city != b.city) return a.city < b.city;
    return a.score > b.score;
}
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> stu[i].name >> stu[i].city >> stu[i].score;
    sort(stu + 1, stu + n + 1, cmp);
    for (int i = 1; i <= n; i++)
        cout << stu[i].name << " " << stu[i].city << " " << stu[i].score << endl;
}
```

## 五、课堂总结（5分钟）🌟

> 结构体进阶三大技能：
>
> 1. **结构体指针**：`Student* p = &stu;` → 用 `p->成员` 访问（等价于 `(*p).成员`）
>
> 2. **结构体嵌套**：`stu.addr.city`——用两个 `.` 分两层访问
>
> 3. **函数参数三种方式：**
>    - `Student s`：值传递，有拷贝，修改不影响原变量
>    - `Student& s`：引用传递，无拷贝，修改影响原变量
>    - `const Student& s`：只读引用，推荐用于只需读取的函数
>
> 下节课我们学习自定义函数进阶，默认参数和多种传参方式！💡
