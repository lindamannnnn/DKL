## 一、课程简介（5分钟）

### 🎯 课程目标

1. 掌握函数默认参数的定义与使用规则
2. 深入理解三种参数传递方式（值传递、指针传递、引用传递）的本质区别

### 📚 核心知识点

- 默认参数：`void f(int a, int b = 0)` 定义规则与调用方式
- 值传递：复制一份，函数内修改不影响外部变量
- 指针传递：传地址，函数内通过 `*` 解引用修改原变量
- 引用传递：别名，函数内修改直接影响原变量
- const 引用：`const int& x`，只读，提高效率
- 函数在题目中的实际应用（封装算法逻辑）

### 2. 知识点讲解

#### 2.1 函数默认参数

函数参数可以有**默认值**，调用时可以省略：

```cpp
// 定义：有默认值的参数必须放在最後面
int add(int a, int b = 10, int c = 0) {
    return a + b + c;
}

// 调用：
add(5);          // a=5, b=10, c=0   → 15
add(5, 3);       // a=5, b=3,  c=0   → 8
add(5, 3, 2);    // a=5, b=3,  c=2   → 10
```

> ⚠️ 规则：默认参数必须从右向左连续设置！不能跳过——如果 b 有默认值但 c 没有，则不合法。

**常见用法：输出分隔符（默认空格，可指定换行）**

```cpp
void printArr(int* a, int n, char sep = ' ') {
    for (int i = 0; i < n; i++) {
        cout << a[i];
        if (i < n - 1) cout << sep;
    }
    cout << endl;
}

printArr(a, n);        // 空格分隔（默认）
printArr(a, n, '\n');  // 换行分隔
```

#### 2.2 三种参数传递方式对比

**值传递（最常见，最安全）：**

```cpp
void doubleVal(int x) {
    x = x * 2;    // 修改的是副本
}

int a = 5;
doubleVal(a);
cout << a;    // 仍然是 5，原变量未变
```

**引用传递（修改原变量，无拷贝开销）：**

```cpp
void doubleRef(int& x) {
    x = x * 2;    // 直接修改原变量
}

int a = 5;
doubleRef(a);
cout << a;    // 10，原变量被修改
```

**指针传递（传地址，效果同引用）：**

```cpp
void doublePtr(int* x) {
    *x = (*x) * 2;    // 通过地址修改原变量
}

int a = 5;
doublePtr(&a);     // 传入地址
cout << a;         // 10
```

**三种方式对比表：**

| 方式 | 语法 | 是否复制 | 能否修改原变量 | 典型用法 |
|------|------|---------|-------------|---------|
| 值传递 | `f(int x)` | ✅ 复制 | ❌ 不能 | 只读小数据 |
| 引用传递 | `f(int& x)` | ❌ 不复制 | ✅ 能 | 需要修改原变量 |
| 指针传递 | `f(int* x)` | ❌ 不复制 | ✅ 能（通过 `*`） | 传数组，历史遗留 |
| const 引用 | `f(const int& x)` | ❌ 不复制 | ❌ 不能 | 只读大数据（结构体等） |

#### 2.3 经典应用：swap 函数

**值传递版（错误！交换不了）：**

```cpp
void swapWrong(int a, int b) {
    int t = a; a = b; b = t;   // 只交换了副本
}
```

**引用传递版（正确）：**

```cpp
void mySwap(int& a, int& b) {
    int t = a; a = b; b = t;   // 交换原变量
}
mySwap(x, y);    // x 和 y 被真正交换
```

**指针传递版（正确，C 风格）：**

```cpp
void mySwapPtr(int* a, int* b) {
    int t = *a; *a = *b; *b = t;
}
mySwapPtr(&x, &y);    // 传地址
```

#### 2.4 函数在竞赛题目中的应用

**封装常用操作（代码复用）：**

```cpp
// 封装：判断一个数是否是素数
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}

// 在主程序中多次调用
for (int i = 2; i <= 100; i++)
    if (isPrime(i)) cout << i << " ";
```

**封装：快速幂**

```cpp
long long power(long long base, long long exp, long long mod) {
    long long result = 1;
    while (exp > 0) {
        if (exp % 2 == 1) result = result * base % mod;
        base = base * base % mod;
        exp /= 2;
    }
    return result;
}
```

### 3. GESP 真题演练 ⚡

**抢答题 1（选择题）：**

> 函数定义 `void f(int a, int b=5, int c)` 的问题是（ ）
>
> A. 函数名不合法
> B. 默认参数必须从右到左连续，c 没有默认值不能放在 b 后面
> C. 参数个数太多
> D. 返回值类型错误
>
> **答案：B**
>
> 解析：默认参数必须从右到左连续——如果 b 有默认值，那 b 右边的所有参数（c）也必须有默认值，否则调用时二义性。

**判断题 2：**

> 引用传递和值传递的区别在于：引用传递函数内的修改会影响原变量，值传递不会。（ ）
>
> **答案：✓（正确）**
>
> 解析：引用 `int& x` 是原变量的别名，任何对 x 的修改等同于修改原变量；值传递 `int x` 是副本，修改副本不影响原变量。

**抢答题 3（选择题）：**

> 以下哪种参数类型最适合"只需读取一个很大的结构体，不需要修改它"的场景？
>
> A. `Student s`（值传递）
> B. `Student& s`（引用传递）
> C. `const Student& s`（const 引用）
> D. `Student* s`（指针传递）
>
> **答案：C**
>
> 解析：A 有拷贝开销（结构体大则代价高）；B 可修改原变量（不符合"只读"需求）；C 无拷贝开销且只读，最合适；D 也无拷贝但需要传地址，语义不如 C 直观。

### 4. 进阶扩展

**函数重载（Overloading）：**

同名函数因参数类型或数量不同而共存：

```cpp
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
int add(int a, int b, int c) { return a + b + c; }

add(1, 2);        // 调用 int 版本
add(1.5, 2.5);    // 调用 double 版本
add(1, 2, 3);     // 调用三参数版本
```

> 黑板推演：编译器根据参数的**类型和数量**自动选择合适的重载版本，这叫**静态多态**。

**题目描述：**

编写函数 `void printLine(int n, char c = '*')` 输出 n 个字符 c，调用两次：一次用默认字符，一次用 `#`。

**输入格式：** 一个整数 n

**输出格式：** 两行，第一行 n 个 `*`，第二行 n 个 `#`

**样例输入：** `5`  **样例输出：** `*****\n#####`

**题解代码：**

```cpp
#include <iostream>
using namespace std;
void printLine(int n, char c = '*') {
    for (int i = 0; i < n; i++) cout << c;
    cout << endl;
}
int main() {
    int n; cin >> n;
    printLine(n);
    printLine(n, '#');
    return 0;
}
```

### 练习 2（基础）：引用传参

**题目描述：**

编写函数 `void addToAll(int* a, int n, int delta)` 将数组每个元素加上 delta，main 中调用后输出。

**输入格式：** n delta，然后 n 个整数

**输出格式：** n 个增加后的整数

**样例输入：** `4 3\n1 2 3 4`  **样例输出：** `4 5 6 7`

**题解代码：**

```cpp
#include <iostream>
using namespace std;
void addToAll(int* a, int n, int delta) {
    for (int i = 0; i < n; i++) a[i] += delta;
}
int a[105];
int main() {
    int n, delta; cin >> n >> delta;
    for (int i = 0; i < n; i++) cin >> a[i];
    addToAll(a, n, delta);
    for (int i = 0; i < n; i++) {
        if (i) cout << " ";
        cout << a[i];
    }
    return 0;
}
```

### 练习 3（综合）：用引用传参返回多个值

**题目描述：**

编写函数 `void findMinMax(int* a, int n, int& minVal, int& maxVal)` 同时返回数组的最小值和最大值（通过引用参数）。

**输入格式：** n，然后 n 个整数

**输出格式：** 最小值 最大值

**样例输入：** `5\n3 1 4 1 5`  **样例输出：** `1 5`

**题解代码：**

```cpp
#include <iostream>
using namespace std;
void findMinMax(int* a, int n, int& minVal, int& maxVal) {
    minVal = maxVal = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] < minVal) minVal = a[i];
        if (a[i] > maxVal) maxVal = a[i];
    }
}
int a[105];
int main() {
    int n; cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];
    int mn, mx;
    findMinMax(a, n, mn, mx);
    cout << mn << " " << mx << endl;
    return 0;
}
```

### 练习 4（综合）：函数封装：统计素数

**题目描述：**

编写函数 `bool isPrime(int n)` 判断 n 是否为素数，用它统计 [2, m] 中素数的个数并输出所有素数。

**输入格式：** 整数 m（2 ≤ m ≤ 1000）

**输出格式：** 第一行所有素数，第二行素数个数

**样例输入：** `20`  **样例输出：** `2 3 5 7 11 13 17 19\n8`

**题解代码：**

```cpp
#include <iostream>
using namespace std;
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}
int main() {
    int m; cin >> m;
    int cnt = 0;
    for (int i = 2; i <= m; i++) {
        if (isPrime(i)) {
            if (cnt > 0) cout << " ";
            cout << i;
            cnt++;
        }
    }
    cout << endl << cnt << endl;
    return 0;
}
```
