## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> **楼梯问题引入：**
>
> 一个台阶有 n 级，你每次可以走 1 步或 2 步，问走到第 n 级共有多少种走法？
>
> 分析：
> - 走到第 1 级：1 种（只能走 1 步）
> - 走到第 2 级：2 种（1+1 或 2）
> - 走到第 3 级：3 种（1+1+1，1+2，2+1）
> - 走到第 4 级：5 种（= 第3级的走法 + 第2级的走法）
>
> 规律：走到第 n 级 = 走到第 n-1 级的走法 + 走到第 n-2 级的走法！
>
> 因为：最后一步要么从 n-1 级走 1 步上来，要么从 n-2 级走 2 步上来。
>
> 这就是斐波那契数列！**找到递推关系，就找到了解题钥匙！**

### 2. 知识点讲解

#### 2.1 递推算法基本思想

**定义：** 递推（Recurrence）= 用前面的计算结果推导后面的结果。

**三要素：**
1. **边界条件（初始值）**：最小规模问题的答案（如 `f[1] = 1`）
2. **递推关系式**：`f[n]` 如何由之前的 `f[...]` 表示
3. **递推方向**：从小到大（正向递推）或从大到小（反向递推）

**代码框架：**

```cpp
// 第一步：初始化边界值
f[1] = ...;
f[2] = ...;

// 第二步：用循环递推
for (int i = 3; i <= n; i++) {
    f[i] = f[i-1] + f[i-2];  // 递推关系式
}

// 第三步：输出答案
cout << f[n];
```

---

#### 2.2 经典问题一：斐波那契数列

**数列：** 1, 1, 2, 3, 5, 8, 13, 21, 34, ...

**递推关系：** `f[n] = f[n-1] + f[n-2]`（n ≥ 3）

**边界：** `f[1] = 1, f[2] = 1`

```cpp
#include <iostream>
using namespace std;

long long f[50];

int main() {
    int n;
    cin >> n;
    f[1] = 1; f[2] = 1;
    for (int i = 3; i <= n; i++)
        f[i] = f[i-1] + f[i-2];
    cout << f[n] << endl;
    return 0;
}
```

> 注意：斐波那契数增长很快，f[50] 就超过了 int 范围，要用 `long long`！

---

#### 2.3 经典问题二：楼梯走法

**题目：** n 级台阶，每次走 1 步或 2 步，共几种走法？

**递推分析：**

> 到达第 n 级的最后一步，只有两种情况：
> - 从第 n-1 级走 1 步上来
> - 从第 n-2 级走 2 步上来
>
> 因此：`ways[n] = ways[n-1] + ways[n-2]`
>
> 边界值：`ways[1] = 1`（只有一种：走1步），`ways[2] = 2`（两种：1+1 或 2）

```cpp
long long ways[55];
int n;
cin >> n;
ways[1] = 1; ways[2] = 2;
for (int i = 3; i <= n; i++)
    ways[i] = ways[i-1] + ways[i-2];
cout << ways[n];
```

---

#### 2.4 经典问题三：数字三角形（递推推导）

**问题：** 已知数字三角形每个数等于它正上方和左上方的数之和（边界为1），这就是杨辉三角。

```
第1行：1
第2行：1 1
第3行：1 2 1
第4行：1 3 3 1
第5行：1 4 6 4 1
```

**递推关系：** `C[i][j] = C[i-1][j-1] + C[i-1][j]`

**边界：** `C[i][0] = C[i][i] = 1`（左右边界都是 1）

```cpp
long long C[25][25];
int n;
cin >> n;
for (int i = 0; i <= n; i++) {
    C[i][0] = C[i][i] = 1;
    for (int j = 1; j < i; j++)
        C[i][j] = C[i-1][j-1] + C[i-1][j];
}
```

---

#### 2.5 推导递推关系式的方法

> **步骤：**
>
> 1. **列出小规模答案**：手工算 n=1, 2, 3, 4, 5 的答案
> 2. **找差值或比值规律**：差值是否有规律？是否等于前几项之和？
> 3. **用语言描述规律**："第 n 项 = 第 n-1 项 + 第 n-2 项"
> 4. **写成代码**：翻译成 `f[n] = f[n-1] + f[n-2]`

**例题推导：** 在 n 个圆中互相交叉，最多能分成多少个区域？

| n（圆数） | 1 | 2 | 3 | 4 |
|-----------|---|---|---|---|
| 区域数    | 2 | 4 | 8 | 14 |

差值：2, 4, 6, ... → 差值是 2n！

所以：`f[n] = f[n-1] + 2*(n-1)`，边界 `f[1] = 2`。

### 4. 进阶扩展

**递推 vs 递归：**

| | 递推 | 递归 |
|--|------|------|
| 方式 | 循环从小到大 | 函数自我调用 |
| 效率 | 高（无重复计算） | 低（重复计算子问题） |
| 空间 | O(n) 存储所有结果 | O(n) 调用栈 |
| 复杂度 | 通常更好 | 可能指数级 |

> 计算 fib(40) 时：循环只需 40 次，递归需要约 2^40 次！

**记忆化递归（Memoization）：**

```cpp
long long memo[55] = {0};  // 初始化为0表示未计算
long long fib(int n) {
    if (n <= 2) return 1;
    if (memo[n]) return memo[n];   // 已算过直接返回
    memo[n] = fib(n-1) + fib(n-2);
    return memo[n];
}
```

> 黑板推演：记忆化递归 = 递归的写法 + 递推的效率，两全其美！

### 练习 4（综合）：最大路径和

**题目描述：** 数字三角形，从顶到底每步只能走左下或右下，求路径数字总和的最大值。

**输入格式：** n，然后 n 行数字三角形

**样例输入：**
```
4
1
3 2
4 10 1
4 3 2 20
```

**样例输出：** `24`（1→3→10→（注意下标）→20的路径不合法，正确是1→3→10→3=17或其他路径最大）

实际样例：`1→3→4→4=12` vs `1→2→10→3=16` vs ... → 最大 `1→3→10→3 = 17`，本例最优 `1+3+10+3=17`。

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int a[20][20];
long long dp[20][20];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= i; j++) cin >> a[i][j];
    dp[1][1] = a[1][1];
    for (int i = 2; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            long long best = 0;
            if (j > 1) best = max(best, dp[i-1][j-1]);
            if (j <= i-1) best = max(best, dp[i-1][j]);
            dp[i][j] = best + a[i][j];
        }
    }
    long long ans = 0;
    for (int j = 1; j <= n; j++) ans = max(ans, dp[n][j]);
    cout << ans << endl;
}
```

### 练习 5（进阶）：铺满地板

**题目描述：** 用 1×2 的方块铺满 2×n 的地板，有几种铺法？

**输入：** 整数 n（1 ≤ n ≤ 40）  **输出：** 铺法数

**分析：**
- `f[1] = 1`（只能竖放）

```cpp
#include <iostream>

long long f[45];
int main() {
    int n; cin >> n;
    f[1] = 1; f[2] = 2;
    for (int i = 3; i <= n; i++) f[i] = f[i-1] + f[i-2];
    cout << f[n] << endl;
}
```

## 五、课堂总结（5分钟）🌟

> 递推算法——以"小"推"大"的艺术！
>
> **核心三步：**
> 1. 初始化边界值（`f[1] =`, `f[2] =`）
> 2. 写递推关系式（`f[i] = f[i-1] + ...`）
> 3. 用循环递推到 n
>
> **推导技巧：** 先算前几个值，找规律，用"上一步"描述"这一步"！
>
> 递推是动态规划的基础，掌握后你将打开算法竞赛的新大门！🚪
