1. 理解文件重定向的概念，掌握竞赛中常用的 `freopen` 重定向方法

- 文件重定向：`freopen` 函数的使用

- 文件打开模式：`ios::in`、`ios::out`、`ios::app` 等
- 异常处理：`try { ... } catch (exception& e) { ... }`
- 常见异常类型：`runtime_error`、`out_of_range` 等

### 2. 知识点讲解

#### 2.1 文件重定向（竞赛最常用）

**`freopen` 函数**：将标准输入/输出重定向到文件。

```cpp
freopen("input.txt", "r", stdin);   // 把 stdin 重定向到文件读取
freopen("output.txt", "w", stdout); // 把 stdout 重定向到文件写入
```

这样，程序里的 `cin` 会从 `input.txt` 读，`cout` 会写到 `output.txt`，代码其他部分不需要修改！

**竞赛标准模板（常用）：**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    freopen("input.txt", "r", stdin);
    freopen("output.txt", "w", stdout);
    
    // 正常使用 cin 和 cout
    int n;
    cin >> n;
    cout << n * 2 << endl;
    
    fclose(stdin);   // 关闭文件（可选但建议）
    fclose(stdout);
    return 0;
}
```

> 💡 竞赛技巧：可以用条件编译，本地测试时开启文件重定向，提交时关闭：
>
> ```cpp
> #define LOCAL
> #ifdef LOCAL
>     freopen("input.txt", "r", stdin);
> #endif
> ```

---

#### 2.2 ifstream——文件输入流

**读取文件（更规范的方式）：**

```cpp
#include <fstream>
#include <iostream>
using namespace std;

int main() {
    ifstream fin("data.txt");    // 打开文件
    
    if (!fin.is_open()) {        // 检查是否打开成功
        cout << "打开文件失败！" << endl;
        return 1;
    }
    
    int x;
    while (fin >> x) {           // 循环读取，文件末尾自动停止
        cout << x << " ";
    }
    
    fin.close();                 // 关闭文件
    return 0;
}
```

**逐行读取（`getline`）：**

```cpp
ifstream fin("data.txt");
string line;
while (getline(fin, line)) {    // 每次读一行到 line
    cout << line << endl;
}
fin.close();
```

---

#### 2.3 ofstream——文件输出流

**写入文件：**

```cpp
#include <fstream>
using namespace std;

int main() {
    ofstream fout("result.txt");    // 打开文件写入（会覆盖原内容）
    
    fout << "Hello, File!" << endl;
    fout << 42 << endl;
    
    fout.close();
    return 0;
}
```

**追加模式（不覆盖原内容）：**

```cpp
ofstream fout("log.txt", ios::app);    // app = append，追加模式
fout << "新增一行日志" << endl;
fout.close();
```

---

#### 2.4 fstream——读写文件流

```cpp
#include <fstream>
using namespace std;

int main() {
    fstream fs("data.txt", ios::in | ios::out | ios::app);
    
    // 先读现有内容
    string line;
    while (getline(fs, line)) cout << line << endl;
    
    // 再追加写入
    fs << "新数据行" << endl;
    
    fs.close();
    return 0;
}
```

**文件打开模式：**

| 模式 | 说明 |
|------|------|
| `ios::in` | 只读（ifstream 默认） |
| `ios::out` | 只写（ofstream 默认），文件存在则清空 |
| `ios::app` | 追加写，不清空原内容 |
| `ios::binary` | 二进制模式 |
| `ios::in \| ios::out` | 读写模式 |

#### 2.5 异常处理机制

**基本语法：**

```cpp
try {
    // 可能出错的代码
    // 如果出错，抛出异常：throw exception;
} catch (exception_type& e) {
    // 处理异常
    cout << "错误：" << e.what() << endl;
}
```

**示例：捕获文件打开失败**

```cpp
#include <fstream>
#include <stdexcept>
using namespace std;

int main() {
    try {
        ifstream fin("not_exist.txt");
        if (!fin.is_open()) {
            throw runtime_error("文件打开失败！");
        }
        int x;
        fin >> x;
        cout << x << endl;
    } catch (runtime_error& e) {
        cout << "捕获异常：" << e.what() << endl;
    }
    return 0;
}
```

**示例：捕获数组越界（out_of_range）**

```cpp
#include <vector>
#include <stdexcept>
using namespace std;

int main() {
    vector<int> v = {1, 2, 3};
    try {
        cout << v.at(10);    // at() 越界会抛出 out_of_range 异常
    } catch (out_of_range& e) {
        cout << "越界错误：" << e.what() << endl;
    }
    return 0;
}
```

**常用异常类型：**

| 异常类型 | 触发场景 |
|---------|---------|
| `runtime_error` | 运行时错误（可用 throw 手动抛出） |
| `out_of_range` | 容器下标越界（vector::at 等） |
| `bad_alloc` | 内存分配失败（new 失败） |
| `invalid_argument` | 参数无效 |

> 💡 竞赛中 try-catch 很少用，但在实际工程开发中是必备技能！

### 3. GESP 真题演练 ⚡

**抢答题 1（选择题）：**

> `freopen("a.txt", "r", stdin)` 的作用是（ ）
>
> A. 把 a.txt 写入到标准输入
> B. 把标准输入重定向到 a.txt，之后 cin 从 a.txt 读取
> C. 把标准输出重定向到 a.txt
> D. 清空 a.txt 的内容
>
> **答案：B**

**判断题 2：**

> `ofstream fout("out.txt");` 以写模式打开 out.txt，若文件已存在则在原内容末尾追加。（ ）
>
> **答案：✗（错误）**
>
> 解析：ofstream 默认使用 `ios::out` 模式会清空原文件内容再写入。若要追加，需指定 `ios::app` 模式。

**抢答题 3（选择题）：**

> try-catch 块中，catch 捕获的是（ ）
>
> A. 编译错误  B. 逻辑错误  C. 运行时抛出的异常  D. 语法错误
>
> **答案：C**

### 4. 进阶扩展

**文件流与 string 结合——stringstream：**

```cpp
#include <sstream>
using namespace std;

string s = "100 200 300";
istringstream iss(s);    // 把字符串当成输入流
int a, b, c;
iss >> a >> b >> c;      // 从字符串读取整数
cout << a + b + c;       // 600
```

> 应用场景：对一整行字符串逐词解析，比 `sscanf` 更 C++ 风格。

## 四、课堂练习（45分钟）🎈

### 练习 1（基础）：文件重定向读写

**题目描述：**

用 `freopen` 从 `input.txt` 读入 n 个整数，将其升序排序后写入 `output.txt`。（实际运行时可在目录下创建 input.txt 测试）

**题解代码（带文件重定向）：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[100005];
int main() {
    freopen("input.txt", "r", stdin);
    freopen("output.txt", "w", stdout);
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    sort(a + 1, a + n + 1);
    for (int i = 1; i <= n; i++) {
        if (i > 1) cout << " ";
        cout << a[i];
    }
    cout << endl;
    fclose(stdin); fclose(stdout);
    return 0;
}
```

### 练习 2（基础）：ifstream 读文件

**题目描述：**

用 `ifstream` 打开文件 `numbers.txt`，读取所有整数求和后输出（假设文件存在）。

**题解代码：**

```cpp
#include <fstream>
#include <iostream>
using namespace std;
int main() {
    ifstream fin("numbers.txt");
    long long sum = 0;
    int x;
    while (fin >> x) sum += x;
    fin.close();
    cout << sum << endl;
    return 0;
}
```

### 练习 3（综合）：ofstream 写文件

**题目描述：**

生成乘法口诀表（1×1 到 9×9），将结果写入文件 `table.txt`，每行格式为 `a×b=c`。

**题解代码：**

```cpp
#include <fstream>
using namespace std;
int main() {
    ofstream fout("table.txt");
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= i; j++) {
            if (j > 1) fout << " ";
            fout << j << "x" << i << "=" << i*j;
        }
        fout << endl;
    }
    fout.close();
    return 0;
}
```

### 练习 4（综合）：异常处理

**题目描述：**

输入两个整数 a 和 b，用 try-catch 处理除零异常（当 b=0 时输出错误信息而不崩溃）。

**题解代码：**

```cpp
#include <iostream>
#include <stdexcept>
using namespace std;
int safeDivide(int a, int b) {
    if (b == 0) throw runtime_error("除数不能为零！");
    return a / b;
}
int main() {
    int a, b; cin >> a >> b;
    try {
        cout << safeDivide(a, b) << endl;
    } catch (runtime_error& e) {
        cout << "错误：" << e.what() << endl;
    }
    return 0;
}
```

### 练习 5（进阶）：日志记录系统

**题目描述：**

编写简单日志系统：运行程序时输入 n 条日志信息（字符串），每次输入后追加写入 `log.txt`，最后读取 `log.txt` 并输出所有内容。

**题解代码：**

```cpp
#include <fstream>
#include <iostream>
#include <string>
using namespace std;
int main() {
    int n; cin >> n; cin.ignore();
    // 追加写入
    ofstream fout("log.txt", ios::app);
    for (int i = 0; i < n; i++) {
        string s; getline(cin, s);
        fout << s << endl;
    }
    fout.close();
    // 读取输出
    ifstream fin("log.txt");
    string line;
    while (getline(fin, line)) cout << line << endl;
    fin.close();
    return 0;
}
```
