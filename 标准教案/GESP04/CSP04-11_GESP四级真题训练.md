## 三、真题演练（45分钟）

### 🔢 选择题训练

**题 1：** 冒泡排序对 n 个元素进行升序排列，最多需要进行多少次元素交换？

A. n   B. n-1   C. n(n-1)/2   D. n²

> **答案：C**
>
> 解析：最坏情况（完全逆序），第1趟交换n-1次，第2趟n-2次...总计 1+2+...+(n-1) = n(n-1)/2 次。

---

**题 2：** 定义 `int a[3][4];`，以下表达式计算 `sizeof(a)` 的结果是（ ）

A. 7   B. 12   C. 28   D. 48

> **答案：D**
>
> 解析：3×4=12 个 int 元素，每个 int 占 4 字节，共 48 字节。

---

**题 3：** 执行 `sort(a+2, a+7)` 后，被排序的元素是（ ）

A. a[2] 到 a[7]（共6个）
B. a[2] 到 a[6]（共5个）
C. a[3] 到 a[7]（共5个）
D. a[2] 到 a[7]（共7个）

> **答案：B**
>
> 解析：sort 的范围是左闭右开 [a+2, a+7)，即 a[2]..a[6]，共 5 个元素。

---

**题 4：** 设 `int a = 5; int* p = &a;`，执行 `*p = 10;` 后，`a` 的值是？

A. 5   B. 10   C. &a   D. 编译错误

> **答案：B**
>
> 解析：`*p` 解引用得到 a 的值，`*p = 10` 将 a 修改为 10。

---

**题 5：** 以下关于结构体的说法，正确的是（ ）

A. 结构体的每个成员必须是同一类型
B. 结构体变量可以整体赋值给同类型的另一个变量
C. 定义结构体时成员没有分号 `;`
D. 结构体的大小等于所有成员大小的简单相加

> **答案：B**
>
> 解析：A 错，结构体可包含多种类型；B 正确；C 错，每个成员后需要 `;`；D 错，内存对齐可能使大小更大。

---

**题 6：** 以下关于函数默认参数的说法，正确的是（ ）

A. 默认参数可以放在任意位置
B. 有默认值的参数必须在没有默认值的参数右边
C. 一个函数只能有一个默认参数
D. 有默认参数的函数不能被重载

> **答案：B**
>
> 解析：C++ 规定默认参数必须从右到左连续设置，即有默认值的参数必须排在没有默认值的参数之后。

---

**题 7：** 斐波那契数列中，`f[6]` 的值是（f[1]=f[2]=1）

A. 5   B. 8   C. 10   D. 13

> **答案：B**
>
> 解析：1,1,2,3,5,8，f[6]=8。

---

**题 8：** `freopen("a.txt", "w", stdout)` 的效果是（ ）

A. 从 a.txt 读取数据到标准输入
B. 把标准输出重定向到文件 a.txt
C. 清空 a.txt 并向其中追加内容
D. 以只读模式打开 a.txt

> **答案：B**
>
> 解析："w" 表示写模式，stdout 表示标准输出，此操作将标准输出重定向到 a.txt（会清空原内容）。

---

**题 9：** 指针 `p+1` 中的"1"实际上偏移的字节数（假设 `int* p`）是（ ）

A. 1 字节   B. 4 字节   C. 8 字节   D. 取决于系统

> **答案：B**
>
> 解析：指针运算的单位是所指类型的大小。`int` 占 4 字节，所以 `p+1` 偏移 4 字节。

---

**题 10：** 以下哪种函数参数方式既无拷贝开销又能修改原变量？

A. 值传递 `f(int x)`
B. const 引用 `f(const int& x)`
C. 引用传递 `f(int& x)`
D. 以上都不是

> **答案：C**
>
> 解析：引用传递使用别名，不复制，且可以修改原变量。const 引用虽无拷贝，但不可修改。

### ✅ 判断题训练

**判 1：** 插入排序是一种稳定的排序算法。（ ）

> **答案：✓（正确）**  解析：相等元素不交换，相对顺序保持不变。

**判 2：** `int* p = nullptr;` 然后执行 `*p = 5;` 程序会正常运行。（ ）

> **答案：✗（错误）**  解析：对空指针解引用会导致段错误（程序崩溃）。

**判 3：** `sort(s.begin(), s.end())` 可以对 string 的内部字符排序。（ ）

> **答案：✓（正确）**  解析：`begin()` 和 `end()` 是 string 的迭代器，sort 可以用它们对字符排序。

**判 4：** 二维数组 `a[i][j]` 和 `*(*(a+i)+j)` 是等价的。（ ）

> **答案：✓（正确）**  解析：`*(a+i)` 得到第 i 行的地址（一维数组），再 `+j` 偏移 j 个元素，解引用得到 `a[i][j]`。

**判 5：** 递推算法必须从最小规模的边界值开始计算。（ ）

> **答案：✓（正确）**  解析：递推需要边界值作为起点，否则无法推导后续结果。

#### 编程题 1：学生成绩管理（结构体 + 排序）

**题目描述：**

输入 n 个学生的姓名、学号和三科成绩（语文、数学、英语），计算每人总分，然后按总分降序排列，总分相同按学号升序排列，输出排名结果（名次 姓名 总分）。

**输入格式：**
- 第一行整数 n（1 ≤ n ≤ 100）
- 接下来 n 行：姓名 学号 语文 数学 英语

**输出格式：** n 行，`第i名 姓名 总分`

**样例输入：**
```
3
Alice 1001 85 92 88
Bob 1002 90 78 85
Carol 1003 85 92 88
```

**样例输出：**
```
第1名 Alice 265
第2名 Carol 265
第3名 Bob 253
```

**参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Student {
    string name;
    int id, cn, math, en, total;
} stu[105];

bool cmp(const Student& a, const Student& b) {
    if (a.total != b.total) return a.total > b.total;
    return a.id < b.id;
}

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> stu[i].name >> stu[i].id >> stu[i].cn >> stu[i].math >> stu[i].en;
        stu[i].total = stu[i].cn + stu[i].math + stu[i].en;
    }
    sort(stu + 1, stu + n + 1, cmp);
    for (int i = 1; i <= n; i++)
        cout << "第" << i << "名 " << stu[i].name << " " << stu[i].total << endl;
    return 0;
}
```

#### 编程题 2：楼梯走法（递推）

**题目描述：**

n 级台阶，每次可以走 1、2 或 3 步，求共有多少种走法（答案对 1000000007 取模）。

**输入格式：** 整数 n（1 ≤ n ≤ 10000）

**输出格式：** 走法数对 1e9+7 取模

**样例输入：** `5`  **样例输出：** `13`

**参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MOD = 1e9 + 7;
long long f[10005];
int main() {
    int n; cin >> n;
    f[1] = 1; f[2] = 2;
    f[3] = (n >= 3) ? 4 : f[n];
    for (int i = 4; i <= n; i++)
        f[i] = (f[i-1] + f[i-2] + f[i-3]) % MOD;
    cout << f[n] << endl;
    return 0;
}
```

#### 编程题 3：矩阵螺旋遍历

**题目描述：**

输入 n×m 的整数矩阵，按顺时针螺旋顺序输出所有元素（从左上角开始，向右→向下→向左→向上螺旋）。

**输入格式：**
- 第一行两个整数 n m（1 ≤ n, m ≤ 20）
- 接下来 n 行 m 列的整数矩阵

**样例输入：**
```
3 3
1 2 3
4 5 6
7 8 9
```

**样例输出：** `1 2 3 6 9 8 7 4 5`

**参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[25][25];
int main() {
    int n, m; cin >> n >> m;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) cin >> a[i][j];
    
    int top = 1, bottom = n, left = 1, right = m;
    bool first = true;
    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++) { if (!first) cout << " "; cout << a[top][j]; first = false; }
        top++;
        for (int i = top; i <= bottom; i++) { if (!first) cout << " "; cout << a[i][right]; first = false; }
        right--;
        if (top <= bottom) {
            for (int j = right; j >= left; j--) { if (!first) cout << " "; cout << a[bottom][j]; first = false; }
            bottom--;
        }
        if (left <= right) {
            for (int i = bottom; i >= top; i--) { if (!first) cout << " "; cout << a[i][left]; first = false; }
            left++;
        }
    }
    cout << endl;
    return 0;
}
```
