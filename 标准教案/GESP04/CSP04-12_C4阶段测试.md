## 三、判断题（10分，每题1分）

**1.** 二维数组的每一行可以作为一个一维数组来使用。（ **✓** ）

**2.** `sort(a+1, a+n+1)` 对 a[1] 到 a[n] 升序排序，无需传比较函数。（ **✓** ）

**3.** 指针 `p+2` 表示 p 所指地址加 2 字节。（ **✗** — 加 `2 × sizeof(类型)` 字节）

**4.** 结构体的成员不可以是另一个结构体类型。（ **✗** — 可以嵌套）

**5.** `const int& x` 参数类型既无拷贝开销，又不允许函数修改 x 的值。（ **✓** ）

**6.** 递推算法中，边界条件不是必须的。（ **✗** — 必须有边界值才能开始递推）

**7.** `try-catch` 块可以捕获运行时抛出的异常。（ **✓** ）

**8.** `swap(a[j], a[j+1])` 在冒泡排序中可以交换两个相邻元素。（ **✓** ）

**9.** 对于 `int a[3][4]`，`a[3][0]` 是合法的访问。（ **✗** — 行下标最大为 2，越界）

**10.** `sort` 函数默认使用快速排序，时间复杂度为 O(n log n)。（ **✓** — 准确说是 IntroSort）

## 四、编程题（60分，共3题）

### 编程题 1（20分）：学生信息排序

**题目描述：**

输入 n 个学生的姓名（字符串）、年级（1-6）和成绩（整数），先按年级升序，同年级按成绩降序，成绩也相同按姓名字典序升序，输出排序结果。

**输入格式：**
- 第一行整数 n（1 ≤ n ≤ 1000）
- 接下来 n 行：姓名 年级 成绩

**输出格式：** n 行，每行姓名 年级 成绩

**样例输入：**
```
4
Alice 3 90
Bob 2 85
Carol 3 90
Dave 2 95
```

**样例输出：**
```
Dave 2 95
Bob 2 85
Alice 3 90
Carol 3 90
```

**参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Student {
    string name;
    int grade, score;
} stu[1005];

bool cmp(const Student& a, const Student& b) {
    if (a.grade != b.grade) return a.grade < b.grade;
    if (a.score != b.score) return a.score > b.score;
    return a.name < b.name;
}

int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++)
        cin >> stu[i].name >> stu[i].grade >> stu[i].score;
    sort(stu + 1, stu + n + 1, cmp);
    for (int i = 1; i <= n; i++)
        cout << stu[i].name << " " << stu[i].grade << " " << stu[i].score << endl;
    return 0;
}
```

### 编程题 2（20分）：矩阵图形

**题目描述：**

输入正奇数 n，输出以下格式的 n×n 矩阵：
- 矩阵边框用 `*` 填充
- 矩阵对角线（主对角和副对角）用 `#` 填充
- 其余位置用 `.` 填充
（若某位置同时满足多个条件，优先级：边框 > 对角线 > 点）

**输入格式：** 奇数 n（3 ≤ n ≤ 15）

**样例输入：** `5`

**样例输出：**
```
*****
*#.#*
*.#.*
*#.#*
*****
```

**参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (i == 1 || i == n || j == 1 || j == n)
                cout << '*';
            else if (i == j || i + j == n + 1)
                cout << '#';
            else
                cout << '.';
        }
        cout << endl;
    }
    return 0;
}
```

### 编程题 3（20分）：数字接龙（递推）

**题目描述：**

定义数字接龙序列：`a[1] = 1`，之后每一项的生成规则是：

- 设 `a[n-1]` 的末位数字为 `d`
- `a[n] = a[n-1] + (d == 0 ? 10 : d) * 常数k`（常数 k 由输入给出）

输入 n 和 k，输出 a[n]（答案可能很大，对 `10^9 + 7` 取模）。

**输入格式：** 两个整数 n（1 ≤ n ≤ 100000）和 k（1 ≤ k ≤ 100）

**输出格式：** `a[n] mod (10^9 + 7)`

**样例输入：** `5 1`  **样例输出（演示）：** a[1]=1, a[2]=1+1=2, a[3]=2+2=4, a[4]=4+4=8, a[5]=8+8=16 → 输出 `16`

**参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
const long long MOD = 1e9 + 7;
long long a[100005];

int main() {
    int n, k;
    cin >> n >> k;
    a[1] = 1;
    for (int i = 2; i <= n; i++) {
        int d = a[i-1] % 10;
        if (d == 0) d = 10;
        a[i] = (a[i-1] + (long long)d * k) % MOD;
    }
    cout << a[n] << endl;
    return 0;
}
```
