# CSP05-01 递归改造循环

## 一、课程简介（5分钟）

### 🎯 课程目标

1. 理解递归算法的核心概念，能用自己的语言描述"递归"的定义
2. 掌握递归函数的两大要素：递归关系式与边界条件
3. 理解递归与递推（循环）的本质区别与相互转化关系
4. 能分析递归的优缺点，判断哪些场景适合使用递归

### 📚 核心知识点

- 递归算法的概念：函数直接或间接调用自身
- 递归函数的定义：递归关系式 + 边界条件（停止条件）
- 递归的执行过程："有去有回"，调用栈的压栈与出栈
- 递归的优点：代码简洁，适合描述分治结构
- 递归的缺点：栈空间有限，可能栈溢出；存在重复计算
- 递归与递推的区别：递归自顶向下，递推自底向上

### 2. 知识点讲解

#### 2.1 递归算法的基本概念

**什么是递归？**

> 如果一个函数在执行过程中直接或间接地调用了自身，这种调用方式就叫做**递归调用**，对应的函数叫做**递归函数**。

**递归函数的两大要素（缺一不可！）：**

> 1. **递归关系式**：把"大问题"转化为"相同结构的小问题"的规律
> 2. **边界条件（停止条件）**：什么时候不再递归，直接给出答案

**经典例子：求 f(n) = 1 + 2 + 3 + ... + n**

- 递归关系式：`f(n) = f(n-1) + n`（n > 1 时）
- 边界条件：`f(1) = 1`

```cpp
int f(int n) {
    if (n == 1) return 1;   // 边界条件：直接返回
    return f(n - 1) + n;   // 递归关系式：转化为更小的问题
}
```

#### 2.2 递归的执行过程

以 `f(4)` 为例，展示"调用栈"的变化：

> **下行（压栈）：**
>
> `f(4)` → 需要 `f(3)`
>
> `f(3)` → 需要 `f(2)`
>
> `f(2)` → 需要 `f(1)`
>
> `f(1)` → 直接返回 1（触发边界）
>
> **上行（出栈，有去有回）：**
>
> `f(2)` = `f(1)` + 2 = 1 + 2 = 3
>
> `f(3)` = `f(2)` + 3 = 3 + 3 = 6
>
> `f(4)` = `f(3)` + 4 = 6 + 4 = 10 ✅

**互动提问：**

> 如果我们去掉边界条件，`f(n)` 会发生什么？
>
> 答：函数会无限递归下去，直到**栈空间耗尽**，程序报错（栈溢出 Stack Overflow）！

#### 2.3 递归与递推（循环）的区别

| 对比项目 | 递推（循环） | 递归 |
|---------|------------|------|
| 方向 | 自底向上（从小到大）| 自顶向下（从大到小）|
| 代码风格 | for/while 循环 | 函数调用自身 |
| 空间开销 | 一般 O(1) | 需要调用栈，O(n) |
| 适用场合 | 问题有明确的迭代顺序 | 问题结构天然分治/递归 |

> 循环就像 **排队打饭**：从第1个开始，依次到第n个，有明确的顺序。
>
> 递归就像 **查字典**：查一个词发现要先查另一个词，层层嵌套，最终找到直接答案再回头。

#### 2.4 递归的优缺点与适用条件

**优点：**

> - 代码简洁优雅，逻辑清晰（高度符合数学定义）
> - 适合描述天然具有递归结构的问题（如树、分治、回溯）

**缺点：**

> - 函数调用有额外开销（保存现场/恢复现场），速度比循环慢
> - 递归深度受限于栈空间（一般 ~10000 层），深度太大会栈溢出
> - 可能存在大量重复计算（如斐波那契数列的朴素递归）

**适用条件：**

> 1. 问题可以被分解为**相同结构的子问题**
> 2. 存在明确的**边界条件**（最小问题可直接求解）
> 3. 子问题规模**不断缩小**，保证能到达边界

**抢答题 1（选择题）：**

> 关于递归函数，下列说法正确的是（ ）
>
> A. 递归函数不需要终止条件，可以无限调用自身
>
> B. 递归函数必须有终止条件，否则会导致栈溢出
>
> C. 递归函数的效率总是比循环高

> D. 递归和循环完全等价，任何情况下都可以互换

**判断题 2：**

> 递归函数一定可以改写成循环形式。（ ）
>
> **答案：✓（正确，理论上可以，但有时实现很复杂）**
>
> 解析：从理论上说，所有递归都可以用循环+手动栈实现，但对于树遍历、回溯等场景，改写后代码非常复杂，不建议强行转化。

**抢答题 3（选择题）：**

> 下面代码的输出是（ ）
>
> ```cpp
> int f(int n) {
>     if (n <= 1) return 1;
>     return f(n-1) * n;
> }
> int main() { cout << f(5); }
> ```
>
> A. 5  B. 24  C. 120  D. 25
>
> **答案：C**
>
> 解析：f(5) = 5×f(4) = 5×4×3×2×1 = 120，即5的阶乘。

### 4. 进阶扩展

**递归改造成循环（以求和为例）：**

> 黑板推演：
>
> 递归版：`f(n) = f(n-1) + n`，自顶向下，先"去"后"回"
>
> 循环版：`sum = 1 + 2 + ... + n`，自底向上，直接累加

```cpp
// 递归版
int f_recursive(int n) {
    if (n == 1) return 1;
    return f_recursive(n - 1) + n;
}

// 循环版（等价）
int f_loop(int n) {
    int sum = 0;
    for (int i = 1; i <= n; i++) sum += i;
    return sum;
}
```

> 💡 两者结果完全相同，但循环版更高效（无额外函数调用开销）。

### 练习 3（综合）：斐波那契数列

**题目描述：**

斐波那契数列定义：F(1)=1, F(2)=1, F(n)=F(n-1)+F(n-2)（n≥3）

用递归方法计算第 n 项的值。

**输入格式：**
- 一行，一个正整数 n（1 ≤ n ≤ 30）

**输出格式：**
- 输出 F(n) 的值

**样例输入：**

**样例输出：**
```
55
```

```cpp
#include <iostream>
using namespace std;

int fib(int n) {
    if (n == 1 || n == 2) return 1;  // 两个边界条件

}

int main() {
    int n;
    cin >> n;
    cout << fib(n) << endl;
    return 0;
}
```

### 练习 4（综合）：递归判断回文串

**题目描述：**

用递归方法判断一个字符串是否是回文串（正读反读都相同）。

**输入格式：**
- 一行，一个只含小写字母的字符串（长度 1∼100）

**输出格式：**
- 如果是回文串输出 `YES`，否则输出 `NO`

**样例输入：**
```
abcba
```

**样例输出：**
```
YES
```

**题解代码：**

```cpp
#include <iostream>
#include <string>
using namespace std;

// 判断 s[l..r] 是否为回文
bool isPalin(const string& s, int l, int r) {
    if (l >= r) return true;        // 边界：区间为空或只有一个字符
    if (s[l] != s[r]) return false; // 两端不同，不是回文
    return isPalin(s, l + 1, r - 1); // 检查内部
}

int main() {
    string s;
    cin >> s;
    if (isPalin(s, 0, s.size() - 1))
        cout << "YES" << endl;
    else
        cout << "NO" << endl;
    return 0;
}
```

### 练习 5（进阶）：数字倒序输出

**题目描述：**

输入一个正整数 n，用递归方法将其各位数字倒序输出（不输出前导零）。

**输入格式：**
- 一行，一个正整数 n（1 ≤ n ≤ 10^9）

**输出格式：**
- 倒序输出 n 的各位数字（中间无空格）

**样例输入：**
```
12345
```

**样例输出：**
```
54321
```

**思路分析：**

定义 `f(n)` = 倒序输出 n：
- 如果 n < 10：直接输出 n（边界）
- 否则：先输出 `n%10`（个位），再递归调用 `f(n/10)`

**题解代码：**

```cpp
#include <iostream>
using namespace std;

void f(int n) {
    if (n < 10) {
        cout << n;
        return;
    }
    cout << n % 10;  // 先输出个位
    f(n / 10);       // 再处理剩余高位（递归，规模缩小）
}

int main() {
    int n;
    cin >> n;
    f(n);
    cout << endl;
    return 0;
}
```

>
> **三句话记住递归：**
>
> 🚀 **递归 = 自己调用自己**（函数在执行中调用自身）
>
> 🛑 **边界条件是灵魂**（没有边界 = 无限递归 = 栈溢出！）

>

```cpp
#include <iostream>
```

```cpp
bool isEven(int n) {

    return isEven(n - 2);      // 减2不改变奇偶性

    cout << (isEven(n) ? "Even" : "Odd") << endl;
    return 0;
}
```
