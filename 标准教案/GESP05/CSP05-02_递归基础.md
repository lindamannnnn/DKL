### 2. 知识点讲解

#### 2.1 递归思路分析三步法

**第一步：问题的定义**

> 把题目用"函数"的语言重新描述，明确：
>
> - 函数 f 代表什么（函数的语义）
> - 函数的参数代表什么范围或规模

**第二步：问题的转化**

> 找到 f(大规模) 和 f(小规模) 之间的递推关系。
> 同时找到最小规模下的直接解（边界条件）。

**第三步：递归实现**

> 将以上分析直接翻译成代码：边界条件写 `if` 直接返回，递归关系写 `return f(...)`。

**示例：求数组前 k 个数的最大值**

> - 定义：f(k) = 前 k 个数的最大值
> - 转化：f(k) = max(a[k], f(k-1))；边界：f(1) = a[1]
> - 实现见下方代码

```cpp
int a[105];
int f(int k) {
    if (k == 1) return a[1];
    return max(a[k], f(k - 1));
}
```

#### 2.2 算法时间复杂度分析

**什么是时间复杂度？**

> 衡量算法运行时间随输入规模 n 增长的速度，用大 O 记号表示。
> 忽略常数项和低阶项，只保留最高阶。

**常见复杂度（从优到差）：**

| 复杂度 | 代表算法 | n=10^6 时约需操作数 |
|--------|---------|-------------------|
| O(1) | 直接计算 | 1 次 |
| O(log n) | 二分查找 | 约 20 次 |
| O(n) | 线性扫描 | 10^6 次 |
| O(n²) | 冒泡排序 | 10^12 次（太慢！）|
| O(2^n) | 朴素斐波那契递归 | 天文数字 |

**分析朴素斐波那契递归的复杂度：**

> `fib(n)` 的调用次数约为 2^n 级（指数级），非常慢！
>
> 为什么？因为 fib(n) 调用 fib(n-1) 和 fib(n-2)，每层都分叉为两个，形成一棵二叉树。
>
> fib(5) 的调用树中，fib(3) 被计算了 2 次，fib(2) 被计算了 3 次 ——**大量重复！**

#### 2.3 空间复杂度分析

> 递归函数每次调用都会在调用栈中保存一帧（局部变量、返回地址等）。
>
> 对于深度为 n 的递归（如 f(n) → f(n-1) → ... → f(1)），同时存在 n 层调用，因此空间复杂度为 **O(n)**。
>
> 当 n 很大时（如 n=10^6），每帧约占几十字节，总空间可达几十 MB，容易**栈溢出**。

**互动提问：**

> 如果递归深度是 100000，每帧占 50 字节，总共需要多少空间？
>
> 答：100000 × 50 = 5,000,000 字节 = 约 5MB，一般系统的线程栈大小约 1~8MB，有栈溢出风险！

#### 2.4 记忆化搜索（Memoization）

**核心思想：**

> 用一个数组（或哈希表）保存每个子问题的计算结果。
>
> 每次调用前先查表，如果已经计算过，直接返回缓存值；否则计算后存入缓存。

**斐波那契记忆化版：**

```cpp
#include <iostream>
using namespace std;

int memo[100] = {0};   // 0 表示未计算

int fib(int n) {
    if (n <= 2) return 1;           // 边界条件
    if (memo[n] != 0) return memo[n]; // 查表，命中则直接返回
    memo[n] = fib(n - 1) + fib(n - 2); // 计算并存入缓存
    return memo[n];
}

int main() {
    int n;
    cin >> n;
    cout << fib(n) << endl;
    return 0;
}
```

**效果对比：**

> - 朴素递归 fib(40)：约 2 亿次调用（O(2^n)）
> - 记忆化递归 fib(40)：仅 40 次不同的子问题计算（O(n)）
>
> 这就是记忆化搜索的威力——**将指数级降低到线性级！**

### 3. GESP 真题演练 ⚡

**抢答题 1（选择题）：**

> 用递归计算 fib(5)（斐波那契第5项），共需调用多少次 fib() 函数（包括 fib(5) 本身）？
>
> A. 5  B. 9  C. 15  D. 25
>
> **答案：C（15次）**
>
> 解析：fib(5)调用fib(4)和fib(3)；fib(4)调用fib(3)和fib(2)；……展开后共15次函数调用。

**判断题 2：**

> 使用记忆化搜索后，斐波那契数列的时间复杂度从 O(2^n) 降低到 O(n)。（ ）
>
> **答案：✓（正确）**
>
> 解析：每个子问题只计算一次，共有 n 个不同子问题，因此总时间复杂度为 O(n)。

**抢答题 3（选择题）：**

> 以下关于记忆化搜索的说法，**错误**的是（ ）
>
> A. 记忆化搜索可以消除重叠子问题
>
> B. 记忆化搜索需要额外的空间来存储子问题结果
>
> C. 记忆化搜索总是比动态规划（自底向上）效率更高
>
> D. 记忆化搜索是一种自顶向下的动态规划
>
> **答案：C**
>
> 解析：记忆化（自顶向下）和 DP（自底向上）效率相当，有时 DP 甚至更优（无递归开销）。C 的说法"总是更高"不正确。

### 4. 进阶扩展

**记忆化搜索一般模板：**

```cpp
// 全局 memo 数组，初始化为 -1（表示未计算）
int memo[100005];
fill(memo, memo + 100005, -1);

int f(int n) {
    if (/* 边界条件 */) return /* 边界值 */;
    if (memo[n] != -1) return memo[n];  // 查表
    memo[n] = /* 递归计算 */;           // 存入缓存
    return memo[n];
}
```

> 黑板推演：以爬楼梯问题为例
>
> 每次可以走1级或2级台阶，走到第n级有多少种方法？
>
> - f(1) = 1，f(2) = 2（边界）
> - f(n) = f(n-1) + f(n-2)（转化）
>
> 这正是斐波那契数列！用记忆化优化后时间复杂度为 O(n)。

### 练习 3（综合）：递归求最小值路径

**题目描述：**

有一个 n×n 的数字三角形，从顶部出发，每次可以向左下或右下走一步，到达底部。求路径上数字之和的最小值。

**输入格式：**
- 第一行整数 n（1 ≤ n ≤ 20）
- 接下来 n 行，第 i 行有 i 个整数，表示数字三角形

**输出格式：**
- 路径数字之和的最小值

**样例输入：**
```
4
2
3 4
6 5 7
4 1 8 3
```

**样例输出：**
```
11
```

**思路分析：**

定义 `f(i, j)` = 从 (i,j) 出发到达底部的最小路径和。
- 边界：i==n 时，f(n,j)=a[n][j]
- 转化：f(i,j) = a[i][j] + min(f(i+1,j), f(i+1,j+1))

**题解代码：**

```cpp
#include <iostream>
#include <climits>
using namespace std;

int a[25][25], n;
int memo[25][25];

int f(int i, int j) {
    if (i == n) return a[i][j];
    if (memo[i][j] != -1) return memo[i][j];
    memo[i][j] = a[i][j] + min(f(i + 1, j), f(i + 1, j + 1));
    return memo[i][j];
}

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= i; j++)
            cin >> a[i][j];
    fill(&memo[0][0], &memo[24][25], -1);
    cout << f(1, 1) << endl;
    return 0;
}
```

### 练习 4（综合）：连续整数和的方案数

**题目描述：**

给定 n，求有多少种方法可以把 n 写成若干个正整数之和（顺序不同算不同方案，但每个数不超过自身之前一个数）。

**输入格式：**
- 一行，整数 n（1 ≤ n ≤ 15）

**输出格式：**
- 方案数

**样例输入：**
```
4
```

**样例输出：**
```
4
```

**思路分析：**

定义 f(n, k) = 将 n 分拆为不超过 k 的正整数之和的方案数。
- f(0, k) = 1（任意 k，和为0的方案就是空集）
- f(n, 1) = 1（只能全用1）
- f(n, k) = f(n, k-1) + f(n-k, k)（k>n时不选k，否则选或不选k）

**题解代码：**

```cpp
#include <iostream>
using namespace std;

int memo[20][20];

int f(int n, int k) {
    if (n == 0) return 1;
    if (k == 1) return 1;
    if (memo[n][k] != -1) return memo[n][k];
    if (k > n)
        memo[n][k] = f(n, n);
    else
        memo[n][k] = f(n, k - 1) + f(n - k, k);
    return memo[n][k];
}

int main() {
    int n;
    cin >> n;
    fill(&memo[0][0], &memo[19][20], -1);
    cout << f(n, n) << endl;
    return 0;
}
```

### 练习 5（进阶）：多重递归的优化

**题目描述：**

定义函数 g(n)：如果 n 为偶数，g(n)=g(n/2)+1；如果 n 为奇数（n>1），g(n)=g(n-1)+1；g(1)=0。

计算 g(n) 的值（即将 n 变为 1 的最少步数）。

**输入格式：**
- 一行，整数 n（1 ≤ n ≤ 10^6）

**输出格式：**
- g(n) 的值

**样例输入：**
```
12
```

**样例输出：**
```
4
```

**思路分析：**

12 → 6(偶/2) → 3(偶/2) → 2(奇-1) → 1，共4步。用记忆化避免重复计算。

**题解代码：**

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

unordered_map<int, int> memo;

int g(int n) {
    if (n == 1) return 0;
    if (memo.count(n)) return memo[n];
    if (n % 2 == 0)
        memo[n] = g(n / 2) + 1;
    else
        memo[n] = g(n - 1) + 1;
    return memo[n];
}

int main() {
    int n;
    cin >> n;
    cout << g(n) << endl;
    return 0;
}
```

#### 作业 2：数字最大乘积

**题目描述：**

将正整数 n（n≥2）拆分为若干个正整数之和（至少拆成2个），使它们的乘积最大，输出最大乘积。

**输入格式：**
- 一行整数 n（2 ≤ n ≤ 10）

**输出格式：**
- 最大乘积

**样例输入：**
```
8
```

**样例输出：**
```
18
```

**样例说明：** 8 = 2+3+3，乘积 = 2×3×3 = 18

**题解代码：**

```cpp
#include <iostream>
using namespace std;
long long memo[15];

// f(n) = 将n拆分后的最大乘积（至少拆成2个）
// dp[i] = max(直接使用i, 继续拆分i)
long long dp[15];

int main() {
    int n;
    cin >> n;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = 0;
        for (int j = 1; j < i; j++) {
            dp[i] = max(dp[i], max((long long)j*(i-j), (long long)j*dp[i-j]));
        }
    }
    cout << dp[n] << endl;
    return 0;
}
```

#### 作业 3：求反向斐波那契

**题目描述：**

给定斐波那契数列的某一项值 v，判断它是第几项。已知 F(1)=1, F(2)=1，若 v 不是斐波那契数则输出 -1。

**输入格式：**
- 一行整数 v（1 ≤ v ≤ 10^6）

**输出格式：**
- 若 v 是第 n 项，输出 n；否则输出 -1

**样例输入：**
```
8
```

**样例输出：**
```
6
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int main() {
    int v;
    cin >> v;
    long long a = 1, b = 1;
    int idx = 2;
    while (b < v) {
        long long c = a + b;
        a = b; b = c;
        idx++;
    }
    if (b == v) cout << idx;
    else cout << -1;
    return 0;
}
```

#### 挑战 6：复杂度分析练习

分析下面代码的时间复杂度（相对于 n）：

```cpp
int f(int n) {
    if (n == 1) return 1;
    return f(n/2) + f(n/2) + n;
}
```

**提示：** 设 T(n) = 2T(n/2) + n，根据主定理，答案为 O(n log n)。
