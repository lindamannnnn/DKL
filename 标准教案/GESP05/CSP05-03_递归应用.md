### 2. 知识点讲解

#### 2.1 递归进制转换

**十进制转二进制（除2取余法）：**

> 例：将 13 转换为二进制
>
> - 13 ÷ 2 = 6 ... **余 1**（个位）
> - 6 ÷ 2 = 3 ... **余 0**
> - 3 ÷ 2 = 1 ... **余 1**
> - 1 ÷ 2 = 0 ... **余 1**（最高位）
>
> 从下往上读余数：**1101**

**为什么递归可以自动"逆序"输出？**

> 普通方法需要先把所有余数存起来，再逆序输出。
>
> 递归的巧妙之处：先递归（处理更高位），再输出当前余数（低位）。
>
> 这样，最深层递归先返回，最高位先输出！

**递归实现（十进制转任意进制）：**

```cpp
// 将十进制数 n 转换为 base 进制并输出
void convert(int n, int base) {
    if (n == 0) return;         // 边界：没有更高位了
    convert(n / base, base);   // 先递归处理高位
    int digit = n % base;       // 当前位
    if (digit < 10)
        cout << digit;
    else
        cout << (char)('A' + digit - 10);  // 十六进制用A-F
}
```

> ⚠️ 注意：如果 n 本身就是 0，上面的函数什么都不输出，需要在 main 中特判！

**完整代码（含特判）：**

```cpp
#include <iostream>
using namespace std;

void convert(int n, int base) {
    if (n == 0) return;
    convert(n / base, base);
    int digit = n % base;
    if (digit < 10) cout << digit;
    else cout << (char)('A' + digit - 10);
}

int main() {
    int n, base;
    cin >> n >> base;
    if (n == 0) { cout << 0; return 0; }
    convert(n, base);
    cout << endl;
    return 0;
}
```

**互动提问：**

> 把 60 转换为八进制，手动模拟递归调用过程：

#### 2.2 汉诺塔问题

**递归分析：**

> 将 n 个圆盘从柱子 A 移到柱子 C，借助柱子 B：
>
> **大问题（n个盘）分解为：**
>
> 1. **第一步：** 将上面 n-1 个盘从 A 移到 B（借助 C）
> 2. **第二步：** 将最大的盘从 A 直接移到 C
> 3. **第三步：** 将 n-1 个盘从 B 移到 C（借助 A）
>
> **边界条件：** n=1 时，直接把这个盘从 A 移到 C。

**递归实现：**

```cpp
#include <iostream>
using namespace std;

// 把 n 个盘从 from 借助 via 移到 to
void hanoi(int n, char from, char via, char to) {
    if (n == 1) {
        cout << "Move disk 1 from " << from << " to " << to << endl;
        return;
    }
    hanoi(n - 1, from, to, via);    // 把n-1个盘从from移到via
    cout << "Move disk " << n << " from " << from << " to " << to << endl;
    hanoi(n - 1, via, from, to);    // 把n-1个盘从via移到to
}

int main() {
    int n;
    cin >> n;
    hanoi(n, 'A', 'B', 'C');
    return 0;
}
```

> 当 n=3 时，执行 7 步：
>
> Move disk 1 from A to C
> Move disk 2 from A to B
> Move disk 1 from C to B
> Move disk 3 from A to C
> Move disk 1 from B to A
> Move disk 2 from B to C
> Move disk 1 from A to C

**最少步数分析：**

> 设 f(n) 为移 n 个盘的最少步数：
>
> - f(1) = 1
> - f(n) = 2×f(n-1) + 1
>
> 解递推可得：**f(n) = 2^n - 1**
>
> n=64 时，f(64) = 2^64 - 1 ≈ 1.8 × 10^19，若每秒移一次需约 5800 亿年！

**抢答题 1（选择题）：**

> 将十进制数 26 转换为二进制，结果是（ ）
>
> A. 10110  B. 11010  C. 11001  D. 10011
>
> **答案：B（11010）**
>
> 解析：26÷2=13余0, 13÷2=6余1, 6÷2=3余0, 3÷2=1余1, 1÷2=0余1。余数逆序读：11010。

**判断题 2：**

> 用递归解决汉诺塔问题时，n 个圆盘需要移动 2n-1 次。（ ）
>
> **答案：✗（错误）**
>
> 解析：应该是 2^n - 1 次（2的n次方减1），不是 2×n-1。例如 n=3 时需要 7 次，不是 5 次。

**抢答题 3（选择题）：**

> 十六进制数 `1A` 对应的十进制数是（ ）
>
> A. 20  B. 26  C. 10  D. 1
>
> **答案：B（26）**
>
> 解析：1×16 + A×1 = 16 + 10 = 26。

### 4. 进阶扩展

**通用进制转换函数（含输入检验）：**

```cpp
#include <iostream>
#include <string>
using namespace std;

string convert(int n, int base) {
    if (n == 0) return "0";
    string result = "";
    while (n > 0) {
        int digit = n % base;
        char c = (digit < 10) ? ('0' + digit) : ('A' + digit - 10);
        result = c + result;  // 倒序拼接（等价于递归）
        n /= base;
    }
    return result;
}

int main() {
    int n, base;
    cin >> n >> base;
    cout << convert(n, base) << endl;
    return 0;
}
```

> 黑板推演：这个循环版本与递归版本等价——循环中"倒序拼接"模拟了递归的"先递归后输出"。

#### 作业 3：汉诺塔步数公式验证

输入 n，分别用递归计算汉诺塔步数和公式 2^n-1 验证两者相等，输出步数。

**题解代码：**

```cpp
#include <iostream>
using namespace std;
long long hanoi_steps(int n) {
    if (n == 1) return 1;
    return 2 * hanoi_steps(n - 1) + 1;
}
int main() {
    int n; cin >> n;
    long long steps = hanoi_steps(n);
    long long formula = (1LL << n) - 1;  // 2^n - 1
    cout << steps << endl;  // 两者应相等
    return 0;
}
```
