### 2. 知识点讲解

#### 2.1 约数与倍数

> 若整数 a 能被整数 b 整除（即 a ÷ b 余数为 0），则称 **b 是 a 的约数（因数）**，**a 是 b 的倍数**。
>
> 记作：`b | a`（b整除a）

**代码：枚举 n 的所有约数**

```cpp
for (int i = 1; i <= n; i++) {
    if (n % i == 0) {
        cout << i << " ";  // i 是 n 的约数
    }
}
```

> 💡 优化：约数对称出现，只需枚举到 √n：

```cpp
for (int i = 1; (long long)i * i <= n; i++) {
    if (n % i == 0) {
        cout << i << " ";
        if (i != n / i) cout << n / i << " ";
    }
}
```

#### 2.2 奇偶性

> 整数 n：
> - 若 `n % 2 == 0`，n 为**偶数**
> - 若 `n % 2 == 1`（或 `n % 2 != 0`），n 为**奇数**

**奇偶性的性质（常考）：**

> - 奇数 + 奇数 = 偶数
> - 奇数 × 奇数 = 奇数
> - 偶数 × 任何数 = 偶数

**互动提问：**

> a=7, b=3，a+b=? 奇偶性如何？（10，偶数；奇+奇=偶）

#### 2.3 素数与合数

> - **素数（质数）**：只有 1 和自身两个因数的正整数（2, 3, 5, 7, 11...）
>   注意：1 既不是素数也不是合数！
> - **合数**：有三个及以上因数的正整数（4, 6, 8, 9...）
> - **2 是唯一的偶质数！**

**判断 n 是否为素数：**

```cpp
bool isPrime(int n) {
    if (n < 2) return false;     // 1 不是质数
    for (int i = 2; (long long)i * i <= n; i++) {
        if (n % i == 0) return false;  // 有因数则不是质数
    }
    return true;
}
```

> 时间复杂度：O(√n)。对于 n ≤ 10^9 的情况，√n ≤ 31623，速度很快！

#### 2.4 同余与模运算

> **同余**：如果 a 和 b 除以 m 的余数相同，称 a 与 b 模 m 同余，记作 `a ≡ b (mod m)`。
>
> 在代码中用 `%` 运算符表示取模（求余数）。

**模运算的重要性质：**

> - `(a + b) % m = ((a % m) + (b % m)) % m`
> - `(a × b) % m = ((a % m) × (b % m)) % m`
> - `(a - b) % m = ((a % m) - (b % m) + m) % m`（注意保证非负！）

**互动提问：**

> 计算 `(2^10) % 7` 的值？
>
> `2^10 = 1024`，`1024 % 7 = 2`（因为 1024 = 146×7 + 2）

#### 2.5 最大公约数（GCD）与欧几里得算法

> **GCD(a, b)**：a 和 b 的最大公约数，即能同时整除 a 和 b 的最大正整数。

**欧几里得算法（辗转相除法）：**

> 核心公式：`GCD(a, b) = GCD(b, a % b)`
>
> 边界：`GCD(a, 0) = a`

**代码实现：**

```cpp
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}

// 或者一行版（C++14可用）：
// int gcd(int a, int b) { return b ? gcd(b, a % b) : a; }
```

**推演示例（GCD(48, 18)）：**

> ```
> GCD(48, 18) → GCD(18, 48%18=12) → GCD(12, 18%12=6) → GCD(6, 12%6=0) → 6
> ```

#### 2.6 最小公倍数（LCM）

> **LCM(a, b)**：a 和 b 的最小公倍数。

**关键公式：**

> `LCM(a, b) = a / GCD(a, b) × b`
>
> ⚠️ 注意：先除后乘，避免溢出！

```cpp
long long lcm(int a, int b) {
    return (long long)a / gcd(a, b) * b;  // 先除后乘防溢出
}
```

#### 2.7 质因数分解与唯一分解定理

> **唯一分解定理（算术基本定理）：** 任何大于1的正整数都可以唯一分解为质数的乘积（不计顺序）。
>
> 例：`12 = 2² × 3`，`60 = 2² × 3 × 5`

**代码：对 n 进行质因数分解**

```cpp
void factorize(int n) {
    for (int i = 2; (long long)i * i <= n; i++) {
        while (n % i == 0) {
            cout << i << " ";  // i 是 n 的质因数
            n /= i;
        }
    }
    if (n > 1) cout << n;  // n 本身是质数
}
```

```cpp
#include <iostream>

int main() {
    long long a, b;
    cin >> a >> b;
    long long g = gcd(a, b);
    cout << g << endl << a / g * b << endl;
    return 0;
}
```

### 练习 2（基础）：判断素数

**题目描述：**

输入 n 个正整数，逐个判断是否为素数。

**输入格式：**
- 第一行 n（1≤n≤100），第二行 n 个正整数（每个不超过10^6）

**输出格式：**
- 对每个数，素数输出 `Yes`，否则 `No`

**样例输入：**
```
4
2 4 7 9
```

**样例输出：**
```
Yes No Yes No
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; (long long)i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}
int main() {
    int n; cin >> n;
    for (int i = 0; i < n; i++) {
        int x; cin >> x;
        cout << (isPrime(x) ? "Yes" : "No");
        if (i < n - 1) cout << " ";
    }
    return 0;
}
```

### 练习 3（综合）：质因数分解

**题目描述：**

输入一个正整数 n（n≥2），输出其质因数分解结果（从小到大，格式如 `2 2 3` 表示 2²×3）。

**输入格式：** 一行整数 n（2 ≤ n ≤ 10^8）

**输出格式：** 质因数从小到大排列，用空格分隔

**样例输入：** `12`  **样例输出：** `2 2 3`

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    bool first = true;
    for (int i = 2; (long long)i * i <= n; i++) {
        while (n % i == 0) {
            if (!first) cout << " ";
            cout << i;
            first = false;
            n /= i;
        }
    }
    if (n > 1) { if (!first) cout << " "; cout << n; }
    return 0;
}
```

### 练习 4（综合）：区间互质对数

**题目描述：**

给定区间 [l, r]，求其中有多少对 (i, j)（i < j）满足 GCD(i, j) = 1（互质）。

**输入格式：** 一行两个整数 l, r（1 ≤ l ≤ r ≤ 1000）

**输出格式：** 互质对的数量

**样例输入：** `1 5`  **样例输出：** `7`

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int gcd(int a, int b) { return b ? gcd(b, a % b) : a; }
int main() {
    int l, r; cin >> l >> r;
    int cnt = 0;
    for (int i = l; i <= r; i++)
        for (int j = i + 1; j <= r; j++)
            if (gcd(i, j) == 1) cnt++;
    cout << cnt << endl;
    return 0;
}
```

### 练习 5（进阶）：最简分数化简

**题目描述：**

输入分子 p 和分母 q，将分数 p/q 化为最简分数输出。

**输入格式：** 一行，两个正整数 p, q（1 ≤ p, q ≤ 10^6）

**输出格式：** 最简分数形式，如 `3/4`

**样例输入：** `6 8`  **样例输出：** `3/4`

**题解代码：**

```cpp
#include <iostream>
using namespace std;
int gcd(int a, int b) { return b ? gcd(b, a % b) : a; }
int main() {
    int p, q; cin >> p >> q;
    int g = gcd(p, q);
    cout << p / g << "/" << q / g << endl;
    return 0;
}
```

}
