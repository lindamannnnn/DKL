## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> **筛子比喻：**
>
> 想象你手里有一个数字筛子，初始时把 2 到 n 的所有数都放进去。
>
> 然后你从最小的数 2 开始：2 是质数！把 2 的所有倍数（4, 6, 8...）全部筛掉（标记为合数）。
>
> 然后看 3：3 没被筛掉，所以 3 是质数！再把 3 的倍数（6, 9, 12...）全部筛掉。
>
> 然后 4：4 已经被筛掉了，跳过。
>
> 5 是质数！筛掉 10, 15, 25...
>
> 如此重复，最终筛子里剩下的所有数，都是**质数**！
>
> 这就是古希腊数学家**埃拉托斯特尼**发明的筛法，已有2000多年历史！

### 2. 知识点讲解

#### 2.1 埃拉托斯特尼筛法（埃氏筛）

**核心思想：**

> 对于每个质数 p，把它的倍数 p², p²+p, p²+2p, ... 全部标记为合数。（从 p² 开始，是因为 p² 以下的 p 的倍数已被更小的质数筛过）

**代码实现：**

```cpp
#include <iostream>
using namespace std;

const int MAXN = 1e7 + 5;
bool notPrime[MAXN];  // false=质数，true=合数
int primes[700000];   // 存储质数
int cnt = 0;

void sieve(int n) {
    notPrime[0] = notPrime[1] = true;  // 0和1不是质数
    for (int i = 2; i <= n; i++) {
        if (!notPrime[i]) {
            primes[cnt++] = i;         // i是质数，加入质数表
            for (long long j = (long long)i * i; j <= n; j += i) {
                notPrime[j] = true;    // 标记i的倍数为合数
            }
        }
    }
}

int main() {
    int n;
    cin >> n;
    sieve(n);
    cout << "2 到 " << n << " 内共有 " << cnt << " 个质数。" << endl;
    return 0;
}
```

**时间复杂度分析：**

> 每个质数 p 筛去约 n/p 个合数，总操作数约为 n/2 + n/3 + n/5 + n/7 + ... 
>
> 数学上可证这是 O(n log log n) ≈ 几乎是线性的！

**互动提问：**

> 为什么内层循环从 `i*i` 开始而不从 `2*i` 开始？
>
> 因为 `2i, 3i, ..., (i-1)×i` 都已经被比 i 更小的质数筛掉了！从 `i²` 开始可以减少重复工作。

#### 2.2 线性筛法（欧拉筛）

**埃氏筛的缺陷：**

> 合数 12 = 2×6 = 3×4，会被 2 和 3 各筛一次，存在重复！
>
> 线性筛保证每个合数**恰好被其最小质因数筛一次**，从而实现真正的 O(n)。

**核心思想：**

> 对每个数 i，用"当前已知的每个质数 p"乘以 i。
> - 若 p | i（p 整除 i），则 i 的最小质因数 ≤ p，此时 i×p 的最小质因数就是 p，停止（保证每个合数只被其最小质因数筛一次）。
> - 若 p ∤ i，则继续枚举更大的质数。

**代码实现：**

```cpp
#include <iostream>
using namespace std;

const int MAXN = 1e7 + 5;
bool notPrime[MAXN];
int primes[700000];
int cnt = 0;

void linearSieve(int n) {
    notPrime[0] = notPrime[1] = true;
    for (int i = 2; i <= n; i++) {
        if (!notPrime[i]) {
            primes[cnt++] = i;            // i 是质数
        }
        for (int j = 0; j < cnt && (long long)i * primes[j] <= n; j++) {
            notPrime[i * primes[j]] = true;  // 用 i 和每个质数的乘积筛合数
            if (i % primes[j] == 0) break;   // 关键！保证每个合数只被筛一次
        }
    }
}

int main() {
    int n;
    cin >> n;
    linearSieve(n);
    cout << cnt << endl;
    return 0;
}
```

**两种筛法对比：**

| 特性 | 埃氏筛 | 线性筛 |
|------|--------|--------|
| 时间复杂度 | O(n log log n) | O(n) |
| 代码复杂度 | 简单 | 稍复杂 |
| 常数因子 | 小（缓存友好）| 稍大 |
| 实际速度（n=10^7） | 约 0.1-0.2s | 约 0.1s |
| 额外功能 | 可稍微扩展 | 可同时求最小质因数、phi 函数等 |

> 💡 实际竞赛中，埃氏筛已足够用；线性筛的优势在于**同时维护更多数论函数**（如欧拉函数、最小质因数）。

### 4. 进阶扩展

**利用线性筛同时求最小质因数：**

```cpp
int minPF[MAXN];  // minPF[i] 存 i 的最小质因数

void sieveWithMinPF(int n) {
    for (int i = 2; i <= n; i++) minPF[i] = i;  // 初始化为自身
    for (int i = 2; (long long)i * i <= n; i++) {
        if (minPF[i] == i) {  // i 是质数
            for (int j = i * i; j <= n; j += i) {
                if (minPF[j] == j) minPF[j] = i;  // 最小质因数是 i
            }
        }
    }
}
```

> 有了 `minPF` 数组，可以 O(log n) 时间内对任意数进行质因数分解！

### 练习 1（基础）：筛出指定范围质数

**题目描述：**

输入正整数 n，用埃氏筛法找出 2 到 n 内所有质数，逐个输出。

**输入格式：** 一行，整数 n（2 ≤ n ≤ 10^6）

**输出格式：** 所有质数，用空格分隔

**样例输入：** `20`

**样例输出：** `2 3 5 7 11 13 17 19`

**题解代码：**

```cpp
#include <iostream>
using namespace std;
const int MAXN = 1e6 + 5;
bool notPrime[MAXN];
int main() {
    int n; cin >> n;
    notPrime[0] = notPrime[1] = true;
    for (int i = 2; i <= n; i++) {
        if (!notPrime[i]) {
            for (long long j = (long long)i * i; j <= n; j += i)
                notPrime[j] = true;
        }
    }
    bool first = true;
    for (int i = 2; i <= n; i++) {
        if (!notPrime[i]) {
            if (!first) cout << " ";
            cout << i;
            first = false;
        }
    }
    return 0;
}
```

### 练习 5（进阶）：利用最小质因数快速分解

**题目描述：**

预处理 1 到 n 内每个数的最小质因数，然后对 q 次询问，每次快速输出某个数的质因数分解。

**输入格式：**
- 第一行 n 和 q（n ≤ 10^6，q ≤ 10^5）
- 接下来 q 行，每行一个数 x（2 ≤ x ≤ n）

**样例输入：**
```
100 2
12
30
```

**样例输出：**
```
2 2 3
2 3 5
```

**题解代码：**

```cpp
#include <iostream>
using namespace std;
const int MAXN = 1e6 + 5;
int minPF[MAXN];
int main() {
    int n, q; cin >> n >> q;
    for (int i = 2; i <= n; i++) minPF[i] = i;
    for (int i = 2; (long long)i * i <= n; i++)
        if (minPF[i] == i)
            for (int j = i * i; j <= n; j += i)
                if (minPF[j] == j) minPF[j] = i;
    while (q--) {
        int x; cin >> x;
        bool first = true;
        while (x > 1) {
            if (!first) cout << " ";
            cout << minPF[x];
            x /= minPF[x];
            first = false;
        }
        cout << endl;
    }
    return 0;
}
```

## 五、课堂总结（5分钟）🌟

> 今天我们学了两种高效的质数筛法！
>
> **埃氏筛（推荐日常使用）：**
>
> 从每个质数出发，筛掉它的倍数，从 p²开始。时间复杂度 O(n log log n)，代码简洁。
>
> **线性筛（竞赛精准控制）：**
>
> 每个合数只被最小质因数筛一次，实现真正 O(n)。可同时维护其他数论函数。
>
> **常用数据：**
> - 1到10^6 内有约 78498 个质数
> - 1到10^7 内有约 664579 个质数
