### 2. 知识点讲解

#### 2.1 因数个数公式

> 若 n = p1^a1 × p2^a2 × ... × pk^ak（质因数分解），则
>
> **n 的因数个数 = (a1+1) × (a2+1) × ... × (ak+1)**

**代码实现：**

```cpp
int countDivisors(int n) {
    int result = 1;
    for (int i = 2; (long long)i * i <= n; i++) {
        int exp = 0;
        while (n % i == 0) {
            exp++;
            n /= i;
        }
        result *= (exp + 1);
    }
    if (n > 1) result *= 2;  // 剩余的质因数幂次为1，贡献 (1+1)=2
    return result;
}
```

**示例：** 12 = 2² × 3¹，因数个数 = (2+1)(1+1) = 6（1, 2, 3, 4, 6, 12）✓

#### 2.2 因数之和公式

> n = p1^a1 × p2^a2 × ... × pk^ak，则
>
> **n 的因数之和 = (1+p1+p1²+...+p1^a1) × (1+p2+...+p2^a2) × ...**
>
> 即每个质数因子对应的等比数列之和相乘。

```cpp
long long sumDivisors(int n) {
    long long result = 1;
    for (int i = 2; (long long)i * i <= n; i++) {
        if (n % i == 0) {
            long long pk = 1, sum = 1;
            while (n % i == 0) {
                pk *= i;
                sum += pk;  // sum = 1 + i + i^2 + ... + i^exp
                n /= i;
            }
            result *= sum;
        }
    }
    if (n > 1) result *= (1 + n);  // 剩余质因数 p，贡献 (1+p)
    return result;
}
```

#### 2.3 数论结合枚举：找满足条件的因子对

**经典模型：** 给定 n，找出所有满足 a×b = n 且 a ≤ b 的正整数对 (a, b)。

```cpp
void findFactorPairs(int n) {
    for (int a = 1; (long long)a * a <= n; a++) {
        if (n % a == 0) {
            cout << a << " " << n / a << endl;
        }
    }
}
```

**变形：** 给定 n，找出 a + b = n 且 GCD(a, b) 最大的正整数对 (a, b)。

> 思路：GCD(a, n-a) = GCD(a, n)（欧几里得性质），所以 GCD(a, n-a) 必是 n 的因数。
>
> 最大的 GCD 就是 n 本身吗？不，要 a ≥ 1 且 b = n-a ≥ 1，所以 GCD 最大取 n 的最大因数（即 n/最小质因数）。

#### 2.4 数论结合贪心

**经典模型：** 有 n 堆石子，合并任意两堆后放回，操作代价为两堆总数。
求最小总代价使所有石子合为一堆。

> 数论辅助：若所有石子总数为 S，GCD 不影响最优策略，贪心用优先队列"哈夫曼"解。

**数论+贪心示例：** 给定整数 n，用最少次数的 "除以一个质数" 操作将 n 变为 1。

> 思路：每次操作除以 n 的最小质因数，最少操作次数 = n 的 Ω(n) 函数（质因数个数，计重数）。

```cpp
int minOps(int n) {
    int cnt = 0;
    for (int i = 2; (long long)i * i <= n; i++) {
        while (n % i == 0) { n /= i; cnt++; }
    }
    if (n > 1) cnt++;
    return cnt;
}
```

### 4. 进阶扩展

**完全数的判断（因数之和应用）：**

```cpp
// 若一个正整数等于其所有真因子（不含本身）之和，则为完全数
bool isPerfect(int n) {
    if (n <= 1) return false;
    int sum = 1;  // 1 一定是因子
    for (int i = 2; (long long)i * i <= n; i++) {
        if (n % i == 0) {
            sum += i;
            if (i != n / i) sum += n / i;
        }
    }
    return sum == n;
}
// 完全数：6, 28, 496, 8128, ...
```

### 练习 4（综合）：因数个数最多的数

**题目：** 给定 n，找出 1 到 n 中因数个数最多的数（若有多个取最小）。

**样例输入：** `100`  **样例输出：** `60`（60的因数个数为12，是100以内最多的）

```cpp
#include <iostream>
using namespace std;
int countDiv(int n) {
    int result = 1;
    int tmp = n;
    for (int i = 2; (long long)i * i <= tmp; i++) {
        int e = 0;
        while (tmp % i == 0) { e++; tmp /= i; }
        result *= (e + 1);
    }
    if (tmp > 1) result *= 2;
    return result;
}
int main() {
    int n; cin >> n;
    int best = 0, bestN = 1;
    for (int i = 1; i <= n; i++) {
        int d = countDiv(i);
        if (d > best) { best = d; bestN = i; }
    }
    cout << bestN << endl;
    return 0;
}
```

### 练习 5（进阶）：最长连续整除子序列

**题目：** 给定数组 a[1..n]，找最长的连续子数组，使得子数组中每个元素都能整除后一个元素。

**输入：** 第一行 n，第二行 n 个正整数

**样例输入：**
```
6
1 2 4 8 3 6
```
**样例输出：** `4`（子数组 1,2,4,8，每个整除后一个）

```cpp
#include <iostream>
using namespace std;
int a[100005];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int maxLen = 1, curLen = 1;
    for (int i = 2; i <= n; i++) {
        if (a[i] % a[i-1] == 0) curLen++;
        else curLen = 1;
        maxLen = max(maxLen, curLen);
    }
    cout << maxLen << endl;
    return 0;
}
```

若一个数的质因数只有 2, 3, 5，称为丑数（1也是丑数）。输出第 n 个丑数。

```cpp
#include <iostream>
using namespace std;
int ugly[1505];
int main() {
    int n; cin >> n;
    ugly[1] = 1;
    int i2 = 1, i3 = 1, i5 = 1;
    for (int i = 2; i <= n; i++) {
        int next = min({ugly[i2]*2, ugly[i3]*3, ugly[i5]*5});
        ugly[i] = next;
        if (next == ugly[i2]*2) i2++;
        if (next == ugly[i3]*3) i3++;
        if (next == ugly[i5]*5) i5++;
    }
    cout << ugly[n] << endl;
    return 0;
}
```
