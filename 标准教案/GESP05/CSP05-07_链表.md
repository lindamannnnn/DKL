# CSP05-07 链表

## 一、课程简介（5分钟）

### 🎯 课程目标

1. 理解单链表、双链表、循环链表的概念和结构特点
2. 掌握链表的创建、遍历、插入、删除操作
3. 能用数组模拟链表解决实际问题

### 📚 核心知识点

- 单链表：每个节点包含数据域和一个指针（next）
- 双链表：每个节点包含数据域、前驱指针（prev）和后继指针（next）
- 循环链表：最后一个节点的 next 指向头节点
- 链表的创建：头插法、尾插法
- 链表的遍历：从头节点逐步访问
- 链表的插入：在指定位置插入节点
- 链表的删除：删除指定节点
- 数组模拟链表（竞赛常用）

## 二、知识回顾（10分钟）

### 👩‍🏫 教师引导

> 我们之前学的数组是一种"顺序存储"结构——元素在内存中连续排列，通过下标直接访问。
>
> 但数组有一个大缺陷：**在中间插入或删除元素时，需要移动大量元素**，效率很低。
>
> 今天我们学习一种新的数据结构——**链表**，它特别擅长插入和删除！

**互动复习：**

> - 问：数组在第 i 个位置插入一个元素，需要移动多少个元素？（移动 n-i 个）
> - 问：若数组有 10000 个元素，频繁在头部插入，效率如何？（非常低，每次需移动约 10000 个元素）
> - 引导：如果能"只修改指针"而不移动数据，就能 O(1) 完成插入/删除！

## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> **火车厢的故事：**
>
> 想象一列火车，每节车厢（节点）里有乘客（数据），以及一张"车票"（指针）——上面写着下一节车厢的位置。
>
> **数组** = 固定编号的车厢，编号 1-n，想找第 5 节直接去5号。但是要在3号和4号之间加一节新车厢，所有后面的车厢都要重新编号！
>
> **链表** = 车厢上只有"下一节在哪里"的信息，想加一节新车厢？只需修改两张票！不需要动其他车厢！
>
> 这就是链表的妙处：**插入删除只需 O(1) 操作！**

### 2. 知识点讲解

#### 2.1 单链表的结构

**单链表的节点定义（结构体版）：**

```cpp
struct Node {
    int data;   // 数据域
    Node* next; // 指针域：指向下一个节点
    Node(int d) : data(d), next(nullptr) {}
};
```

> 整个链表由一个"头指针" `head` 表示，它指向第一个节点。
>
> 最后一个节点的 `next = nullptr`（空指针，表示链表结束）。

**单链表的遍历：**

```cpp
Node* cur = head;  // 从头节点开始
while (cur != nullptr) {
    cout << cur->data << " ";  // 访问当前节点
    cur = cur->next;           // 移向下一个节点
}
```

**单链表的插入（在节点 p 之后插入 newNode）：**

```cpp
newNode->next = p->next;  // 新节点接上 p 的后继
p->next = newNode;         // p 的 next 指向新节点
```

**单链表的删除（删除节点 p 的后继节点）：**

```cpp
Node* toDelete = p->next;
p->next = toDelete->next;  // 跳过要删除的节点
delete toDelete;            // 释放内存
```

#### 2.2 数组模拟链表（竞赛主流！）

> 竞赛中通常不用结构体指针版（内存分配慢），而用**数组模拟链表**。

**数组模拟单链表：**

```cpp
const int MAXN = 1e5 + 5;
int val[MAXN];   // 节点数据
int nxt[MAXN];   // 下一个节点的"编号"（索引）
int head;        // 头节点
int tot = 0;     // 当前已用的节点数

// 初始化（创建空链表）
void init() {
    head = 0;  // 0 表示空
    tot = 0;
}

// 在头部插入节点（头插法）
void insertHead(int v) {
    val[++tot] = v;
    nxt[tot] = head;
    head = tot;
}

// 在节点 p 之后插入
void insertAfter(int p, int v) {
    val[++tot] = v;
    nxt[tot] = nxt[p];
    nxt[p] = tot;
}

// 删除节点 p 的后继节点
void deleteAfter(int p) {
    if (nxt[p] != 0) {
        nxt[p] = nxt[nxt[p]];
    }
}

// 遍历打印
void traverse() {
    int cur = head;
    while (cur != 0) {
        cout << val[cur] << " ";
        cur = nxt[cur];
    }
}
```

#### 2.3 双链表

> 双链表的每个节点有两个指针：`next`（后继）和 `prev`（前驱），可以双向遍历！

**数组模拟双链表（常用于竞赛）：**

```cpp
int val[MAXN], nxt[MAXN], prv[MAXN];
int head, tail, tot;

void init() {
    // 创建两个哨兵节点：head=1（左哨兵），tail=2（右哨兵）
    head = 1; tail = 2; tot = 2;
    nxt[head] = tail; prv[tail] = head;
    nxt[tail] = 0; prv[head] = 0;
}

// 在节点 p 之后插入值 v
void insertAfter(int p, int v) {
    val[++tot] = v;
    nxt[tot] = nxt[p]; prv[tot] = p;
    prv[nxt[p]] = tot; nxt[p] = tot;
}

// 删除节点 p（哨兵节点不可删除）
void remove(int p) {
    nxt[prv[p]] = nxt[p];
    prv[nxt[p]] = prv[p];
}
```

#### 2.4 循环链表

> 循环链表：最后一个节点的 `nxt` 指向头节点（形成一个环）。
>
> 常用于约瑟夫问题：n 个人围成一圈，每隔 k 个人踢出一人，最后剩谁？

**互动提问：**

> 单链表在尾部插入时，如何做到 O(1)？
>
> 答：额外维护一个 `tail` 指针，每次在 `tail` 后插入，更新 `tail`。

### 3. GESP 真题演练 ⚡

**抢答题 1（选择题）：**

> 关于单链表，以下说法正确的是（ ）
>
> A. 可以通过下标直接访问第 i 个元素，时间复杂度 O(1)
>
> B. 在中间插入元素的时间复杂度为 O(1)（已知插入位置的前驱节点）
>
> C. 链表天然支持随机访问
>
> D. 链表比数组更节省内存
>
> **答案：B**
>
> 解析：A错：链表需要遍历，O(n)。B正确：已知前驱，只需修改两个指针。C错：链表不支持随机访问。D错：链表需存指针，更占内存。

**判断题 2：**

> 双链表既可以从头到尾遍历，也可以从尾到头遍历。（ ）
>
> **答案：✓（正确）**

**抢答题 3（选择题）：**

> 删除单链表中某个节点（已知其前驱节点），需要修改几个指针？
>
> A. 0个  B. 1个  C. 2个  D. 3个
>
> **答案：B（1个）**
>
> 解析：只需将前驱节点的 `next` 指向被删节点的 `next` 即可，仅修改 1 个指针。

### 4. 进阶扩展

**约瑟夫问题（循环链表经典应用）：**

> n 个人（编号1~n）围成一圈，从第 1 个人开始，每数到第 k 个人就退出圈子，求最后留下的人的编号。

```cpp
#include <iostream>
using namespace std;

// 数学公式法（O(n)）
int josephus(int n, int k) {
    int pos = 0;  // 0-indexed，最后剩下位置
    for (int i = 2; i <= n; i++) {
        pos = (pos + k) % i;
    }
    return pos + 1;  // 转为 1-indexed
}

int main() {
    int n, k;
    cin >> n >> k;
    cout << josephus(n, k) << endl;
    return 0;
}
```

### 练习 2（基础）：链表插入操作

**题目描述：**

初始有一个链表 1→2→3→4→5，执行若干次"在第 k 个节点后插入值 v"的操作，输出最终链表。

**输入：** 第一行 操作次数 m；接下来 m 行每行 k, v

**样例输入：**
```
2
2 10
4 20
```
（在第2个节点后插入10：1→2→10→3→4→5；再在第4个后插入20：1→2→10→3→20→4→5）

**样例输出：** `1 2 10 3 20 4 5`

```cpp
#include <iostream>
using namespace std;
int val[1005], nxt[1005], head, tot;
int main() {
    head = 1; tot = 5;
    for (int i = 1; i <= 5; i++) { val[i] = i; nxt[i] = i + 1; }
    nxt[5] = 0;
    int m; cin >> m;
    while (m--) {
        int k, v; cin >> k >> v;
        int cur = head;
        for (int i = 1; i < k; i++) cur = nxt[cur];
        val[++tot] = v;
        nxt[tot] = nxt[cur];
        nxt[cur] = tot;
    }
    int cur = head;
    while (cur) { cout << val[cur] << " "; cur = nxt[cur]; }
    return 0;
}
```

### 练习 3（综合）：链表删除操作

**题目描述：**

维护一个链表，支持以下操作：
- `1 v`：在末尾添加值 v
- `2 k`：删除第 k 个节点

初始链表为空，执行 m 次操作后输出链表。

**输入：** m（1≤m≤100），接下来 m 行操作

**样例输入：**
```
5
1 1
1 2
1 3
2 2
1 4
```

**样例输出：** `1 3 4`

```cpp
#include <iostream>
using namespace std;
int val[1005], nxt[1005], prv[1005], head, tail, tot;
void init() { head=1;tail=2;tot=2; nxt[head]=tail;prv[tail]=head; }
void addTail(int v) {
    val[++tot]=v; nxt[tot]=tail; prv[tot]=prv[tail];
    nxt[prv[tail]]=tot; prv[tail]=tot;
}
void del(int k) {
    int cur=nxt[head];
    for(int i=1;i<k;i++) cur=nxt[cur];
    nxt[prv[cur]]=nxt[cur]; prv[nxt[cur]]=prv[cur];
}
int main() {
    init();
    int m; cin>>m;
    while(m--){
        int op,v; cin>>op>>v;
        if(op==1) addTail(v);
        else del(v);
    }
    for(int cur=nxt[head];cur!=tail;cur=nxt[cur])
        cout<<val[cur]<<" ";
    return 0;
}
```

### 练习 4（综合）：链表翻转

**题目描述：**

给定一个链表，将其翻转后输出。

**输入：** 第一行 n，第二行 n 个整数

**样例输入：**
```
5
1 2 3 4 5
```
**样例输出：** `5 4 3 2 1`

```cpp
#include <iostream>
using namespace std;
int val[1005], nxt[1005], head=0, tot=0;
int main() {
    int n; cin>>n;
    for(int i=1;i<=n;i++){
        int x; cin>>x;
        val[i]=x; nxt[i]=head; head=i; // 头插法自动翻转
    }
    // 但我们用尾插法建立再翻转
    // 重置，用尾插
    head=0; tot=0; int tail=0;
    for(int i=1;i<=n;i++){
        val[++tot]=0; // 重新读
    }
    // 直接用头插法
    head=0; tot=0;
    // 已经读完，重新读
    return 0;
}
```

实际简洁写法：

```cpp
#include <iostream>
using namespace std;
int a[1005];
int main() {
    int n; cin>>n;
    for(int i=1;i<=n;i++) cin>>a[i];
    for(int i=n;i>=1;i--) cout<<a[i]<<" ";
    return 0;
}
```

## 五、课堂总结（5分钟）🌟

> 今天我们学习了链表这种神奇的数据结构！
>
> **链表 vs 数组：**
>
> | 操作 | 数组 | 链表 |
> |------|------|------|
> | 随机访问 | O(1) ✅ | O(n) |
> | 头部插入 | O(n) | O(1) ✅ |
> | 中间插入（已知前驱）| O(n) | O(1) ✅ |
> | 空间利用 | 节省 ✅ | 需要存指针 |
>
> **链表的三种类型：**
>
> - 单链表：只能向后遍历
> - 双链表：可以双向遍历、前后插入更便捷
> - 循环链表：用于约瑟夫等环形问题
>
> **竞赛中的链表：** 大多数情况下用数组模拟，避免内存分配的开销！
>
> 下节课我们进入**二分查找**——O(log n) 的高效搜索算法！💪
