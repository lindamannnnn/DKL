## 一、课程简介（5分钟）

### 🎯 课程目标

1. 掌握二分查找的基本思路和适用条件（有序数组）
2. 能手写二分查找元素 x 出现位置的代码

4. 掌握 C++ STL 中的二分查找函数（`lower_bound`、`upper_bound`、`binary_search`）

### 📚 核心知识点

- 二分查找的基本条件：元素有序
- 二分查找 x：闭区间写法 `[l, r]`，`while(l<=r)`
- 二分查找左边界：第一个 `≥x` 的位置
- 二分查找右边界：最后一个 `≤x` 的位置
- `lower_bound`：返回第一个 `≥x` 的位置
- `upper_bound`：返回第一个 `>x` 的位置
- 时间复杂度：O(log n)

### 2. 知识点讲解

#### 2.1 二分查找（查找元素 x）

**适用条件：** 数组已从小到大排序。

**核心思路：**

> 1. 设定左右边界 `l=1, r=n`
> 2. 计算中间位置 `mid = (l+r)/2`
> 3. 比较 `a[mid]` 与 `x`：
>    - `a[mid] == x`：找到，返回 mid
>    - `a[mid] < x`：x 在右半，`l = mid + 1`
>    - `a[mid] > x`：x 在左半，`r = mid - 1`
> 4. 重复直到 `l > r`（未找到）

**代码（闭区间 [l, r] 写法）：**

```cpp
// 在有序数组 a[1..n] 中查找 x，返回下标，不存在返回 -1
int binarySearch(int a[], int n, int x) {
    int l = 1, r = n;
    while (l <= r) {
        int mid = l + (r - l) / 2;  // 防止 l+r 溢出
        if (a[mid] == x) return mid;
        else if (a[mid] < x) l = mid + 1;
        else r = mid - 1;
    }
    return -1;  // 未找到
}
```

**推演示例（在 [10,30,45,50,100] 中查找 50）：**

> - l=1, r=5, mid=3, a[3]=45 < 50 → l=4
> - l=4, r=5, mid=4, a[4]=50 == 50 → 找到！返回4

#### 2.2 二分查找左边界

> **左边界**：第一个 `≥x` 的元素位置（即 x 在数组中首次出现的位置）。

**思路：** 找到 `a[mid]==x` 时，不立刻返回，继续向左找（`r = mid - 1`）。

```cpp
// 返回第一个 >= x 的位置，若全小于 x 则返回 n+1
int lowerBound(int a[], int n, int x) {
    int l = 1, r = n + 1;  // 右哨兵
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] >= x) r = mid;     // 包括等于，继续向左
        else l = mid + 1;
    }
    return l;  // l == r，即左边界
}
```

#### 2.3 二分查找右边界

> **右边界**：最后一个 `≤x` 的元素位置（即 x 在数组中最后出现的位置）。

```cpp
// 返回最后一个 <= x 的位置，若全大于 x 则返回 0
int upperBound(int a[], int n, int x) {
    int l = 0, r = n;  // 左哨兵
    while (l < r) {
        int mid = l + (r - l + 1) / 2;  // 注意向上取整，防止死循环
        if (a[mid] <= x) l = mid;        // 包括等于，继续向右
        else r = mid - 1;
    }
    return l;  // 最后一个 <= x 的位置
}
```

#### 2.4 STL 二分查找函数

```cpp
#include <algorithm>

// lower_bound(begin, end, x)：返回指向第一个 >= x 元素的指针
// upper_bound(begin, end, x)：返回指向第一个 >  x 元素的指针

int a[] = {0, 10, 30, 50, 50, 70};  // 下标 1..5

// 找 50 的第一次出现位置
int pos1 = lower_bound(a+1, a+6, 50) - a;  // 返回 3（下标）

// 找 50 的最后一次出现位置
int pos2 = upper_bound(a+1, a+6, 50) - a - 1;  // 返回 4（下标）

// 判断 x 是否存在
bool exist = binary_search(a+1, a+6, 50);  // true
```

> **答案：✗（错误）**

> A. 下标2，下标5  B. 下标2，下标4  C. 下标1，下标4  D. 下标2，下标6
>
> **答案：A（1-indexed：第2个=第一个3；第5个=3后面的第一个非3=7的位置）**

### 4. 进阶扩展

**二分查找变形：查找最接近 x 的值：**

```cpp
// 在有序数组 a[1..n] 中找最接近 x 的值
int findClosest(int a[], int n, int x) {
    int pos = lower_bound(a+1, a+n+1, x) - a;  // 第一个 >= x 的位置
    if (pos == 1) return a[1];
    if (pos == n + 1) return a[n];
    // 比较 pos 和 pos-1 哪个更近
    if (x - a[pos-1] <= a[pos] - x) return a[pos-1];
    else return a[pos];
}
```

### 练习 1（基础）：二分查找基本版

**题目：** 有序数组，查找 x 出现的位置（不存在输出 -1）。

**输入：** 第一行 n 和 x；第二行 n 个升序整数。

**样例输入：**
```
6 50
10 30 45 50 100 120
```
**样例输出：** `4`

```cpp
#include <iostream>
using namespace std;
int a[100005];
int main() {
    int n, x; cin >> n >> x;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int l = 1, r = n;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] == x) { cout << mid; return 0; }
        else if (a[mid] < x) l = mid + 1;
        else r = mid - 1;
    }
    cout << -1;
    return 0;
}
```

### 练习 4（综合）：最接近的学校

**题目：** 有 m 所学校，分数线各不相同（升序）。每次查询一个分数，找与该分数最接近的学校的分数线（距离最近的，如果距离相同取较小的分数线）。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
int a[100005];
int main() {
    int m, q; cin >> m >> q;
    for (int i = 1; i <= m; i++) cin >> a[i];
    while (q--) {
        int x; cin >> x;
        int pos = lower_bound(a+1, a+m+1, x) - a;
        if (pos == 1) { cout << a[1] << "\n"; continue; }
        if (pos > m) { cout << a[m] << "\n"; continue; }
        if (x - a[pos-1] <= a[pos] - x) cout << a[pos-1] << "\n";
        else cout << a[pos] << "\n";
    }
    return 0;
}
```

### 练习 5（进阶）：在二维矩阵中搜索

**题目：** n×m 的矩阵，每行从左到右升序，每行第一个元素大于上一行最后一个元素。对多次查询判断 x 是否在矩阵中。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
int a[1005][1005];
int main() {
    int n, m; cin >> n >> m;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            cin >> a[i][j];
    int q; cin >> q;
    while (q--) {
        int x; cin >> x;
        // 二分找所在行
        int lo = 1, hi = n;
        while (lo < hi) {
            int mid = (lo + hi + 1) / 2;
            if (a[mid][1] <= x) lo = mid;
            else hi = mid - 1;
        }
        int row = lo;
        // 在该行二分找 x
        bool found = binary_search(a[row]+1, a[row]+m+1, x);
        cout << (found ? "Yes" : "No") << "\n";
    }
    return 0;
}
```

## 五、课堂总结（5分钟）🌟

> 今天我们掌握了二分查找这个效率极高的搜索算法！
>
> **三种二分模式：**
>
> 🎯 **查找 x**：`while(l<=r)` + 三分支（等于/大于/小于）
>
> 📐 **左边界**：`while(l<r)` + `>=x` 时 `r=mid`（找第一个 ≥x）
>
> 📐 **右边界**：`while(l<r)` + `<=x` 时 `l=mid`（找最后一个 ≤x，需注意上取整）
>
> **STL 工具：**
> - `lower_bound`：第一个 ≥x → 首次出现位置
> - `upper_bound`：第一个 >x → 末次出现位置+1
>
> **关键：** 二分查找要求数组**有序**！时间复杂度 O(log n)，极其高效！
>
> 下节课学习**二分答案**——把二分应用到答案的搜索空间上，解决一类最优化问题！💪
