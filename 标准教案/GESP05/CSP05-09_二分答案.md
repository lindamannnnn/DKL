# CSP05-09 二分答案

## 一、课程简介（5分钟）

### 🎯 课程目标

1. 理解"二分答案"的思想：对答案空间进行二分而非对数据空间
2. 掌握二分答案的适用条件：答案具有单调性
3. 学会分析左边界、右边界的确定方法
4. 掌握设计 `check(mid)` 函数的思路

### 📚 核心知识点

- 二分答案的适用条件：答案具备单调性（满足某条件的最大/最小值）
- 答案的左右边界：确定答案的可能范围
- check(mid) 函数：判断答案为 mid 时条件是否满足
- 最大化最小值 / 最小化最大值问题的二分建模

## 二、知识回顾（10分钟）

### 👩‍🏫 教师引导

> 上节课我们学的二分查找，是在有序数组中找一个数。
>
> 今天我们要把这个思想"反过来"：**不是查找一个数，而是查找一个最优解**！
>
> 关键条件：答案具有"单调性"——满足条件的答案集合和不满足的答案集合各成一段，之间有一个分界点。

**互动复习：**

> - 问：如果我要找"最小的使得 x≥10 成立的 x"，数轴上哪些 x 满足，哪些不满足？（10, 11, 12...满足，1-9不满足）—— 这就有单调性！
> - 问：我们可以对这个数轴做什么？（二分！找到分界点）

## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> **伐木工切木头的难题：**
>
> 一片森林有 n 棵树，高度各不相同。现在来了一台锯木机，设置一个锯切高度 h：
>
> 如果树高大于 h，就锯掉高于 h 的部分；树高小于 h 则不锯。
>
> 伐木工想得到**至少 m 米**的木材，问锯切高度 h 最大是多少？
>
> **直接枚举 h**：h 从 0 到最大，逐个尝试，太慢！
>
> **发现单调性**：锯切高度 h 越大，得到的木材越少。所以存在一个分界：h = H* 以下，木材≥m；h = H*+1 以上，木材<m。
>
> **用二分找分界点 H***  —— 这就是二分答案！

### 2. 知识点讲解

#### 2.1 二分答案的框架

**三步建模：**

> 1. **确定答案范围**：答案的最小值（左边界 l）和最大值（右边界 r）
> 2. **设计 check(mid)**：判断"答案为 mid 时，条件是否满足"
> 3. **确定二分方向**：是求满足条件的**最大**还是**最小**？

**通用代码框架：**

```cpp
// 求满足条件的最大值（右边界型）
int l = left_bound, r = right_bound;
while (l < r) {
    int mid = l + (r - l + 1) / 2;  // 向上取整，防止死循环
    if (check(mid)) l = mid;          // mid 满足，答案可能更大，向右搜
    else r = mid - 1;                 // mid 不满足，向左搜
}
// 最终 l == r 就是答案

// 求满足条件的最小值（左边界型）
while (l < r) {
    int mid = l + (r - l) / 2;       // 向下取整
    if (check(mid)) r = mid;          // mid 满足，答案可能更小，向左搜
    else l = mid + 1;                 // mid 不满足，向右搜
}
```

#### 2.2 案例1：伐木工（求满足条件的最大锯切高度）

```cpp
#include <iostream>
using namespace std;

const int MAXN = 100005;
int a[MAXN], n;
long long m;

bool check(long long h) {
    long long wood = 0;
    for (int i = 1; i <= n; i++)
        if (a[i] > h) wood += a[i] - h;
    return wood >= m;  // 能得到至少 m 米木材
}

int main() {
    cin >> n >> m;
    long long maxH = 0;
    for (int i = 1; i <= n; i++) { cin >> a[i]; maxH = max(maxH, (long long)a[i]); }
    
    long long l = 0, r = maxH;
    while (l < r) {
        long long mid = l + (r - l + 1) / 2;
        if (check(mid)) l = mid;   // 能得到足够木材，锯切高度可以更高
        else r = mid - 1;          // 不够，降低锯切高度
    }
    cout << l << endl;
    return 0;
}
```

#### 2.3 案例2：愤怒的奶牛（最大化最小间距）

> **题目背景：** 有 n 个牛棚，坐标已知。将 m 头奶牛放入，使相邻奶牛间的最小距离最大。
>
> **二分答案**：二分"最小间距"的值 d。
>
> **check(d)**：贪心验证——从最左牛棚开始，每次尽量向右放，距离至少为 d，看最终能否放 m 头。

```cpp
bool check(int d, int pos[], int n, int m) {
    int cnt = 1;           // 首个牛棚放第1头
    int last = pos[1];     // 上一头奶牛的位置
    for (int i = 2; i <= n; i++) {
        if (pos[i] - last >= d) {
            cnt++;
            last = pos[i];
        }
    }
    return cnt >= m;
}
```

#### 2.4 二分答案 vs 二分查找

| 对比 | 二分查找 | 二分答案 |
|------|---------|---------|
| 搜索对象 | 数组中的某个值 | 答案空间中的最优值 |
| 判断函数 | 目标值与 a[mid] 的关系 | check(mid)：验证 mid 是否满足条件 |
| 前提 | 数组有序 | 答案具有单调性 |
| 方向 | 找确定的目标 | 找满足条件的最大/最小值 |

### 3. GESP 真题演练 ⚡

**抢答题 1（选择题）：**

> 二分答案适用于哪类问题？
>
> A. 在有序数组中查找特定元素
>
> B. 求满足某条件的最大/最小整数值，且答案具备单调性
>
> C. 任何最优化问题
>
> D. 只能用于整数答案
>
> **答案：B**

**判断题 2：**

> 二分答案中，当 check(mid) 为 true 时，一定说明 mid 是最终答案。（ ）
>
> **答案：✗（错误）**
>
> 解析：check(mid)=true 只说明 mid 可行，但根据求最大/最小的不同，还需继续二分找更优的可行答案。

**抢答题 3：**

> 伐木工问题中，check 函数验证：高度为 mid 时，能否得到至少 m 米木材。当 check(mid)=true 时，说明高度可以设为 mid，甚至可以更（高/低）？
>
> **答案：更高**（锯切更高，木材更少；我们要找最大的使得木材≥m的高度，所以满足时要继续试更高的）

### 4. 进阶扩展

**跳石头问题（最大化最小跳跃距离）：**

> 可以移走最多 m 块石头，使得跳跃中的最小距离最大化。
>
> check(d)：贪心计算至少要移走多少石头才能保证所有相邻间距 ≥ d。如果需要移走的石头数 ≤ m，则 d 可行。

## 四、课堂练习（45分钟）🎈

### 练习 1（基础）：整数平方根

**题目：** 用二分答案求 n 的整数平方根（即最大的 x 使得 x² ≤ n）。

**样例输入：** `26`  **样例输出：** `5`

```cpp
#include <iostream>
using namespace std;
int main() {
    long long n; cin >> n;
    long long l = 1, r = n;
    while (l < r) {
        long long mid = l + (r - l + 1) / 2;
        if (mid * mid <= n) l = mid;
        else r = mid - 1;
    }
    cout << l << endl;
    return 0;
}
```

### 练习 2（基础）：切绳子

**题目：** 给 n 段绳子，每段长度 a[i]，将它们切成 m 段相同长度的绳子，求最大可能的长度（整数）。

```cpp
#include <iostream>
using namespace std;
int a[100005], n, m;
bool check(int len) {
    int cnt = 0;
    for (int i = 1; i <= n; i++) cnt += a[i] / len;
    return cnt >= m;
}
int main() {
    cin >> n >> m;
    int mx = 0;
    for (int i = 1; i <= n; i++) { cin >> a[i]; mx = max(mx, a[i]); }
    int l = 1, r = mx;
    while (l < r) {
        int mid = l + (r - l + 1) / 2;
        if (check(mid)) l = mid;
        else r = mid - 1;
    }
    cout << l << endl;
    return 0;
}
```

### 练习 3（综合）：伐木工（经典）

**题目：** n 棵树，高度 h[i]，设置锯切高度 H，得到的木材 = Σmax(h[i]-H, 0)。求满足木材 ≥ m 的最大 H。

    long long l = 0, r = mx;

        if (check(mid)) l = mid;
        else r = mid - 1;
    }

    return 0;
}

### 练习 4（综合）：最大最小间距（愤怒的奶牛）

**题目：** n 个牛棚坐标（已排序），放 m 头奶牛，最大化相邻奶牛的最小间距。

**样例输入：** `5 3\n1 2 8 4 9`  **样例输出：** `3`

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
int pos[100005], n, m;
bool check(int d) {
    int cnt = 1, last = pos[1];
    for (int i = 2; i <= n; i++)
        if (pos[i] - last >= d) { cnt++; last = pos[i]; }
    return cnt >= m;
}
int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> pos[i];
    sort(pos + 1, pos + n + 1);
    int l = 1, r = pos[n] - pos[1];
    while (l < r) {
        int mid = l + (r - l + 1) / 2;
        if (check(mid)) l = mid;
        else r = mid - 1;
    }
    cout << l << endl;
    return 0;
}
```

### 练习 5（进阶）：装箱问题（最小化最大值）

**题目：** 将 n 个货物（重量 w[i]）分配给 m 个工人，每人连续一段，最小化最大单人总重。

**样例输入：** `5 3\n3 2 4 1 5`  **样例输出：** `6`（[3,2]|[4,1]|[5]）

```cpp
#include <iostream>
using namespace std;
int a[100005], n, m;
bool check(long long mid) {
    int cnt = 1; long long sum = 0;
    for (int i = 1; i <= n; i++) {
        if (sum + a[i] > mid) { cnt++; sum = a[i]; }
        else sum += a[i];
        if (a[i] > mid) return false;
    }
    return cnt <= m;
}
int main() {
    cin >> n >> m;
    long long sum = 0, mx = 0;
    for (int i = 1; i <= n; i++) { cin >> a[i]; sum += a[i]; mx = max(mx, (long long)a[i]); }
    long long l = mx, r = sum;
    while (l < r) {
        long long mid = l + (r - l) / 2;
        if (check(mid)) r = mid;
        else l = mid + 1;
    }
    cout << l << endl;
    return 0;
}
```

## 五、课堂总结（5分钟）🌟

> 今天我们把二分思想延伸到了答案空间！
>
> **二分答案核心三问：**
>
> 1️⃣ 答案的范围是多少？（确定 l 和 r）
>
> 2️⃣ check(mid) 怎么验证？（贪心/枚举都行）
>
> 3️⃣ 满足条件时往哪边走？（求最大→往右，求最小→往左）
>
> **典型题型：**
>
> - 最大化最小值：愤怒的奶牛、跳石头
> - 最小化最大值：装箱分段
> - 求满足条件的最大/最小参数值：伐木工、切绳子
>
> 下节课我们综合练习二分查找和二分答案！💪
