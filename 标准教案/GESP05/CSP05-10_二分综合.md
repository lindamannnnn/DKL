### 2. 知识点讲解

#### 2.1 二分查找左右边界综合题型

**题型：给定有序数组，回答多次区间查询**

```cpp
// 统计 [ql, qr] 范围内有多少个 x
// 思路：使用 lower_bound 和 upper_bound 的差

int a[MAXN];  // sorted
// x 出现的次数
int count = upper_bound(a+1, a+n+1, x) - lower_bound(a+1, a+n+1, x);
// x 出现的起始位置（1-indexed）
int start = lower_bound(a+1, a+n+1, x) - a;
// x 出现的结束位置（1-indexed）
int end = upper_bound(a+1, a+n+1, x) - a - 1;
```

#### 2.2 二分答案综合题型汇总

**最大化最小值（间距、距离类）**

> 关键词：相邻两者的最小值尽量大
>
> check(d)：贪心放置，验证是否可行
>
> 框架：向上取整 mid，满足时 l=mid，不满足时 r=mid-1

**最小化最大值（负载均衡、分段类）**

> 关键词：各部分的最大值尽量小
>
> check(mid)：贪心分配，验证是否可行
>
> 框架：向下取整 mid，满足时 r=mid，不满足时 l=mid+1

**参数化最大/最小（伐木工、切绳子类）**

> 关键词：某参数值越大/越小，条件越容易/越难满足
>
> check(mid)：直接计算该参数下的结果

#### 2.3 二分答案中 check 函数的设计技巧

> **贪心策略**：在验证 `mid` 是否可行时，通常用贪心（最优策略）来验证。
>
> 如果贪心后都不满足，说明 mid 确实不可行。

## 四、课堂练习（45分钟）🎈

### 练习 1（基础）：区间中某值出现次数

**题目：** n 个升序整数，q 次询问，每次问 x 在数组中出现几次。

**样例输入：** `6 3\n1 2 3 3 3 5\n3\n5\n4`  **样例输出：** `3\n1\n0`

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
int a[100005];
int main() {
    int n, q; cin >> n >> q;
    for (int i = 1; i <= n; i++) cin >> a[i];
    while (q--) {
        int x; cin >> x;
        int cnt = upper_bound(a+1,a+n+1,x) - lower_bound(a+1,a+n+1,x);
        cout << cnt << "\n";
    }
    return 0;
}
```

---

### 练习 2（基础）：在有序数组中找最接近的值

**题目：** n 个升序整数，q 次询问，每次找与 x 最接近的值（距离相同取较小）。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
int a[100005];
int main() {
    int n, q; cin >> n >> q;
    for (int i = 1; i <= n; i++) cin >> a[i];
    while (q--) {
        int x; cin >> x;
        int pos = lower_bound(a+1, a+n+1, x) - a;
        if (pos == 1) { cout << a[1] << "\n"; continue; }
        if (pos > n) { cout << a[n] << "\n"; continue; }
        if (x - a[pos-1] <= a[pos] - x) cout << a[pos-1] << "\n";
        else cout << a[pos] << "\n";
    }
    return 0;
}
```

### 练习 3（综合）：最长切绳段数

**题目：** n 段绳子长度各不同，将所有绳子切成相同长度的小段，最多能切多少段？（整数长度，每段长度至少1）

```cpp
#include <iostream>
using namespace std;
long long a[100005], n;
bool check(long long len) {
    long long cnt = 0;
    for (int i = 1; i <= n; i++) cnt += a[i] / len;
    return cnt > 0;  // 至少能切1段
}
int main() {
    cin >> n;
    long long mx = 0;
    for (int i = 1; i <= n; i++) { cin >> a[i]; mx = max(mx, a[i]); }
    // 找最大长度使得cnt >= 某个预设值
    // 简化：直接枚举check所有可能
    long long l = 1, r = mx, ans = 1;
    while (l <= r) {
        long long mid = l + (r - l) / 2;
        long long cnt = 0;
        for (int i = 1; i <= n; i++) cnt += a[i] / mid;
        if (cnt >= 1) { ans = mid; l = mid + 1; }
        else r = mid - 1;
    }
    long long best = 0;
    for (int i = 1; i <= n; i++) best += a[i] / ans;
    cout << best << endl;
    return 0;
}
```

**样例输入：** `6 2\n1 2 3 4 5 6`  **样例输出：** `0`（[1,2,3]=[6]，差=0为最优情况示例，视数据而定）

### 练习 5（进阶）：矩形中第 K 小

**题目：** n×n 乘法表（a[i][j]=i×j），找第 k 小的数（n≤500，k≤n²）。

```cpp
#include <iostream>
using namespace std;
long long n, k;
bool check(long long mid) {
    long long cnt = 0;
    for (int i = 1; i <= n; i++)
        cnt += min((long long)n, mid / i);
    return cnt >= k;
}
int main() {
    cin >> n >> k;
    long long l = 1, r = n * n;
    while (l < r) {
        long long mid = l + (r - l) / 2;
        if (check(mid)) r = mid;
        else l = mid + 1;
    }
    cout << l << endl;
    return 0;
}
```
