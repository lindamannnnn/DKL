### 2. 知识点讲解

#### 2.1 大整数的存储方式

**为什么倒序存储（个位在 a[1]）？**

> 因为加法/减法运算是从**低位**（个位）开始的，倒序存储后，`a[1]` 是个位，`a[2]` 是十位，处理进位/借位只需 `a[i+1]`，无需考虑数组边界问题。

**从字符串读入并存储：**

```cpp
#include <iostream>
#include <cstring>
using namespace std;

const int MAXN = 1005;
int a[MAXN], len_a;

void readNum(int a[], int &len, const string &s) {
    len = s.size();
    for (int i = 1; i <= len; i++) {
        a[i] = s[len - i] - '0';  // 倒序：个位存在 a[1]
    }
}

void printNum(int a[], int len) {
    if (len == 0) { cout << 0; return; }
    for (int i = len; i >= 1; i--) cout << a[i];
}
```

**示例：** 字符串 `"12345"` → `a[1]=5, a[2]=4, a[3]=3, a[4]=2, a[5]=1`

#### 2.2 高精度加法

**竖式计算模拟：**

> 从低位到高位逐位相加，处理进位（carry）。
>
> ```
> 结果位 = (a[i] + b[i] + carry) % 10
> 新进位 = (a[i] + b[i] + carry) / 10
> ```

```cpp
// 计算 a + b，结果存入 c，len_c 为结果位数
// 前提：a, b 已倒序存储，len_a, len_b 为位数
void bigAdd(int a[], int la, int b[], int lb, int c[], int &lc) {
    lc = max(la, lb);
    int carry = 0;
    for (int i = 1; i <= lc; i++) {
        int sum = a[i] + b[i] + carry;
        c[i] = sum % 10;
        carry = sum / 10;
    }
    if (carry) c[++lc] = carry;  // 最高位进位
}
```

**推演示例（999 + 1）：**

> - i=1：9+1+0=10，c[1]=0，carry=1
> - i=2：9+0+1=10，c[2]=0，carry=1
> - i=3：9+0+1=10，c[3]=0，carry=1
> - 最终 carry=1，c[4]=1
> - 结果：c = [0, 0, 0, 1]，即 "1000" ✓

#### 2.3 高精度减法

**步骤：**

> 1. 先比较大小（位数多的大，位数相同从高位比）
> 2. 始终用大数减小数（若 a<b，先算 b-a，再在结果前加负号）
> 3. 从低位到高位逐位相减，处理借位

**比较大小：**

```cpp
// 若 a >= b 返回 true
bool bigGE(int a[], int la, int b[], int lb) {
    if (la != lb) return la > lb;
    for (int i = la; i >= 1; i--)
        if (a[i] != b[i]) return a[i] > b[i];
    return true;  // 相等
}
```

**高精度减法（保证 a >= b）：**

```cpp
void bigSub(int a[], int la, int b[], int lb, int c[], int &lc) {
    lc = la;
    int borrow = 0;  // 借位
    for (int i = 1; i <= lc; i++) {
        int diff = a[i] - b[i] - borrow;
        if (diff < 0) { diff += 10; borrow = 1; }
        else borrow = 0;
        c[i] = diff;
    }
    // 去除前导零
    while (lc > 1 && c[lc] == 0) lc--;
}
```

**推演示例（1000 - 1）：**

> - i=1：0-1-0=-1，加10=9，borrow=1，c[1]=9
> - i=2：0-0-1=-1，加10=9，borrow=1，c[2]=9
> - i=3：0-0-1=-1，加10=9，borrow=1，c[3]=9
> - i=4：1-0-1=0，borrow=0，c[4]=0
> - 去前导零：lc 从 4 变为 3
> - 结果："999" ✓

> 高精度加减中，为什么要将大整数**倒序**存入数组？

### 4. 进阶扩展

**完整的高精度大数类（结构体版）：**

```cpp
struct BigInt {
    static const int MAXN = 1005;
    int a[MAXN], len;
    
    BigInt() : len(0) { memset(a, 0, sizeof(a)); }
    BigInt(const string& s) {
        len = s.size();
        for (int i = 1; i <= len; i++) a[i] = s[len-i] - '0';
    }
    
    bool operator>=(const BigInt& b) const {
        if (len != b.len) return len > b.len;
        for (int i = len; i >= 1; i--)
            if (a[i] != b.a[i]) return a[i] > b.a[i];
        return true;
    }
    
    BigInt operator+(const BigInt& b) const {
        BigInt c;
        c.len = max(len, b.len);
        int carry = 0;
        for (int i = 1; i <= c.len; i++) {
            int s = a[i] + b.a[i] + carry;
            c.a[i] = s % 10; carry = s / 10;
        }
        if (carry) c.a[++c.len] = carry;
        return c;
    }
    
    BigInt operator-(const BigInt& b) const {  // 保证 *this >= b
        BigInt c;
        c.len = len;
        int borrow = 0;
        for (int i = 1; i <= c.len; i++) {
            int d = a[i] - b.a[i] - borrow;
            if (d < 0) { d += 10; borrow = 1; } else borrow = 0;
            c.a[i] = d;
        }
        while (c.len > 1 && c.a[c.len] == 0) c.len--;
        return c;
    }
    
    void print() const {
        if (len == 0) { cout << 0; return; }
        for (int i = len; i >= 1; i--) cout << a[i];
    }
};
```

#include <iostream>

int a[1005], b[1005], c[1005];
int la, lb, lc;
bool ge() {
    if (la != lb) return la > lb;
    for (int i = la; i >= 1; i--) if (a[i]!=b[i]) return a[i]>b[i];

}
void sub(int x[], int lx, int y[], int ly) {
    lc = lx;
    int borrow = 0;
    for (int i = 1; i <= lc; i++) {

### 练习 3（综合）：斐波那契大数

**题目：** 计算第 n 个斐波那契数（n ≤ 200，结果超出 long long 范围）。

            c.a[i]=s%10; carry=s/10;

        return c;

### 练习 4（综合）：高精度累加

**题目：** 计算 1 + 2 + ... + n 的精确值（n ≤ 10000，结果可能超 long long）。

**样例输入：** `100`  **样例输出：** `5050`

```cpp
// 每次加一个数（高精度加普通数的简化版）
#include <iostream>
using namespace std;
int c[100005], lc = 0;
void add(int x) {
    int carry = x;
    for (int i = 1; i <= lc || carry; i++) {
        c[i] += carry;
        carry = c[i] / 10;
        c[i] %= 10;
        if (i > lc) lc = i;
    }
}
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) add(i);
    for (int i = lc; i >= 1; i--) cout << c[i];
    return 0;
}
```

## 五、课堂总结（5分钟）🌟

> 今天我们实现了大整数的加减法！
>
> **核心步骤（加法）：**
>
> 1️⃣ 用字符串读入，倒序存到数组（个位在 a[1]）
>
> 2️⃣ 从低位到高位：`sum = a[i]+b[i]+carry`，`c[i]=sum%10`，`carry=sum/10`
>
> 3️⃣ 最终 carry > 0 则 `c[++lc] = carry`
>
> **核心步骤（减法）：**
>
> 1️⃣ 先判断大小，保证大减小
>
> 2️⃣ 从低位到高位：有借位则 `d += 10; borrow=1`
>
> 3️⃣ 去除前导零：`while(lc>1 && c[lc]==0) lc--`
>
> 下节课学习**高精度乘法和除法**，挑战更高难度！💪
