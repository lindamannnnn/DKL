## 一、课程简介（5分钟）

1. 掌握高精度乘法（大整数 × 普通整数）的实现

3. 能组合运用高精度加减乘除解决实际问题

### 📚 核心知识点

- 高精度乘法：大整数 × 普通整数（每位乘以单个整数，处理进位）
- 高精度除法：大整数 ÷ 普通整数（从高位到低位商，处理余数）
- 大整数 × 大整数（进阶）：双重循环，每位相乘累加

### 2. 知识点讲解

#### 2.1 高精度 × 普通整数（最常用！）

**竖式模拟：**

> 每一位 `a[i]` 乘以 `k`，加上前一位的进位，得到 `a[i]*k + carry`
> - 当前位结果：`(a[i]*k + carry) % 10`
> - 进位：`(a[i]*k + carry) / 10`

```cpp
// 计算 a × k，结果存入 c，le_c 为位数
// a 已倒序存储，la 为位数，k 为普通正整数
void bigMulInt(int a[], int la, int k, int c[], int &lc) {
    lc = la;
    int carry = 0;
    for (int i = 1; i <= la; i++) {
        int prod = a[i] * k + carry;
        c[i] = prod % 10;
        carry = prod / 10;
    }
    while (carry) {       // 处理高位进位
        c[++lc] = carry % 10;
        carry /= 10;
    }
    // 去除前导零（乘以0的特殊情况）
    while (lc > 1 && c[lc] == 0) lc--;
}
```

**推演示例（99 × 12）：**

> - i=1：9×12+0=108，c[1]=8，carry=10（注意这里carry可能超过9！）
> - i=2：9×12+10=118，c[2]=8，carry=11
> - 处理剩余carry：11%10=1，c[3]=1；1/10=0，carry=0
> - 结果：c=[8,8,1] → "188"（99×12=1188？不对！）
>
> 等等，让我重新计算：实际上 99×12=1188
> - i=1（个位9×12=108）：c[1]=8,carry=10
> - i=2（十位9×12+10=118）：c[2]=8,carry=11
> - 继续处理进位：11→c[3]=1,carry=1→c[4]=1
> - 结果"1188" ✓

#### 2.2 高精度 ÷ 普通整数

**从高位到低位逐位处理：**

> 从最高位开始，每一位的处理：
> - `当前位的值 = 上一步余数 * 10 + a[i]`（从高位到低位迭代）
> - `商的当前位 = 当前位的值 / k`
> - `余数 = 当前位的值 % k`

```cpp
// 计算 a ÷ k，商存入 c，remain 为余数
void bigDivInt(int a[], int la, int k, int c[], int &lc, int &remain) {
    lc = la;
    remain = 0;
    for (int i = la; i >= 1; i--) {  // 从高位到低位
        long long cur = (long long)remain * 10 + a[i];
        c[i] = cur / k;
        remain = cur % k;
    }
    // 去除前导零
    while (lc > 1 && c[lc] == 0) lc--;
}
```

**推演示例（1188 ÷ 12）：**

> a = [8, 8, 1, 1]（倒序），la=4，k=12
>
> - i=4（最高位1）：cur=0*10+1=1，c[4]=0，remain=1
> - i=3（次高位1）：cur=1*10+1=11，c[3]=0，remain=11
> - i=2（十位8）：cur=11*10+8=118，c[2]=9，remain=10
> - i=1（个位8）：cur=10*10+8=108，c[1]=9，remain=0
> - c=[9,9,0,0]，去前导零后 lc=2，结果 "99" ✓

#### 2.3 大整数 × 大整数（进阶）

**核心思路：** a 的第 i 位 × b 的第 j 位 → 结果的第 (i+j-1) 位！

```cpp
void bigMul(int a[], int la, int b[], int lb, int c[], int &lc) {
    lc = la + lb;  // 乘积最多 la+lb 位
    for (int i = 1; i <= la; i++) {
        for (int j = 1; j <= lb; j++) {
            c[i+j-1] += a[i] * b[j];  // 累积到对应位
        }
    }
    // 统一处理进位
    for (int i = 1; i < lc; i++) {
        c[i+1] += c[i] / 10;
        c[i] %= 10;
    }
    while (lc > 1 && c[lc] == 0) lc--;
}
```

### 4. 进阶扩展

**n! 的计算（高精度乘普通整数的综合应用）：**

```cpp
#include <iostream>
using namespace std;
const int MAXN = 10005;
int c[MAXN], lc;

void mulInt(int k) {
    int carry = 0;
    for (int i = 1; i <= lc; i++) {
        long long prod = (long long)c[i] * k + carry;
        c[i] = prod % 10;
        carry = prod / 10;
    }
    while (carry) { c[++lc] = carry % 10; carry /= 10; }
}

int main() {
    int n; cin >> n;
    c[1] = 1; lc = 1;  // 初始为 1
    for (int i = 2; i <= n; i++) mulInt(i);
    for (int i = lc; i >= 1; i--) cout << c[i];
    return 0;
}
```

## 五、课堂总结（5分钟）🌟

> 今天我们完成了高精度四则运算的学习！
>
> **高精度乘法（×普通整数）：**
>
> 从低位到高位：`prod = a[i]*k + carry`，`c[i]=prod%10`，`carry=prod/10`
>
> 最后继续处理 carry 直到为0
>
> **高精度除法（÷普通整数）：**
>
> 从高位到低位：`cur = remain*10 + a[i]`，`c[i]=cur/k`，`remain=cur%k`
>
> **大数×大数：** `c[i+j-1] += a[i]*b[j]`，最后统一处理进位
>
> **经典应用：** n! 的精确计算、大数幂次、高精度分数
>
> 接下来进入贪心算法的学习！💪
