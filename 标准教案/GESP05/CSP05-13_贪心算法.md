## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> **超市打折的贪心策略：**
>
> 超市促销：买任意商品，但最贵的一件半价。你有 n 件想买的商品，每件只需买一次，可以使用多次优惠（每次选3件，最贵的半价）。
>
> 问：怎样选择使总花费最少？
>
> 贪心策略：把所有商品按价格排序，每次选最贵的 3 件（最贵的半价，另两件全价）！
>
> 为什么这样最优？因为让最贵的每次都享受半价，节省最多！
>
> 这就是贪心——**每次让收益最大化的局部决策**。

### 2. 知识点讲解

#### 2.1 贪心算法的概念

> **贪心算法（Greedy Algorithm）：** 在每一步决策中，都选择当前状态下的最优解（局部最优），期望通过局部最优的累积达到全局最优。

**贪心的"两大条件"（满足才能用贪心！）：**

> 1. **贪心选择性质：** 每次局部最优选择，不会影响后续问题的结构，即局部选择不回头。
>
> 2. **最优子结构：** 问题的最优解包含子问题的最优解。

**贪心 vs 动态规划：**

| 对比 | 贪心 | 动态规划 |
|------|------|---------|
| 每步决策 | 一次选定不撤销 | 考虑所有可能 |
| 复杂度 | 一般更低 | 较高 |
| 适用条件 | 局部最优→全局最优 | 全局最优（有重叠子问题）|
| 验证方式 | 找反例 | 状态转移方程 |

#### 2.2 经典贪心问题1：活动选择问题

**问题：** n 个活动，每个活动有开始时间和结束时间。同一时刻最多参加一个活动，最多能参加几个？

**贪心策略：** 每次选结束时间最早的活动（不与已选冲突的）！

> 为什么有效？结束最早的活动，给后续活动留下最多时间！

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Activity {
    int start, end;
};

bool cmp(Activity a, Activity b) {
    return a.end < b.end;  // 按结束时间升序排序
}

int main() {
    int n; cin >> n;
    Activity act[1005];
    for (int i = 0; i < n; i++) cin >> act[i].start >> act[i].end;
    sort(act, act + n, cmp);
    
    int cnt = 1, lastEnd = act[0].end;  // 选第一个活动
    for (int i = 1; i < n; i++) {
        if (act[i].start >= lastEnd) {  // 不冲突则选
            cnt++;
            lastEnd = act[i].end;
        }
    }
    cout << cnt << endl;
    return 0;
}
```

#### 2.3 经典贪心问题2：零钱兑换

**问题：** 给定若干面值的硬币（1, 5, 10, 20, 50, 100），用最少硬币数凑出金额 n。

**贪心策略：** 总是选当前可用的最大面值！

> ⚠️ 注意：贪心并非在所有面值下都正确！例如面值{1, 3, 4}时，凑6：贪心选4+1+1=3枚，但最优是3+3=2枚。**贪心只在特定面值（如上面的标准硬币）下正确！**

```cpp
int coins[] = {100, 50, 20, 10, 5, 1};
int greedy(int n) {
    int cnt = 0;
    for (int i = 0; i < 6; i++) {
        cnt += n / coins[i];
        n %= coins[i];
    }
    return cnt;
}
```

#### 2.4 经典贪心问题3：区间覆盖

**问题：** 数轴上有 n 个区间 [l_i, r_i]，选最少数量的区间完全覆盖 [L, R]。

**贪心策略：** 每次选起点不超过当前覆盖右端的、终点最远的区间！

```cpp
sort(intervals, intervals + n, cmpByStart);
int coverage = L, cnt = 0;
while (coverage < R) {
    int farthest = coverage;
    for (int i = 0; i < n && intervals[i].l <= coverage; i++)
        farthest = max(farthest, intervals[i].r);
    if (farthest == coverage) { /* 无法继续覆盖，失败 */ break; }
    coverage = farthest;
    cnt++;
}
```

### 4. 进阶扩展

**霍夫曼编码（最优前缀码）的贪心构造：**

> 思路：把所有字符的频率放入优先队列（最小堆），每次取两个最小频率合并成新节点，直到只剩一个节点。这棵树就是最优霍夫曼树！
>
> 这是经典的贪心算法，每次合并最小的两个可以最小化总编码长度。

### 练习 1（基础）：硬币找零

**题目：** 面值 1, 5, 10, 50, 100 的硬币，最少硬币数凑 n 元。

**样例输入：** `376`  **样例输出：** `8`（100×3+50×1+20×1+5×1+1×1→但面值只有1,5,10,50,100，所以100×3+50×1+10×2+5×1+1×1=8枚）

```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    int coins[] = {100, 50, 10, 5, 1};
    int cnt = 0;
    for (int i = 0; i < 5; i++) { cnt += n/coins[i]; n %= coins[i]; }
    cout << cnt << endl;
    return 0;
}
```

### 练习 2（基础）：最多活动数

**题目：** n 个活动有开始和结束时间，求最多同时参加（互不重叠）的活动数。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
struct Act { int s, e; };
bool cmp(Act a, Act b) { return a.e < b.e; }
Act act[1005];
int main() {
    int n; cin>>n;
    for(int i=0;i<n;i++) cin>>act[i].s>>act[i].e;
    sort(act,act+n,cmp);
    int cnt=1, last=act[0].e;
    for(int i=1;i<n;i++)
        if(act[i].s>=last){ cnt++; last=act[i].e; }
    cout<<cnt<<endl;
    return 0;
}
```

### 练习 4（综合）：任务调度（最小完成时间和）

**题目：** n 个任务，单台机器，执行第 i 个任务需要 t[i] 时间。问如何安排顺序使所有任务完成时间之和最小？

**贪心策略：** 按执行时间从小到大排序！

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
int t[1005];
int main() {
    int n; cin>>n;
    for(int i=0;i<n;i++) cin>>t[i];
    sort(t,t+n);
    long long total=0, cur=0;
    for(int i=0;i<n;i++){cur+=t[i];total+=cur;}
    cout<<total<<endl;
    return 0;
}
```

### 练习 5（进阶）：装水问题

**题目：** n 个容器，高度 h[i]，宽度均为1，选任意两个容器作两端，中间装水量 = min(h[i],h[j]) × (j-i)。求最大装水量。

**贪心（双指针）策略：** 两端向中间收缩，每次移动较短的那端。

```cpp
#include <iostream>
using namespace std;
int h[100005];
int main(){
    int n; cin>>n;
    for(int i=1;i<=n;i++) cin>>h[i];
    int l=1,r=n; long long ans=0;
    while(l<r){
        ans=max(ans,(long long)min(h[l],h[r])*(r-l));
        if(h[l]<h[r]) l++; else r--;
    }
    cout<<ans<<endl;
    return 0;
}
```
