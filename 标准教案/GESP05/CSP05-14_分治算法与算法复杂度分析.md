### 2. 知识点讲解

#### 2.1 算法复杂度回顾与含多项式复杂度

| 复杂度 | 算法示例 | n=10^4 时操作次数 |
|--------|---------|----------------|
| O(n) | 线性扫描 | 10^4 |
| O(n log n) | 归并排序 | 约 14万（快！）|
| O(n²) | 冒泡排序 | 10^8 （可能超时）|
| O(n³) | 三重循环 | 10^12（严重超时）|
| O(2^n) | 全枚举子集 | 天文数字 |

**多项式复杂度的计算：**

> 两重循环 → O(n²)
>
> 三重循环 → O(n³)
>
> k 重循环 → O(n^k)
>
> 但有些双重循环可能不是 O(n²)，要看内外层是否都与 n 有关！

#### 2.2 含对数复杂度

**O(log n)：** 每次问题规模减半（如二分查找）

**O(n log n)：** 执行 n 次 O(log n) 操作（如堆排序、归并排序）

> 为什么归并排序是 O(n log n)？
>
> 每次将数组一分为二，共分 log n 层；每层合并操作总共 O(n)；
>
> 总时间 = O(n) × log n 层 = O(n log n)！

#### 2.3 归并排序

**思路（分治三步）：**

> 1. **Divide**：将数组的中间位置一分为二
> 2. **Conquer**：递归排序左半和右半
> 3. **Combine**：将两个有序的半数组合并为一个有序数组

```cpp
#include <iostream>
using namespace std;

int a[100005], tmp[100005];

void merge(int l, int mid, int r) {
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else tmp[k++] = a[j++];
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int x = l; x <= r; x++) a[x] = tmp[x];
}

void mergeSort(int l, int r) {
    if (l >= r) return;           // 边界：只有一个元素
    int mid = (l + r) / 2;
    mergeSort(l, mid);            // 分治左半
    mergeSort(mid + 1, r);        // 分治右半
    merge(l, mid, r);             // 合并
}

int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    mergeSort(1, n);
    for (int i = 1; i <= n; i++) cout << a[i] << " ";
    return 0;
}
```

#### 2.4 快速排序

**思路：**

> 1. 选一个**基准元素**（pivot）
> 2. **划分**：将数组分成"≤pivot"和">pivot"两部分
> 3. **递归**：对两部分分别快速排序

```cpp
void qsort(int l, int r) {
    if (l >= r) return;
    int pivot = a[(l + r) / 2];  // 选中间元素为基准
    int i = l - 1, j = r + 1;
    while (i < j) {
        do i++; while (a[i] < pivot);
        do j--; while (a[j] > pivot);
        if (i < j) swap(a[i], a[j]);
    }
    qsort(l, j);
    qsort(j + 1, r);
}
```

**归并 vs 快速排序对比：**

| 对比 | 归并排序 | 快速排序 |
|------|---------|---------|
| 时间复杂度 | O(n log n)（最坏保证）| O(n log n)期望，O(n²)最坏 |
| 空间复杂度 | O(n)（需临时数组）| O(log n)（递归栈）|
| 稳定性 | ✅ 稳定 | ❌ 不稳定 |
| 实践速度 | 稍慢（常数大）| 实际更快（缓存友好）|

**逆序对计数（归并排序应用）：**

> 在归并时，如果右半的 a[j] 先被放入结果（说明 a[j] < a[i] 且 j > i），则 (i...mid) 中的所有元素都与 a[j] 构成逆序对！贡献 `mid - i + 1` 个逆序对。

### 练习 3（综合）：逆序对计数（归并排序应用）

**题目：** 给定 n 个整数，统计逆序对数量（i<j 但 a[i]>a[j]）。

```cpp
long long cnt = 0;
void merge(int l, int mid, int r) {
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else { tmp[k++] = a[j++]; cnt += mid - i + 1; }  // 关键！
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int x = l; x <= r; x++) a[x] = tmp[x];
}
```

### 练习 4（综合）：最大子数组（分治版）

**题目：** 求数组中和最大的连续子数组。分治思路：最大子数组要么在左半、右半，要么跨越中间。

```cpp
long long maxSubArray(int l, int r) {
    if (l == r) return a[l];
    int mid = (l + r) / 2;
    long long leftMax = maxSubArray(l, mid);
    long long rightMax = maxSubArray(mid + 1, r);
    // 计算跨中间的最大子数组
    long long ls = a[mid], s = a[mid];
    for (int i = mid - 1; i >= l; i--) { s += a[i]; ls = max(ls, s); }
    long long rs = a[mid+1]; s = a[mid+1];
    for (int i = mid + 2; i <= r; i++) { s += a[i]; rs = max(rs, s); }
    return max({leftMax, rightMax, ls + rs});
}
```

### 练习 5（进阶）：复杂度估算

给定以下代码，估算其时间复杂度：

```cpp
for (int i = 1; i <= n; i++) {
    for (int j = i; j <= n; j += i) {
        // O(1) 操作
    }
}
```

**答案：O(n log n)（调和级数：n/1 + n/2 + n/3 + ... ≈ n×ln(n)）**

## 五、课堂总结（5分钟）🌟

> **分治三步：**
>
> 📦 Divide：把问题分成两半
>
> ⚔️ Conquer：递归解决每一半
>
> 🧩 Combine：把两个解合并
>
> **复杂度总结：**
>
> - 归并排序：O(n log n)，稳定，需要 O(n) 额外空间
> - 快速排序：期望 O(n log n)，原地，实践更快
>
