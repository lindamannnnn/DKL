## 三、新知讲解（45分钟）

### 1. 分治应用1：快速幂

**问题：** 计算 a^n % mod（n 可能很大）

**分治思路：**

> - a^n = a^(n/2) × a^(n/2)（n 为偶数）
> - a^n = a^(n/2) × a^(n/2) × a（n 为奇数）
> - 边界：a^0 = 1

```cpp
long long quickPow(long long a, long long n, long long mod) {
    if (n == 0) return 1;
    long long half = quickPow(a, n / 2, mod);
    long long result = half * half % mod;
    if (n % 2 == 1) result = result * a % mod;
    return result;
}
```

**时间复杂度：** O(log n)（每次问题规模减半）

### 2. 分治应用2：逆序对统计

在归并排序的合并步骤中统计逆序对：

```cpp
long long cnt = 0;
void merge(int l, int mid, int r) {
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else {
            tmp[k++] = a[j++];
            cnt += mid - i + 1;  // 右边的 a[j] < 左边的 a[i..mid]，产生逆序对
        }
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int x = l; x <= r; x++) a[x] = tmp[x];
}
```

### 3. 分治应用3：最大子段和（分治版）

```cpp
long long maxCross(int l, int mid, int r) {
    long long ls = LLONG_MIN, s = 0;
    for (int i = mid; i >= l; i--) { s += a[i]; ls = max(ls, s); }
    long long rs = LLONG_MIN; s = 0;
    for (int i = mid + 1; i <= r; i++) { s += a[i]; rs = max(rs, s); }
    return ls + rs;
}

long long maxSub(int l, int r) {
    if (l == r) return a[l];
    int mid = (l + r) / 2;
    return max({maxSub(l, mid), maxSub(mid + 1, r), maxCross(l, mid, r)});
}
```

### 练习 1（基础）：快速幂

**题目：** 计算 a^n % mod，n 可达 10^18。

**样例输入：** `2 10 1000`  **样例输出：** `24`

```cpp
#include <iostream>
using namespace std;
long long quickPow(long long a, long long n, long long mod) {
    a %= mod; long long r = 1;
    while (n > 0) {
        if (n & 1) r = r * a % mod;
        a = a * a % mod;
        n >>= 1;
    }
    return r;
}
int main() {
    long long a, n, mod; cin >> a >> n >> mod;
    cout << quickPow(a, n, mod) << endl;
    return 0;
}
```

### 练习 4（综合）：分治求数组最大值和最小值

**题目：** 用分治法（只用一次递归）同时找数组最大值和最小值，比较次数尽量少。

```cpp
pair<int,int> minmax(int l, int r) {
    if (l == r) return {a[l], a[l]};
    int mid = (l + r) / 2;
    auto [lMin, lMax] = minmax(l, mid);
    auto [rMin, rMax] = minmax(mid + 1, r);
    return {min(lMin, rMin), max(lMax, rMax)};
}
```

// 一维最近点对：排序后相邻元素之差的最小值

sort(x, x+n);
for(int i=1;i<n;i++) minDist=min(minDist,x[i]-x[i-1]);
