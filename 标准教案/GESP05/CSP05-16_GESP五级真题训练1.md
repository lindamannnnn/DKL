## 三、真题训练（75分钟）

### 📝 选择题（30分）

**第1题：**

> 关于递归函数，说法正确的是（ ）
>
> A. 递归函数可以没有边界条件
>
> B. 递归函数在执行时使用调用栈保存现场
>
> C. 递归函数的效率一定比循环高
>
> D. 每次递归调用时，递归深度必须减小
>
> **答案：B**  解析：A错，无边界会栈溢出；B正确；C错，递归有额外开销；D错，递归深度不一定单调减小（如相互递归）。

**第2题：**

> 有序数组 a = {2, 4, 6, 8, 10}（1-indexed），对 x=6 进行二分查找，第一次mid=3，a[3]=6，返回3。那么 `lower_bound(a+1, a+6, 5)` 返回的指针指向的元素是？
>
> A. a[2]=4  B. a[3]=6  C. a[4]=8  D. a[5]=10
>
> **答案：B（6是第一个≥5的元素）**

**第3题：**

> 执行以下代码后输出是（ ）
>
> ```cpp
> int f(int n) {
>     if (n == 0) return 0;
>     return f(n/2) + n%2;
> }
> cout << f(13);
> ```
>
> A. 0  B. 1  C. 2  D. 3
>
> **答案：D（3，这个函数计算13的二进制中1的个数，13=1101，有3个1）**

**第4题：**

> GCD(72, 48) 的值是（ ）
>
> A. 12  B. 24  C. 48  D. 6
>
> **答案：B（24）**  解析：72=24×3，48=24×2，GCD=24。

**第5题：**

> 埃氏筛法筛出 1 到 n 内所有质数，内层循环从 i*i 开始的原因是（ ）
>
> A. 节省时间，避免重复筛已被更小质数筛过的数
>
> B. i×i 是 i 的第一个因数
>
> C. 只需筛到 n 的平方根
>
> D. 这是固定规则，没有特别原因
>
> **答案：A**

**第6题：**

> 对单链表进行以下操作的时间复杂度，说法正确的是（ ）
>
> A. 访问第 i 个节点：O(1)
>
> B. 在已知前驱节点后插入一个新节点：O(1)
>
> C. 删除已知节点（不知道前驱）：O(1)
>
> D. 在任意位置插入节点：O(1)
>
> **答案：B**

### 💻 编程题（60分）

#### 编程题1（30分）：最大公约数链

**题目描述：**

给定 n 个正整数 a[1], a[2], ..., a[n]，求所有相邻两数的最大公约数之和。即 GCD(a[1],a[2]) + GCD(a[2],a[3]) + ... + GCD(a[n-1],a[n])。

**输入格式：**
- 第一行整数 n（2 ≤ n ≤ 1000）
- 第二行 n 个正整数（每个不超过 10^6）

**输出格式：**
- 一个整数，即所有相邻 GCD 之和

**样例输入：**
```
5
12 18 6 24 9
```
**样例输出：**
```
21
```
（GCD(12,18)+GCD(18,6)+GCD(6,24)+GCD(24,9) = 6+6+6+3 = 21）

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int a[1005];
int gcd(int a, int b) { return b ? gcd(b, a%b) : a; }
int main() {
    int n; cin >> n;
    for(int i=1;i<=n;i++) cin>>a[i];
    long long ans=0;
    for(int i=1;i<n;i++) ans+=gcd(a[i],a[i+1]);
    cout<<ans<<endl;
    return 0;
}
```

#### 编程题2（30分）：二分查找统计

**题目描述：**

给定有序数组（升序），对每次询问，输出区间 [ql, qr] 内有多少个不同的值，以及每个值出现的次数（只输出各不同值和其次数）。

**输入格式：**
- 第一行 n（1≤n≤10^5）和 q 次询问
- 第二行 n 个升序整数
- 接下来 q 行，每行 ql qr（下标1-indexed）

**输出格式：**
- 每次询问独立输出（每个值及其次数，按值升序）

**参考思路：**

用 lower_bound 和 upper_bound 配合找每个不同值的起止位置。
