### 💻 编程题（60分）

#### 编程题1（30分）：跳跳游戏

**题目描述：**

有 n 块石头，坐标 p[1] < p[2] < ... < p[n]。青蛙从石头 1 出发，想到达石头 n。每次只能向前跳，跳跃距离最大为 d。

但可以移走最多 m 块石头（不能移走第 1 块和第 n 块），使得青蛙能够到达终点。

求青蛙在剩余石头上，最小跳跃距离的最大值。

**输入格式：**
- 第一行：终点坐标 L，石头数量 n，可移走数量 m
- 接下来 n+2 行：n+2 个石头坐标（包括起点 0 和终点 L）

**输出格式：** 最小跳跃距离的最大可能值

**样例输入：**
```
25 5 2
2
11
14
17
21
```
**样例输出：** `4`

**参考代码（二分答案+贪心check）：**

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
const int MAXN = 50005;
int a[MAXN], n, m, L;

bool check(int d) {
    int removed = 0, last = 0;
    for (int i = 1; i <= n; i++) {
        if (a[i] - a[last] < d) removed++;  // 间距<d，移走这块
        else last = i;                        // 保留这块，更新位置
    }
    return removed <= m;
}

int main() {
    cin >> L >> n >> m;
    a[0] = 0;
    for (int i = 1; i <= n; i++) cin >> a[i];
    a[n + 1] = L;
    n++;
    
    int l = 1, r = L;
    while (l < r) {
        int mid = l + (r - l + 1) / 2;
        if (check(mid)) l = mid;
        else r = mid - 1;
    }
    cout << l << endl;
    return 0;
}
```

#### 编程题2（30分）：大数排序

**题目描述：**

输入 n 个大整数（每个不超过100位），按从小到大的顺序输出。

**输入格式：** 第一行 n（1≤n≤100），接下来 n 行每行一个大整数

**输出格式：** 按升序输出 n 个大整数

**参考思路：** 大整数比较时，先比长度（长的更大），长度相同则按字典序比较。用 `sort` + 自定义比较函数。

```cpp
#include <iostream>
#include <algorithm>
#include <string>
#include <vector>
using namespace std;

bool cmp(const string& a, const string& b) {
    if (a.size() != b.size()) return a.size() < b.size();
    return a < b;  // 等长则字典序
}

int main() {
    int n; cin >> n;
    vector<string> s(n);
    for (int i = 0; i < n; i++) cin >> s[i];
    sort(s.begin(), s.end(), cmp);
    for (const auto& x : s) cout << x << "\n";
    return 0;
}
```
