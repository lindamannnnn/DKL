## 四、编程题（共60分）

### 编程题1（30分）：质因数分解与因数个数

**题目描述：**

给定 T 组测试数据，每组输入正整数 n，输出：
1. n 的质因数分解式（格式如 `12 = 2^2 * 3^1`）
2. n 的因数个数

**输入格式：**
- 第一行 T（1≤T≤10），接下来 T 行每行一个正整数 n（2≤n≤10^7）

**输出格式：**
- 每行先输出分解式，再输出因数个数

**样例输入：**
```
3
12
36
100
```

**样例输出：**
```
12 = 2^2 * 3^1, 因数个数 = 6
36 = 2^2 * 3^2, 因数个数 = 9
100 = 2^2 * 5^2, 因数个数 = 9
```

**参考代码：**

```cpp
#include <iostream>
using namespace std;

void solve(int n) {
    cout << n << " = ";
    int orig = n;
    int divCnt = 1;
    bool first = true;
    for (int i = 2; (long long)i * i <= n; i++) {
        if (n % i == 0) {
            int exp = 0;
            while (n % i == 0) { exp++; n /= i; }
            if (!first) cout << " * ";
            cout << i << "^" << exp;
            first = false;
            divCnt *= (exp + 1);
        }
    }
    if (n > 1) {
        if (!first) cout << " * ";
        cout << n << "^1";
        divCnt *= 2;
    }
    cout << ", 因数个数 = " << divCnt << "\n";
}

int main() {
    int T; cin >> T;
    while (T--) {
        int n; cin >> n;
        solve(n);
    }
    return 0;
}
```

### 编程题2（30分）：区间调度

**题目描述：**

有 n 个任务，每个任务有开始时间 s[i] 和结束时间 e[i]。你只有一台机器，同一时刻只能运行一个任务。问最多能完成多少个任务？（完成意思是从开始到结束不中断）

**输入格式：**
- 第一行 n（1≤n≤10^5）
- 接下来 n 行，每行 s[i] e[i]（1≤s[i]<e[i]≤10^9）

**输出格式：**
- 最多能完成的任务数

**样例输入：**
```
5
1 3
2 4
3 5
0 6
5 7
```

**样例输出：**
```
3
```

**参考代码：**

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Task {
    int s, e;
};

bool cmp(Task a, Task b) {
    return a.e < b.e;
}

int main() {
    int n; cin >> n;
    Task tasks[100005];
    for (int i = 0; i < n; i++) cin >> tasks[i].s >> tasks[i].e;
    sort(tasks, tasks + n, cmp);
    
    int cnt = 0, lastEnd = -1;
    for (int i = 0; i < n; i++) {
        if (tasks[i].s >= lastEnd) {
            cnt++;
            lastEnd = tasks[i].e;
        }
    }
    cout << cnt << endl;
    return 0;
}
```
