>
> 如果我们把迷宫格子看成湖面，起点看成石头入水点，BFS 就像水波一样，第1步能到达的格子先"被淹"，然后才是第2步能到达的格子……
>
> **所以，第一次"淹到"终点时，用的步数一定是最少的（最短路）！**

### 2. 知识点讲解

#### 2.1 BFS 的核心思想

> **BFS = 逐层搜索**：先搜索距起点为1步的所有节点，再搜索2步的，以此类推。

**关键特性：**

> 在无权图（或边权均为1的图）中，BFS 找到的路径**必然是最短路径**！
>
> 原因：BFS 按距离从小到大的顺序访问节点，第一次到达终点时用的距离是最小的。

#### 2.2 队列：BFS 的核心数据结构

**为什么用队列？**

> 队列是**先进先出（FIFO）**的数据结构：排在前面的先出来。
>
> BFS 需要保证"距起点近的节点先被处理"，正好符合队列的 FIFO 特性！

**C++ STL queue 基本操作：**

```cpp
#include <queue>
queue<int> q;      // 定义整数队列

q.push(x);         // 将 x 加入队尾
q.pop();           // 删除队首元素
q.front();         // 访问队首元素（不删除）
q.empty();         // 判断队列是否为空
q.size();          // 返回队列中元素个数
```

#### 2.3 BFS 标准框架

```cpp
void bfs(起点) {
    queue<节点类型> q;
    q.push(起点);
    vis[起点] = true;  // 入队时就标记（不要等出队时）
    
    while (!q.empty()) {
        取出队首节点 cur = q.front(); q.pop();
        
        if (cur 是终点) { 处理结果; break; }
        
        for (cur 的每个邻居 nxt) {
            if (nxt 合法 && !vis[nxt]) {
                vis[nxt] = true;   // 标记
                q.push(nxt);      // 入队
            }
        }
    }
}
```

> ⚠️ **重要：** 标记操作应在**入队时**完成，而不是出队时！
>
> 若在出队时标记，同一节点可能被多次入队，导致重复处理和效率降低。

#### 2.4 BFS 求迷宫最短步数

用结构体记录坐标和步数：

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node { int x, y, step; };

int n, m, a[105][105];
bool vis[105][105];
int dx[]={0,-1,1,0,0}, dy[]={0,0,0,-1,1};

int bfs(int sx, int sy, int ex, int ey) {
    queue<Node> q;
    q.push({sx, sy, 0});
    vis[sx][sy] = true;
    
    while (!q.empty()) {
        Node cur = q.front(); q.pop();
        
        if (cur.x==ex && cur.y==ey) return cur.step;
        
        for (int i=1;i<=4;i++) {
            int nx=cur.x+dx[i], ny=cur.y+dy[i];
            if (nx>=1&&nx<=n&&ny>=1&&ny<=m&&a[nx][ny]==0&&!vis[nx][ny]) {
                vis[nx][ny]=true;
                q.push({nx, ny, cur.step+1});
            }
        }
    }
    return -1;  // 无路可达
}

int main() {
    cin>>n>>m;
    for(int i=1;i<=n;i++) for(int j=1;j<=m;j++) cin>>a[i][j];
    cout<<bfs(1,1,n,m);
    return 0;
}
```

#### 2.5 BFS vs DFS 的对比

| 特性 | BFS | DFS |
|------|-----|-----|
| 数据结构 | 队列（FIFO） | 栈/递归 |
| 搜索方式 | 逐层扩展 | 一条路走到黑 |
| 最短路 | ✅ 天然保证（无权图）| ❌ 需枚举所有路径 |
| 空间复杂度 | 较大（存一层节点）| 较小（等于最大深度）|
| 适用场景 | 最短路、层次遍历 | 所有解、回溯、深度遍历 |

> **一句话总结：** 想找**最短路**，用 BFS；想找**所有解**，用 DFS。

### 3. GESP 真题演练 ⚡

**抢答题 1（选择题）：**

> BFS 使用哪种数据结构保证按层次顺序访问节点？
>
> A. 栈（Stack）  B. 队列（Queue）  C. 优先队列（Priority Queue）  D. 数组
>
> **答案：B**
>
> 解析：队列 FIFO 的性质保证了先发现的节点（距起点更近）先被处理，天然形成层次遍历顺序。

**判断题 2：**

> BFS 一定比 DFS 找最短路更高效。（ ）
>
> **答案：✓（在无权图中正确）**
>
> 解析：BFS 第一次到达终点时即为最短路，无需枚举所有路径；而 DFS 必须枚举所有路径取最小值，效率低得多。

**抢答题 3（选择题）：**

> 使用 BFS 时，访问标记应该在什么时候设置？
>
> A. 节点出队时  B. 节点入队时  C. 节点第一次被发现且未访问时  D. B 和 C 都对
>
> **答案：D**
>
> 解析：在入队时就标记（即发现时），可以防止同一节点被多次加入队列。

### 4. 进阶扩展

**用两个队列分别存 x、y 坐标（另一种常见写法）：**

```cpp
queue<int> qx, qy;
int dis[105][105];  // 记录每个格子到起点的距离

void bfs(int sx, int sy) {
    qx.push(sx); qy.push(sy);
    dis[sx][sy] = 0;
    memset(dis, -1, sizeof(dis)); // 初始化为-1（未访问）
    dis[sx][sy] = 0;
    
    while (!qx.empty()) {
        int x=qx.front(), y=qy.front();
        qx.pop(); qy.pop();
        
        for (int i=1;i<=4;i++) {
            int nx=x+dx[i], ny=y+dy[i];
            if (nx>=1&&nx<=n&&ny>=1&&ny<=m&&a[nx][ny]==0&&dis[nx][ny]==-1) {
                dis[nx][ny] = dis[x][y] + 1;
                qx.push(nx); qy.push(ny);
            }
        }
    }
}
```

> 💡 用 `dis` 数组代替 `vis` 数组，好处是同时记录了每个格子到起点的最短距离！

### 练习 2（基础）：BFS 层次遍历

**题目描述：**

n×m 网格（全为0），从(1,1)出发BFS遍历，输出每个格子被访问时的步数（到起点的距离）。

**输入格式：** n m（1≤n,m≤10）

**输出格式：** n行m列的距离矩阵

**样例输入：** `3 4`

**样例输出：**
```

```

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,m,dis[15][15];
int dx[]={0,-1,1,0,0}, dy[]={0,0,0,-1,1};

int main() {
    cin>>n>>m;
    memset(dis,-1,sizeof(dis));
    queue<pair<int,int>> q;
    q.push({1,1}); dis[1][1]=0;

### 练习 3（综合）：泉水灌溉

**题目描述：**

n×m 地图，`.`是平地，`#`是山，`S`是泉水源头，水可以向上下左右流动（不能穿越山），求水能覆盖多少块平地（含起点S）。

- 第一行：n m（1≤n,m≤100）
- 接下来 n 行字符图

**输出格式：** 水覆盖的格子数

**样例输入：**
```

### 练习 5（进阶）：多源 BFS

**题目描述：**

n×m 网格，有若干个起点（`S`），若干个障碍（`#`），其余为空地（`.`）。对每个空地格子，求距离最近的起点的步数，输出整个距离矩阵。

**输入格式：**
- 第一行：n m（1≤n,m≤50）
- 接下来 n 行字符图

**输出格式：** n×m 的距离矩阵，障碍格子输出 -1

**样例输入：**
```
3 4
S..#
....

```

**样例输出：**
```

1 2 3  2
-1 3 2  0
```

**思路分析：**

> **多源BFS：** 将所有起点同时入队，同时向外扩展，每次扩展到的格子记录的就是到最近起点的距离！

**题解代码：**

```cpp

int main() {

    for(int i=1;i<=n;i++) for(int j=1;j<=m;j++) {
        cin>>a[i][j];
        if(a[i][j]=='S') { dis[i][j]=0; q.push({i,j}); }
    }
    while(!q.empty()) {
        auto [x,y]=q.front(); q.pop();
        for(int i=0;i<4;i++) {
            int nx=x+dx[i], ny=y+dy[i];
            if(nx>=1&&nx<=n&&ny>=1&&ny<=m&&a[nx][ny]!='#'&&dis[nx][ny]==-1) {
                dis[nx][ny]=dis[x][y]+1;
                q.push({nx,ny});
            }
        }
    }
    for(int i=1;i<=n;i++) {
        for(int j=1;j<=m;j++) cout<<dis[i][j]<<" \n"[j==m];
    }
    return 0;
}
```

#### 作业 3：连通块数量（BFS版）

n×m网格，1是陆地0是海洋，BFS统计岛屿数量（上下左右相邻的陆地算同一岛屿）。

**输入：** n m 及网格 | **输出：** 岛屿数量

**样例输入：** `3 4` 及 `1 1 0 0 / 0 1 0 1 / 0 0 0 1` | **样例输出：** `2`

**题解代码：**
```cpp
#include <bits/stdc++.h>
using namespace std;
int n,m,a[15][15],cnt;
bool vis[15][15];
int dx[]={-1,1,0,0}, dy[]={0,0,-1,1};
void bfs(int sx, int sy) {
    queue<pair<int,int>> q;
    q.push({sx,sy}); vis[sx][sy]=true;
    while(!q.empty()) {
        auto [x,y]=q.front(); q.pop();
        for(int i=0;i<4;i++) {
            int nx=x+dx[i], ny=y+dy[i];
            if(nx>=1&&nx<=n&&ny>=1&&ny<=m&&a[nx][ny]==1&&!vis[nx][ny]) {
                vis[nx][ny]=true; q.push({nx,ny});
            }
        }
    }
}
int main() {
    cin>>n>>m;
    for(int i=1;i<=n;i++) for(int j=1;j<=m;j++) cin>>a[i][j];
    for(int i=1;i<=n;i++) for(int j=1;j<=m;j++)
        if(a[i][j]==1&&!vis[i][j]) { cnt++; bfs(i,j); }
    cout<<cnt; return 0;
}
```

### 🔥 拓展习题（尖子生挑战，7道）

#### 挑战 1：BFS 记录路径

在BFS求最短路的同时，记录并输出最短路径经过的坐标（每个格子记录它的前驱格子，倒推路径）。

**提示：** `prev[nx][ny]={x,y}` 记录前驱，到终点时从终点往回追踪

---

#### 挑战 2：多终点最近距离

n×m迷宫，有多个终点`E`，BFS从起点出发，找到最近终点的距离。

**提示：** BFS到达任意E时即为最短距离（BFS天然找最近的）

---

#### 挑战 3：步数限制内能到达的格子

BFS从起点出发，统计步数≤k范围内能到达的格子数量。

**提示：** BFS时记录步数，超过k的格子不再扩展

---

#### 挑战 4：谣言传播

n个人组成社交网络，给出朋友关系，某人在第0天知道了谣言，每天传给所有朋友。问第几天所有人都知道？

**提示：** BFS模拟，`dis[v]=dis[u]+1`，答案是最大的`dis`值

---

#### 挑战 5：数字变换最短路

从整数A变换到B，每步可以+1、-1或×2，求最少操作次数。

**提示：** 数字也是状态，BFS枚举状态变化，注意设置数值范围上限

---

#### 挑战 6：骑士最短路

国际象棋的骑士（马），从 (0,0) 出发，用最少步数到达 (a,b)（8个方向的日字走法，无限大棋盘）。

**提示：** BFS，马的8个方向：`dx[]={-2,-2,-1,-1,1,1,2,2}`，`dy[]={-1,1,-2,2,-2,2,-1,1}`

---

#### 挑战 7：01 BFS（混合路径）

n×m地图，走普通格子花1步，走特殊格子花0步（传送门）。求最少步数到终点。

**提示：** 使用双端队列 `deque`，花0步的入队头，花1步的入队尾（0-1 BFS）
