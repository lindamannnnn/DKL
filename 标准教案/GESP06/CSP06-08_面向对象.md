### 2. 知识点讲解

#### 2.1 面向对象思想

传统编程（面向过程）：以**函数**为核心，数据和操作分离。

面向对象编程（OOP）：以**对象**为核心，数据和操作绑定在一起。

> 比喻：
> - 面向过程：切菜的函数、炒菜的函数、摆盘的函数……
> - 面向对象：厨师对象（有姓名属性，有切菜/炒菜/摆盘方法）

#### 2.2 类的定义

```cpp
class 类名 {
public:          // 公有成员（外部可访问）
    数据类型 成员变量;
    返回类型 成员函数() { ... }
    
private:         // 私有成员（只有类内可访问）
    数据类型 私有变量;
};
```

**示例：Student 类**

```cpp
class Student {
public:
    string name;
    int age;
    float score;
    
    void print() {
        cout << "姓名:" << name << " 年龄:" << age << " 成绩:" << score << "\n";
    }
    
    bool isPassed() {
        return score >= 60;
    }
};

int main() {
    Student s;          // 创建对象
    s.name = "小明";
    s.age = 12;
    s.score = 85.5;
    s.print();          // 调用成员函数
    return 0;
}
```

#### 2.3 构造函数

构造函数：**对象创建时自动调用**，用于初始化成员变量。

```cpp
class Student {
public:
    string name;
    int age;
    float score;
    
    // 构造函数（无参数）
    Student() {
        name = "未知";
        age = 0;
        score = 0;
    }
    
    // 带参数的构造函数
    Student(string n, int a, float s) {
        name = n;
        age = a;
        score = s;
    }
};

int main() {
    Student s1;                          // 调用无参构造
    Student s2("小红", 13, 92.0);        // 调用有参构造
    return 0;
}
```

#### 2.4 析构函数

析构函数：**对象销毁时自动调用**，用于释放资源。

```cpp
class Student {
public:
    Student() { cout << "学生创建\n"; }
    ~Student() { cout << "学生销毁\n"; }  // 析构函数
};
```

> 💡 对于简单的竞赛编程，析构函数通常不需要手动编写；
> 但在涉及动态内存分配（`new`）时，需要在析构函数中 `delete`。

#### 2.5 面向对象三大特性

| 特性 | 含义 | 比喻 |
|------|------|------|
| **封装** | 将数据和操作捆绑，隐藏实现细节 | 手机封装了复杂电路，用户只需按按钮 |
| **继承** | 子类继承父类的属性和方法 | 电动汽车继承了普通汽车的所有特性 |
| **多态** | 同一方法在不同对象上有不同表现 | 同样叫"叫"，猫叫"喵"狗叫"汪" |

**继承示例：**

```cpp
class Animal {  // 父类
public:
    string name;
    void eat() { cout << name << "在吃东西\n"; }
    virtual void speak() { cout << "...\n"; }  // 虚函数
};

class Dog : public Animal {  // 子类，继承Animal
public:
    void speak() override { cout << name << "：汪汪！\n"; }
};

class Cat : public Animal {
public:
    void speak() override { cout << name << "：喵喵！\n"; }
};

int main() {
    Dog d; d.name="旺财"; d.eat(); d.speak();
    Cat c; c.name="咪咪"; c.eat(); c.speak();
    return 0;
}
```

### 4. 进阶扩展

**运算符重载（让类支持 + - 等运算）：**

```cpp
class Vector2D {
public:
    double x, y;
    Vector2D(double x=0, double y=0) : x(x), y(y) {}
    
    // 重载 + 运算符
```

### 练习 2（基础）：定义 Stack 类（手动实现栈）

**题目描述：**

用类实现一个整数栈，支持 push（压栈）、pop（出栈）、top（查栈顶）、empty（判空）操作。

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

class MyStack {
private:
    int data[1005];
    int top_;
public:
    MyStack() : top_(0) {}
    void push(int x) { data[++top_] = x; }
    void pop() { if(top_>0) top_--; }
    int top() { return data[top_]; }
    bool empty() { return top_ == 0; }
};

int main() {
    MyStack s;
    s.push(1); s.push(2); s.push(3);
    while(!s.empty()) { cout << s.top() << " "; s.pop(); }
    return 0;
}
```

### 练习 4（综合）：分数类

**题目描述：**

定义分数类 Fraction（分子分母），支持加减乘除运算，结果自动化简。

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

class Fraction {
public:
    int num, den;
    Fraction(int n=0, int d=1) : num(n), den(d) { simplify(); }
    void simplify() {
        int g=__gcd(abs(num),abs(den));
        num/=g; den/=g;
        if(den<0) { num=-num; den=-den; }
    }
    Fraction operator+(const Fraction& f) const { return Fraction(num*f.den+f.num*den, den*f.den); }
    Fraction operator*(const Fraction& f) const { return Fraction(num*f.num, den*f.den); }
    void print() { cout << num << "/" << den << "\n"; }
};

int main() {
    Fraction a(1,2), b(1,3);
    (a+b).print();  // 5/6
    (a*b).print();  // 1/6
    return 0;
}
```

### 练习 5（进阶）：链表类

**题目描述：**

用类实现单向链表，支持头插、尾插、遍历打印、删除节点操作。

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

class LinkedList {
    struct Node {
        int val;
        Node* next;
        Node(int v) : val(v), next(nullptr) {}
    };
    Node* head;
public:
    LinkedList() : head(nullptr) {}
    void pushFront(int v) { Node* n=new Node(v); n->next=head; head=n; }
    void pushBack(int v) {
        Node* n=new Node(v);
        if(!head) { head=n; return; }
        Node* cur=head; while(cur->next) cur=cur->next; cur->next=n;
    }
    void print() { for(Node* cur=head;cur;cur=cur->next) cout<<cur->val<<" "; cout<<"\n"; }
    ~LinkedList() { while(head) { Node* t=head; head=head->next; delete t; } }
};

int main() {
    LinkedList l;
    l.pushBack(1); l.pushBack(2); l.pushFront(0); l.print();
    return 0;
}
```

```cpp
    string name; int scores[10],n;
```
