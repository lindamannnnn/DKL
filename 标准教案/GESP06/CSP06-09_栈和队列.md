## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> **📚 书堆 vs 排队**
>
> **栈**就像一摞书：你只能从最上面放书、取书。最后放进去的书，最先被取出来——**后进先出（LIFO / FILO）**。
>
> **队列**就像排队打饭：新来的人排到队尾，先到的人先打到饭——**先进先出（FIFO）**。
>
> 这两种结构看似简单，却是无数算法的基础！

### 2. 知识点讲解

#### 2.1 栈（Stack）

**特性：后进先出（LIFO）**

| 操作 | 说明 |
|------|------|
| `s.push(x)` | 将 x 压入栈顶 |
| `s.pop()` | 弹出栈顶元素（不返回值） |
| `s.top()` | 查看栈顶元素 |
| `s.empty()` | 判断栈是否为空 |
| `s.size()` | 返回栈中元素数量 |

```cpp
#include <stack>
stack<int> s;
s.push(1); s.push(2); s.push(3);
while(!s.empty()) {
    cout << s.top() << " ";  // 3 2 1（后进先出）
    s.pop();
}
```

#### 2.2 队列（Queue）

**特性：先进先出（FIFO）**

| 操作 | 说明 |
|------|------|
| `q.push(x)` | 将 x 加入队尾 |
| `q.pop()` | 删除队首元素 |
| `q.front()` | 查看队首元素 |
| `q.back()` | 查看队尾元素 |
| `q.empty()` | 判断队列是否为空 |

```cpp
#include <queue>
queue<int> q;
q.push(1); q.push(2); q.push(3);
while(!q.empty()) {
    cout << q.front() << " ";  // 1 2 3（先进先出）
    q.pop();
}
```

#### 2.3 循环队列

> 用数组模拟队列时，如果每次 `pop()` 真的删除元素，头指针往后移，会浪费前面的空间。
>
> **循环队列** = 让头尾指针在数组范围内"循环"，重复利用空间。

```cpp
int q[1005], head=0, tail=0;      // 初始队列为空
// 入队
q[tail++] = x;
if(tail >= 1005) tail = 0;  // 循环

// 出队
head++;
if(head >= 1005) head = 0;

// 判空
bool isEmpty = (head == tail);
// 队首
int front = q[head];
```

> 💡 STL 的 queue 内部已经处理好了循环问题，竞赛中直接用 STL 即可。

#### 2.4 栈的经典应用：括号匹配

**问题：** 给一串括号（`(`、`)`、`[`、`]`、`{`、`}`），判断是否合法（匹配）。

**策略：**

> 遇到左括号 `(`，压入栈；
>
> 遇到右括号 `)`，取出栈顶与之匹配；
>
> 若栈顶是对应的左括号，匹配成功；否则失败。
>
> 最后栈为空则全部匹配成功。

```cpp
#include <bits/stdc++.h>
using namespace std;
bool isMatch(string s) {
    stack<char> stk;
    for(char c : s) {
        if(c=='('||c=='['||c=='{') stk.push(c);
        else {
            if(stk.empty()) return false;
            char top=stk.top(); stk.pop();
            if(c==')' && top!='(') return false;
            if(c==']' && top!='[') return false;
            if(c=='}' && top!='{') return false;
        }
    }
    return stk.empty();
}
int main() {
    string s; cin>>s;
    cout<<(isMatch(s)?"YES":"NO");
    return 0;
}
```

### 4. 进阶扩展

**单调栈——O(n) 求数组中每个元素的"下一个更大元素"：**

> **问题：** 对数组每个元素，找到它右边第一个比它大的数。
>
> **暴力：** O(n²)；**单调栈：** O(n)

```cpp
stack<int> stk;  // 存下标
int nxt[100005] = {0};  // nxt[i]=a[i]右边第一个更大数，-1表示没有

for(int i=n;i>=1;i--) {
    while(!stk.empty() && a[stk.top()] <= a[i]) stk.pop();
    nxt[i] = stk.empty() ? -1 : a[stk.top()];
    stk.push(i);
}
```

> 💡 单调栈的核心：维护一个递减的栈，每次入栈前弹出比当前元素小的。

### 练习 2（基础）：用栈实现队列

**题目描述：**

用两个栈模拟一个队列，支持 push（入队）和 pop（出队）操作。

**输入格式：**
- 第一行：q 个操作
- 每行：`push x` 或 `pop`（pop 输出队首元素）

**样例输入：**
```
5
push 1
push 2
pop
push 3
pop
```
**样例输出：**
```
1
2
```

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
stack<int> s1, s2;

void push(int x) { s1.push(x); }

int pop() {
    if(s2.empty()) while(!s1.empty()) { s2.push(s1.top()); s1.pop(); }
    int r=s2.top(); s2.pop(); return r;
}

int main() {
    int q; cin>>q;
    while(q--) {
        string op; cin>>op;
        if(op=="push") { int x; cin>>x; push(x); }
        else cout<<pop()<<"\n";
    }
    return 0;
}
```

### 练习 3（综合）：表达式求值（简化版）

**题目描述：**

给一个不含括号、只有加减法的表达式（如 `1+2-3+4`），用栈求值。

**输入格式：** 一行表达式字符串

**输出格式：** 计算结果

**样例输入：** `1+2-3+4`  |  **样例输出：** `4`

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s; cin>>s;
    int result=0, cur=0, sign=1;
    for(char c:s) {
        if(isdigit(c)) cur=cur*10+(c-'0');
        else { result+=sign*cur; cur=0; sign=(c=='+'?1:-1); }
    }
    result+=sign*cur;
    cout<<result;
    return 0;
}
```

### 练习 4（综合）：模拟浏览器前进后退

**题目描述：**

模拟浏览器的前进/后退功能：
- `visit x`：访问页面x（清空"前进历史"）
- `back`：后退一页
- `forward`：前进一页
- `print`：输出当前页名

**输入格式：**
- 第一行：操作数 q
- 接下来 q 行：操作命令

**样例输入：**
```
6
visit A
visit B
visit C
back
print
forward
```
**样例输出：** `B`

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    stack<string> back_, forward_;
    string cur="";
    int q; cin>>q;
    while(q--) {
        string op; cin>>op;
        if(op=="visit") {
            string page; cin>>page;
            if(cur!="") back_.push(cur);
            cur=page;
            while(!forward_.empty()) forward_.pop();
        } else if(op=="back") {
            if(!back_.empty()) { forward_.push(cur); cur=back_.top(); back_.pop(); }
        } else if(op=="forward") {
            if(!forward_.empty()) { back_.push(cur); cur=forward_.top(); forward_.pop(); }
        } else { cout<<cur<<"\n"; }
    }
    return 0;
}
```

### 练习 5（进阶）：单调栈——下一个更大元素

**题目描述：**

给长度为 n 的数组，对每个元素求右边第一个比它大的数（不存在则输出 -1）。

**输入格式：** n 及 n 个整数（1≤n≤100000）

**输出格式：** n 个整数

**样例输入：** `5` 及 `2 1 4 3 5`

**样例输出：** `4 4 5 5 -1`

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, a[100005], nxt[100005];
int main() {
    cin>>n;
    for(int i=1;i<=n;i++) cin>>a[i];
    stack<int> stk;
    for(int i=n;i>=1;i--) {
        while(!stk.empty()&&a[stk.top()]<=a[i]) stk.pop();
        nxt[i]=stk.empty()?-1:a[stk.top()];
        stk.push(i);
    }
    for(int i=1;i<=n;i++) cout<<nxt[i]<<" \n"[i==n];
    return 0;
}
```

#### 作业 2：用栈判断回文串

用栈判断字符串是否是回文串（将一半字符压栈，再与后一半比对）。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s; cin>>s; int n=s.size();
    stack<char> st; for(int i=0;i<n/2;i++) st.push(s[i]);
    for(int i=n/2+(n%2);i<n;i++) { if(st.top()!=s[i]){cout<<"NO";return 0;} st.pop(); }
    cout<<"YES"; return 0;
}
```
