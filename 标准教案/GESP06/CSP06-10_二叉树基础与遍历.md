### 2. 知识点讲解

#### 2.1 树的基本概念

| 术语 | 含义 |
|------|------|
| 根节点 | 树的"祖先"，没有父节点 |
| 叶节点 | 没有子节点的节点 |
| 深度/层在 | 根节点深度为0（或1），子节点深度=父节点+1 |
| 高度 | 树中最大深度 |
| 度 | 节点的子节点数量 |

#### 2.2 二叉树的定义与性质

二叉树：每个节点最多有**两个子节点**（左子节点 left，右子节点 right）。

> **重要性质：**
> - 第 k 层（根为第1层）最多有 2^(k-1) 个节点
> - 高度为 h 的二叉树最多有 2^h - 1 个节点
> - 叶节点数 = 度为2的节点数 + 1

**完全二叉树 vs 满二叉树：**

| 类型 | 含义 |
|------|------|
| **满二叉树** | 所有叶节点在同一层，每个非叶节点都有2个子节点 |
| **完全二叉树** | 除最后一层外全满，最后一层从左到右排列 |

#### 2.3 二叉树的存储

**1. 数组存储（适用于完全二叉树）：**

```cpp
// 节点 i 的父节点：i/2；左子节点：2*i；右子节点：2*i+1
int tree[100005];
// 访问节点 i 的左子节点：tree[2*i]
// 访问节点 i 的右子节点：tree[2*i+1]
```

**2. 链式存储（通用）：**

```cpp
struct TreeNode {
    int val;
    TreeNode* left;   // 左子节点指针
    TreeNode* right;  // 右子节点指针
    TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};
```

#### 2.4 四种遍历方式

> **遍历** = 按某种顺序访问每个节点，且每个节点只访问一次。

**先序遍历（Pre-order）：根 → 左 → 右**

```cpp
void preorder(TreeNode* root) {
    if(!root) return;
    cout << root->val << " ";  // 先访问根
    preorder(root->left);
    preorder(root->right);
}
```

**中序遍历（In-order）：左 → 根 → 右**

```cpp
void inorder(TreeNode* root) {
    if(!root) return;
    inorder(root->left);
    cout << root->val << " ";  // 中间访问根
    inorder(root->right);
}
```

**后序遍历（Post-order）：左 → 右 → 根**

```cpp
void postorder(TreeNode* root) {
    if(!root) return;
    postorder(root->left);
    postorder(root->right);
    cout << root->val << " ";  // 最后访问根
}
```

**层次遍历（Level-order）：用 BFS**

```cpp
void levelorder(TreeNode* root) {
    if(!root) return;
    queue<TreeNode*> q;
    q.push(root);
    while(!q.empty()) {
        TreeNode* cur=q.front(); q.pop();
        cout << cur->val << " ";
        if(cur->left) q.push(cur->left);
        if(cur->right) q.push(cur->right);
    }
}
```

> **黑板推演（以二叉树为例）：**
>
> ```
>         1
>        / \
>       2   3
>      / \
>     4   5
> ```
>
> 先序：1 2 4 5 3
>
> 中序：4 2 5 1 3
>
> 后序：4 5 2 3 1
>
> 层次：1 2 3 4 5

> 对于完整的二叉树，节点 i 的左子节点下标是（ ）（根节点下标为1）
>
> A. i-1  B. 2i  C. 2i+1  D. i/2
>
> **答案：B**

**判断题 2：**

> 完全二叉树一定是满二叉树。（ ）
>
> **答案：✗**
>
> 解析：完全二叉树最后一层可以不满（但必须从左到右排列），而满二叉树要求所有叶节点在同一层。

**抢答题 3：**

> 已知二叉树的先序遍历为 `1 2 4 5 3`，中序遍历为 `4 2 5 1 3`，求后序遍历。
>
> **答案：** `4 5 2 3 1`
>
> 解析：先序第一个是根（1），在中序中找到1的位置，左侧（4 2 5）是左子树，右侧（3）是右子树。

### 4. 进阶扩展

**由先序+中序重建二叉树：**

```cpp
// 先序序列 pre[preL..preR]，中序序列 in[inL..inR]
// 重建二叉树，返回根节点
TreeNode* build(int* pre, int preL, int preR, int* in, int inL, int inR) {
    if(preL>preR) return nullptr;
    int rootVal=pre[preL];
    TreeNode* root=new TreeNode(rootVal);
    
    int rootIdx=inL;
    while(in[rootIdx]!=rootVal) rootIdx++;  // 在中序中找根的位置
    
    int leftSize=rootIdx-inL;  // 左子树节点数
    root->left=build(pre,preL+1,preL+leftSize,in,inL,rootIdx-1);
    root->right=build(pre,preL+leftSize+1,preR,in,rootIdx+1,inR);
    return root;
}
```

### 练习 1（基础）：数组模拟二叉树遍历

**题目描述：**

用数组存储完全二叉树（节点i的左子节点为2i，右子节点为2i+1，根为1），输入节点数n和各节点值，输出先序、中序、后序遍历结果。

**输入格式：** n 及节点值（按编号从1到n）

**输出格式：** 三行，分别是先序、中序、后序遍历

**样例输入：** `5` 及 `1 2 3 4 5`

**样例输出：**
```
1 2 4 5 3
4 2 5 1 3
4 5 2 3 1
```

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, a[105];

void pre(int i){ if(i>n) return; cout<<a[i]<<" "; pre(2*i); pre(2*i+1); }
void in(int i){ if(i>n) return; in(2*i); cout<<a[i]<<" "; in(2*i+1); }
void post(int i){ if(i>n) return; post(2*i); post(2*i+1); cout<<a[i]<<" "; }

int main() {
    cin>>n;
    for(int i=1;i<=n;i++) cin>>a[i];
    pre(1); cout<<"\n"; in(1); cout<<"\n"; post(1); cout<<"\n";
    return 0;
}
```

### 练习 3（综合）：统计二叉树节点数

输入完全二叉树的节点数n和各节点值，统计叶节点数、最大深度、节点总数。

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, a[105], leafCnt=0, maxDepth=0;
void dfs(int i, int depth) {
    if(i>n) return;
    maxDepth=max(maxDepth,depth);
    if(2*i>n) leafCnt++;  // 叶节点：没有左子节点
    else { dfs(2*i,depth+1); dfs(2*i+1,depth+1); }
}
int main() {
    cin>>n; for(int i=1;i<=n;i++) cin>>a[i];
    dfs(1,1);
    cout<<"节点总数:"<<n<<"\n叶节点数:"<<leafCnt<<"\n最大深度:"<<maxDepth<<"\n";
    return 0;
}
```

### 练习 4（综合）：由先序中序重建二叉树并后序输出

**题目描述：**

给定先序和中序遍历序列，重建二叉树，输出后序遍历。

**输入格式：**
- n（1≤n≤30）
- 先序遍历（n个数）
- 中序遍历（n个数）

**输出格式：** 后序遍历

**样例输入：**
```
5
1 2 4 5 3
4 2 5 1 3
```
**样例输出：** `4 5 2 3 1`

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, pre[35], in_[35];

void build(int pL,int pR, int iL,int iR) {
    if(pL>pR) return;
    int root=pre[pL], idx=iL;
    while(in_[idx]!=root) idx++;
    int leftSize=idx-iL;
    build(pL+1,pL+leftSize,iL,idx-1);
    build(pL+leftSize+1,pR,idx+1,iR);
    cout<<root<<" ";
}

int main() {
    cin>>n;
    for(int i=1;i<=n;i++) cin>>pre[i];
    for(int i=1;i<=n;i++) cin>>in_[i];
    build(1,n,1,n);
    return 0;
}
```

### 练习 5（进阶）：二叉树的最大路径和

**题目描述：**

给完全二叉树（数组存储），求从根到叶节点路径上节点值之和最大是多少。

**输入格式：** n 及节点值

**输出格式：** 最大路径和

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, a[105], ans=INT_MIN;
void dfs(int i, int sum) {
    if(i>n) return;
    sum+=a[i];
    if(2*i>n) { ans=max(ans,sum); return; }
    dfs(2*i,sum); dfs(2*i+1,sum);
}
int main() {
    cin>>n; for(int i=1;i<=n;i++) cin>>a[i];
    dfs(1,0); cout<<ans;
    return 0;
}
```
