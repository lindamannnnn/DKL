# CSP06-11 二叉搜索树

## 一、课程简介（5分钟）

### 🎯 课程目标

1. 理解 BST（二叉搜索树）的定义与核心性质
2. 掌握 BST 的查找、插入、删除三种基本操作
3. 能分析 BST 操作的时间复杂度
4. 了解 BST 退化（变链表）及平衡树的概念

### 📚 核心知识点

- BST 定义：左子树所有节点 < 根 < 右子树所有节点
- BST 查找：O(h)，最优 O(log n)
- BST 插入：仿查找，在正确位置插入新节点
- BST 删除：三种情况分别处理
- BST 中序遍历 = 升序序列
- BST 时间复杂度分析：平均 O(log n)，最坏 O(n)

### 2. 知识点讲解

#### 2.1 BST 的定义与性质

> **BST 的核心性质（对每个节点都成立）：**
>
> 左子树中所有节点的值 < 当前节点值 < 右子树中所有节点的值

```
       5
      / \
     3   7
    / \   \
   1   4   9
```

验证：根5，左子树{1,3,4}都<5，右子树{7,9}都>5 ✅

> **最重要的性质：BST 的中序遍历结果是升序序列！**
>
> 上例中序：1 3 4 5 7 9 ✅

#### 2.2 BST 查找

```cpp
TreeNode* search(TreeNode* root, int target) {
    if(!root) return nullptr;           // 未找到
    if(root->val == target) return root; // 找到！
    if(target < root->val)              // 在左子树查找
        return search(root->left, target);
    else                                // 在右子树查找
        return search(root->right, target);
}
```

> 时间复杂度：O(h)，h 是树的高度。平衡时 h=O(log n)，退化成链表时 h=O(n)。

#### 2.3 BST 插入

```cpp
TreeNode* insert(TreeNode* root, int val) {
    if(!root) return new TreeNode(val);  // 找到空位，插入
    if(val < root->val)
        root->left = insert(root->left, val);
    else if(val > root->val)
        root->right = insert(root->right, val);
    // 若 val==root->val，BST中不允许重复（忽略）
    return root;
}
```

#### 2.4 BST 删除（三种情况）

```cpp
TreeNode* remove(TreeNode* root, int val) {
    if(!root) return nullptr;
    if(val < root->val) {
        root->left = remove(root->left, val);
    } else if(val > root->val) {
        root->right = remove(root->right, val);
    } else {
        // 找到要删除的节点
        if(!root->left) return root->right;   // 情况1：无左子树
        if(!root->right) return root->left;   // 情况2：无右子树
        // 情况3：有两个子节点——用右子树最小值（中序后继）替换
        TreeNode* minNode = root->right;
        while(minNode->left) minNode = minNode->left;
        root->val = minNode->val;
        root->right = remove(root->right, minNode->val);
    }
    return root;
}
```

> **三种删除情况：**
>
> 1. 叶节点：直接删除
> 2. 只有一个子节点：用子节点替换
> 3. 有两个子节点：用中序后继（右子树最小值）替换，然后删除后继

#### 2.5 BST 时间复杂度

| 操作 | 平均（平衡）| 最坏（退化链表）|
|------|-----------|--------------|
| 查找 | O(log n) | O(n) |
| 插入 | O(log n) | O(n) |
| 删除 | O(log n) | O(n) |

> BST 退化：若按升序插入 1,2,3,4,5，树会变成一条右斜链表，效率退化为 O(n)。
> 解决方法：**平衡二叉树（AVL树、红黑树）**，保证高度始终 O(log n)。

### 4. 进阶扩展

**用 set/map 代替 BST（C++ STL）：**

> STL 的 `set` 和 `map` 内部实现就是**红黑树（一种平衡BST）**！
>
> 竞赛中一般不手写BST，直接用 set/map 享受 O(log n) 的查找、插入、删除。

```cpp
#include <set>
set<int> s;
s.insert(5); s.insert(3); s.insert(7);
s.erase(3);
if(s.count(5)) cout<<"5存在\n";
// 中序遍历（升序输出）
for(int x : s) cout << x << " ";
```

## 四、课堂练习（45分钟）🎈

### 练习 1（基础）：BST 查找

**题目描述：**

构建BST（依次插入n个数），查询m个数是否在BST中。

**输入格式：** n，n个整数；m，m个查询数

**输出格式：** 每个查询输出 YES 或 NO

**样例输入：** `5 1 3 5 7 9` 及查询 `3 2 5`

**样例输出：** `YES NO YES`

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
struct Node { int val; Node* l; Node* r; Node(int v):val(v),l(nullptr),r(nullptr){} };
Node* root=nullptr;
void insert(Node*& r, int v){ if(!r){r=new Node(v);return;} if(v<r->val)insert(r->l,v);else insert(r->r,v); }
bool search(Node* r, int v){ if(!r)return false; if(v==r->val)return true; return v<r->val?search(r->l,v):search(r->r,v); }
int main(){
    int n; cin>>n;
    for(int i=0;i<n;i++){int x;cin>>x;insert(root,x);}
    int m; cin>>m;
    while(m--){int x;cin>>x;cout<<(search(root,x)?"YES":"NO")<<"\n";}
    return 0;
}
```

### 练习 3（综合）：BST 插入删除查找

给 q 个操作：`insert x`、`delete x`、`find x`，用BST（或set）维护，find时输出YES/NO。

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main(){
    int q; cin>>q; set<int> s;
    while(q--){
        string op; int x; cin>>op>>x;
        if(op=="insert") s.insert(x);
        else if(op=="delete") s.erase(x);
        else cout<<(s.count(x)?"YES":"NO")<<"\n";
    }
    return 0;
}
```

**题目描述：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, a[105];
bool isBST(int i, long long lo, long long hi) {
    if(i>n) return true;
```
