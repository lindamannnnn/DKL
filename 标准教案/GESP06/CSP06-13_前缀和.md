# CSP06-13 前缀和

## 一、课程简介（5分钟）

### 🎯 课程目标

1. 理解前缀和的核心思想：预处理换取快速查询
2. 掌握一维前缀和的构建与区间查询
3. 掌握二维前缀和的构建与矩形区域查询
4. 能分析前缀和的时间复杂度优势

### 📚 核心知识点

- 前缀和定义：`pre[i] = a[1]+a[2]+...+a[i]`
- 一维前缀和构建：`pre[i] = pre[i-1] + a[i]`
- 一维区间查询：`sum(L,R) = pre[R] - pre[L-1]`
- 二维前缀和构建（容斥原理）
- 二维矩形查询：加减四个角的前缀和

### 2. 知识点讲解

#### 2.1 一维前缀和

**定义：** `pre[i] = a[1] + a[2] + ... + a[i]`

**构建：**

```cpp
int a[100005], pre[100005];
// 构建前缀和（O(n)）
pre[0] = 0;
for(int i = 1; i <= n; i++) {
    pre[i] = pre[i-1] + a[i];
}
```

**区间查询（O(1)）：**

```cpp
// 区间 [L, R] 的和
int sum = pre[R] - pre[L-1];
```

> **黑板推演：**
>
> 数组：1 2 3 4 5
>
> pre：0 1 3 6 10 15
>
> 查询[2,4]：pre[4] - pre[1] = 10 - 1 = 9 ✅

#### 2.2 二维前缀和

**定义：** `pre[i][j] = 矩阵左上角 (1,1) 到 (i,j) 的区域和`

**构建（容斥原理）：**

```cpp
for(int i = 1; i <= n; i++)
    for(int j = 1; j <= m; j++)
        pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j];
```

**矩形区域查询：** 左上角 (r1,c1) 到右下角 (r2,c2)

```cpp
int sum = pre[r2][c2] - pre[r1-1][c2] - pre[r2][c1-1] + pre[r1-1][c1-1];
```

> **黑板推演（容斥原理）：**
>
> 大矩形 - 上方矩形 - 左方矩形 + 左上角（减了两次）

### 4. 进阶扩展

**前缀和的变种：前缀最大值/最小值**

```cpp
// 前缀最大值
maxPre[0] = INT_MIN;
for(int i = 1; i <= n; i++)
    maxPre[i] = max(maxPre[i-1], a[i]);
// 查询 [1, R] 的最大值：maxPre[R]
```

**前缀和 + 离线查询技巧：** 先收集所有查询，排序后统一用前缀和处理。

## 四、课堂练习（45分钟）🎈

### 练习 1（基础）：区间求和

**题目描述：**

给长度 n 的数组和 m 次查询，每次查询 [L,R] 的和。

**输入格式：** n，n个整数，m及m行L R

**输出格式：** 每次查询输出一行答案

**样例输入：**
```
5
1 2 3 4 5
3
1 3
2 4
3 5
```
**样例输出：** `6 / 9 / 12`

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, m, a[100005];
long long pre[100005];
int main() {
    cin>>n; for(int i=1;i<=n;i++){cin>>a[i];pre[i]=pre[i-1]+a[i];}
    cin>>m; while(m--){int l,r;cin>>l>>r;cout<<pre[r]-pre[l-1]<<"\n";}
    return 0;
}
```

### 练习 2（基础）：二维矩阵区域和

**题目描述：**

给 n×m 矩阵和 q 次查询，每次查询矩形区域 (r1,c1)~(r2,c2) 的和。

**输入格式：** n m，矩阵，q及q行r1 c1 r2 c2

**输出格式：** 每次查询答案

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,m,q,a[505][505];
long long pre[505][505];
int main(){
    cin>>n>>m;
    for(int i=1;i<=n;i++) for(int j=1;j<=m;j++){cin>>a[i][j];pre[i][j]=pre[i-1][j]+pre[i][j-1]-pre[i-1][j-1]+a[i][j];}
    cin>>q;
    while(q--){
        int r1,c1,r2,c2;cin>>r1>>c1>>r2>>c2;
        cout<<pre[r2][c2]-pre[r1-1][c2]-pre[r2][c1-1]+pre[r1-1][c1-1]<<"\n";
    }
    return 0;
}
```

### 练习 3（综合）：连续子数组最大和（前缀和+最小前缀）

**题目描述：**

给 n 个整数，求连续子数组的最大和（Kadane 变形：用前缀和做法）。

**输入格式：** n 及 n 个整数（-10000≤a[i]≤10000）

**输出格式：** 最大子数组和

**样例输入：** `8 -2 1 -3 4 -1 2 1 -5`  |  **样例输出：** `6`

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int n;
long long pre[100005], minPre, ans=LLONG_MIN;
int main(){
    cin>>n; minPre=0;
    for(int i=1;i<=n;i++){int x;cin>>x;pre[i]=pre[i-1]+x;ans=max(ans,pre[i]-minPre);minPre=min(minPre,pre[i]);}
    cout<<ans; return 0;
}
```

### 练习 4（综合）：区间相等判断

**题目描述：**

给两个长度 n 的数组 A 和 B，q 次查询：[L,R] 范围内，A 和 B 的区间和是否相等？

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
long long preA[100005],preB[100005];
int main(){
    int n;cin>>n;
    for(int i=1;i<=n;i++){int x;cin>>x;preA[i]=preA[i-1]+x;}
    for(int i=1;i<=n;i++){int x;cin>>x;preB[i]=preB[i-1]+x;}
    int q;cin>>q;
    while(q--){int l,r;cin>>l>>r;cout<<(preA[r]-preA[l-1]==preB[r]-preB[l-1]?"YES":"NO")<<"\n";}
    return 0;
}
```

### 练习 5（进阶）：二维前缀和 — 子矩阵最大和

**题目描述：**

给 n×m 矩阵，求所有子矩阵中元素和最大的（n,m≤50）。

**题解代码：**（枚举行范围，用前缀和压缩为一维最大子数组）

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,m,a[55][55],pre[55][55];
long long ans=LLONG_MIN;
int main(){
    cin>>n>>m;
    for(int i=1;i<=n;i++) for(int j=1;j<=m;j++){cin>>a[i][j];pre[i][j]=pre[i-1][j]+a[i][j];}
    for(int r1=1;r1<=n;r1++) for(int r2=r1;r2<=n;r2++){
        long long cur=0;
        for(int j=1;j<=m;j++){
            long long v=pre[r2][j]-pre[r1-1][j];
            cur=max((long long)v,cur+v);
            ans=max(ans,cur);
        }
    }
    cout<<ans; return 0;
}
```

## 五、课堂总结（5分钟）🌟

> 前缀和是竞赛中**性价比最高**的算法技巧之一！
>
> **三句话记住前缀和：**
>
> 📦 **预处理换查询**：O(n) 构建，O(1) 查询
>
> 🔢 **一维公式**：`pre[i]=pre[i-1]+a[i]`，区间和=`pre[R]-pre[L-1]`
>
> 🔲 **二维公式**：容斥原理，矩形和 = 大格 - 上条 - 左条 + 左上角
>
> 下节课学与前缀和密切相关的——**差分思想**！它是前缀和的"逆运算"！🔄
