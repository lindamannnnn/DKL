# CSP06-14 差分思想

## 一、课程简介（5分钟）

### 🎯 课程目标

1. 理解差分的概念：原数组的相邻差值构成的新数组
2. 掌握差分与前缀和的逆运算关系
3. 能用差分数组实现 O(1) 的区间加法操作
4. 掌握二维差分的矩形区域加法应用

### 📚 核心知识点

- 差分概念：`diff[i] = a[i] - a[i-1]`
- 差分与前缀和的关系：差分数组做前缀和 = 原数组
- 一维差分区间操作：`[L,R]` 全部加 v
- 二维差分的矩形区域操作
- 差分的典型应用：多次区间修改、最终输出结果

### 2. 知识点讲解

#### 2.1 差分的定义

原数组 `a[1..n]`，差分数组 `diff[i] = a[i] - a[i-1]`（`diff[1] = a[1]`）

> **关键性质：对 `diff` 数组做前缀和，可以还原回 `a` 数组！**

```cpp
// 构建差分数组
diff[1] = a[1]; diff[0] = 0;
for(int i = 2; i <= n; i++) diff[i] = a[i] - a[i-1];

// 由差分还原原数组（前缀和）
for(int i = 1; i <= n; i++) a[i] = a[i-1] + diff[i];
```

#### 2.2 差分实现区间加法

**对区间 [L,R] 的所有元素加上 v：**

```cpp
// 只需两步操作（O(1)）：
diff[L] += v;      // 从L开始，所有后续还原时+v
diff[R+1] -= v;    // 从R+1开始，不再+v（抵消）
```

**原理：**

> 还原时，`a[i] = a[i-1] + diff[i]`
>
> `diff[L] += v` → 从 L 开始，还原值每次都比之前多 v
>
> `diff[R+1] -= v` → 从 R+1 开始，抵消加的 v

**完整流程：**

```cpp
// 初始化差分数组（全零数组）
int diff[100005] = {0};

// 对 [L,R] 加 v
diff[L] += v;
diff[R+1] -= v;

// 最终还原，得到修改后的数组
int result[100005];
result[0] = 0;
for(int i=1;i<=n;i++) result[i] = result[i-1] + diff[i];
```

#### 2.3 二维差分

**对矩形区域 (r1,c1)~(r2,c2) 的所有元素加 v：**

```cpp
// 二维差分的四角操作
diff[r1][c1] += v;
diff[r1][c2+1] -= v;
diff[r2+1][c1] -= v;
diff[r2+1][c2+1] += v;

// 还原（做二维前缀和）
for(int i=1;i<=n;i++)
    for(int j=1;j<=m;j++)
        a[i][j] = a[i-1][j] + a[i][j-1] - a[i-1][j-1] + diff[i][j];
```

> **答案：B**（每次操作 O(1)，最后还原 O(n)）

## 四、课堂练习（45分钟）🎈

### 练习 1（基础）：区间加法

**题目描述：**

给长度 n 的数组（初始全0），m 次操作每次对 [L,R] 加 v，最后输出数组。

**输入格式：** n m，m行L R v

**输出格式：** 最终数组

**样例输入：**
```
5 3
1 3 2
2 5 1
3 4 3
```
**样例输出：** `2 3 6 4 1`

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
long long diff[100005], a[100005];
int main(){
    int n,m; cin>>n>>m;
    while(m--){int l,r,v;cin>>l>>r>>v;diff[l]+=v;diff[r+1]-=v;}
    for(int i=1;i<=n;i++){a[i]=a[i-1]+diff[i];cout<<a[i]<<" \n"[i==n];}
    return 0;
}
```

### 练习 2（基础）：有初始值的区间加法

**题目描述：**

```cpp
#include <bits/stdc++.h>
using namespace std;
long long a[100005],diff[100005];

    return 0;
}
```

### 练习 3（综合）：二维区域加法

**题目描述：**

给 n×m 的矩阵（初始全0），q 次操作每次对矩形 (r1,c1)~(r2,c2) 加 v，最后输出矩阵。

**输入格式：** n m q，q行r1 c1 r2 c2 v

**输出格式：** 最终矩阵

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
long long diff[505][505], a[505][505];
int main(){
    int n,m,q; cin>>n>>m>>q;
    while(q--){
        int r1,c1,r2,c2,v; cin>>r1>>c1>>r2>>c2>>v;
        diff[r1][c1]+=v; diff[r1][c2+1]-=v;
        diff[r2+1][c1]-=v; diff[r2+1][c2+1]+=v;
    }
    for(int i=1;i<=n;i++) for(int j=1;j<=m;j++){
        a[i][j]=diff[i][j]+a[i-1][j]+a[i][j-1]-a[i-1][j-1];
        cout<<a[i][j]<<" \n"[j==m];
    }
    return 0;
}
```

### 练习 5（进阶）：差分判断覆盖完整性

**题目描述：**

长度 n 的序列，m 次区间覆盖操作 [Li,Ri]，判断整个 [1,n] 是否被完整覆盖。

**输入格式：** n m，m行L R

**输出格式：** YES（完全覆盖）或 NO

**题解代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int diff[100005], a[100005];
int main(){
    int n,m; cin>>n>>m;
    while(m--){int l,r;cin>>l>>r;diff[l]++;diff[r+1]--;}
    for(int i=1;i<=n;i++){a[i]=a[i-1]+diff[i];if(a[i]==0){cout<<"NO";return 0;}}
    cout<<"YES"; return 0;
}
```

## 五、课堂总结（5分钟）🌟

> 差分是前缀和的逆运算，专门应对"区间批量修改"场景！
>
> **两句话记住差分：**
>
> ➕ **区间加 v**：`diff[L]+=v, diff[R+1]-=v`，O(1) 搞定
>
> 🔄 **还原结果**：对差分数组求前缀和即得修改后的原数组
>
> **搭配前缀和：** "修改用差分，查询用前缀和"——二者一对，所向披靡！
>
> 下节课进入算法核心专题——**动态规划（DP）**！这是竞赛中最重要的算法之一！🔥

#### 作业 3：区间最大覆盖次数

n 个路段，m 次 [L,R] 覆盖，求被覆盖次数最多的路段被覆盖了多少次。

```cpp
#include <bits/stdc++.h>
using namespace std;
int diff[100005], a[100005];
int main(){
    int n,m; cin>>n>>m;
    while(m--){int l,r;cin>>l>>r;diff[l]++;diff[r+1]--;}
    int ans=0;
    for(int i=1;i<=n;i++){a[i]=a[i-1]+diff[i];ans=max(ans,a[i]);}
    cout<<ans; return 0;
}
```
