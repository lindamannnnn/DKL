## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> **🏔️ 数字三角形：让每步都最优**
>
> 一座数字三角形，从顶部出发，每步只能往下走到左下或右下，问到达底部时经过的数字之和最大是多少？
>
> ```
>     5
>    1 3
>   2 7 1
>  4 3 2 5
> ```
>
> 暴力：2^(n-1) 条路径，n=30 时需要 5 亿次运算！
>
> **DP 思路：** "要得到从(i,j)出发到底部的最大值，只需知道(i+1,j)和(i+1,j+1)到底部的最大值"——子问题！

---

### 2. 知识点讲解

#### 2.1 DP 三要素

| 要素 | 含义 |
|------|------|
| **状态定义** | `dp[i]` 代表什么含义（子问题的最优解） |
| **状态转移方程** | 如何从子问题推出当前问题 |
| **初始条件** | 最小子问题的答案 |

> **DP 的本质：** 将原问题分解为若干子问题，利用子问题的解推出原问题的解；同时用表格保存已计算的子问题，避免重复计算。

#### 2.2 DP 适用条件

1. **最优子结构**：大问题的最优解包含子问题的最优解
2. **无后效性**：子问题的解只依赖更小的子问题，不受后续决策影响

#### 2.3 数字三角形（自底向上 DP）

```cpp
// dp[i][j] = 从(i,j)到底部的最大路径和
for(int i = n; i >= 1; i--)
    for(int j = 1; j <= i; j++)
        dp[i][j] = a[i][j] + (i==n ? 0 : max(dp[i+1][j], dp[i+1][j+1]));
cout << dp[1][1];
```

#### 2.4 最长上升子序列（LIS）

**问题：** 求序列中严格递增的最长子序列长度。

**状态：** `dp[i]` = 以第 i 个元素结尾的最长上升子序列长度

**转移：** `dp[i] = max(dp[j]+1)`，对所有 j<i 且 `a[j]<a[i]`

**初始：** `dp[i] = 1`（每个元素自身）

```cpp
for(int i=1;i<=n;i++){
    dp[i]=1;
    for(int j=1;j<i;j++)
        if(a[j]<a[i]) dp[i]=max(dp[i],dp[j]+1);
}
cout<<*max_element(dp+1,dp+n+1);
```

> **时间复杂度：** O(n²)，可用二分优化到 O(n log n)

#### 2.5 最长公共子序列（LCS）

**问题：** 求两个序列的最长公共子序列的长度。

**状态：** `dp[i][j]` = A 的前 i 个元素与 B 的前 j 个元素的 LCS 长度

**转移：**
- `A[i]==B[j]`：`dp[i][j] = dp[i-1][j-1] + 1`
- 否则：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

```cpp
for(int i=1;i<=n;i++) for(int j=1;j<=m;j++){
    if(A[i]==B[j]) dp[i][j]=dp[i-1][j-1]+1;
    else dp[i][j]=max(dp[i-1][j],dp[i][j-1]);
}
cout<<dp[n][m];
```

### 4. 进阶扩展

**LIS 二分优化（O(n log n)）：**

```cpp
vector<int> tails;  // tails[i]=长度为i+1的上升子序列末尾最小值
for(int i=0;i<n;i++){
    auto it=lower_bound(tails.begin(),tails.end(),a[i]);
    if(it==tails.end()) tails.push_back(a[i]);
    else *it=a[i];
}
cout<<tails.size();
```

## 四、课堂练习（45分钟）🎈

### 练习 1（基础）：斐波那契 DP

用 DP（迭代+记忆化）计算 fib(n)。

```cpp
#include <bits/stdc++.h>
using namespace std;
long long dp[50];
int main(){
    int n; cin>>n;
    dp[1]=1; dp[2]=1;
    for(int i=3;i<=n;i++) dp[i]=dp[i-1]+dp[i-2];
    cout<<dp[n]; return 0;
}
```

### 练习 2（基础）：数字三角形

给 n 行数字三角形，从顶到底选一条路，经过的数字之和最大是多少（每步只能左下或右下）？

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,a[105][105],dp[105][105];
int main(){
    cin>>n; for(int i=1;i<=n;i++) for(int j=1;j<=i;j++) cin>>a[i][j];
    for(int j=1;j<=n;j++) dp[n][j]=a[n][j];
    for(int i=n-1;i>=1;i--) for(int j=1;j<=i;j++) dp[i][j]=a[i][j]+max(dp[i+1][j],dp[i+1][j+1]);
    cout<<dp[1][1]; return 0;
}
```

### 练习 3（综合）：最长上升子序列

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,a[1005],dp[1005];
int main(){
    cin>>n; for(int i=1;i<=n;i++) cin>>a[i];
    int ans=0;
    for(int i=1;i<=n;i++){
        dp[i]=1;
        for(int j=1;j<i;j++) if(a[j]<a[i]) dp[i]=max(dp[i],dp[j]+1);
        ans=max(ans,dp[i]);
    }
    cout<<ans; return 0;
}
```

### 练习 4（综合）：最长公共子序列

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,m,dp[1005][1005]; string A,B;
int main(){
    cin>>A>>B; n=A.size(); m=B.size();
    A=" "+A; B=" "+B;
    for(int i=1;i<=n;i++) for(int j=1;j<=m;j++){
        if(A[i]==B[j]) dp[i][j]=dp[i-1][j-1]+1;
        else dp[i][j]=max(dp[i-1][j],dp[i][j-1]);
    }
    cout<<dp[n][m]; return 0;
}
```

### 练习 5（进阶）：最大连续子数组和（DP版）

Kadane 算法：`dp[i]` = 以第 i 个元素结尾的最大子数组和。

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,a[100005]; long long dp,ans;
int main(){
    cin>>n; cin>>a[1]; dp=ans=a[1];
    for(int i=2;i<=n;i++){cin>>a[i];dp=max((long long)a[i],dp+a[i]);ans=max(ans,dp);}
    cout<<ans; return 0;
}
```


#### 作业 2：最大不相邻子序列和
数组中选若干数，任意两个不相邻，使总和最大。

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,a[100005]; long long dp[100005];
int main(){cin>>n;for(int i=1;i<=n;i++)cin>>a[i];dp[1]=a[1];dp[2]=max(a[1],a[2]);for(int i=3;i<=n;i++)dp[i]=max(dp[i-1],dp[i-2]+a[i]);cout<<dp[n];return 0;}
```

#### 作业 3：硬币凑零钱（全覆盖）
给 n 种面值的硬币，每种无限个，能否凑出金额 W？

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,W,c[105]; bool dp[10005];
int main(){
    cin>>n>>W; for(int i=0;i<n;i++) cin>>c[i];
    dp[0]=true;
    for(int i=0;i<n;i++) for(int j=c[i];j<=W;j++) dp[j]=dp[j]||dp[j-c[i]];
    cout<<(dp[W]?"YES":"NO"); return 0;
}
```
