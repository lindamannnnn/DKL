## 一、课程简介（5分钟）

### 🎯 课程目标

1. 理解 01 背包的状态设计与转移方程

4. 了解背包问题的常见变形

### 📚 核心知识点

- 01 背包模型：每件物品最多选一次
- 01 背包状态：`dp[i][j]` = 前 i 件物品装入容量 j 的最大价值
- 01 背包转移：选 or 不选当前物品
- 完全背包模型：每件物品可选无限次
- 一维空间优化：滚动数组（01背包逆序，完全背包正序）

## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> **🎒 探险家的背包**
>
> 探险家要进入宝库，背包最多承重 W。宝库里有 n 件宝物，每件有重量 w[i] 和价值 v[i]。
>
> 每件宝物**只有一个**，要么带走（选），要么留下（不选）——**01 背包**！
>
> 问：如何选使得带走的总价值最大（总重量不超过W）？

---

### 2. 知识点讲解

#### 2.1 01 背包（二维 DP）

**状态：** `dp[i][j]` = 考虑前 i 件物品，背包容量为 j 时的最大价值

**转移：**
- 不选第 i 件：`dp[i][j] = dp[i-1][j]`
- 选第 i 件（需 `j >= w[i]`）：`dp[i][j] = dp[i-1][j-w[i]] + v[i]`
- 取最大值：`dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])`

```cpp
for(int i=1;i<=n;i++) for(int j=0;j<=W;j++){
    dp[i][j]=dp[i-1][j];
    if(j>=w[i]) dp[i][j]=max(dp[i][j],dp[i-1][j-w[i]]+v[i]);
}
cout<<dp[n][W];
```

#### 2.2 01 背包一维优化（空间 O(W)）

**关键：** 对 j 从大到小枚举（逆序），确保每件物品只被选一次：

```cpp
// dp[j] = 容量j时的最大价值
for(int i=1;i<=n;i++)
    for(int j=W;j>=w[i];j--)  // 逆序！
        dp[j]=max(dp[j], dp[j-w[i]]+v[i]);
cout<<dp[W];
```

#### 2.3 完全背包（每件物品可选无限次）

**区别：** 对 j 从小到大枚举（正序），允许多次选同一件物品：

```cpp
for(int i=1;i<=n;i++)
    for(int j=w[i];j<=W;j++)  // 正序！
        dp[j]=max(dp[j], dp[j-w[i]]+v[i]);
cout<<dp[W];
```

> **01背包逆序 vs 完全背包正序的原因：**
>
> 逆序：更新 j 时，`dp[j-w[i]]` 还是上一轮（物品i-1）的值 → 每件只选一次
>
> 正序：更新 j 时，`dp[j-w[i]]` 已经是本轮的值（可能已选过物品i）→ 每件可选多次

### 3. GESP 真题演练 ⚡

**抢答题 1：**

> n=3，W=5，物品：(w=2,v=3),(w=3,v=4),(w=4,v=5)，01背包最大价值？
>
> **答案：7**（选第1和第2件：重2+3=5，价值3+4=7）

**判断题 2：**

> 完全背包中，对 j 从大到小枚举是正确的。（ ）
>
> **答案：✗**（完全背包应从小到大正序，01背包才是逆序。）

**抢答题 3：**

> 01背包和完全背包一维优化的唯一区别是（ ）
>
> A. 状态定义不同  B. 内层循环的枚举顺序不同  C. 转移方程不同  D. 初始条件不同
>
> **答案：B**

### 4. 进阶扩展

**背包计数（方案数变形）：**

```cpp
// dp[j] = 恰好装满容量j的方案数
dp[0]=1; // 恰好装满0的方案：什么都不装，1种
for(int i=1;i<=n;i++)
    for(int j=W;j>=w[i];j--)  // 01背包逆序
        dp[j]+=dp[j-w[i]];
cout<<dp[W];  // 恰好装满W的总方案数
```

## 四、课堂练习（45分钟）🎈

### 练习 1（基础）：经典 01 背包

**题目描述：** n 件物品，背包容量 W，求最大价值。

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,W,w[105],v[105]; long long dp[10005];
int main(){
    cin>>n>>W;
    for(int i=1;i<=n;i++) cin>>w[i]>>v[i];
    for(int i=1;i<=n;i++) for(int j=W;j>=w[i];j--) dp[j]=max(dp[j],dp[j-w[i]]+v[i]);
    cout<<dp[W]; return 0;
}
```

### 练习 2（基础）：完全背包

**题目描述：** n 种物品（每种无限个），背包容量 W，求最大价值。

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,W,w[105],v[105]; long long dp[10005];
int main(){
    cin>>n>>W;
    for(int i=1;i<=n;i++) cin>>w[i]>>v[i];
    for(int i=1;i<=n;i++) for(int j=w[i];j<=W;j++) dp[j]=max(dp[j],dp[j-w[i]]+v[i]);
    cout<<dp[W]; return 0;
}
```

### 练习 3（综合）：凑零钱（完全背包计数）

n 种硬币，每种无限个，凑出 W，求最少硬币数。

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,W,c[105]; int dp[10005];
int main(){
    cin>>n>>W; for(int i=1;i<=n;i++) cin>>c[i];
    fill(dp,dp+W+1,INT_MAX/2); dp[0]=0;
    for(int i=1;i<=n;i++) for(int j=c[i];j<=W;j++) dp[j]=min(dp[j],dp[j-c[i]]+1);
    cout<<(dp[W]>=INT_MAX/2?-1:dp[W]); return 0;
}
```

### 练习 4（综合）：背包恰好装满方案数

n 件物品（01），求恰好装满容量 W 的方案数。

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,W,w[105]; long long dp[10005];
int main(){
    cin>>n>>W; for(int i=1;i<=n;i++) cin>>w[i];
    dp[0]=1;
    for(int i=1;i<=n;i++) for(int j=W;j>=w[i];j--) dp[j]+=dp[j-w[i]];
    cout<<dp[W]; return 0;
}
```

### 练习 5（进阶）：二维背包（重量+体积双限制）

每件物品有重量 w、体积 vol 和价值 v，背包最多承重 W、体积 V，求最大价值。

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,W,V,w[105],vol[105],val[105]; long long dp[105][105];
int main(){
    cin>>n>>W>>V;
    for(int i=1;i<=n;i++) cin>>w[i]>>vol[i]>>val[i];
    for(int i=1;i<=n;i++) for(int j=W;j>=w[i];j--) for(int k=V;k>=vol[i];k--)
        dp[j][k]=max(dp[j][k],dp[j-w[i]][k-vol[i]]+val[i]);
    cout<<dp[W][V]; return 0;
}
```

## 五、课堂总结（5分钟）🌟

> 背包问题是 DP 殿堂的经典！
>
> **一句话辨别 01 vs 完全：**
>
> 🔄 **01背包逆序**：每件物品只选一次（逆序防止重复）
>
> ♾️ **完全背包正序**：每件物品可选无限次（正序允许重复）
>
> 记住这个顺序，背包题就再也不怕了！💪

#### 作业 2：零件拼装（完全背包）
n种零件每种无限，总容量W，求最多能拼多少价值。（同练习2）

#### 作业 3：凑整数（01背包计数）
n个正整数，是否能选若干个使其和为target？输出YES/NO。

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,target,a[105]; bool dp[10005];
int main(){
    cin>>n>>target; for(int i=1;i<=n;i++) cin>>a[i];
    dp[0]=true;
    for(int i=1;i<=n;i++) for(int j=target;j>=a[i];j--) dp[j]=dp[j]||dp[j-a[i]];
    cout<<(dp[target]?"YES":"NO"); return 0;
}
```
