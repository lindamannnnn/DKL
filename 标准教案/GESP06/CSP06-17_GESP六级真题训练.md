**第1题：** 关于深度优先搜索（DFS），以下描述正确的是（ ）

> A. DFS 使用队列实现
> B. DFS 保证找到最短路径
> C. DFS 使用栈或递归实现，按"深度优先"探索
> D. DFS 时间复杂度始终是 O(n)

> **答案：C**

**第2题：** 以下哪个结构体定义是合法的 C++ 类？（ ）

> A. `class A { int x; public: A() {} };`  ✓
> B. `class A() { int x; };`  ✗（括号错误）
> C. `class A { A() = delete; A() {} };`  ✗（重复定义）
> D. `class A { return int x; };`  ✗（语法错误）

### 编程题环节（每题25分）

#### 编程题 1：图的连通分量

**题目描述：**

给一个 n×m 的字符图，`#` 代表陆地，`.` 代表海洋。用 DFS/BFS 统计陆地连通块（岛屿）的数量，并输出最大岛屿的面积（格子数）。

**输入格式：**
- 第一行：n m（1≤n,m≤100）
- 接下来 n 行字符图

**输出格式：**
- 第一行：岛屿数量
- 第二行：最大岛屿面积

**样例输入：**
```
4 5
##..#
.#...
.####
.....
```

**样例输出：**
```
3
4
```

**参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,m,cnt,maxArea;
char a[105][105];
bool vis[105][105];
int dx[]={-1,1,0,0}, dy[]={0,0,-1,1};

int dfs(int x, int y) {
    vis[x][y]=true; int area=1;
    for(int i=0;i<4;i++) {
        int nx=x+dx[i], ny=y+dy[i];
        if(nx>=1&&nx<=n&&ny>=1&&ny<=m&&a[nx][ny]=='#'&&!vis[nx][ny])
            area+=dfs(nx,ny);
    }
    return area;
}

int main() {
    cin>>n>>m;
    for(int i=1;i<=n;i++) for(int j=1;j<=m;j++) cin>>a[i][j];
    for(int i=1;i<=n;i++) for(int j=1;j<=m;j++)
        if(a[i][j]=='#'&&!vis[i][j]) { cnt++; maxArea=max(maxArea,dfs(i,j)); }
    cout<<cnt<<"\n"<<maxArea;
    return 0;
}
```

#### 编程题 2：最大价值背包

**题目描述：**

n 件物品，背包容量 W。每件物品有重量 w[i] 和价值 v[i]。求 01 背包的最大总价值，并输出选择了哪些物品（输出物品编号，按从小到大排序）。

**输入格式：**
- 第一行：n W（1≤n≤100，1≤W≤1000）
- 接下来 n 行：w[i] v[i]

**输出格式：**
- 第一行：最大价值
- 第二行：选择的物品编号（空格隔开）

**样例输入：**
```
4 10
3 4
4 5
5 6
2 3
```

**样例输出：**
```
12
1 2 4
```

**参考代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int n,W,w[105],v[105];
long long dp[105][1005];

int main() {
    cin>>n>>W;
    for(int i=1;i<=n;i++) cin>>w[i]>>v[i];
    for(int i=1;i<=n;i++) for(int j=0;j<=W;j++){
        dp[i][j]=dp[i-1][j];
        if(j>=w[i]) dp[i][j]=max(dp[i][j],dp[i-1][j-w[i]]+v[i]);
    }
    cout<<dp[n][W]<<"\n";
    // 回溯找选了哪些物品
    vector<int> chosen;
    int j=W;
    for(int i=n;i>=1;i--) {
        if(dp[i][j]!=dp[i-1][j]) { chosen.push_back(i); j-=w[i]; }
    }
    sort(chosen.begin(),chosen.end());
    for(int x:chosen) cout<<x<<" ";
    return 0;
}
```
