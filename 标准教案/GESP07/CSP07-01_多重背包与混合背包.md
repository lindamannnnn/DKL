### 2. 知识点讲解

#### 2.1 多重背包模型定义

**问题描述：**

有一个容量为 V 的背包，共 N 种物品。第 i 种物品的体积为 `c[i]`，价值为 `w[i]`，**最多可选 num[i] 件**。

求在总体积不超过 V 的条件下，能获得的最大价值。

> **与0/1背包的对比：**
> | 背包类型 | 每种物品可选数量 | 枚举维度 |
> |--------|------------|--------|
> | 0/1背包 | 0 或 1 | 选/不选 |
> | 完全背包 | 无限 | 选多少件 |
> | **多重背包** | **0 到 num[i]** | **选 k 件（0≤k≤num[i]）** |

---

#### 2.2 朴素解法（三重循环）

对于第 i 件物品，枚举选 k 件（k 从 0 到 num[i]），状态转移方程为：

```cpp
// 对于每件物品 i，枚举选取 k 件
for (int k = 0; k <= num[i]; k++) {
    dp[j] = max(dp[j], dp[j - k * c[i]] + k * w[i]);
}
```

完整三重循环代码框架：

```cpp
for (int i = 1; i <= n; i++)           // 枚举物品
    for (int j = V; j >= c[i]; j--)    // 枚举容量（从大到小，因为每件物品最终等效0/1）
        for (int k = 1; k <= num[i] && k * c[i] <= j; k++)  // 枚举选多少件
            dp[j] = max(dp[j], dp[j - k * c[i]] + k * w[i]);
```

> **时间复杂度分析：**
> O(N × V × max_num)，当 num[i] 较大时效率较低。
>
> 例如：N=1000，V=10000，num=1000 → 约 10^10 次运算，会超时！

> ❓ 互动提问：有没有办法让多重背包变成我们熟悉的 0/1 背包呢？

---

#### 2.3 二进制分组优化 ⚡

**核心思路**：将 num[i] 个相同物品，用**二进制**的方式拆成若干"组合物品"，每个组合当作一件新物品，再用 0/1 背包求解。

**为什么能这样做？**

> 任意一个正整数，都可以用二进制表示。
> 例如 num[i] = 13，二进制为 1101：
> - 13 = 1 + 2 + 4 + 6（1+2+4=7，余 13-7=6）
> - 拆成：1件、2件(组合)、4件(组合)、6件(组合)，共 4 个新物品
> - 0 到 13 之间的任意数，都能用这 4 个数的子集表示！

**拆分规律：**
- 先按 1, 2, 4, 8, ... 依次拆
- 最后剩余的数单独成一组

```cpp
// 二进制拆分函数
vector<pair<int,int>> items; // 存储拆分后的(体积, 价值)

for (int i = 1; i <= n; i++) {
    int c, w, s;
    cin >> c >> w >> s;
    // 二进制拆分
    for (int k = 1; k <= s; k *= 2) {
        items.push_back({k * c, k * w});
        s -= k;
    }
    if (s > 0) items.push_back({s * c, s * w});
}

// 对所有新物品做0/1背包
for (auto [ci, wi] : items) {
    for (int j = V; j >= ci; j--) {
        dp[j] = max(dp[j], dp[j - ci] + wi);
    }
}
```

> **优化效果：**
> 对 num[i] 个物品，拆分后产生约 log₂(num[i]) 个新物品。
>
> 复杂度从 O(N×V×num) 降至 O(N×V×log(num))，大大提速！

---

#### 2.4 混合背包的求解

**混合背包**：同一个背包问题中，不同物品的类型不同：
- 有些物品只能选 0/1 件（0/1背包）
- 有些物品可无限选（完全背包）
- 有些物品最多选 num[i] 件（多重背包）

**解决策略：分类处理**

> 对每件物品，根据其类型决定其处理方式：
> - 若 num[i] = 1 → 0/1背包处理（逆序枚举容量）
> - 若 num[i] = ∞（或极大值）→ 完全背包处理（正序枚举容量）
> - 否则 → 二进制拆分后，用0/1背包处理

```cpp
for (int i = 1; i <= n; i++) {
    int c, w, s;
    cin >> c >> w >> s;
    
    if (s == -1) {  // 0/1背包（-1表示只有1件）
        for (int j = V; j >= c; j--)
            dp[j] = max(dp[j], dp[j - c] + w);
    } else if (s == 0) {  // 完全背包（0表示无限件）
        for (int j = c; j <= V; j++)
            dp[j] = max(dp[j], dp[j - c] + w);
    } else {  // 多重背包，二进制拆分
        for (int k = 1; k <= s; k *= 2) {
            int kc = k * c, kw = k * w;
            for (int j = V; j >= kc; j--)
                dp[j] = max(dp[j], dp[j - kc] + kw);
            s -= k;
        }
        if (s > 0) {
            for (int j = V; j >= s * c; j--)
                dp[j] = max(dp[j], dp[j - s * c] + s * w);
        }
    }
}
```

#### 2.6 进阶扩展：单调队列优化（了解）

多重背包的朴素三重循环，可以用**单调队列**进一步优化到 O(N×V)。

> **优化思路（黑板推演）：**
>
> 按余数分组枚举：将 j 按模 c[i] 的余数分成若干组，
> 同一组内的状态满足特定的窗口结构，
> 利用滑动窗口的单调队列，每次 O(1) 完成最大值查询。
>
> 这是竞赛中的进阶优化，了解思路即可，工程实现较复杂。

### 练习1：多重背包板题（基础）

**题目描述：**

有一个容量为 V 的背包，共 N 种物品，第 i 种物品体积为 c[i]，价值为 w[i]，数量为 num[i]。求能放入背包的最大价值。

**输入格式：**
- 第一行：N V
- 接下来 N 行，每行三个整数 c[i] w[i] num[i]

**输出格式：**
- 一个整数，表示最大价值

**样例输入：**
```
4 20
3 5 3
2 6 2
6 4 2
10 10 2
```

**样例输出：**
```
32
```

**思路分析：** 直接使用二进制拆分 + 0/1背包模板。

**参考代码：**
```cpp
#include <iostream>
#include <vector>
using namespace std;

int dp[10005];

int main() {
    int n, V;
    cin >> n >> V;
    
    vector<pair<int,int>> items;
    for (int i = 1; i <= n; i++) {
        int c, w, s;
        cin >> c >> w >> s;
        // 二进制拆分
        for (int k = 1; k <= s; k *= 2) {
            items.push_back({k * c, k * w});
            s -= k;
        }
        if (s > 0) items.push_back({s * c, s * w});
    }
    
    // 0/1背包
    for (auto [ci, wi] : items) {
        for (int j = V; j >= ci; j--)
            dp[j] = max(dp[j], dp[j - ci] + wi);
    }
    
    cout << dp[V] << endl;
    return 0;
}
```

### 练习3：砝码称重（综合）

**题目描述：**

有重量分别为 1g、2g、3g、5g、10g、20g 的砝码各若干枚（总重 ≤ 1000g），求用这些砝码能称出多少种不同的重量（不包含0）。

**输入格式：**
- 一行六个整数，依次表示6种砝码的数量

**输出格式：**
- `Total=XXX`

**样例输入：**
```
1 1 0 0 0 0
```

**样例输出：**
```
Total=3
```

**思路分析：**

用布尔型 dp，dp[j] 表示重量 j 是否可以被组合出来。多重背包框架：

**参考代码：**
```cpp
#include <iostream>
using namespace std;

int w[] = {0, 1, 2, 3, 5, 10, 20};
int a[10];
bool dp[1005];

int main() {
    for (int i = 1; i <= 6; i++) cin >> a[i];
    dp[0] = true;
    
    for (int i = 1; i <= 6; i++) {
        // 将第i种砝码二进制拆分后做0/1背包
        int s = a[i];
        for (int k = 1; k <= s; k *= 2) {
            int wt = k * w[i];
            for (int j = 1000; j >= wt; j--)
                dp[j] = dp[j] || dp[j - wt];
            s -= k;
        }
        if (s > 0) {
            int wt = s * w[i];
            for (int j = 1000; j >= wt; j--)
                dp[j] = dp[j] || dp[j - wt];
        }
    }
    
    int cnt = 0;
    for (int j = 1; j <= 1000; j++)
        if (dp[j]) cnt++;
    
    cout << "Total=" << cnt << endl;
    return 0;
}
```

### 练习4：混合背包（综合）

**题目描述：**

有一个容量为 C 的背包，共 N 件物品，每件物品有体积 w 和价值 v，以及类型 t：
- t=0：该物品只有1件（0/1背包）
- t=-1：该物品无限件（完全背包）
- t>0：该物品有 t 件（多重背包）

求能装入背包的最大价值。

**输入格式：**
- 第一行：N C
- 接下来 N 行：v w t

**输出格式：**
- 最大价值

**样例输入：**
```
4 10
2 3 0
3 5 -1
4 7 2
1 2 3
```

**样例输出：**
```
19
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;

int dp[10005];

void zeroOne(int c, int w, int V) {
    for (int j = V; j >= c; j--)
        dp[j] = max(dp[j], dp[j - c] + w);
}

void complete(int c, int w, int V) {
    for (int j = c; j <= V; j++)
        dp[j] = max(dp[j], dp[j - c] + w);
}

int main() {
    int n, V;
    cin >> n >> V;
    
    for (int i = 0; i < n; i++) {
        int c, w, t;
        cin >> c >> w >> t;
        
        if (t == 0) {          // 0/1背包
            zeroOne(c, w, V);
        } else if (t == -1) {  // 完全背包
            complete(c, w, V);
        } else {               // 多重背包（二进制拆分）
            int s = t;
            for (int k = 1; k <= s; k *= 2) {
                zeroOne(k * c, k * w, V);
                s -= k;
            }
            if (s > 0) zeroOne(s * c, s * w, V);
        }
    }
    
    cout << dp[V] << endl;
    return 0;
}
```

**作业3：判断题与简答**

1. 多重背包的二进制分组优化中，将 num[i] = 10 的物品拆分，会产生几个新物品？

> 答：按 1+2+4=7，余3，拆成3个：1件组合、2件组合、3件组合，共 **3个**新物品。

2. 混合背包中，如何确定对每件物品使用哪种背包策略？

> 答：根据物品的数量类型分类：num=1用0/1背包（逆序），num=∞用完全背包（正序），num=k用多重背包（二进制拆分+0/1背包）。

### 🔥 拓展习题（尖子生挑战，7道）

**挑战1：二进制拆分的正确性证明**

证明：对于任意正整数 n，将其按 1, 2, 4, ..., 2^k, r 拆分后，用这些数的子集可以表示 [0, n] 中的所有整数。

> 思路提示：用数学归纳法，证明每次加入 2^k 后，可表示范围从 [0, S] 扩展到 [0, S+2^k]。

**挑战2：多重背包朴素解法超时分析**

给出一个多重背包问题（N=100，V=1000，num[i]≤100），计算朴素三重循环和二进制优化的操作次数之比约为多少？

> 思路提示：朴素约 100×1000×100=10^7，优化约 100×1000×7≈7×10^5，比约 14:1。

**挑战3：混合背包综合**

洛谷 P1833 樱花，结合多重背包和完全背包求解。

> 思路提示：读入每种物品的类型，分类处理，时间不够则用完全背包，否则用多重背包。

**挑战4：多重背包求方案数**

若将多重背包的目标从"最大价值"改为"恰好装满的方案总数"，状态转移方程如何修改？

> 思路提示：dp[j] 改为方案数，初始化 dp[0]=1，转移时用加法代替 max。

**挑战5：单调队列优化多重背包**

了解并实现多重背包的单调队列 O(NV) 优化。

> 思路提示：将 dp 数组按模 c[i] 的余数分组，每组内用滑动窗口最大值（单调队列）求解。

**挑战6：背包问题变体——恰好装满**

将经典多重背包的"不超过V"改为"恰好等于V"，初始化和转移有什么变化？

> 思路提示：初始化 dp[0]=0，dp[1..V]=-∞（或极小值），转移时只从合法状态转移，最终答案为 dp[V]（若为负则无解）。

**挑战7：二维费用的多重背包**

每件物品有两个费用（体积和重量），背包有两个限制（最大体积 V 和最大重量 W），求最大价值。

> 思路提示：dp[j][k] 表示体积不超过 j、重量不超过 k 的最大价值，二进制拆分后套二维 0/1 背包框架。
