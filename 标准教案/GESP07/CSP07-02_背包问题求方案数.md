# CSP07-02 背包问题求方案数

## 一、课程简介（5分钟）

### 课程目标 🎯

1. 理解将"求最优值"转化为"求方案数"的DP思维转换
2. 掌握背包问题方案数的状态转移方程（加法代替max）
3. 理解 dp[0]=1 的初始化含义，掌握初始化细节
4. 能求解"最优价值对应的方案数"这一复合问题

### 核心知识点 📚

- 方案数 DP：将 `max` 替换为求和（`sum`）
- 状态定义：dp[j] 表示恰好用体积 j 的物品组合的方案数
- 转移方程：`dp[j] = dp[j] + dp[j - w[i]]`
- 初始化：`dp[0] = 1`（空集是一种合法方案）
- 求最优价值下的方案数：双数组联合维护

### 2. 知识点讲解

#### 2.1 从求最优值到求方案数

**两类问题对比：**

| 问题类型 | 状态含义 | 初始化 | 转移方式 |
|--------|--------|-------|--------|
| 求最大价值 | dp[j] = 体积不超过j的最大价值 | dp[0..V] = 0 | max |
| **求方案数** | dp[j] = **恰好**体积为j的方案数 | dp[0]=1, dp[1..V]=0 | **加法（sum）** |

> **关键区别：**
> - 求最优值时，不关心"不超过"还是"恰好"——因为 max 中包含了不选的情况
> - 求方案数时，必须明确是"**恰好**"满足某条件的方案数

---

#### 2.2 方案数的状态转移

以 0/1 背包为例，设 dp[j] 表示**恰好**体积为 j 的方案数：

**转移方程：**
```cpp
dp[j] = dp[j] + dp[j - w[i]];
// 含义：不选第i件（方案数dp[j]不变）+ 选第i件（从体积j-w[i]的方案转来）
```

**初始化：**
```cpp
dp[0] = 1;  // 什么都不选，是一种合法方案（空集）
dp[1..V] = 0;  // 初始时，其余体积均无法达到
```

**枚举顺序：** 与0/1背包相同，容量从大到小枚举

```cpp
#include <iostream>
using namespace std;

long long dp[10005];

int main() {
    int n, V;
    cin >> n >> V;
    
    dp[0] = 1;  // 关键初始化！
    
    for (int i = 1; i <= n; i++) {
        int w, v;
        cin >> w >> v;  // 这里 v 暂时不用，只关心体积
        for (int j = V; j >= w; j--)
            dp[j] = dp[j] + dp[j - w];  // 累加方案数
    }
    
    // dp[V] 就是体积恰好为V的方案总数
    cout << dp[V] << endl;
    return 0;
}
```

> **dp[0]=1 的深刻含义：**
>
> dp[0] = 1 表示"恰好体积为0的方案有1种"，即**空集（什么都不选）**。
> 这是所有方案的"起点"。如果 dp[0]=0，那么所有方案都无法被计数！

---

#### 2.3 完全背包的方案数

完全背包（每种物品无限件）的方案数，枚举顺序改为从小到大：

```cpp
dp[0] = 1;
for (int i = 1; i <= n; i++) {
    int w;
    cin >> w;
    for (int j = w; j <= V; j++)
        dp[j] = dp[j] + dp[j - w];  // 正向枚举允许重复选
}
```

> **经典应用：凑零钱问题**
>
> 有面值为 1、2、5 的硬币，各无限枚，凑出 N 元的方案数？
> 这就是完全背包的方案数问题！

---

#### 2.4 求最优价值下的方案数

这是更复杂的问题：**先求最优价值，再统计达到该最优价值的方案数。**

需要维护两个数组：
- `dp[j]`：体积不超过 j 的最大价值
- `cnt[j]`：体积不超过 j 时，达到最大价值 dp[j] 的方案数

**转移规则：**

当我们更新 dp[j] 时，同步更新 cnt[j]：

```cpp
// 对于物品 i（体积w，价值v）：
for (int j = V; j >= w; j--) {
    if (dp[j - w] + v > dp[j]) {
        dp[j] = dp[j - w] + v;  // 找到更优解，方案数重置
        cnt[j] = cnt[j - w];
    } else if (dp[j - w] + v == dp[j]) {
        cnt[j] += cnt[j - w];   // 同等最优，方案数累加
    }
    // 若 dp[j-w]+v < dp[j]，不更新
}
```

**初始化：**
```cpp
fill(dp, dp + V + 1, 0);     // 最大价值初始为0
fill(cnt, cnt + V + 1, 1);   // 初始时每个体积都有1种方案（空集）
```

> ❓ 互动提问：为什么 cnt 数组初始化为全 1，而不是 cnt[0]=1 其余为 0？
>
> 因为这里 dp[j] 是"不超过"体积 j 的最大价值，初始状态下，体积 [0,V] 的最大价值都是 0，且都有一种方案（空集），所以 cnt 全部初始化为 1。

#### 2.5 GESP真题演练 ⚡

**判断题1：**

> 在背包求方案数问题中，若 dp[0]=0，则所有方案都无法被统计到。（ ）

> 解析：✅ 正确。dp[0]=1 是所有方案的起点，若为0则无法从"空集"状态扩展到任何方案。

**抢答题2：**

> 用面值分别为 1、3 的硬币，凑出 4 元的方案数是多少？

> 解析：方案有 {1+1+1+1}、{1+3}、{3+1}（注意是否有序？无序的话）
>
> 若用0/1背包（每种硬币只能用1枚）：不超过5枚的话，面值1用0或1个，面值3用0或1个，能凑4的方案：{1+3}，共1种。
>
> 若用完全背包：{1×4}、{1×1+3×1}，共2种（不计顺序）。

**抢答题3：**

> 求"最多装入V体积的最优价值对应的方案数"时，cnt 数组应如何初始化？

> 解析：cnt[0..V] 全部初始化为 **1**（因为空集方案对所有体积限制都是合法的初始状态）。

---

#### 2.6 进阶扩展：方案数取模

> **实际竞赛中，方案数可能非常大（指数级别），通常要求对 10^9+7 取模。**
>
> 只需在每次累加后对大质数取模即可：
> ```cpp
> const int MOD = 1e9 + 7;
> cnt[j] = (cnt[j] + cnt[j - w]) % MOD;
> ```

### 练习1：凑零钱方案数（基础）

**题目描述：**

有面值分别为 1、2、5 的硬币，各有无限枚，问凑出 N 元共有多少种方案？（不考虑顺序）

**输入格式：**
- 一个整数 N（1 ≤ N ≤ 100）

**输出格式：**
- 方案总数

**样例输入：**
```
5
```

**样例输出：**
```
4
```

（方案：5，1+1+1+1+1，1+1+1+2，1+2+2）

**参考代码：**
```cpp
#include <iostream>
using namespace std;

long long dp[105];

int main() {
    int n;
    cin >> n;
    
    int coins[] = {1, 2, 5};
    dp[0] = 1;
    
    for (int c : coins)
        for (int j = c; j <= n; j++)
            dp[j] += dp[j - c];
    
    cout << dp[n] << endl;
    return 0;
}
```

**题目描述：**

有一个恰好容量为 V 的背包，共 N 件物品，体积分别为 w[i]。问恰好将背包装满的方案数（每件物品选或不选，选则必须整件放入）。

### 练习3：最优价值的方案数（综合）

**题目描述：**

有一个容量为 V 的背包，共 N 件物品，体积 w[i]，价值 v[i]。求能装入的**最大价值**，以及达到最大价值的**方案数**。

**输入格式：**
- 第一行：N V
- 接下来 N 行：w[i] v[i]

**输出格式：**
- 第一行：最大价值
- 第二行：方案数

**样例输入：**
```
4 10
2 3
3 5
4 7
5 8
```

**样例输出：**
```
15
2
```

**参考代码：**
```cpp
#include <iostream>
#include <cstring>
using namespace std;

int dp[10005];
long long cnt[10005];
const int NEG = -1e9;

int main() {
    int n, V;
    cin >> n >> V;
    
    fill(dp, dp + V + 1, 0);
    fill(cnt, cnt + V + 1, 1LL);
    
    for (int i = 0; i < n; i++) {
        int w, v;
        cin >> w >> v;
        for (int j = V; j >= w; j--) {
            if (dp[j - w] + v > dp[j]) {
                dp[j] = dp[j - w] + v;
                cnt[j] = cnt[j - w];
            } else if (dp[j - w] + v == dp[j]) {
                cnt[j] += cnt[j - w];
            }
        }
    }
    
    cout << dp[V] << endl;
    cout << cnt[V] << endl;
    return 0;
}
```

### 练习4：完全背包方案数（综合）

**题目描述：**

商店有 N 种面值的货币（可无限使用），每种面值为 a[i]。问凑出恰好 M 元的方案数（对 10^9+7 取模）。

**输入格式：**
- 第一行：N M
- 第二行：N 个整数

**输出格式：**
- 方案数 mod (10^9+7)

**样例输入：**
```
3 10
1 2 5
```

**样例输出：**
```
10
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;

const int MOD = 1e9 + 7;
long long dp[100005];

int main() {
    int n, m;
    cin >> n >> m;
    
    dp[0] = 1;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    
    for (int i = 0; i < n; i++)
        for (int j = a[i]; j <= m; j++)
            dp[j] = (dp[j] + dp[j - a[i]]) % MOD;
    
    cout << dp[m] << endl;
    return 0;
}
```

**作业3：简答题**

解释为什么"求最优价值"和"求方案数"的转移方向（枚举顺序）相同，但转移方式（max vs sum）不同？

> 答：枚举顺序（逆序）保证每件物品最多选一次，这是0/1背包的核心约束，两类问题都需要遵守。
> 但目标不同：最优价值要取"选"和"不选"中的较大者（max）；方案数要累计所有可能的选法（sum），两者都不选也是一种方案。

### 🔥 拓展习题（尖子生挑战，7道）

**挑战1：恰好装满的方案数（初始化陷阱）**

将"方案数"问题改为"恰好装满"语义，初始化规则有什么不同？为什么不能全初始化为1？

> 思路提示：dp[0]=1，dp[1..V]=-∞或特殊标记表示"无法达到"，只有可达状态才能转移。

**挑战2：求字典序最小的方案**

在求方案数的同时，如何输出字典序最小的一种方案组合？

> 思路提示：从后向前追踪dp数组，贪心地选择编号最小的物品。

**挑战3：恰好凑出V的最少硬币数**

有N种硬币（无限枚），凑出恰好V时的最少枚数，以及这种最优解的方案数。

> 思路提示：先做完全背包求最少枚数，再在最少枚数相等时累加方案数（cnt数组）。

**挑战4：背包方案数（大数取模）**

洛谷 P1077 加分序列，方案数需要取模，注意初始化和转移时处理取模。

> 思路提示：所有累加操作后 % MOD，确保不溢出。

**挑战5：二维背包的方案数**

背包有体积和重量两个限制，如何统计恰好体积为V、重量为W的方案数？

> 思路提示：dp[j][k] 表示体积j重量k的方案数，转移类似一维版本的二重嵌套。

**挑战6：分组背包的方案数**

N件物品分成若干组，每组最多选一件，求恰好体积为V的方案数。

> 思路提示：分组背包转移时，遍历同一组内的所有物品，方案数累加。

**挑战7：「NOIP 2018」货币系统**

给定货币面值系统，判断哪些面值是"多余"的（可被其他面值凑出），求最小货币系统的大小。

> 思路提示：对所有面值从小到大排序，用完全背包方案数判断当前面值是否能被已选面值组合表示。
