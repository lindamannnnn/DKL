# CSP07-04 最长上升子序列模型（LIS）

## 一、课程简介（5分钟）

### 课程目标 🎯

1. 理解"子序列"与"子数组"的区别，建立 LIS 问题的直觉
2. 掌握 LIS 的状态定义与 O(n²) 动态规划解法
3. 能够推导并验证 LIS 的状态转移方程
4. 了解 LIS 的常见变形（最长不下降子序列等）

### 核心知识点 📚

- LIS 模型：最长严格上升子序列（Longest Increasing Subsequence）
- 状态定义：`dp[i]` = 以第 i 个元素结尾的最长上升子序列长度
- 状态转移方程：`dp[i] = max(dp[j] + 1)`，其中 j < i 且 a[j] < a[i]
- 最终答案：`max(dp[1..n])`
- O(n²) 解法的枚举方式与边界处理

### 2. 知识点讲解

#### 2.1 LIS 的正式定义

**问题描述：**

给定一个长度为 n 的整数序列 a[1..n]，找出一个**最长的上升子序列**，使得该子序列中的元素严格递增（每个元素比前一个大）。

**示例：**

序列：`5, 2, 8, 6, 3, 6, 9, 7`

可能的上升子序列：
- `2, 3, 6, 9`：长度4 ✓
- `2, 6, 9`：长度3
- `5, 8, 9`：长度3
- `2, 3, 7`：长度3

**LIS 长度 = 4**（如 `2, 3, 6, 9` 或 `2, 3, 6, 7`）

---

#### 2.2 状态定义

> **关键设计：**
>
> 如果我们定义 `dp[i]` 为"前 i 个元素中的最长上升子序列长度"，转移会很复杂（我们不知道这个子序列是否以 a[i] 结尾）。
>
> **正确的定义：** `dp[i]` = **以 a[i] 结尾**的最长上升子序列的长度

**为什么这样定义？**

固定了子序列的**结尾元素**，使得状态之间的转移关系变得清晰：

- 若 a[j] < a[i] 且 j < i，则可以在以 a[j] 结尾的上升子序列后面，追加 a[i]
- dp[i] 取所有这样的 dp[j] + 1 的最大值

---

#### 2.3 状态转移方程

```
dp[i] = max(dp[j] + 1)    其中 j < i 且 a[j] < a[i]
dp[i] = 1（初始值，至少自身为一个长度1的子序列）
```

**枚举方式：**

```cpp
for (int i = 1; i <= n; i++) {
    dp[i] = 1;  // 初始：只有自身
    for (int j = 1; j < i; j++) {
        if (a[j] < a[i]) {
            dp[i] = max(dp[i], dp[j] + 1);
        }
    }
}
```

**最终答案：**

```cpp
int ans = 0;
for (int i = 1; i <= n; i++)
    ans = max(ans, dp[i]);
cout << ans << endl;
```

> **逐步推演示例（黑板演示）：**
>
> 序列：3, 1, 4, 1, 5, 9, 2, 6
>
> | i | a[i] | 满足条件的 j | dp[i] |
> |---|------|------------|-------|
> | 1 | 3    | 无          | 1     |
> | 2 | 1    | 无          | 1     |
> | 3 | 4    | j=1(a=3<4),j=2(a=1<4) | max(1,1)+1=2 |
> | 4 | 1    | 无（没有比1更小的） | 1 |
> | 5 | 5    | j=1,2,3,4 → 3<5,1<5,4<5,1<5 → max dp=2 → dp[5]=3 |
> | 6 | 9    | j=1..5 全部 < 9 → max dp=3 → dp[6]=4 |
> | 7 | 2    | j=2,j=4(1<2) → dp=1 → dp[7]=2 |
> | 8 | 6    | j满足<6: dp[3]=2,dp[5]=3,dp[7]=2 → max=3 → dp[8]=4 |
>
> 最终 max(dp) = max(1,1,2,1,3,4,2,4) = **4**

---

#### 2.4 完整代码

```cpp
#include <iostream>
using namespace std;

const int MAXN = 1005;
int a[MAXN], dp[MAXN];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        dp[i] = 1;  // 至少是自身
        for (int j = 1; j < i; j++)
            if (a[j] < a[i])
                dp[i] = max(dp[i], dp[j] + 1);
        ans = max(ans, dp[i]);
    }
    
    cout << ans << endl;
    return 0;
}
```

> **时间复杂度：** O(n²)，对 n ≤ 5000 的问题足够

#### 2.5 GESP真题演练 ⚡

**抢答题1：**

> 序列 [1, 5, 2, 4, 3] 的 LIS 长度是多少？请说出一条最长的上升子序列。

> 解析：dp = [1, 2, 2, 3, 3]，LIS 长度为 **3**。
> 例如：1,2,4 或 1,2,3 或 1,4,... 不，1,5 → 2→找比2大的→4或3（4>3，选4→下一个比4大→无）1→2→4 ✓ 长度3。

**判断题2：**

> dp[i] 的含义是"前 i 个元素中以某元素结尾的最长上升子序列长度"，因此最终答案是 dp[n]。（ ）

> 解析：❌ 错误。dp[i] 是**以 a[i] 结尾**的 LIS 长度，最终答案是 **max(dp[1..n])**，因为最长子序列不一定以最后一个元素结尾。

**抢答题3：**

> 若将"严格上升（a[j] < a[i]）"改为"不下降（a[j] ≤ a[i]）"，状态转移方程如何修改？

> 解析：只需将 `a[j] < a[i]` 改为 `a[j] <= a[i]`，求的就是**最长不下降子序列**。

---

#### 2.6 进阶扩展：LIS 的应用变形

**变形1：最长不下降子序列**

将 `<` 改为 `<=` 即可

**变形2：最长下降子序列**

将条件改为 `a[j] > a[i]`

**变形3：输出具体方案**

用 `pre[i]` 记录 dp[i] 从哪个 j 转移来，最后回溯输出

```cpp
int pre[MAXN] = {0};  // 记录前驱下标

// 在转移时记录前驱
if (a[j] < a[i] && dp[j] + 1 > dp[i]) {
    dp[i] = dp[j] + 1;
    pre[i] = j;
}

// 回溯输出
int idx = 0;
for (int i = 1; i <= n; i++) if (dp[i] > dp[idx]) idx = i;
vector<int> path;
while (idx) {
    path.push_back(a[idx]);
    idx = pre[idx];
}
reverse(path.begin(), path.end());
for (int x : path) cout << x << " ";
```

### 练习3：输出 LIS 路径（综合）

**题目描述：**

给定长度为 N 的整数序列，输出一条最长严格上升子序列（若有多条输出字典序最小的一条）。

**输入格式：**
- 第一行：N
- 第二行：N 个整数

**输出格式：**
- 一条最长上升子序列的元素，空格分隔

**样例输入：**
```
6
3 1 2 4 3 5
```

**样例输出：**
```
1 2 4 5
```

**参考代码：**
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
int a[1005], dp[1005], pre[1005];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int ans = 0, last = 0;
    for (int i = 1; i <= n; i++) {
        dp[i] = 1; pre[i] = 0;
        for (int j = 1; j < i; j++)
            if (a[j] < a[i] && dp[j]+1 > dp[i]) {
                dp[i] = dp[j]+1; pre[i] = j;
            }
        if (dp[i] > ans) { ans = dp[i]; last = i; }
    }
    vector<int> path;
    for (int idx = last; idx; idx = pre[idx])
        path.push_back(a[idx]);
    reverse(path.begin(), path.end());
    for (int x : path) cout << x << " ";
    cout << endl;
    return 0;
}
```

## 五、课堂总结（5分钟）🌟

> 今天我们学习了 DP 领域的经典模型——**最长上升子序列（LIS）**！
>
> **核心要点：**
> - `dp[i]` 定义为"以 a[i] 结尾的 LIS 长度"，固定结尾是关键
> - 转移：枚举所有 j<i 且 a[j]<a[i]，取 dp[j]+1 的最大值
> - 答案是 max(dp[1..n])，不是 dp[n]！
>
> **思路可扩展：**
> - 改变比较条件 → 不下降子序列、下降子序列
> - 记录 pre 数组 → 输出具体方案
>
> 下节课我们学习**最长公共子序列（LCS）**，这是 LIS 的二维升级版，同样精彩！

### 🔥 拓展习题（尖子生挑战，7道）

**挑战1：O(n log n) 的 LIS**

用二分查找与贪心维护"单调栈"，将 LIS 时间复杂度从 O(n²) 降至 O(n log n)。

> 思路提示：维护一个数组 tails，tails[k] 表示长度为 k 的上升子序列的最小末尾元素，对每个 a[i] 用二分查找其位置并更新。

**挑战2：最长公共上升子序列（LCIS）**

给两个序列，求既是两个序列的公共子序列，又是严格上升的，最长的长度。

> 思路提示：dp[i][j] = 以 B[j] 结尾的 A 前 i 个与 B 前 j 个的最长公共上升子序列长度。

**挑战3：导弹拦截（第二问）**

NOIP2002 导弹拦截第二问：至少需要几套拦截系统才能拦截所有导弹？

> 思路提示：贪心+Dilworth定理，答案等于最长严格上升子序列长度。

**挑战4：最长摆动子序列**

一个序列，相邻元素交替大小（即先增后减再增...），求最长摆动子序列。

> 思路提示：用两个 DP 数组，up[i] 和 down[i]，分别表示以上升/下降结尾的最长摆动子序列长度。

**挑战5：二维 LIS**

给 n 个箱子，每个箱子有 (长, 宽)，要找最长的嵌套链（小箱子完全放入大箱子），求最多能嵌套几个？

> 思路提示：按长度排序，对宽度求 LIS。

**挑战6：最长等差子序列**

给定序列，求最长的等差子序列长度（子序列中相邻元素差相同）。

> 思路提示：dp[i][d] = 以 a[i] 结尾，公差为 d 的最长等差子序列，用 map 存储。

**挑战7：滑动窗口内的 LIS**

给定序列和窗口大小 K，求每个长度为 K 的窗口内的 LIS 长度。

> 思路提示：O(K² × (n-K)) 朴素解，或用数据结构（树状数组+线段树）优化。
