1. 理解"公共子序列"的概念，建立 LCS 问题的直觉

### 核心知识点 📚

- LCS 模型：最长公共子序列（Longest Common Subsequence）
- 状态定义：`dp[i][j]` = A 的前 i 个与 B 的前 j 个的最长公共子序列长度
- 状态转移：当 A[i]=B[j] 时 `dp[i][j] = dp[i-1][j-1] + 1`；否则 `max(dp[i-1][j], dp[i][j-1])`
- 滚动数组优化空间复杂度：从 O(N×M) 优化到 O(M)

### 2. 知识点讲解

#### 2.1 LCS 的状态定义

**问题描述：**

给定两个序列 A[1..n] 和 B[1..m]，求它们的最长公共子序列（LCS）的长度。

**状态设计：**

`dp[i][j]` = A 的前 i 个字符与 B 的前 j 个字符的最长公共子序列的长度

---

#### 2.2 状态转移方程推导

> **关键分析：对于 A[i] 和 B[j] 这两个字符，只有两种情况：**

**情况1：A[i] == B[j]**

A 的第 i 个和 B 的第 j 个相同！那么可以把它们都加入公共子序列：

```
dp[i][j] = dp[i-1][j-1] + 1
```

**情况2：A[i] != B[j]**

不能同时选 A[i] 和 B[j]，要从放弃其中一个的最优情况中取较大值：

```
dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

**完整方程：**
```
         ┌ dp[i-1][j-1] + 1        若 A[i] == B[j]
dp[i][j] = ┤
         └ max(dp[i-1][j], dp[i][j-1])  若 A[i] != B[j]
```

**边界条件：**
```
dp[0][j] = 0  // A 为空时，公共子序列长度为 0
dp[i][0] = 0  // B 为空时，公共子序列长度为 0
```

> **黑板推演示例：**
>
> A = "ABCB"，B = "BDCAB"
>
> |   |   | B | D | C | A | B |
> |---|---|---|---|---|---|---|
> |   | 0 | 0 | 0 | 0 | 0 | 0 |
> | A | 0 | 0 | 0 | 0 | 1 | 1 |
> | B | 0 | 1 | 1 | 1 | 1 | 2 |
> | C | 0 | 1 | 1 | 2 | 2 | 2 |
> | B | 0 | 1 | 1 | 2 | 2 | 3 |
>
> LCS 长度 = **3**（如 BCB 或 ACB）

---

#### 2.3 完整代码（基础二维版）

```cpp
#include <iostream>
#include <string>
using namespace std;

int dp[1005][1005];

int main() {
    string A, B;
    cin >> A >> B;
    int n = A.size(), m = B.size();
    
    // dp 数组默认初始化为 0（边界已满足）
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            if (A[i-1] == B[j-1])  // 注意：string 从0开始索引
                dp[i][j] = dp[i-1][j-1] + 1;
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }
    
    cout << dp[n][m] << endl;
    return 0;
}
```

> **时间复杂度：** O(N×M)
> **空间复杂度：** O(N×M)

---

#### 2.4 滚动数组优化空间复杂度

当 N 和 M 较大时，二维数组占用空间过多。观察转移：

`dp[i][j]` 只依赖 `dp[i-1][j-1]`、`dp[i-1][j]`、`dp[i][j-1]`（上一行和当前行）

因此可以用一维数组滚动：

> **注意：** 当 A[i]==B[j] 时，需要用到 `dp[i-1][j-1]`，若直接覆盖，这个值会被丢失！
>
> 解决方案：用临时变量 `pre` 保存 `dp[j-1]` 更新前的值（即 `dp[i-1][j-1]`）。

```cpp
#include <iostream>
#include <string>
using namespace std;

int dp[1005];  // 一维滚动数组

int main() {
    string A, B;
    cin >> A >> B;
    int n = A.size(), m = B.size();
    
    for (int i = 1; i <= n; i++) {
        int pre = 0;  // 保存 dp[i-1][j-1] 的值
        for (int j = 1; j <= m; j++) {
            int temp = dp[j];  // 保存即将被覆盖的 dp[i-1][j]
            if (A[i-1] == B[j-1])
                dp[j] = pre + 1;
            else
                dp[j] = max(dp[j], dp[j-1]);
            pre = temp;  // 更新 pre 为下一轮的 dp[i-1][j-1]
        }
    }
    
    cout << dp[m] << endl;
    return 0;
}
```

> **空间优化效果：** O(N×M) → O(M)！

#### 2.5 GESP真题演练 ⚡

**抢答题1：**

> A = "XMJYAUZ"，B = "MZJAWXU"，LCS 长度是多少？

> 解析：LCS 为 "MJAU"，长度 **4**。

**判断题2：**

> LCS 的滚动数组中，不需要额外的变量 pre，直接用 `dp[j] = max(dp[j], dp[j-1])` 即可。（ ）

> 解析：❌ 错误。当 A[i]==B[j] 时需要用到 dp[i-1][j-1]，而 dp[j-1] 在同一行枚举时已经被更新成了 dp[i][j-1]，所以必须用 pre 变量保存 dp[i-1][j-1] 的旧值。

**抢答题3：**

> "ABAB" 和 "BABA" 的 LCS 长度是多少？

> 解析：LCS 为 "ABA" 或 "BAB"，长度 **3**。

#### 2.6 进阶扩展：LCS 的应用

**应用1：最短公共超序列长度**

包含 A 和 B 作为子序列的最短序列长度 = `|A| + |B| - LCS(A, B)`

**应用2：字符串编辑距离（理解）**

插入、删除操作的最少次数 = `|A| + |B| - 2 × LCS(A, B)`

**应用3：输出具体 LCS**

通过回溯 dp 数组，从 dp[n][m] 开始反向重建 LCS：

```cpp
// 在二维版本中回溯
string lcs = "";
int i = n, j = m;
while (i > 0 && j > 0) {
    if (A[i-1] == B[j-1]) {
        lcs = A[i-1] + lcs;  // 加入当前字符
        i--; j--;
    } else if (dp[i-1][j] > dp[i][j-1]) {
        i--;
    } else {
        j--;
    }
}
cout << lcs << endl;
```

### 练习3：LCS 并输出路径（综合）

**题目描述：**

给定两个字符串，输出一条最长公共子序列（若有多条，输出任意一条）。

**输入格式：**
- 第一行：字符串 A
- 第二行：字符串 B

**输出格式：**
- 一条最长公共子序列

**样例输入：**
```
AGGTAB
GXTXAYB
```

**样例输出：**
```
GTAB
```

**参考代码：**
```cpp
#include <iostream>
#include <string>
using namespace std;
int dp[1005][1005];
int main() {
    string A, B;
    cin >> A >> B;
    int n = A.size(), m = B.size();
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
```

### 练习5：编辑距离（进阶）

**题目描述：**

给定两个字符串 A 和 B，每次操作可以：插入一个字符、删除一个字符、替换一个字符。求将 A 变为 B 的最少操作次数（编辑距离）。

**输入格式：**
- 第一行：字符串 A
- 第二行：字符串 B

**输出格式：**
- 最少编辑操作次数

**样例输入：**
```
kitten
sitting
```

**样例输出：**
```
3
```

**思路分析：**

`dp[i][j]` = 将 A[1..i] 变为 B[1..j] 的最少操作数：
- 若 A[i]==B[j]：dp[i][j] = dp[i-1][j-1]
- 否则：dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])

**参考代码：**
```cpp
#include <iostream>
#include <string>
using namespace std;
int dp[1005][1005];
int main() {
    string A, B;
    cin >> A >> B;
    int n = A.size(), m = B.size();
    for (int i = 0; i <= n; i++) dp[i][0] = i;  // 删除i次
    for (int j = 0; j <= m; j++) dp[0][j] = j;  // 插入j次
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            if (A[i-1] == B[j-1]) dp[i][j] = dp[i-1][j-1];
            else dp[i][j] = 1 + min({dp[i-1][j], dp[i][j-1], dp[i-1][j-1]});
        }
    cout << dp[n][m] << endl;
    return 0;
}
```

## 五、课堂总结（5分钟）🌟

> 今天我们征服了字符串 DP 中的经典利器——**最长公共子序列（LCS）**！
>
> **核心收获：**
> - `dp[i][j]`：A前i个与B前j个的最长公共子序列长度
> - 转移：匹配则 `dp[i-1][j-1]+1`；不匹配则 `max(左, 上)`
> - 滚动数组：用 `pre` 临时变量保存 dp[i-1][j-1]，压缩到 O(M) 空间
>
> **LCS 家族：**
> 编辑距离、最短公共超序列、差异比较……LCS 是这些问题的基础！
>
> 下节课我们进入更强的 DP 模型——**区间DP**，挑战"合并类"问题！

解释为什么对 LCS 使用滚动数组时，需要 `pre` 临时变量，而对背包问题的滚动数组不需要额外变量？

> 答：LCS 中 A[i]==B[j] 时的转移需要 dp[i-1][j-1]，即"左上角"的值。在滚动数组（从左到右更新）中，dp[j-1] 处在更新时已被修改为 dp[i][j-1]，所以需要 `pre` 提前保存旧值。而0/1背包从右到左枚举，dp[j] 更新时右侧的值尚未改变，不存在这个问题。

### 🔥 拓展习题（尖子生挑战，7道）

**挑战1：最短公共超序列**

给两个字符串 A、B，求包含 A 和 B 作为子序列的最短字符串长度。

> 思路提示：答案 = |A| + |B| - LCS(A, B)。

**挑战2：差异数统计**

若将删除操作和插入操作的代价不同（删除代价为 del，插入代价为 ins），如何修改编辑距离 DP？

> 思路提示：转移时，删除对应 dp[i-1][j] + del，插入对应 dp[i][j-1] + ins。

**挑战3：最长公共子串（连续）**

与 LCS 不同，公共子串要求连续，如何修改 DP？

> 思路提示：dp[i][j] 仅当 A[i]==B[j] 时等于 dp[i-1][j-1]+1，否则=0，答案为 max(dp[i][j])。

**挑战4：LCS 数量统计**

给定 A 和 B，统计所有不同 LCS 的数量（对 MOD 取模）。

> 思路提示：同时维护 cnt[i][j]：A前i个与B前j个的 LCS 方案数，配合 dp 同步更新。

**挑战5：回文子序列**

给一个字符串 S，求最长的回文子序列的长度。

> 思路提示：等价于 S 与其反串 S_rev 的 LCS 长度。

**挑战6：三个字符串的 LCS**

给三个字符串 A、B、C，求它们的最长公共子序列长度。

> 思路提示：dp[i][j][k] = A前i个、B前j个、C前k个的最长公共子序列，三维DP。

**挑战7：LCS 的 O(n log n) 优化**

在某些情况下（如序列元素互不相同），可将 LCS 问题转换为 LIS 问题，从而用 O(n log n) 算法求解。

> 思路提示：将 B 中每个元素的出现位置记录到映射中，将 A 中每个元素替换为其在 B 中的位置列表（若有多个，逆序列举），然后对替换后的序列求 LIS。
