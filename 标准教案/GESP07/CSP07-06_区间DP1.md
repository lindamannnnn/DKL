# CSP07-06 区间DP1

## 一、课程简介（5分钟）

### 课程目标 🎯

1. 理解区间 DP 的核心思想：将大区间问题分解为两个小区间问题
2. 掌握区间 DP 的状态定义方式：`dp[i][j]` 表示区间 [i, j] 的最优解
3. 掌握区间 DP 的标准枚举框架（先枚举区间长度，再枚举起点）
4. 会用区间 DP 解决"石子合并"等经典合并问题

### 核心知识点 📚

- 区间 DP 的适用场景：**合并类**、**划分类**问题
- 状态定义：`dp[i][j]` = 区间 [i, j] 上满足某条件的最优值
- 分割点枚举：枚举区间 [i, j] 的最后一次分割点 k（i ≤ k < j）
- 状态转移：`dp[i][j] = min/max(dp[i][k] + dp[k+1][j] + cost(i, k, j))`
- 枚举顺序：**必须**从小区间向大区间推算（按区间长度升序枚举）

## 二、知识回顾（10分钟）

### 教师引导 👩‍🏫

> 同学们，我们已经掌握了序列上的 DP（LIS、LCS）和二维 DP。今天要挑战一种更特殊的 DP —— **区间 DP**！
>
> 它的特点是：问题的"子结构"不是"前缀"，而是"区间"。
> 典型的场景是：把 n 堆石子合并成一堆，问最小代价是多少？
>
> 先来暖热身：如果有 3 堆石子，合并顺序不同，代价也不同！

**互动复习：**

> ❓ 假设有3堆石子，数量分别为 [1, 2, 3]，每次合并相邻两堆，代价是两堆数量之和。
> 
> **合并方式1：** 先合并[1,2]得到3，代价3；再合并[3,3]，代价6。总代价 = 9
>
> **合并方式2：** 先合并[2,3]得到5，代价5；再合并[1,5]，代价6。总代价 = 11
>
> 不同顺序，代价不同！要找**最优合并顺序**，就需要区间 DP！

## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> 同学们，来想象一个场景——矩阵链乘法！
>
> 假设你要计算 A×B×C 三个矩阵的乘积（矩阵维度不同），乘法次数取决于计算顺序：
> - 先算 (A×B) 再乘 C
> - 先算 (B×C) 再乘 A
>
> 不同顺序的计算量可能相差数十倍！
>
> 解决这类**"分割合并"**问题的 DP，叫做**区间动态规划（Interval DP）**。
>
> 核心思想：一个大区间的最优解，来自于**两个更小区间的最优解的组合**。

---

### 2. 知识点讲解

#### 2.1 区间 DP 的模型思想：合并与划分

**合并类问题：**

给定 n 个物品（排成一排），每次合并相邻的物品，直到合并为一个。代价与被合并的物品有关，求最小（或最大）总代价。

**区间 DP 的核心：**

对于区间 [i, j]，最后一次合并一定发生在某个分割点 k（i ≤ k < j），将 [i, k] 和 [k+1, j] 分别合并后再合并在一起。

因此：
```
dp[i][j] = min(dp[i][k] + dp[k+1][j] + cost(i, j))
            对所有 i <= k < j 取最小值
```

---

#### 2.2 状态定义与含义

`dp[i][j]` = 将第 i 堆到第 j 堆石子合并成一堆所需的**最小（或最大）代价**

**边界条件：**

```
dp[i][i] = 0  // 只有一堆，无需合并，代价为0
```

---

#### 2.3 石子合并问题

**问题描述：**

有 N 堆石子排成一排，相邻两堆可以合并，代价为这两堆的石子总数。问将所有石子合并成一堆的最小代价。

**关键：用前缀和辅助计算代价**

合并区间 [i, j] 的代价 = 区间内所有石子数之和 = `sum[j] - sum[i-1]`

其中 `sum[k] = a[1] + a[2] + ... + a[k]`（前缀和）

**状态转移：**
```
dp[i][j] = min(dp[i][k] + dp[k+1][j]) + sum[j] - sum[i-1]
            其中 i <= k < j
```

**枚举顺序（重要！）：**

必须**先枚举短区间，再枚举长区间**——因为长区间的答案依赖短区间的答案。

> **黑板推演：枚举框架**
>
> ```
> for (int len = 2; len <= n; len++) {    // 枚举区间长度（从2开始）
>     for (int i = 1; i + len - 1 <= n; i++) { // 枚举左端点
>         int j = i + len - 1;                  // 右端点
>         dp[i][j] = INF;
>         for (int k = i; k < j; k++) {         // 枚举分割点
>             dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + sum[j] - sum[i-1]);
>         }
>     }
> }
> ```

---

#### 2.4 完整代码

```cpp
#include <iostream>
#include <climits>
using namespace std;

const int MAXN = 305;
int a[MAXN], sum[MAXN], dp[MAXN][MAXN];

int main() {
    int n;
    cin >> n;
    
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        sum[i] = sum[i-1] + a[i];  // 前缀和
    }
    
    // 初始化：区间长度为1时代价为0（默认已是0）
    // 枚举区间长度
    for (int len = 2; len <= n; len++) {
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            dp[i][j] = INT_MAX;
            for (int k = i; k < j; k++) {
                dp[i][j] = min(dp[i][j], 
                               dp[i][k] + dp[k+1][j] + sum[j] - sum[i-1]);
            }
        }
    }
    
    cout << dp[1][n] << endl;
    return 0;
}
```

> **时间复杂度：** O(N³) — 三层嵌套循环
> **空间复杂度：** O(N²)

---

#### 2.5 最大代价变体

若求合并的**最大代价**，只需将 `min` 改为 `max`，同时初始化 `dp[i][j] = 0`（或 INT_MIN）：

```cpp
dp[i][j] = max(dp[i][j], dp[i][k] + dp[k+1][j] + sum[j] - sum[i-1]);
```

---

#### 2.6 GESP真题演练 ⚡

**抢答题1：**

> 4堆石子 [1, 3, 5, 2]，区间 [2, 4]（即 3,5,2）的最小合并代价是多少？

> 解析：
> - 先合并 [2,3]（3+5=8），再合并 [2,4]（8+2=10）：代价 8+10=18
> - 先合并 [3,4]（5+2=7），再合并 [2,4]（3+7=10）：代价 7+10=17
> - 最小代价 = **17**

**判断题2：**

> 区间 DP 中，可以直接按 i 从 1 到 n，j 从 i+1 到 n 的顺序枚举，而不需要按区间长度枚举。（ ）

> 解析：❌ 错误。必须保证计算 dp[i][j] 前，所有更短的区间 dp[i][k] 和 dp[k+1][j] 都已计算完毕。按区间长度枚举是最安全的方式。

**抢答题3：**

> N=5 时，区间 DP 的状态数（即有多少个不同的 dp[i][j] 需要计算）是多少？

> 解析：长度≥2的区间数 = C(5,2) = 10 个，加上5个单元素区间，共 **15** 个状态。

---

#### 2.7 进阶扩展：区间 DP 的框架总结

> **区间 DP 的三要素（黑板小结）：**
>
> 1. **状态**：dp[i][j] = 区间 [i, j] 上满足题意的最优值
> 2. **分割**：枚举分割点 k（i ≤ k < j），将区间一分为二
> 3. **转移**：dp[i][j] = opt(dp[i][k] + dp[k+1][j]) + cost(i, j)
>
> **枚举顺序：先短后长**，保证子问题先算出来。

### 练习1：石子合并最小代价（基础）

**题目描述：**

N 堆石子排成一排，每次可合并相邻两堆，代价为合并后的石子总数，求合并成一堆的最小代价。

**输入格式：**
- 第一行：N（1≤N≤300）
- 第二行：N 个整数（每堆石子数≤100）

**输出格式：**
- 最小合并代价

**样例输入：**
```
4
1 3 5 2
```

**样例输出：**
```
22
```

**参考代码：**
```cpp
#include <iostream>
#include <climits>
using namespace std;
int a[305], s[305], dp[305][305];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) { cin >> a[i]; s[i] = s[i-1]+a[i]; }
    for (int len = 2; len <= n; len++)
        for (int i = 1; i+len-1 <= n; i++) {
            int j = i+len-1;
            dp[i][j] = INT_MAX;
            for (int k = i; k < j; k++)
                dp[i][j] = min(dp[i][j], dp[i][k]+dp[k+1][j]+s[j]-s[i-1]);
        }
    cout << dp[1][n] << endl;
    return 0;
}
```

### 练习3：括号匹配（综合）

**题目描述：**

给定一个只含 `(` 和 `)` 的字符串，每次可以删除一对相邻的（），求最少需要删除多少对括号无法配对的字符（即字符串变空需要最少添加多少括号）。

**输入格式：**
- 一行字符串（仅含 `(` 和 `)`，长度 ≤ 200）

**输出格式：**
- 使字符串完全匹配最少需要添加的括号数

**样例输入：**
```
())(
```

**样例输出：**
```
2
```

**思路分析：**

dp[i][j] = 使 s[i..j] 完全匹配最少需요添加的括号数：
- 若 s[i] 和 s[j] 匹配：dp[i][j] = dp[i+1][j-1]
- 枚举分割点：dp[i][j] = min(dp[i][k] + dp[k+1][j])
- 基础：dp[i][i] = 1（单个括号需要1个配对）

**参考代码：**
```cpp
#include <iostream>
#include <string>
using namespace std;
int dp[205][205];
int main() {
    string s; cin >> s;
    int n = s.size();
    // 初始化：单个字符需要1次操作
    for (int i = 0; i < n; i++) dp[i][i] = 1;
    
    for (int len = 2; len <= n; len++)
        for (int i = 0; i+len-1 < n; i++) {
            int j = i+len-1;
            dp[i][j] = n;  // 初始为较大值
            // 若两端能匹配
            if ((s[i]=='(' && s[j]==')') || (s[i]=='{' && s[j]=='}'))
                dp[i][j] = (len == 2) ? 0 : dp[i+1][j-1];
            // 枚举分割点
            for (int k = i; k < j; k++)
                dp[i][j] = min(dp[i][j], dp[i][k]+dp[k+1][j]);
        }
    cout << dp[0][n-1] << endl;
    return 0;
}
```

### 练习4：能量项链（综合）

**题目描述：**

有 N 颗宝石排成一圈，每颗有质量值。相邻两颗可以融合，产生的能量 = 左石质量 × 右石质量 × 融合后位置石质量。问把所有宝石融合成一颗，最多能产生多少能量？

（本题需要处理**环形**情况，先学线性版本思路）

**线性版本输入格式：**
- 第一行：N
- 第二行：N 个整数（宝石质量）

**输出格式：**
- 最大总能量

**样例输入：**
```
4
1 2 3 4
```

**样例输出：**
```
48
```

**思路分析：**

dp[i][j] = 合并 i 到 j 的最大能量，设 w[i] 为宝石质量：
- 分割点 k：dp[i][j] = max(dp[i][k] + dp[k+1][j] + w[i]*w[k]*w[j+1])
- 类似矩阵链乘法

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int w[305], dp[305][305];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> w[i];
    for (int len = 2; len <= n; len++)
        for (int i = 1; i+len-1 <= n; i++) {
            int j = i+len-1;
            for (int k = i; k < j; k++)
                dp[i][j] = max(dp[i][j], dp[i][k]+dp[k+1][j]+w[i]*w[k+1]*w[j+1]);
        }
    cout << dp[1][n] << endl;
    return 0;
}
```

### 练习5：最优矩阵链乘（进阶）

**题目描述：**

有 N 个矩阵依次相乘，第 i 个矩阵的维度为 p[i-1] × p[i]。相邻矩阵相乘次数为 p[left-1] × p[k] × p[right]，求总乘法次数最少的计算顺序对应的最小次数。

**输入格式：**
- 第一行：N（矩阵个数，2≤N≤500）
- 第二行：N+1 个整数（p[0], p[1], ..., p[N]）

**输出格式：**
- 最少乘法次数

**样例输入：**
```
3
10 100 5 50
```

**样例输出：**
```
7500
```

（(A1×A2)×A3: 10×100×5+10×5×50=5000+2500=7500，另一种(A1×(A2×A3)): 100×5×50+10×100×50=25000+50000=75000）

**参考代码：**
```cpp
#include <iostream>
#include <climits>
using namespace std;
int p[505], dp[505][505];
int main() {
    int n; cin >> n;
    for (int i = 0; i <= n; i++) cin >> p[i];
    for (int len = 2; len <= n; len++)
        for (int i = 1; i+len-1 <= n; i++) {
            int j = i+len-1;
            dp[i][j] = INT_MAX;
            for (int k = i; k < j; k++)
                dp[i][j] = min(dp[i][j], dp[i][k]+dp[k+1][j]+p[i-1]*p[k]*p[j]);
        }
    cout << dp[1][n] << endl;
    return 0;
}
```

石子排成一圈而不是一排，求最小合并代价。

**挑战2：插入括号问题（混合运算）**

> 思路提示：维护两个 dp（最大/最小），分割点时分四种组合（max×max, min×min, max+max, min+min等）。

**挑战3：戳气球**

LeetCode 312，N 个气球排成一排，戳破气球 i 得到 nums[left]*nums[i]*nums[right] 的金币，求戳破所有气球的最大金币数。

> 思路提示：反向思维，考虑"最后戳破"哪个气球，dp[i][j] = 区间 [i, j] 最后戳破某气球 k 的最大值。

**挑战4：多边形剖分**

将 N 个顶点的凸多边形剖分成若干三角形，每个三角形的代价是三个顶点编号之积，求最小剖分总代价。

> 思路提示：与石子合并类似，顶点1固定，枚举第三点 k，dp[i][j] 表示以 1,i,j 为顶点的多边形的最小剖分。

**挑战5：区间 DP 中的记忆化搜索**

用递归+记忆化的方式重写石子合并，与迭代版对比运行效率。

> 思路提示：`solve(i, j)` 函数检查 `memo[i][j]` 是否已算过，否则递归求解。

**挑战6：最大分数的卡牌组**

LeetCode 1039，将多边形三角剖分的最大点权问题。

> 思路提示：与凸多边形剖分类似，定义 dp[i][j] 为剖分三角形的最大积之和。

**挑战7：奇怪的打印机**

LeetCode 664，区间 DP 经典难题，考察分析能力和区间 DP 的设计技巧。

> 思路提示：dp[i][j] 表示打印 s[i..j] 的最少操作数，分析何时可以利用之前的打印。
