### 2. 知识点讲解

#### 2.1 循环顺序与枚举方式的深入理解

**为什么按区间长度枚举正确？**

区间 DP 的计算依赖关系如下：

```
dp[i][j] 依赖 dp[i][k] 和 dp[k+1][j]
其中：len(i,k) < len(i,j)，len(k+1,j) < len(i,j)
```

因此，只要保证**长度较短的区间先算完**，就能保证所有依赖都已满足。

**三种等价的枚举方式：**

```cpp
// 方式1：按区间长度枚举（推荐）
for (int len = 2; len <= n; len++)
    for (int i = 1; i + len - 1 <= n; i++) {
        int j = i + len - 1;
        // 枚举分割点 k ...
    }

// 方式2：按右端点枚举
for (int j = 2; j <= n; j++)
    for (int i = j-1; i >= 1; i--) {
        // 此时 dp[i][k] 和 dp[k+1][j] 是否都已计算?
        // dp[i][k]: k < j，且 i < k，已计算 ✓
        // dp[k+1][j]: k+1 > i，且 k+1 <= j... 需要 dp[k+1][j] 在 dp[i][j] 前已算
        //             若 i 从大到小枚举，k+1 > i，则 dp[k+1][j] 已算 ✓
    }

// 方式3：记忆化搜索（最直观）
int memo[305][305];
memset(memo, -1, sizeof(memo));
int solve(int i, int j) {
    if (i == j) return 0;
    if (memo[i][j] != -1) return memo[i][j];
    memo[i][j] = INF;
    for (int k = i; k < j; k++)
        memo[i][j] = min(memo[i][j], solve(i,k) + solve(k+1,j) + cost(i,j));
    return memo[i][j];
}
```

#### 2.2 边界条件处理详解

**长度为1（单元素）：**
- 石子合并：`dp[i][i] = 0`（一堆石子无需合并）
- 括号匹配：`dp[i][i] = 1`（单个括号需1次添加）
- 矩阵链乘：`dp[i][i] = 0`（单矩阵无需乘法）

**长度为2（双元素）：**

长度为2 时，分割点只有 k=i 一个，这往往是最容易推导出错的地方：

```cpp
// 以石子合并为例，len=2 时：
// dp[i][j] = dp[i][i] + dp[j][j] + sum[j]-sum[i-1]
//           = 0 + 0 + (a[i]+a[j])
//           = a[i] + a[j]  ✓（符合直觉）
```

#### 2.3 括号匹配问题

**问题描述：**

给定一个只含 `(` 和 `)` 的字符串，求使其完全匹配需要**添加**的最少括号数。

**状态定义：** `dp[i][j]` = 使 s[i..j] 完全合法需要添加的最少括号数

**转移分析：**

- 若 `s[i]=='(' && s[j]==')'`：两端可以匹配，`dp[i][j] = dp[i+1][j-1]`（len=2时=0）
- 枚举分割点 k：`dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j])`
- 基础：`dp[i][i] = 1`（单个括号一定需要1个配对）

```cpp
for (int i = 0; i < n; i++) dp[i][i] = 1;
for (int len = 2; len <= n; len++) {
    for (int i = 0; i + len - 1 < n; i++) {
        int j = i + len - 1;
        dp[i][j] = n;  // 初始为大值
        if ((s[i] == '(' && s[j] == ')'))
            dp[i][j] = (len == 2) ? 0 : dp[i+1][j-1];
        for (int k = i; k < j; k++)
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j]);
    }
}
```

#### 2.4 环形区间 DP（复制序列法）

**问题：** 石子排成**圆圈**，求最小合并代价。

**处理方法：破环成链**

将序列复制一倍，变成长为 2N 的线性序列，然后枚举所有长度为 N 的起点：

```cpp
// 将序列复制一倍
for (int i = n+1; i <= 2*n; i++) {
    a[i] = a[i - n];
    s[i] = s[i-1] + a[i];
}

// 在 2N 的线性序列上做区间DP
for (int len = 2; len <= n; len++) {
    for (int i = 1; i + len - 1 <= 2*n; i++) {
        int j = i + len - 1;
        dp[i][j] = INF;
        for (int k = i; k < j; k++)
            dp[i][j] = min(dp[i][j], dp[i][k]+dp[k+1][j]+s[j]-s[i-1]);
    }
}

// 枚举所有长度为N的窗口的最小值
int ans = INF;
for (int i = 1; i <= n; i++)
    ans = min(ans, dp[i][i+n-1]);
```

#### 2.5 GESP真题演练 ⚡

**抢答题1：**

> 字符串 `)()(` 的最少括号添加数是多少？

> 解析：需要在开头添加 (，在倒数第2个 ( 后添加 )，即添加 **2** 个括号，使其变为 ()(()。
> dp 计算：`)()(` → dp[0][3] = min结构... 最终 = **2**。

**判断题2：**

> 环形区间 DP 将序列复制后，需要在长为 2N 的序列上做完整的区间 DP（包括长度 > N 的区间）。（ ）

> 解析：❌ 只需要枚举**长度恰好为 N** 的区间即可（因为答案是将 N 个元素合并，不存在长度>N的情况），但做区间DP时长度从 2 到 N 都要计算。

**抢答题3：**

> 凸多边形三角剖分中，N 个顶点的凸多边形可以被剖分成多少个三角形？

> 解析：**N-2** 个三角形。任意凸多边形的三角剖分数都是 N-2。

#### 2.6 进阶扩展：多边形三角剖分

**问题：** N 个顶点的凸多边形，每次可以连接两个不相邻顶点（对角线），将其剖分成三角形，每个三角形的代价是三顶点编号之积。求最小总代价。

**建模思路：**

固定一条边（如 1-N），枚举第三个顶点 k（2 ≤ k ≤ N-1），将多边形分为三角形 (1,k,N) 和两个较小的多边形：

```
dp[i][j] = 以顶点 i 和 j 为基边时，所有三角形最小代价之和
dp[i][j] = min(dp[i][k] + dp[k][j] + w[i]*w[k]*w[j])
            对所有 i < k < j
```

边界：`dp[i][j] = 0`（当 j-i < 2 时，无法形成三角形）

### 练习1：括号合法化（基础）

**题目描述：**

给一个括号字符串（只含 `(` 和 `)`），求最少需要添加多少括号才能使其完全合法。

**输入格式：**
- 一行字符串

**输出格式：**
- 最少添加括号数

**样例输入：**
```
((()
```

**样例输出：**
```
1
```

**参考代码：**
```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;
int dp[205][205];
int main() {
    string s; cin >> s;
    int n = s.size();
    for (int i = 0; i < n; i++) dp[i][i] = 1;
    for (int len = 2; len <= n; len++)
        for (int i = 0; i+len-1 < n; i++) {
            int j = i+len-1;
            dp[i][j] = n;
            if (s[i]=='(' && s[j]==')') dp[i][j] = (len==2)?0:dp[i+1][j-1];
            for (int k = i; k < j; k++)
                dp[i][j] = min(dp[i][j], dp[i][k]+dp[k+1][j]);
        }
    cout << dp[0][n-1] << endl;
    return 0;
}
```

### 练习2：环形石子合并（基础）

**题目描述：**

N 堆石子排成**环形**，相邻两堆可合并，代价为两堆之和，求最小总代价。

**输入格式：**
- 第一行：N（2≤N≤200）
- 第二行：N 个整数

**输出格式：**
- 最小合并代价

**样例输入：**
```
4
1 3 5 2
```

**样例输出：**
```
20
```

**参考代码：**
```cpp
#include <iostream>
#include <climits>
using namespace std;
int a[405], s[405], dp[405][405];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) { cin >> a[i]; a[i+n] = a[i]; }
    for (int i = 1; i <= 2*n; i++) s[i] = s[i-1]+a[i];
    for (int len = 2; len <= n; len++)
        for (int i = 1; i+len-1 <= 2*n; i++) {
            int j = i+len-1;
            dp[i][j] = INT_MAX;
            for (int k = i; k < j; k++)
                dp[i][j] = min(dp[i][j], dp[i][k]+dp[k+1][j]+s[j]-s[i-1]);
        }
    int ans = INT_MAX;
    for (int i = 1; i <= n; i++) ans = min(ans, dp[i][i+n-1]);
    cout << ans << endl;
    return 0;
}
```

### 练习4：凸多边形三角剖分（综合）

**题目描述：**

给定 N 个顶点的凸多边形（顶点编号 1 到 N，按顺序排列），每条对角线可以划分三角形。三角形的代价为三个顶点编号之积。求最小总代价。

**输入格式：**
- 第一行：N（3≤N≤200）
- 第二行：N 个整数（顶点权值 w[1..N]）

**输出格式：**
- 最小总代价

**样例输入：**
```
5
1 2 3 4 5
```

**样例输出：**
```
52
```

**参考代码：**
```cpp
#include <iostream>
#include <climits>
using namespace std;
int w[205];
long long dp[205][205];
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> w[i];
    // 初始化 INF
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            dp[i][j] = (i+1 >= j) ? 0 : 1e18;
    for (int len = 3; len <= n; len++)
        for (int i = 1; i+len-1 <= n; i++) {
            int j = i+len-1;
            for (int k = i+1; k < j; k++)
                dp[i][j] = min(dp[i][j], dp[i][k]+dp[k][j]+(long long)w[i]*w[k]*w[j]);
        }
    cout << dp[1][n] << endl;
    return 0;
}
```

### 练习5：记忆化搜索版石子合并（进阶）

**题目描述：**

用**记忆化递归**（而非迭代）实现石子合并的区间 DP 解法，输出最小代价。

**输入格式：** 同练习1（线性石子合并）

**样例输入：**
```
4
1 3 5 2
```

**样例输出：**
```
22
```

**参考代码：**
```cpp
#include <iostream>
#include <climits>
#include <cstring>
using namespace std;
int a[305], s[305], n;
int memo[305][305];

int solve(int i, int j) {
    if (i == j) return 0;
    if (memo[i][j] != -1) return memo[i][j];
    memo[i][j] = INT_MAX;
    for (int k = i; k < j; k++)
        memo[i][j] = min(memo[i][j], solve(i,k)+solve(k+1,j)+s[j]-s[i-1]);
    return memo[i][j];
}

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) { cin >> a[i]; s[i]=s[i-1]+a[i]; }

```

## 五、课堂总结（5分钟）🌟

> 今天我们全面深化了区间 DP 的掌握！
>
> **核心收获：**
> - 枚举顺序保证子问题先算：按长度枚举 or 记忆化递归
> - 边界条件是区间 DP 的易错点，len=1 和 len=2 要格外小心
> - 括号匹配：两端能配就配，再枚举分割点
> - 环形区间 DP：**复制序列**为 2N，枚举所有长度 N 的窗口
>
> **区间 DP 的本质：**
> 将大问题分解为两个相邻子问题，先解决小区间，逐步扩展到大区间。

### 📝 课后作业（3道）

**作业1：小括号配对**

字符串 `(())(` 需要添加几个字符使其合法？

> 分析：`(())` 已合法，最后 `(` 缺少配对，添加 `)` 即可。答案 **1**。

**作业2：环形3个石子**

石子 [2, 3, 4] 排成环，求最小合并代价。

> 解析：复制为 [2,3,4,2,3,4]，枚举长度3的窗口：[2,3,4]→min合并=2+3+4+min(2+3,3+4)= 先合2,3=5，再5+4=9，总=14；先合3,4=7，再2+7=9，总=16。最小=**14**。

**作业3：判断题**

区间 DP 的分割点必须是连续子序列的中间点，不能取端点（即 k 的范围是 i < k < j）。（ ）

> 答：视问题而定——石子合并中 k 是 i≤k<j（分割为 [i,k] 和 [k+1,j]），括号匹配等问题 k 范围类似。但凸多边形剖分中 k 是 i<k<j（顶点 k 在中间）。不能一概而论。

**挑战7：超级蛋蛋**
