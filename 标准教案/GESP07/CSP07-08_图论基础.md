### 2. 知识点讲解

#### 2.1 图的基本概念

**图的定义：** 由**顶点集合 V** 和**边集合 E** 组成的二元组 G = (V, E)

**基本术语：**

| 术语 | 含义 |
|-----|------|
| **顶点（Vertex/Node）** | 图中的节点，如城市、人 |
| **边（Edge）** | 连接两个顶点的关系，如道路、认识 |
| **度（Degree）** | 与顶点相连的边的数量（无向图），有向图分入度和出度 |
| **路径（Path）** | 从一个顶点到另一个顶点经过的顶点序列 |
| **连通（Connected）** | 两顶点间存在路径（无向图） |
| **权重（Weight）** | 边上附带的值（如距离、费用） |

**有向图 vs 无向图：**

- **无向图**：边没有方向，如朋友关系（A认识B = B认识A）
- **有向图**：边有方向，如网页链接（A链接到B ≠ B链接到A）

**特殊概念：**

- **稀疏图**：E << V²（边很少，如大地图、交通网）
- **稠密图**：E ≈ V²（边很多，如完全图）
- **简单图**：无重边、无自环

---

#### 2.2 邻接矩阵

用一个 V×V 的二维数组 `adj[i][j]` 表示图：

- `adj[i][j] = 1`：顶点 i 和 j 之间有边（无权图）
- `adj[i][j] = w`：顶点 i 到 j 有权重为 w 的边（带权图）
- `adj[i][j] = 0` 或 INF：无边

```cpp
// 无权无向图的邻接矩阵
int adj[1005][1005];

// 读入并建图
int n, m;
cin >> n >> m;
for (int i = 0; i < m; i++) {
    int u, v;
    cin >> u >> v;
    adj[u][v] = 1;
    adj[v][u] = 1;  // 无向图双向
}

// 查询 u 和 v 是否相连：O(1)
if (adj[u][v]) { ... }

// 遍历 u 的所有邻居：O(V)
for (int v = 1; v <= n; v++)
    if (adj[u][v]) { ... }
```

> **优缺点总结：**
> - ✅ 查询边是否存在：O(1)
> - ✅ 实现简单直观
> - ❌ 空间：O(V²)，当 V=10^4 时，需要 10^8 个元素，不可接受
> - ❌ 遍历邻居：O(V)，即使只有少数邻居

---

#### 2.3 邻接表

用一个数组的 vector，`adj[i]` 存储顶点 i 的所有邻居：

```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<int> adj[1000005];  // adj[i] = i 的所有邻居列表

// 读入并建图
int n, m;
cin >> n >> m;
for (int i = 0; i < m; i++) {
    int u, v;
    cin >> u >> v;
    adj[u].push_back(v);  // u 的邻居列表中加入 v
    adj[v].push_back(u);  // 无向图，双向加入
}

// 遍历 u 的所有邻居：O(degree(u))
for (int v : adj[u]) {
    // 处理邻居 v
}
```

**带权图的邻接表：**

```cpp
vector<pair<int,int>> adj[1000005];  // adj[i] = {邻居, 权重} 的列表

// 加入边：u->v，权重 w
adj[u].push_back({v, w});
adj[v].push_back({u, w});  // 无向图

// 遍历
for (auto [v, w] : adj[u]) {
    // 处理邻居 v 和权重 w
}
```

> **优缺点总结：**
> - ✅ 空间：O(V+E)，适合稀疏图
> - ✅ 遍历所有邻居：O(degree(u))，高效
> - ❌ 查询某条边是否存在：O(degree(u))，不如矩阵快

---

#### 2.4 两种存储方式的对比

| 特性 | 邻接矩阵 | 邻接表 |
|-----|---------|-------|
| **空间复杂度** | O(V²) | O(V+E) |
| **查询边(u,v)** | O(1) | O(degree(u)) |
| **遍历u的邻居** | O(V) | O(degree(u)) |
| **适用场景** | 稠密图、V较小 | 稀疏图、V较大 |
| **实现难度** | 简单 | 稍复杂 |

> **经验法则：**
> - V ≤ 1000 → 可用邻接矩阵
> - V > 1000 或 E << V² → 用邻接表

#### 2.5 GESP真题演练 ⚡

**抢答题1：**

> 一个有 5 个顶点的完全无向图（每两个顶点间都有边），共有多少条边？

> 解析：C(5,2) = 5×4÷2 = **10** 条边。完全图的边数为 V×(V-1)/2。

**判断题2：**

> 无向图的邻接矩阵一定是对称矩阵（即 adj[i][j] == adj[j][i]）。（ ）

> 解析：✅ 正确。无向图中 i-j 之间有边等价于 j-i 之间有边，所以矩阵关于主对角线对称。

**抢答题3：**

> 若一个图有 1000 个顶点、2000 条边，用邻接矩阵需要多少存储空间（int型，4字节）？用邻接表呢？

> 解析：
> - 邻接矩阵：1000×1000×4 = **4MB**
> - 邻接表：约 (1000+2000×2)×4 = 20KB（远小于矩阵）

#### 2.6 进阶扩展：链式前向星（了解）

在大规模图中（V, E 可达 10^6），`vector` 邻接表的常数较大。**链式前向星**是一种更高效的邻接表实现：

```cpp
struct Edge {
    int to, next, w;
} edges[2000005];
int head[1000005], cnt = 0;

void addEdge(int u, int v, int w) {
    edges[++cnt] = {v, head[u], w};
    head[u] = cnt;
}

// 遍历 u 的所有边
for (int i = head[u]; i; i = edges[i].next) {
    int v = edges[i].to, w = edges[i].w;
    // 处理 v 和 w
}
```

> 链式前向星本质是静态链表，性能优于 vector，但代码较复杂，竞赛中常用。

### 练习1：建图并查询（基础）

**题目描述：**

给定 N 个顶点，M 条无向边，之后 Q 次查询，每次询问顶点 u 和 v 之间是否直接相连。

**输入格式：**
- 第一行：N M（1≤N≤1000，1≤M≤10000）
- 接下来 M 行：每行两个整数 u v（表示一条无向边）
- 第 M+2 行：Q（查询次数）
- 接下来 Q 行：u v

**输出格式：**
- 每次查询输出 YES 或 NO

**样例输入：**
```
4 4
1 2
1 3
2 4
3 4
3
1 4
2 3
1 2
```

**样例输出：**
```
NO
NO
YES
```

**参考代码：**
```cpp
#include <iostream>
using namespace std;
int adj[1005][1005];
int main() {
    int n, m; cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v;
        adj[u][v] = adj[v][u] = 1;
    }
    int q; cin >> q;
    while (q--) {
        int u, v; cin >> u >> v;
        cout << (adj[u][v] ? "YES" : "NO") << "\n";
    }
    return 0;
}
```

### 练习3：邻接表建带权图（综合）

**题目描述：**

给定 N 个顶点，M 条有向边（带权重），读入后对每个顶点输出其所有出边（目标顶点和权重）。

- 接下来 M 行：u v w（从 u 到 v 有权重 w 的边）

**输出格式：**

### 练习4：判断是否有路径（综合）

**题目描述：**

给定 N 个顶点，M 条无向边，判断顶点 s 和顶点 t 之间是否存在路径（直接或间接相连）。

**输入格式：**
- 第一行：N M s t
- 接下来 M 行：每行两整数 u v

**输出格式：**
- "YES" 或 "NO"

**样例输入：**
```
5 4 1 5
1 2
2 3
3 4
4 2
```

**样例输出：**
```
NO
```

**思路：** 用 BFS 或 DFS 从 s 出发，看能否到达 t

**参考代码：**
```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;
vector<int> adj[1005];
bool vis[1005];
int main() {
    int n, m, s, t;
    cin >> n >> m >> s >> t;
    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    // BFS
    queue<int> q;
    q.push(s); vis[s] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u])
            if (!vis[v]) { vis[v] = true; q.push(v); }
    }
    cout << (vis[t] ? "YES" : "NO") << endl;
    return 0;
}
```

- 第一行：N M

- 四行分别输出：顶点数、边数、最大度顶点、最大度数

```
5 5
1 2
1 3
2 3
2 4
4 5
```

**样例输出：**
```
5
5
2
3
```

**参考代码：**
```cpp
#include <iostream>
#include <vector>
using namespace std;
int deg[1005];
int main() {
    int n, m; cin >> n >> m;
    for (int i = 0; i < m; i++) {
```

## 五、课堂总结（5分钟）🌟

> 今天我们正式踏入了图论的大门！
>
> **核心收获：**
> - 图由顶点和边组成，有向图的边有方向，无向图没有
> - **邻接矩阵**：查询快 O(1)，但空间 O(V²)，适合稠密图
> - **邻接表**：空间 O(V+E)，遍历邻居快，适合稀疏图
>
> **图论学习路线：**
> 图的存储 → DFS 遍历 → BFS 遍历 → 最短路 → 最小生成树 → ...
>
> 下节课我们将学习在图上"探险"的第一种方式——**深度优先搜索（DFS）**！

**挑战4：图的转置**

给一个有向图，输出其"转置图"（所有边方向反转）的邻接表。

> 思路提示：读入 u→v 时，在转置图中加入 v→u。

> 条件：图是连通的，且奇度顶点个数为0或2。

**挑战6：图的二部性判断**

判断无向图是否是二部图（所有顶点可以分成两组，每条边连接不同组）。

> 思路提示：用 BFS/DFS 染色，相邻顶点染不同颜色，若发现冲突则非二部图。

**挑战7：度序列与图的重建**

给一个度数序列（如 [2, 3, 3, 2]），判断是否存在满足该度序列的简单无向图。

> 思路提示：Erdős–Gallai 定理：对排序后的度序列 d1≥d2≥...≥dn，满足条件当且仅当度数之和为偶数，且对所有 k 满足一定不等式。
