# CSP07-09 图论算法1：DFS深度优先搜索

## 一、课程简介（5分钟）

### 课程目标 🎯

1. 理解 DFS 在图上的遍历原理：一条路走到底，遇到死路再回头
2. 掌握图上 DFS 的递归实现与非递归（栈）实现
3. 掌握 DFS 遍历序列的推导方法（笔试常考）
4. 掌握 DFS 在连通块判断中的典型应用

### 核心知识点 📚

- DFS 算法核心：递归回溯，深度优先
- DFS 与栈的关系（隐式调用栈）
- 图的 DFS 遍历序列：从起点出发，按邻居顺序依次深入
- 连通块判断：用 DFS 标记所有可达节点，统计连通分量数
- 时间复杂度：O(V+E)（每个顶点和边都会被访问一次）

### 教师引导 👩‍🏫

> 上节课我们学习了图的两种存储方式。今天开始探索图的第一种遍历算法——**深度优先搜索（DFS）**！
>
> DFS 是我们的老朋友——在树和数组上我们已经用过递归回溯（八皇后、全排列），今天我们把这个思路用到"图"上，但要多注意**避免重复访问**！

**互动复习：**

> ❓ DFS 的核心思想是什么？用一句话描述。
>
> 答：**一条路走到底**，到达尽头（无路可走）时，回退到上一个分叉口，再探索其他方向。
>
> ❓ 在之前的递归搜索中，我们用什么防止走重复的路？
>
> 答：**vis（visited）数组**，记录哪些位置已经访问过！

## 三、新知讲解（45分钟）

### 1. 新知导入 🎬

> 想象你在走迷宫，策略是这样的：
>
> - 走到一个分叉口，标记"已来过"
> - 选一个方向走到底（如果能走的话）
> - 遇到死路或所有方向都走过了，原路返回到上一个分叉口
> - 换另一个方向继续探索
>
> 这就是 **DFS 迷宫搜索算法**！在图上，DFS 的行为与此完全相同。

### 2. 知识点讲解

#### 2.1 DFS 基本框架

**递归版DFS：**

```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<int> adj[100005];
bool vis[100005];

void dfs(int u) {
    vis[u] = true;
    cout << u << " ";  // 访问当前节点
    
    for (int v : adj[u]) {
        if (!vis[v]) {
            dfs(v);  // 递归访问未访问的邻居
        }
    }
}

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    dfs(1);  // 从顶点1开始DFS
    return 0;
}
```

**DFS与栈（非递归版）：**

```cpp
#include <stack>
void dfs_iterative(int start, int n) {
    stack<int> st;
    st.push(start);
    vis[start] = true;
    
    while (!st.empty()) {
        int u = st.top(); st.pop();
        cout << u << " ";
        
        for (int v : adj[u]) {
            if (!vis[v]) {
                vis[v] = true;
                st.push(v);
            }
        }
    }
}
```

> **分析：** 递归版 DFS 的调用栈就是一个隐式的栈结构，非递归版只是把这个栈显式化了。

#### 2.2 DFS 遍历序列的推导（笔试重点）

给定图的邻接表，根据 DFS 规则手动推导遍历序列：

> **示例：**
>
> 图：5个顶点，邻接表（按编号从小到大排列邻居）：
> - 1: [2, 3]
> - 2: [1, 4, 5]
> - 3: [1, 5]
> - 4: [2]
> - 5: [2, 3]
>
> **DFS 从顶点1开始：**
>
> 1. 访问1（标记），邻居[2,3]，先访问2
> 2. 访问2（标记），邻居[1,4,5]，1已访问，先访问4
> 3. 访问4（标记），邻居[2]，2已访问，回退到2
> 4. 2的邻居继续，访问5
> 5. 访问5（标记），邻居[2,3]，2已访问，访问3
> 6. 访问3（标记），邻居[1,5]，1已访问，5已访问，回退
> 7. 全部返回
>
> **DFS序列：1 → 2 → 4 → 5 → 3**

---

#### 2.3 图的 DFS 遍历序列

**关键规则：**
1. 从起点开始，标记并访问
2. 选择邻居中**未访问**的，按特定顺序（通常从小到大或按加入顺序）深入
3. 当所有邻居都已访问，回退到上一节点
4. 若图不连通，对所有未访问顶点重复以上过程

---

#### 2.4 DFS 在连通块中的应用

**问题：** 给定一个无向图，判断共有多少个连通分量。

**思路：** 对每个未访问的顶点启动一次 DFS，每次启动代表一个新的连通分量。

```cpp
int components = 0;

for (int i = 1; i <= n; i++) {
    if (!vis[i]) {
        dfs(i);         // 从 i 出发 DFS 标记整个连通块
        components++;   // 连通分量数 +1
    }
}

cout << "连通分量数：" << components << endl;
```

#### 2.5 GESP真题演练 ⚡

**判断题1：**

> DFS 使用队列来维护遍历顺序。（ ）

> 解析：❌ 错误。DFS 使用**栈**（或递归调用栈）。使用队列的是 BFS（广度优先搜索）。

**抢答题2：**

> 图有4个顶点：1,2,3,4，边为 {1-2, 1-3, 2-4}。从顶点1开始对编号从小到大的邻居做DFS，遍历序列是什么？

> 解析：1→2（1的最小邻居）→4（2的未访问邻居）→回退→3（1的下一个邻居）
> **序列：1 2 4 3**

**抢答题3：**

> 一个有 N 个顶点的图，DFS 的时间复杂度是多少？

> 解析：O(V+E)。每个顶点访问一次 O(V)，每条边被检查两次（无向图）O(E)，总 O(V+E)。

---

#### 2.6 进阶扩展：DFS 时间戳

DFS 中可以记录每个顶点被访问的时间（**入时间戳 dfn[u]**），用于判断图的结构属性（如树、桥、割点等）：

```cpp
int timer = 0, dfn[100005];

void dfs(int u) {
    vis[u] = true;
    dfn[u] = ++timer;  // 记录入时间戳
    for (int v : adj[u])
        if (!vis[v]) dfs(v);
}
```

### 练习4：岛屿数量（综合）

**题目描述：**

给定 N×M 的二维网格，'1' 表示陆地，'0' 表示水。上下左右相邻的陆地视为同一个岛屿，求岛屿总数。

**输入格式：**
- 第一行：N M
- 接下来 N 行，每行 M 个字符（'0' 或 '1'）

**输出格式：**
- 岛屿数量

**样例输入：**
```
4 5
11110
11010
11000
00000
```

**样例输出：**
```
1
```

**参考代码：**
```cpp
#include <iostream>
#include <string>
using namespace std;
int n, m;
string grid[105];
bool vis[105][105];
int dx[] = {0,0,1,-1}, dy[] = {1,-1,0,0};
void dfs(int x, int y) {
    vis[x][y] = true;
    for (int d = 0; d < 4; d++) {
        int nx = x+dx[d], ny = y+dy[d];
        if (nx>=0&&nx<n&&ny>=0&&ny<m&&!vis[nx][ny]&&grid[nx][ny]=='1')
            dfs(nx, ny);
    }
}
int main() {
    cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> grid[i];
    int cnt = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            if (!vis[i][j] && grid[i][j]=='1') { dfs(i,j); cnt++; }
    cout << cnt << endl;
    return 0;
}
```

### 练习5：有向图DFS路径（进阶）

**题目描述：**

给定有向图，从顶点 s 出发，判断是否能到达顶点 t，若能，输出一条路径。

**输入格式：**
- 第一行：N M s t
- 接下来 M 行：u v（有向边）

**输出格式：**
- 若能到达，输出路径（空格分隔）；否则输出 "NO PATH"

**样例输入：**
```
4 4 1 4
1 2
2 3
3 4
1 3
```

**样例输出：**
```
1 2 3 4
```

**参考代码：**
```cpp
#include <iostream>
#include <vector>
using namespace std;
vector<int> adj[1005];
bool vis[1005], found;
int path[1005], depth, s, t;
void dfs(int u) {
    if (found) return;
    path[depth++] = u;
    if (u == t) { found = true; return; }
    for (int v : adj[u])
        if (!vis[v]) { vis[v]=true; dfs(v); if (found) return; vis[v]=false; }
    depth--;
}
int main() {
    int n, m; cin >> n >> m >> s >> t;
    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v; adj[u].push_back(v);
    }
    vis[s]=true; found=false; depth=0;
    dfs(s);
    if (found) { for (int i = 0; i < depth; i++) cout << path[i] << " "; cout << endl; }
    else cout << "NO PATH" << endl;
    return 0;
}
```
