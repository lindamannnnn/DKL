### 1. 新知导入 🎬

> 来一个生动的例子！

>
> **BFS 能保证找到的是最短路径**，这正是它最重要的特性！

### 2. 知识点讲解

#### 2.1 BFS 基本框架

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

vector<int> adj[100005];
bool vis[100005];

void bfs(int start) {
    queue<int> q;
    q.push(start);
    vis[start] = true;
    
    while (!q.empty()) {
        int u = q.front(); q.pop();
        cout << u << " ";  // 访问当前节点
        
        for (int v : adj[u]) {
            if (!vis[v]) {
                vis[v] = true;
                q.push(v);  // 加入队列，等待后续访问
            }
        }
    }
}
```

> **与 DFS 框架的对比：**
> - DFS：`stack<int>` + `pop`（或递归） → 深度优先
> - BFS：`queue<int>` + `pop` → 广度优先（层次遍历）

---

#### 2.2 BFS 遍历序列推导（笔试关键）

> **规则：** 从起点开始，将所有未访问的邻居加入队列；依次出队并访问，再将其未访问邻居加入队列，如此反复。

**示例图（邻居按编号从小到大）：**

```
顶点：1,2,3,4,5,6
边：1-2, 1-3, 2-4, 2-5, 3-6
```

| 步骤 | 出队 | 邻居入队 | 队列状态 |
|-----|-----|---------|---------|
| 初始 | — | 1 入队 | [1] |
| 1 | 1 | 2,3 入队 | [2,3] |
| 2 | 2 | 4,5 入队 | [3,4,5] |
| 3 | 3 | 6 入队 | [4,5,6] |
| 4 | 4 | 无新邻居 | [5,6] |
| 5 | 5 | 无新邻居 | [6] |
| 6 | 6 | 无新邻居 | [] |

**BFS序列：1 → 2 → 3 → 4 → 5 → 6**（按层次）

---

#### 2.3 BFS 求无权图最短路径

**关键思想：** 在无权图中，第一次通过 BFS 访问某个节点时，所走的步数就是从起点到该节点的**最短路径**！

**dist[] 数组记录最短距离：**

```cpp
int dist[100005];
memset(dist, -1, sizeof(dist));  // -1 表示未到达

void bfs_shortest(int start) {
    queue<int> q;
    q.push(start);
    dist[start] = 0;  // 起点距离为0
    
    while (!q.empty()) {
        int u = q.front(); q.pop();
        
        for (int v : adj[u]) {
            if (dist[v] == -1) {  // 未访问
                dist[v] = dist[u] + 1;  // 距离 = 父节点距离 + 1
                q.push(v);
            }
        }
    }
}

// 访问 dist[t] 即为起点到 t 的最短距离，若 dist[t]==-1 则不可达
```

#### 2.4 DFS vs BFS 对比

| 特性 | DFS | BFS |
|-----|-----|-----|
| **数据结构** | 栈（递归） | 队列 |
| **搜索方式** | 一条路走到底 | 逐层扩展 |
| **内存使用** | O(最大深度) | O(最大宽度) |
| **能找最短路？** | ❌ 不能 | ✅ 能（无权图） |
| **能找所有解？** | ✅ 适合 | ❌ 复杂 |
| **适用场景** | 连通性、全路径、回溯 | 最短路、层次遍历 |

> **一句话记忆：**
> 找**所有解**用 DFS；找**最短路**用 BFS。

#### 2.5 GESP真题演练 ⚡

**抢答题1：**

> 图有顶点1-5，边：{1-2, 1-4, 2-3, 4-5}（邻居按编号从小到大）。从顶点1出发BFS，遍历序列是什么？

> 解析：
> - 访问1，邻居2,4入队 → 访问2，邻居3入队 → 访问4，邻居5入队（1已访问）→ 访问3 → 访问5
> - **BFS序列：1 2 4 3 5**

**判断题2：**

> BFS 求无权图最短路时，可能需要多次访问同一顶点以更新最短距离。（ ）

> 解析：❌ 错误。BFS 第一次访问某顶点时就已确定最短距离，无需重复访问（通过 vis[] 或 dist[] 标记防止重复）。

**抢答题3：**

> 从起点到终点的路径长度为 K，BFS 会在多少轮（出队操作）之后到达终点？

> 解析：恰好在第 **K 轮**（第 K 次扩展）后到达，即访问距离为 K 的所有节点时包含终点。

#### 2.6 进阶扩展：BFS 求多源最短路

若有多个起点，将所有起点**同时**放入初始队列，一次 BFS 即可求出所有点到最近起点的距离：

```cpp
// 多源BFS示例
queue<int> q;
for (int s : sources) {
    q.push(s);
    dist[s] = 0;
}
// 然后正常BFS...
```

> **应用：** 从多个"病毒感染源"出发，求每个城市最早被感染的时间。

### 练习1：BFS 遍历序列（基础）

**题目描述：**

给定无向图，从顶点1开始BFS（邻居按编号从小到大），输出BFS遍历序列。

**输入格式：**
- 第一行：N M
- 接下来 M 行：u v

**输出格式：**
- BFS序列

**样例输入：**
```
5 5
1 2
1 3
2 4
3 5
4 5
```

**样例输出：**
```
1 2 3 4 5
```

**参考代码：**
```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;
vector<int> adj[1005];
bool vis[1005];
int main() {
    int n, m; cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v); adj[v].push_back(u);
    }
    for (int i = 1; i <= n; i++) sort(adj[i].begin(), adj[i].end());
    queue<int> q;
    q.push(1); vis[1]=true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        cout << u << " ";
        for (int v : adj[u]) if (!vis[v]) { vis[v]=true; q.push(v); }
    }
    cout << endl;
    return 0;
}
```

### 练习2：BFS最短路（基础）

**题目描述：**

给定无向图，求从顶点s到顶点t的最短路径长度（边数）。若不可达输出-1。

**输入格式：**
- 第一行：N M s t
- 接下来M行：u v

**输出格式：**
- 最短路径边数，或-1

**样例输入：**
```
5 5 1 5
1 2
2 3
3 4
4 5
1 3
```

**样例输出：**
```
3
```

（路径：1→3→4→5，长度3）

**参考代码：**
```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <cstring>
using namespace std;
vector<int> adj[1005];
int dist[1005];
int main() {
    int n, m, s, t; cin >> n >> m >> s >> t;
    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v); adj[v].push_back(u);
    }
    memset(dist, -1, sizeof(dist));
    queue<int> q;
    q.push(s); dist[s]=0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u]) if (dist[v]==-1) { dist[v]=dist[u]+1; q.push(v); }
    }
    cout << dist[t] << endl;
    return 0;
}
```

### 练习3：迷宫最短路（综合）

**题目描述：**

N×M 的迷宫，'.' 为可走格，'#' 为墙。从左上角 (1,1) 走到右下角 (N,M)，每步可上下左右移动，求最少步数。若不可达输出-1。

**输入格式：**
- 第一行：N M
- 接下来N行字符串

**输出格式：**
- 最少步数或-1

**样例输入：**
```
4 4
....
.##.
....
....
```

**样例输出：**
```
6
```

**参考代码：**
```cpp
#include <iostream>
#include <queue>
#include <string>
#include <cstring>
using namespace std;
struct Node { int x, y, d; };
string grid[105];
int dist[105][105];
int dx[]={0,0,1,-1}, dy[]={1,-1,0,0};
int main() {
    int n, m; cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> grid[i];
    memset(dist, -1, sizeof(dist));
    queue<Node> q;
    q.push({0,0,0}); dist[0][0]=0;
    while (!q.empty()) {
        auto [x,y,d] = q.front(); q.pop();
        for (int i = 0; i < 4; i++) {
            int nx=x+dx[i], ny=y+dy[i];
            if (nx>=0&&nx<n&&ny>=0&&ny<m&&grid[nx][ny]!='#'&&dist[nx][ny]==-1) {
                dist[nx][ny]=d+1; q.push({nx,ny,d+1});
            }
        }
    }
    cout << dist[n-1][m-1] << endl;
    return 0;
}
```

### 练习5：感染传播（进阶）

**题目描述：**

N 个城市，M 条双向道路，病毒从城市 s 出发，每天沿道路传播到相邻城市，问第 K 天结束后有多少城市被感染（包括第0天的起始城市）？

**输入格式：**
- 第一行：N M s K
- 接下来M行：u v

**输出格式：**
- 被感染城市数

**样例输入：**
```
6 6 1 2
1 2
1 3
2 4
3 5
4 6
5 6
```

**样例输出：**
```
5
```

（第0天：1；第1天：2,3；第2天：4,5；共1+2+2=5个）

**参考代码：**
```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <cstring>
using namespace std;
vector<int> adj[1005];
int dist[1005];
int main() {
    int n, m, s, k; cin >> n >> m >> s >> k;
    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v); adj[v].push_back(u);
    }
    memset(dist, -1, sizeof(dist));
    queue<int> q;
    q.push(s); dist[s]=0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u]) if (dist[v]==-1) { dist[v]=dist[u]+1; q.push(v); }
    }
    int cnt = 0;
    for (int i = 1; i <= n; i++) if (dist[i]!=-1 && dist[i]<=k) cnt++;
    cout << cnt << endl;
    return 0;
}
```

## 五、课堂总结（5分钟）🌟

> 今天我们掌握了 BFS 的精髓！
>
> **核心收获：**
> - BFS 用**队列**逐层扩展，保证先远后近
> - BFS 求无权图最短路：第一次到达时的步数即为最短距离，用 dist[] 记录
