## 一、课程简介（5分钟）

### 课程目标 🎯

1. 理解泛洪算法（Flood Fill）的概念与原理
2. 掌握泛洪算法的寻路与染色两种典型用途

### 核心知识点 📚

- 泛洪算法：从某点出发，将连通区域的所有相同属性格子进行标记/染色
- 寻路应用：判断两点连通、求连通区域面积
- 染色原理：将目标区域统一更改为新颜色（标记）
- DFS 实现：递归深入，代码简洁
- BFS 实现：队列扩展，更适合求最短步数/防栈溢出

### 2. 知识点讲解

#### 2.1 泛洪算法的本质

**Flood Fill = 在二维网格上的连通区域标记**

从一个起始格子 (x, y) 出发，将所有与之**连通且属性相同**的格子，都进行某种操作（染色/标记/计数）。

**"连通"的定义：** 通常是四连通（上下左右）或八连通（上下左右+斜向）

---

#### 2.2 DFS 实现 Flood Fill

```cpp
#include <iostream>
#include <string>
using namespace std;

int n, m;
char grid[105][105];
bool vis[105][105];
int dx[] = {0, 0, 1, -1};   // 方向：右,左,下,上
int dy[] = {1, -1, 0, 0};

// 从 (x,y) 开始，标记所有与之连通的 target 颜色格子
void dfs(int x, int y, char target) {
    if (x < 0 || x >= n || y < 0 || y >= m) return;  // 越界
    if (vis[x][y]) return;                              // 已访问
    if (grid[x][y] != target) return;                  // 颜色不同
    
    vis[x][y] = true;  // 标记已访问
    
    for (int d = 0; d < 4; d++) {
        dfs(x + dx[d], y + dy[d], target);
    }
}

int main() {
    cin >> n >> m;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> grid[i][j];
    
    // 从 (0,0) 开始泛洪
    dfs(0, 0, grid[0][0]);
    
    return 0;
}
```

**应用变体：计数连通区域面积**

```cpp
int area = 0;  // 全局计数器

void dfs(int x, int y, char target) {
    if (out of bounds || vis[x][y] || grid[x][y] != target) return;
    vis[x][y] = true;
    area++;  // 每访问一格，面积+1
    for (int d = 0; d < 4; d++)
        dfs(x+dx[d], y+dy[d], target);
}
```

---

#### 2.3 BFS 实现 Flood Fill

BFS 版 Flood Fill 更适合求**最少步数**，或在 n 很大时避免 DFS 的栈溢出问题：

```cpp
#include <queue>
using namespace std;

void bfs(int startX, int startY, char target) {
    queue<pair<int,int>> q;
    q.push({startX, startY});
    vis[startX][startY] = true;
    
    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();
        
        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d], ny = y + dy[d];
            if (nx>=0 && nx<n && ny>=0 && ny<m 
                && !vis[nx][ny] && grid[nx][ny]==target) {
                vis[nx][ny] = true;
                q.push({nx, ny});
            }
        }
    }
}
```

---

#### 2.4 Flood Fill 的两种选择

> **何时选 DFS？**
> - 代码简洁，递归写法自然
> - 网格规模较小（避免栈溢出，通常 N×M ≤ 10^6 安全）
> - 只需判断连通性，不需要最短距离
>
> **何时选 BFS？**
> - 需要**最短步数/距离**
> - 网格非常大（防止 DFS 递归栈溢出）
> - 多源泛洪（多个起点同时扩散）

#### 2.5 GESP真题演练 ⚡

**抢答题1：**

> 5×5 网格，全部为 '.'，从 (0,0) 开始泛洪算法，最终标记的格子数是多少？

> 解析：全连通，共 5×5 = **25** 格全部标记。

**判断题2：**

> Flood Fill 算法要求连通区域内所有格子的属性（颜色）必须完全相同，若存在不同属性，则该格子为边界，不会被染色。（ ）

> 解析：✅ 正确。Flood Fill 根据格子属性决定是否继续扩展，属性不同（或越界）时停止。

**抢答题3：**

> 在使用 DFS 实现 Flood Fill 时，如果网格非常大（如 10^6 个格子），可能会出现什么问题？

> 解析：**栈溢出（Stack Overflow）**。DFS 深度过大会导致系统栈超限。此时应改用 BFS 实现。

#### 2.6 进阶扩展：Flood Fill 与最短路结合

**问题：** 给定网格，起点 S，终点 T，空地为 '.'，墙为 '#'，水从 S 出发泛洪，每秒扩散一格，问水到达 T 的时间？

**解法：** 直接用 BFS Flood Fill，dist[T] 即为答案：

```cpp
// 只需在 BFS 中记录步数
struct Cell { int x, y, step; };

queue<Cell> q;
q.push({sx, sy, 0});
dist[sx][sy] = 0;

while (!q.empty()) {
    auto [x, y, step] = q.front(); q.pop();
    if (x == tx && y == ty) { cout << step; return 0; }
    for (int d = 0; d < 4; d++) {
        int nx = x+dx[d], ny = y+dy[d];
        if (valid && grid[nx][ny]!='#' && dist[nx][ny]==-1) {
            dist[nx][ny] = step+1;
            q.push({nx, ny, step+1});
        }
    }
}
```

### 练习4：水漫金山（综合）

**题目描述：**

N×M 网格，'S' 为水源，'.' 为平地，'#' 为山脉（水无法通过）。水从 S 出发每秒向四周扩散，求所有平地被淹没的最短时间（若某平地无法到达，输出 -1 表示该格）。

**输入格式：**
- 第一行：N M
- 接下来N行字符

**输出格式：**
- 输出 N×M 的距离矩阵（S处为0，#处为-2，无法到达处为-1）

**样例输入：**
```
3 4
S..#
.#..
....
```

**样例输出（示意）：**
（自行计算BFS结果）

**参考代码：**
```cpp
#include <iostream>
#include <string>
#include <queue>
#include <cstring>
using namespace std;
int dist[105][105], n, m;
string grid[105];
int dx[]={0,0,1,-1}, dy[]={1,-1,0,0};
int main() {
    cin>>n>>m;
    for (int i=0;i<n;i++) cin>>grid[i];
    memset(dist,-1,sizeof(dist));
    queue<pair<int,int>> q;
    for (int i=0;i<n;i++) for (int j=0;j<m;j++)
        if (grid[i][j]=='S') { dist[i][j]=0; q.push({i,j}); }
    while (!q.empty()) {
        auto [x,y]=q.front(); q.pop();
        for (int d=0;d<4;d++) {
            int nx=x+dx[d], ny=y+dy[d];
            if (nx>=0&&nx<n&&ny>=0&&ny<m&&grid[nx][ny]!='#'&&dist[nx][ny]==-1) {
                dist[nx][ny]=dist[x][y]+1; q.push({nx,ny});
            }
        }
    }
    for (int i=0;i<n;i++) {
        for (int j=0;j<m;j++) {
            if (grid[i][j]=='#') cout<<-2<<" ";
            else cout<<dist[i][j]<<" ";
        }
        cout<<"\n";
    }
    return 0;
}
```
