## 一、课程简介（5分钟）

### 课程目标 🎯

1. 理解哈希表的核心思想：通过哈希函数将键映射到数组位置
2. 了解哈希冲突的成因与常见解决方案
3. 掌握哈希表的时间复杂度特性（O(1) 期望）

### 核心知识点 📚

- 哈希表的概念：键值对的高效存储结构
- 哈希函数：将任意键映射为一个整数（数组下标）
- 哈希冲突：两个不同键映射到同一位置（碰撞）
- 解决冲突的方法：链式法（拉链法）、开放地址法
- 时间复杂度：期望 O(1) 的查找、插入、删除
- C++ STL：`unordered_map` 和 `unordered_set`

### 2. 知识点讲解

#### 2.1 哈希表的核心思想

**哈希表 = 数组 + 哈希函数**

- **数组**：提供 O(1) 的随机访问能力
- **哈希函数**：将键（key）映射为数组下标，`index = hash(key) % array_size`

**例子：简单的整数哈希**

```cpp
int hash(int key) {
    return key % 100;  // 映射到 [0, 99]
}
```

存储 key=253 → `hash(253) = 53` → 放入 `table[53]`
查找 key=253 → `hash(253) = 53` → 检查 `table[53]`

---

#### 2.2 哈希冲突

**问题：** 两个不同的键映射到同一个位置，称为**哈希冲突（Collision）**

例如：`hash(53) = 53`，`hash(153) = 53`，两者冲突！

**冲突是不可避免的**（鸽巢原理：键的数量 > 格子数时必然冲突）

---

#### 2.3 解决冲突的方法

**方法1：链式法（拉链法）**

每个格子存储一个链表，所有映射到同一位置的元素都放入链表：

```
table[53] → [53] → [153] → [253] → null
```

```cpp
// 简化的链式哈希表
const int BUCKET = 1000;
vector<pair<int,int>> table[BUCKET];  // table[i] 存储所有 hash(key)=i 的键值对

void insert(int key, int val) {
    int h = key % BUCKET;
    for (auto &p : table[h])
        if (p.first == key) { p.second = val; return; }
    table[h].push_back({key, val});
}

int find(int key) {
    int h = key % BUCKET;
    for (auto &p : table[h])
        if (p.first == key) return p.second;
    return -1;  // 未找到
}
```

**方法2：开放地址法**

冲突时，找下一个空位（线性探测）：

```cpp
int table[BUCKET];  // 记录键
bool used[BUCKET];

void insert(int key) {
    int h = key % BUCKET;
    while (used[h]) h = (h + 1) % BUCKET;  // 线性探测下一个空位
    table[h] = key; used[h] = true;
}
```

---

#### 2.4 时间复杂度与应用

| 操作 | 期望时间 | 最坏时间 |
|-----|---------|---------|
| 插入 | O(1) | O(n) |
| 查找 | O(1) | O(n) |
| 删除 | O(1) | O(n) |

> **期望 O(1) 的前提：** 哈希函数均匀分布，装载因子（元素数/桶数）适中（通常 < 0.75）

---

#### 2.5 C++ STL 哈希表

**`unordered_map`（哈希映射，键值对）：**

```cpp
#include <unordered_map>
using namespace std;

unordered_map<int, int> mp;
mp[1] = 100;        // 插入
mp[2] = 200;
cout << mp[1];      // 查找：100
mp.erase(1);        // 删除
cout << mp.count(1); // 判断键是否存在（0或1）

// 遍历
for (auto [k, v] : mp)
    cout << k << ":" << v << " ";
```

**`unordered_set`（哈希集合，只存键）：**

```cpp
#include <unordered_set>

unordered_set<int> st;
st.insert(5);
st.insert(10);
cout << st.count(5);  // 1（存在）
cout << st.count(3);  // 0（不存在）
st.erase(5);
```

> **竞赛场景：**
> - 需要频繁判断某个值是否出现过 → `unordered_set`
> - 需要存储键值对并快速查找 → `unordered_map`

#### 2.7 进阶扩展：字符串哈希

字符串作为键时，可以用字符串哈希函数：

```cpp
// 多项式字符串哈希
unsigned long long hashStr(const string &s) {
    unsigned long long h = 0, base = 31;
    for (char c : s) h = h * base + (c - 'a' + 1);
    return h;
}

unordered_map<string, int> strMap;
strMap["hello"] = 1;
strMap["world"] = 2;
```

### 练习1：两数之和（基础）

**题目描述：**

给定 N 个整数和目标值 T，判断是否存在两个不同的数（下标不同），其和等于 T。若存在，输出 YES 和这两个数；否则输出 NO。

**输入格式：**
- 第一行：N T
- 第二行：N 个整数

**输出格式：**
- YES + 两数，或 NO

**样例输入：**
```
5 9
2 7 11 15 4
```

**样例输出：**
```
YES 2 7
```

**参考代码：**
```cpp
#include <iostream>
#include <unordered_map>
using namespace std;
int main() {
    int n, t; cin >> n >> t;
    unordered_map<int,int> seen;  // 值→下标
    for (int i = 0; i < n; i++) {
        int a; cin >> a;
        if (seen.count(t - a)) {
            cout << "YES " << a << " " << (t-a) << endl;
            return 0;
        }
        seen[a] = i;
    }
    cout << "NO" << endl;
    return 0;
}
```

### 练习2：词频统计（基础）

**题目描述：**

给定 N 个单词，用哈希表统计每个单词出现的次数，按第一次出现的顺序输出每个单词及其频率。

**输入格式：**
- 第一行：N
- 接下来 N 行：每行一个单词（小写字母，长度≤20）

- 按首次出现顺序输出：`单词 次数`

**样例输入：**
```
7
apple
banana
apple
cherry
banana
apple
cherry
```

**样例输出：**
```
apple 3
banana 2
cherry 2
```

**参考代码：**
```cpp
#include <iostream>
#include <unordered_map>
#include <vector>
using namespace std;
int main() {
    int n; cin >> n;
    unordered_map<string,int> cnt;
    vector<string> order;
    for (int i = 0; i < n; i++) {
        string w; cin >> w;
        if (!cnt.count(w)) order.push_back(w);
        cnt[w]++;
    }
    for (auto &w : order) cout << w << " " << cnt[w] << "\n";
    return 0;
}
```

### 练习3：去重查找（综合）

**题目描述：**

给定 N 个整数，找出其中所有不重复出现的元素（只出现了一次的），升序输出。

**输入格式：**
- 第一行：N
- 第二行：N 个整数

**输出格式：**
- 所有只出现一次的整数，升序排列

**样例输入：**
```
8
4 3 2 7 8 2 3 1
```

**样例输出：**
```
1 4 7 8
```

**参考代码：**
```cpp
#include <iostream>
#include <unordered_map>
#include <vector>
#include <algorithm>
using namespace std;
int main() {
    int n; cin >> n;
    unordered_map<int,int> cnt;
    for (int i = 0; i < n; i++) { int x; cin>>x; cnt[x]++; }
    vector<int> res;
    for (auto [k,v] : cnt) if (v==1) res.push_back(k);
    sort(res.begin(), res.end());
    for (int x : res) cout << x << " ";
    cout << endl;
    return 0;
}
```

### 练习4：最长无重复子数组（综合）

**题目描述：**

给定 N 个整数，求最长的不含重复元素的连续子数组的长度。

**输入格式：**
- 第一行：N
- 第二行：N 个整数

**输出格式：**
- 最长无重复子数组长度

**样例输入：**
```
8
1 2 3 1 2 3 4 5
```

**样例输出：**
```
5
```

（子数组：1,2,3,4,5，长度5）

**思路：** 滑动窗口 + 哈希表记录每个元素最后出现的位置

**参考代码：**
```cpp
#include <iostream>
#include <unordered_map>
using namespace std;
int main() {
    int n; cin >> n;
    unordered_map<int,int> last;  // 每个元素最后出现的下标
    int left = 0, ans = 0;
    for (int i = 0; i < n; i++) {
        int x; cin >> x;
        if (last.count(x) && last[x] >= left)
            left = last[x] + 1;  // 移动左边界
        last[x] = i;
        ans = max(ans, i - left + 1);
    }
    cout << ans << endl;
    return 0;
}
```

### 练习5：集合的交集（进阶）

**题目描述：**

给定两个整数集合 A 和 B，求它们的交集（两个集合都包含的元素），升序输出（无重复）。

**输入格式：**
- 第一行：N（A的元素数）
- 第二行：N个整数
- 第三行：M（B的元素数）
- 第四行：M个整数

**输出格式：**
- 交集元素，升序

**样例输入：**
```
4
1 2 3 4
5
2 4 6 8 10
```

**样例输出：**
```
2 4
```

**参考代码：**
```cpp
#include <iostream>
#include <unordered_set>
#include <vector>
#include <algorithm>
using namespace std;
int main() {
    int n; cin >> n;
    unordered_set<int> setA;
    for (int i = 0; i < n; i++) { int x; cin>>x; setA.insert(x); }
    int m; cin >> m;
    vector<int> res;
    unordered_set<int> seen;
    for (int i = 0; i < m; i++) {
        int x; cin>>x;
        if (setA.count(x) && !seen.count(x)) { res.push_back(x); seen.insert(x); }
    }
    sort(res.begin(), res.end());
    for (int x : res) cout << x << " ";
    cout << endl;
    return 0;
}
```

## 五、课堂总结（5分钟）🌟

> 今天我们掌握了数据结构的"速度之王"——**哈希表**！
>
> **核心收获：**
> - 哈希表 = 数组 + 哈希函数，期望 O(1) 的插入、查找、删除
> - 哈希冲突不可避免，解决方案有链式法和开放地址法
> - STL 中 `unordered_map` 和 `unordered_set` 是竞赛中的利器
>
> **使用场景：**
> - 频繁判断元素是否存在 → `unordered_set`
> - 频繁根据键查值 → `unordered_map`
> - 需要按顺序输出（有序）→ 用 `map`（红黑树）

给 N 个整数，再给 M 个查询，每次查询某个数是否在集合中，输出 YES/NO。用哈希表实现 O(1) 查询。
