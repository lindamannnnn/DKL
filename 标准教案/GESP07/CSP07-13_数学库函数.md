# CSP07-13 数学库函数

## 一、课程简介（5分钟）

### 课程目标 🎯

1. 掌握 C++ `<cmath>` 库中常用三角函数（sin、cos）的用法
2. 掌握对数函数（log10、log2）和指数函数（exp）的用法
3. 理解这些函数的输入输出类型（double）、精度问题和常见错误
4. 能在竞赛题中合理运用数学库函数解决实际问题

### 核心知识点 📚

- 三角函数：`sin(x)`、`cos(x)`（参数为弧度）
- 角度与弧度的转换：`弧度 = 度数 × π / 180`
- 对数函数：`log10(x)`（以10为底）、`log2(x)`（以2为底）、`log(x)`（自然对数）
- 指数函数：`exp(x)` = eˣ
- 常数：`M_PI`（π约等于3.14159...）
- 精度问题：浮点误差、`abs` vs `fabs`、比较用 `eps`

### 2. 知识点讲解

#### 2.1 使用数学库的前提

```cpp
#include <cmath>  // 必须包含此头文件
using namespace std;
```

所有数学函数均接受 `double` 类型参数，返回 `double` 类型值。

---

#### 2.2 三角函数 sin、cos

**基本用法：**

```cpp
#include <iostream>
#include <cmath>
using namespace std;

const double PI = acos(-1.0);  // 最精确的 π 获取方式
// 也可以用 M_PI（某些编译器提供）

int main() {
    // 角度转弧度
    double deg = 30.0;
    double rad = deg * PI / 180.0;
    
    cout << "sin(30°) = " << sin(rad) << endl;  // 0.5
    cout << "cos(60°) = " << cos(60.0 * PI / 180.0) << endl;  // 0.5
    
    // 反三角函数
    cout << "asin(0.5) = " << asin(0.5) * 180.0 / PI << "°" << endl;  // 30°
    cout << "acos(0.5) = " << acos(0.5) * 180.0 / PI << "°" << endl;  // 60°
    
    return 0;
}
```

**常用值对照表：**

| 角度 | sin | cos | tan |
|-----|-----|-----|-----|
| 0° | 0 | 1 | 0 |
| 30° | 0.5 | √3/2 ≈ 0.866 | 1/√3 ≈ 0.577 |
| 45° | √2/2 ≈ 0.707 | √2/2 ≈ 0.707 | 1 |
| 60° | √3/2 ≈ 0.866 | 0.5 | √3 ≈ 1.732 |
| 90° | 1 | 0 | 未定义 |

> **注意：** sin(90° in degrees)，用代码写时需换算：`sin(90.0 * PI / 180.0)`
> 由于浮点误差，`sin(PI/2)` 可能不严格等于 1.0，而是如 0.9999...99 或 1.0000...01

---

#### 2.3 对数函数 log10、log2、log

```cpp
#include <cmath>

// 以 10 为底的对数
cout << log10(100) << endl;   // 2.0（10^2 = 100）
cout << log10(1000) << endl;  // 3.0

// 以 2 为底的对数
cout << log2(8) << endl;   // 3.0（2^3 = 8）
cout << log2(1024) << endl;  // 10.0

// 自然对数（以 e ≈ 2.718 为底）
cout << log(exp(1)) << endl;   // 1.0（log(e) = 1）

// 换底公式：log_b(x) = log(x) / log(b)
double log3_of_27 = log(27.0) / log(3.0);  // 3.0
```

**典型应用：判断位数**

```cpp
// 整数 n 的十进制位数 = floor(log10(n)) + 1
int digits = (int)log10(1234.0) + 1;  // 4

// 整数 n 的二进制位数 = floor(log2(n)) + 1
int bits = (int)log2(8.0) + 1;  // 4（8 = 1000₂）
```

---

#### 2.4 指数函数 exp

```cpp
// exp(x) = e^x
cout << exp(1) << endl;   // 2.71828...（e¹）
cout << exp(0) << endl;   // 1.0（e⁰）
cout << exp(2) << endl;   // 7.38906...（e²）

// pow(底数, 指数)：任意底数的幂
cout << pow(2, 10) << endl;   // 1024.0（2^10）
cout << pow(3, 4) << endl;    // 81.0

// sqrt：平方根
cout << sqrt(16) << endl;  // 4.0
cout << sqrt(2) << endl;   // 1.41421...
```

---

#### 2.5 浮点数精度处理

> **重要：** 浮点数计算存在精度误差，不能直接用 `==` 比较！

```cpp
// 错误写法：
if (sin(PI / 6) == 0.5) { ... }  // 可能因误差而失败！

// 正确写法：用 eps 容差比较
const double EPS = 1e-9;
if (fabs(sin(PI / 6) - 0.5) < EPS) { ... }  // ✓

// 注意：整数取整用 (int)，但浮点接近整数时需注意误差
int n = (int)(log2(8.0) + EPS);  // 加 EPS 避免 2.9999 被截断为 2
```

#### 2.6 GESP真题演练 ⚡

**抢答题1：**

> C++ 代码 `sin(PI/2)` 的返回值保证严格等于 1.0 吗？

> 解析：**不一定**。浮点计算存在误差，结果可能是 0.9999999... 或 1.0000000001...。正确比较方式是用容差 EPS。

**判断题2：**

> `log(x)` 函数（`<cmath>` 中）计算的是以 e 为底的自然对数。（ ）

> 解析：✅ 正确。C++ 中 `log(x)` 是自然对数（ln x），`log10(x)` 是常用对数，`log2(x)` 是以2为底的对数。

**抢答题3：**

> 如何用对数函数判断一个整数 n（n ≥ 1）是否是2的幂？

> 解析：`n` 是2的幂 ⟺ `log2(n)` 是整数 ⟺ `fabs(log2(n) - round(log2(n))) < EPS`
> 也可用位运算：`n > 0 && (n & (n-1)) == 0`（更可靠）

#### 2.7 进阶扩展：常用数学函数汇总

```cpp
#include <cmath>

// 绝对值（浮点数用 fabs，整数用 abs）
fabs(-3.14)   // 3.14
abs(-5)       // 5

// 取整
floor(3.7)    // 3.0（向下取整）
ceil(3.2)     // 4.0（向上取整）
round(3.5)    // 4.0（四舍五入）

// 最大/最小（整数）
max(3, 5)     // 5
min(3, 5)     // 3
max({1,2,3})  // 3（C++11，initializer_list）

// 幂与根
pow(2, 8)     // 256.0
sqrt(2.0)     // 1.41421...
cbrt(27.0)    // 3.0（立方根）
```

### 练习1：角度计算（基础）

**题目描述：**

给定角度 θ（度数），输出 sin(θ) 和 cos(θ) 的值（保留6位小数）。

**输入：** 一个实数 θ（0 ≤ θ ≤ 360）

**输出：** `sin(θ) = X.XXXXXX`，`cos(θ) = X.XXXXXX`

**样例输入：** `30`

**样例输出：**
```
sin(30) = 0.500000
cos(30) = 0.866025
```

**参考代码：**
```cpp
#include <iostream>
#include <cmath>
#include <iomanip>
using namespace std;
int main() {
    const double PI = acos(-1.0);
    double deg; cin >> deg;
    double rad = deg * PI / 180.0;
    cout << fixed << setprecision(6);
    cout << "sin(" << (int)deg << ") = " << sin(rad) << endl;
    cout << "cos(" << (int)deg << ") = " << cos(rad) << endl;
    return 0;
}
```

### 练习2：位数计算（基础）

**题目描述：**

给定正整数 N，输出其十进制位数和二进制位数（不用转换，直接用对数）。

**输入：** 整数 N（1 ≤ N ≤ 10^9）

**输出：** `十进制位数: X，二进制位数: Y`

**样例输入：** `1000`

**样例输出：** `十进制位数: 4，二进制位数: 10`

**参考代码：**
```cpp
#include <iostream>
#include <cmath>
using namespace std;
int main() {
    int n; cin >> n;
    int dec = (int)log10((double)n) + 1;
    int bin = (int)log2((double)n) + 1;
    cout << "十进制位数: " << dec << "，二进制位数: " << bin << endl;
    return 0;
}
```

### 练习3：圆上坐标（综合）

**题目描述：**

给定圆的半径 r 和角度 θ（度数），输出圆上该点的坐标 (x, y)（保留4位小数）。

**输入：** r θ（实数）

**输出：** `(X.XXXX, Y.XXXX)`

**样例输入：** `5 30`

**样例输出：** `(4.3301, 2.5000)`

**参考代码：**
```cpp
#include <iostream>
#include <cmath>
#include <iomanip>
using namespace std;
int main() {
    const double PI = acos(-1.0);
    double r, deg; cin >> r >> deg;
    double rad = deg * PI / 180.0;
    double x = r * cos(rad), y = r * sin(rad);
    cout << fixed << setprecision(4);
    cout << "(" << x << ", " << y << ")" << endl;
    return 0;
}
```

### 练习4：利率计算（综合）

**题目描述：**

银行存款，本金 P，年利率 r%，存 N 年（复利），求本息之和（保留2位小数）。

公式：`A = P × (1 + r/100)^N = P × exp(N × log(1 + r/100))`

**输入：** P r N（P和r为实数，N为整数）

**输出：** `A.XX`

**样例输入：** `1000 5 10`

**样例输出：** `1628.89`

**参考代码：**
```cpp
#include <iostream>
#include <cmath>
#include <iomanip>
using namespace std;
int main() {
    double P, r; int N;
    cin >> P >> r >> N;
    double A = P * pow(1 + r / 100.0, N);
    cout << fixed << setprecision(2) << A << endl;
    return 0;
}
```

### 练习5：三角形面积（进阶）

**题目描述：**

已知三角形三边长 a, b, c（均为正数，保证能构成三角形），用海伦公式求面积（保留4位小数）。

海伦公式：s = (a+b+c)/2，面积 = sqrt(s×(s-a)×(s-b)×(s-c))

**输入：** a b c

**输出：** 面积（保留4位小数）

**样例输入：** `3 4 5`

**样例输出：** `6.0000`

**参考代码：**
```cpp
#include <iostream>
#include <cmath>
#include <iomanip>
using namespace std;
int main() {
    double a, b, c; cin >> a >> b >> c;
    double s = (a+b+c)/2.0;
    double area = sqrt(s*(s-a)*(s-b)*(s-c));
    cout << fixed << setprecision(4) << area << endl;
    return 0;
}
```
