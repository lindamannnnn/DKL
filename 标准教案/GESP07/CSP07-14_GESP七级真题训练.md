## 三、真题演练（90分钟）

### 选择题专练（20题典型考点）

**第1题：** 下列关于动态规划的说法正确的是（ ）

A. 动态规划只能解决最优化问题
B. 所有递归问题都可以改写为动态规划
C. 动态规划需要问题具有最优子结构和无后效性
D. 动态规划总比递归更高效

> **答案：C**
> 解析：DP 的必要条件是最优子结构+无后效性（有时加上重叠子问题）。A 错，DP 也可以求方案数。B 错，不是所有递归都有重叠子问题。D 错，不是绝对的。

---

**第2题：** 以下关于 0/1 背包和完全背包的区别，说法正确的是（ ）

A. 两者的状态转移方程形式完全不同
B. 0/1背包枚举容量时从大到小，完全背包从小到大
C. 0/1背包和完全背包的初始化方式不同
D. 0/1背包中每件物品可以选多件

> **答案：B**
> 解析：两者转移方程形式相同（max(dp[j], dp[j-w]+v)），只是枚举方向不同。0/1背包从大到小防止重复选，完全背包从小到大允许重复选。

---

**第3题：** 多重背包的二进制分组优化中，将 num[i] 个物品分组后，每组物品作为（ ）处理

A. 完全背包物品
B. 0/1背包物品
C. 多重背包物品
D. 分组背包物品

> **答案：B**
> 解析：二进制拆分的本质是将多重背包转化为 0/1 背包，每个拆分出的组合作为一件只能选或不选的新物品。

---

**第4题：** 设序列 A = [5, 2, 8, 6, 3, 6, 9, 7]，则 LIS（最长严格上升子序列）的长度为（ ）

A. 3  B. 4  C. 5  D. 6

> **答案：B**
> 解析：dp = [1,1,2,2,2,3,4,4]，max = 4。例如 2,3,6,9 或 2,6,9... 不对，2<3<6<9=4个，2<8<9=3个，所以是4（2,3,6,9；2,3,6,7等）。答案 **B（4）**。

---

**第5题：** LCS 问题的状态转移方程中，当 A[i] ≠ B[j] 时，dp[i][j] 等于（ ）

A. dp[i-1][j-1]
B. dp[i-1][j] + dp[i][j-1]
C. max(dp[i-1][j], dp[i][j-1])
D. min(dp[i-1][j], dp[i][j-1])

> **答案：C**
> 解析：A[i]≠B[j] 时，要么不选A[i]（dp[i-1][j]），要么不选B[j]（dp[i][j-1]），取两者较大值。

---

**第6题：** 区间 DP 的标准枚举框架中，最外层循环应枚举（ ）

A. 左端点 i
B. 右端点 j
C. 区间长度 len
D. 分割点 k

> **答案：C**
> 解析：必须先确保短区间的结果先计算完，所以最外层枚举区间长度从小到大。

---

**第7题：** 关于图的邻接矩阵，下列说法不正确的是（ ）

A. 无向图的邻接矩阵是对称矩阵
B. 邻接矩阵查询两点间是否有边的时间复杂度为 O(1)
C. 邻接矩阵的空间复杂度为 O(E)
D. 稠密图适合用邻接矩阵存储

> **答案：C**
> 解析：邻接矩阵的空间复杂度为 **O(V²)**，与边数 E 无关（即使 E 很少也要 V² 的空间）。

---

**第8题：** BFS 适用于（ ）

A. 找无权图中两点之间的最短路径
B. 找有权图中两点之间的最短路径
C. 枚举图中所有可能的路径
D. 判断图是否有环

> **答案：A**
> 解析：BFS 能保证找到**无权图（或均匀权重）**的最短路。有权图需要 Dijkstra 等算法。

---

**第9题：** DFS 和 BFS 的空间复杂度分别是（ ）

A. 都是 O(V)
B. DFS 是 O(最大深度)，BFS 是 O(最大层宽)
C. DFS 是 O(V)，BFS 是 O(E)
D. BFS 总比 DFS 占更少内存

> **答案：B**
> 解析：DFS 的栈深度等于搜索树的最大深度；BFS 队列中同时存在一层的所有节点，宽度等于最大层宽。

---

**第10题：** 哈希表在最坏情况下的查找时间复杂度是（ ）

A. O(1)
B. O(log n)
C. O(n)
D. O(n²)

> **答案：C**
> 解析：最坏情况下（所有元素哈希到同一个桶），退化为链表，查找需要 O(n)。期望情况下为 O(1)。

### 判断题专练（10题）

**判断题1：** 背包问题中，若 dp[j] 的初始值为 0，表示"不超过 j 容积的最大价值"；若初始值为 -∞（除dp[0]=0），则表示"恰好等于 j 容积的最大价值"。（ ）

> **答案：✅ 正确**

**判断题2：** LIS 的最终答案是 dp[n]（以最后一个元素结尾的最长上升子序列长度）。（ ）

> **答案：❌ 错误**。最终答案是 max(dp[1..n])，不一定以最后一个元素结尾。

**判断题3：** 区间 DP 的时间复杂度通常是 O(n³)（三重循环：区间长度、左端点、分割点）。（ ）

> **答案：✅ 正确**

**判断题4：** 在无向图中，顶点的度数等于邻接矩阵该行（或列）中非零元素的个数。（ ）

> **答案：✅ 正确**

**判断题5：** BFS 在有向图中同样可以求最短路径（无权图）。（ ）

> **答案：✅ 正确**。BFS 对有向图和无向图都适用，只需按照有向边方向扩展。

**判断题6：** Flood Fill 算法本质上是一种 DFS 或 BFS，在二维网格上的连通块标记。（ ）

> **答案：✅ 正确**

**判断题7：** `unordered_map` 能保证键值对按键的大小顺序排列。（ ）

> **答案：❌ 错误**。`unordered_map` 是无序的，若需有序请用 `map`。

**判断题8：** C++ 中 `log(x)` 函数计算的是以 2 为底的对数。（ ）

> **答案：❌ 错误**。`log(x)` 是自然对数（以 e 为底），以 2 为底用 `log2(x)`。

**判断题9：** 多重背包二进制优化后，可以将时间复杂度从 O(N×V×max_num) 降至 O(N×V×log(max_num))。（ ）

> **答案：✅ 正确**

**判断题10：** 若图有 V 个顶点，最多有 V×(V-1)/2 条边（无向简单图）。（ ）

> **答案：✅ 正确**。完全图的边数 = C(V,2) = V×(V-1)/2。

## 四、编程题训练（45分钟）🎈

### 编程题1：最大背包价值（综合，30分）

**题目描述：**

有 N 种物品，背包容量为 V。每种物品有体积 w[i]、价值 v[i] 和类型 t[i]：
- t[i] = 1：只有1件（0/1背包）
- t[i] = 2：无限件（完全背包）
- t[i] = 3：有 s[i] 件（多重背包，二进制优化）

请输出能装入背包的最大总价值。

**输入格式：**
- 第一行：N V
- 接下来 N 行：每行包含 t w v（若 t=3，还有 s）

**输出格式：**
- 最大总价值

**样例输入：**
```
4 10
1 2 3
2 3 5
3 4 7 2
1 1 2
```

**样例输出：**
```
19
```

**参考代码（混合背包）：**
```cpp
#include <iostream>
#include <vector>
using namespace std;

int dp[10005];

void zeroOne(int w, int v, int V) {
    for (int j = V; j >= w; j--)
        dp[j] = max(dp[j], dp[j-w]+v);
}

void complete(int w, int v, int V) {
    for (int j = w; j <= V; j++)
        dp[j] = max(dp[j], dp[j-w]+v);
}

int main() {
    int n, V; cin >> n >> V;
    for (int i = 0; i < n; i++) {
        int t, w, v; cin >> t >> w >> v;
        if (t == 1) {
            zeroOne(w, v, V);
        } else if (t == 2) {
            complete(w, v, V);
        } else {
            int s; cin >> s;
            for (int k = 1; k <= s; k *= 2) {
                zeroOne(k*w, k*v, V);
                s -= k;
            }
            if (s > 0) zeroOne(s*w, s*v, V);
        }
    }
    cout << dp[V] << endl;
    return 0;
}
```

### 编程题2：图的最短路（综合，30分）

**题目描述：**

给定 N 个城市，M 条无向道路，每条道路需要 1 小时。从城市 S 出发，问到达每个城市各需要多少小时，若无法到达输出 -1。

**输入格式：**
- 第一行：N M S
- 接下来 M 行：u v（无向边）

**输出格式：**
- N 行，第 i 行输出城市 i 的最短时间

**样例输入：**
```
5 5 1
1 2
1 3
2 4
3 5
4 5
```

**样例输出：**
```
0
1
1
2
2
```

**参考代码：**
```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <cstring>
using namespace std;
vector<int> adj[10005];
int dist[10005];
int main() {
    int n, m, s; cin >> n >> m >> s;
    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v); adj[v].push_back(u);
    }
    memset(dist, -1, sizeof(dist));
    queue<int> q;
    q.push(s); dist[s]=0;
    while (!q.empty()) {
        int u=q.front(); q.pop();
        for (int v : adj[u]) if (dist[v]==-1) { dist[v]=dist[u]+1; q.push(v); }
    }
    for (int i = 1; i <= n; i++) cout << dist[i] << "\n";
    return 0;
}
```
